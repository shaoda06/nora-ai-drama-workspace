# 短剧项目

每部短剧使用本目录下的独立项目目录。按照Nora短剧技能完成初始化，资料、素材、执行记录及项目自身设置保存在对应项目中。ComfyUI服务地址与认证由工作区根目录的 `comfyui-config.json` 共用，项目内不另建配置，具体按[工作区配置规则](../.agents/skills/nora-generation/references/ComfyUI-服务配置与任务提交规范.md#工作区-comfyui-配置)执行。

首页与顶部菜单的顺序使用 `项目总索引.md`，新建项目时同步登记，具体见[项目总索引规范](../.agents/skills/nora-ai-short-drama/references/共用规则/项目初始化规范.md#项目总索引)。

公共工作区模板只跟踪本说明，真实项目均由根目录 `.gitignore` 排除。需要项目版本管理或备份时单独安排，不依赖公共模板仓库。

目录使用边界及测试资料归属统一见[主技能技术测试规则](../.agents/skills/nora-ai-short-drama/references/共用规则/文件版本与工作稿规范.md#技术测试资料归属)。
