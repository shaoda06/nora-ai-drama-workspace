# 开发记录模板

填写规则见[开发记录规范](开发记录规范.md)。复制下面正文到 `docs/开发记录/WNNN-事项名称.md`，替换占位内容；没有未完成事项时删除最后一节。不要把模板文件本身当作W记录。

```markdown
# WNNN：事项名称

日期：YYYY-MM-DD
状态：进行中／待验证／待发布／已完成（选择一项）
关联版本：实际关联版本及发布状态；未发布或不涉及发布时如实注明

## 修改原因

具体问题、预期结果及本次范围。

## 具体改动

实际完成的修改；必要的取舍、关键文件或引用。

## 验证结果

实际执行的检查及结果；尚未验证时明确写“尚未验证”。

## 未完成事项

具体待办、未解决问题或需要用户决定的事项；没有则删除本节。
```
