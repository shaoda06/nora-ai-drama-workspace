# W412：本镜通过插入分镜起始意见

日期：2026-10-26
状态：已完成
关联版本：v0.8.119（已发布）

## 修改原因

修改意见编辑栏重复显示标题；用户希望一键填写当前分镜通过意见，时间使用该候选历史分镜的起始秒数。

## 具体改动

去掉编辑工具行的“修改意见”标题，文本框保留无障碍名称；在“插入时间”“清空”前增加“本镜通过”。SegmentWorkspace复用当前候选历史分镜的累计时长与当前镜头，传入起始秒数；点击插入该镜起点、镜号及“这个分镜没问题”，分镜起点按十分秒显示时消除累加浮点误差。缺少视频、有效分镜时长或意见尚未读取时禁用。

复用原插入处理：未聚焦时追加，编辑时替换当前选区、光标移到新增文本后；保留长度上限及自动保存。“插入时间”仍使用当前播放位置；只写审看意见，不改变采用或批准状态。同步页面实现说明与覆盖表，未新增公共组件或改业务存储。
