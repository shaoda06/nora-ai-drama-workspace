# W345：候选采用标签与重建编号整理

日期：2026-10-23
状态：已完成
关联版本：v0.8.32（已发布）

## 修改原因

采用是候选的状态，不是独立版本；重建实际产出需保留独立候选，选择候选后不能被轮次默认文件替换。

## 具体改动

版本选择保留候选名并以独立“已采用”标签标识批准状态，候选按编号倒序显示。切换轮次后保留明确选择的具体文件。为标签补足版本按钮宽度，其余布局结构保持。按用户要求将片尾一次缓存重建独立为一采R005（第6轮），二采R001计划顺延至第7轮且来源R005。扩展固定迁移工具支持只拆出指定的一次历史执行，保持原R003及批准，原任务ID、请求、工作流和取回凭据不改字节；同步候选规则及调用说明。

## 验证结果

- 场次选择回归11项通过，包括同R有不同文件时明确选择不被轮次默认项替换；首次新增用例复现了旧轮次状态键丢失问题，修正后通过。
- 编号迁移回归6项通过；新增覆盖只改指定任务、保留原候选批准与来源、原请求/凭据/视频字节及目标冲突。首次在macOS符号临时目录运行出现路径不一致，改用物理临时目录并兼容任务记录相对项目路径后通过。
- Nora技能校验通过；检索并订正同配置重建不增号的现行规则冲突，沿原规范维护唯一编号入口。
- 固定迁移工具先预览，再在服务停止时完成：移动2处、更新3份当前记录和1条后台任务；原R003任务入口及已采用状态保留。原第6轮未提交二采准备作历史保存，第7轮prepare-only检查通过，实际二采任务数为0。
- 前端TypeScript与正式构建通过，统一启动器重启后/api/service为v0.8.32、ready=true。
- Browser plugin not available，使用已有Playwright在真实片尾页验证1362×918及390×844视口：5个一采候选无重复“正式版”项；候选三带已采用标签；R003/R004/R005分别切至第4/5/6轮并播放对应文件；移动端标签完整、菜单不越界。首次窄屏检查发现标签截断，补足按钮宽度后通过；已查看截图。
