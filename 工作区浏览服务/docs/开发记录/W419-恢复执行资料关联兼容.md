# W419：恢复执行资料关联兼容

日期：2026-10-27
状态：已完成
关联版本：v0.8.127（已发布）

## 修改原因

同一视频任务恢复执行后，原目录与恢复子目录各自保存输入映射，沿用同一候选编号但冻结素材路径不同。浏览器将它们当成互相冲突的生成资料，导致项目反复读取失败。用户要求保留原执行记录并恢复浏览。

## 具体改动

- 仅对带有 recovery.original_local_task_id 且位于原映射目录内的恢复记录，按 generation_contexts_recorded_at 选择最新冻结资料；不依赖遍历顺序、文件修改时间或恢复文件夹命名。
- 原执行记录和恢复附件继续保留在资料树中，不修改、移动或删除真实项目文件。未标记恢复关系、其他任务目录或无法区分先后的冲突继续校验。
- 更新解析缓存版本，避免重启后继续使用旧的资料关联。
- 测试夹具统一解析临时项目的真实路径，避免 macOS /var 与 /private/var 目录别名使路径边界检查跳过测试资料。
