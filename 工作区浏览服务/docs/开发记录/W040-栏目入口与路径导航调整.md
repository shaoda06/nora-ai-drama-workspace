# W040 栏目入口与路径导航调整

日期：2026-10-06。版本：0.1.0同版维护。

## 修改

从其他顶部栏目切入剧集制作时清除单集选择；只在剧集制作处于当前栏目时挂载EpisodeProduction，离开后移除本地分页和场次状态，重新进入显示选集第一页。其他栏目的已读内容和状态保留。单集内返回列表仍保留原分页，路径返回与按钮返回都把焦点还给原选集按钮。

项目各栏目正文框不再重复栏目标题；制作统计直接放在正文框顶部。项目主标题、实际文档章节和具体资产详情标题保留。Breadcrumbs从栏目开始，顶层只显示当前位置，单集详情显示“剧集制作 / EP编号”；当前位置由15px改为18px，前缀保持15px并作为链接。单集标题栏移除底色、边框、圆角和内边距，保留集号、题名、状态及返回按钮，场次选择和空白内容区延续原结构。

浏览检查发现W039场次提取中的story局部变量覆盖了主旨与简介的解析结果，使其接口返回500。本轮改名为script_body，并扩展原场次测试：读取含剧本及未开始集的项目后，主旨与简介接口仍返回200及原正文。没有添加错误吞并或修改项目原文件。

项目浏览入口规范v1.105→v1.106，修改前完整归档，更新组件说明及版本记录。
