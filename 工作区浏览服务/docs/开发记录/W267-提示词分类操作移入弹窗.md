# W267：提示词分类操作移入弹窗

日期：2026-10-22
版本：0.7.9

## 修改

移除分类树下方的“当前分类／改名／移动／删除”区域。在中间列表栏的分类名称旁增加铅笔图标，点击打开既有分类弹窗。弹窗保留分类名称与上级分类，新增删除按钮及同一弹窗内的确认／取消删除操作。

主目录、搜索结果和回收站不显示分类编辑入口。新建分类弹窗不显示删除按钮。分类删除继续使用已有版本检查和非空限制，失败信息显示在弹窗内；未保存提示词的离开提示保留。

- 左侧操作区移除，列表标题旁入口打开正确分类；新建／搜索不误显示编辑或删除入口。
- 弹窗内改名、移动、删除空分类、取消删除通过；非空分类删除失败保留弹窗与内容。
- 未保存提示词点击分类编辑，继续编辑保留输入；放弃后正常打开分类弹窗。
