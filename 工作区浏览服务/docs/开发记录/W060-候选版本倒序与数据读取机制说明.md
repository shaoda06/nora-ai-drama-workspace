# W060 候选版本倒序与数据读取机制说明

日期：2026-10-07。版本：0.1.0同版维护。

## 修改

SegmentWorkspace只调整版本下拉的候选排序为降序：正式版仍优先，其余候选按对应R从新到旧排列。候选编号继续由后端既有顺序生成，不因倒序重编号；默认最新、手动选择及场次内选择保留不变。浏览规范更新至v1.119，修改前按既定公式归档。

## 后端机制核对

Project的status查询每5秒发起；ProjectStore收到查询后，在距上次文件扫描至少3秒且未同步时，比较本地文件路径、修改时间及大小。首次访问直接解析并缓存；有变化时后台重新调用build_data，成功后revision递增，网页发现新版本后读取活动栏目；同步中保留上一份完整数据。后端不持续查询ComfyUI，也不主动下载媒体。

project解析器发现规范目录内的实际视频文件，以完整EP/C/P/R/阶段对应执行附件输入映射中的generation_contexts；generation解析器只读取该关联指向的历史资料，不凭视频文件或现行正文推断输入。统一提交入口在POST前自动保存当次关联及快照。任务完成后的实际输出选择、下载落盘及执行记录维护仍由Agent按原流程处理；人工批准后维护采用记录，网页据本地事实自动更新，无额外网页关联或HTML导出步骤。

本轮没有改变后端读取、生成提交或结果取回流程，也未修改真实项目文件。
