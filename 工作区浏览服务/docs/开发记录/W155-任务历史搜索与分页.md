# W155：任务历史搜索与分页

日期：2026-10-11。发布版本：v0.6.9。

## 实现

当前节点的历史列表支持按任务标题或来源会话名称进行部分匹配，忽略英文字母大小写和搜索词首尾空格。结果筛选包含全部结果、已完成、异常、已取消，支持与搜索组合。异常包括生成失败、提交被拒、取回失败、状态待核对、提交结果待核对；生成结束后正在取回全部成果的任务仍在全部结果中展示，不提前算作已完成。

默认按实际结束时间倒序读取最近20条，旧记录缺少结束时间时按登记时间排序；加载更多每次追加20条，读完后隐藏按钮。历史标签显示当前节点全部历史数量，列表底部显示已加载数量／当前条件匹配数量。切换节点、分类或搜索筛选条件时从首批重新读取，不串节点记录。没有匹配内容时显示明确空态。

新接口 `GET /api/comfy/history?url=...&q=...&result=...&offset=0&limit=20` 只读筛选现有TaskStore记录，返回卡片字段、匹配总数及下一页位置，不读取工作流或成果文件，不改任务状态，不提交、下载或发送Agent通知。limit边界为1–100，offset不能为负数，结果类型使用接口枚举。详情复用既有详情接口和标题行入口。

网页任务列表及原SSE指定include_history=false，不再携带全部历史卡片；返回活动任务、每节点分类数量及历史更新时间。原接口默认完整快照保持兼容。历史沿SSE更新当前条件下所有已加载页面，保留搜索、筛选和加载范围；列表按任务ID去重。打开的详情沿当前节点历史更新时间刷新。请求失败显示原因与重新读取，加载更多失败保留已显示卡片。
