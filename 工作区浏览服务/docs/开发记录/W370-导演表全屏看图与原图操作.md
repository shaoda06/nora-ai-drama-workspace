# W370：导演表全屏看图与原图操作

日期：2026-10-23
状态：已完成
关联版本：v0.8.58、v0.8.59、v0.8.61（均已发布，以v0.8.61为当前交付）

## 修改原因

点击导演表直接进入铺满浏览区域的全屏看图模式；原图查看和下载放到图片下方页码行右侧。当前IAB未提供requestFullscreen原生接口，采用公共Dialog的全视口规格，不调用系统全屏。

## 具体改动

公共Dialog增加fullscreen规格，固定定位并铺满浏览视口，关闭按钮及Esc沿公共实现。全屏打开时取消页面滚动条预留并锁定背景滚动，关闭后恢复。SceneDirectorSheets直接进入此规格，图片适应剩余空间，沿用圆形左右箭头；关闭后保留当前页，不打开原Preview图片浮窗。生成／审阅记录仍沿用原Preview。

FileActions增加可选viewLabel／downloadLabel，默认文案及下载地址处理不变。导演表下方页码居中，右侧复用FileActions显示查看原图／下载原图，手机换行。公共展示、规则、覆盖说明及测试同步。导演表规则同步默认全屏及原图入口位置，旧规范已按本地时间归档；没有更改项目图片、正文及采用事实。

## 验证结果

暂存快照静态检查0项违规。1362px、390px及320px隔离浏览器检查通过：全屏尺寸与视口一致、全屏内翻图、Esc退出后保留当前页、关闭按钮、首尾箭头、原图链接及下载参数、页码居中／链接靠右、手机换行、无横向溢出；公共展示真实fullscreen规格及自定义文件文案验证通过，其他弹窗／消息和分页现有检查保留。规则quick_validate通过，现行规范与页面说明一致。

v0.8.58首次发布后，真实IAB发现稳定滚动条预留使全屏宽度少15px；v0.8.59仅在全屏时取消预留，实测全屏框为[0,0,1362,918]、视口1362×918，退出恢复原滚动条规则。真实页面点击直接全屏，左右翻图正常，退出保留当前页；下方查看原图和下载原图指向当前图片，页码居中、原图操作靠右。页面非空、无框架错误覆盖，控制台无error/warn。截图：/tmp/nora-director-fullscreen.png、/tmp/nora-director-original-actions.png。

## v0.8.61补充：去掉全屏顶部栏

用户要求删除全屏顶部整条标题／关闭区域。公共Dialog增加showHeader参数，默认保留顶部栏；导演表全屏及公共展示的真实示例使用无顶部栏规格。仍保留aria-label，点击图片或按Esc退出，左右翻图和当前页保留不变。普通弹窗与生成／审阅记录不变。

验证：暂存静态检查0项违规；1362px、390px及320px隔离检查通过，覆盖顶部栏不存在、全视口尺寸、Esc／点击图片退出、翻图及退出保留当前页，公共展示使用真实无顶部栏规格。人工核对未复制弹窗或覆盖公共顶部栏样式，新增showHeader参数默认不改变其他弹窗。统一启动器构建并重启8782后，/api/service返回v0.8.61、ready=true。真实IAB确认顶部栏不存在、全屏框为[0,0,1362,918]，翻到第2页后点击图片退出，页码和原图链接保留第2页；页面非空、无框架覆盖、控制台无error/warn。截图：/tmp/nora-director-headerless.png。Browser插件未提供，使用现有隔离Playwright用例及内置浏览器CUA核验UI；不改真实项目资料。
