# W377：分段视频重复播放与连续播放互斥

日期：2026-10-24
状态：已完成
关联版本：v0.8.69（已发布）

## 修改原因

在分段播放器“连续播放”左边增加“重复播放”：当前视频结束后从头循环；连续播放开启时自动关闭并禁用重复播放，保留当前轮次的连续播放逻辑。

## 具体改动

- SegmentVideo增加默认关闭的“重复播放”，位于“连续播放”左侧，使用原生video.loop，不另建播放队列；切换视频分段或版本后重置，无视频时禁用。
- SceneWorkspace通过SegmentWorkspace传递连续播放状态，开启后立即停用循环并清空重复选择；取消连续播放后不自动恢复重复播放。原有按当前轮次切段、缺失下一段时停止的逻辑保留。
- 普通与宽屏使用同一控件和既有复选框样式；真实组件展示可操作两个开关，演示明确不驱动项目队列，并同步组件覆盖表及实现说明。
- 手机空视频用例发现占位的固有宽度撑大隐式网格列，继而让宽屏操作行越界；公共播放器网格使用minmax(0,1fr)约束列宽，保留操作区换行，不添加页面覆盖。
- 仅涉及浏览服务，不修改项目资料或生成任务。
