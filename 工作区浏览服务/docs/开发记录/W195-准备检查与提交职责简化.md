# W195 准备检查与提交职责简化

日期：2026-10-15。版本：0.6.58。

## 分工与实现

Agent负责内容准备、内容合理性判断、调用工具和读取报告／结果；工具负责实际上传、提交、技术核验、状态和执行报告。内容核对在准备阶段完成，授权后不重新审稿或人工复查脚本项目。

统一入口增加`--prepare-only`，通过本机凭证调用准备接口，不上传、不入队、不提交生成。工具在原执行附件保存`执行检查报告.json`，检查本地配对、实际输入与输出映射，以及H3实际拼接字符数、标签、媒体份数／时长。保留现有模板字段和审批结构，未变化的准备结果直接复用；输入或源文件变化时停止，显式返回准备阶段，不改稿后继续提交。旧排队任务没有新报告时保留原有执行路径，不补造旧准备事实。

正常准备与提交不查询`/object_info`、`/models`或`/system_stats`验证能力，不新增能力缓存或时效门槛。节点、模型及远端参数支持由ComfyUI实际接收／执行时判断。提交拒绝和执行错误在原技术报告中保存原始详情，专用Agent状态接口返回error_details；不自动重发、切服务或改参数。独立能力盘点技能仅用于明确要求的盘点／诊断。

H3在同端和转移后均保留阶段缓存、所需前段缓存检查，避免一采意外执行二采；队列仍在上传前与最终POST前核对。防重复POST、未知接受不重发和已有成果不覆盖保持不变。

新上传使用实际传输时生成的指纹，不为重复槽位再次读文件；恢复已有凭据时每个唯一源文件计算一次，所有凭据都必须匹配。源文件过程中变化时保留已发生的上传凭据并停止。冻结资料按唯一文件复用读取，保留同名不同内容、旧版本和审核事实的保护。

共同运行状态与技术报告由后台保存，各P不抄写整批状态、数量、异常及任务身份。模板引用共同入口，保留本段资料、成果和人工审阅。工具报告可在任务详情已有记录列表打开，无新增前端字段或审核关卡。
