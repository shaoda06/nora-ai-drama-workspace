# W421：选集列表显示时长并限制两列

日期：2026-10-27
状态：待发布
关联版本：v0.8.129（待发布）

## 修改原因

剧集制作选集列表一行最多显示两个入口，窄屏换行；制作状态前显示本集时长，沿用实际视频优先、缺失值用计划补足并加星号的规则。

## 具体改动

制作列表使用公共选集网格两列规格，700px及以下一列；分集大纲保留原网格。EpisodeButton新增可选duration，显示在制作状态前；标题、集名状态为一组，窄屏下时长与制作状态为一组换行，长题名省略，不拆开编号或挤出状态。

ProductionEpisodeButton仅给当前页入口读取已有单集播放API，按每集最新共同轮次或最新旧场次轮次组合统计。复用W420时长计算、文件版本缓存及详情查询，不新增后端接口或改写项目。片头片尾同样统计；读取异常用公共消息并保留重试。未知时长不显示为0。

公共展示同步真实的两列／手机单列、实际／带星号计划／无时长及长题名示例，更新覆盖表与自动布局检查。
