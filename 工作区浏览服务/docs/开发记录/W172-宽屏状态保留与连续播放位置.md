# W172 宽屏状态保留与连续播放位置

宽屏状态原先保存在带分段key的SegmentWorkspace中，切换分段重新挂载时回到普通布局。状态改由SceneWorkspace通过既有useRefreshState保存，传递给分段和视频组件。同一场次的手动切段、画质、候选版本和连续播放切段不会重置布局；点击“恢复布局”改回普通状态，并在之后切段时继续保持。状态参与既有自动刷新位置保存。

连续播放仍由场次控制，仅将控件放到视频下方、宽屏显示按钮左侧。导出修改意见保持在顶部选择行。勾选框改为紧凑样式，手机窄屏下视频来源和操作行可换行，避免横向溢出。

TypeScript与Vite生产构建通过；8782前后端v0.6.33、production、ready=true，工作区指向G盘。Browser插件不可用，使用现有Playwright和Chrome无头浏览器，在用户当前127.0.0.1地址验证荒院暴富EP003。
