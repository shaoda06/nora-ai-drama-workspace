# W384：菜单内容宽度与图片比例及预览下载

日期：2026-10-25
状态：已完成
关联版本：v0.8.84（已发布）

## 修改原因

用户要求菜单最小与触发按钮同宽，内容可自然撑宽，不设固定最大宽度；图片尺寸后追加网页计算的简化比例；通用图片预览移除查看原图，只保留居中的下载入口。

## 具体改动

- TabSelect使用内容自然宽度、触发按钮最小宽度；仅保留屏幕边界限制，纯图标也按内容适配。
- AssetMediaCard原本即通过图片加载后的naturalWidth／naturalHeight读取真实尺寸，在现有宽高后计算最简整数比，不改文档格式或实际文件。
- 通用Preview的图片分支复用FileActions下载和居中规格，文档、视频、音频等非图片预览不改变原入口。
