# W376：统一图片候选与正式名称校验

日期：2026-10-24
状态：已完成
关联版本：v0.8.68（已发布）

## 修改原因

图片保存入口只检查候选后缀，未把名称绑定到对应正式图片；Qwen还可能用布局类型拼文件名。需要统一生成、处理及手工保存入口的命名核对，并保留历史任务恢复。

## 具体改动

图片生成请求声明对应正式路径formal，Imagegen准备与保存、Qwen统一装配、新图片登记和后处理共用同一命名核对。Qwen按正式图片名分配候选和v版本，图片类型继续只用于布局、模板和种子。RTX超分与本地规格处理核对批准源图和输出编号。社交图片及直接复制正式图可调用只读check-name；保留社交原生／宽高标识、导演表页码及无独立正式图的画风样例格式。历史请求、已登记任务和恢复路径不追溯修改。

维护共用规则、Imagegen／Qwen／后处理及社交手工保存入口和工具说明，移除候选与正式图片身份不一致的旧示例。

207项相关测试通过：图片准备／原生收尾／后处理109项，固定CLI命名7项，任务登记／执行检查／队列及历史恢复90项，旧式新登记绕过检查1项。均使用独立临时项目，不调用真实生成，不写生产项目。测试在macOS使用TMPDIR=/private/tmp避开临时目录路径别名。3个技能入口校验通过；已检查规则真源、上下游引用及新命令帮助，相关文件链接无缺失。正式前端构建通过；统一启动器重启8782后，/api/service返回v0.8.68、ready=true。人物、场景、道具和封面栏目无资料警告；319项历史任务状态保持315项完成、4项失败，没有新增或重新生成任务。
