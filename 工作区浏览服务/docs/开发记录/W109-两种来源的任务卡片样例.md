# W109：两种来源的任务卡片样例

日期：2026-10-09
状态：原记录未单列，以正文为准
关联版本：原记录未单列，以正文为准

## 修改原因

用户要求先看本机提交和其他设备提交两种样例，再讨论细调。任务卡片提取为独立TaskCard组件，共用骨架，按来源展示不同内容；样式移入TaskCard.css，侧栏继续负责节点分页和上下队列布局。

## 具体改动

本机卡片展示来源、执行状态、项目与制作类型、任务名称、当前阶段、分段进度、当前阶段采样步数及成果取回数量。原组序、完整任务ID、逐段取回及通知状态放入可展开的任务详情。

其他设备卡片展示来源、状态、短任务ID、提交时间和排队位置，完整ID放入任务详情。已有结果数量和错误信息有对应展示位置；样例不伪造实时采样进度、项目名或剧集名。

5179模拟测试页新增smoke=cards、smoke=local-card及smoke=external-card，分别展示两张卡片和单张卡片；smoke=mixed也包含两种来源。所有样例均为模拟数据，未接入其他客户端的真实远端任务查询。本地队列仍留空，正式8782仍使用0.4.3构建，本次不正式发布。

## 验证结果

类型检查及预览构建通过。浏览器验证两种来源、详情展开、采样进度仅出现在本机卡片；390px移动窗口无卡片横向溢出，节点标签滚动时位置不变，控制台无相关错误。局域网预览返回200并保持运行，已保存两张卡片截图供用户审阅。
