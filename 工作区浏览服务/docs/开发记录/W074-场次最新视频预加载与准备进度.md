# W074 场次最新视频预加载与准备进度

日期：2026-10-07。codex/browser-dev开发分支，仅更新8783前端，未发布至main或8782。

## 实现

进入场次后，SceneWorkspace按现有latestVideo规则为每段取一个最新视频，交useSceneVideoCache依照分段剧情顺序逐个完整读取，当前第一段优先、接着下一段和其余段。不批量预加载历史候选；没有视频的分段不计入准备数量，没有任何视频时不显示准备提示。

临时缓存使用浏览器Blob与Object URL，不写服务器runtime或项目文件。准备进度位于分段条下方灰线之后、画质和候选选择按钮之前，灰色12像素小字靠右显示：“最新视频已准备 X／Y”或“本场最新视频已全部准备好”；失败时显示失败数量，悬停可查看读取错误，其他文件继续准备，播放器仍可正常按需读取。

SegmentWorkspace把对应缓存地址交给SegmentVideo。切到已经准备好的视频时直接播放缓存，视频原文件链接仍指向真实文件；旧候选按需加载。当前已经加载的播放器在后台缓存完成时保持原地址，避免播放跳回开头。文件更新仍沿用“视频已有更新／加载新文件”，缓存按已有带文件版本号的URL区分，不自动替换正在播放的文件。只保留本场次的缓存；若当前场次出现新文件，上一文件缓存暂留到离开以支持原播放器，未变的文件不重复下载。离开场次时取消进行中的预加载并撤销所有Object URL；切到本场的场次分镜标签时，缓存继续准备并可供返回使用。

Browser plugin not available，沿用已有Chrome／Playwright。TypeScript／Vite构建通过，没有安装新依赖。
