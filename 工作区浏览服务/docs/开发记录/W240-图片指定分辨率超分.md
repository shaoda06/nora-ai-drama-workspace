# W240 图片指定分辨率超分

状态：已发布v0.6.117；隔离回归与服务核验通过。

## 实现范围

- `submission_plans.build_image`沿用既有`size`字段，显式宽高时选择RTX的`target dimensions`；缺省仍为2倍。正整数宽高校验在清单边界完成，不把原图强制处理成Qwen送审尺寸。
- `image_workflow`只改任务副本，同步宽高动态控件、位置控件和API；质量ULTRA、强度1.0、8-bit RGB、输入节点2及输出节点3保持。随包2倍工作流未改。
- `image_closeout`接受两种模式，指定尺寸须与成果计划相等，实际PNG仍必须达到计划；原批准章节、具体候选、上传凭据和正式保存要求不变。记录填写真实处理方式与原生尺寸，批准事实和原图保留。
- 调用说明及Imagegen规则同步到已支持的入口。没有新增前端操作或页面变更；版本号按统一发布约定递增。
