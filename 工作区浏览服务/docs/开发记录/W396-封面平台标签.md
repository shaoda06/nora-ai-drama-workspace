# W396：封面平台标签

日期：2026-10-25
状态：已完成
关联版本：v0.8.102（已发布）

## 修改原因

用户要求封面页面增加通用、抖音、小红书、快手四个平台子标签，切换查看对应封面。

## 具体改动

CoverLibrary复用UnderlineTabs，按指定顺序筛选当前采用封面及候选，继续按套组显示；多平台成品在各自平台出现，默认选择第一个已有成品的平台。平台没有采用封面时显示对应空状态。旧采用图和旧候选缺少平台时，保留独立折叠入口，不归入通用、不删除或改写原记录。候选平台只读取原生成记录的显式字段，缺失字段的“未记录”按未登记处理。

继续复用AssetMediaCard、Dialog和FileActions，套组及平台过滤后的图片仍使用原文件和批准关联。未增加平台编辑或生图操作。

## 验证结果

13项封面解析与登记测试通过，覆盖候选的显式多平台和旧字段缺失。真实组件隔离测试在1362px、390px、320px下检查四标签顺序、平台切换、同套横竖版、多平台共用的成品及候选、空平台、未登记旧资料和详情文件入口；人物／场景／道具与封面共用文件操作回归在桌面和手机通过。详情的内容随原生toggle事件更新，测试等待可见候选后检查结果。TypeScript与隔离正式构建通过。

- 公共组件复用检查：未扩展或复制公共组件，UnderlineTabs的既有外观及交互直接复用；只增加业务过滤和共用卡片编排，没有页面限定样式覆盖。同步组件说明中的调用位置和业务归属；暂存快照静态与三档公共组件浏览器检查通过，已人工核对实际页面筛选和历史入口。
