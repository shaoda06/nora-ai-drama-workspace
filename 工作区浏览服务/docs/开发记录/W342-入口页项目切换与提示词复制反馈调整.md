# W342：入口页项目切换与提示词复制反馈调整

日期：2026-10-23
状态：已完成
关联版本：v0.8.29（已发布）

## 修改原因

用户要求首页不显示项目切换按钮，并修复提示词复制后的已复制提示撑高操作区问题。旧CopyButton在没有onMessage时把notice段落插入按钮组；实测操作区从38.09375像素变成67.5像素，正文区随之缩小29.40625像素。

## 具体改动

- ProjectSwitcher在首页路由/不渲染TabSelect，保留品牌链接及其他页面的项目切换入口。
- 提示词库与回收站两处CopyButton传入现有useNotify，复制反馈通过左下角公共通知显示并按公共规则关闭，不再在操作区插入notice。不改复制正文、保存或删除行为。

## 验证结果

- TypeScript及前端构建通过；统一启动器重启8782后，/api/service返回v0.8.29、ready=true，服务目录与工作区正确。
- Playwright/Chromium在1362×918桌面与390×844手机尺寸验证：首页切换按钮数量为0，提示词页为1；复制后公共通知出现并自动关闭。
- 两种尺寸复制前后按钮区的位置、宽高与正文区的位置、宽高完全一致；桌面按钮区稳定为38.09375像素，没有内联notice或页面脚本错误。已查看桌面截图。
- 测试替换浏览器剪贴板写入函数并核对收到的正文与隐藏复制缓冲区一致，没有改写系统剪贴板。
- 回收站使用浏览器内模拟GET响应验证，复制正文匹配、公共通知显示、操作区位置尺寸不变；没有删除、恢复或新增真实资料。
- 临时脚本、测量结果及截图保存在/tmp，未入库。
