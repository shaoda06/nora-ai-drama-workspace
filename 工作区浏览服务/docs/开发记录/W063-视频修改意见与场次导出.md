# W063 视频修改意见与场次导出

日期：2026-10-07。

## 问题与结果

用户希望审看片段时分别记录多版本意见，并按当前场次统一整理。分镜显示方式增加“修改意见”，下方切为注明项目、EP、C、P、阶段、候选／正式版和R的文本框；视频继续播放，返回对齐／全部不清空意见。画质与版本未选齐时禁用入口。

## 存放与保存

逐集目录规范v1.39统一规定场次专项JSON：`09-剧集制作/EP编号/其他资料/工作稿/EP编号-C编号-视频修改意见.json`。按P／阶段／R分条，记录原话、带时区更新时间及正在播放文件的既有fileRevision。候选采用、同R文件更新及Agent完成修改不自动清空；新R为空。同R文件更新后提示旧意见基于更新前文件，再次编辑才更新该标记。备注独立于执行、输入冻结和审批，后续Agent仅在获授权整理／修改时读取，不自动生成任务。

backend.services.revision_notes使用现有项目路径边界、Pydantic输入校验、锁内读改写及临时文件替换；同场多条保存互不覆盖。文件损坏、身份不一致和写入失败明确返回错误，保留旧文件。GET不创建文件；PUT只接受本机／局域网同源请求，同源校验与Krea更新共用，Krea原凭证校验保持。

revisionNotes外部状态按项目／EP／C缓存记录和每条草稿，不随页面组件卸载丢失；停笔约1秒自动保存、blur及编辑区卸载立即保存。请求逐条串行，较早响应不会覆盖新输入。失败保留草稿、显示未保存并提供重试；仍有未保存输入时刷新／关闭使用浏览器离开提醒，已保存内容从文件恢复。单条文本最多20000字符，界面与API一致。

## 导出与样式

工具行连续播放右侧增加导出按钮；汇总本场全部非空意见，依分段索引、阶段及同阶段R从新到旧排列，包含历史版本和有标记的未保存草稿。SceneWorkspace持有导出稿，复用Dialog、CopyButton，连续播放推进分段不丢弹窗编辑。复制当前文本，临时改稿不回写、不清空原意见、不新增导出文件。

UnderlineTabs取消整组灰色底线，选中项仅在文字宽度下显示绿色边框，底部留12像素距离，间隔无边框。模式按钮继续复用TabNav compact。

浏览入口规范v1.122同步页面行为及独立备注输入依赖；README与组件清单同步。两份技能规范在修改前均留存本地历史备份。
