# W355：提交前自动检查公共组件复用

日期：2026-10-23
状态：已完成
关联版本：不涉及发布（开发检查工具与规则，运行版本仍为v0.8.44）

## 修改原因

用户要求在人工提交前检查基础上，自动检查能够明确判断的重复实现与公共样式覆盖，其余事项继续人工核对。

## 具体改动

- 增加frontend/scripts/check-shared-components.mjs及规则模块，使用TypeScript语法树与PostCSS解析Git暂存内容，对比HEAD，只报告本次引入或改变的问题；支持新增、修改、重命名，删除文件不读取正文。不保存独立baseline，不添加页面豁免。
- 明确违规会返回非零状态并输出文件、行号与复用建议：公共实现以外的原生弹窗／菜单／搜索框／开关等已登记结构、直接复制、直接下载链接及公共组件根class的重复实现；页面限定选择器或公共样式实现以外的字号、颜色、内边距等外观覆盖。
- 容器宽度、外边距等空间分配不单独拦截；新增Blob URL只提示人工区分下载与合法媒体预览。动态样式、间接调用、未登记组件、业务差异和展示同步继续人工检查。
- 新增.githooks/pre-commit，并在本机仓库启用core.hooksPath=.githooks。提交前端src改动时自动执行；纯文档／其他资料提交不依赖Node。前端检查缺少Node或依赖时失败，不静默跳过。新克隆和其他设备需要按README各自启用，未覆盖已有自定义钩子。
- 增加check:shared、test:shared-check命令；PostCSS8.5.28作为直接开发依赖声明，复用已有锁定版本，没有升级其他依赖。更新README自动／人工分工、AGENTS及开发记录规范／模板。

## 验证结果

- pnpm test:shared-check的5组测试通过：原生结构与直接复制、样式覆盖与合法布局、Blob URL人工提示、历史未改问题与新增副本／媒体条件变化、真实Git提交钩子。
- 临时Git仓库实测：暂存违规且工作区已修复仍拒绝提交；暂存正确但工作区含违规可以提交正确快照；新增违规文件拒绝；重命名、删除与纯文档提交正常。全部使用临时资料，不修改真实项目或队列。
- sh -n检查提交钩子语法通过；本机core.hooksPath读取值为.githooks。手动check:shared确认当前没有暂存前端源码变更。
- 公共组件复用检查：本次只修改检查工具、开发依赖、钩子和文档，不改变UI组件、外观、交互或展示页。人工核对自动规则的判定边界、实现归属和跳过历史问题的方式；暂存内容自动检查结果按上述记录，不以测试通过代替未来UI改动的人工复核。
- 本次不构建或重启8782，不递增服务版本。
