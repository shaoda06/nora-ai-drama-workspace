# W415：下拉当前标记保持同行

日期：2026-10-26
状态：已完成
关联版本：v0.8.122（已发布）

## 修改原因

轮次下拉菜单的“当前”标记另起一行，选中项显著高于其他选项。

## 具体改动

在正式页只读复现：菜单选项允许flex换行，加上标题区4em最小宽，使“当前”标记被挤到下一行；第11轮选项高81.89px，其他项43.5px。临时验证后，在TabSelect公共CSS禁止整行换行、标题最小宽改为0，选中项恢复43.5px，标记与标题同行；长名称仍在文字区内换行，菜单的内容宽度、屏幕边界与原按钮宽度下限保持。同步真实组件展示说明、覆盖表和公共导航回归。

## 验证结果

- Browser plugin not available，使用现有Playwright；正式页复现仅GET，无项目写入。修复前新增的短轮次回归确实失败，提示“当前标记不能另起一行”；同一用例在修复后通过。
- 暂存快照check:shared通过：桌面1362px、手机390px／320px下验证短轮次及图标短选项的标记同行、选中与普通项等高；普通、紧凑、小号、工具栏／高亮及表单规格的长项仍能换行，当前标记不另起一行，菜单及内容不越界。原键盘、禁用、分页、消息、弹窗等公共回归同时通过。
- 公共组件复用检查：修复位于TabSelect唯一公共CSS，两条声明；未加业务页覆盖、固定宽度或另一套菜单，展示页直接使用原组件并同步简短规则与覆盖表。静态检查0项需修正／待判断，人工核对布局归属和实际使用入口无遗漏。
