# W432：片头片尾按当前方案显示时长

日期：2026-10-27
状态：已完成
关联版本：v0.8.139、v0.8.143（均已发布）

## 修改原因

片头、片尾的各场次代表独立方案，顶部合计全部场次会误导使用者。用户要求显示当前选中场次时长，正集继续显示本集总时长。

## 具体改动

制作详情顶部根据对象类型选择当前场次时长或本集总时长，提示文字同步说明统计范围。复用现有场次时长计算、实际媒体时长与计划时长标记，不改变列表卡片、下载或播放组合。
