# W375：相关资料增加账号资料入口

日期：2026-10-23
状态：已完成
关联版本：v0.8.66、v0.8.67（已发布）

## 修改原因

项目已有账号头像与主页背景图，但“相关资料”缺少入口。需要从现有账号视觉索引读取正式图，把候选和历史版本留在制作记录中，不复制项目资料或固化某个平台规格。

## 具体改动

- 新增通用账号资料解析器，读取`11-社交媒体资料/账号视觉索引.md`的当前正式表及链接到的具体审阅章节，核对批准、候选版本、正式路径和当前处置。文件存在不等于已采用，已被替换的旧批准不充当当前采用。图片真实尺寸通过已有Pillow依赖读取，支持现有图片格式，不绑定抖音或固定像素。
- “相关资料”增加“账号资料”，仅在项目已有对应目录时出现。当前采用图复用AssetMediaCard、图片预览与FileActions；索引和其他资料通过FileTree的“制作记录”默认收起，包含工作稿候选、历史与执行附件。
- 项目缓存格式版本递增以重新解析已有项目的栏目列表；不改变项目目录、索引字段、审阅事实或业务技能模板。
- 新增AccountLibrary作为业务编排，更新组件使用说明和展示覆盖归属；不新建公共卡片、弹窗、菜单或样式。
