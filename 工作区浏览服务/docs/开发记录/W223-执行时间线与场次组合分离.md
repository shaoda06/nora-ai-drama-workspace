# W223 执行时间线与场次组合分离

版本：v0.6.87；日期：2026-10-17。

规则与模板明确：轮次JSON是播放组合依据，输入映射segments保存执行原组，selected_indices限定本次执行业务范围。局部轮次登记支持明确base_round和segment_changes，展开沿用项；重新分段使用完整方案。

准备工具强制新视频任务填写scene_modification_round，核对剧本／分镜版本、选中身份与计划时长，以及一采／二采API所选组时长。准备报告prepared_input.scene_composition保存实际引用组合；相关文档沿用既有文件状态检查，轮次总表不作为整体文件依赖，后续追加轮次或改备注不触发重查。无新增网络查询、上传或通知前审核。

后台在新视频登记状态保存scene_round_required，重启和恢复不降级；旧登记缺此标记时，保留原preparation_required及其校验，不强加轮次要求、不回填输入映射。显式重新准备未提交任务后可启用新要求。结果回写仍只处理真实outputs，回归保护整场组合、未选段和旧批准原话。

测试使用隔离临时项目、任务库和模拟远端，覆盖新要求缺失、旧准备任务与更早任务恢复、新登记重启、局部沿用、合法旧缓存、关联不符、追加轮次复用及结果保护。无项目历史迁移，无视频生成。
