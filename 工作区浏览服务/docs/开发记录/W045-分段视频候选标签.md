# W045 分段视频候选标签

日期：2026-10-06。版本：0.1.0同版维护。

## 已实现

视频区域上方增加同宽横向候选标签，复用TabNav，鼠标或键盘切换真实视频文件。仅加载当前候选，使用手动播放和metadata预加载；切换场次、分段时重置选择。播放器下方显示原R编号、处理阶段及原文件链接；播放失败显示错误。没有实际候选时保留空框，手机仅标签组内滚动。

后端复用已有制作目录视频清单，按当前EP/C/P精确匹配规范文件名及候选目录，兼容旧结构的分段阶段候选目录。按R数字升序标成候选1、候选2……；不以显示序号重命名源文件，不纳入场次成片、整集成片、执行附件、历史版本或其他分段。segments增加videos数组，离线入口继续原目录展示。

现行荒院暴富EP001 P001有R001–R003三个一采候选，P002–P007各有两个；无当前获批采用版，不创建正式版占位标签。没有修改或搬动项目视频及审阅记录。浏览入口规范v1.110→v1.111，修改前已完整归档。
