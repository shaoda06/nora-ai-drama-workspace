# 本地操作按钮悬停配色预览

日期：2026-10-10

本地操作按钮新增对应色系的悬停样式：绿色、蓝色、橙色、红色按钮悬停时加深背景，边框变为同色文字色，并以150毫秒过渡背景和边框颜色。移出后恢复原配色，不改变按钮尺寸、顺序和分类显示。恢复按钮沿用绿色悬停样式。当前按钮仍禁用实际操作，但可预览悬停配色。

TypeScript检查和Vite预览构建通过。内嵌浏览器用真实鼠标定位禁用按钮，核对绿色按钮悬停后背景由rgb(227,242,233)变为rgb(204,231,215)、边框加深；再移到取消按钮，绿色恢复，红色背景由rgb(250,230,227)变为rgb(242,204,198)、边框加深。计算样式确认颜色过渡为150毫秒，控制台无警告或错误。保存实际悬停对照截图local-queue-button-hover.png。
