# W016-剧集视频目录迁移

日期：2026-10-06；状态：已完成。

## 变更

逐集目录规范将06-生成结果限定为01-场次成片、02-整集成片。待审、未采用及被替换的视频留在单集其他资料/候选视频；当前采用的一采、二采和后处理分段分别进入其他资料/阶段采用视频的三个阶段目录。一采最终导演包与画布跟随其采用场次保存。生成、执行和审阅记录集中在其他资料，保留具体EP-C-P及R编号；目录只在实际需要时创建。

共用解析器支持新阶段采用路径，保留旧06阶段目录和C/P目录的读取兼容；场次与整集成片的新编号沿用成片说明置顶。精确R编号的实际英文提示词及对应中文说明仍与媒体关联，不拿其他轮次或其他分段的提示词代替。

同时清理技能中的旧06存放口径，工作流基准与任务副本要求集中到维护规范，首帧输入要求集中到首帧规范，模板保留实际填写字段；监控模板统一按服务或离线模式同步浏览入口。没有修改工作流节点、API映射、参数或媒体内容。

## 已有项目迁移

用户授权两个项目一起迁移。荒院暴富EP001迁移30个文件，谁懂啊，我们办公室EP001迁移823个文件，共853个；其中25个视频归入候选视频。现有结果没有明确采用依据，不创建阶段采用目录或补写批准。552处Markdown链接在72份当前文档中重新计算，原请求、响应、日志中的当时路径保留。

每个EP的其他资料/执行附件/EP001-目录迁移记录-001.md保存逐文件旧新位置对照；修改前Markdown压缩归档在本集历史版本。既有历史归档与已交付静态页保留当时内容，当前使用动态服务入口。真实项目资料按工作区Git规则保存在本机。
