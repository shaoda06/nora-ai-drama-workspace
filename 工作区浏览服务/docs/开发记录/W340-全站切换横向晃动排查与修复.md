# W340：全站切换横向晃动排查与修复

日期：2026-10-22
状态：已完成
关联版本：v0.8.26（已发布）

## 修改原因

开发记录页修复后，用户要求检查其他页面，有同类问题则一并修复。实际复现风格库搜索结果变空及恢复、项目栏目切换、长短页面往返时主区域x在53.5和61之间变化，横移7.5像素。原因仍是非覆盖式滚动条出现或消失改变可用宽度；仅开发记录页预留滚动条时，往返其他页面还会改变页头位置。

## 具体改动

把frontend/src/style.css原先仅用于.history-layout的scrollbar-gutter:stable移到公共html规则，全站统一预留页面滚动条位置。实际代码仅调整这一处公共规则，沿用已有页面布局与滚动方式。

- TypeScript检查及正式前端构建通过；统一启动器重启8782后，/api/service返回v0.8.26、ready=true，服务目录与工作区正确。
