# W191 本轮连播版本与意见导出

## 行为

首次开启连续播放，以当前画质为准，为本场各段及上集末段选择同画质中R编号最高、已有可播放地址的视频。保存本轮分段顺序及各段画质、R编号和版本身份；最新版本尚未取回时可选择同画质最近可播放候选，不能跨画质替代。后续资料更新不改变本轮版本和顺序，缺少本轮视频时停止并提示，不跳过或偷偷换版本。本轮视频准备名单采用同一组固定版本。

取消连播不清除本轮，再勾选恢复原版本；“开始新一轮”按当前选定画质重新确定各段版本。手动切换画质／候选会关闭自动接续，允许对照旧视频，本轮导出身份仍保持原样，并提示当前查看版本不属于本轮；切回分段或恢复连播沿用本轮版本。自动发布刷新沿用已有位置恢复保存本轮身份，普通重新打开页面需重新确定本轮。

默认导出“本轮意见”，按分段、画质、R编号精确筛选已有意见及未保存草稿；未填写时不补入旧版本意见。无本轮时明确提示先开启连播，仍可选择“全部历史意见”导出现行范围的全部记录。两个导出范围各自保留临时编辑稿，切换不丢文字；关闭任一已修改稿仍需沿用原有放弃提示。导出只编辑临时稿，不更改项目原意见。回看上集末段时，本轮范围只包含该末段的固定版本，全部历史范围继续包含对应上一集场次的全部意见。

## 验证

TypeScript检查、正式构建和本次文件git diff --check通过。Browser plugin not available，使用Playwright及已安装Chrome，在192.168.10.15:8782以1351×924和390×844验证，导出本轮／历史及手机截图已查看，无页面脚本异常或框架错误覆盖。

浏览器隔离资料覆盖：同画质有R011可播放、R012未取回时选R011；替换过去记住的旧选择；排除旧版本及其他画质意见；本轮某段无意见不补旧意见；全部历史保留原记录。新候选到达、索引顺序变化和新增分段通过真实5秒刷新触发，连播仍按原版本和顺序接续。原本缺少本轮视频的段落后来取回，也不加入旧轮。当前固定版本记录被移除时显示不可播放，不回退到新候选，原意见仍可导出。取消再勾选不重选，“开始新一轮”才采用新的候选；新一轮无意见时不带出上一轮文本。

上集末段同画质版本及意见独立范围通过，使用真实视频结束事件验证从上集末段接到第一段、从第一段接到第二段；缺段时停在当前段而非跨画质或跳段。手动对照旧版本不改变本轮导出，恢复连播回本轮。自动刷新位置恢复固定身份和修改意见页签。导出范围切换保留两份临时编辑稿，关闭修改稿的放弃提示保持有效；手机开启本轮、状态显示、范围切换及历史导出通过。
