# W106：任务栏桌面加宽与移动端全宽

日期：2026-10-09
状态：原记录未单列，以正文为准
关联版本：原记录未单列，以正文为准

## 修改原因

用户要求电脑端展开至少占1080P屏幕宽度的三分之一，移动端占满屏幕宽度。展开宽度改为max(640px,33.333333vw)，700px及以下窗口改为100vw。继续固定悬浮覆盖，折叠保留40px窄栏。

## 具体改动

仅调整TaskSidebar.css，版本递增到0.4.2。现有局域网模拟预览同步新构建，保留模拟任务及测试服务，不提交真实生成任务。

## 验证结果

检查结果：类型检查及生产构建通过。浏览器测得1920px窗口展开640px，2560px窗口展开约853.33px，1440px窗口展开640px，390px移动窗口展开390px；折叠均为40px，正文位置与宽度不变，长任务卡片无横向溢出，无相关控制台错误。
