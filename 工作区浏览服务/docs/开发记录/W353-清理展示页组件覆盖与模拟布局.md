# W353：清理展示页组件覆盖与模拟布局

日期：2026-10-23
状态：已完成
关联版本：v0.8.43（已用于本地正式浏览服务）

## 修改原因

展示页存在公共控件后代样式覆盖、入口跳转拦截和独立模拟宽屏，可能与正式页面变化脱节。保留示例数据与展示容器，组件样式及交互直接复用。

## 具体改动

- 移除展示页对下拉、分页、搜索、标题、入口卡、图片网格、音视频卡片、选集、分段及任务卡片的独立样式覆盖。演示标题选择器由全部后代h3收窄至外框直属h3，避免改变内部卡片标题。演示自己的外框、排列、说明、示例文本域和列表样式保留；较宽的组件通过fullWidth外框占满一行。
- 发现History.css还通过祖先选择器覆盖展示分页：取消历史页单独12px间距，统一沿用公共20px间距，并将窄屏换行设置在公共pagination中。
- 入口卡片移除捕获点击和阻止跳转，直接使用EntryCard链接跳转首页，说明明确告知会离开展示页。
- 提取SegmentWorkspace原有容器、播放器行和宽屏侧栏为SegmentLayout，保留DOM结构、原CSS、播放器props及子内容；制作页和展示页共同调用。展示播放器移除320px模拟宽度切换，宽屏真实显示同一分段侧栏布局。
- 保留示例数据、选择状态、操作计数、受控输入及明确标注的模拟任务回调，不将这些示例数据编排误当成公共控件内部行为。
- AGENTS.md明确展示页只能设置外框与说明，不得覆盖公共组件后代样式或拦截事件替换交互；共性问题回公共实现处理并回归使用页。实现说明同步SegmentLayout展示归属和维护边界。
