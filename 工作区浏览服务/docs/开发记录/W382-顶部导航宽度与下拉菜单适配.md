# W382：顶部导航宽度与下拉菜单适配

日期：2026-10-25
状态：已完成
关联版本：v0.8.80（已发布）

## 修改原因

用户要求取消顶部不合理的宽度限制，并让下拉选项菜单随触发按钮宽度适配，避免小按钮展开340px宽菜单。

## 具体改动

- 调整共用顶部容器宽度，不改变正文的阅读宽度、按钮尺寸或正常窄屏换行。
- 有文字的TabSelect菜单与触发按钮同宽，仍受屏幕边界限制；长文字在菜单中换行，保留当前标记、禁用、键盘和点击操作。
- 当前标记放不下时另起一行；菜单打开期间窗口变化会重新测量宽度与位置，不重置键盘选中项。
- 纯三角入口只有22px，保留既有可读菜单宽度，不压成22px；项目切换和快速选集不改变功能。

- 新断言先在旧实现失败：1362px真实尺寸顶部夹具无法品牌／8栏目同排，公共导航菜单宽度不等于按钮；确认两处断言能抓住旧问题后再修改实现。
