# W105：生成任务计数分两行

用户要求去掉任务栏的“实时状态 · 仅查看”，把右上角数量稍微放大，并分两行显示进行中、已完成。

`TaskSidebar` 保留既有进行中状态分类，已完成数量统计 `completed` 状态；两行计数使用13px字号，右对齐。移除连接说明行，连接状态仍用于空任务时的等待提示。任务监听与取回逻辑保持原样。
