# W434：后处理按轮次整套采用与归位

日期：2026-10-28
状态：已完成
关联版本：v0.8.141，已发布

## 修改原因

多产物后处理原来只认一个最终文件，透明视频留在执行附件，阶段采用目录却只有绿底。改为整个R轮次的全套产物共同采用，默认项只控制展示，不限制批准、归位或下载。

## 具体改动

- 规则、清单模板和收尾调用说明同步：全部产物批准前沿用候选视频位置，批准后全部进入阶段采用目录；没有独立的预览文件类别。更换轮次整套退回候选。
- 共用清单读取以default选择默认项，兼容旧role及播放关联；采用工具逐项检查并移动、更新清单和工作稿链接，审阅区列明整轮文件。
- 浏览页保留版本旁的产物选择器，默认项标“默认”，采用标记仍在轮次上；一个R的多个媒体不新增候选。
- ZIP、原生剪映包包含所有产物，时间线只放每段默认项，其他文件列入素材；透明播放继续使用同轮棋盘格视频，原文件链接指向MOV。
- C002 R001三份产物归入正式阶段采用目录，当前记录和链接同步；原执行请求及下载凭据保留当时事实，迁移关系记录在本轮执行附件。
