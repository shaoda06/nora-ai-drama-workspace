# Imagegen回传与图片链接预览修复

- 日期：2026-10-21
- 授权：用户同意修复实测发现的原生结果回传与共享网页图片预览问题，并要求修复后测试。
- 范围：固定Imagegen交接、调用说明、图片文字链接预览及相关验证；真实生成仅在独立的Imagegen链路测试项目进行。

## 根因及改动

双参考图原生生成已成功，但执行者按普通MCP的content数组处理Imagegen返回值，仅打印字段名，导致父代理无法接收实际结果。prepare现在生成Imagegen内置调用.js，内含完整提示词及实际参考图顺序；子代理原样提交到functions.exec，同次调用先store完整结果再generatedImage。CLI返回调用文件和保存键；旧清单仍可使用原complete恢复，不重复生成。执行规范及工具说明同步，规则只保留一处真源。

Markdown解析为本地链接附加data-doc，Rich此前统一按markdown打开，因此PNG被送入文字预览。Rich现在按PNG、JPEG、WebP、GIF扩展名选择image；其余文档仍走原Markdown预览。没有修改解析缓存、项目格式或真实短剧素材。

## 验证

- 新增原生返回回归在旧实现因缺少generation_call_file失败；修复后覆盖无content的真实返回结构、双图顺序、提示词原文保留，以及显示中断后仍能读取已保存结果。Imagegen、项目解析、服务和发布相关188项测试通过。测试主动注入的无效分段时长日志为预期错误用例。
- 固定gpt-6-luna、medium、fork_turns=none真实双参考图复测：一次调用，原样执行自动生成的JS；1672×941 PNG、1551724字节；子代理直接取得原生路径并运行complete，报告completed、网页核验通过。父代理未人工恢复路径，未二次生图或再次运行远端超分。
- 浏览器回归先在旧版8782真实复现PNG预览失败；验证脚本位于tests/test_markdown_image_ui.mjs，通过当前CUA IAB接口运行。当前未提供Browser插件，按可用CUA接口验证，未另起Playwright浏览器。
- 两项技能结构校验通过；图片链路相关28份说明、1326处本地链接及锚点检查通过。
- TypeScript检查与v0.6.122生产构建通过。
