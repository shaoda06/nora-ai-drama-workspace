# W441：运营模块与交付目录整合

日期：2026-10-29
状态：已完成
关联版本：v0.8.151

## 修改原因

运营子技能统一个人页、封面、发布包和复盘，项目目录调整后需要同步浏览与图片采用入口。

## 具体改动

- 新增模块化运营子技能，六个模块分别维护配置连接、个人页、封面、发布准备、作品复盘、制作参考；主技能通过统一接续规范进入。
- 取消被吸纳的旧社交视觉技能入口；封面规范及模板移入运营模块，资产、生成及主控引用同步。项目配置与真实数据不进入共用技能。
- 10号目录统一社交资料，98号目录按集保存最终成片与发布材料；单集初始化提前创建导出目录，明确分段后处理与用户人工剪辑之间的交接。
- 共用浏览页的发布资料分组改为社交媒体资料、成片交付；个人页／封面组件保持采用状态判断；交付组件按实际一级目录分类，支持发布材料文件树。
- 图片准备与采用从运营模块取得封面模板；解析缓存版本随目录结构更新。
- 浏览器任务在对应profile内使用单次标签组，结束关闭任务页、清除组及任务临时窗口，保留用户原有浏览状态。
