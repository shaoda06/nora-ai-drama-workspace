# W416：同轮次后处理产物选择

日期：2026-10-26
状态：已完成
关联版本：v0.8.123（已发布）

## 修改原因

同一次后处理包含最终透明版和过程绿底版，需要在原版本按钮旁选择产物，单产物保持原样，并统一Agent写入格式、预览和下载。

## 具体改动

- SegmentWorkspace复用TabSelect工具栏规格，在版本后显示多产物菜单，默认最终产物；SegmentVideo将代理播放与原文件入口分开，不新增候选或修改版本选择。
- 后端从本R执行附件的后处理产物.json读取产品角色、项目相对文件路径及可选预览；每份清单唯一最终产物，校验重复和路径边界。无清单兼容旧单视频。
- 当前选定表可以引用清单内最终文件，仍核对该具体输出审阅批准；过程文件获批不自动赋予新最终文件批准。整集／场次采用视频下载使用最终文件。
- 同步目录规范唯一规则入口、JSON模板、分段工作稿字段、执行与汇报规范、浏览输入依赖和服务说明。真实片头R002登记透明最终、绿底过程与棋盘格代理，保留旧生成和批准事实。

## 验证结果

- 后端相关回归91项通过，覆盖新最终产物不能继承过程产物批准。macOS临时目录规范化后使用TMPDIR=/private/tmp；默认临时路径的既有直接解析用例存在/private路径别名差异，不改动无关解析规则。
- 前端TypeScript及Vite构建通过。
- 公共组件复用检查：本次菜单直接复用TabSelect，无新增CSS、弹窗或交互副本；普通／宽屏来自同一选择栏。暂存快照静态检查与1362px、390px、320px真实组件浏览器检查通过；新增用例覆盖单／多产物显隐、菜单边界、角色选择、预览及原文件链接，原展示页同规格比较通过。
- 两个技能入口quick_validate通过；真实片头离线解析确认候选二仍为单一版本、最终交付已采用、两项角色准确、无制作结构问题。

- 正式发布：统一启动器重启8782，/api/service确认v0.8.123、production、ready=true；正式片头页面默认透明最终，切换绿底过程并返回正常，原文件链接分别指向MOV／MP4，控制台无错误。正式接口确认本R一个候选、两项产物、批准有效；真实项目制作结构问题为空。
- 新增规则链接目标核对无缺失，执行入口、采用、汇报和模板均可到达唯一格式规则；旧“透明只能配套链接展示”的说法已替换。
