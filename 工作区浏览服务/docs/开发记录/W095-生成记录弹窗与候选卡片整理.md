# W095：生成记录弹窗与候选卡片整理

日期：2026-10-09
状态：原记录未单列，以正文为准
关联版本：原记录未单列，以正文为准

## 修改原因

- 范围：正式参考图与候选图片卡片的展示和记录预览。

## 具体改动

候选卡片底部移除独立审阅文件树及重复的生成记录原文件链接。已有“生成记录-编号”改为链接；正式参考图的“生成记录”也改为相同的文档弹窗入口。两处均读取后端已有记录URL中的工作稿路径及章节锚点，复用现有Preview，不新增后台接口或另一套文档弹窗。

文件核对、看图授权及范围、授权查看的发现、用户决定等字段，标题与内容同行显示，长内容在值区域换行。弹窗内章节滚动预留标题栏空间，防止定位标题被遮挡。

本轮仅调整网页，不改变工作稿字段、审核事实、图片类型或创作模板。

## 验证结果

### 检查与发布

TypeScript及Vite正式构建通过；8782运行v0.2.11，ready=true、environment=production。

在现有应用内浏览器的844×531视口完成实际检查：正式肖像的生成记录弹窗定位到生成010；候选本体的编号链接定位到生成004，两处标题均位于弹窗顶栏下方，项目URL保持不变。关闭弹窗后回到原候选卡片及已展开分组。

文件核对、看图授权及范围、授权查看的发现、用户决定四项标题与值从同一行开始；长决定内容换行时，标题仍与第一行对齐。候选卡片不含额外审阅文件树或重复生成记录页脚。页面有正常内容，无框架错误覆盖层；控制台无警告和错误。截图保存在系统临时目录，未提交到仓库。本轮未单独测试移动端或其他浏览器。
