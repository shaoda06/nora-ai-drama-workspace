# W256：左下角公共消息组件

日期：2026-10-22；状态：实现与隔离验证完成，尚未发布。

## 范围与实现

用户批准合并三套左下角提示，统一样式、位置，多条消息不互相覆盖，保留各自按钮、消失时机及更新逻辑。

- Notifications改为同一宿主内独立堆叠；useNotify接口不变，每条消息拥有独立关闭、清理和截止时间。默认3秒，duration=0不自动关闭，新通知不替换其他来源的消息。
- 新增FloatingMessage接入Document、Preview和AppShell原有常驻提示。读取按钮仍分别更新当前文档或预览revision；没有额外的关闭按钮或倒计时，来源条件消失／组件卸载时清理。
- SyncNotification、Result、音频错误及useAppUpdate的业务逻辑不变，重试倒计时继续逐秒更新，自动刷新仍等待编辑、未保存意见、媒体播放及弹窗等原条件。
- 统一白色框体、圆角、内边距、宽度与左下角位置，错误仍使用红色。间距12px，超高时内部滚动；返回顶部按整栈高度避让。阅读弹窗开关时迁移顶层宿主，通知截止时间不重置。
- 不合并页面内MessagePanel、视频准备数量行、悬停提示或居中弹窗；不新增请求、提醒历史或依赖，不修改项目资料。

React工程规则用于稳定上下文函数及独立消息生命周期；frontend-testing-debugging用于桌面／手机交互与几何核验。Browser插件不可用，使用现有Playwright，不安装浏览器或新依赖。
