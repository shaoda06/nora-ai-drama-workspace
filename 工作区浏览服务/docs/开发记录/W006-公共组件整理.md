# W006：公共组件整理

日期：2026-10-05
状态：原记录未单列，以正文为准
关联版本：原记录未单列，以正文为准

## 修改原因

### 需求与原因

用户要求顶部名称统一为“Nora workspace”，盘点现有页面和组件，统一同用途组件的表现，提取公共实现，避免重复建组件。

原服务已有公共文档阅读器、文件树、预览和弹窗；但页头、选择导航、搜索框在页面内分别书写，分页位于Project页面中、由Krea跨页面导入。品牌中文副标题也使用不同字号与字重。

## 具体改动

提取AppShell、PageHeader、EntryCard、TabNav、SearchField、Pagination、CopyButton。四类页面共用页头；栏目、详情和开发记录选择共用TabNav；三类搜索共用SearchField；Project与Krea直接导入公共Pagination。原有Document、FileTree、Dialog等实现保留。

品牌和网页标题统一为“Nora workspace”。共用导航支持横排与竖排，统一选中、焦点和按钮样式。人物、场景、道具继续使用同一Assets业务组件；不同用途的入口、资产和风格卡片保留业务差异。

浏览器复查还发现正式媒体显示名称没有扩展名时，Preview未识别文件类型。本轮改用真实路径识别，复用原有媒体预览实现。

完整清单、页面映射和复用约定见[组件与页面实现](../组件与页面实现.md)。本轮仅维护前端与服务开发文档，没有改变短剧项目或资源更新数据。

### 后续约定

新增页面先查公共组件清单，同用途复用已有实现。样式在公共层维护；业务字段与数据读取保留在相应页面，不新增未使用的抽象组件。
