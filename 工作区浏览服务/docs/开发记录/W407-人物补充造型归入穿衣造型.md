# W407：人物补充造型归入穿衣造型

日期：2026-10-25
状态：已完成
关联版本：v0.8.113（已发布）

## 修改原因

人物详情将“单人全身造型参考图”“Q版角色三视图”及其试稿显示在“人物基础”。旧分类只识别服装和角色六视图，其余类型全部回退人物基础；浏览入口规范沿用了同一口径，页面实现说明还保留旧的四标签结构。

## 具体改动

- 人物基础只收录肖像、本体及既有名称别名；独立服装图进入服装，其余已登记的人物补充造型进入穿衣造型。空记录的默认入口保持人物基础；正式、候选、历史共用分类，不从图像内容或文件名猜测。
- 同步浏览入口分类真源、人物图片类型填写说明和当前页面实现说明，明确“四类标准参考图”不等于网页“人物基础”。不改目录、媒体或批准范围。
- 核对《我们的AI短剧》男女主各一条单人造型及一条Q版三视图，共4条已采用记录。依已有批准与正式资产表补齐具体候选、范围、正式位置等遗留占位，原始文件与历史生成事实保持；项目条目重新解析核验通过。真实项目按Git忽略规则保留在本机。
