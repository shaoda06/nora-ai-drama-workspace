# W406：连续播放跨场次接续

日期：2026-10-25
状态：已完成
关联版本：v0.8.112（已发布）

## 修改原因

分段制作的连续播放只遍历当前场次，末段结束后不能接到下一场，切场次还会重建并清除连播状态。用户要求按本集场次顺序连续播放。

## 具体改动

EpisodeProduction维护本集连播状态、开启时各场所选轮次及跨场目标；SceneWorkspace保留场内版本选择，并在末段结束时接续下一场首段。新场播放器首次挂载即使用正确候选和自动播放状态，避免只切页面却不播放。已有轮次选择沿用，未选择的取开启时最新轮次；缺轮次、分段或对应视频时停止，整集末段不循环，手动切场关闭连播。同步README、组件实现说明及展示页的说明文字，未新增公共UI或样式。
