# W388：集名状态名称统一

日期：2026-10-25
状态：已完成
关联版本：v0.8.92（已发布）

## 修改原因

集名状态统一为“待定集名／临时集名／最终定名”，区分名称用途与剧集制作进度；三集正式名称及其最终定名决定保留。

## 具体改动

分集命名规则与浏览输入说明同步新名称，剧本获批当轮的定名提醒继续执行。解析器读取新值，同时将旧“待定／工作集名”转换为“待定集名／临时集名”，旧工作集名记录继续按同源题名匹配。缓存版本升至15，避免服务重启后沿用旧状态文字。共用选集按钮、本集路径提示和真实公共展示示例同步“临时集名”；不改制作状态或项目历史文件。
