# W347：统一消息时长与手动关闭

日期：2026-10-23
状态：已完成
关联版本：v0.8.34（已发布）

## 修改原因

统一普通成功提示3秒关闭、错误不定时关闭、所有提示可手动关闭；关闭消息不能中断业务操作。

## 具体改动

- Notifications统一普通成功提示3秒关闭、错误提示不设到期时间；持续业务提示保留来源清理条件。调用方不能另设普通提示时长。
- 所有公共消息显示关闭按钮，手动关闭只移除消息。FloatingMessage记住同次挂载的关闭状态，来源重新渲染不再次弹出；来源结束后新一条提示可以正常显示。
- DownloadButton取消原5秒结果提示，完成与失败遵循公共规则。关闭进度不取消下载，后续完成结果仍正常提示。
- 同步服务工作约定及公共组件说明；历史开发记录保留当时事实。
