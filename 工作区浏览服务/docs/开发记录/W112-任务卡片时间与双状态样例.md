# 任务卡片时间与双状态样例

日期：2026-10-09

本机任务标题右侧增加时间信息。排队时显示本机提交记录的created_at，转换为访问网页设备的当地时刻，以及从该时刻算起的等待时长；进行中隐藏提交时间，只显示从started_at算起的运行时长。统一使用“00小时:20分钟:05秒”，时长每秒更新，小时可超过24。窄屏时间放在标题之后的下一行。

后台收到本任务的execution_start消息时持久保存started_at并更新为运行中，重连不重置已有开始时间。没有开始时间的旧任务显示“待获取开始时间”，不把提交时间当作执行开始时间。当前尚未发布正式后台，新增记录逻辑将在后续正式发布后生效。

远端列表只保留提交中、排队中、运行中、取回中这些活动任务：提交中及排队中统一显示“排队中”，运行中及取回中统一显示“进行中”。终态任务不再作为这两种状态的卡片显示；节点完成数量仍按记录统计，后台错误、下载和通知记录不改写。

局域网5179新增smoke=timing场景，提供两张本机样例：等待约20分钟的排队任务与运行约30分钟的进行中任务。使用模拟时间，不提交真实ComfyUI任务。预览服务已重启并保持0.0.0.0监听，正式8782未重启或发布。

TypeScript检查、预览构建和40项ComfyUI后台测试通过。首次测试中的原生分段网络用例在6秒限时内超时，未改代码或放宽限时，重跑全部通过。浏览器验证两种状态、详情默认折叠、提交时间仅在排队卡片显示、时长递增；1920×1080和390×844布局无卡片横向溢出。
