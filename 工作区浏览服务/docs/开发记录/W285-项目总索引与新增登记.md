# W285：项目总索引与新增登记

日期：2026-10-22
状态：已完成
关联版本：v0.8.18（已发布）、v0.8.19（已发布）

## 修改原因

项目首页此前直接按目录名称排序，无法维护指定顺序。现在由本机 `projects/项目总索引.md` 的有序列表统一控制首页卡片及顶部菜单；索引只登记真实目录名，不改变项目名称。未登记目录接在末尾，缺少索引时保留原名称排序，失效条目不生成卡片。服务只读索引，不回写资料。

用户进一步要求明确总索引维护、编号及条目内容，并在网页项目标题前显示两位序号。

## 具体改动

Nora主技能与skill-creator用于确定规则真源、初始化职责及维护检查。规则集中在主技能“项目初始化规范／项目总索引”，浏览入口规范、维护索引、项目说明及服务文档引用该入口。共用 `scripts/project_index.py` 由初始化脚本和浏览服务复用。项目模式在目录就绪后追加条目，重复运行不重写已有顺序；单集、片头、片尾模式不修改总索引。JSON报告新增 `project_index` 和 `index_added`，命令、帮助和成功条件同步维护。总索引属于真实项目资料，按现有Git忽略规则留在本机。

React规范用于保留首页和菜单共用的TanStack Query键与请求去重；菜单增加原有5秒重新读取，在项目内页也能同步。FastAPI规范用于保留同步文件读取接口及既有返回结构，不新增接口或数据写入入口。网页测试使用frontend-testing-debugging；Browser插件未提供，使用现有Playwright验证，不安装依赖。

主技能总索引规范补齐基本格式、从1连续填写的列表编号、两位显示序号、调序、补登记、改名、移除及核验要求；现有真实索引符合格式，无需重写。修改前规范原文保存在技能历史版本目录。首页和菜单在现有有序数组上拼接两位序号、半角横杠及完整标题；序号只用于显示，跳转继续使用原项目ID，API和初始化脚本没有修改。组件说明引用规则真源。
