# W408：单集共用修改轮次

日期：2026-10-26
状态：待验证
关联版本：v0.8.116（已运行，发布协调核对中）

## 修改原因

同一集各场次独立计轮无法表达一次跨场次集中修改。用户确认轮次绑定单集，允许只修改部分场次／分段，其余沿用；旧记录不迁移、不重编号，界面继续显示“第N轮”。

## 具体改动

新增单集组合登记，写入`EP编号-修改轮次.json`；首次接该集旧最大轮号加一，每批一次登记所有修改场次，其余场次／P沿用明确基轮。共用剧本与各场分镜留存副本，独占锁避免并行分配相同编号；旧场次文件只读保留。

后端按共同轮号投影各场组合，缓存结构升版；新视频准备必须引用共同轮次，旧已登记任务的准备凭据、场次引用及恢复逻辑保留。场次审看意见仍保留原存储归属，能够引用新共同轮号；整集意见汇总由另一事项处理，不并入本次。

页面轮次选择上移到场次栏上方，仍显示“第N轮”；切场保持该轮，连续播放固定各场组合，缺片停止。选历史候选跳到包含它的最新共同轮次，并保留具体视频文件；旧模式及旧场次历史仍可查看，不把旧同号记录合并。

同步版本组合规则、轮次模板、登记CLI说明、分镜与提示词／工作稿模板、分镜技能入口、生成任务规范、浏览入口及页面实现说明；保留旧文件名与锚点供原链接追溯。不改真实项目、不补造轮次、不提交生成、不推送。
