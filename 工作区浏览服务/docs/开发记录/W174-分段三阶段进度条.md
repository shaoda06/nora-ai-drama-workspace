# W174 分段三阶段进度条

用户要求在分段条下方添加同宽的进度行，每格固定按一采、二采、后处理显示三个图标：绿色勾表示已采纳，黄色横杠表示已开始但尚未完成，灰色圆表示未开始，鼠标悬停显示具体状态。

SegmentStageStrip复用已有分段接口与人工批准标记，不新增任务查询、提交或审批。某阶段有真实修订记录时计为已开始；仅有成功候选不能显示绿色。存在有效采用版时优先显示绿色，未批准的新候选不撤销原采用事实。没有阶段记录时显示灰色。黄色的说明包含最新R编号和任务状态，候选已到达时注明尚未采纳，未有视频时区分未取回、取回失败和资料准备中。详细传输校验段落不直接塞入悬停提示。

两行放在同一滚动容器，共用计划时长比例列，单列最小84px；移动端只滚动该容器，页面不横向溢出。图标提供原生title、无障碍名称及键盘焦点。原分段选择、自动更新与视频布局状态继续由SceneWorkspace负责。
