# W059 连续播放勾选、分段选择保留与参考素材

日期：2026-10-07。版本：0.1.0同版维护。

## 行为与实现

SceneWorkspace用默认关闭的连续播放复选框代替启动／停止按钮。勾选只改变当前视频结束后的行为，不回到第一段，也不启动或暂停当前视频。原生ended事件在勾选时推进紧邻的下一段，以该段保留的画质和版本自动播放；没选齐或没有视频时停在当前段并提示具体P，不跳过、不自动改选最新。最后一段结束保留末帧，不回绕，复选框仍保留勾选状态。

场次进入时用既有latestVideo按最大R初始化每个P的画质和版本，同一场次内分别保存各段选择，包括只有画质、没有版本的状态；手动切段恢复该段选择且新视频暂停，勾选保持。“最新”只更新当前段。SceneWorkspace沿用场次／剧集key重挂和离开制作栏目时卸载，因此切场次、离开大标题或刷新后重新按最新初始化，复选框重新关闭；不使用持久存储。删除已不用的播放序列和playbackSession，播放器仍只有左栏一处。

新增UnderlineTabs样式组件，仅用于分镜脚本／提示词：透明背景，选中项下划线及强调文字，空选禁用；分镜显示方式和提示词语言继续使用原TabNav compact。原文件入口、固定高度、正文滚动和分镜时间推进规则保持。

参考区改为公共参考素材／本组参考素材，接收图片、视频、音频，按此顺序排列，同类型保留实际槽位标签及顺序。图片和视频使用方形缩略预览，音频使用可缩放的音符标识；点击复用现有Preview，在大预览内使用图片或原生音视频控件，并提供原文件入口。列表不自动播放参考媒体、不额外显示原文件链接。各组仍三列、固定高度、独立垂直滚动；音视频标识适配窄屏的小缩略格。

统一提交入口的generation_context资料保存扩展为读取原生refs／refVideos／refAudios及各自imageFile／videoFile／audioFile，按图片、视频、音频冻结输入素材并保留Picture／Video／Audio独立编号。本组仅覆盖同类型同index的公共项，公共开关关闭则不保存公共输入。单视频referenceVideo按节点兼容行为作为index 0，原生同槽位优先。沿用已有generation_contexts和输入素材目录，无新台账、上传或生成任务。后端在同一映射中识别媒体类型、稳定排序并生成原文件入口；旧图片关联继续可读，不补猜历史音视频。

浏览规范v1.118、逐集目录规范v1.37及提交接口说明同步。规则真源仍为浏览入口的剧集制作章节和目录规范的生成版本资料关联章节，技术槽位沿用导演台节点规范。修改前规范、接口说明及资料保存脚本已留本地历史备份；项目分镜、提示词、素材、请求及审批事实未改写。
