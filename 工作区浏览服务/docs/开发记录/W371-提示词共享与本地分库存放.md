# W371：提示词共享与本地分库存放

日期：2026-10-23
状态：已完成
关联版本：v0.8.57、v0.8.60、v0.8.63（均已发布）

## 修改原因

用户要求提示词在同一页面管理，实际内容区分随公共仓库分享和仅本地保存；新建默认共享，勾选“仅本地保存”后排除出仓库。

## 具体改动

- 新增共享目录`共享提示词/`，复用现有`提示词管理/`作为本地库。已有正文及旧回收站不迁移、不自动分享。页面合并分类和搜索，提示词及回收站保留独立存储身份，列表标出共享／本地。
- 编辑页增加原生复选框“仅本地保存”；新建默认不勾选，读取已有文件时沿用实际归属。切换归属属于未保存修改，保存成功后才在两库之间移动正文；同名冲突、来源外部修改与写入失败保留原内容，不覆盖目标。
- 分类改名和移动同时处理两库对应目录；删除前检查两边都是空分类。回收站恢复保留原存储归属。
- `.gitignore`继续忽略本地库，并排除共享库回收站与临时写入文件；共享库内名为“历史版本”等分类不受其他用途的目录忽略规则影响。页面保存不操作Git索引、提交或推送；取消共享不抹除Git历史。
- 更新工作区及服务README中的目录用途、默认值、保存及Git边界。没有改动项目创作规则或真实项目文件。
