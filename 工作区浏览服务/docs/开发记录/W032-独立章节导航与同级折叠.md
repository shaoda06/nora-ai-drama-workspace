# W032 独立章节导航与同级折叠

日期：2026-10-06。

## 修改

原章节导航的展示直接写在Document中。新增独立ChapterNavigation组件，接收标题及跳转回调，维护目录层级和展开状态。Document读取实际二至六级标题及原锚点，缺少锚点时沿用自动编号，导航点击后滚动并聚焦原正文标题。

目录按实际标题顺序及层级形成树，不补造中间标题。默认只显示根章节；有子章节的标题旁显示展开／收起开关，没有子章节的不显示开关。同一个列表只保存一个展开分支，切换分支时移除之前的子列表；关闭父级或整个章节导航时移除下层列表，重新打开时下层状态全部收起。标题跳转与目录开关分别由按钮承担，正文始终保持原有展开内容。

项目正文、资料卡、阅读弹窗及开发记录继续经Document共用组件，不创建另一套正文阅读器。其他资料的大章节保留。浏览入口规范v1.97→v1.98，修改前完整归档；第1节维护网页服务共用规则，相关简介、大纲及输入说明同步引用，并明确离线页沿用原二／三级导航。源Markdown、正文模板、解析器和离线HTML未改动。
