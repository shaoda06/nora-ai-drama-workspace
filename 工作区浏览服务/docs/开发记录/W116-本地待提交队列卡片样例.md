# 本地待提交队列卡片样例

日期：2026-10-10

本地队列复用TaskCard，保留本机来源、项目、五种固定任务类型、标题和排队状态。本地队列卡片将提交时间标签改为入队时间，继续使用本机时区与带单位的时分秒格式，等待时长每秒更新。尚未提交到远端，不显示运行时长、节点进度、导演台分段取回或空的任务详情。

LocalTask增加可选queue字段。本地展示只取queue为local且状态为queued的记录，远端区域排除queue为local的记录。本地队列不按选中的远端节点过滤。未提供queue字段的既有已登记任务仍按原远端展示处理；本次未增加真实本地待提交任务的创建、持久化、调度或自动提交流程。

5179临时smoke服务新增local-queue场景，上半区保留五种远端进行中样例，下半区展示五种本地等待提交样例，所有数据均为模拟。TypeScript、Vite预览构建及smoke脚本语法检查通过；1920×1080桌面和390×844窄屏无卡片横向溢出。浏览器核对本地五张卡片全部显示排队中、没有详情，切换备用节点时本地五张卡片保持，远端对应节点变为空列表；控制台无警告或错误。保留预览供用户讨论，未发布8782或提交真实媒体任务。
