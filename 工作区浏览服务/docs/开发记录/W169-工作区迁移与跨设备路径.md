# W169 工作区迁移与跨设备路径

日期：2026-10-11；正式版本：v0.6.29。

## 本次修改

Agent入队和后台任务持久化使用项目名、项目内相对路径，后台按当前工作区解析上传素材、执行附件和成果目标。旧任务数据库、下载凭据、导演台映射和视频采用凭据中的旧项目路径可对应到当前项目；原始请求、响应、过程记录和通知正文保留。取回重试复用成功文件，原有项目边界与不覆盖检查继续生效。

Git仓库保留共用代码和规则；真实项目、个人配置、运行队列、依赖及缓存不分发。另一台设备按README独立安装、构建并放入自己的项目，浏览服务默认从所在目录定位资料，不要求相同盘符或用户名。Node、FFmpeg和Codex连接仍按设备配置。

## 验证与发布

338项后台测试通过，56项Agent脚本检查中55项通过、1项既有跳过；新增4项覆盖相对入队、移动恢复、旧下载证据与导演台最终成果，以及越界拒绝。干净仓库副本完成依赖安装、生产构建和独立项目网页验证，无真实项目或旧配置依赖；不是在第二台物理设备上运行。

本机完整文件复制逐字节核对48,616个普通文件，无差异。重建依赖后8782从新目录运行，51条历史和295条事件保留，66项成果记录的状态与可用性无变化，68个素材/记录入口可访问。第二集12段、第三集9段，视频播放和历史详情通过，页面无运行错误。前后端v0.6.29匹配、ready=true。

Codex项目登记需在界面切换到新主目录，旧会话工作目录不由服务修改；codex-home不迁移。桌面旧目录的普通文件全部移走，残留空目录与依赖链接受进程占用及自动审批清理拒绝影响，详细本机记录保存在综合资料中的迁移验收，不作为Git共享内容。
