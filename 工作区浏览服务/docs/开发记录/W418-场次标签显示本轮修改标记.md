# W418：场次标签显示本轮修改标记

日期：2026-10-26
状态：已完成并发布
关联版本：v0.8.126

## 修改原因

分段条已有本轮新生成视频的小黄点，场次标签没有对应提示，用户需逐场切换才能找到本轮修改内容。场次标记应随所选轮次变化，并与分段条采用相同判定。

## 具体改动

- 将既有分段判定提取到newVideoSegmentsForRound，场次内任一段首次在本轮出现且已有实际视频URL，场次标签就显示黄点；沿用旧视频的不标记。
- TabNav普通标签支持标记及无障碍说明，场次与横竖分段条共用RoundNewDot，保持原有黄点大小、颜色和位置。
- 补齐公共组件展示、覆盖说明、样式归属检查及桌面／手机交互验证。
