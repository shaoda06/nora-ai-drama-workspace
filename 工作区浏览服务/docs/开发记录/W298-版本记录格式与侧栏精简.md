# W298：版本记录格式与侧栏精简

日期：2026-10-22
状态：已完成
关联版本：v0.8.21（已发布）

## 修改原因

用户要求核实并统一版本记录的模板与写法，每条先链接W文件再写内容；调整规则、整理并检查后取消侧栏中逐个W文件按钮。

## 具体改动

原规则只要求发布摘要链接W记录，没有专用模板或固定链接位置。新增[版本记录规范](../版本记录规范.md)及[版本记录模板](../版本记录模板.md)，在服务AGENTS、README及开发记录规范中建立入口，规定标题下先列W链接、再写内容；发布事实、缺失信息、多个W与同版记录、历史补录及检查要求一并说明。

核对开始时的304个历史条目，其中227条带数字版本号，其余为早期同版维护、开发环境维护等条目。原有245条带W链接；漏链的19条依据W正文和原提交补回链接。其余40条未找到可核实对应的独立W文件，按原版本摘要建立W299—W338历史补录，明确补录日期、原题、来源提交及未重新验证历史工作的限制，原摘要逐字保留；没有补造实现和测试过程。历史条目统一先列W链接，保留原说明、版本日期、限制及有归属意义的正文引用。

检查通过后修改History页面：侧栏仅保留7个总入口，不再逐项列W文件；“全部开发记录”根据现有文档列表动态生成，包含未关联发布的记录，无需另维护索引。正文W链接继续使用公共文档组件；修正链接含章节片段时把片段当成文件路径的问题，读取正文后定位目标章节。切换文档返回顶部，轮询不改变当前阅读位置。
