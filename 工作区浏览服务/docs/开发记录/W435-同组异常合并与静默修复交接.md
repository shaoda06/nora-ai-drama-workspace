# W435：同组异常合并与静默修复交接

日期：2026-10-28
状态：已完成
关联版本：v0.8.144（已发布至8782）

## 修改原因

同一任务组的同类故障先后出现时，后台重复发送异常消息；异常交接与需要用户决定的提醒没有明确区分。用户要求合并同组同类异常，Agent在原授权内先自行修复，需要用户决定或无法继续时才汇报，正常完成仍按组汇总。

## 具体改动

- 组报告增加`issues`，按失败阶段和原因归类；本地错误全角冒号后的文件／字段不进入分类标题，各成员完整错误继续保留。
- 组未终结时，同类异常并入尚未读取的交接通知和最新报告，复用已有通知批次及回执，重启后继续有效。不同组、不同原因不合并；读取后的新故障仍交接Agent，避免永久抑制导致漏处理；发送未知不重发，全组完成通知不被异常合并吞掉。
- 报告`handoff`和发送正文明确先静默修复；原授权内沿原任务ID处理，需要用户决定、超出授权或确实无法继续时才合并汇报。正常完成按组汇总，成功取回及批准规则不变。
- 同步执行技能、监控规范、结果处理入口、交接模板和服务说明。修改前规则已按维护规范归档，不改历史任务及既有通知正文。
- 本机`codex queue --help`没有隐藏／静音交接参数；减少重复交接及Agent对用户的报错，不宣称内部消息在桌面不可见。
