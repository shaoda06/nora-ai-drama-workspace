# W164：任务异常处理提示

日期：2026-10-11；状态：实现及专项验证完成，未发布。用户安排本项与剪映草稿完成后统一进行网页回归；当前剪映草稿后台仍有并行改动，本次不重启正式服务，不递增正式版本。

## 改动

TaskDetailDialog在当前问题下方增加“任务处理提示”。沿既有详情字段区分后台等待自动重试、正在取回、取回重试耗尽／需要检查资料、提交被拒绝、生成失败、提交结果不明、远端状态待核对；已完成任务的已保存成果现在缺失时，提示Agent先查找或恢复原文件。成功和取消任务不显示无关的处理提示。

提示说明由后台继续处理还是由来源Agent接手，并定位到当前问题、成果与过程记录。取回失败指向已有Agent“重试取回”入口，只处理未保存成果；结果不明不引导重复提交，生成失败不自动重生成。不新增操作按钮、API、通知或新的任务状态，不修改素材、队列或重试机制。

Agent通知区增加等待会话空闲、连接恢复重试、发送中、等待接收确认及送达状态不明的说明，明确结果不明只核对接收确认，不自动重发；正常已确认通知不显示待处理文字。
