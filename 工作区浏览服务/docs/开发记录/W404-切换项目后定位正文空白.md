# W404：切换项目后定位正文空白

日期：2026-10-25
状态：已完成
关联版本：v0.8.110（已发布）

## 修改原因

从顶栏切换项目后，“项目定位”标题显示，但正文为空，需要刷新才恢复。排查栏目恢复状态与已挂载栏目列表的同步关系。

## 具体改动

根因是刷新恢复到非定位栏目后，Project的已访问栏目列表仅包含该栏目；下拉切换项目复用同一组件，栏目选择通过useRefreshState重置为定位，但已访问列表没有同步，因此未挂载定位正文，也没有发出定位读取请求。

Project路由入口按项目名为内部ProjectPage设置key，切换项目时重新初始化整页局部状态。同项目内切栏目不重新挂载整页，既有刷新恢复、查询缓存与公共控件不改。不修改真实项目资料、后端代码或运行中的生成任务。

新增只读回归夹具，直接调用真实ProjectSwitcher、HashRouter及Project，用本地临时HTTP响应替代项目接口。
