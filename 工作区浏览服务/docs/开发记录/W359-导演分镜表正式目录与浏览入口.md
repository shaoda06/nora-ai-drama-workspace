# W359：导演分镜表正式目录与浏览入口

日期：2026-10-23
状态：已完成
关联版本：v0.8.49（已发布）

## 修改原因

导演分镜表已采用后仍留在工作稿素材目录，网页与普通图片候选混排。需要明确候选与正式图归属，增加按场次和页码查看正式版、候选及历史的入口，并将《我们的AI短剧》第一集已批准5张原图复制至正式目录，保留候选和历史。

## 具体改动

- 导演表专项、固定模板、逐集路径表和浏览输入说明补齐候选、正式复制、历史替换及当前采用清单。候选仍在其他资料/工作稿/素材，正式图归03-分镜脚本/导演分镜表，执行凭据仍归执行附件。
- 解析器按场次提供directorSheets.formal/candidates/record；正式页按数字页码排列，候选按图表版本切换。导演表从普通materials分离，既有Imagegen及图片收尾仍能在制作对象解析数据中找到候选。
- 场次分镜旁增加“导演分镜表”，默认正式图，使用TabSelect、AssetMediaCard、Preview、FileActions查看版本、图片与原文件。它属于真实资料业务编排，不在公共展示页启动真实项目；展示覆盖说明已同步。
- 导演表显示当前采用资料，隐藏不适用的视频轮次选择，避免将新表误认为旧轮次分镜。未生成或只有候选时，保留明确空态和查看入口，不影响原制作完成状态。
- 第一集已采用5张原生图复制后逐字节一致，候选、原始提示词、输入和执行凭据保留；工作稿逐页登记源分镜v07、图表v02、候选与正式入口及原批准，不改剧本或分镜正文。
- 实际服务曾复用schema 8的旧剧集缓存，新增字段缺失；按investigate先确认缓存原文与读入条件，回归复现失败后将既有CACHE_SCHEMA提升为9，重建解析结果，不清理项目文件或历史请求。
