# W007 页面导航与局域网更新

日期：2026-10-06。状态：已完成。

## 用户要求

局域网能够操作风格库更新管理；Clio与Ray选项改为中文；“跨项目视觉参考”移到Krea2标题右侧；去掉顶部全局导航，风格库显示筛选栏，项目页显示项目栏目。优先复用组件，新增组件前询问。

## 实现

- AppShell沿用原品牌、状态、页脚、返回顶部，只调整顶部容器。HeaderControlsContext与React Portal把页面现有的风格筛选栏、TabNav放到该容器；页面仍管理原选择及搜索状态，没有新增组件或复制控件。
- PageHeader增加eyebrowInline布局选项，风格库启用；其他页面沿用原标题布局。SearchField、TabNav、Dialog及Pagination继续共用。
- 下拉选项为“全部资源库／风格库／灵感库”；详情和管理窗口保留Clio／Ray来源名称，资源文件和来源键不变。
- 更新管理允许回环及局域网IP客户端通过回环或局域网IP入口操作，仍校验Origin与会话令牌。兼容内置浏览器Origin省略端口时，必须同时满足same-origin标记及完整同源Referer。公网客户端、其他域名访问不获得操作凭证。
- 检查、准备、应用、放弃、恢复共用原更新执行程序。没有修改下载器、ZIP边界检查、备份或恢复机制。
- 品牌链接返回工作区首页，项目、风格库和开发记录入口卡片保留。
