# W053 分镜按视频播放时间显示

日期：2026-10-07。版本：0.1.0同版维护。

## 修改

分镜脚本按钮下增加“显示全部”“跟视频对齐”，默认显示全部。对齐模式只展示当前播放时间对应的一镜。按用户最后确认，以该候选当次历史分镜中的逐镜计划时长累计，视频从本分段第0秒起计；不按视频实长缩放，不直接使用场次累计时间作播放时间。区间左闭右开，3秒的首镜在第3秒切换；超过计划总时长保持最后一镜。暂停、拖动、回放和播放结束均更新对应镜头。

generation解析器在原有当次资料关联中增加shots（id、duration、html），只从匹配版本的归档分镜及对应分段提取，与scriptHtml采用同一原文；后处理沿用明确来源的shots。缺失、零值或非数值时长记录为null，保留全部正文并说明不能对齐，不补造时长。没有历史正文时沿用既有缺失提示。未选择画质和版本时模式按钮禁用；时长不足以定位时单独禁用对齐按钮。

SegmentVideo把metadata、timeupdate、seeked、pause及ended的currentTime传给SegmentWorkspace。播放位置绑定视频文件key，换候选按0秒显示首镜；切场次或分段重挂工作区，恢复默认显示全部与空选。切分镜／提示词保留播放器及时间，切回继续对应当前镜头；换镜后正文滚动到顶部。TabNav增加单项disabled供对齐按钮使用，沿用现有按钮样式。右栏固定高度、内部滚动、单一原文件入口及候选的提示词／输入图绑定保持。

这次是展示交互修改，现有分镜已规定逐镜时长，规则和模板无需补写。没有修改任何项目创作文件或生成历史记录。
