# W343：公共消息框自适应宽度

日期：2026-10-23
状态：已完成
关联版本：v0.8.30（已发布）

## 修改原因

用户希望左下角公共消息框随文字长度收窄，最长限制为520像素，手机上不超出屏幕。

## 具体改动

Notifications公共样式改为每条消息独立按内容确定宽度，保留消息栈的520像素上限和窄屏边距。透明宿主容器也按内容收窄，避免短消息仍占用整条宽度、挡住后方按钮。同步组件说明，现有及以后复用该组件的页面自动沿用。

## 验证结果

- 前端正式构建通过；首次误在工作区根目录运行构建因无package.json退出，随后在frontend目录正确执行通过。
- Browser plugin not available，使用已有Playwright验证8782提示词页。1362、390、320像素视口均正常渲染，无框架错误层及控制台应用错误。
- 复制成功消息约144.81像素；模拟长复制错误与短消息堆叠，长框分别为520、318、248像素。短框宽度保持不变，连续英文错误详情换行，无消息内容横向溢出。单条短消息宿主宽度与卡片一致。
- 验证手动关闭及3秒自动关闭。手机堆叠场景的第二次复制用DOM点击触发模拟错误，以免现有通知遮住原复制按钮；未改写真实剪贴板或项目资料。
- 模拟首页读取失败：带重新读取按钮的常驻提示在1362和320像素视口分别约347.80和248像素；按钮可点击，恢复模拟成功响应后消息消失。
- 查看桌面及手机截图；统一启动器重启后/api/service返回v0.8.30、ready=true，代码与资料目录均为当前正式工作区。
