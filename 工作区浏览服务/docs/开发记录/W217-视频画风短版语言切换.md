# W217：视频画风短版语言切换

日期：2026-10-17

版本：0.6.81

## 原因与调整

Document原先只识别完整画风的小节，新增短版按普通Markdown显示成上下两份代码块。现在同一配对逻辑识别完整画风及视频短版，Rich按小节交给内部CodeBlock保存各自语言选择；继续使用TabNav、CopyButton和原有样式。默认中文，切换后复制对应原文，完整画风已有的英文说明保留；只有中文时不补译或生成英文按钮，旧完整画风独立英文标题写法保持兼容。

这是纯展示调整，规则和模板结构不变；未改项目Markdown、第三集提示词、执行资料、批准或媒体。
