# W374：修正节点转移测试的远端生命周期

日期：2026-10-23
状态：已完成
关联版本：不涉及发布（测试修复）

## 修改原因

节点转移的HTTP／WebSocket端到端测试固定延迟完成任务，却在执行期间始终返回空队列和空历史，导致后台按既有保护进入状态待核对。需要修正模拟服务器的生命周期，并保留真实缺少证据时不重提的保护。

## 具体改动

模拟服务器在提交后、完成前返回对应运行任务；去掉固定50毫秒延迟，等待运行队列被查询后再返回完成事件与历史结果。测试保留并等待完成任务，避免丢失后台异常。

增加转移到目标节点后确实缺少队列／历史证据的用例，验证只查询原目标节点、保留原任务ID、进入needs_attention、不重新提交或下载。正式后台逻辑及现行保护不改，故不递增版本或重启服务。

## 验证结果

原测试修改前失败（needs_attention与completed不符）；修改后节点队列模块15项通过，包含HTTP／WebSocket实际传输和新的无证据保护用例，均使用临时目录与模拟服务器，不调用真实生成服务。全量后台回归924项：921项通过、3项跳过，原节点转移失败已消除，无失败。全量使用明确模块入口，避免既有默认发现命令的同名导入冲突。
