# W373：关联更新预检与已有成果登记修复

日期：2026-10-23
状态：已完成
关联版本：v0.8.65（已发布）

## 修改原因

[W372](W372-图片入库进度范围预检与登记恢复.md)复查发现关联更新只提前检查项目进度，其他原文与填充标记错误仍在成果保存后失败；等待期间原文变化后，已接受计划又无法经固定入口安全修复。

## 具体改动

- 共用预检覆盖全部关联更新的字段、Markdown路径、原文唯一性、支持的填充标记及进度阶段范围。Imagegen使用待保存的工作稿正文预览，不提前写入资料。
- 后台通知登记增加仅修复记录的参数；Imagegen原complete和本地原任务清单分别接入同一修复方法。原任务、提示词、图片、尺寸、正式路径和批准依据不改，不重新生成、超分、尺寸处理或排队。
- 请求匹配当前生效更新，只能修改原关联文件，使用当前原文及实际目标文字；工具拒绝新增文件、过期请求及改写用户确认，保留修复前报告和请求。系统登记项不重写，最终源文字与原批准检查保留；相同修复重复接续不重复登记。
- 本地已有收尾报告接续时不再用尚未填充的原进度更新重新校验已应用内容；仍检查原图批准、路径、规格及准备依据，实际登记继续核对变化。
- 结果处理规范与固定工具说明接通：正常成功只交付，已登记只差网页时只核验，未完成登记才走记录修复。未登记报告的历史后台／Imagegen结果也支持修复。
