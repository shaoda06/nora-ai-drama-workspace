# W008 首页分区与顶部居中

日期：2026-10-06。状态：已完成。

## 范围与实现

- 删除首页“NORA · WORKSPACE／工作区／从这里进入项目……”介绍区。
- 将版本与开发记录从共用工具独立分区，按“共用工具→版本与开发记录→短剧项目”排列。用户原话中的“项目、短剧”先按现有“短剧项目”分区处理，已提出澄清并在执行时说明；没有添加不存在的其他项目分类。
- 原项目发现接口、五秒检查和空项目提示保持；所有入口卡片仍复用EntryCard。Home不再使用PageHeader，其他页面继续使用。
- 顶部TabNav和风格筛选栏通过同一header-controls样式居中；项目栏目换行时每行居中，风格搜索框宽度收敛到480像素以内，避免把整组控件撑满。小屏搜索仍独占一行，选项沿用自适应规则。
- 没有新增组件，没有修改后端或执行资源更新。
