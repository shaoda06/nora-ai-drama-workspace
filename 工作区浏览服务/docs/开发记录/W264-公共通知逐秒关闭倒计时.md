# W264：公共通知逐秒关闭倒计时

日期：2026-10-22；版本：0.7.6；状态：已发布8782，ready=true。

## 范围与实现

用户确认现有样式，要求后续新增左下角消息统一复用公共组件，并让自动消失通知显示逐秒变化的3、2、1。

- Notifications的每条限时消息在关闭按钮前显示剩余数字，按原expiresAt计算；默认3→2→1后由原关闭计时器移除，不显示0，也不改写来源消息正文。
- 秒数采用等宽数字，避免位数变化带动布局；数字对辅助技术隐藏，避免状态提示每秒重复朗读。关闭按钮、每条消息清理及原截止时间保持不变。
- 每条限时消息独立更新；卸载或手动关闭清理自己的关闭计时器与秒数更新器。弹窗迁移后按原截止时间显示，不重新开始3秒。
- duration=0及FloatingMessage不增加倒计时；后台“30秒后重试”等业务消息继续沿用原倒计时，不变成3秒关闭。
- 浏览服务AGENTS及组件说明明确：新增左下角普通／限时消息使用useNotify，常驻／带操作消息使用FloatingMessage，禁止另写固定定位、框体和独立样式。页面正文MessagePanel、视频准备数量行仍独立。

按React工程规则使用消息局部时钟状态并在渲染时计算剩余数字，稳定effect依赖；按frontend-testing-debugging复用现有真实组件夹具。Browser插件未提供，使用已有Playwright，不安装依赖。
