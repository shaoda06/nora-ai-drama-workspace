# W220：场次修改轮次

日期：2026-10-17

版本：0.6.84

## 数据与展示

- 新增项目内唯一场次组合JSON，记录每轮剧本／分镜文件和版本、完整分段顺序、计划时长及阶段／R。登记工具只追加组合并留存可读文档副本，未变文档复用；不改原执行和人工决定，不提交生成。
- 解析器按明确组合保留旧布局独有P和未回片R，读取对应冻结资料。快照缺失或版本不匹配明确提示，不使用当前文档顶替；解析缓存格式递增为3。
- 页面场次轮次选择联动本集剧本与场次分镜、分段条及播放身份。普通修改意见仍按原P／阶段／R保存；本轮导出按组合筛选，临时查看其他版本不修改组合。浏览器临时片单与正式修改轮次区分。
- 新任务可在输入映射引用scene_modification_round，固定准备检查核对选中范围身份和分镜版本；旧任务无此字段继续保留原执行事实，不为接入改写旧请求。
- “本段最新版本”只选择当前阶段最高R；场次的“最新修改轮次”选择最新明确组合。未回片、播放失败或新轮次到达均不暗中切换视频。旧轮次和已批准身份保持。

## 规则与接入

业务真源是逐集目录与资产管理规范的“场次修改轮次”，模板、提交准备、逐集创作及网页规则链接此处。第三集只以可核实当前方案接入一份组合，不凭R拼造历史轮次，不重编号既有R，不修改审核或生成媒体。

## 验证

隔离Python测试覆盖混合R、未改文档复用、缺片资料、旧布局、快照缺失、越界／重复输入、缓存变化及提交身份；现有生成资料、项目解析、服务及发布回归一并运行。浏览器夹具覆盖旧／新轮次切换、剧本分镜联动、阶段内最新、组合外提示、本轮意见导出、按轮次连播及缺片停止、新轮次到达保持选择。测试接口、任务与项目写入隔离，视频请求拦截，不解码真实视频。

复现：在浏览服务目录执行`.venv/Scripts/python.exe -X utf8 -B -m unittest tests.test_scene_rounds tests.test_generation_context tests.test_project_parser tests.test_service tests.test_release -q`；已有Playwright环境下运行`node tests/test_scene_rounds_ui.mjs http://192.168.10.15:8782 荒院暴富`，可用PLAYWRIGHT_MODULE指定现有模块。

发布构建后使用统一启动器restart --no-browser，核对正式版本、ready及第三集实际轮次条目。截图与临时报告保存于系统临时目录，不进入项目。
