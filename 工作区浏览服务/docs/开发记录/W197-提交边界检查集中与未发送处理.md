# W197 提交边界检查集中与未发送处理

日期：2026-10-15。版本：0.6.60。

## 实现

后台在接收工作流时检查一次基础JSON结构，上传只改写声明的素材字段，发送使用已检查对象，不再由通信层遍历同一结构。通信工具的独立文件入口仍检查一次，无新增跳过检查的CLI开关。

上层登记保留执行目录的登记／成果记录保护、项目／路径／输出身份、证据名称不冲突和同任务ID复用；提交尝试、请求、响应三份证据不在登记或后台发送函数重复扫描。已有远端ID仍阻止进入新提交，原ID的监控和恢复保持。

底层通信工具统一检查三份提交证据，保留独占创建标记及请求文件。任一已有证据或独占创建冲突返回`submission_guard`、`submission_state=not_sent`；没有生成POST，不覆盖原始字节。后台记录blocked事件，待执行任务暂停，已有拒绝／未知等结果及原始错误恢复保留，不把被拦截的调用记录为新的拒绝或提交未知，也不累计为新的远端提交尝试。连接建立后才进入提交状态，连接失败不覆盖旧结果。

实际远端拒绝、超时或响应不明继续保留原始证据和错误详情，不自动重发。没有更改审批、分段版本、远端能力边界、阶段缓存及上传复用策略。

规则真源为[执行前检查与复用](../../../.agents/skills/nora-generation/references/ComfyUI-服务配置与任务提交规范.md#执行前检查与复用)，固定工具说明及服务README同步引用。模板字段、网页解析和审批格式未变，无需前端业务组件适配。
