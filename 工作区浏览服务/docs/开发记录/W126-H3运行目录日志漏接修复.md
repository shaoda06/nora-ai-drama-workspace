# H3运行目录日志漏接修复

日期：2026-10-10

后台处理execution_start时原先将日志游标推进到查询结果末尾。如果目录日志先于开始消息的处理到达，目录会被跳过，后续保存事件虽有完整MP4路径，也因缺少本轮目录绑定而无法提前取回。

修改仅涉及comfy_segments.py的目录绑定与日志游标：开始事件不再清空已到达日志；以ComfyUI串行worker最后一条“Prompt executed in …”为前序任务结束边界，排除排队期间的其他任务日志。绑定前在日志查询后再次核对运行队列中的prompt ID，防止请求期间队列已切换。保留目录原始日志作为绑定证据；旧任务已经收到开始事件但丢失目录时，若结束边界和本轮目录仍在缓冲中，可以恢复绑定。读取游标保持单调，取回仍复用现有下载凭据和版本处理。

边界依据：[ComfyUI原生串行worker](https://github.com/Comfy-Org/ComfyUI/blob/master/main.py)在task_done之后、下一轮取队列任务之前打印耗时结束日志；[原生日志实现](https://github.com/Comfy-Org/ComfyUI/blob/master/app/logger.py)按写入顺序保存日志。使用同一远端日志的先后顺序，无需猜无时区日志与本机时间的偏移。

验证：219项后台测试通过，其中24项覆盖H3分段取回。新增四个用例分别覆盖延迟处理开始消息、两个排队前序任务、重启恢复丢失目录、读取日志期间队列切换；四项在旧代码上均复现失败。真实HTTP/WS集成用例改为在POST返回前先发送开始事件并写入目录和保存日志，确认运行中自动取回、终态核对、全程仅一次生成POST。TypeScript及Vite正式构建通过。

正式发布：8782已加载v0.4.5，/api/service返回ready=true，代码与资料仍指向原工作区。重启只影响本机浏览后台，按原prompt ID恢复远端监听。EP001 P003—P007二采的目录绑定从空值恢复为远端日志声明的20261009_124759目录，原prompt ID仍为8fd21818-241f-4529-898e-f2b12498d40e；后台自动取回3/5段，目录告警清除，仍在运行。网页任务详情同步显示当前第4/5段、已取回3/5段。未新建该轮任务、未播放或分析候选视频。

限制：日志缓冲已丢失目录或无法确认边界时，不能凭文件名推测归属，沿用最终报告取回。没有修改Agent规则、生成参数、审批状态或定时器，也没有提交新的生成任务。
