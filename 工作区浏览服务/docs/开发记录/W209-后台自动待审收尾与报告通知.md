# W209-后台自动待审收尾与报告通知

日期：2026-10-16。发布版本：v0.6.72。

## 范围与行为

结果处理实现见提交`76d1844b`。后台在视频全部成果保存后自动登记待审、同步并核验本批网页入口，再保存最终报告并通知来源会话。Agent调用一次`browser_tasks.py report`读取报告，工具同时确认收到；正常成功不再要求Agent单独ack、登记待审或准备常规更新。

输出选择和远端身份在同一终态中复用；执行后入队资料复用，过程记录只读取新增事件并增量写入，状态变化不重写无变化的历史。可选业务更新复用同次已读取的报告和文本摘要。文件变化、凭据冲突、最终替换前源文字变化、通知归属和网页实际就绪检查继续保留。

收尾暂时失败最多自动重试3次，间隔2、5、10秒；次数和下次时间持久保存，重启接续、不重置额度。冲突停止并报告，已完成登记不重写。最终报告在通知发送前保存，发送结果不明不重发，读取报告确认可唤醒等待。图片继续原人工审核及展示方式。兼容入口保留。

网页失败重试时重读已完成登记报告及核对任务身份这一轻量操作保留。本发布不继续优化，也不改变提交前流程。
