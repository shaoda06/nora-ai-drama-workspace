# W379：发布成片分页选集与页内播放

日期：2026-10-24
状态：已完成
关联版本：v0.8.72、v0.8.73、v0.8.74、v0.8.75、v0.8.76（均已发布）；本轮调整随后保留于v0.8.77

## 修改原因

用户要求取消发布成片文件列表，改为每页5集的选集栏，显示上一页、下一页和总集数，下方直接播放当前选中的视频。

## 具体改动

- 复用公共TabNav与Pagination，按实际视频文件提供每页5集的选择；翻页选中该页首集，手动选集切换下方唯一播放器，不自动播放。
- 发布目录及子目录的视频纳入选集，保留原名称并按路径自然数字排序；只读使用现有文件接口，不新增项目写入或修改后端目录读取。
- 不足一页仍显示翻页按钮和总集数，首末页禁用对应按钮；无视频显示空状态。离开栏目停止并卸载播放器，重新进入栏目沿用既有项目入口重置行为，默认第一集。
- 同步真实组件展示、实现说明及专用回归。

## 选集栏与视频尺寸调整（2026-10-24）

- 按用户反馈将文件名选集放入分页中间，取消左侧独立选集与中间页码／总计；左右仍为上一页／下一页。每页最多5个实际文件名去扩展名，保持一行，窄屏仅选集内部横向滚动。
- 公共Pagination新增compact紧凑规格与children中间内容，公共TabNav新增scrollable单行滚动规格；由公共实现控制间距，不在发布成片页覆盖组件样式。发布模块间距缩为12px。
- 项目路径标题改为“发布成片（数量）”，计数与播放器共用releaseVideos递归筛选口径，不另发请求或按页计数。
- 视频取消width:100%和背景填充，仅限制65vh最大高度与容器最大宽度，按实际媒体比例缩放，消除页面额外撑出的黑边，不裁切视频本身。
- 同步真实展示及专用回归，最终验证和发布结果见下。
