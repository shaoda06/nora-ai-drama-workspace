# W379：发布成片分页选集与页内播放

日期：2026-10-24
状态：已完成
关联版本：v0.8.72（已发布）

## 修改原因

用户要求取消发布成片文件列表，改为每页5集的选集栏，显示上一页、下一页和总集数，下方直接播放当前选中的视频。

## 具体改动

- 复用公共TabNav与Pagination，按实际视频文件提供每页5集的选择；翻页选中该页首集，手动选集切换下方唯一播放器，不自动播放。
- 发布目录及子目录的视频纳入选集，保留原名称并按路径自然数字排序；只读使用现有文件接口，不新增项目写入或修改后端目录读取。
- 不足一页仍显示翻页按钮和总集数，首末页禁用对应按钮；无视频显示空状态。离开栏目停止并卸载播放器，重新进入栏目沿用既有项目入口重置行为，默认第一集。
- 同步真实组件展示、实现说明及专用回归。
