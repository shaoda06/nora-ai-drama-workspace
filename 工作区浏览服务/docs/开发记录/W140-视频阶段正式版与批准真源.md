# W140 视频阶段正式版与批准真源

日期：2026-10-10。

## 问题与原因

荒院暴富EP001完成后处理后，一采、二采在网页仍显示候选。项目当前选定表及审阅已批准，执行条目的用户决定仍有待审核或缺项；旧解析只认执行条目决定。同R多阶段使用旧标题时，旧解析还可能只取到第一个同R条目。

原流程已要求记录采用事实及同步文件引用，但未规定审阅决定的唯一维护入口和采用收尾的逐阶段核对，造成重复状态漏维护。补正以原有批准事实为依据，不新增审批。

## 修改

批准与关联的业务真源为[逐集目录规范](../../../.agents/skills/nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#视频采用记录与批准依据)。模板提供对应引用位置；当前选定表和执行条目引用具体审阅决定。

解析按明确审阅链接和精确文件身份认定各阶段正式版，保留仅执行条目审批的旧记录兼容；失效、未批准或文件身份不匹配不认定正式版并记录资料提示。video_record_body逐项匹配同R的实际阶段，避免误取别的阶段。

依据已有审批，荒院暴富EP001、EP002共19份分段工作稿补齐57个阶段的关联，12条已有叙述式二采批准补充标准决定字段。修改前工作稿留存在各集其他资料／历史版本；保留用户原话、原批准时间、输出字节、原执行证据及历史状态。项目资料继续按Git忽略规则本地保存。
