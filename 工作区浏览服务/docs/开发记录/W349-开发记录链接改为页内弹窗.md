# W349：开发记录链接改为页内弹窗

日期：2026-10-23
状态：已完成
关联版本：v0.8.39（已发布）

## 修改原因

移除低频的全部开发记录入口及列表，让W链接在页内弹窗显示，阅读详情时保持原列表页码与位置。

## 具体改动

- History删除“全部开发记录”侧栏入口与右侧完整列表，开发记录文件不删除。
- 文档链接通过PreviewContext打开公共Dialog，按需读取history/document并使用Document显示正文；弹窗内的链接继续在同一弹窗切换，章节锚点在弹窗内定位。
- 关闭按钮及Esc沿用公共Dialog行为，主页面内容、页码、滚动位置保持。读取失败沿用Result的公共错误消息与重试。
- 同步服务工作约定、版本记录规范与组件说明，未关联发布的W文件留在原目录，不新增网页索引。

## 验证结果

- TypeScript检查及正式前端构建通过；统一启动器重启8782后，/api/service返回v0.8.39、ready=true，代码与资料目录正确。
- Browser插件不可用，使用现有Playwright在1362×918、390×918检查正式页面：入口与列表已移除，版本记录每页10条和底部分页正常；第2页中部W链接打开正文弹窗、弹窗内文档链接继续打开、关闭按钮及Esc关闭均通过。
- 弹窗关闭前后版本正文、页码与原滚动位置一致；弹窗不超出视口，主页面无横向溢出，无框架错误遮罩或页面运行错误。桌面与手机截图已查看。
