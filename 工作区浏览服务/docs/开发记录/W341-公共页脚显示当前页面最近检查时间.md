# W341：公共页脚显示当前页面最近检查时间

日期：2026-10-23
状态：已完成
关联版本：v0.8.27、v0.8.28（已发布）

## 修改原因

用户要求公共页脚显示当前页面真实最近检查时间，取消非项目页固定占位及项目数据构建时间。原项目页采用builtAt，非项目页固定显示“上次同步：—”，不能代表当前页面的实际读取检查。

## 具体改动

- 新增公共PageCheckStatus组件，通过FooterCheckContext接入AppShell页脚。各页面传入本页已有读取Query，使用非占位数据的最近成功读取时间dataUpdatedAt；数据没有变化的成功读取同样更新。
- 接入首页、项目、风格库、开发记录、提示词、资产列表/详情和内置工作流。项目构建时间不再用于页脚；独立服务版本和任务栏轮询不作为本页检查来源，不新增定时器或改变原检查周期。
- 请求失败保留最近成功时间并标明检查失败；首次读取显示正在检查，尚无成功记录时如实标明。没有读取的新建资产表单显示尚未检查，不沿用上一页时间。
- v0.8.28补充手机显示：600px以下只显示时分秒，避免完整日期将时间挤出页脚；电脑保留完整日期。time元素的datetime、title及aria-label保留完整时间。
- 组件与页面实现文档同步说明接入方式；后续页面复用PageCheckStatus并传入本页实际读取Query。

## 验证结果

- TypeScript检查和正式构建通过；统一启动器发布后，/api/service返回v0.8.28、ready=true，工作区和服务目录正确。
- 使用现有Playwright/Chromium验证（Browser plugin not available）：9个入口（资产三类分别计入）均显示本次浏览会话实际读取产生的时间，只有一份页脚时间，无旧“上次同步”占位及页面脚本错误。
- 浏览器内拦截首页项目列表，固定相同响应：初次成功后按原5秒轮询更新时间。模拟503失败，成功时间保持不变且显示检查失败；恢复200后时间更新并清除失败标记。测试没有写入真实项目。
- 工作流页在服务版本和项目切换器轮询期间保持自己的读取时间不变；切换到新建资产表单不带入旧时间。延迟资产列表响应时显示正在检查，成功后显示新时间。
- 已核对1362×918桌面及390×844手机截图；手机显示完整时分秒。日期仍使用浏览器本地时区，语义时间保留完整日期。
- 临时脚本、结果及截图保存在/tmp，未入库。未单独验证其他浏览器引擎。
