# W251：共用页面提示区域

日期：2026-10-22；版本：0.6.131。

## 功能与实现

新增MessagePanel公共组件，接收messages数组，每项包含稳定id及content，按需提供tone、detail和actions。统一框体、信息行、错误alert语义、明细提示和同行操作；无消息不渲染。消息由调用页面派生，组件不保存业务状态，不增加请求、计时器或通知队列。

SceneWorkspace将视频准备数量／失败明细、轮次资料错误、组合外版本提示、临时片单操作、连播异常、上集末段、分段顺序及历史轮次编辑说明统一传入组件。普通布局位于分段导航下方、版本选择上方，宽屏也保留。其他场次标签只显示当前适用信息；移除已替代的分散提示CSS。切换版本、轮次、连播、片单和导出仍由原操作处理。

本次按React工程技能从现有业务状态直接派生消息，前端验证技能用于真实浏览器检查；组件清单及使用方式已同步。纯展示及组件复用调整，不涉及创作规则、模板、项目资料或审批／生成流程。
