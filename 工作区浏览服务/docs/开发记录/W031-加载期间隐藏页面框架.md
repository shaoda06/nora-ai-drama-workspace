# W031 加载期间隐藏页面框架

日期：2026-10-06。

## 修改

Loading增加page选项：加载显示挂到页面根节点之外，固定在视口内居中；CSS在页面加载显示存在时隐藏应用根节点，因此品牌、导航、阶段栏、标题、路径、正文框及页脚都不显示。请求与原组件仍保持挂载，资料就绪或失败后加载显示移除，框架随之恢复，无需新增全局加载状态或计数器。

Suspense、工作区首页、项目状态／概览及活动栏目、开发记录、风格库目录读取使用page选项。已访问但隐藏的栏目不显示页面加载。详情及阅读弹窗继续使用区域加载，页面已有资料的后台检查继续保留完整框架和正文。轮询周期、通知规则、项目内容和资源更新逻辑不变。

浏览入口规范v1.96→v1.97，修改前完整归档；同步组件说明及版本记录。正文模板与离线HTML无需改动。

## 验证

TypeScript和Vite生产构建、技能校验通过。Browser插件及browser技能未提供，使用现有Chrome与Playwright；未安装依赖。目标服务http://192.168.10.15:8782，桌面1398×928、手机390×844。

分阶段暂缓实际请求：页面代码 → 项目状态 → 项目概览 → 定位栏目。各阶段都只显示加载动画和文字，应用框架不可见；最后读取完成后框架与真实内容恢复。首次切换故事大纲沿用此行为，活动栏目外没有隐藏页的加载残留。

暂缓一次5秒后台状态请求，已加载框架和正文仍保持可见；完整进度阅读弹窗的加载留在弹窗中。首页、开发记录和风格库目录分别检查首次加载与恢复。手机加载区域覆盖视口并居中，无横向溢出。注入一次503读取失败，加载显示消失且全局错误通知出现；该503为测试模拟，非实际服务故障。

页面身份、内容恢复、交互和错误覆盖层检查通过，正常请求无应用运行错误。截图位于本机临时目录nora-loading-frame-qa；未生成独立HTML测试报告。仅验证Chrome，未验证其他浏览器；加载框架隐藏使用当前Chrome支持的CSS :has及既有React portal。后端无需重启，已打开的网页刷新后使用新构建。
