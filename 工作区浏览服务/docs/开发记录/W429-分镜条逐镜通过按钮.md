# W429：分镜条逐镜通过按钮

日期：2026-10-27
状态：已完成
关联版本：v0.8.135（已发布）；v0.8.136（已发布）

## 修改原因

用户要求每个分镜进度条下方都有一个“本镜通过”按钮，与对应分镜格居中对齐。

## 具体改动

修改意见页的分镜格内增加独立通过按钮，沿原时长比例网格居中；每个按钮绑定自身镜号和起始时间，不跟随当前播放镜头。文本框工具行保留插入时间、清空和保存状态。复用原光标插入与自动保存，不改变视频采用状态。
