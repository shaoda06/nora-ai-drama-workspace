# W199 映射文件名检查复用与目录占用拆分

日期：2026-10-15。版本：0.6.62。

## 固定检查

上传映射的必填字段、值类型、json-path格式、目标目录和源文件名，以及各类证据文件名的合法性、重名、保留名称冲突统一由准备工具检查，保存在既有执行检查报告。报告匹配时直接复用，入队、实际上传和发送不重复这些检查；显式重复准备且依据未变也复用。格式不合规的上传字典可以登记但不会被用于文件操作，开工时在依据比较或固定补查中停止。

统一入口仅传递上传映射，不提前做字段或文件名判断。后台正常化可用的本地路径并保持项目范围；路径转换不拒绝缺字段或错误类型的映射，也不借转换重复格式核验。通信使用准备后的源路径和工作流；独立CLI调用保留输入检查，真实上传响应的文件身份仍核对。没有新增外部跳过检查开关。

## 目录与动态证据

入队从SQLite识别同目录任务，同任务返回原ID；未识别任务的固定后台状态／过程记录则保护不覆盖。不扫描自定义上传／终态／下载凭据，不把API、画布、映射等准备文件当成目录不可用。

准备报告匹配后，已有上传凭据在上传环节按实际端点和源文件指纹核对并恢复；终态或下载凭据在提交环节阻止新生成，返回execution_guard及not_sent，待执行任务暂停，旧结果保留。底层三份提交证据检查、独占创建，以及实际下载的不覆盖继续保持。报告位置已有其他资料则停止，不覆盖该资料。

执行端配置、队列、缓存及上传期间文件变化检查保持。规则真源、固定工具说明和服务README同步；既有H3入口和模板继续引用同一真源，不改审批、业务字段或项目资料，无需前端业务组件适配。
