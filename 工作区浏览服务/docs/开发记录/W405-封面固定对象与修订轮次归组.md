# W405：封面固定对象与修订轮次归组

日期：2026-10-25
状态：已完成
关联版本：v0.8.111，已发布至8782

## 修改原因

封面页按生成文件平铺，同一平台横版、竖版的多轮修改散成独立卡片，用户无法直观看到它们属于同一张封面。用户已选择页面与版本关联一起整理，范围包含共用规则、登记工具、页面及《我们的AI短剧》现有封面资料。

## 具体改动

- 每个平台及用途的横竖封面登记固定COV编号，修改使用R轮次；原图、处理成品、候选及执行记录关联到同一对象及轮次。同轮可有多次生成，尺寸处理不另算设计版本。
- 主页面每个封面对象只显示一张公共卡片，优先显示当前正式版；尚无正式版时预览最新候选。新候选不会顶替当前正式版。详情区分当前正式、最新候选与倒序且默认折叠的版本记录，文件的查看／下载跟随对应条目；无法核实的旧资料保留紧凑待归类入口。
- 解析器保留原有items、candidates接口字段，增加assets、unassigned归组数据。旧记录只依据明确编号、历史补录及原采用链接建立关系，不猜文件名、不追写历史平台。旧成品使用本轮保留输出或明确补录的历史文件，避免引用被新版本覆盖的正式路径。
- Imagegen与Qwen的新封面登记须引用索引已声明的编号及修订轮次，并检查平台、版式与套组一致；旧执行清单恢复及后处理不受新登记字段限制。采用更新继承旧封面编号。
- 同步封面规则、索引和工作稿模板、工具说明与浏览入口规范。《我们的AI短剧》6个固定对象、22条生成记录完成历史归属补录，其中1条失败执行归入对应轮次；原生成、审批原文、请求文件、图片及路径保留，整理前文档另存项目历史版本。当前三平台六张正式封面不重新生成、不重新批准。
- AssetMediaCard增加可选空态文案，默认文案不变；真实公共展示补充“已登记尚未生成”示例。
