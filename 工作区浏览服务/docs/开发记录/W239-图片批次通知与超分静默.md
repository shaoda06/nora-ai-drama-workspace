# W239 图片批次通知与超分静默

## 行为

- 任务清单在准备阶段给其中的普通图片生成任务登记持久批次标识和完整预期任务数；超分、视频不计入这批图片。清单恢复、部分入队恢复和后台重启不改变范围；不同项目、来源会话和清单分开判断。
- 每张图继续独立下载、技术核验、登记及网页同步。整批全部成功并可审后，一次报告包含本批全部成果；部分正常完成不再逐张唤醒来源会话。
- 超分完成正式保存、关联记录和网页核验后，通知记为 `not_required`，本地报告及真实文件仍保留，不发送完成消息或重复展示。失败、异常暂停、取回和收尾异常仍按原停止／重试规则单独通知。
- 没有批次关联的历史及旧式单任务不自动猜测合批；已发送和送达不明的通知不重发。正常超分的历史通知只读取并确认，不输出对话进度或完成回复。
- 通知关联不改变工作流、生成参数、审批与下一阶段授权；准备检查的生成依据不纳入这两个通知字段，旧报告保持兼容。

## 检查

回归使用临时项目、模拟下载／网页／桌面发送，覆盖分次完成后统一报告、跨项目与不同批次隔离、重启等待、部分入队不缩减数量、异常先报及恢复后整批交付。真实PNG夹具验证静默超分仍完成正式保存并保留原审批。

本次不生成图片或视频，不向真实会话发送测试通知。规则修改前的原文按技能维护规范保留本地历史，正式规则真源为生成技能《ComfyUI-任务监控规范》的“图片批次通知与超分静默”。

任务链路204项回归通过；三份受影响技能入口校验通过，10条新增规则链接及锚点核对通过，前端生产构建通过。macOS测试使用`TMPDIR=/private/tmp`，不修改产品路径安全检查。
