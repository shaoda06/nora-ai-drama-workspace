# W348：版本记录分页与取消章节导航

日期：2026-10-23
状态：已完成
关联版本：v0.8.35（已发布）

## 修改原因

版本记录整份展示导致页面过长、章节导航冗长，改为分页并保留记录内容与W文件入口。

## 具体改动

- history/document按版本记录的三级标题切分完整条目，每页10条，只渲染和返回当前页正文以及页码、总数。原文件与历史内容保留；其他文档仍完整返回。
- History上下复用公共Pagination，翻页回到顶部，打开W文件再从侧栏返回版本记录保留页码。公共分页新增pageSize参数，已有调用仍默认36项。
- Document新增showChapters参数，版本记录关闭章节扫描及导航，其他文档保留原行为。手机分页控件可换行，不超出屏幕。

## 验证结果

- tests.test_history_pagination的3项HTTP测试通过：23条模拟记录分三页无遗漏或重复，W链接及正文完整，末页越界与非法页码处理、无记录、其他文档及路径边界检查通过；原Markdown内容未修改。
- TypeScript检查与正式构建通过。统一启动器重启后，8782返回v0.8.35、ready=true，代码和资料目录正确。
- 正式版本记录320条与源文件三级标题数一致，第2页仅返回10条，HTML正文6934字节。
- Browser插件不可用，使用现有Playwright检查1362×918、390×918：页面正确加载、无框架错误遮罩或页面运行错误；翻到第2／3页、返回上一页、打开W链接再返回原页码均通过；开发记录规范仍有章节导航；版本记录无章节导航、无横向溢出。截图保存在本机临时目录。
