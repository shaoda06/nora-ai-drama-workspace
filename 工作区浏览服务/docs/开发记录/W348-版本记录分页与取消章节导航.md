# W348：版本记录分页与取消章节导航

日期：2026-10-23
状态：已完成
关联版本：v0.8.35（已发布）；v0.8.37（已发布）；v0.8.38（已发布）

## 修改原因

版本记录整份展示导致页面过长、章节导航冗长，改为分页并保留记录内容与W文件入口。

## 具体改动

- history/document按版本记录的三级标题切分完整条目，每页10条，只渲染和返回当前页正文以及页码、总数。原文件与历史内容保留；其他文档仍完整返回。
- History上下复用公共Pagination，翻页回到顶部，打开W文件再从侧栏返回版本记录保留页码。公共分页新增pageSize参数，已有调用仍默认36项。
- 2026-10-23补充：按用户反馈取消顶部翻页栏，仅保留正文底部翻页；单一版本记录Markdown文件继续保存全部版本摘要。
- 2026-10-23补充：版本记录页通过限定样式隐藏正文开头重复的一级标题，保留源文件标题与其他文档标题。
- Document新增showChapters参数，版本记录关闭章节扫描及导航，其他文档保留原行为。手机分页控件可换行，不超出屏幕。
