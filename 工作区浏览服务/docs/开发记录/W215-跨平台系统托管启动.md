# W215：跨平台系统托管启动

日期：2026-10-17
版本：0.6.79

## 范围

- 日常启动及Agent发布重启统一使用launcher。Windows由当前用户任务计划程序启动前台工作进程，Mac由用户launchd启动；系统项不设置开机、登录、定时或失败重启触发。
- 新增Mac启动／停止.command入口，使用本机.venv/bin/python；Git设置可执行权限和LF换行。Windows保留原双击入口，系统任务使用普通权限、交互用户凭据，不保存密码。
- 新增restart及--no-browser供发布使用；核对原服务身份后停止，等待退出，再由系统启动并等待ready。旧版直接启动进程可在本次重启时切换。
- 系统项绑定用户、端口及实际代码目录；同名项属于其他目录时拒绝操作，托管失败不回退到Codex子进程。日志仍存runtime/server.log，环境及资料目录仍从本机service.json读取。
- 同步工作区README、服务README及服务AGENTS发布规则；不改节点配置、任务记录或项目资料，不安装开机自启项。

## 验证

- 15项启动器测试通过，覆盖身份隔离、占用端口、停止失败不再启动、旧进程切换、等待就绪、Mac无自启定义及注册／卸载调用和冲突拒绝。
- Windows使用独立临时目录及8791端口实测：启动命令退出后接口持续响应；进程祖先为svchost、services和wininit；任务状态为运行、触发器0个、普通权限、无执行时限。
- Windows托管重启后PID变化且ready=true；停止成功；另一份代码目录争用同名后台项被拒绝，原后台项可继续启动。用户SID被系统显示为账号名时，按实际身份解析后核对。
- Mac仅验证生成的plist及模拟launchctl调用，尚未在Mac实测系统注册、双击权限、发布重启、退出Codex后存活及后台外部工具调用。
- 启动器、发布及HTTP隔离共20项测试通过，前端正式构建通过；4个受影响本地链接／锚点有效，两个.command的Git模式均为100755、内容为LF换行。
- 正式8782通过新入口restart --no-browser切换为系统托管，版本0.6.79、ready=true，代码与资料目录正确。正式后台项运行中、0个触发器、普通权限、无执行时限；进程祖先来自Windows服务管理器。
- 内置浏览器只读核对首页、两个当前节点、历史计数及版本0.6.79，控制台无错误或警告；未修改节点配置、任务记录或项目资料。本次未退出正在工作的Codex应用，进程托管来源已直接核验。
- 临时8791服务已停止，对应测试后台项已删除，正式后台项保留。
