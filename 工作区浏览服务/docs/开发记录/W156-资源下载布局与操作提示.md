# W156：资源下载布局与操作提示

日期：2026-10-11。发布版本：v0.6.10、v0.6.11。

资源下载加载或读取失败时仅显示对应状态，不显示后处理、二采、一采章节。每个阶段的正式版视频数量移至“正式版视频下载”标题旁，用小字显示；视频按钮简写为“打包下载”。导演包下载使用原生details默认折叠，展开后导演包和画布每行一个。所有资源下载按钮共用样式。

DownloadButton自行记录每次点击时间，在该按钮后显示“已请求下载，请查看浏览器下载列表”。多个按钮的提示相互独立，同一按钮重复点击也逐次追加；仅在当前页面保留，不持久化，不冒充浏览器保存成功。原生下载及后端接口不变。

## 命名与层级

- 阶段视频ZIP：`剧名-EP编号-阶段-正式版视频.zip`，例如`荒院暴富-EP001-二采-正式版视频.zip`，覆盖整集所有场次该阶段已批准的正式视频。
- “打包下载本集内容”：仅后处理正式视频，名称同后处理阶段包，例如`荒院暴富-EP001-后处理-正式版视频.zip`；完成条件比阶段下载严格，要求整集完成且每段齐备。
- ZIP内部：`C编号-场次/视频原文件名.mp4`，例如`C001-场次/EP001-C001-P001-R010-后处理.mp4`。文件原名中的EP/C/P/R分别对应集、场、分段和修改版本；各段R可不同，不另加统一打包版本或提交批次编号。下载不合并为单条视频、不转码、不重命名原视频。
- 导演包与画布：下载已有原文件，保留原名，例如`EP001-C001-后处理定稿-标准版-导演包.mmxpack.zip`及`EP001-C001-后处理定稿-标准版.workflow.json`。网页不创建外层ZIP或修改导演包内部结构。当前EP001导演包内包含`pack.json`、`timeline.json`以及`extra/`、`shared_params/`、`asset_groups/`等既有资料；这些名字由原导演包制作工具决定。
- `runtime/downloads/videos-随机字符.zip`仅为服务端临时包名；浏览器通过附件响应取得上述正式下载名称。重名下载由浏览器决定如何保存，网页不追加R或批次号。
