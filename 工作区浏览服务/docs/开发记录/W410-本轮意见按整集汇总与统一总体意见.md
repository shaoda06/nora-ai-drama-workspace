# W410：本轮意见按整集汇总与统一总体意见

日期：2026-10-26
状态：已完成
关联版本：v0.8.117（已发布）

## 修改原因

修改轮次已改为整集共用，意见导出需要同步按整集选中轮次汇总，并提供一份本轮汇总意见，避免重复填写各场总体意见。

## 具体改动

- 接续[W408](W408-单集共用修改轮次.md)：本轮意见按场次、P段、镜头顺序复制导出，保留阶段、R及候选身份；同集同轮只有一份可编辑的“本轮汇总意见”。
- 新整集轮次的分段意见与汇总意见统一保存到 `EP编号-视频修改意见.json`，分段按C归组，先比对全部原文，再原子替换一个文件。原场次文件和旧总体意见保留，不自动迁移、重编号或合成新汇总。
- 旧场次模式提供“当前组合意见”只读汇总，保留各场真实旧轮号；旧意见在原分段编辑区修改，真实整集轮次才启用整集汇总输入。上集末段历史入口继续独立，保存整集分段意见时归回整集文件，不另建场次副本。
- 弹窗状态归属整集，跨场连播后保留打开时的范围、保存目标和未保存输入。复制按镜号和时间整理带标记的正文块，保存原文不改排序；保存／还原／复制、关闭确认和错误反馈继续复用现有公共实现。
- 同步目录规范、浏览入口、README和组件说明；排除整集备注JSON对项目编译／revision的影响。身份迁移脚本兼容整集按C分组的JSON，并保留各审看轮次键；未执行真实项目迁移。
