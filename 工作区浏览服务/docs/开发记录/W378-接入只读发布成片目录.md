# W378：接入只读发布成片目录

日期：2026-10-24
状态：已完成
关联版本：v0.8.70（已发布）

## 修改原因

项目结构已有用户使用的98-发布成片目录，浏览页尚未接入。增加独立入口，按原目录展示文件与子目录，支持视频预览和下载，不修改用户文件。

## 具体改动

- 将98-发布成片接入既有项目栏目和栏目查询接口，导航直接从实际目录发现，独立于相关资料、参考素材和剧集制作，不新增文件写入接口。
- 按原目录递归列出文件、多层子目录和空目录；使用现有文件分类及文件优先排序，支持任意文件名，非浏览器支持格式保留原文件入口。列表只读元信息，不要求索引，也不解析用户文档正文或推断审批／发布状态。
- 排除隐藏项和越出项目边界的链接，目录符号链接不递归。98目录及其空子目录加入现有文件变动快照，新增／删除空目录也能同步；升级既有解析缓存schema，避免旧缓存隐藏新栏目。
- 完全复用Catalogue、FileTree、Preview及FileActions，保留搜索、折叠、媒体预览和下载，不另做播放器或下载流程；同步真实公共组件示例、页面说明及覆盖表。
- 使用主技能确定用户发布成片与制作中间文件的边界；工程技能落实按栏目读取、现有同步接口和公共组件复用。未创建、整理或修改真实项目中的目录与文件。
