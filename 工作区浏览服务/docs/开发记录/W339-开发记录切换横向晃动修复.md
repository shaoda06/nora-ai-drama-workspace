# W339：开发记录切换横向晃动修复

日期：2026-10-22
状态：已完成
关联版本：v0.8.24（已发布）

## 修改原因

用户反馈点击开发文档列表时列表左右晃动。使用非覆盖式滚动条复现：页面滚动条在长短文档及加载阶段切换时出现或消失，占用宽度变化15像素，使居中的主区域及侧栏横移7.5像素；侧栏自身宽度始终220像素。

## 具体改动

在frontend/src/style.css中，为含有.history-layout的页面设置scrollbar-gutter:stable，固定预留页面滚动条位置。样式仅用于开发记录页，切换到其他页面后不保留该设置。

## 验证结果

- 前端TypeScript检查及正式构建通过。
- 在正式页面逐帧测量7个入口切换：临时关闭此样式，侧栏x在81.5与89之间变化；恢复样式后，x始终为81.5，横移由7.5像素降为0。
- 分别使用非覆盖式滚动条、默认浏览器配置和390×844手机尺寸核验；入口切换位置稳定，无页面横向溢出或JavaScript页面错误，桌面及手机截图已检查。
- 离开开发记录页后，scrollbar-gutter恢复auto。
- 使用统一启动器重启8782；/api/service返回v0.8.24、ready=true，工作区和服务目录正确；页面页脚显示v0.8.24。
