# W425：切换场次保留重复播放与宽屏

日期：2026-10-27
状态：已完成
关联版本：v0.8.131（已发布）

## 修改原因

同一集切换场次后，重复播放与宽屏显示回到默认。根因是宽屏状态由SceneWorkspace按场次保存，重复播放由会随视频重建的SegmentVideo内部保存，切场卸载后重新初始化。

## 具体改动

将制作页两项偏好交由EpisodeProduction按制作对象持有，场次、分段、播放器复用受控值。连续播放开启仍清除并禁用重复播放，关闭连续播放不自动恢复。公共播放器保留独立调用的默认行为。

SegmentVideo增加可选repeatControl，SegmentWorkspace转交该值，SceneWorkspace改用上层宽屏及重复状态；制作页更换分段、候选或轮次重挂播放器也保持偏好，换制作对象回到默认。展示页使用同一受控播放器示例并同步规则、覆盖表；未传控制值的独立播放器仍沿用本地开关及版本重挂默认值。
