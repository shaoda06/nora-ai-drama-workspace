## 具体改动

### 问题与修复

打开提示词后向下滚动，点击目录会清空编辑区。原三栏高度随编辑区从约666px缩短为580px，文档可滚动高度减少，浏览器把scrollY从121自动限制到35。记录window.scrollTo调用后确认点击目录并未触发程序主动回顶。

电脑端三栏改为稳定高度，长正文、预览和目录在各自栏内滚动；不添加强制恢复页面滚动的位置补丁。相同操作在修复后高度和scrollY均保持一致。窄屏保留逐层导航。

编辑表单移除“编辑提示词／已保存到本地文件”行，标题和所在分类标签改到控件左侧。分类选择复用TabSelect模块内既有弹出式组件，仅新增该组件的导出，不改变其他调用方行为。选择分类后仍需点击保存才移动文件，未保存离开提示保留。

## 验证结果

新增 `tests/test_prompts_layout_ui.mjs`，全部API由浏览器内测试数据接管，不读写真实提示词资料。可对运行中的前端执行：

```sh
PLAYWRIGHT_MODULE=/path/to/playwright node tests/test_prompts_layout_ui.mjs http://127.0.0.1:8782
```

同一条滚动断言在旧版失败（121→35），修复后通过；覆盖固定区域高度、长预览内部滚动、目录切换、鼠标选分类、键盘Home／Enter／Escape、未保存提示、保存分类和正文保留。桌面1362×918与窄屏390×844验证标签与控件同行，菜单未溢出，无页面错误。

TypeScript、生产构建和3项发布检查通过。使用统一启动器重启正式后台，核对版本及ready，并对真实页面只读核对滚动与选择器显示。
