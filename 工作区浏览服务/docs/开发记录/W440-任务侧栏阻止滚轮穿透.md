# W440：任务侧栏阻止滚轮穿透

日期：2026-10-28
状态：待发布
关联版本：v0.8.150（待发布）

## 修改原因

侧栏打开时，鼠标位于标题／空白等不可滚动区域，以及列表到达边界时，滚轮会带动背景页面。要求侧栏内可滚动区域继续独立滚动，侧栏内其余滚轮不传给背景；鼠标在侧栏外或关闭后保留背景滚动。

## 具体改动

复现侧栏标题区域的真实滚轮会让背景scrollY从300增加到550。根因是侧栏滚动链未被阻断；仅给真实公共TaskSidebar的[data-open=true]加overscroll-behavior:contain。局部验证确认标题、空列表、分类及窄栏不传给背景，可滚列表正常，顶底边界隔离，侧栏外及关闭后背景仍正常滚动。无需事件拦截或body全局锁滚；不改队列、拖拽或外部关闭逻辑。同步真实展示说明与覆盖表。

## 验证结果

Browser plugin not available，使用现有Playwright真实侧栏及隔离API。

- 修正前1362px原生wheel复现：节点标题悬停滚轮让背景从300到550，新增回归断言失败。临时仅注入候选CSS即可通过桌面所有场景；正式实现只增加同一条CSS属性。
- `test_task_sidebar_wheel_ui.mjs`通过1362／390／320px：节点标题、空列表、本地分类标题、侧边窄栏不带动背景；内部列表正常滚动，上下边界不传给背景；桌面侧栏外及各尺寸收起后背景滚动正常。背景测试先实测可滚动，避免不可滚背景造成假通过；空列表、溢出列表均验证，无API写入、浏览器错误0。手机列表底部出现1px浏览器取整，断言仅对内部边界允许1px，背景位置仍严格相等。截图：`/tmp/nora-sidebar-wheel-nccEXV/`。
