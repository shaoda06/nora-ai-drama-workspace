# W201 工作区共用ComfyUI配置与认证

- 版本：0.6.64
- 日期：2026-10-16

Agent与后台共同复用主技能scripts/comfyui_config.py，从实际资料工作区根目录读取配置，取消项目文件扫描与覆盖。工作区旧地址数组格式仅作读取兼容；项目文件不是回退来源。配置结构及迁移规则仅在[服务配置规范](../../../.agents/skills/nora-generation/references/ComfyUI-服务配置与任务提交规范.md#工作区-comfyui-配置)维护。

通信客户端在不改变原请求正文的前提下支持Basic认证；队列查询、上传、生成POST、history、download及任务／节点WebSocket共用凭据。节点凭据变更触发监听重连；未填账号密码时本地返回missing_auth，不进行远端请求。既有任务仍沿原地址查询，未配置旧地址不会借用主节点凭据。明确直接通信及场次定稿导出也复用同一读取器。

任务快照保留退出配置的旧节点，以便读取其历史；旧节点不参与自动调度或作为转移目标。新节点和旧节点的队列、历史及计数均按实际地址区分。界面显示待填写凭据及退出配置原因，不展示账号密码；TaskInput与任务持久化结构不增加认证字段。

验证采用临时工作区、模拟HTTP／WebSocket及现有准备、上传、提交、下载、防重与恢复回归；不向正式远端提交测试生成。实际两个HTTPS地址的认证连接需在本机配置填写后核对。

检查结果：队列、恢复、准备／提交边界等118项首次回归仅有旧配置测试夹具失败；夹具修正及旧节点入口加入后，任务／认证／发布45项回归和新增跨项目登记测试全部通过。配置／入队14项、固定通信21项及场次留档17项通过，前端构建与技能校验通过。规则入口及修改文档的本地引用已核对；组件文档中的“相对路径”为原有格式示意。未填写真实凭据，不宣称实际HTTPS登录或远端生成已验证。
