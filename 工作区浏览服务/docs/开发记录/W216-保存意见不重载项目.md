# W216：保存意见不重载项目

日期：2026-10-17
状态：原记录未单列，以正文为准
关联版本：0.6.80

## 修改原因

### 问题与原因

视频意见虽使用独立GET／PUT接口，其JSON仍参加ProjectStore项目快照和正文目录。每次停笔保存使项目revision改变，剧集和候选资料重新查询。SegmentWorkspace在新revision开始时没有占位数据，已读取的参考素材短暂变成空态，显示加载和同步提示。

## 具体改动

- 只排除固定路径`09-剧集制作/EP编号/其他资料/工作稿/同EP编号-C编号-视频修改意见.json`，创建、修改及删除均不影响项目快照或编译目录；意见接口继续实时读取与保存，身份和自动保存方式不变。
- 不排除其他JSON：输入映射、执行请求、审批及正文、素材变化继续被检测；EP不匹配或备份文件也正常参与扫描。
- 同一项目、完整候选身份的generation-context重新读取时保留已加载数据；换项目、EP、C、P、R或阶段不沿用旧参考。真正变更仍发请求，不删除revision依赖。
- 不涉及生成、提交、正式任务库、凭证或审批事实。

## 验证结果

- 新增回归覆盖意见首次创建、修改、清空、删除；真实正文和映射依然失效；同名错误路径不被豁免；意见不进入编译来源；意见保存后内存与重启播放缓存继续复用。
- 完整后端回归619项通过；新版下另核对项目扫描／加载／解析、意见、候选关联及发布183项通过。新增4项测试覆盖上述意见豁免和缓存范围，旧审批、任务、素材读取回归保持通过。
- TypeScript及Vite生产构建通过，正式8782已用托管入口重启，`/api/service`返回0.6.80与`ready=true`。
- 浏览器插件不可用，使用现有Playwright与headless Edge，1531×974。针对现有项目连续两次模拟自动保存：剧集和候选查询次数不增加、6项参考保持、无同步通知；真实revision改变仍重新读取，等待时参考保留；换候选立即清除旧参考。无页面运行错误。视频请求替换为空响应，未测试视频解码，预期媒体错误不计应用错误。
- 所有意见PUT由浏览器拦截，不写用户真实意见；后端测试仅临时项目与隔离服务，不访问正式任务库和凭证。
