# W439：后台通知摘要与接续入口精简

日期：2026-10-28
状态：待发布
关联版本：v0.8.149（待发布）

## 修改原因

后台结果通知把项目身份、内部编号和整套处理规则堆为长段落，用户难以阅读。按已确认方案，将用户摘要、报告入口和固定规范分层；保留分组、结果接收、异常恢复与交付边界。

## 具体改动

将真实发送入口的两套长正文合并为`notification_prompt`：用户区只显示稳定任务身份与“有更新”，Agent区显示实际通知ID、来源会话、带引号完整脚本路径及读取命令、明确规范章节入口。历史无组任务保留所有项目／任务名称；组报告及接收处理不变。新增“后台通知接续”规则路由，并同步结果处理规范与固定脚本说明；按维护要求完整归档修改前的监控规范。

## 验证结果

- 48项隔离通知测试通过：组固定成员、正常收尾、同类异常合并、部分终态、历史无组图片／视频、延迟／重复接收、服务重启及发送状态不明；发送器全部模拟，无真实消息或任务执行。新增断言验证完整读取命令携带真实通知ID、来源归属、用户区不含内部编号／过期状态、分段与规范入口；原报告和失败事实仍可读取。
- 两个技能quick_validate通过；11条修改行本地链接和章节锚点可达。按旧通知逐项复查范围、异常合并与静默修复、用户决定边界、同类后到成员接续、禁止重复核验／轮询／生成、业务actions、正常超分静默、后处理采用及交付去重，均由新入口直达现有真源，未删减处理要求。结果处理规范和report说明均已指向新入口。
- 用真实格式化器生成纯合成示例：498字符、最长段落191字符，样例保存`/tmp/nora-notification-preview.txt`，没有发送消息。
