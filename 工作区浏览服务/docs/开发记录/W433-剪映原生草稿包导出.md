# W433：剪映原生草稿包导出

日期：2026-10-27
状态：待验证
关联版本：v0.8.140（已发布；原生导入待用户试用）

## 修改原因

普通 ZIP 解压到剪映目录不一定触发新草稿扫描。用户已选择原生草稿包自动导入，要求修复导出链路，不再手工补本机索引，并明确本次不得操作剪映。

## 具体改动

为本场各阶段与完集下载增加 `.jypack` 格式，保留 ZIP。按本机剪映11.6安装包中的导入代码处理归档记录头，继续使用原视频及三份草稿JSON。原生导入由剪映处理，遵守其会员权限检查。

## 验证结果

- 31项原生包与下载API测试通过：场次与完集范围、普通ZIP兼容、两份时间线同源、格式校验、异常清理；原生包头还原后CRC及媒体字节通过。额外覆盖媒体内含PK/JY字节、中文名、成员注释及ZIP64扩展记录，避免全局替换损坏视频。
- C002试用包已从最终透明MOV生成，原生头还原后逐字节等于原视频，只有C002一段，时长6.567秒。包和核验结果保存在被忽略的综合资料/剪映自动识别验证-20261027/原生包试用/。
- 公共组件复用检查：复用DownloadButton及原有容器，无新增CSS或组件覆盖。暂存静态检查0项问题；公共布局在1362、390、320px通过，实际SceneDownloads夹具核对jypack请求保留C002、浏览器保存扩展名正确、空阶段禁用。最初将折叠导演包中的隐藏按钮纳入边界断言导致测试失败，已改为展开后再核对，没有跳过断言。制作页时长回归三种宽度通过，包含新增顶部按钮。
- TypeScript/Vite构建通过；统一启动器重启8782后 `/api/service` 返回0.8.140、ready=true。正式C002后处理HTTP导出返回jypack文件名与对应MIME，包含唯一透明MOV和三份JSON，原生头还原后CRC及原视频字节再次通过。
- 仅静态读取剪映安装包，不启动或附加应用进程，不修改其目录、索引、设置。
