# W393：封面套组与平台展示

日期：2026-10-25
状态：已完成
关联版本：v0.8.99（已发布）

## 修改原因

封面索引已规定套组与逐项适用平台，浏览页尚未读取和显示，无法区分同套横竖版和平台成品。

## 具体改动

封面解析读取套组名称、多平台清单、目标格式及规格依据。CoverLibrary按套组编排现有AssetMediaCard，组头展示套组和平台汇总，详情显示逐项平台与规格依据。旧索引字段缺失时明确标为未登记，不从文件名或索引顶部推定；原有批准与真实尺寸判定保持独立。

《我们的AI短剧》现有两张采用封面归入“系列通用”套组，适用平台按用户要求标为快手；沿用原正式文件及尺寸，原图、历史生成与批准事实保留。项目记录注明这是用户指定交付规格，快手实际上传与裁切未验证，不将抖音预设改称快手官方要求。

## 验证结果

11项封面解析／登记测试通过，包含新字段、多平台和旧索引兼容。真实组件隔离浏览器测试在1362px、390px、320px下通过同套两版、多平台共用、未登记状态、详情关闭与文件入口检查。Browser plugin not available，使用仓库Playwright与隔离测试资料，无正式项目写入。

- 公共组件复用检查：CoverLibrary继续调用真实AssetMediaCard、Dialog及FileActions；本次只增加业务分组和详情内容，没有新增公共组件或页面限定的组件外观覆盖，展示归属仍是现有公共媒体卡／弹窗／文件操作。暂存快照静态检查和三种宽度的公共组件浏览器检查通过，已人工核对业务内容与实现说明。
- 发布核验：从HEAD及本次改动构建v0.8.99，排除其他会话尚未提交的前端改动。发布前一次路径检查失败触发启动器自动构建，随后纠正检查并以已验证的隔离构建包重新发布；最终通过统一启动器重启。正式服务version=0.8.99、ready=true。三种宽度的真实项目页面均显示一套两张、快手平台和逐项规格依据，两张保持已采用，项目updating=false、error=null，无应用错误或业务写请求。
