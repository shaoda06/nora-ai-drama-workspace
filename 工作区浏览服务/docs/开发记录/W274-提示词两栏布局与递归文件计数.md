# W274：提示词两栏布局与递归文件计数

日期：2026-10-22
版本：0.8.3

## 修改

- 编辑模式仅控制正文的预览和文本编辑，标题与所在分类不再随之禁用；保存和未保存保护沿用原逻辑。
- 移除中间提示词列表，桌面左侧目录栏由210px增至320px，宽屏350px。搜索结果和回收站列表在左栏展示，手机在目录与详情之间切换。
- 分类修改按钮移到每个目录行右侧，独立于目录展开按钮。目录名后显示括号文件数，按提示词的分类路径逐级累加到祖先目录；目录本身不计数，回收站不计入全库。主目录显示全库提示词总数。
- 原布局最低580px叠加main上下留白造成外层溢出。改为扣除公共页头、页脚后的窗口高度，再让正文填满面板剩余空间；正文和目录内部滚动，底部操作组不随正文滚出可视范围。
