# W278-项目顶部栏目按钮统一加宽

用户反馈顶部项目栏目按钮出现省略号，要求每个按钮加宽。原固定108px宽度与下拉控件的文字、箭头、间距和内边距共同挤压文字，手机原为100px。仅对header-controls直属tabs-grouped的按钮统一设置128px，保留高度、顺序、原自动换行及其他控件的宽度。

TypeScript／Vite构建通过。真实8782页面在1362×918、390×844核验：7个按钮实测宽度均为128px，下拉文字scrollWidth不超过clientWidth，相关资料及参考素材可展开，选择后的文字完整，整页无横向溢出、无页面错误或写请求。桌面保持一排，手机按原方式换行；截图desktop.png、mobile.png及results.json保存在下述临时目录。Browser plugin not available，使用既有Playwright运行时；临时验证资料保存在/private/tmp/nora-header-width-validation。
