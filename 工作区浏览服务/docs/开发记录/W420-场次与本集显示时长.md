# W420：场次与本集显示时长

日期：2026-10-27
状态：已完成
关联版本：v0.8.128（已发布）

## 修改原因

在场次按钮后显示场次时长，在制作对象标题行右侧显示本集总时长。实际视频时长优先，缺少实际时长的片段使用计划时长，含计划值的总计加星号。

## 具体改动

按当前所选轮次的片段组合逐段统计，同段的多个候选和多个画质不重复相加。不计上集末段。无轮次时按当前分段计划与默认视频统计；后处理使用最终产物，不统计过程产物。读取视频元数据，不播放、不改写媒体或项目文档。

实际值按视频文件 URL（含文件版本）缓存，切场不重复读取；先累计完整精度，再以0.1秒显示，分钟进位统一处理。尚未读出实际值时显示带星号的计划值。读取失败复用公共 FloatingMessage，保留重新读取入口，不在正文增加错误框。空场次标示“时长未记录”，不显示为0秒。

沿用 TabNav、Breadcrumbs 的公共操作区及 PointerTooltip；业务 CSS 仅排列标题行时长与原有下载按钮，没有覆盖公共组件外观。整页业务无新增独立展示控件，覆盖表注明真实业务测试入口。
