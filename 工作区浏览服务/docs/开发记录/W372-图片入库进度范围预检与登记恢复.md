# W372：图片入库进度范围预检与登记恢复

日期：2026-10-23
状态：已完成
关联版本：v0.8.64（已发布）

## 修改原因

图片已完成后才发现入库计划夹带其他阶段的进度更新，导致正式登记中断；异常通知又把正常成功时不重复登记写成了笼统禁令，Agent因此将内部修复问题交给用户。

## 具体改动

- 图片生成、超分、本地尺寸处理和Imagegen交接在准备阶段复用既有进度范围检查；实际登记继续保留原文及范围核对，不放宽保护。
- 正常成功通知与异常恢复分开说明。已有授权覆盖的登记修复由Agent使用既有入口完成，保留原成果、批准与用户修改，不重新生成或超分。
- 结果处理规范维护恢复边界，后台监控、Imagegen、工具说明和维护索引链接到同一规则。
