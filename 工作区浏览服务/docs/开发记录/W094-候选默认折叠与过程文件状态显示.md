# W094：候选默认折叠与过程文件状态显示

日期：2026-10-09
状态：原记录未单列，以正文为准
关联版本：原记录未单列，以正文为准

## 修改原因

- 范围：候选分组初始状态、过程文件列表和分类依据核对。

## 具体改动

候选图片类型分组默认全部折叠，打开某一类后仍收起其他类型，展开时才渲染图片卡片。

原过程文件列表通过通用解析器读取每份Markdown的“确认状态”；字段不存在时原先补成“未记录”并渲染灰色标签。现取消该占位标签，保留文件里实际填写的确认状态；资料卡和正式资产的审批状态读取不变。

### 分类依据

人物四类基础图由人物参考图制作与记录规范规定；人物参考图工作稿模板在每条生成记录的任务信息中保留“图片类型”字段，网页读取该字段分组，不根据文件名或图像猜测类别。

CH001的试装组来自生成记录001的“图片类型：单张试装图（用户指定的设计预览，非正式四类基础资产）”。该条保留用户指定的预览目标、尺寸、候选文件和限定采用范围，未作为正式四类图登记。当前模板可记录其他既定用途，但没有统一的额外图片类型命名规范；本轮核对不将自由填写的历史类型说成已有固定枚举，也不改写原生成事实。
