# W206 项目扫描复用与后台检查

- 版本：v0.6.69
- 日期：2026-10-16

首次读取仍完整核对项目文件快照及持久缓存，成功后记录检查时间，避免同一首次状态请求再次全扫描。概览、栏目、单集和候选缓存格式未变，不变更CACHE_SCHEMA。

扫描复用os.scandir目录项，普通目录继承已核验的父目录边界，减少反复构造Path与解析实际路径；Windows目录联接／重解析点仍核验实际目标，目录符号链接仍排除，文件符号链接仍核对目标在项目内。两种后台记录先匹配文件名再核对执行目录，保留仅按存在性扫描的原规则；其他文件的路径、修改时间与大小仍全部核对，新增／删除／改名、隐藏和综合资料排除规则保持。

已有核验数据时，状态接口只启动一次后台检查并返回现有状态；扫描在项目锁外执行，同一项目同时仅有一次扫描。没有变化不显示同步提示、不增加revision；有变化才接续既有refresh及缓存失效流程。扫描完成登记检查时间，长扫描结束不立即启动下一轮。扫描与解析错误共用原来的日志、原因、30秒重试与保留旧结果规则；目录持续不可读时普通检查不不断顺延已有重试期限，资料变化仍可提前重试。

状态接口新增checking。Project正常每5秒发起检查，仅checking期间每200毫秒读取结果，完成后恢复5秒；保留原后台3秒节流与重试到期优先规则。已有正文仍提示“读取新版本”，不会直接换掉阅读内容。没有页面请求时不持续扫描，不引入文件监听器或缩小扫描范围。
