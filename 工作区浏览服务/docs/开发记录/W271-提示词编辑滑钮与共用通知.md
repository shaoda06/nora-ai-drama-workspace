# W271：提示词编辑滑钮与共用通知

日期：2026-10-22
版本：0.8.1

## 修改

- “已保存”“已移入回收站”“已恢复”通过useNotify进入现有左下角通知区，使用原有倒计时、关闭和堆叠规则；移除页面顶部绿色提示条。错误和外部变更仍按原有位置显示。
- 分类选择继续复用MarkedTabSelect，在选中项右侧显示“当前”，使用轮次选择的既有badge样式，不修改其他菜单的选中规则。
- 删除提示词确认正文改为：确定将“标题”移入回收站吗？
- 两个编辑／预览按钮改为带switch语义的“编辑模式”滑钮。打开文件、新建和恢复后默认关闭，显示Markdown预览；打开后可修改标题、分类和正文。切换不自动保存，保存后保持当前模式。
- 预览请求复用已有接口与请求库，根据当前草稿正文生成；失败可重试或切回编辑，异步请求不会替换草稿。

## 验证

扩展 `tests/test_prompts_layout_ui.mjs`，接口响应与写入均在浏览器内模拟，不写入真实资料。覆盖：

- 原有目录切换不跳动、长预览内部滚动、桌面／窄屏同行标签与菜单尺寸。
- 默认预览、编辑滑钮、切换保留多行正文、预览失败重试、保存冲突保留草稿、新建草稿不自动落盘。
- 根目录及子目录选中项的“当前”标记、鼠标与键盘操作。
- 精确删除确认文案；保存、回收及恢复后的共用通知，弹窗关闭后仍正常显示并自动消失，顶部不再出现notice。

TypeScript、生产构建与3项发布检查通过。正式服务通过统一启动器重启，核对版本和ready；真实提示词仅进行打开、切换模式、查看菜单和取消删除等只读操作。
