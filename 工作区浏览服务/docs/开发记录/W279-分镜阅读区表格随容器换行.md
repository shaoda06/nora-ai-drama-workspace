# W279-分镜阅读区表格随容器换行

## 原因与最小修改

用户反馈右侧分镜脚本表格产生水平滚动，要求表格与区域等宽、单元格文字换行。按investigate方法先复现：1362×918页面中，表格继承.prose .table-scroll table的min-width:640px，而容器只有542px，实际scrollWidth为640px。临时覆盖验证为542px表格／542px容器，列宽按内容自动分配，无横向超出。

仅在.segment-script内将表格min-width改为0，单元格使用overflow-wrap:anywhere及white-space:normal。保留自动列宽、原文字、纵向滚动及其他文档表格规则，不隐藏溢出来掩盖内容。

## 验证

TypeScript／Vite构建通过。真实8782页面在1362×918及390×844核验，桌面表格与容器均为542px，手机均为246px；常规及宽屏模式中表格自身scrollWidth均等于容器宽度，7行数据保留，单元格自动换行，右侧正文无横向溢出。常规模式整页无横向溢出，页面错误0、写请求0。手机宽屏模式另观测到整页横向溢出，表格自身已适配，本次未调整该布局。Browser plugin not available，使用既有Playwright，临时诊断脚本及结果保存在/private/tmp/nora-script-table-validation。
