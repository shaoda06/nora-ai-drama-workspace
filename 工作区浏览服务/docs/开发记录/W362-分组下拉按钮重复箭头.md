# W362：分组下拉按钮重复箭头

日期：2026-10-23
状态：已完成
关联版本：v0.8.49（已发布核对）

## 修改原因

顶栏“相关资料”选中场景资料后出现两个下拉箭头。公共TabSelect已渲染SVG箭头，旧分组导航选中态又添加背景箭头，覆盖组件原本的background-image:none。

## 具体改动

TabSelect.css将background-image:none单独限定到真实button根节点，比旧分组导航的背景箭头规则优先；不新增页面覆盖、不用!important，不改变字号、内边距、居中及绿色选中态。组件继续仅显示原内置SVG箭头。ComponentShowcase补充单箭头规则，覆盖表同步说明，复用现有真实组件，不复制另一套菜单。

新增隔离页面及test_tab_select_arrow_ui.mjs，验证真实TabNav、TabSelect和ComponentShowcase，无真实项目API或任务操作。运行代码、回归与本记录单独提交；展示页说明和覆盖表已随同轮公共导航维护同步，不混入其他会话尚未完成的导演表改动。

## 验证结果

旧样式在选中“场景资料”后无法通过“无背景箭头”断言，实际仍有白色SVG背景图。修复后1362px、390px及320px检查通过：按钮各只有一个SVG、背景图为none，选中／未选中／禁用、鼠标选择、方向键／Home／Enter、Esc关闭、展示页各规格及水平边界均正常，无页面异常或API调用。
