# W354：各页面公共组件复用统一

日期：2026-10-23
状态：已完成
关联版本：v0.8.44，已在8782正式服务发布

## 修改原因

用户要求检查展示页以外的页面，统一公共组件的重复实现与页面私有样式覆盖，避免网站与展示页分别维护相同的样式和行为。

## 具体改动

- 提示词的分类、恢复、未保存确认及删除确认弹窗复用Dialog，取消本地弹窗实现；紧凑宽度与关闭禁用由公共组件负责。提交过程中，关闭按钮、Esc和遮罩均不能退出。
- 提示词Markdown预览复用Rich，删除私有标题、表格和代码块排版。提示词页标题在手机上沿用PageHeader布局。
- 提示词、资产、任务历史搜索统一SearchField，提供禁用及紧凑规格；筛选条件和延迟查询逻辑保留。
- TabSelect明确提供表单、紧凑、小号、工具栏及选中高亮规格，替换表单、队列和场次栏的私有样式。菜单选中项仍统一显示“当前”。TabNav接管项目顶部加宽、历史侧栏手机两列规格。
- 任务侧栏的节点、本地任务分类复用UnderlineTabs，支持紧凑、横向滚动、图标与公共悬停说明。节点切换、连接状态和计数由业务提供。普通UnderlineTabs统一支持换行。
- 资产图片预览复用Preview，文件下载复用FileActions。分镜修改意见导出改为DownloadButton接收本地文本，浏览器保存和公共结果提示共用同一流程。
- 展示页加入上述真实规格与状态；更新实现说明覆盖表和服务AGENTS规则，业务页面不得再复制公共交互或私自覆盖组件外观。页面容器位置、空间分配、真实保存与查询逻辑保持各自职责。

- 2026-10-23补充：将公共组件复用核对纳入每次提交前必查项；README提供具体步骤，开发记录规范和模板要求记录范围、结论、处理及验证依据。本次补充仅修改文档，不递增版本或重启服务。
