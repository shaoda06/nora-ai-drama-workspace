# W278：全站统一下拉菜单当前标记

日期：2026-10-22
版本：0.8.7

## 修改

- TabSelect收敛为同一个自定义菜单实现；删除原生select分支与badge配置，选中项右侧固定显示“当前”。保留无已选项的占位状态、禁用、纯图标和导航重新选择行为。
- 场次修改轮次仍最新在上，取消“当前方案”。提示词分类、快速制作对象不再重复拼接标记。
- 原生下拉接入共用组件：服装分类筛选／编辑、项目资料分类、大纲故事阶段、参考素材分类、风格资源库／分类、提示词搜索范围／上级分类／恢复分类、历史任务结果、转移任务。任务转移仍是选择目标后执行的动作，未选择目标时不伪造选中项。
- 顶部项目切换也接入，保留读取失败的公共提示及重试。项目列表提前读取并复用现有查询缓存，当前项目匹配路由。
- 菜单靠近底部时向上展开；长菜单内部滚动。Esc关闭下拉菜单后不继续关闭外层弹窗。空选项禁用，避免键盘选择不存在的项。去掉旧原生箭头在分组菜单上的重复显示。
