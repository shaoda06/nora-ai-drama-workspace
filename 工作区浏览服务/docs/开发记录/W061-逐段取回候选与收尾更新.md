# W061 逐段取回候选与收尾更新

日期：2026-10-07。

## 问题与结果

原运行中分段只留在执行附件，整轮结束才归候选；网页不会把执行附件当候选，因此已取回的视频仍不能在版本菜单出现。改为保持原远端保存事件、任务身份及download依据，下载成功先落各P执行附件，再立即移动为现有候选目录的固定文件名。整轮完成核对未变则复用，确认改写则保留旧文件并原子发布终态文件；同一R及候选编号不变。

## 规则与模板

逐集目录规范v1.38统一维护文件留存、收尾替换、当前采用与旧批准关系，以及工作稿状态字段。共同任务状态和最近检查时间仅在归属P/R条目维护；其他P明确链接该章节，各P单独维护取回核对状态。终态失败不抹去已知分段，不自动批准、重试或推进阶段。

导演台节点规范v1.18、H3执行规范v1.50、监控模板及分段视频工作稿模板同步引用／填写要求。运行中被改写的旧视频是专项历史留存，保留修改时间；普通候选替代仍按原规则流转。浏览入口规范v1.120同步解析字段及显示行为。六份规则与模板修改前已按维护规范留存本地历史备份。

## 后端与网页

project解析器为各视频读取取回核对状态、唯一共同任务状态与最近检查时间；缺旧字段保持未记录，不从输入映射或文件存在推定成功。文件修改时间和大小组成fileRevision并放入视频URL，仅作加载标记，不新增内容哈希、审批依据或版本台账。文件接口遇旧标记时按同一身份及专项历史文件名读取保留修改时间的旧文件，原播放器后续Range请求不会混入新字节；找不到对应旧版本明确404，不返回新文件冒充旧版本。

SegmentWorkspace展示本段核对及共同状态，失败／中断注明部分结果。SegmentVideo在同一候选文件更新时保留当前媒体和进度，提示“视频已有更新／加载新文件”；点击后加载新URL、重置分镜时间并接续原播放／暂停状态。提示位于画面上方，不遮住原生控制条。只刷新状态不重新加载文件。SceneWorkspace保留本场选择，初次无视频的分段在首个候选到达后自动选中；后续新候选不覆盖旧选择或手动留空。
