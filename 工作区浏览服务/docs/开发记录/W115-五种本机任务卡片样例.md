# 五种本机任务卡片样例

日期：2026-10-09

5179临时smoke服务新增task-types场景，默认节点依次展示图片生成、图片超分、视频一采、视频二采、视频后处理五张本机提交卡片。各类型也可通过type-image、type-image-upscale、type-video-first-pass、type-video-second-pass、type-video-postprocess单独查看。全部是进行中的模拟任务，节点名、进度、时间和分段数量用于样式预览；未向ComfyUI提交真实任务。

共用TaskCard详情采用“当前节点”和“当前节点进度”，移除仅适用于采样的步数单位。图片生成、图片超分和视频后处理样例只显示通用节点详情；一采、二采样例包含导演台消息，在进度条下同一行增加“当前分段：第N/M段”和“已取回：N/M段”。按实际存在的director_progress决定是否显示分段行，不按视频任务类型推断。非导演台卡片移除执行中的成果取回统计。外框、头部、标题、计时、双状态文字及默认折叠的“任务详情”保持共用。

用户纠正W114讨论中的本地队列定位：本地队列只显示本机尚未提交到远端的排队任务，不承担进行中、取回或已完成任务展示。非导演台任务在执行完成后才取回；导演台任务才需要在执行期间展示分段取回。本次只制作卡片样例，未接入本地待提交队列、远端全队列或已完成记录页面。

TypeScript检查、Vite预览构建、smoke脚本语法检查通过。在内嵌浏览器逐张展开五种卡片并截图，确认只有导演台样例显示分段取回；1920×1080桌面及390×844窄屏检查通过，五张卡片无横向溢出，控制台无警告或错误。回到task-types场景后确认五张详情全部默认折叠，保留预览服务和浏览器页供用户比较。未发布正式8782。
