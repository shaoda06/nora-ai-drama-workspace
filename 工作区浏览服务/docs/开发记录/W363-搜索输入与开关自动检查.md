# W363：搜索输入与开关自动检查

日期：2026-10-23
状态：已完成
关联版本：v0.8.50（已发布）

## 修改原因

补充第三组自动检查，覆盖公共搜索框、采用全局样式的原生文本输入框与多行输入框，以及公共开关的长文字、禁用、输入与切换，验证桌面和手机布局。

## 具体改动

- 既有暂存快照浏览器检查新增InputsFixture及check-shared-inputs。直接使用SearchField、Switch、原生input／textarea及全站CSS，不增加演示版输入组件，不调用业务API。
- 覆盖标准／紧凑搜索、中文及连续英文长占位与输入、受控状态同步、清空重输、多行回车、只读、禁用、重新启用和Tab跳过禁用控件。输入前后外框尺寸保持稳定；单行内容可在框内滚动，多行内容不横向撑宽。
- 覆盖长说明旁开关的关闭／开启状态、鼠标／空格／回车一次切换、aria-checked、外框及圆点边界；禁用后不触发回调，开关不隐式提交所在表单。
- 修复实际复现问题：桌面输入框250px最小宽度改为不超过容器，输入与多行文本统一受最大宽度限制；Switch禁止被flex布局压缩，避免长说明把38px开关挤至22px。
- 展示页增加可填入长文字的单行／多行输入、只读和禁用控制、长说明开关及长搜索入口，全部复用真实组件与全局样式。README、服务AGENTS和展示覆盖表同步当前范围。
