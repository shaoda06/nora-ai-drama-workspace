# W346：全站操作反馈统一公共消息

日期：2026-10-23
状态：已完成
关联版本：v0.8.33（已发布）

## 修改原因

用户要求检查其他页面，将遗漏的操作反馈与浮动提示统一接入公共消息组件，沿用按内容收窄、最多520像素及手机边距的公共样式。

## 具体改动

- CopyButton默认使用useNotify，覆盖风格库、文档代码块、分镜修改导出、修改意见及提示词复制；取消调用方可自行显示反馈的onMessage接口，只保留成功文字定制。失败保留手动复制文本区。
- DownloadButton将准备／接收进度接入FloatingMessage，完成或失败通过useNotify显示5秒，带资源说明。内置工作流保留同卡片两按钮互斥，移除按钮旁的独立消息及空列。
- 提示词读取、保存、预览、弹窗错误、分类缺失及外部修改提醒；资产操作错误；Krea更新错误；修改意见读取／保存错误和插入时间失败；节点配置保存／还原及错误；任务操作／历史／详情读取错误；媒体预览错误和视频更新／恢复失败，接入公共消息。
- 保留原重试、重新载入、加载新文件操作及草稿。提示词、资产及修改意见同一来源错误不再重复呈现。
- 加载占位、未保存状态、确认操作、正文资料说明、任务记录中的故障详情、连接状态、场次MessagePanel和视频准备数量仍就地显示。整体应用崩溃的错误边界保留独立渲染；已无调用的旧浮动样式不代表存在独立提示入口。
- 更新服务维护约定与组件说明，使新页面操作反馈默认复用公共组件。仅清理本次停用的复制、视频、节点及下载提示样式。
