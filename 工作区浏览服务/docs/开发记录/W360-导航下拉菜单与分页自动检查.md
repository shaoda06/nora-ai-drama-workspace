# W360：导航下拉菜单与分页自动检查

日期：2026-10-23
状态：已完成
关联版本：v0.8.48，正式页面已核对本次公共组件修复及新增演示

## 修改原因

扩充提交前自动检查，覆盖导航、下拉菜单、分页的长文字、禁用与切换布局；使用真实公共组件，在桌面及手机验证并修复确定的问题。

## 具体改动

- 在既有暂存快照浏览器检查中加入NavigationFixture和check-shared-navigation，复用TabNav、UnderlineTabs、TabSelect、Pagination；测试数据不调用正式API。
- 检查中文与连续英文长选项、普通／分组／竖排滚动／手机网格导航、普通／滚动页签；禁用选项及整体禁用、空／全禁用菜单；菜单方向键双向跳过禁用项、Home／End、Enter和Esc、当前标记及浮层边界。
- 分页检查首末页禁用、空／单页隐藏、9到10及8位到9位页码；比较按钮横向位置、宽度和高度。临时隔离测试外框切换长短内容，验证页面滚动条出现／消失不会横移，不修改组件样式。
- 修复实际复现的问题：TabSelect接收单项disabled，鼠标不可选、键盘跳过，全禁用菜单不能打开；普通导航长串允许换行，手机网格列可收缩，固定高度按钮省略；下划线页签统一字重，避免选中加粗挤动；分页使用等宽数字并按总页数预留当前页码位数，避免数字位数变化挤动按钮。专用滚动导航仍允许内部横向滚动。
- 公共组件展示页增加长页签、禁用下拉项、分组长选项及多位页码演示，直接调用真实组件。README、服务AGENTS和展示覆盖表同步当前自动检查范围。
