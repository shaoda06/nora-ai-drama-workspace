# W081 同步倒计时与固定错误提示

日期：2026-10-08。状态：主线实现及隔离验证完成，待正式发布。

## 用户要求与修改

将同步错误缩短为“资料更新失败，X秒后重试。”，逐秒更新秒数；通用读取错误使用固定中文模板，不直接显示接口原文。同时落实此前讨论的区分：读取过程中源文件被其他会话修改，使用普通提示，不当作真正的读取故障。

- 解析器沿用原内容一致性检查，只把对应异常明确为SourceChangedError；不取消检查、不混用新旧内容。后台标为source_changed并记录INFO，其他错误标为read_failed并保留ERROR调用栈。原error字段仍保留具体原因。
- ProjectStore保留原30秒重试与文件变化提前重试，增加毫秒时间戳retryAt供页面使用。重试期限仍由单调时钟判断，页面到点主动查询status；到期重试不受3秒扫描节流延迟。成功清除错误、分类与重试时间。
- SyncNotification使用后台重试时间逐秒显示，倒计时只在通知组件内部更新，不使整个项目页每秒重新渲染。真正同步错误为红色“资料更新失败，X秒后重试。”；并发修改为普通“资料正在更新，X秒后重试。”；请求尚未确认启动而计时已到时为“正在等待重试…”，后台确认开始后为“正在同步资料…”。成功或离开项目清除对应通知。
- Notifications保留单条替换，默认仍3秒关闭；倒计时可持续显示、手动关闭，同次轮询不重新弹出。调用返回的清理函数只关闭本条，不误关随后出现的其他消息。
- Result统一为“资料读取失败，请稍后再试。”，保留原Error对象用于诊断；场次分镜的同屏错误也改为固定中文。此次不改意见保存、视频缓存、复制或风格更新管理的各自状态区，不新增错误模板体系。
