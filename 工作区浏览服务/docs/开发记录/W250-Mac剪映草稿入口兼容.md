# W250 Mac剪映草稿入口兼容

2026-10-22，v0.6.130。

用户反馈网页下载的草稿在Mac剪映首页能显示名称和时长，但点击不能进入编辑。只读核对发现：Mac剪映11.6.0的本地登记指向`draft_info.json`，下载包只写`draft_content.json`和`draft_meta_info.json`；原Windows11.5验证未覆盖Mac入口。两份用户反馈的下载包JSON可解析、视频齐全、时间线引用有效，首页0.0B不能当作素材丢失依据。

## 副本实测

- 从原下载包创建独立验证副本，视频实际复制，分配新的草稿身份和测试名称；原ZIP、现有草稿、项目视频和制作历史不改。
- 仅新增与`draft_content.json`内容相同的`draft_info.json`，保留原平台标记、素材字段、固定目录占位符和素材库相对路径。未安装额外库、未复制原生草稿设备信息、未解密草稿。
- Mac剪映11.6.0正常进入编辑，素材库显示12段、时间线显示12段完整视频与波形。实际播放时画面变化、时间码前进且音频电平响应；没有素材丢失提示。未将电平响应扩大为完整音轨听审。
- 在副本中将第一段缩放从100%改为95%，保存退出并重开，选中该段仍显示95%，证明实际编辑已持久保存。剪映原生保存将本机入口改为非明文格式，未因此改写另一入口。
- 副本内12个视频逐一与原ZIP视频字节比较一致。原下载包及原草稿保持，不将测试缩放写回正式导出。

## 最小修复与边界

`jianying_draft.draft_files`只序列化一次时间线，在原Windows文件之外增加同内容的Mac入口，继续共用同一草稿ID、素材登记、同包视频与既有ZIP装配逻辑。本场、本集和各阶段下载一并生效，不按项目或生成阶段特判。

Windows入口的生成内容、时间线、原声、素材路径和视频字节不变。保留既有Windows11.5原生验证结论；本轮未重新进行Windows桌面实测，不声称所有剪映版本均兼容，也不把两份入口在跨平台编辑后自动同步作为功能。

新增回归覆盖本场和本集ZIP必须含两个内容逐字一致的时间线入口，同ID、完整时长和素材路径不变；修复前两条接口均因缺少Mac文件失败，修复后通过。既有视频范围、顺序、原字节和异常清理测试保留。

本轮只影响下载包的剪映兼容附件，不改变项目业务格式、批准流程、工作流或生成规范，无需修改创作模板和技能规则。测试资料按隔离验证规则保存，不在正式`projects/`建立测试项目。
