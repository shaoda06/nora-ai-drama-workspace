# W085-人物卡片对齐与音色试听

- 日期：2026-10-08。
- 范围：main源码维护和临时预览验证；未发布8782，未启动8783，未修改项目源资料或创作规则、模板。

## 修改内容

Assets共用列表将简介固定为两行高度，通过CSS行数截断显示省略号。标题单行省略，状态、正式图及候选数量、详情按钮分别对齐；待审核入口仍保留。

人物列表接口增加voice，只从该人物资料卡“说话声音参考音频（可选）”字段提取实际存在、位于07-参考音频/正式素材中的音频。没有关联或文件已缺失时返回null；不读取其他章节的历史链接，不猜测声音身份。关联多条时使用字段中首个可用正式音频。

人物名后增加小播放按钮，有关联时绿色，无关联时灰色禁用。Assets只使用一个audio，preload为none，点击后才加载；再次点击暂停，结束恢复图标，切换人物、进入详情和离开栏目停止原音频。播放失败使用既有通知组件。可试听只表示该音频能读取，不新增批准事实。
