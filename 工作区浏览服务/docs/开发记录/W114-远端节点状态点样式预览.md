# 远端节点状态点样式预览

日期：2026-10-09

远端节点标签前增加8px圆点，配置顺序中的默认节点使用绿色，备用节点使用红色。当前圆点仅用于预览样式，未接入后端到ComfyUI的常驻WebSocket或真实连接状态；提示文字明确为样式示意。删除远端队列标题右侧的进行中、已完成数量文字及对应统计，保留侧栏收起按钮上的原有数量。
