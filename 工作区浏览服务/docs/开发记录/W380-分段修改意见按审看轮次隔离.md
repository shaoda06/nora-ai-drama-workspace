# W380：分段修改意见按审看轮次隔离

日期：2026-10-24
状态：已完成
关联版本：v0.8.77（已发布）

## 修改原因

本轮导出用视频片单筛选分段意见，沿用旧视频会同时带入之前轮次的意见。用户要求分段意见按审看轮次保存，本轮仅包含本轮填写内容，旧意见保留在全部历史意见中。

## 具体改动

分段意见以审看轮次＋P段＋阶段＋R号分别保存，编辑器切轮后使用独立草稿，导出默认只读取所选轮次。历史范围显示各轮与未标注轮次的意见，保存、清空、导出编辑均保留原轮次。旧格式根据意见更新时间所在的已登记轮次及片单匹配归属，无法确定的记录保留为未标注轮次；读取不改写原文件，下次保存时固定已识别归属。兼容旧接口，并保留同源限制、并发读改写锁、批量保存冲突检查及原子替换。
