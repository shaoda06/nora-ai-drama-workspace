# W392：统一描边图标下载按钮

日期：2026-10-25
状态：已完成
关联版本：v0.8.98（已发布）

## 修改原因

下载入口混用绿色实心按钮、工作流专用大小和文字链接。用户选定描边图标方案，要求提取独立样式组件并统一使用。

## 具体改动

- 新增DownloadControl及独立样式：描边加16px下载图标，15px文字、7px圆角、7px／14px内边距；准备时显示旋转图标，禁用时淡化。
- DownloadButton和FileActions共同调用。FileActions仍用原生下载链接，保留查询参数并去掉章节片段；DownloadButton保留准备／接收文件、打包及公共消息逻辑，不改变大文件下载方式。
- 删除工作流、标题栏及场次下载样式中的按钮外观覆盖，页面只分配位置和换行空间；同步真实公共展示、实现说明与覆盖表。
- 将下载组件归属登记到现有复用检查，增加真实组件浏览器用例。纯网页展示调整，不修改短剧规则、模板或项目文件。
