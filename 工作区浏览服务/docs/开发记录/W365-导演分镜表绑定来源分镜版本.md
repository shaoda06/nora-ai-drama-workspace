# W365：导演分镜表绑定来源分镜版本

日期：2026-10-23
状态：已完成
关联版本：v0.8.52（已发布）

## 修改原因

导演分镜表应依附场次轮次对应的分镜版本；已采用是图片方案状态，不是独立的版本选项。现有独立正式／候选菜单无法表达来源关联。

## 具体改动

导演表沿用场次轮次选择器，按该轮的来源分镜版本筛选；同一分镜被多个轮次复用时共用同一套图，不新增轮次。候选按来源内编号显示，已采用／部分已采用标在具体候选上，默认采用方案，无采用时显示该来源最新候选。未制作或缺少来源登记时显示相应空态，不换用其他版本。

原场次工作稿增加来源分镜版本、图表版本和候选编号登记；后台从登记及既有页面采用清单读取关系，采用页使用对应正式图，候选与原执行凭据保留。解析缓存结构升至10，避免旧缓存漏掉来源信息。SceneWorkspace传递当前分镜版本；普通正式分镜对象也暴露自身版本以支持无轮次场景。

使用skill-creator更新导演表规范、固定模板及浏览输入依赖说明，现行规则旧版已按本地时间完整归档。EP001按既有事实登记v07下的候选1／2／3，候选2五页已采用；未改图片、剧本、分镜正文、视频、历史请求和实际轮次。
