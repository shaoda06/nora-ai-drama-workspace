# W273：切回页面恢复视频画面

日期：2026-10-22。

## 原因与范围

在8782当前内置浏览器复现P016 R002二采黑屏：readyState=4、视频尺寸1920×1088、媒体及控制台均无错误；点击播放后时钟推进，画面仍黑。现场两个帧观测API均未提供。切换分段再返回后同一文件正常显示。

W255依赖帧回调／帧计数检查播放中停帧，未覆盖无这两种接口的浏览器，也未在暂停后返回页面时恢复画面。本次只调整SegmentVideo及其回归测试，不修改视频、素材、候选身份或人工采用。

## 修改

- 监听visibilitychange、窗口blur／focus及pagehide／pageshow，在确实离开再返回时重建当前video，不依赖帧检测接口；首次focus／pageshow不触发，多路返回事件只处理一次。
- 恢复同一文件和当前播放位置，保留音量、静音、倍速与离开前的播放／暂停选择。浏览器后台自动暂停不覆盖用户原选择，正常切回不消耗停帧自动重试额度。
- 保留既有播放停帧、等待及媒体错误检查和两次恢复上限；卸载时清理返回监听、定时器及帧回调。

## 验证

新增无帧接口的暂停返回、visibilityState不变的blur／focus、页面返回和清理、连续多次返回的状态恢复、后台自动暂停五组回归。旧实现无法通过新增回归；新实现播放器12项通过，分段版本选择10项通过。发布检查3项、TypeScript及隔离生产构建通过。

本机未安装独立Playwright模块，test_scene_rounds_ui.mjs不能启动；实际内置浏览器验证使用已提供的CUA，不安装新依赖。已在当前内置浏览器的临时页面中，使用实际SegmentVideo组件和临时蓝色视频验证：显式禁用两种帧接口，暂停在2.4秒→模拟画面丢失并离开→返回后画面恢复且仍暂停在2.4秒；播放中同样恢复并继续推进，音量0.4、静音及1.5倍速保留。无媒体／应用错误。临时页面和打包文件均位于/tmp/nora-resume-browser-check，未读取或写入真实项目。正式服务更新待与并发发布协调后继续。
