# W426：侧栏外部关闭与队列操作反馈

日期：2026-10-27
状态：已完成
关联版本：v0.8.133（已发布）

## 修改原因

任务侧栏展开后点击外部不能关闭，本地拖拽排序滚动位置跳动；按钮操作缺少明确结果反馈。需要复用左下角公共消息组件显示操作结果，避免成功、失败或刷新失败无法区分。

## 具体改动

TaskSidebar在展开期间监听外部pointerdown关闭侧栏，侧栏自身、弹窗、已展开浮层及拖拽过程除外；隐藏侧栏不卸载或取消进行中的操作。NodeEditor草稿仍留在原组件。

已用真实拖拽复现滚动从850跳至728，根因是浏览器滚动锚定跟随移动／隐藏的卡片内容；队列滚动容器关闭overflow-anchor后保持像素位置，未新增手工滚动恢复定时器。手机测试另发现操作按钮组撑宽导致水平滚动，公共LocalQueueCard将操作组限制为容器宽度并换行。

处理进度与排序保护错误使用FloatingMessage；按钮操作、转移、排序的成功／失败使用useNotify。普通成功按公共规则3秒关闭，错误不自动关闭；立即提交只提示请求已接受，不冒充远端已开跑。接口已成功但回读失败时明确提示“操作已完成，但列表刷新失败”。连续排序保护错误只更新一条消息。原租约、释放及调度协议不变。

展示外层复用现有真实TaskSidebar，更新其规则与覆盖表，不新增第二套侧栏或真实任务演示。
