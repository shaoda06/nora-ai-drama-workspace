# W194 共用素材上传去重

日期：2026-10-15。版本：0.6.57。

## 问题与修复

后台此前逐条处理上传绑定，同一文件被多个分段引用时会重复传输。修复保留现有上传绑定接口，以当前准备任务、实际执行端、解析后的本地文件路径和目标上传目录为复用范围，不创建跨任务或跨服务的上传缓存。

准备开始时先核对已有凭据的执行端、成功状态和文件SHA-256，包括位于绑定列表后方的凭据。缺少凭据的槽位可复用同一文件的已完成上传；新上传成功后也可供本次其他槽位使用。每个槽位仍保存独立凭据，复用凭据增加reused_from，过程记录区分实际upload/success与upload/reused。

绑定使用远端真实返回的路径和文件名，导演台根时间线与编辑工作区一起更新；原始登记工作流不变。不同文件、目标目录或任务不合并，错误执行端、文件变化与上传失败仍停止处理。现有历史凭据保持原文，不为已经运行或完成的任务重传素材、重发生成请求或重写业务资料。
