# W066 修改意见清空与导出关闭确认

日期：2026-10-07。

## 调整结果

修改意见标题后增加链接样式的“清空”，使用无边框、无内边距的文字链接外观及下划线，保留按钮键盘操作语义。未读取或文本为空时禁用；清空只修改当前P／画质／R的文本，走现有自动保存流程，不清空其他身份的意见。

导出稿有自定义修改并请求关闭时，右上角的关闭按钮替换为继续编辑／放弃修改并关闭，后者使用红色警示样式。正文仍显示自定义修改不会保存的说明，不再重复按钮。继续编辑保留文本并恢复关闭按钮；放弃后关闭弹窗。关闭、Esc和点击外侧仍共用同一检查。未修改直接关闭。

Dialog增加可选headerActions，用于替换默认关闭控件；未传入的其他弹窗保持原行为。手机确认按钮组在标题下一行右对齐。
