# W069-ComfyUI后台任务与全局进度栏

## 功能与职责

统一提交入口完成原有选端、上传与generation_context保存后，将准备好的任务交给浏览服务；先建立同client_id的WebSocket，再复用comfyui_client.submit执行唯一POST。监听终态事件并通过status核实，用明确的输出节点／列表字段／索引调用download。SQLite保存运行与通知状态，终态与下载响应留在原执行附件；项目审批和正式记录继续由原会话维护。

FastAPI lifespan启动时接续原prompt ID，停止时结束监听，不取消远端任务。WebSocket断线重连，重新核对history/queue；正常静默连接每5分钟补查。二进制预览及其他prompt的消息忽略，不按采样步数认定全任务完成。

TaskSidebar在AppShell全局挂载，通过SSE接收完整状态快照，路由切换不重复创建连接。展开后桌面内容区让位，小屏覆盖；侧栏只含展开／收起交互，无提交、取消、重试等操作。公开快照不含桌面管道、调用上下文、工作流或本机凭证。

## 会话通知边界

Agent从真实Codex环境登记连接和获准的目标会话。后台使用已安装codex-app-tools的MCP适配器；只支持读取目标状态与发送固定任务通知，不覆盖模型或思考等级。目标忙时等待空闲，连接不可用时等待；发送前先记sending，成功后记sent，发送失败或发送中服务重启均保留delivery_unknown，不自动重发。

这是桌面内部接口适配，不能据单次成功保证未来版本兼容。没有可靠标准输出映射的原生导演台任务显式登记空数组，后台核实终态后通知原会话按专项规则取回。旧批次和定时器不自动迁移，也不将任务栏当作整个远端队列。

## 验证范围

测试使用临时项目和模拟远端，覆盖WebSocket先于POST、同client_id、大整数参数、提交超时不重提、服务重启接续、断线重连、外来事件隔离、成功取回、缺失输出、执行失败、会话忙等待、通知送达不明不重发，以及内部接口拒绝浏览器操作。现有通信和统一选端回归继续运行；页面另核对全局挂载、收起展开、SSE更新和只有查看操作。

真实远端生成、长时间离线、桌面升级及全部自定义节点不由模拟测试证明。正式发布版本为0.3.2，未自动接管正在运行的旧任务。页面验证发现全屏加载会隐藏整个root，已将有任务栏时的加载遮罩限制到内容区，保留加载期间的全局任务状态。

验证结果：浏览服务186项、统一提交入口30项及通信客户端18项测试通过；前端类型检查与正式构建通过，新增引用核对通过。清除继承的Codex环境后，后端使用登记上下文向用户指定的闲置会话发送测试，该会话仅回复“已收到”。正式8782和隔离模拟任务页面完成收起展开、跨路由、小屏、SSE步数变化、只读控件及加载遮罩检查，页面控制台未见相关错误。没有发起真实远端生成。
