# W247：单集路径快速选集

日期：2026-10-22；版本：0.6.127。

## 行为与实现

剧集制作的单集详情在路径“剧集制作”链接后显示小下拉三角。点击列出本项目已有的全部剧集，显示集号、题名及已记录的集名状态，当前集带标记；选择后直接进入该集首场并聚焦当前位置。原文字链接仍返回选集列表，列表页和其他栏目不显示三角。

Breadcrumbs提供独立选择器插槽，EpisodeProduction通过Portal复用当前剧集列表和已有打开操作，保持选集分页。TabSelect增加纯图标入口选项，沿用弹出层、键盘选择、Escape、外点关闭和长列表滚动。普通选择器保持原显示方式，不新增接口、请求或依赖。

使用React工程技能，将选项直接从现有列表派生；前端验证技能用于实际浏览器交互检查。纯页面交互调整，同步组件实现说明；不涉及业务字段、目录、模板或项目资料修改。
