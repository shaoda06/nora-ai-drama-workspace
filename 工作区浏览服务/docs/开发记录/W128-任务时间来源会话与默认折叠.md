# W128：任务时间、来源会话与默认折叠

2026-10-10，正式版本v0.5.1。

远端本机提交卡片的提交时间改为浏览器本机时区的`YYYY-MM-DD HH:mm`；等待和运行时长继续使用带小时、分钟、秒的时长。标题下显示“来源会话：会话标题”，格式与独立本地队列卡片一致。后台异步只读获取登记会话的真实标题，保存到任务公开状态，不阻塞生成监听、不发送会话消息。获取失败记录警告，网页明确显示会话名称暂不可用。

页面初次载入及刷新后默认折叠左侧任务栏，不再读取或写入旧的展开偏好；用户仍可手动展开。

运行开始时间优先保存ComfyUI `execution_start`的毫秒时间戳，旧版远端不提供时间戳时使用收到开始事件的时间。已保存时间不会被重连或重复开始消息覆盖。缺少开始时间时，从同一prompt ID的历史开始事件恢复；运行中历史为空时不推算，不用提交时间代替开始时间。

核对中的“荒院暴富 EP001 P003—P007 二采”任务后台`started_at`为空。远端`/queue`仅有提交时间，`/history/{prompt_id}`尚无结果；导演台运行目录日志是无时区的阶段日志，不能当作整项任务开始时间。本次提示改为“开始时间未记录”，悬停解释原因。该旧任务现阶段无法恢复准确时长，后续监听到的开始时间会持久保存。
