# 浏览服务开发与正式运行

- 本目录的网页和后端日常开发使用独立Git worktree的 `codex/browser-dev` 分支。开始修改前运行 `git worktree list --porcelain`，找到该分支的工作目录，并在该目录执行编辑、构建、测试和开发服务重启。
- 原工作区的 `main` 目录用于正式服务，端口8782。日常网页修改不在正式目录直接编辑代码、构建前端或重启服务。项目创作与制作资料仍在原工作区按既有规则维护，不迁入开发目录。
- 开发服务端口8783，资料目录由开发工作目录的 `runtime/service.json` 指向原工作区。该本机配置不入Git。开发页的意见保存／清空会直接写入正式项目资料；自动化写入测试使用临时目录或临时API响应，不把测试内容写入真实资料。
- 开发任务只提交本次浏览服务改动，不混入主目录其他会话的规则修改。改动按任务完整提交到开发分支，未经明确发布要求不自动合并或更新正式服务。
- 用户明确要求发布时，先核对两边工作区状态、测试与完整差异，再合并、构建并按约定更新正式服务；不覆盖无关未提交改动。启动／停止均使用目标目录的脚本，核对服务端口、代码目录和资料目录，避免操作另一套服务。
- 具体环境配置和开发／发布步骤见本目录README的“开发环境与正式环境”。
