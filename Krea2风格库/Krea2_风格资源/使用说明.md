# Krea2 本地风格库

## 打开方式

- **浏览与更新**：双击本工具目录的 `启动Krea2风格库.command`。需要 Python 3.9 或更新版本；服务仅监听本机 `127.0.0.1:8876`。保持启动窗口开启，按 Ctrl+C 停止。
- **离线浏览**：双击 `Krea2_风格浏览.html`。图片、搜索和提示词查看可用；更新操作需要上述本地服务。

HTML、资源目录、更新工具目录与启动文件集中于工作区 `Krea2风格库/`，应一起移动并保持相对位置不变。其他系统可在本工具目录运行 `python3 Krea2_更新工具/server.py`；加 `--no-browser` 可只启动服务，`--port` 可指定端口（默认8876）。

## 两个资源来源

- `krea2_styles/`：跟踪 [lumenastrum/clio-style-preview](https://github.com/lumenastrum/clio-style-preview)。当前 398 种，10 类，398 张图片。卡片按 1:1 展示。采用仓库 manifest 中的完整提示词模板，包含风格名称。
- `Krea2_moodboard/`：跟踪 [Ray3780 的 Civitai 发布页](https://civitai.com/models/2856809/ray-style-switching-extension)中的 Moodboard 带图 ZIP。当前 3549 种，37 类，3549 张图片。卡片按 2:3 展示。

初始资源从远程 ComfyUI 导出。2026-09-28 首次接入两路上游：Clio 提交 `82b8b79a`，Ray 文件 ID `3135400`（`3549_moodboard_styles_local v1.1.zip`）。当前共 3947 种风格、3947 张图片。后续数量以页面与 catalog.json 为准，版本以 versions.json 为准。

## 更新流程

1. 点击入口页的“资源更新”。两路来源可以独立操作。
2. “检查更新”只读取上游版本信息。Clio 比较 GitHub 提交，Ray 比较 Moodboard 带图资源文件 ID。Ray 展示的日期是发布页修改日期，不代表该 ZIP 的精确上传日期。
3. “下载并查看变化”将选中的上游包下载至临时目录，展示新增、提示词、图片、分类和移除项；此时不修改当前库。
4. “应用更新”保存该库上一版，替换资源并刷新页面索引。
5. “恢复上一版”只恢复对应资源库，不改变另一个库；恢复前的版本会成为新的上一版。


已有风格按英文名称匹配，保留中文名和目录名。新风格没有中文名时使用原名。上游重命名表现为删除旧项、新增新项。提示词及预览图来自对应上游包，不重新生成；ZIP 中缺失而本地已有的图片会保留，并列入缺图说明。

Ray 当前包未包含 `Ethereal Noir Motion — Spectral Smear` 的图片，保留先前从 Krea 原图地址取得的 PNG。此前缺图的 `Vibrant Chrome Cyber-Surrealism` 已从 Ray 的带图包补齐。

## 文件结构

每个单风格目录包含 `positive.txt`、`negative.txt`、`style.json` 和实际预览图片。`catalog.json` 是浏览索引；`catalog.js` 为离线页面提供同一份数据。`versions.json` 记录已应用的来源版本。

更新程序位于 `Krea2_更新工具/server.py`，仅依赖 Python 标准库。准备中的资源与每个库的上一版保存在该工具的 `work/` 下，不通过网页提供访问。不要在更新过程中关闭服务。

手工编辑 TXT 不会自动重建索引；上游更新会覆盖源资源中的本地修改。创作中改写的提示词请另存到对应项目。

## 使用与维护入口

工作区agent使用或维护本工具时，读取工作区 `.agents/skills/krea2-style-library/SKILL.md`。资源来源与许可边界见[第三方说明](../THIRD_PARTY_NOTICES.md)。资源随模板入库，更新仅由使用者手动触发；`Krea2_更新工具/work/` 和Python缓存不随仓库分发。
