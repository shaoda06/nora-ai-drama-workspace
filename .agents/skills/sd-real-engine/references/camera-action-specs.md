# 打斗镜头规格与空间铁律 (Camera & Action Specs) · ★权威总控

> 镜头是打斗的骨架。每个镜头必须把 5 维参数想清楚（设计检查表），落到镜行时只写三要素 + 动作 + 声音/台词。本文件提供空间可读性、景别取舍、动作机位候选和衔接方法。

---

## 一、 镜头规格五要素（设计检查表 · 每次镜必想）

$$\text{格式}：[\text{景别}] · [\text{拍摄视角}+\text{角度}] · [\text{运镜方式}] · [\text{跟随目标}]$$

| 要素 | 标准选项 | 正确写法示例 |
|---|---|---|
| ① 景别 | 特写 / 近景 / 中近景 / 中景 / 全景 | `近景` / `中景` |
| ② 拍摄视角 | 正面(0°) / 侧面(90°) / 斜角(30°-60°) / 俯拍 / 仰拍 | `45°斜侧` / `正面0°` / `30°仰视` |
| ③ 角度 | 平视 / 仰视(N°) / 俯视(N°) | `平视` / `30°仰视` |
| ④ 运镜方式 | 跟拍跟镜 / 急速推镜 / 急速拉镜 / 甩镜闪切 / 升降运镜 / 环移 / 固定镜头 | `急速推镜` / `跟拍跟镜` |
| ⑤ 跟随目标 | 角色、肢体或具体接触点 | `跟随右拳推进至心口接触点` |

> ⚠️ **镜行书写口径（落稿只写三要素）**：五要素是**设计检查表**；落到【时间轴分镜】镜行时只写 `[镜头N] 景别 · 视角角度 · 运镜。动作描述。声音：…。台词：…。`——不写"跟随@谁"（跟随目标作为运镜策略自然融进动作描述，如"镜头随其位移横移"），不用括号五要素连写的外部变体。

## 二、 空间与动作的可读性

镜头选择统一按[场次分镜选择流程](../../short-drama-storyboard/references/场次分镜制作规范.md#运镜构图与切镜的选择)执行；观察角度、景别、运动与焦点的含义读取[镜头语言指南](../../camera-language/references/镜头语言参考指南.md)。下列组合是候选方法，不设镜头配额、固定切换周期或角度禁区。

正侧面可以清楚展示轮廓、距离和接触，斜侧可以展示纵深与前后关系；按必要信息选择，不能仅凭“横版感”否定90°侧拍。大动作需要读清完整轨迹时扩大范围，小动作需要读清接触细节时收紧；仍要结合画幅、遮挡与前后镜，不能仅凭动作幅度指定景别。多人同时需要被辨认时保留相应清晰范围，不把人数转成必然糊脸的结论。

## 三、 双画幅构图（B 锁锁定后按此执行）

### 16:9 横屏
- 中长焦空间纵深与环境压迫；双人对立位三分线站位；攻防推进沿对角线动势；
- 腾空横飞/撞墙横飞/贴地滑行等横向轨迹优先展示；
- 重击用广角+低仰，横向轨迹横扫、左右对称构图（R1 只写真实受力反馈与环境破坏，不写气效）。

### 9:16 竖屏
- 垂直高度落差：腾空下劈、贴地滑行、跳起下砸、冲镜特写；
- 前后景叠压（前景遮挡制造压迫）；俯仰角对立位；
- 位移展示纵向优先（下劈/贴地/上冲）。

### 21:9 宽幕
- 横向展开最大化，双人长距离对冲/追逐戏优先；
- 参考 16:9 构图法则，强化左右端纵深。

> 上述画幅搭配是候选构图，不因画幅改写动作方向或强制俯仰。

> 画幅细则路由：使用上游 `short-drama-director/references/aspect-ratio-adaptation.md` 对应画幅章节（同款规则可复用）。

## 四、 景别与切点选择

按[镜头选择](../../short-drama-storyboard/references/场次分镜制作规范.md#运镜构图与切镜的选择)决定保留同镜或换镜。同景别、同机位可以连续使用；高潮前不强插特写，收尾不固定采用鸟瞰、过肩或遮挡转场。微观发力、完整攻防、环境结果可按当前剧情选择观看顺序，不必依次凑齐。

### Eye-Trace 视线流

切镜时可让视觉重点保持邻近位置或沿动势接续；需要突然转移注意时，也可有意改变落点。检查观众是否能及时找到本镜重点，不要求始终保持同一象限。

## 五、 动作与机位候选（先定观看任务，再选机位）

机位须让本镜必要的发力、接触、受力或反应可读；下表提供可比较的拍法，不把招式与某一种机位绑定。

| 动作语义 | 机位选择 | 可帮助呈现什么 |
|---|---|---|
| 贴地横扫 | 低机位贴地跟拍 | 看到腿/武器水平切过，高度差制造切割感 |
| 重拳砸地/砸墙 | 大仰角中景 | 体量压迫感拉满 |
| 侧闪/绕背 | FPV 第一人称跟随或过肩 | 代入感最强，看穿动作轨迹 |
| 升空/跳起 | 俯拍起跳 → 仰拍升空 | 先压后升，力学过程可见 |
| 摔投贯地 | 低机位全景侧拍（30-45°） | 完整看到被摔者弧线舒展 |
| 近身缠斗 | 肩后过肩镜头 | 看两人重心的撕扯 |
| 挑衅/神态 | 特写浅景深 | 表情或停顿的观看重点；可独立拍摄，也可与动作同镜 |
| 环境破坏 | 中景快速拉远 | 破坏结果整体呈现 |

## 六、 受击镜头工具箱（挨打方怎么拍）

> 受击不是"被打飞"三个字了事。按受击强度选用，让挨打方也有镜头语言：

- **短促径向震动**：命中瞬间镜头沿受力方向短促震一下（1~2 帧），模拟受力冲击传递到摄影机；
- **轻微轴向受力**：镜头随受击方向小幅偏转/倾斜，传递"摄影机也被波及"的重量感；
- **瞬时焦点变化**：受击瞬间焦点从攻方急切到受击方面部（痛苦细节），或随击飞目标快速转移；
- **动态模糊与速度匹配**：击飞/震退段加径向动态模糊，模糊方向与位移方向严格匹配，禁全屏均匀模糊；
- **Time Ramp 变速**：可强调接触、感知或节奏转折；按所需表演和实际制作能力安排持续时间，不设通用秒数上限或整段慢镜禁令。

## 七、 三手法六式镜头衔接（多镜剪辑阶段）

### 三手法
1. **换机位**：改变拍摄角度与视角，保持主体动作连续；
2. **切景别**：特写切中景，中景切全景，由微观入宏观；
3. **跨段反应**：攻击击出瞬间切受击方防御或受创表情。

### 六式
- ① 动作连续切（挥招前半段切命中后半段）；
- ② 反应镜头切（攻方重击切守方瞳孔骤缩/咬牙/咳血）；
- ③ 景别跳切（长距离突进由全景跳入近景）；
- ④ 视线引导切（主角转头看向右侧，顺视线切右侧出现的威胁）；
- ⑤ 遮挡过渡切（前景立柱/人影掠过遮挡瞬间完成场景切换）；
- ⑥ 动势匹配切（上一镜向右翻滚，下一镜向右滑步冲拳）。

## 八、 镜头与生成段的接续

先按分镜确定实际切点，再由[视频分段规划](../../short-drama-storyboard/references/视频分段规划规范.md)及[提示词转写](../../nora-video-prompts/SKILL.md)落实当前模型的输入和接续要求。不把所有模型概括为不支持硬切，也不为适配生成段强制改成长镜头或连续运镜。选用一镜到底时写清连续观察路径；固定机位长镜同样成立，动作与镜头运动分别说明。
