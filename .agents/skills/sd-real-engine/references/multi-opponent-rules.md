# 小规模多点战斗调度 (Multi-Opponent Choreography) · ★多人战斗唯一真源

> 本文件是 **小规模多点战斗（小规模多人）的唯一真源**：1v2 / 1v3 / 2v2 / 3v3。
> 凡任务中出现「两人以上同场交手」，本文件的规则**覆盖** `r1-combat-core.md` / `camera-action-specs.md` / `render-adapters.md` 中的 1v1 默认写法（轴线锁定、开局构图、站位声明、景别策略）。
> 镜头选择沿用[场次分镜制作规范](../../short-drama-storyboard/references/场次分镜制作规范.md)，本节补充多人关系的可读性。本文件未写到的部分，回到 `r1-combat-core.md`。

---

## 一、 适用边界

适用于 1v2、1v3、2v2、3v3 等小规模多人场面。是否拆组由空间复杂度、必要动作和实际制作能力决定，不按人数自动规定镜数或限制每镜只能三人交手。多人同焦是否可靠须按当前模型、素材和实测结果判断，不能预设四人必糊脸。

## 二、 逐镜明确观看重点

先定本镜要跟随谁、看清哪组关系。以主角为锚点可帮助连续追踪，但配角交锋、旁观反应和群像也能独立成镜；不要求主角每镜在场，不按平均分配镜数判错。

**围攻近身交锋的默认组织**：先突出当前直接攻防的一组人物，让其他对手通过纵深、侧位、封路、逼近或绕位保持可辨认的威胁；新攻击进入时再转移重点。以此减少多条动作同时争抢注意，但不是一次只能两人交手。剧情要求协同夹击或群像时，可让多人同时清晰，前提是攻击路径、应对和后果读得清。

景深、遮挡和人物分层可突出重点，也可让多人同时清晰。所选人物应能辨认，必要动作与反应不被遮住；不设焦平面人数上限。

## 三、 多轴管理

根据当前交锋建立人物相对位置、视线和攻击方向。当前对手更换、人物转向或新威胁介入都可能改变关注关系；这些是常见情境，不是合法切换的穷尽清单。

切镜、镜内移动或越轴时给观众足够的空间依据。轴线是帮助理解关系的工具，不要求全场固定画左画右；直接切到新威胁也可成立，不强制先让主角转头。

## 四、 多人行动与轮转

逐人交代当前在做什么：压上、被击退、绕位、封路、等待机会或观察。三拍轮转可用于逐个突破，也可同时交手；不规定每秒必须移动或一次只能接触一人。

若角色本应行动却像等待轮次的陪练，应修正对应动机和调度；静止本身不是错误。例如主角以甲为屏障阻住乙时，乙可暂时停步寻找入口，而非为避免“站等”强行位移。

## 五、 节拍弧与破围节奏

已确认剧情是陷入包围后突围时，可优先组织“接敌 → 多向受压 → 找到破围点 → 利用缺口 → 脱离或收势”。破围点应落在造成局势改变的动作上，不固定到某个秒段，也不强制改写为逐个击败全部对手。

若前一个对手失衡打开了通路，后续处理可更紧凑，让连续追击或迅速脱离体现机会正在流失；遇到更强阻挡、体力下降或救人等任务时，也可放慢。同样长的交锋是否需要调整，看局势是否重复而没有推进，不凭时长相同判错。敌人停步、后退或转头看同伴须有受阻、畏惧或战术原因，不能把这些反应预设成每场结尾。

## 六、 群像镜头选择

围攻关系首次形成、主要攻击方向改变或破围路线出现时，优先让观众辨清来敌方向、出口与当前遮挡；可用全景，也可在现有镜头中通过调度、摇移或连续动作交代。先判断本镜需要整体关系还是局部细节，再选景别与机位。人数增加不意味着镜头必须收紧；全景、正侧面、斜角、越肩和多人近景按信息可读性选择。

主角看向新威胁后，可以切到威胁，也可以通过现有构图、摇镜、焦点转换或画外声音呈现；若暂时隐瞒威胁有叙事作用，也可延迟揭示。不规定“看向哪里，下一镜就必须切哪里”。

## 七、 防「分身 / 复制人」（多人专属）

多人场景触发分身 / 复制人的概率远高于单挑——**三个穿同款黑西装的人，最容易被渲染成同一个人被复制三次**。

**强制差异化锚点**：每人至少 **2 项不同**，写进【核心人物】段：

> 体型（高 / 矮 / 壮 / 瘦）· 发型（长 / 短 / 束 / 秃）· 服装（颜色 / 层次 / 配件）· 兵器（长短 / 形制 / 持法）· 站位习惯（左撇 / 沉步 / 前倾）

**服饰统一时**（如黑衣保安队）**必须用配件 / 兵器 / 体型做区分**：
`✅ 一人持短棍、一人持长棍、一人赤手；左侧者体型偏壮、右侧者偏瘦高。`

**负面词叠加**（在 `render-adapters.md` §六 默认三区基础上追加）：
`同一人物重复出现、服装互换、多手多脚、人物融合、同脸复制`

## 八、 站位声明（多人版格式）

`render-adapters.md` §三 的「一行式」是 **1v1 格式**；多人改为 **三行制**：

```text
【站位声明】
主轴：@CHR-A（画面左·背靠墙面锚点·侧身45°朝右）↔ @CHR-B（画面右·朝左），当前轴线关系保持可追踪；
从轴：@CHR-C 位于 B 外侧（画面右后），@CHR-D 位于 A 外侧（画面左后）；
全员动态：A 锚点→中央对决区（抢攻）；B 右位→中央（迎击）；C 右后→切入中央（压上）；
         D 左后→退至门边（被击退，武器脱手）
```

- **三条线缺一不可**：主轴行（交代方位关系）+ 从轴行（其余人相对侧位）+ 全员动态行（逐人 `起点→终点` + **动作原因**）；
- **禁瞬移**（沿用 1v1 口径）：每一步位移必须有攻击 / 闪避 / 击退的因果；
- **禁画图**（沿用 1v1 口径）：禁俯视 ASCII 空间图 / 坐标表。

## 九、 时长、镜数与拆组

镜数按观看任务和剪辑作用选择，时长按动作、表演及模型分段要求分配，不按人数分配固定镜数或强制两组。需要交代的攻击、防守和后果可同镜完成；不要求每个对手单独获得受力镜，也不为记人数增加本来没有的命中。

拆组时核对动作、站位和状态承接，不能为了截帧把剧情切碎或改变对抗结果。

## 十、 出稿自检

检查必要人物与动作是否可辨、空间是否可追踪、切点是否服务当前叙事；逐人核对当前威胁、受阻原因及下一次介入，确认主攻换人时人物位置与注意力都有承接。人物区分沿用已确认资产，不新增无依据的外形。固定镜头、主角不在场、多人同焦或相同镜数都不自动判错。

角色等待、观察、犹豫可以是剧情动作；只有本应介入却无缘由停止行动时，才修正动作或调度。必要受力结果须符合原剧情，不要求每个对手都挨打。

## 十一、 对照示例

不成立的写法：三名对手被要求同时进攻，但两个始终无缘由停在旁边，观众看不到人数压力。修正应补清实际配合与限制，而不是每秒强行换机位。

可成立的写法：固定全景中甲正面施压、乙封住出口、丙观察主角持械手；主角推甲挡住乙，借空隙脱离。若观看重点转到丙发现破绽，可独立切丙近景，不必强留主角入画。
