# 防守三态与闪避大幅化 (Defense 3-States & Evasion) · ★权威总控

> 打斗的"好看"一半在挨打方。防守方被破防后必须经历真实的失衡过渡过程，**严禁被重击后下一帧立刻原地满血架防**。承担关键避险、换位或破围任务时，优先考虑方向清楚、足以读出的闪避幅度；局部卸力和细小避让按下方取景条件判断，不把“大幅”当作每次防守的配额。

---

## 一、 防守三态溃败链条

```text
┌──────────────────┐       ┌──────────────────┐       ┌──────────────────┐
│  1. 完整态 (Full) │ ───>  │ 2. 崩防线 (Break) │ ───>  │ 3. 过渡态 (Mess)  │
│ 桩步稳固,架桥封门 │       │ 招式被破,双臂弹开 │       │ 狼狈侧闪,零碎抵抗 │
└──────────────────┘       └──────────────────┘       └──────────────────┘
```

### 1. 完整态 (Full Defense)
桩步稳固，双臂架桥护头护胸，姿态从容。防守有效时可以持续；受攻仍须有相应承压、卸力或观察，不能因固定秒数强制破防。当前模型能否保持姿态需实际验证。

### 2. 崩防线 (Break Line)
剧情确认防线被突破时，按打击方向呈现失守；例如重拳直接震散格挡：双臂向两侧弹开，中线与要害彻底大开。
- 写法：`重拳砸在格挡双臂上，双臂被震得向两侧弹开，中路门户大开`。

### 3. 过渡态 (Messy Transition)
来不及重新架防，只能靠狼狈本能零碎抗争：
- 狼狈极低下潜 / 铁板桥大后仰弯腰 / 单臂仓促向外乱拍 / 碎步踉跄后撤。

写防守溃败时，保留“有效防守 → 实际失守 → 恢复前的应对”因果；不必各拆一镜，具体时长按实际动作。稳稳承住或主动卸开攻击不属于破防，不能强制套用溃败链。

## 二、 闪避大幅化法则

**默认建议与适用条件**：远一些的画框、高速攻击或需要清楚交代脱离攻击线时，优先采用方向明确、幅度足够的潜身、后仰或侧步，并留下原攻击落空的空间依据。近景已能读清拳路与头肩关系时，小幅避让可以成立；格挡卸力也不必每击大步后退。幅度不足以避开攻击或在当前取景中看不出关键避险时，才调整动作或机位。

以下为需要大幅避险／换位时的候选，按角色能力与现场空间选择：

| 闪避方式 | 写法要点 | 视觉特征 |
|---|---|---|
| **极低位下潜** | 身形骤降贴地 | 重拳擦着头皮削过，削断发丝/帽檐 |
| **铁板桥大后仰** | 腰身向后折叠 ≥45° | 腿风自面门上方两指处呼啸而过 |
| **侧空翻/360°旋转跳开** | 闪避即位移 | 闪避+换位一步完成，落地即蓄力 |
| **大步滑移/滑步** | 大幅横向/斜向位移 | 重心低、幅度大，瞬间拉开距离 |
| **贴地滑铲** | 下盘突破/避险 | 从腿间滑过或滑至侧后 |

**闪避后的接续**：持续追击中，优先让闪避落地承接下一招的支撑或脱离路径；若角色已经脱离危险、受创恢复或重新判断，可合理停留。节奏与轻重统一按[力度与节奏参考](../../sd-combat-engine/references/combat-intensity-guardrails.md)处理，不为接续而强加反击。

## 三、 防守方零碎抵抗写法（过渡态弹药库）

- 单臂仓促拍开：`守方单臂斜拍，勉强改变拳路方向，拳锋擦耳而过`；
- 缩身下潜：`守方缩身下潜，攻方重拳自头顶呼啸而过`；
- 碎步后撤：`守方碎步连连后撤，脚下踉跄，险些绊倒`；
- 本能格挡：`守方双臂胡乱格挡，每挡一下都被震退半步`。

## 四、 防守三态 + 闪避大幅化组合示例（直接可投喂）

```text
00:04-00:07 [镜头2] 中近景 · 45°斜拍平视 · 跟拍跟镜。攻方右直拳砸向守方面门，
守方双臂架桥格挡被震得双臂弹开（崩防线），随即本能下潜闪避，攻方左摆拳擦着头皮削过
（过渡态·大幅闪避），守方顺势贴着地面一个滑步绕到攻方侧后，起身已是反击架势。
声音：拳风破空+布帛摩擦。台词：无。
```

## 五、 与机位联动

- 大幅闪避（下潜/空翻/滑铲）→ 按 `camera-action-specs.md` 机位-动作语义绑定表配 低机位贴地跟拍 或 过肩 FPV 跟随；
- 崩防线细节（双臂弹开/门户大开）→ 近景/特写放大；
- 三态演进的节奏 = 快（破防）→ 中（闪避）→ 蓄（起身反击），配合快慢呼吸。
