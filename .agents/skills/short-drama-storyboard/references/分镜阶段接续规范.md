# 分镜阶段接续规范

### 4. 整理场次分镜并划分视频生成分段

共用片头片尾先读取[内容稿接续规则](../../nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#全剧共用片头与片尾)，以实际内容稿代替故事剧本作为上游依据；场次拆分及本阶段其余规则、模板与正集相同。用户明确要求先形成待审分镜时，标明来源和待确认范围，不冒称来源已批准。

设计和送审按[对白、反应与多人镜头的取舍](场次分镜制作规范.md#对白反应与多人镜头的取舍)选择出镜人物，按[可见内容与画外连续性](场次分镜制作规范.md#镜头可见内容与画外连续性)区分镜头画面、声音及分段接续记录；将[统一方向参照](../../camera-language/references/镜头语言参考指南.md#13-统一方向参照)落实到机位、身体／头部朝向、移动路径及环境落点。检查与订正沿用既有送审流程，不新增审批或状态台账。

新写或实质性修订场次的镜头设计、切镜、对白覆盖或站位接续前，由本技能按[分镜方法补充](场次分镜制作规范.md#分镜方法补充)选择所需参考，将结果落实到场次分镜的既有逐镜字段与P段规划。同轮按[山音方法的范围与适配](../../nora-ai-short-drama/references/共用规则/山音方法适配规范.md#山音方法的范围与适配)自动读取 `screenwriting-master` 的分镜方法，将结果合并落实到当前镜头设计；仅改错字、格式或记录时不因本步骤加载上述技能，分镜完成后接续[文本交付前自检](../../short-drama-review/references/文本自检与订正规范.md#文本交付前的自检与订正)。

编写或实质性修订场次分镜时，按[运镜、构图与切镜的选择](场次分镜制作规范.md#运镜构图与切镜的选择)执行表达任务、取景可读性、观看效果取舍与整场复核，在选择过程中取用该节所链镜头指南，再把选定设计写入既有字段。分段时按[段内表达及段间接续](../../nora-video-prompts/references/视频提示词制作规范.md#h3切镜与接续表达)核对动作和声音的真实边界，实际开关仍在执行资料维护，不用生成段替代镜头设计。具体填写和修订边界分别见下方场次分镜与视频分段规则。

本步骤先按[职责分工](../../nora-ai-short-drama/references/共用规则/创作职责与接续规范.md#剧本分镜与提示词的职责分工)及[润色后的批准与分镜接续](../../short-drama-write/references/台词润色交接与回稿规范.md#回稿检查批准与分镜接续)核对来源版本与内容边界，再依据整集故事剧本的各场次形成场次分镜，读取[场次分镜制作规范](场次分镜制作规范.md#3-场次分镜脚本)并填写[场次分镜模板](../../nora-ai-short-drama/references/模板/场次分镜模板.md)的场头与逐镜正文；场景采用字段在视频资料包提交前按[场景采用规则](../../nora-drama-assets/references/场景资料与参考图规范.md#43-场次采用记录与提示词边界)补齐实际方案。每场镜头正文及分段规划完成后、送审前，先按[剧本到分镜的覆盖核对](场次分镜制作规范.md#剧本到分镜的覆盖核对)检查转写，再按[镜头状态的变化、延续与参考差异](场次分镜制作规范.md#镜头状态的变化延续与参考差异)从头到尾复查整场，问题处理落实到正文和分段状态。

场次及整集分镜送审前，按[场次与跨集转场接续](场次分镜制作规范.md#场次与剧集之间的转场和接续)连读场次边界、上集结尾与本集开头，落实必要过渡及相关正文、时长和素材同步。

在同一场次分镜中按[视频分段规划规范](视频分段规划规范.md#4-场次内视频分段与本集索引)填写视频分段及段内时间表，直接为后续视频提示词提供依据；正文维护与返修归属执行该规范，不另抄一份分段镜头正文。

分镜设计时同时执行[参考输入规划与分段可执行性](视频分段规划规范.md#参考输入规划与分段可执行性)，在各P段中落实公共／本组参考需求、容量结论及超限处理；后续素材准备与提交按该规划接续，不能只按时长划段、将输入超限留到上传时处理。

本集分镜索引的内容与核对要求执行[视频分段规划规范](视频分段规划规范.md#4-场次内视频分段与本集索引)，保存位置执行[逐集目录规范第2节](../../nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#2-正式文件与目录)，旧文件接续执行该目录规范第6节。

场次分镜成形后，按[手绘导演分镜表规范](手绘导演分镜表规范.md#1-用途与询问时机)在原分镜讨论或送审中询问用户是否需要辅助图文表，沿用已明确的范围选择；需要时以当前版分镜制作并一起讨论。反馈回写剧本或场次分镜的归属、分页与交付按该规范执行，不另设必做审批，不要求现有项目补做。
