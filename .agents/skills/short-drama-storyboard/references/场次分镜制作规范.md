# 场次分镜制作规范

## 3. 场次分镜脚本

接续已选参考图片时，先执行[已选原图的接续](../../nora-ai-short-drama/references/共用规则/创作职责与接续规范.md#已选原图的接续)，核对实际素材入口及本阶段采用范围；后续素材映射引用该入口和具体版本，不以大纲中的图片名称或网址代替本地文件。

全剧共用片头片尾的上游内容依据及无实景字段填写，见[共用制作规则](../../nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#全剧共用片头与片尾)；场次拆分、分镜和分段继续执行本规范。

开始编写或修订时，先按[职责分工](../../nora-ai-short-drama/references/共用规则/创作职责与接续规范.md#剧本分镜与提示词的职责分工)核对本场剧本依据及内容范围，再按本节落实镜头设计。

分镜引用项目资产或视图时，按[引用链接规则](../../nora-ai-short-drama/references/流程规范/项目浏览入口规范.md#5-输入格式与解析依赖)在引用处写清名称、编号及对应文件／章节链接；视图编号与版本号分开表达。镜头的机位、方向和布局须用具体空间关系写清，不能只写“沿V008方向”等内部简称。后续转写提示词按[项目引用与模型标签](../../nora-video-prompts/references/视频提示词制作规范.md#项目引用与模型标签)处理；分镜阶段不预设尚未确定的模型输入序号。

分镜的画面描述按[统一方向参照](../../creative-techniques/references/镜头语言参考指南.md#13-统一方向参照)使用当前镜头的画面坐标；机位变化时按场景真实关系重新换算，按下方[镜头字段分工](#景别选项与镜头字段分工)落实到机位/构图、运镜、起止画面及情绪/动作字段。

编写或修订本节分镜时，调用[镜头语言与表达](../../creative-techniques/SKILL.md#镜头表达)辅助选择拍法，参考[镜头语言参考指南](../../creative-techniques/references/镜头语言参考指南.md)的构图与景别、观察角度、运动、光影及焦点相关内容。围绕本镜需要看清的信息和人物关系，按下方[景别选项与镜头字段分工](#景别选项与镜头字段分工)填写；逐镜边界同时按[逐镜起止画面与转场方式](#逐镜起止画面与转场方式)落实。不另加模板外字段，不要求每镜填满技巧，不因镜头设计改变资产设定。

### 景别选项与镜头字段分工

本节在场次分镜初稿、修订及送审自检时执行；固定字段及顺序以[场次分镜模板](../../nora-ai-short-drama/references/模板/场次分镜模板.md)为准。景别统一使用：**远景、全景、中全景、中景、中近景、近景、特写、大特写**。取景含义参考[构图与景别](../../creative-techniques/references/镜头语言参考指南.md#3-构图与景别)，具体裁切及可见范围在“机位/构图”中说明，不能只凭术语推断关键肢体或物件已经入画。

“景别”通常只填一个名称；同一连续镜头确有取景变化时，按发生顺序写“全景→中景”等，过程与成因写入“运镜”或“情绪/动作”。实际切镜分别使用镜号，不能用箭头将多个切镜并成一镜。平视、俯拍、斜侧、过肩、双人同框、主观视点和牛仔景等角度、构图或裁切说明写入“机位/构图”，不作为额外景别选项，也不写进景别后的长段解释。

| 字段 | 应填写的内容与边界 |
| --- | --- |
| 景别 | 标准景别名称或同镜连续变化；不承载人物站位、动作过程及物件状态。 |
| 机位/构图 | 摄影机的观察位置、高度、角度与轴线侧别，取景对象及裁切范围，主体画面位置、纵深关系、清晰区域、必要入画和遮挡边界。写明关键脸部、肢体、接触或物件怎样看得见；不把动态表演全过程塞入此栏。 |
| 运镜 | 固定镜头，或摄影机运动／变焦／焦点转移的起止、方向、必要幅度与速度及新揭示内容；固定机位与变焦分别说明。人物自己的行走、转身不当作摄影机运动。 |
| 起始画面、结束画面 | 各自时点的可见瞬间：人物位置、姿态、表情、双手与持物、物件数量／落点、环境状态和动作进度。两端分别落实本镜有作用的真实状态，不能只在构图里提过物件就省略其状态接续。 |
| 情绪/动作 | 两端之间的表演、动作路线、接触与受力、触发对象、先后或并行、状态变化及反应；说话与倾听中的持续姿态、手部状态及变化按[身体表演](../../short-drama-write/references/对白与表演修订规范.md#说话与倾听时的身体表演)填写，不能只写变化而漏掉持续范围，也不能用景别或运镜代替人物行为。 |
| 转场方式 | 切向哪一镜、切换方法及动作／视线／声音的具体接续点；不与运镜混写。 |

同栏分别交代机位与构图：先写摄影机的观察位置、高度和角度，再写主体及环境的画面位置、裁切和必要可见范围；按本镜需要填写，不机械罗列全部项目。

台词、音效及时间／时长按其既有规则填写。机位/构图说明空间与取景，起止画面说明具体时点；同一必要关系可在起止状态中简短落实，但不逐栏复制整段说明。光影、色调及效果按其作用分别落入构图、起止画面或变化过程，不因此新增镜头字段。

送审前逐镜核对：景别与实际裁切是否一致，构图是否容纳必要主体、肢体及动作，运动后的构图与结束画面是否一致，动作和物件状态是否仍有明确起点、变化和结果。取景人数、局部入画和画外事实边界按[出镜选择](#对白反应与多人镜头的取舍)及[可见内容分工](#镜头可见内容与画外连续性)核对；位置、身体／头部朝向、路径与环境落点按[统一方向参照](../../creative-techniques/references/镜头语言参考指南.md#13-统一方向参照)核对，并对照台词发声与实际可见口型，发现背向与正面口型、张嘴反应与闭口要求等冲突时先订正。缩短景别字段时只调整信息归属，不删掉空间参照、肢体归属、关键可见范围、参考差异或因果时序。后续提示词转写须合并读取上述相关字段，将必要取景、机位、运动与状态落实到官方既有镜头描述，不新增同名模型字段，也不只读取景别一项。

### 分镜正文的清楚表达

分镜的机位、运镜、起止画面、动作、音效和转场说明都须用可直接理解的完整表述。填写术语和方向不能代替把话说清楚；读者无需猜测省略的人物、动作、对象或参照，即可理解当前画面。

- **动作与方向分清**：写清谁在什么位置、做什么、朝向或看向哪里。身体朝向、转头和眼睛注视分别按实际需要表达；画面左右／前后以当前镜头为参照，并落实到已明确的门、菜畦或对手等目标。不把部位、动词和空间词压成需要读者还原的短语。
- **所指明确、用词准确**：多人段落中的代词、手臂、持物和反应须能唯一对应人物；不能确定时直接使用姓名和具体部位。专业词只在含义准确且有作用时保留，不用简称、名词堆叠或抽象口令代替可见动作。
- **连读各字段及前后镜**：正文完成后按播放顺序读顺每句，并将起始画面、动作、运镜、结束画面、台词和音效连起来核对。已经蹲下或站定的起点，不得在其他字段无依据地再次下蹲或迈步；结束字段说明切走时的状态，不混入需要重新执行的动作。发现矛盾须回查来源，不以润色补造剧情。
- **方法落实到订正**：发现拗口、歧义或需要猜的句子，或用户明确要求表达复查时，按[表达润色适配](../../short-drama-write/references/对白与表演修订规范.md#编剧补充与表达润色)使用 `humanizer-zh` 处理相关分镜说明；再按[文本审查方法](../../short-drama-review/references/文本审查与返修规范.md#文本审查的方法补充)复核方向、视线、动作及状态含义。完整稿首次送审或完整重做检查全部正文；局部修订检查受影响句子及必要接续，范围沿用[文本自检与订正](../../short-drama-review/references/文本自检与订正规范.md#文本交付前的自检与订正)。检查与订正并入既有工作稿，不以读取技能、字段齐全或格式通过代替内容检查。

### 运镜、构图与切镜的选择

新写或实质性修订时，先根据已确认剧本明确本场的表达重点与信息顺序，再按下面的过程选择各镜及其接续。剧情、角色知情和悬念揭示的既定时点保持有效；镜头选择不能自行改变事件因果，也不先排一组半身正反打再填动作。

1. **明确表达任务**：确定此处观众必须看懂或听懂什么、主要体验谁的处境、暂时不能知道什么，以及这一变化怎样承接前后内容。分清信息落在细小表情、手物接触、完整动作、人物关系还是环境尺度上；声音已能承担的信息，不必重复用画面解释。一个任务可以由同镜的连续变化或相连几镜完成，不按剧本句数分镜。
2. **排除不能完成任务的取景**：按[景别与取景范围](../../creative-techniques/references/镜头语言参考指南.md#31-景别与取景范围)、[观察角度](../../creative-techniques/references/镜头语言参考指南.md#4-拍摄角度与观察方式)及[焦点与景深](../../creative-techniques/references/镜头语言参考指南.md#7-焦段景深与特殊光学表达)核对目标在实际画幅中的大小、裁切、遮挡、清晰区域和辨认时间。必须看懂的细节过小、接触点被挡、必要动作被裁掉或信息提前泄露时，调整取景、运动或镜头分工；不能因为文字写了动作，就认定观众看得见。较远或较近都不是天然更好，取决于此处要读清的内容。
3. **在可行拍法中比较观看效果**：按指南的[动态配合与取舍](../../creative-techniques/references/镜头语言参考指南.md#51-构图与运镜的配合)考虑固定、连续运动、调焦或切镜各自保留和失去什么：表演是否完整，人物关系是否清楚，注意力如何转移，体验距离与节奏是否贴合本场。机位、光影和焦点围绕同一重点配合。能拍清后仍要判断哪种更能表现当前故事，不以技术复杂、运动更多或镜头更近作为加分条件；固定也不因省事而优先，运动也不因情绪变化而必选。
4. **选定并连贯复核**：在已有方向与授权内选择更合适的方案，直接落实到既有字段；难分优劣且都满足目标时，依据项目风格与相邻镜头确定，不强行制造唯一答案。沿下方全过程检查连读整场；取景虽成立但弱化本场重点时也应订正，并说明具体损失，不能只因个人偏好换拍法。普通镜头不例行列候选、打分或增加分析字段；关键设计存在显著不同的观看效果时，按[分镜方法补充](#分镜方法补充)中的方案比较处理。

设计或修订镜头时，按信息组织需要从[构图方式](../../creative-techniques/references/镜头语言参考指南.md#32-构图方式与裁切说明)选择主体位置、留白、框景或纵深层次；涉及跟随、揭示、注意力转移或观看距离与压力变化时，读取[构图与运镜的配合](../../creative-techniques/references/镜头语言参考指南.md#51-构图与运镜的配合)，把具体画面关系写入机位/构图，把触发、运动过程及落点写入运镜和起止画面。静态首帧只承接开场瞬间，视频提示词合并这些字段转写动态变化；需要补画面关系时回到分镜订正，不在转写时自行另排站位或运镜。

- **可见信息有取舍**：区分本镜必须看清的内容、只需维持连续但可在画外的事实，以及可通过后续取景揭示的内容。人物说话、地面物件和周围状态不必同时清楚入画；不能为展示所有持物、落点和环境而裁掉关键表情、改变站姿或移动物件。实际裁切容纳不了必要信息时，调整景别、机位、运动或有作用的切点，按[画外连续性](#镜头可见内容与画外连续性)维护未展示事实。
- **比较连续呈现与切镜**：对逼近、取用、拦抢、交接、撤步及新信息进入视野等连续过程，比较同镜保留过程与切镜选择观看位置的效果；按必要接触、反应、细节和节奏选用，不把能用同镜拍清作为优于切镜的充分理由。单人对白不要求每句、每个动作另切一镜；连续运动可以在同镜不同阶段分别取单人，必要的共同空间揭示按[出镜选择](#对白反应与多人镜头的取舍)处理。
- **运动服务全过程**：采用运动时写清跟随对象或揭示目标、开始时点、方向与必要幅度／速度、起始及结束构图。俯身、起身、靠近和撤开时，核对运动各阶段是否仍容纳需要辨认的面部、手或接触点；不能只在动作结束后才把关键内容追回画面。“小幅推、移、摇”可以使用，但须落实上述作用；固定构图能完成本镜预期的表演与观看效果时可以保留，不设运动比例或切镜配额。
- **视线与景别共同核对**：对白机位按[正反打与视线连续性](../../creative-techniques/references/镜头语言参考指南.md#41-正反打与视线连续性)确定摄影机高度、脸部朝向及注视目标，不用画面上／下方泛指对手。按空间交代、动作与表情的实际需要收放景别，关键反应按[表情与特写选择](#表情反应与特写的选择)落实，同一取景能够持续承载交流时可以复用；关键表情或动作因此看不清时才调整，不为变化而无故切镜。
- **调度与构图相互配合**：分镜设计可根据剧本中的目的、阻拦、接近或离开安排有动机的站位和路径，保持已确认的空间与行动事实；由机位和取景组织画面重心。不能为凑三角或对称擅改既定调度，也不能把人物一律锁死而失去表演。提示词转写承接已确定的调度，必要变化先回分镜处理。
- **可见还要可读**：按指南的[动态配合](../../creative-techniques/references/镜头语言参考指南.md#51-构图与运镜的配合)核对揭示时点、清晰区域及辨认时间，并纳入[时长安排](../../nora-ai-short-drama/references/共用规则/层级编号与时长规范.md#对白与动作时长核对)。既避免提前泄露，也避免关键内容刚露出就切走；能在运动中读清时无需额外停顿。
- **并行变化有取舍**：人物动作、对白、摄影机运动、焦点与背景事件同时变化时，核对谁在何时承载主要信息，是否争抢注意、遮住接触过程或挤掉反应。发生冲突时，先保住本镜必要因果、表演和有作用的观看体验，减少无必要的运动或效果，再考虑错开变化、调整取景或切点；不靠统一加速、删除必要反应或不断追加禁令解决。复杂度按具体冲突判断，不设动作数量上限，也不因复杂而一律改固定。

拍法本身不作为质量高低的判据。固定、运动、重复构图、正侧面、远景、特写、空镜、长镜及快切都按当前叙事、表演、空间、氛围和节奏判断；不设换机位、景别交替、运动组合或特写次数配额。专项方法中的镜数、秒数、角度和先后组合只作适用情境的参考，不因题材标签自动成为门槛。项目明确采用的风格约定及实际制作限制仍按其适用范围执行。提出修改须指出具体表达损失，不能为了变化强制换镜、加运镜、加动作，或把原本成立的拍法改成另一种。

专项中有适用条件的默认建议和已有反馈继续参与选择，不能因取消配额而一并忽略。涉及打戏时，在起稿阶段按[力度与节奏参考](../../sd-combat-engine/references/combat-intensity-guardrails.md)选择本段的速度、轻重与强调方式，并按[动作负荷与可读性](../../sd-combat-engine/references/combat-rhythm-and-load-guardrails.md)核对所需动作、支撑和位移；多人围攻同时用[多人调度](../../sd-real-engine/references/multi-opponent-rules.md)安排当前攻防重点及其他威胁。写完后在既有自检中核对这些选择是否实际落入镜头正文，不能只声明读过专项。

上述选择写入现有景别、机位/构图、运镜、起止画面、情绪/动作及转场方式，不新增镜头分析字段。送审时将这些字段和台词按播放顺序连读，沿“最初看哪里—何事触发—中间必须看清什么—最终获得什么—怎样接下一镜”推演同一过程，并回到本镜表达任务核对实际观看效果：关键信息是否可读，运动或切镜是否有作用，是否为强调局部丢掉必要关系或表演，整场是否机械重复同一种强调手法。发现问题，订正相应字段及受影响的时长、分段，再核对接续；不只在审阅说明里提出问题而保留原正文。各方法按镜头需要选择，不设置构图数量、运镜比例或全场统一造型。

合并自检以镜头正文中的可见关系、运动过程和具体接续为依据；仅声明“已阅读指南”不算完成选镜。交付时简述本场或本次修订中有作用的关键取舍及其表现效果，普通选择不逐镜解释，不另建分析表。

### 表情、反应与特写的选择

先定位本场需要观众读懂或贴近感受的表情、反应、接触和效果细节，再确定景别。按指南的[特写对象与动作接续](../../creative-techniques/references/镜头语言参考指南.md#特写对象与动作接续)比较保持现有构图、收紧或切入特写的观看效果；不能因为宽景已能看见动作，就跳过它对人物体验、打击分量与细节强调的作用。主要信息落在眼神、嘴角、迟疑或反应变化时，优先考虑面部特写；对象也可为身体碰撞、手脚、兵器交接、法术作用面、道具及环境细节，不把特写固定为脸部。特写用于日常试探、幽默和亲近，也用于交锋中的判断、承压和转折，不限于高潮。

动作场面同时检查交手双方的主动判断、抵抗和受力变化：只拍攻方出招、守方只在宽景里被动后退时，核对是否漏掉有作用的反应；按此刻的叙事重点选择人物或接触对象，不平均分配特写，也不让所有对手依次露脸。把选定对象、裁切和可见变化写进既有景别、构图、起止画面及动作字段，不只在说明中列“考虑特写”。

接触、交接、起身等过程须保留看清因果所需的信息，但不要求始终在一个全身镜头里完成。选特写时，连读切入前、特写内、切出后的同一次动作，按指南核对运动方向、持握、接触阶段、人物反应时点及画外连续性；既不为收紧脸部裁掉尚需交代的接触，也不因怕切断动作而排除能接续清楚的局部镜头。动作落定后的表情可在停顿、视线变化或结果处切近，动作中的反应也可直接承接。双方即时回应本身是重点时可保留共同画面；单独反应可以直接从特写开始，不强制先宽后紧，不在每次攻击或每句对白后固定插反应。

送审时按本场实际重点核对：哪些人物变化、碰撞或效果细节值得强调，当前取景是否让其可读并有足够观看分量，切点是否延续动作。宽景占主导而重要反应／细节只写在文字中，或只有攻方有表演、守方反应缺失时，重新比较特写或现有构图的调整；只有脸部特写时，也检查是否漏掉决定因果或力度的非面部细节。缺少某类或全部特写本身不判错，修改须对应具体表达损失；反过来，已有特写也不能以数量证明完成检查。订正并入原字段和前后镜接续，不新增表格、配额或审批。

### 分镜方法补充

本技能负责Nora场次分镜、P段规划及首帧设计，沿用本流程的参考输入规则；方法资料中的通用编号、目录、画幅偏好、镜长示例与切镜密度不作为本流程标准。首帧与环境图片需求按[首帧规范第1节](首帧参考图规范.md#1-制作复用与画面要求)判断，不由外部方法另设配额或省略本段实际需要的参考。

本节承接已明确的分镜任务，协作边界读取[规则优先级](../../nora-ai-short-drama/SKILL.md#外部技能协作与规则优先级)；同轮山音方法按[范围与适配](../../nora-ai-short-drama/references/共用规则/山音方法适配规范.md#山音方法的范围与适配)合并使用。本技能以已明确的本集剧本、场次需求、可用资产及相邻场段的起止状态为输入，按实际问题选读以下方法：

- 镜头选择、切镜理由、对白覆盖及镜长安排：`references/shot-craft.md`。先用其原文落实方法对照本流程下方覆盖核对，找出漏掉、只在说明里出现、无故重复或顺序改变的事件；再明确此镜需要观众看见或听见什么，决定保留同镜、切说话者、切反应或切关键物。运镜方法用于主动比较观看效果，按[本节选择规则](#运镜构图与切镜的选择)落实，不把题材、情绪或运动表中的先后顺序直接当成唯一拍法。对白可以跨镜延续，但声源、听者反应及事件时点必须清楚。
- 关键揭示、关系转折或复杂调度存在不同镜头方案，且观看位置、知情时机或表演中心会明显改变观众体验时：按需参考 `references/coverage-audition.md` 比较取舍。普通场景不例行生成多套方案；在已确认方向与授权范围内能确定的直接落实，涉及核心创作分歧时按既有确认规则交用户决定，不额外创建外部分镜计划或审批环节。
- 多人站位、视线、手与物品接触及换机位接续：`references/blocking-playbooks.md`。按实际空间关系写清开始位置、动作结果和结束状态，与本流程镜头状态及转场规则一并落实。

结果按下方[逐镜起止画面与转场方式](#逐镜起止画面与转场方式)写入模板对应字段和同一文件中的P段规划，不新增镜头职责栏或独立分镜产物。没有必要切镜时保留同镜；单镜与P的时长按[第1节](../../nora-ai-short-drama/references/共用规则/层级编号与时长规范.md#1-层级编号与时长)，实际参考选择及输入容量按[参考输入规划](视频分段规划规范.md#参考输入规划与分段可执行性)。不照搬外部镜长下限、切镜配额或每镜关键帧要求，不由文本方法自动启动素材生成。

### 场次分镜的填写与接续

先按[对白、反应与多人镜头的取舍](#对白反应与多人镜头的取舍)确定出镜人物，按[镜头可见内容与画外连续性](#镜头可见内容与画外连续性)区分画面、声音与接续记录。对白采用正反打时，参考[正反打与视线连续性](../../creative-techniques/references/镜头语言参考指南.md#41-正反打与视线连续性)，将站位、机位、视线及换镜接续落实到模板对应字段，并按下方[逐镜起止画面与转场方式](#逐镜起止画面与转场方式)核对。需要以光影、景深和前景遮挡共同组织注意力时，参考[对白场景组合示例](../../creative-techniques/references/镜头语言参考指南.md#106-示例d对白场景的光影景深与遮挡)，写清本镜的清晰主体、照明与遮挡边界，并按场景及实际信息需求调整。

保存路径执行[逐集目录规范第2节](../../nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#2-正式文件与目录)，场头与逐镜固定字段使用所链接模板。不要将多个实际切镜藏在一个镜号内；纯镜头运动仍可属于同一镜。

逐镜字段按所链接模板排列，“时长”紧接“时间”；“时间”的格式沿用模板。第一镜从本场 `00:00` 开始，后续镜头的起点等于上一镜终点，终点按本镜时长顺延；最后一镜终点等于本场计划总时长。小数秒保留实际精度，不为格式取整改变节奏。“时长”填写该镜持续秒数，与起止时间之差一致；场头的“时间”仍表示日／夜及内／外。

使用[场次分镜模板](../../nora-ai-short-drama/references/模板/场次分镜模板.md)中的固定正文；本节保留适用范围与填写规则。

剧本与分镜场头的“地点”显示真实地点层级，例如 `[青山村，荒院卧房](SC资料卡相对路径)`，点击后打开对应SC资料卡；不以“资料卡v编号”代替地点名称。场头及逐镜字段名使用 `**字段名**：正文`，冒号置于加粗标记外，字段间留空行；文档版本、更新日期、确认状态仍使用原元信息行格式。

场景图未就绪时可以继续完善分镜，但视频资料包提交前必须补齐模板中的场景采用字段及真实批准依据；旧素材无候选时按场景专项规范记录实际留存来源，不虚构版本。这些字段仅用于管理，不能复制到最终模型提示词。

“固定镜头，轻微前推”等表述须明确是固定机位变焦还是摄影机前推，避免动作指令相互矛盾。编排和修订逐镜动作后，按[对白与动作时长核对](../../nora-ai-short-drama/references/共用规则/层级编号与时长规范.md#对白与动作时长核对)确定镜长及受影响时间表。

景别、机位、构图与运动按[运镜、构图与切镜的选择](#运镜构图与切镜的选择)确定并落实到既有镜头字段；体感及抽象画面描述按[可观察画面转写](#不可见感受与抽象画面描述的转写)处理。

视听手法按实际表达需要选用：主观镜头明确视点，反应镜头承接事件影响，细节镜头突出关键信息，构图与遮挡表现关系，环境声／动作声／画外声音建立空间或推进事件；不要求每场凑齐。闪回、交叉剪辑、时间压缩或匹配剪辑按真实切镜分别编号，并写清时空与信息衔接。分屏、倒放等特殊形式不能仅凭文字假定当前H3工作流可实现；涉及新制作操作时先核对并确认，不擅自换接口、加后期或改写已确认剧情。

对白场景按[对白取景与切点](#对白反应与多人镜头的取舍)选择单人正反打、同镜延续或必要的共同画面。围绕动作、信息揭示和情绪转折，按[取景与运动选择](#运镜构图与切镜的选择)安排适合当前交流的取景与接续；固定机位可以持续承载对白和反应，是否调整以具体观看效果为依据。可随人物靠近而移动，以手机／电脑聊天框特写表现消息到达、发送或必要证据，减少可读文字，以面部特写放大反应，以手部等局部特写表现迟疑、操作或动作回扣；只选剧情需要的手法，不设数量配额。将声音负责交代的信息与画面负责强化的表演对应到既有“台词”“情绪/动作”“机位/构图”“运镜”和“时长”字段。屏幕特写不能替代剧本中必要的可听因果；听者反应可承接持续对白，切镜不截断语意，揭示时点仍遵守人物知情及悬念安排。

分镜编写与送审承接[人物性格与当下处境的台词适配](../../short-drama-write/references/对白与表演修订规范.md#人物性格与当下处境的台词适配)，并落实[动作、情绪与标点的联动](../../short-drama-write/references/对白与表演修订规范.md#动作情绪与标点的联动)：将剧本中的交流意图落成能看见、听见的表演，保留有作用的语气、重音、停顿、标点和抢话位置。在既有“情绪/动作”中写出触发、反应及先后，承接关键交流的开口、说话与落句过程；用“机位/构图”及必要运镜确保关键表情、肢体动作与听者反应能被看见，在“台词／音效／时长”中落实声音时点和反应余量。分镜不能把有情绪的剧本压成面无表情地轮流说台词，也不能仅靠频繁切镜制造亮点。送审前连着检查动作与接话能否顺着演、构图是否看得见动作、切镜和分段是否切掉反应或打断效果；发现动机或接话依据缺项时，按[职责分工](../../nora-ai-short-drama/references/共用规则/创作职责与接续规范.md#剧本分镜与提示词的职责分工)回到对应来源订正。

台词字段承接剧本中的对白、VO和OS，标明说话者、声源性质及是否需要口型；将语句与画面动作的并行、先后和跨镜延续落实到既有台词、情绪/动作及时长字段，不另加字段。三类声音的性质按[台词设计、节奏与统计](../../short-drama-write/references/对白与表演修订规范.md#台词设计节奏与统计)区分，口型切换按下节落实。

### 对白、反应与多人镜头的取舍

普通对白优先单人拍当前说话者，独立听者反应优先单人取景；不默认带入对方的肩背、肢体、背景身影、倒影或影子，不让无关人物入画陪站。单人正反打是文戏中常用且有效的表达方式，可优先考虑，尤其适合问答、试探、争执和逐轮回应。单人取景约定谁入画，不限定切镜频率，也不是每镜只能一人的硬限制。切点按[运镜、构图与切镜的选择](#运镜构图与切镜的选择)判断。听者镜头可承接必要的画外对白，人物反应在实际听见或看见触发事件时发生；不能为了等到独立反应镜头才开始变脸，或把动作拆成双方轮流停住等待。

一句一镜、连续几句保持同镜、同一句跨镜均可采用。每句恰好构成一次完整的表达或回应，句末能保留必要的表情落点并顺接对方时，一句一镜可以自然成立；连续表演或话中反应需要另一种切点时再调整。不强制按句切镜，也不为避免一句一镜而刻意合镜、增加运镜或改成多人画面。审查须指出切点具体漏掉的反应、打断的动作、不可读的信息或受损的交流节奏；不能仅凭按句切镜、重复机位或固定镜头判为机械，也不以减少一句一镜作为质量提升依据。

接触、交接、相互阻拦等动作镜只保留实际参与动作且需要看清的人；共同到场、共同反应及必要的场景／空间建立可采用多人镜头。每个入画人物须有当前叙事作用，无关人物排除；不因强调单人取景而将同一次共同到场拆成重复入场。取景数量由该镜的信息与动作决定，不规定单人／多人比例，不为凑配额增加群像。需要过肩或局部入画时按下节明确其身份和裁切，不将其记作纯单人画面。

### 镜头可见内容与画外连续性

逐镜的机位/构图、起始画面、结束画面及动作画面正文只描述本镜实际可见的主体、部位、持物和变化。画外人物的持物、站位及持续动作等必要连续性事实，在既有场头或分段开始／结束状态中维护，供前后镜及出画后再入画核对，不另建台账，也不逐镜复制成画面要求；模型镜头描述不照搬这些画外事实。画外状态未展示不代表消失或复原，后续再次入画仍须承接实际结果。

本镜确实需要的画外对白、脚步、动作声或反应触发保留，并写清声源、方向及可听时点；画内人物的反应只能由其实际可知的信息触发。仅需交代画外视线对象时，说明人物看向当前画面哪侧，不额外展开画外对象的外貌、持物或动作。必要的声源与交流对象按既有姓名／Subject规则表达，不以省略画外状态为由删掉剧情所需的声音或身份对应。

背影、肩颈、手臂等局部只要入画，就属于可见人物：写清人物全名、画面位置与纵深、可见到哪里、清晰程度、遮挡对象及范围。不能同时写“只有一人入画”和“另一人的肩背在前景”；不要以“画外”指代已经入画的肢体。空间关系按[统一方向参照](../../creative-techniques/references/镜头语言参考指南.md#13-统一方向参照)换算，具体部位的身体左右保持其原归属。

### 逐镜起止画面与转场方式

每镜独立填写“起始画面”“结束画面”“转场方式”，字段顺序以[场次分镜模板](../../nora-ai-short-drama/references/模板/场次分镜模板.md)为准。起始画面与结束画面各写一个可冻结的可见瞬间，明确本镜有作用的人物位置、姿态、表情、双手与持物、关键环境状态及动作进度；“情绪/动作”写两者之间怎样变化、谁同时反应。不要把整段动作复制进两端，也不把“结束画面”写成所有人停住等下一镜。

“转场方式”描述从本镜切到哪一镜、怎样切，以及具体接续点。机位位置与观察角度写入“机位/构图”，“固定镜头”写入“运镜”，两者均不能替代转场；“自然衔接”“接上一段”不足以说明切点。按实际需要使用直接切、动作匹配切、视线切、声音跨镜等：动作匹配切须承接同一次动作的进度与方向，视线切须对应看者与所看对象，声音跨镜须明确声源及切前／切后的持续范围，不因切镜重演动作或重复对白。场／集末写清收尾方式和下一场应承接的实际状态。

连读相邻镜头时，逐项对照前镜结束画面、转场方式与后镜起始画面；场／集间再按[转场接续](#场次与剧集之间的转场和接续)检查，分段起止概括实际画面及必要的[画外连续性事实](#镜头可见内容与画外连续性)，不另写一套剧情，也不将整份状态记录复制到每镜。文本边界不要求每镜生成起始／结束图片，图片需求仍按[首帧规范](首帧参考图规范.md#1-制作复用与画面要求)判断；导演台实际接续条件按[原生衔接](../../nora-generation/references/ComfyUI-MiniMaxH3导演台节点使用规范.md#61-局部返修时的前后衔接)核对，不将文字“接上一集”视作模型输入。

### 剧本到分镜的覆盖核对

分镜完成或修订后，由本轮写作者将本节作为交付前合并自检中的覆盖检查，主动核对并在本轮授权范围内处理，不等待用户指出遗漏。对照对应版本剧本核对：推动剧情的台词、行动、信息触发、变化过程及结果，分别落在哪个镜头、怎样让观众看见或听见。不能只核对台词原句和镜号齐全；剧本里的身体恢复、能力作用、物件交接等事件，也要保留其实际表现。抽象体感按[可观察画面转写](#不可见感受与抽象画面描述的转写)处理，不在转写时直接删掉。无需逐字照搬动作说明，也不另建逐句映射表；核对的是叙事信息与行为是否保留。

保留剧本中决定因果的先后、并行与反应对象。例如声音先宣布奖励、植物随后生长，不能转写成植物先长出、人物再听到说明；人物听到新信息后才转惊喜，不能全程只写原有的虚弱神态。反向核对分镜有无新增原稿没有的发声者、持有物、能力、动作结果或提前揭示的信息；属于创作调整时先按[返修归属](../../nora-ai-short-drama/references/共用规则/制作返修与完整重做规范.md#制作返修的上游归属)同步上游，不借镜头设计悄悄改戏。

连读整场时，核对跨镜持续的台词及动作是否只发生一次，切镜有没有漏掉收尾或把已完成动作重新演一遍。未完成的原句可跨镜延续，不因换镜重新说整句；分段边界不能将同一次转身离开写成前后两次离开。检查结论及未解决项写入既有审阅记录；后续模型转写按[模型正文的内容核对](../../nora-video-prompts/references/视频提示词制作规范.md#模型正文的内容核对)接续。

### 场次与剧集之间的转场和接续

编写剧本与场次分镜时，连着检查前场结束和本场开头；新一集还要回读上一集的结尾。核对观众能否理解经过了多久、到了哪里、人物为什么开始当前行动，以及哪些状态继续保留，不能只靠场头写了“次日清晨”就认为画面已经交代清楚。

时间、地点或行动阶段改变而开头缺少交代时，安排必要的短镜头或声音衔接，让观众先辨认新的时空和行动起点，再进入主要事件。可用清晨光线及环境声、人物走出房门或抵达新地点、承接前场物件的动作等；选能完成交代且符合节奏的表现，不逐次补齐全部生活过程。转场不等于必须使用黑场、淡入淡出或额外特效，也不规定固定秒数。现有开场镜头已能交代变化，或前场悬念与动作需要立即接续时，可以直接切入；跨集连续事件不因集号变化自动跳时、复位或重演已经完成的动作。

例如，前场夜间以人物说“明早再种菜”结束，下一场清晨可先用约3秒表现她推开房门走入院子，配合晨光和鸟鸣，再接解种袋的镜头。这个例子只说明时间与行动的过渡；黑土已铺好的剧情依据及门、穿戴、持有物等状态仍须按[镜头状态规则](#镜头状态的变化延续与参考差异)核对，不能用转场掩盖未交代的关键变化。

过渡内容落实到现有剧本动作及分镜模板对应字段，逐镜边界按[起止画面与转场方式](#逐镜起止画面与转场方式)填写；新增独立切镜使用独立镜号，保持已有编号，纳入所属P段及镜号映射。短过渡镜头可以少于4秒，但生成分段仍按[段长规则](../../nora-ai-short-drama/references/共用规则/层级编号与时长规范.md#1-层级编号与时长)规划；插入后按[时长核对](../../nora-ai-short-drama/references/共用规则/层级编号与时长规范.md#对白与动作时长核对)同步镜头、分段、场次及整集计划，不把原段加长到超限。涉及新增行为或改变事件因果时，按[返修归属](../../nora-ai-short-drama/references/共用规则/制作返修与完整重做规范.md#制作返修的上游归属)先同步剧本；取景、切镜与节奏的调整由分镜落实，并同步受影响的首帧、提示词和素材需求。

每场分镜写完后、送审前检查前后场接续；整集分镜写完后连读所有场次边界及上集结尾、本集开头和下集接点。将需要补充的过渡或仍未交代的状态记入现有修订／审阅记录，不另设转场审批阶段。

### 不可见感受与抽象画面描述的转写

分镜的画面描述须明确准备呈现的表演、动作、身体变化或视觉效果。表情允许用“委屈”“忍笑”等抽象词交代意图，并明确本镜有作用的触发、强弱和起止，不要求在分镜阶段逐项拆眉眼嘴；转为首帧或视频模型提示词时，再按[表情拆解](../../creative-techniques/SKILL.md#表情表达)落实具体面部变化。剧本中的“暖流遍及四肢”“力量涌入”“心里一沉”等不可见体感仍不能仅照抄到画面字段，也不能只给变化后的结果；将其叙事含义转成可见的发生过程。原词确需保留时，同处配上对应的可见表现，不能把体感本身当作已经可视化。

普通情绪与体感可通过表情、姿态、手部动作、呼吸起伏、气色等表现；需要观众看见超自然作用时，选择与剧情、人物及项目风格相符的光效、粒子、形变等表现。效果的强弱、范围及夸张程度按当前剧情和镜头需要确定，不固定用金光，也不把所有感受都做成特效。涉及新能力、实体、行为或事件因果变化时，按[制作返修的上游归属](../../nora-ai-short-drama/references/共用规则/制作返修与完整重做规范.md#制作返修的上游归属)先处理对应上游。

采用视觉效果时，写明作用对象、画面内可见部位、颜色／形态、范围和强度；过程及消退按[显隐过程](#显现与消失的过程)，后续残留按[镜头状态规则](#镜头状态的变化延续与参考差异)填写，时长按[对白与动作时长核对](../../nora-ai-short-drama/references/共用规则/层级编号与时长规范.md#对白与动作时长核对)安排。构图须能看见关键变化，出画部位不能充当本镜已展示的证据。画面转写保留原剧情含义，不用新增台词或OS解释代替需要呈现的视觉变化；已有对白与心理声音仍按各自声源及口型规则处理。

### 声景与配乐

本节适用于分镜的声音安排及后续模型提示词。默认不让模型生成环境音或持续背景底声，包括室内底噪、机器嗡鸣、空调声、街道声、远处人群交谈和无明确发声者的杂声；现实、幻想及室内外场景使用同一默认边界。只有本次任务、已确认剧情或明确声音设计要求时，才安排对应环境声，并限定声源与出现区间，不因场景名称自动铺底。

默认保留已指定的人物对白、画外现场对白、旁白／心理声音，以及承担动作信息、因果或节奏的必要离散音效。动作音效写明具体声音及发生点，不为每个动作自动添加一串脚步、衣料和碰撞声。BGM只在本次任务或已确认声音设计明确需要时填写；未安排时不添加配乐，不用“低频氛围音”等模糊词变相生成音乐或持续底声。

“音效：无”表示不新增动作或特效声，也不默认延续环境底噪；已列出的对白、旁白仍按原文发声。无对白、不新增人声、无环境音与完全静音分别说明：去掉环境声不等于删除人物对白或必要音效，完全静音才表示全部声音关闭。

逐镜声音与模型整体声景、音乐字段保持一致；去环境音的要求覆盖整段，不在其他镜头、summary或整体声景中重新加入环境底声。音色参考只保留所需音色，不复制素材中的背景杂声。引用前段音视频时核对是否会带入不允许的底声；导演台上下文及输出模式按[段间声音衔接核对](../../nora-generation/references/ComfyUI-MiniMaxH3导演台节点使用规范.md#61-局部返修时的前后衔接)处理，不以空Audio槽认定没有声音输入。

### 台词与动作的同步

先区分剧情需要的先后关系和可同时进行的表演。人物边坐下边说、边转身边回应等安排，应在同一动作阶段写清开口时点、说话期间继续的动作及落句状态，例如“椅子拉开、身体下降落座时开始说话，落座过程中说完这句”。不能只按文字排列顺序写成先完成全部动作、再停下来开口，或说完整句后才开始动作；不把口型同步等同于动作与对白已经同时发生。

有因果或明确表演目的的先后仍要保留，例如听完新信息再反应、拿稳杯子后道谢、说完拒绝立即切镜。静止说话和必要停顿也可按剧情安排，不强制所有对白都配动作。镜长按真实的先后与重叠核对，可并行的部分不重复累加；声音先行时交代画外声源与入画时点，不能让画内无台词人物代做口型。转写、翻译及审查时同时核对动作阶段与声源，不只检查台词原文是否相同。

### 心理独白与开口对白的切换

- 声音性质按[台词设计、节奏与统计](../../short-drama-write/references/对白与表演修订规范.md#台词设计节奏与统计)判断。OS只供观众听见，画面人物不做同步说话口型；反应由目光、表情及肢体动作承载。对白明确实际说话者与听者，包括不出镜群演；画面内不应说话的人物不做同步口型。
- 同一人物从开口对白转OS时，写清对白结束、合嘴及心理声音开始的先后；OS所在镜头／段落开始即明确闭口状态，不能只在结束处补一句“嘴不动”。从OS转开口对白时同样明确切换点，混合段不能笼统禁止全部对白口型。
- 呼吸、惊吓或疼痛等身体反应与心理声音分别描述；OS期间需要保持闭口时，选择不要求张嘴的可见反应和相应非语言声音，不同时安排张嘴喊叫等相冲突动作。
- 无对白的可见反应不一律要求闭嘴；可按剧情张嘴惊讶而不发声，不做说话口型。闭口要求只覆盖实际需要的镜头和声音区间，不能用全段“所有无声反应闭口”覆盖已明确的张嘴表情；OS及其切换仍按以上专门要求处理。
- 模型转写按第6节读取的官方声音格式表达声源及每句心理声音对应的闭口要求，不自造OS模型标签。提示词符合格式与生成结果执行正确分别记录；用户指出口型问题时，先核对实际提交正文、切换边界与动作冲突，不凭问题反推“没有写闭口”，不擅自审片或重新生成。

### 显现与消失的过程

精灵、虚拟界面、物件或能力效果需要凭空显现、消失或改变形态时，写明简短可见的起点、变化及结果，以及与声音、人物反应和对白的先后／并行；不能只用“突然出现”“消失了”代替需要呈现的过程。重复出现沿已选定的表现，效果结束后留下的显隐状态按[镜头状态规则](#镜头状态的变化延续与参考差异)接续；剧情明确的瞬时变化或时间省略按其原意表达，不强加统一特效。

效果由本场视觉设定和叙事需要选择，简短过程即可，不默认增加独立素材、声效或切镜；纳入既有动作字段并按[对白与动作时长核对](../../nora-ai-short-drama/references/共用规则/层级编号与时长规范.md#对白与动作时长核对)检查。界面的设计与显示内容按[虚拟界面固定元素与剧情内容](../../nora-drama-assets/references/道具资料与参考图规范.md#虚拟界面固定元素与剧情内容)取用。

### 独立生成分段的状态表达

按P段独立生成时，模型依据本段实际提交的提示词和绑定的参考素材、音视频上下文，不默认知道前段剧情或下一段安排。创作上的连续影片不等于模型获得连续上下文；场次分镜在划分P段时就落实以下要求，不留到提示词阶段才补猜。

1. **跨段接续写成当前事实**：把前段结果落实为本段开始时具体的姿态、位置、持物、数量、食物／液体余量及环境状态，只写影响本段表现的内容。不能仅写“餐具不复满”“不恢复原样”“延续前段”让模型推断结果。例如，已在更早分段吃完食物，本段应写“盘里只有碎屑，杯内仅留少量饮料”，而非只写“不要重新出现没吃完的食物”。需要出现的新一份食物另写清容器、持有人及位置，避免与旧餐具混淆。
2. **段内变化可以补充保持要求**：本段已经明确起点、动作和结果时，可用“保持”“不恢复”等补充后续约束，须有本段内可辨认的对象与状态依据。例如，本段从半杯饮料喝到只剩少量后，可写“杯内只剩少量饮料，随后切镜保持这一余量”。这类补充不能替代客观状态，也不要求逐镜重复所有事实。
3. **制作接续与画面描述各归其位**：跨段因果和衔接备注可说明前后关系，但实际画面正文须能凭本段输入理解。“由下一段承接／完成转场”不能替代本段须生成的结束画面，也不能让本段预知未输入的后段。实际传入前段音视频也不等于传入全部前段文字或项目历史。可见范围与必要画外事实仍按[画外连续性](#镜头可见内容与画外连续性)分工，不为交代接续强行让画外物件入画；与参考图的状态差异按下节明确。
4. **明确跨段匹配的实现依据**：在已有“开始状态”“结束状态及衔接要点”和参考规划中说明接续靠什么实现：实际前段音视频引导、具有匹配状态的参考素材与具体正文，或成片剪辑／合成。按所选方式写清来源与用途、两端须匹配的可见／可听状态及未就绪项；未生成的前段尾画面只能列为制作依赖，不能记作已经输入。同一人物、同场景、共用参考图或同批提交都不是自动接续的依据。H3的实际输入边界及引导条件按[导演台段间引导](../../nora-generation/references/ComfyUI-MiniMaxH3导演台节点使用规范.md#6-段间引导与重绘)核对；参考图保持一致是目标，不能当作姿态、空间或运动已匹配的证明。
5. **分清两段各自完成的内容**：跨段动作、遮挡、图形匹配或声音桥须明确本段停在哪里、后段从哪里开始，所需过程与可用接点纳入各自时长。需要在本段完成遮挡时，写清遮挡范围、最终画面及剪辑需要的停留；有意在动作或转场中途切开可以保留，但须有两端状态和可落实的接续方式，不能把未完成部分笼统交给下一段。后期合成效果留在制作备注，不假定导演台会读备注完成剪辑。
6. **逐段独立读，再核对相邻段**：纳入既有分镜复查，先暂不依赖相邻段正文，只读当前P段及拟输入素材，检查起点、变化和结果能否明确理解；再对照前段结束、本段开始及后段所需起点，核对人物姿态、背景结构、地面、光线、构图、图形与声音中实际需要匹配的部分及实现依据。素材分别获批不等于彼此兼容；无法落实的接续返回分段或素材方案处理，不能只写“连续性通过”。分界、接续方式或参考输入改变时重查受影响部分，不新增审批、独立台账或必做补图要求。

### 镜头状态的变化、延续与参考差异

场次分镜按剧情发生顺序写明当前状态、动作造成的变化及变化后的延续。参考图提供身份、造型、空间或物件设计依据，图中某一时刻的状态不自动成为所有镜头的状态。

1. **明确与本场有关的状态**：包括人物的位置、姿态、情绪、身体与知情状态；服装的穿脱、鞋袜、发型及伤妆污渍；道具的持有人、位置、数量及开启、破损、消耗等状态；场景的陈设、被褥、门窗、光照、天气及剧情造成的环境变化；系统界面、精灵与其他效果的显隐和变化。按实际剧情选择有画面、动作或衔接作用的内容，不逐镜重复所有资产设定。
2. **变化有原因，结果有延续**：从上一镜结束状态接续本镜，写清何时、由什么动作或已确认事件改变，以及结束后留下什么状态；镜头切换、分段切换、暂时出画或重新取景都不使状态自动复原。同集跨场继续发生的事件也要承接；穿鞋、整理被褥、关门、移物等改变需有剧情依据，时间跳跃或恢复默认状态须有明确说明，不为填补缺口擅自补戏。人物起身带乱的被褥，后续仍是未叠、散乱的，直到剧情明确有人整理。同一物件被拿起、穿上或转交后，原处数量、持有人或穿戴状态同步变化，不能在新位置保留物件的同时无故在原处复制一件；这些变化写入既有动作与开始／结束状态，不另建物件台账。

   **接触、支撑与受力**：动作涉及人物接触、支撑、拔取、推挡、交接或可移动物件时，写清谁接触哪一部分、物件由哪里支撑、施力方向与必要幅度，以及局部或整体怎样变化、最后落在哪里。区分“捏住被角起皱”“掀起一角”和“整床被子被扬起”，不让含糊动词替代实际动作。例如，手停在床面附近捏住被角，只有手边布料收拢起皱，其余被子仍贴着床面，不因手部动作整床悬空；若剧情确需抛起或搬动物件，则明确其移动过程与落点。多人接触时明确施动者、被接触者及具体部位，如谁用哪只手抓住谁的哪侧手腕、何时松开；不要只写“抓手”“揉手腕”而丢失肢体归属与动作原因。人物移动同时区分身体朝向、行进路径和停留位置，如转身后向院门走去，而非用“退回去”含糊替代转身行走。不要求逐镜填写物理参数，只补决定动作结果的接触与受力关系。 对决定动作结果的过程保留必要因果链：先建立真实接触或握持，再表现支撑、受阻与发力，随后发生分离、移动或交接，并留下稳定结果。不能在前镜尚未握牢时，直接把后镜起点写成已松动或已提起；可并行完成或省略无作用的阶段，不把动作链机械拆成多镜，也不要求慢动作或数值化力度。

   **真实位置与空间参照**：需保持位置的物件，以承托面及床沿、门槛等稳定参照说明实际位置，再按[统一方向参照](../../creative-techniques/references/镜头语言参考指南.md#13-统一方向参照)表达当前机位中的画面位置。换机位可改变画面左右和远近，不能改变物件与参照的真实关系；“人物脚边”等随人物移动的描述不能代替固定位置。物件原在床侧地面，人物取用时写人或肢体移向原处，直到实际拿起、穿上或推动才改变物件状态；没有移动动作的鞋仍在原处地面，不随镜头切换到床上或自动移到脚下。

3. **与参考不一致时明确写出实际状态**：选用参考时，区分需要保留的身份、外形、服装设计或空间结构，以及本镜需要改变的穿戴、姿态、陈设和其他状态。不能只写“下床”“探脚”或“鞋在地上”来暗示赤脚；应明确写“她双脚赤裸，伸出一只赤脚探向地面；旧布鞋仍放在炕边泥地上”，并在后续穿鞋前延续赤脚状态。环境参考若被子叠放整齐，人物起身后的镜头须描述实际散乱位置；不要同时要求完整保留参考中的整齐被褥。不用“完全照参考”“全部保留服装”等笼统要求覆盖已明确的状态差异。临时差异不自动改写基础资料卡或要求重做基础参考图；确需补图时遵循对应素材规范。
4. **落实到现有正文**：场头记录实际开场状态及必要的前场承接；逐镜按[镜头字段分工](#景别选项与镜头字段分工)用“机位/构图”明确必须看清的对象及范围，按[起止画面与转场方式](#逐镜起止画面与转场方式)独立填写两端画面和接续，在“情绪/动作”写明变化过程与反应。分段表的“开始状态”“结束状态及衔接要点”概括所含镜头的实际状态，供相邻分段接续，不另写一套事实。片段开始时已成立的状态必须明确，不能只在动作结束处描述；不以笼统的“同上”“延续上一段”代替独立生成段必需的具体状态。同一P内切镜也要承接决定剧情的状态：植物尚未生长、人物仍赤脚等要求，不能只写在第一镜而在后镜被相反描述覆盖。只重申本镜确有作用的状态，不把全场状态复制到每镜。

   **段内延续与画面取舍**：同一P内，同一次起身、放置、拾取、脱手等状态变化只在对应动作中完成，后镜承接已经成立的结果，不因切镜重演；剧情确需再次发生时须有新的触发与过程。连续时间与共同生成上下文不替代关键状态表达，但不要求每镜重述全部站姿、持物或再次表演同一动作。起止画面只写本镜有作用的可见事实；未展示而仍须延续的内容按[画外连续性](#镜头可见内容与画外连续性)维护，不为同框展示这些事实改变人物姿态或环境位置。

   **参照构图与可见范围**：在“机位/构图”写明关键主体及肢体实际可见到哪里，区分画内、被遮挡与画外；需要表现的接触、穿鞋或表情须处于可见区域。画外物件的状态及记录边界按[画外连续性](#镜头可见内容与画外连续性)处理。多人、精灵与人物同框时，明确各主体的位置、可见部位和遮挡关系，让肢体轮廓有可辨归属；可以用人物半身与精灵全身等取景减少不必要的交叠，不一律要求所有主体全身可见。换景别或机位后重新说明可见范围，同时保留上一镜已成立的身体与物件状态。连续空间内的人物首次进入画面时，交代原有站位、入画路径或原先的遮挡；不因前镜没拍到就让其从墙里或空地凭空出现。明确设计的突然揭示可以保留，但应有对应的机位或遮挡依据。

5. **每场写完后完整复查**：每个场次的镜头正文和分段规划完成后，送审前必须从第一镜到最后一镜按播放顺序通读，逐镜核对开始状态、变化原因、结束结果及下一镜承接；同时检查各P分界和必要的前后场联系。重点查找接触与受力不符、切镜后空间参照改变、肢体归属或遮挡不清、穿戴或持有物凭空变化、同一物件在转移前后位置无故重复、被褥和陈设自动复位、门窗与光照无故改变、数量或消耗恢复、人物未获知信息就反应等问题。发现遗漏或冲突时补齐本场正文及分段状态，再核对受影响的接续；修订后复查受影响范围，不只读被改的一句话。
6. **素材就绪后再对照实际参考**：允许先完成分镜，再准备或复用人物、场景、道具等参考；分镜先写剧情所需状态，未知的实际参考差异作为待核对项。实际采用素材确定后、制作视频提示词前，对照具体文件及版本核对参考状态与各镜剧情状态，补齐差异或解决冲突；不能用“分镜已经批准”省略这次核对。依据已有可信记录或用户明确授权的看图结果核对，遵守技能入口的看图能力调用边界，不因此自动调用看图或审片；没有可靠依据的状态写明未知，不能猜测或记为通过。
7. **提示词与实际输入一致**：按官方H3结构，按[镜头可见内容与画外连续性](#镜头可见内容与画外连续性)筛选实际可见／可听内容，按[参考定义与保留说明](../../nora-video-prompts/references/视频提示词制作规范.md#ref2va参考定义与保留说明)分配参考内容与镜头过程，将当前状态、变化时点和延续结果写入逐镜detailed_description，summary概括本段事件、retention_analysis只说明参考保留内容，中英文对应，不将全场画外状态作为出镜或动作要求；素材定义的内容边界、公共／本组拆分及最终拼接检查按[导演台第4节](../../nora-generation/references/ComfyUI-MiniMaxH3导演台节点使用规范.md#4-公共提示词与本组提示词)落实。执行前及素材或正文变化后的核对范围统一按[模型正文的内容核对](../../nora-video-prompts/references/视频提示词制作规范.md#模型正文的内容核对)执行。

上述复查属于现有创作与提交检查，不增加审批阶段或独立状态台账。正式内容的头部执行[共用头部](../../nora-ai-short-drama/references/共用规则/文件版本与工作稿规范.md#正式内容文档的共用头部)；检查范围和未解决项可简要注明于确认范围，来源分镜／素材版本及完整复查结论保存在审阅记录或“提交前检查”中，并由确认依据关联。缺少决定状态变化的剧情依据时先回上游处理，未解决项不记为可直接生成。历史已提交请求、既有视频及用户批准事实保留；规则补强不授权改写历史请求、撤销批准、自动返修或重新生成。
