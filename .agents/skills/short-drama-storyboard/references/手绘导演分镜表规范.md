# 手绘导演分镜表规范

## 1. 用途与询问时机

手绘导演分镜表将场次分镜转成图文表格，辅助用户讨论构图、空间关系、人物调度和动作过程。它是可选展示方式，不是独立剧情正文、视频输入素材或新的必做审批阶段。

场次分镜形成可展示初稿后，在原分镜讨论或送审时先询问用户是否需要本次范围的手绘导演分镜表；用户明确需要后按授权范围制作，未确认时不自行生图，也不阻塞不依赖本表且已获授权的后续任务。已有用户决定覆盖本场、整集或后续范围时沿用该选择，不重复询问；明确不需要时继续原分镜流程。已批准分镜可以按用户要求补做辅助表，不因此重新审阅未改变的正文。现有项目及旧表不因本规范新增而重做。

分镜技能负责内容提取、分页和正文映射；图像准备与实际生成分别交[资产设计](../../nora-drama-assets/SKILL.md)及[生成执行](../../nora-generation/SKILL.md)，图片能力沿[主技能的导演分镜表默认分支](../../nora-ai-short-drama/SKILL.md#当前参考图生成选型)及对应执行规则，不把本节“是否需要制作”的询问混同为重复询问生图能力。已有适用人物、服装、场景资料按需引用；资料未齐时可用简化示意结构，不补造外观设定或重画基础资产。

## 2. 来源、画风与固定版式

以用户指定或本轮送审的场次分镜具体文件、版本及镜头正文为唯一内容真源。生成前先逐镜提取当前版内容，使用[固定模板](../../nora-ai-short-drama/references/模板/手绘导演分镜表模板.md)组织每页；不让模型凭项目名、文件路径、旧视频或历史表自行补完镜头。固定列名、左右顺序及页头按模板填写，不增删或重排。

- 统一采用白底、黑灰铅笔速写、简洁细线表格及清晰简体中文；六镜页默认采用横向4:3画布，已有用户确认的样式继续沿用。只画清主体数量、构图、人物位置、朝向、视线、动作和空间关系，不刻画发丝、材质或服装纹样等细节。分镜格内的取景与画幅服从源分镜，整张表格画布按阅读需要安排，不改变项目成片规格。
- 每个镜头对应一个数据行。镜号保留源分镜的实际编号，景别、运镜与情绪/动作从该镜忠实提取；动作说明可概括关键过程，但不能添加新行为或改变因果。台词、音效与时长按源字段原文保留，说话者、画外声音及时间精度不得丢失。原文明确无时填无；源资料缺项先回分镜核对，不自行编造。
- 一个镜头需要表达多个动作节点时，在同一行的分镜图格内并列起始、关键或结束状态，可配箭头表达运动；这些小图仍属同一个镜头，不另编号或冒充切镜。
- 表内文字和姿态服务结构讨论，不作为人物外观、服装、场景美术或动态表演已获批准的依据。静态表不能代替语速、停顿及真实表演节奏的判断。

## 3. 每页镜数与分页

每张图最多展示6个实际镜头数据行，表头不计入镜数。一行对应一镜，不为凑满页面合并、增加或重复镜头；末页按实际余数展示，不添加空白占位镜头。单镜文字较多时可以减少本页镜数、增加画布或调整列宽，不删台词、音效、时长或固定列来压缩排版。

同一场按源分镜的实际播放顺序连续分页，不按P段数量代替镜头数量，不跨场混排。每页重复完整表头，并显示场次、来源分镜版本、镜号范围和页码／总页数。制作端先确定全部页面及镜头覆盖，再逐页提供完整内容；全场镜头须无遗漏、无意外重复。图表的页数、分页及箭头不构成新增场次、镜头、P段或修改轮次。

## 4. 讨论反馈与正文同步

用户对表中构图、取景、运镜、镜序或表演提出修改时，回写场次分镜正文及受影响的时长、分段和索引；涉及剧情、对白、人物动机或决定因果的必要动作时，先按[职责分工](../../nora-ai-short-drama/references/共用规则/创作职责与接续规范.md#剧本分镜与提示词的职责分工)同步剧本，再更新对应分镜。版本、范围确认及下游接续沿用原流程，不仅在图上改动而让正文保持矛盾。

正文更新后，需继续展示时只更新受影响的页面及必要接续，标明对应来源版本；旧表保留为当时版本的讨论记录，不冒称仍与新正文一致。图中的错字、漏字或错误姿态只按源分镜纠正图表，不能据生成错误反向改写原文。用户对图的认可仅按其明确范围记录，不自动替代正文、资产或视频的批准，也不授权后续视频生成。

## 5. 保存、记录与交付核对

本表不另建独立正式分镜文件或专项会话。对应场次分镜工作稿中记录用户是否需要及范围、来源分镜文件与版本、页数、页内镜号、图片链接、反馈与正文修改入口；沿用已有讨论和审阅区，不复制第二套镜头正文。

**生成候选**：原生图片保存到本制作对象的`其他资料/工作稿/素材/`，命名为`{完整场次编号}-手绘导演分镜表-v{两位图表版本}-第{两位页码}页.png`。提示词、实际输入、请求及执行凭据保存到同对象的`其他资料/执行附件/`。候选和历次执行资料保留，不因采用而删除或改写。正集、片头和片尾各自在自身制作目录保存，不互相混放。

**正式采用**：用户明确批准具体页面或整套后，将对应原生图片复制到本制作对象的`03-分镜脚本/导演分镜表/`，正式名为`{完整场次编号}-手绘导演分镜表-第{两位页码}页.png`，保持原字节和实际规格，不为正式归档重新生图、缩放或超分。采用清单使用[固定模板](../../nora-ai-short-drama/references/模板/手绘导演分镜表模板.md#采用登记)，维护在原场次工作稿中，登记每页镜号范围、来源分镜版本、图表版本、候选与正式入口及批准依据；原图片生成／审阅记录同步正式入口和当前采用状态。正式图片是源分镜的辅助展示，不新增一份独立分镜正文。

**替换与历史**：替换已有正式页前，将被替换原图保存到本对象既有`其他资料/历史版本/`，文件名保留完整场次、当时图表版本、页码和实际留存时间，再复制已批准新图并更新采用清单及关联记录。源分镜变动后，旧表仍保留对应的原来源版本；新旧版本不得混称同一套已批准图片。正式目录只放当前采用页，不混入候选、旧版和执行附件；其唯一入口由[逐集目录规范](../../nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#2-正式文件与目录)登记。

**来源与候选登记**：在原场次工作稿中按固定模板登记来源分镜版本、图表版本和候选编号；同一来源分镜版本内候选从1编号，图表版本保留为图片文件身份。每个图表版本只对应一个来源分镜版本，不从生成时间、当前正文或视频R编号猜测来源。采用清单按具体页面关联候选与正式图，已采用是候选的状态，不是独立版本或轮次。

**网页入口**：在“剧集制作 → 对应制作对象 → 当前场次”中，点击“场次分镜”旁的“导演分镜表”。沿用场次修改轮次选择器，按该轮引用的来源分镜版本展示对应候选；同一版分镜被多轮复用时共用同一套图，不新增导演表制作轮次。候选选择器在具体候选上标记已采用，默认选已采用候选，无采用时显示该版最新候选；已采用页读取对应正式图片，原候选继续保留。对应分镜版本尚无图时显示空态，不用其他版本顶替；来源未登记时提示补登记，不推断绑定。单次显示一张图，来源标签显示“场次分镜：V版本”；不设上方逐页按钮，图片框左右使用圆形箭头，首张不显示上一张、末张不显示下一张，单张图不显示箭头；底部贴近图片居中显示当前页／总页数，不重复放翻页按钮；同一行右侧放“查看原图／下载原图”，窄屏可换行。点击图片默认进入铺满浏览区域的全屏看图，支持关闭或Esc退出，并保留当前页；全屏内继续沿用圆形翻图箭头。全屏框体、原图操作和生成／审阅记录沿既有公共组件。导演表不再混入普通专用素材候选区；无图时显示空态，现有剧本、分镜和视频仍可独立查看。交付时核对正式与候选的实际条目、顺序、文件入口及源记录，不以文件存在代替网页收录核验。

交付前核对来源版本、镜头顺序与全场覆盖、每页最多6镜、八列及页头、台词音效时长的对应关系。文件规格及结果展示沿现有图片交付流程；是否可调用看图能力仍按[主技能边界](../../nora-ai-short-drama/SKILL.md#看图能力调用边界)，制作本表不另行取得查看其他图片或视频的授权。写入后按[交付前同步检查](../../nora-ai-short-drama/references/流程规范/项目浏览入口规范.md#交付前同步检查)核对本表及原工作稿入口。

本表只用于讨论，不作为[首帧或环境参考](首帧参考图规范.md#1-制作复用与画面要求)自动登记到视频输入。用户后续明确要求将某格用于实际生成参考时，按该素材实际用途另行准备、确认与登记，不直接把整张多镜表输入为单镜首帧。表格尚未制作或未选用，不影响原分镜及本集制作完成标准。
