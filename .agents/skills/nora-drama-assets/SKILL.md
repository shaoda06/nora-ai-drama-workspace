# Nora 资产设计

本技能承担 Nora 的当前业务交付。直接调用也遵循[主控读取范围](../nora-ai-short-drama/SKILL.md#读取范围)与[规则优先级](../nora-ai-short-drama/SKILL.md#外部技能协作与规则优先级)，不回主控重复走全流程。按当前任务选择下方入口；首次完整制作读完整适用要求和模板，局部修改只读受影响内容。方法库中的外部目录、配置、格式、发布及审批流程不替代Nora规则。写入前按[文件与版本](../nora-ai-short-drama/references/共用规则/文件版本与工作稿规范.md)的相关章节保存，交付按[主控完成标准](../nora-ai-short-drama/SKILL.md#完成标准)同步。

## 设计与交接

场景固定空间与持续状态在场景卡维护；当场动作造成的临时状态由剧本／分镜维护。[机位规划](references/场景资料与参考图规范.md#42-视图规划与复用)根据分镜观察方向、背景、遮挡和运动范围归纳复用，不预制全方向套装。场景卡记录视图方案，分镜记录本次选图，视频提示词的素材映射记录实际输入，按[采用边界](references/场景资料与参考图规范.md#43-场次采用记录与提示词边界)互相引用。

首帧构图与提示词由[分镜设计](../short-drama-storyboard/SKILL.md)负责，所需人物／环境／道具图由本技能提供；机位环境图不自动等于人物首帧。法宝或法术外观确需设计时，按需调用[玄幻专项](../sd-xuanhuan-engine/SKILL.md)的造型资料，不额外编造世界规则。

图片引用定位文件中已确认的完整美术正文，按[画风引用](references/Qwen-Image-2.1-提示词规范.md#16-项目画风正文引用)处理。只有表达问题时读取humanizer-zh；图片正文按实际选定的生成能力规则，不作普通文章润色。图片查看、生成选型及权限沿[主控边界](../nora-ai-short-drama/SKILL.md#看图能力调用边界)。内容准备好且获授权时交[生成执行](../nora-generation/SKILL.md)，工具负责技术装配和正常收尾。
