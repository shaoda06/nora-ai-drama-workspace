# 逐集专用素材规范

### 5. 补充本集专用素材与参考素材

用于讨论的[手绘导演分镜表](../../short-drama-storyboard/references/手绘导演分镜表规范.md)按其专项规则制作与保存，不自动作为本节首帧、环境或其他视频输入参考图登记。

制作或修订场景图、首帧图时，参考[镜头语言参考指南](../../short-drama-storyboard/references/镜头语言参考指南.md)中适用的静态表达方法：场景图按专项用途落实空间与观察关系，首帧落实首镜开始状态、构图和注意力中心。应用要求分别见[场景规范](场景资料与参考图规范.md)第4节和[首帧规范](../../short-drama-storyboard/references/首帧参考图规范.md)第1节；本集新增人物、服装及道具图沿用[图片制作步骤与文档分工](核心参考图制作规范.md#80-图片制作步骤与文档分工)的资产展示边界。

据本场分镜按[首帧规范第1节](../../short-drama-storyboard/references/首帧参考图规范.md#1-制作复用与画面要求)确定首帧及环境参考需求，再按[场景规范第4.2、4.3节](场景资料与参考图规范.md#42-视图规划与复用)落实所需选图、补图及实际采用记录。

本集新增人物、衣装及道具素材分别按[人物参考图规则](核心参考图制作规范.md#81-人物参考图)与[道具规范](道具资料与参考图规范.md)归位；剧集专用参考图按[逐集目录规范第2.1节](../../nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#21-剧集专用参考图)判断制作需求与存放，首帧任务读取[首帧规范](../../short-drama-storyboard/references/首帧参考图规范.md)。参考音视频的项目级分类、编号与来源记录执行[音视频管理规范](参考音视频管理规范.md)。

图片制作按[核心参考图入口](核心参考图制作规范.md#8-核心参考图)选择当前类型与已选能力。Imagegen生成／编辑、原图送审及获批后指定尺寸处理按[Imagegen专项](../../nora-generation/references/Imagegen生成与尺寸处理规范.md)执行；以下提示词格式与工作流限于Qwen分支。Qwen文生图按[文生图提示词规则](Qwen-Image-2.1-提示词规范.md#3-文生图规范与模板)及[文生图执行说明](../../nora-generation/references/ComfyUI-文生图执行规范.md)；带参考图生成首帧、衍生或修改按[衍生与合成规则](核心参考图制作规范.md#84-带参考图的衍生与合成)、[图像编辑提示词规则](Qwen-Image-2.1-提示词规范.md#4-图像编辑规范与模板)及[图生图执行说明](../../nora-generation/references/ComfyUI-图生图执行规范.md)。

分段制作前执行[首帧规范](../../short-drama-storyboard/references/首帧参考图规范.md)，确定首帧与环境参考的制作、复用和实际输入方案，落实到各分段素材映射；新旧任务衔接按该规范第6节执行。
