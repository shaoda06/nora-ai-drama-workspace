# 图片提示词规范

## 图片提示词

所有参考图先按[参考图用途与取景](核心参考图制作规范.md#参考图用途与取景)明确本图重点、必须可见的关系与取景边界，再填写对应模板；固定结构展示遵循该节及专用模板。

本文件维护Qwen与Imagegen共用的源参考图资格和修订规则；能力专有的提示词格式、种子及执行参数分别读取对应规范。

生成能力按[主入口选型](../../nora-ai-short-drama/SKILL.md#当前参考图生成选型)。先按本次任务读取下方[源参考图与输入资格](#源参考图与输入资格)及[参考图统一修订规则](#参考图统一修订规则)，再进入能力分支。已选Imagegen时按[Imagegen任务与提示词](../../nora-generation/references/Imagegen生成与尺寸处理规范.md#1-任务与提示词)复用对应类型的画面内容与资产依赖，尺寸及后处理按该专项，不强制使用Qwen专有格式或优化技能。仅编写提示词不触发生成。

场景图片先按[场景用途与状态归属](场景资料与参考图规范.md#40-图片用途与状态归属)明确用途，沿第4.2节核对机位需求与复用，再进入第4.1.1节选择生成分支。画面表达按[视觉表达方法](../../short-drama-storyboard/references/视觉表达方法规范.md#视觉表达方法)落实到实际取景、材质和光线，不因选用方法增加资产或执行步骤。

需要选择或细化构图、机位、光影及焦点时，调用[镜头语言与表达](../../camera-language/SKILL.md)，按本图用途写成静帧可见状态；其候选写法的首次使用提示与实际反馈复核同时适用，不改变已确认资产、首帧设计或模型格式。

人物图片有指定表情时，调用[表情拆解](../../facial-expression/SKILL.md)，把抽象词落成该静帧可见的面部状态；首帧、状态图、封面、头像及返修同样适用。首次实际使用告知与真实反馈更新沿该技能，已明确的面部描述直接复用；中性参考图不另加情绪。

## 源参考图与输入资格

本节适用于Qwen、Imagegen及各类图片的实际参考输入；具体类型需要哪些已批准上游素材，仍由对应资产、状态图或首帧规范确定，不能以通用参考替代必需上游。

- **明确本任务的原始输入。** 在既有输入清单或生成记录中固定源图文件、具体版本、实际顺序、逐张用途和保留范围。“源参考图”是本任务最初选定的原始输入，不是项目中最早的图片，也不是每轮最新结果。原文件保持不变；实际传图，文字提及或文件路径不能代替图片输入。
- **按资格使用。** 服装、场景、道具基础图及资产状态图允许使用用户提供并明确用于本任务的原参考图，不必先将该原图登记为正式资产；记录指定依据和采用范围，不将输入授权等同于整图正式采用。用户也可明确指定项目内适用的已批准图片。单纯上传、保留比较、生成成功或文件核对通过，都不自动授予输入资格；未批准候选不能由agent自行选为源图。
- **依据记录核对。** 输入身份、用途、版本、状态及批准依据优先复用已有真实记录。记录不足、版本冲突或文件变化时，只补查相应缺项；仍缺必要视觉信息时，按[看图边界](../../nora-ai-short-drama/SKILL.md#看图能力调用边界)先取得查看授权。本地能力边界优先于依赖技能中无条件逐图查看的通用建议；工具明确要求的编辑输入读取仍按主入口边界执行。没有实际查看，不把生成目标写成已验证的画面事实。
- **记录来源与实际输入。** 保留原图和工作副本之间的映射，以及本次输入槽位或工具参数中的真实关联；不另建重复台账。Qwen的输入种子核对按[种子规则](Qwen-Image-2.1-提示词规范.md#26-项目七类图片默认种子)，Imagegen未提供的参数如实记未提供，不套用Qwen种子要求。

## 参考图统一修订规则

本节是七类及补充参考图的共用修订真源，适用于Qwen与Imagegen。模板只承载实际生成正文与必要填写说明，不另设修订模板；能力特有的分支限制、格式、采样和尺寸按各自规范执行。

1. **根据反馈重写完整目标。** 在用户授权范围内记录具体问题、目标变化及保留项，将仍有效的已确认要求和最新反馈合并为本次完整提示词。不要只发送“修复上一张”或依赖项目历史才能理解的补丁指令；上一候选和审阅记录作为修订依据留档，不把管理信息送入模型。
2. **图生图每轮回到最初源图。** 使用本任务最初选定的同一组源图及具体版本，加上本轮完整提示词重新生成。V1产生后修订V2，仍输入最初选定的源图，不自动输入V1；即使中间结果获批，也不自动变成下一轮输入。用户说“继续修”“修复”不等于指定换源，不能据此或因agent判断某张错图接近目标，就沿错误结果逐轮打补丁。
3. **换源由用户明确指定。** 用户明确要求以某张新图或中间结果为输入时，才在允许的类型分支中更换源图，并在原输入记录注明文件、版本、用途及生效范围。另一制作任务可以明确选用已批准状态图等新来源；该新任务后续仍固定沿用其已选源图。能力切换也不自动改变源图或上游批准依赖。
4. **无源图的任务保持分支边界。** 文生图返修依据反馈修订完整提示词后重新生成，不自动把本任务结果改作图生图输入；确需改变分支时，须符合类型规则及用户对能力、输入和用途的明确选择。Qwen的具体分支限制见[Qwen修订分支](Qwen-Image-2.1-提示词规范.md#25-参考图统一修订规则)，Imagegen执行见[Imagegen规范](../../nora-generation/references/Imagegen生成与尺寸处理规范.md)。
5. **新结果重新交审。** 保留历次完整提示词、输入版本、实际参数、输出及用户决定；不覆盖历史请求或批准。新候选不继承源图或旧候选的采用状态，仍按[图片交付与用户审核](核心参考图制作规范.md#851-图片交付与用户审核)送审；授权次数、失败处理和完成范围不因本规则扩大。

## Qwen提示词编写

以下格式、参数与依赖要求限于Qwen分支，不覆盖上方共用规则。

- 编写、校对或修订Qwen提示词时，同时读取 `qwen-image-2-1-prompter` 和[Qwen提示词规范](Qwen-Image-2.1-提示词规范.md)。按[接入与适配](Qwen-Image-2.1-提示词规范.md#13-qwen-image-2-1-prompter接入与适配)选择T2I／Edit及API／Pipeline格式，按[中文规则](Qwen-Image-2.1-提示词规范.md#14-统一中文编写审阅与提交)编写、审阅和提交。仅换种子对照不改冻结正文。
- 按[专用模板索引](Qwen-Image-2.1-提示词规范.md#11-图片类型专用模板索引)选择七类图片或已列补充图片的生成方式和输入关系，不临时增类。服装、场景、道具状态图先读[统一状态规则](Qwen-Image-2.1-提示词规范.md#27-资产状态参考图统一规则)及其规格入口，虚拟道具基础界面读取[道具专项规则](道具资料与参考图规范.md#虚拟道具基础界面)。每种一份填写模板；生图模板不维护参考案例、待补位置或项目流水。
