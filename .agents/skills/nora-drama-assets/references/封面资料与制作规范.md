# 封面资料与制作规范

## 1. 用途与制作

封面用于项目展示、片头、介绍或视频发布；按实际需求制作系列通用或单集专用封面。由资产设计负责画面、文案、排版和素材依据，生成执行负责调用、结果登记及规格处理；不新增独立制作阶段。

按需讨论用途、文案、比例和目标尺寸，需求已清楚时直接制作。默认使用内置Imagegen，Qwen Image 2.1为备用；能力选择与切换沿[统一入口](../../nora-ai-short-drama/SKILL.md#当前参考图生成选型)，不重复定义。封面不新增项目固定种子类别。Qwen备用生图遵守现有32像素对齐接口约束，例如横版1536×1152、竖版1152×1536；这些是候选请求尺寸，正式成品仍按本次已定目标处理。

不设固定封面生图提示词模板。根据本次目标自由组织完整实际提示词，写清文案原文、画面与排版、参考图逐张用途和保留／变化范围，沿用项目已确认画风、人物及服装。保存实际提示词与真实输入，修改和重新生成沿[共用源图规则](图片提示词规范.md#参考图统一修订规则)。用户选定某图并指定据此延展时，记录该源图、版本和范围；新横竖版分别送审，不继承源图批准。

## 2. 规格与后处理

每个封面在制作时明确目标宽高、比例和格式；未另定时，横版1440×1080（4:3）、竖版1080×1440（3:4），PNG。这是工作区制作默认值，不作为平台官方固定像素要求。实际用途另有规格时按已确认要求执行。

生成原图完整保留，真实尺寸以文件为准，不把请求比例或文件名当作实际规格。候选送审与用户决定沿[图片交付规则](核心参考图制作规范.md#851-图片交付与用户审核)。

后处理只用于使分辨率、尺寸和比例达到本次目标；已达标直接核对保存，不默认超分。像素足够但需缩小、比例近似需指定尺寸适配时，使用既有图片后处理的[指定尺寸分支](../../nora-generation/references/ComfyUI-图片超分执行规范.md#imagegen原图的指定尺寸处理)，必须明确目标宽高；Qwen备用封面同样可用该指定尺寸分支，不套用其他资产的固定2倍要求。像素不足时才按实际需要超分。不为尺寸处理重新生图。明显改变构图的裁切、补画或扩图按本次用户授权作为修订处理。

用户批准的是具体原图。后处理完成后核对实际宽高、比例、格式和可解码性，记录原图、处理方式、结果及批准依据，再登记正式成品。原图与成品都保留，不把“画面已批准”写成“成品规格已达标”。项目原有不超分约定不免除目标尺寸和比例核对。

## 3. 项目级保存与记录

首次实际制作时建立 `10-封面资料/`，不为无封面项目预建空目录。通用封面只保存一份，单集专用图在名称和索引标注EP编号；用途不限定为发布。

```text
10-封面资料/
├── 封面索引.md
├── 正式封面/
│   └── {通用或EP编号}-{横版或竖版}封面.png
└── 其他资料/
    ├── 工作稿/
    │   ├── 封面制作-工作稿.md
    │   └── 素材/
    ├── 执行附件/
    └── 历史版本/
```

正式文件名如 `通用-横版封面.png`、`EP002-竖版封面.png`。候选使用 `{正式名去扩展名}-候选-vNN.png`，放工作稿素材目录；同名修改版本递增。实际并存多套方案时，在用途名中加已明确的方案名，不覆盖另一套采用图。已有候选在获授权迁移时可保留原名。

索引按[封面索引模板](../../nora-ai-short-drama/references/模板/封面索引模板.md)维护当前成品、采用原图、范围、目标规格、实际版本与批准／处理入口。工作稿按[封面制作工作稿模板](../../nora-ai-short-drama/references/模板/封面制作工作稿模板.md)记录生成、讨论、审阅和规格处理；这是记录格式，不是提示词模板。通用与单集封面共用本项目的一个工作稿，生成序号持续递增。

实际提示词、调用清单及响应归执行附件，候选原图归工作稿素材。用户采用后保留源图及批准记录，正式成品放正式封面目录；替换、旧候选结束及历史留存沿[状态收尾](核心参考图制作规范.md#852-图片采用替换与归档后的状态收尾)。

旧资料迁移先留存完整原状及路径对照，再更新现行链接；既有请求、响应和历史批准事实保持原字节，不追溯改写执行参数。旧入口提供新位置和原状留存入口，避免并行维护两份当前工作稿。

## 4. 固定工具与浏览入口

Imagegen沿[固定交接工具](../../nora-ai-short-drama/references/comfyui-scripts/README.md#imagegen子代理交接与固定收尾)，使用 `kind:封面`、本项目封面工作稿及本次自由编写的 `prompt`。Qwen备用沿现有统一装配入口使用同一登记类型；只保留模型接口必需格式，不新增封面提示词模板。规格处理沿原后处理入队入口，关联采用原图和明确目标尺寸，结果在原生成条目补处理记录。

浏览页读取封面索引、工作稿及真实图片尺寸，独立提供“封面资料”栏目：当前成品、采用原图、实际宽高／比例、用途／版本、记录与下载，以及折叠的历史候选。不从文件存在或目录位置推定采用批准。项目资料变更及工具结果的核验沿[交付同步](../../nora-ai-short-drama/references/流程规范/项目浏览入口规范.md#交付前同步检查)。
