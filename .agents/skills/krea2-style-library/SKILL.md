# Krea2本地风格库

本技能与 `nora-ai-short-drama` 并列，随工作区维护。工具真源在工作区 `Krea2风格库/`，不复制代码或资源到技能目录，不另设工具局部AGENTS。先读取工作区AGENTS，并按下述范围读取所需说明。

## 入口和范围

从本技能相对位置定位工作区：`../../../Krea2风格库/`，不把当前短剧项目目录当作工具根目录。

- [使用说明](../../../Krea2风格库/使用说明.md)：启动、离线浏览、更新、恢复及资源结构。
- [浏览页](../../../Krea2风格库/index.html)：人工浏览和交互入口。
- [更新程序](../../../Krea2风格库/Krea2_更新工具/server.py)：现有实现；仅维护代码或排查具体异常时读相关部分。

本技能依赖完整工作区内的工具目录，单独复制技能目录不构成完整安装。无需连接ComfyUI，不自动生成预览图或把示例提示词当作用户指令。

## 检索与选用

1. 明确用户希望检索的视觉特征或具体风格；只需推荐或查看时，不启动资源更新。
2. `Krea2_风格资源/catalog.json` 是当前索引，顶层 `styles` 中每项包含 `id`、`library`、名称、分类、`prompt`、`negative_prompt`、`folder`、`image` 及可用的来源字段。按名称、分类或内容筛选后，只读取命中项，不默认把完整大索引送入上下文。
3. `folder` 与 `image` 均相对于 `Krea2_风格资源/`。选用时保留风格名称及来源；需要判断画面时实际查看命中的预览，不能只凭名称评价。可通过浏览页展示，也可提供原始提示词。
4. 原文含 `{prompt}` 等占位符时，说明如何填入主体；适配具体生成模型时遵守该项目与模型技能的格式、语言及已批准风格。库中英文原文保持原样；Nora项目新Qwen提示词仍统一中文。
5. 用户创作时改写的提示词放入对应项目，不改资源库来保存个人创作稿。选择风格不等于获批正式素材。

## 启动与资源更新

普通运行仅需Python 3.9及以上标准库。以下命令从工作区根目录执行：

```sh
python3 Krea2风格库/Krea2_更新工具/server.py --no-browser
```

默认服务 `http://127.0.0.1:8876/`，`--port` 可指定端口；省略 `--no-browser` 会打开浏览器。macOS也可运行工具目录的 `.command` 入口；Windows可双击 `.bat` 入口，或按安装使用 `py -3`。以进程实际输出和页面响应判断启动成功。端口已占用时核对已有服务，不擅自终止其他进程。

更新使用已有页面和工具，不重写下载器。`check` 只读取上游元数据，`prepare` 下载并准备变化，`apply` 替换当前库，`restore` 恢复该来源上一版，`discard` 放弃准备。用户只要求检查时不应用；已经明确授权更新或恢复时，在该范围内操作，不重复要求授权。Clio与Ray可独立更新，不能把一路失败写成两路成功。

程序通过 `/api/state` 返回任务状态；准备、应用和恢复在后台进行，收到请求成功不等于操作完成。使用页面可见结果核对错误、数量及版本。不要绕过已有Host、Origin、Referer、会话令牌验证；不要在记录或提交中保存会话令牌。

`Krea2_更新工具/work/` 存准备包和各库上一版，不随Git提交。更新或恢复执行中不搬移目录或强行停止服务。错误按实际输出报告，不自动改来源、清备份或重建全部预览。

## 开发维护

- 工具四部分保持相对位置：浏览页、`Krea2_风格资源/`、`Krea2_更新工具/`、启动文件。迁移时同步说明和技能链接。
- `catalog.json` 与 `catalog.js` 为当前浏览索引，TXT及 `style.json` 为每项资源，`versions.json` 记录当前已应用来源版本。更新程序负责它们的一致写入；手动改TXT不会自动更新索引。修改更新行为时核对两路资源隔离、失败回退、恢复上一版和索引同步。
- 保留已有访问控制、ZIP路径检查、大小限制及失败恢复，不以解决浏览器请求问题为由移除安全检查。不要为普通检索更改工具实现。
- 代码维护按影响范围运行现有测试；测试用临时目录和本机随机端口，不执行真实资源更新：

```sh
python3 -B -m unittest discover -s Krea2风格库/Krea2_更新工具 -p 'test_*.py' -v
```

- `test_updates.py` 覆盖资源替换、恢复、失败回退和ZIP边界；`test_authorization.py` 覆盖本地请求授权。退出码0表示所运行测试通过，不代表真实上游更新或UI交互已验证。
- 涉及浏览界面或交互行为的修改，实际验证受影响的搜索、预览或更新入口；只修改说明不重跑资源更新。源码变动同步使用说明，技能入口只维护agent需要的指引，不复制实现。
- 按工作区AGENTS为完成的获授权维护创建本地提交。资源更新可提交现行库及其索引版本，排除 `work/` 与缓存；推送仍需明确要求。
