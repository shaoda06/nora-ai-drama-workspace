# 单集剧本制作规范

## 2. 本集故事剧本

扩写、修订及送审执行[用户原稿接续规则](../../nora-ai-short-drama/references/共用规则/创作定位与原稿规范.md#用户原稿的读取复用与确认)，原稿使用说明归入既有“编写依据”或其链接的审阅记录。

整集故事剧本使用[本集故事剧本模板](../../nora-ai-short-drama/references/模板/本集故事剧本模板.md)的固定正文，保存路径执行[逐集目录规范第2节](../../nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#2-正式文件与目录)。编写依据记录对应分集大纲入口及版本、制作前检查入口和必要的已确认调整。正文范围及下游接续执行[剧本、分镜与提示词的职责分工](../../nora-ai-short-drama/references/共用规则/创作职责与接续规范.md#剧本分镜与提示词的职责分工)；最终集以收束为主。“其他备注”填写[台词统计与节奏说明](对白与表演修订规范.md#台词设计节奏与统计)，其他补充按需填写。

按[层级编号规则](../../nora-ai-short-drama/references/共用规则/层级编号与时长规范.md#1-层级编号与时长)划分场次，逐场填写[本集故事剧本模板](../../nora-ai-short-drama/references/模板/本集故事剧本模板.md)的场头并保留稳定C编号；需要引用资料的管理信息写入编写依据或其他备注，不混入对白。

调用其他编剧技能或接续外部剧本时，先按实际声源对照[台词设计、节奏与统计](对白与表演修订规范.md#台词设计节奏与统计)，再写入本流程模板；不直接照搬外部的OS／VO字面标签。外部将OS用于现场画外对白时，按本流程实际声源分类转换；原话、说话者、时空及叙事性质保留，声音来源不明时先确认，不借格式转换改成心理独白或添加旁白。外部写作格式不替代本流程正式路径、编号及固定模板。

写作时在既有正文中落实以下要求，不另加场景评分表或写作阶段：

- 按[创作定位与爽感原则](../../nora-ai-short-drama/references/共用规则/创作定位与原稿规范.md#创作定位与爽感原则)承接本集大纲已经建立的期待，把阻力、人物出招、对方回应及结果演出来；具体场景按其任务选择，不要求每场都写成对抗。兑现时写清主角实际得到什么、主动权或关系如何变化，让观众看见并感受到结果，不能只让角色说一句“我赢了”或用旁人喝彩代替。快节奏优先压缩重复铺陈和同义争执，保留翻盘、情感变化及笑点落地所需的反应。
- 场景围绕人物此刻想做什么、遇到什么阻力、如何行动及发生何种变化展开；变化可以是目标进展、关系、信息、情绪或环境理解。建立空间、沉默和余韵有明确作用时可以保留，不要求场场正负价值翻转；重复同一信息且无其他作用的内容优先压缩。
- 用可见动作、可听声音和可表演反应表达心理与选择，不把抽象情绪词当作完整动作。人物卡和大纲可以解释心理；剧本将需要观众听见的心理活动写为OS，保留必要表演提示。可见动作和语言共同叙事，不以“画面表达”为由系统性压低台词数量。
- 台词结合说话目的、人物语言习惯、双方关系及已知信息。潜台词可由回避、停顿、动作和语境体现；直接认错、告知或表达情感同样可以有效，不为隐晦而隐晦。避免人物只为向观众讲设定而对话，也不机械删除推动当下行动所需的解释。
- 情节推进与情绪变化同时检查，重要选择或失去留出反应空间；不强制快慢交替，不用额外反转掩盖动机不足。开场、单集进展和结尾按[分集大纲填写规则](../../short-drama-develop/references/分集大纲规范.md#单集分集大纲填写规则)落实。
