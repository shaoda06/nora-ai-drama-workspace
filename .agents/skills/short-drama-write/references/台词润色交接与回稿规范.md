# 台词润色交接与回稿规范

### 豆包台词润色交接与回稿检查

流程为：**Codex照常完成并保存剧本初稿、提供交接提示词 → 用户将提示词交给豆包 → 豆包读取资料、只润色台词并另存完整剧本 → Codex对比检查、与用户讨论订正 → 用户批准 → 接续场次分镜。** 此交接属于本集剧本步骤，沿用既有会话、审批和授权；新写剧本默认执行，用户另有要求时按其要求处理，已有批准内容不自动重做。

#### 初稿与交接提示词

Codex按既有流程自检并保存初稿，交接直接引用现有文件，不额外搬动、复制或备份初稿。交付时填写[豆包交接提示词模板](../../nora-ai-short-drama/references/模板/豆包-台词润色交接提示词模板.md)，给用户完整可复制正文，并在本集剧本工作稿中留存交接指令。

提示词列出本机剧本、相关人物资料卡、本集及必要前后剧情资料的真实绝对路径。人物卡重点读性格、说话习惯和关系；前后剧情只读与本集有关的部分，不适用的资料删去。按模板说明读取资料、润色要求和另存位置即可，不复述剧本动作或附加逐项限制、版本管理及执行记录要求。

#### 润色范围与保存

豆包只润色台词，不改剧情和其他正文，使人物说话更接地气、更有看点和爽感，符合人物性格、前后接话自然；已有好台词保留。完整润色稿另存到本集 `其他资料/工作稿/EP编号-本集剧本-豆包润色稿.md`，原稿不动，保存完成后告知文件路径。

润色稿作为待审的外部回稿，后续订正沿用这份文件；讨论和审批仍记在本集剧本既有工作稿中，不另建同用途记录。

#### 回稿检查、批准与分镜接续

用户告知保存完成后，Codex直接读取原稿和润色稿，按[对白诊断范围与接续](对白与表演修订规范.md#对白诊断范围与接续)及[文本审查问题与交付](../../short-drama-review/references/文本审查与返修规范.md#文本审查问题与交付)对比检查，提出具体问题，再按讨论及授权订正。保留有效的生活口气和爽点，不因个人审美改回正经腔。版本、文档格式、资料链接、台词统计及时长等由Codex按既有规则处理，不堆进豆包交接提示词。

用户批准具体版本后，按既有采用规则同步正式剧本及批准依据；润色稿保留为当轮回稿，不并行维护另一份现行正文。分镜引用最终批准的剧本及台词，后续需改台词时仍按[职责分工](../../nora-ai-short-drama/references/共用规则/创作职责与接续规范.md#剧本分镜与提示词的职责分工)回写上游。
