# 本集制作与剧本接续规范

### 1. 创建本集制作目录

开始当前剧集时，按[逐集目录规范第1节](../../nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#1-单集根目录与过程文件)创建本集目录，已有目录只补缺，不覆盖文件；正式文件路径读取该规范第2节，视频执行目录读取第4、5节。

### 2. 本集制作前检查

本集准备时按[原稿接续规则](../../nora-ai-short-drama/references/共用规则/创作定位与原稿规范.md#用户原稿的读取复用与确认)核对相关材料，将影响本集的待决事项纳入本检查。

根据本集大纲与全局大纲，检查上一集结束时的人物位置、关系、情绪和已知信息；本集所需人物、场景、道具及服装、伤病、持有物状态；应承接或埋下的伏笔。第一集使用已确认开篇状态。

前集已有已确认故事剧本时，读取其正文及按[逐集内容制作规范第2节](单集剧本制作规范.md#2-本集故事剧本)整理的结束说明，并纳入后续已获批准的文本修订；分集大纲中的计划不代替实际写成的事实。前集尚无正式剧本时注明承接依据仍为规划，不虚构已发生状态。正文、备注或大纲冲突时核对批准依据并处理，不能静默选择；不另建并行状态库或记忆检查点。

正文使用[本集制作前检查模板](../../nora-ai-short-drama/references/模板/本集制作前检查模板.md)，只记录本集相关内容；不存在的问题写“无”，未知项写“待确认”，不虚构上一集或尚未具备的资料入口。

保存到 `01-制作前检查/EP编号-制作前检查.md`，属于本步骤正式检查产出，不因是检查文档就移入过程工作稿。固定章节与顺序使用所链接模板。前两章先展示当前结论、阻塞、需用户决定的问题、下一步及有效素材状态；缺项先于已就绪资料。创作要求与承接居中，依据及历史后置。状态变化时更新前两章，过往快照、已解决问题及过程记录集中到第6章，保留时间与当时结论，不混作当前要求；详细执行、审阅只引用原记录。记录实际入口／版本、重大冲突、后续需补资料及处理环节，不复制创作正文。影响当前扩写的冲突先解决；场次尚未划分而未建场景卡、尚未制作首帧等正常后续工作不阻塞剧本扩写。完成表示输入清楚、重大冲突处理、后续缺项有安排，不要求全部素材就绪，不新增例行检查的强制审批；需用户作创作决定时再确认。

### 3. 扩写本集故事剧本并明确场次需求

根据分集大纲扩写本集完整故事，并按[逐集制作规范第2节](单集剧本制作规范.md#2-本集故事剧本)填写整集正文、备注及编写依据；正式路径按逐集目录规范第2节保存。内容职责与接续边界执行[剧本、分镜与提示词的职责分工](../../nora-ai-short-drama/references/共用规则/创作职责与接续规范.md#剧本分镜与提示词的职责分工)。

新写本集剧本，或实质性修订场景、动作、对白前，由本技能按[编剧补充与表达润色](对白与表演修订规范.md#编剧补充与表达润色)选择与当前问题有关的参考资料，把方法落实到本集场景和对白。同轮按[山音方法的范围与适配](../../nora-ai-short-drama/references/共用规则/山音方法适配规范.md#山音方法的范围与适配)自动读取 `screenwriting-master` 的本集剧本方法，将结果合并落实到当前正文；仅改错字、格式或制作记录时不因本步骤加载上述技能。

初稿完成后或改稿送审前，结合本节既有文本检查核对表达；发现空泛、拗口、重复解释、模板句或人物台词口吻趋同，或用户明确要求润色时，再读取 `humanizer-zh`，按同一方法章节处理具体段落。有明确作用的原句保留；未发现问题时不强行润色，不增加独立阶段或审批。

整集剧本初稿或涉及场景、动作、对白的实质性修订完成后、送审前，默认读取 `dialogue` 的实际安装入口，按[对白诊断范围与接续](对白与表演修订规范.md#对白诊断范围与接续)确定整集、完整交流或受影响场次的范围，再用同一方法章节诊断人物声音、接话、解释和情绪节奏，再由本轮编写者订正；不要只抽查一句是否口语化。将诊断与[文本交付前自检](../../short-drama-review/references/文本自检与订正规范.md#文本交付前的自检与订正)合并执行，不在诊断后重做同一范围的完整审查。仅改错字、格式或制作记录且不改变语义、语气或接话关系时，不触发对白诊断。

本步骤按[台词设计、节奏与统计](对白与表演修订规范.md#台词设计节奏与统计)核对声音叙事及统计，按[文本自检与订正](../../short-drama-review/references/文本自检与订正规范.md#文本交付前的自检与订正)处理问题后交付；正文完成范围由上方职责分工维护。

初稿交付时按[豆包台词润色交接与回稿检查](台词润色交接与回稿规范.md#豆包台词润色交接与回稿检查)同时提供本机文件交接提示词，并在本步骤接续豆包保存后的检查、讨论订正及剧本批准；不将初稿完成或自检通过直接当作进入分镜的依据。

在整集正文中按[故事剧本规则](单集剧本制作规范.md#2-本集故事剧本)编排场次，再核对本集人物出场造型需求，交08按[人物制作时机](../../nora-drama-assets/references/核心参考图制作规范.md#固定制作流程与阶段分工)准备或复用。文字设计缺项先回04处理，参考图未就绪不阻塞不依赖它的剧本或分镜工作。

单集故事剧本明确后，按[道具规范第1节](../../nora-drama-assets/references/道具资料与参考图规范.md#1-制作时机与资产身份)区分文字表达与需建卡、制图的实际需求，再处理对应设计缺项及素材复用。

场次划分后，整理本集空间、状态及取景需求，按[场景规范第1节](../../nora-drama-assets/references/场景资料与参考图规范.md#1-阶段归属与制作顺序)接续资料卡与环境图任务；分镜形成后按该规范第4.2节完成机位归纳、复用与补图，第4.3节完成镜头到实际生成输入的对应；总览与机位图用途见第4.0节。
