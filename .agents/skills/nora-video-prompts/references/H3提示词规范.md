# H3提示词规范

## H3提示词

读取[视觉表达方法](../../short-drama-storyboard/references/视觉表达方法规范.md#视觉表达方法)，并从[分段视频提示词章节](视频提示词制作规范.md#6-分段视频提示词文档)定位P段、采用素材与对应模板；实际编写与检查按[执行顺序](视频提示词制作规范.md#提示词编写与检查顺序)完成，不以读取入口替代执行。

编写或修改H3提示词时，读取 `h3-prompt-writing` 对应实际输入模式的官方指南，按本流程[语言与命名适配](视频提示词制作规范.md#h3模型正文的语言与命名)及[切镜与接续表达](视频提示词制作规范.md#h3切镜与接续表达)落实到模板；当前多参考工作流优先使用Ref2VA。不另复制官方提示词规范，技能缺失时说明，不能声称已按官方规范完成。

Ref2VA同时执行[参考定义与保留说明](视频提示词制作规范.md#ref2va参考定义与保留说明)，将参考来源、保留内容和镜头过程分别落实到对应章节；完成后按[内容核对](视频提示词制作规范.md#模型正文的内容核对)复核实际拼接正文及同版中文。
