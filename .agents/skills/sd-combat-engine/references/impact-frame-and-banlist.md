> **来源**：吸收自用户提供的玄幻一镜到底参考稿。

## 一、冲击帧分级（Impact Frame Grading）

> **一句话：打击的"分量"要靠画面的冲击表现分级，让观众用眼睛"听懂"这一下有多重。**

| 级别 | 触发 | 表现 | 白闪 |
|---|---|---|---|
| **一级** | 普攻、普通命中、格挡 | 单帧硬直 / 局部火花 / 轻震屏 | 无 |
| **二级** | 技能命中、落地、多杀、破防 | 明显震屏 + 冲击波环 + 介质飞散（碎光/碎屑/烟尘） | 无 |
| **三级** | 大招爆发、终结技、全屏清场 | 强震屏 + 大面积冲击波 + 光爆 | **3 帧连续白闪** |

**选用提示（风格示例，不是每次命中的配额）**：

1. **分级 = 叙事权重**：一级是节拍（叙事里的"点"），二级是重音（"顿"），三级是爆点（"轰"）。按所需重音选择使用次数，检查是否淹没其他信息；
2. **白闪的取舍**：白闪可强调过曝式冲击，是否使用取决于风格与可读性，不按级别一律禁用；
3. **细节的呈现**：关键瞬间先检查现有景别能否看清，再决定是否切特写；冲击帧另按强调需要选用，两者不强制绑定。

**写法（自然句，禁工程标记）**：
```
✅ "刀锋切入甲胄的瞬间，画面一震，碎光沿冲击环向外炸开"
❌ "★三级冲击帧 + 3帧白闪"（工程标记，模型不理解）
```

**与总控的关系**：冲击帧是 `short-drama-director/references/camera-specs-15rules.md`「镜头五要素」中"受力反馈"的增强；与 `sd-xuanhuan-engine/references/core-combat-laws.md`「一镜一动一反馈」的"反馈"对齐——**每个动作都要有反馈，冲击帧是反馈强度的标尺**。

## 二、战斗段负面词库（Battle Banlist）

> **用法**：负面提示词每镜必含**本镜最易崩的特点**——**按镜写进该镜的镜行描法里**（打戏最易崩点各不相同），**不是把整张词库堆进段7**。段7【强制禁止项】**保持极简四项**（`画面：禁字幕、禁水印（含 Logo）；音频：禁背景音乐、禁旁白`，见 `model-adapters.md` §5）；仅当本场确有某类穿帮史（如多人场面分身高发）时，才从下表中挑 **1~2 条**追加进段7 并在交付说明写理由。**栏目纪律照旧**：禁止项只装负面清单，正向指令禁入（C19e）。

### 2.1 节奏与摄影选择

空镜、建立镜头、对峙、慢放、定格、静止机位、匀速平推和人物出画均不是通用负面词。按 `combat-iron-laws.md` 铁律7、8、45检查具体的信息缺失、动作误读或非预期变化，不把合法拍法加入禁用清单。

### 2.2 连续镜头与剪辑

已选择一镜到底时，核对连续路径与动作衔接，避免非预期切镜；未选一镜到底时，硬切和多机位剪辑可正常使用。空镜、背影、定格与黑场按剧情及结尾需要选择，不因出现这些形式判失败。

### 2.3 群体/规模类

```
场上只有三五只敌人，敌人数量越来越少，数量稀少，背景空荡，主角对着空气打，
敌人无反应，敌人无前摇
```

### 2.4 特效/受力类

```
特效漂浮无触发源，特效遮挡面部，特效无受力实体，
Z型轨迹断裂，音爆缺失
```

### 2.5 武器/形态类（有武器变形时）

```
单剑中途消失，双刀合并回单剑，强行三刀，凭空多出一把武器，副武器，
武器中途再变形，武器凭空换模，分化演出被省略
```

### 2.6 角色/肢体类

```
角色崩坏变形，肢体扭曲，多指，融图糊成一团，角色面瘫无表情，
畸形手部，多余手臂
```

### 2.7 色彩串色类（有阵营色锁时）

```
敌人被染成暖色/主角色，主角光效变成冷色/敌色，阵营色互串
```

### 2.8 平台合规类（通用，见 `short-drama-director/references/platform-safety-compliance-guide.md`）

```
红色血液，伤口特写，断肢，血雾，怪物化为液体
```

### 2.9 画面瑕疵类（低关联，走否定式兜底即可）

```
UI界面，字幕，水印，背景音乐
```

> **⚠️ 栏目纪律提醒**：以上词条写进【强制禁止项】时，**只列负面**；正向执行指令（如"主角恒为暖色"）**禁入该栏**，回落【画幅风格】/镜行（C19e，见 `short-drama-director/references/model-adapters.md` §5.0.4）。**低关联瑕疵**（水印/变形）与**高关联视觉概念**（发光/笑/空镜）处理方式不同：前者否定式兜底即可，后者必须换词（被禁词根零出现）。
