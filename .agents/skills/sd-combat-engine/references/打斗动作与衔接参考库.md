# 打斗动作与衔接参考库

用于缺少动作变化、近身过程、受击反馈或收招接续时选择候选。已有[招式库](moves-library.md)覆盖的动作直接复用；下表补充选用和衔接方法，不要求每场全部采用，也不固定一招一镜。

| 动作用途 | 可见过程 | 适用条件与结束状态 |
| --- | --- | --- |
| 缩短距离 | 蹬地前移、低重心滑步或跃起前压，方向和落点明确 | 先交代距离与对手反应；抵达可攻击位置后接实际攻防，残影只辅助速度 |
| 闪避后反击 | 侧移、收肩或后仰避开具体攻击，再从重心恢复处反制 | 交代兵器擦过的位置和空隙；不能在闪避结束前凭空回到攻击姿态 |
| 腾空踢击 | 起跳、转髋、伸腿、接触、受力及落地 | 持物与支撑关系一致；落点为下一动作提供依据 |
| 贴身短打 | 进攻引出防守，防守形成下一次出手机会 | 选择实际能看清的动作链，必要停顿与反应由戏剧任务决定 |
| 兵器交锋 | 握持、出刃、接触、拨格与回收 | 拔刀动作须有刀鞘及收刀状态依据；不把名称当作完整动作 |
| 蓄力爆发 | 稳住支撑、身体传力、出击和受击反馈 | 力量落实到身体与接触；衣料、飞尘伴随运动，不遮住关键接触 |
| 拉开与收势 | 顺势撤步或被击退，恢复平衡并观察对方 | 保留位移、伤势与持物结果，按剧情接追击、斗法或停战 |

写作时确定人物目的与动作后果；分镜时确定可见过程、机位和镜长；模型正文阶段按已确认镜头转写。视觉示例的背景、画风、颜色和人物不作为项目固定设定。
