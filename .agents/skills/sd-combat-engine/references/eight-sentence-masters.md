# 八类自然句母版（按镜头需要参考）

以下句式帮助把选定画面写清，不要求每镜套一种或把所有要素塞满。固定观察、静止反应及未列出的拍法同样成立；按 Nora 正式模板写入既有字段，镜头选择见 `combat-iron-laws.md` 铁律7。

---

## 1) 宏观揭示句

**语序公式**：机位焦段景别 → 画框分区(天空/地面/上中下层各占几成) → 大环境 → 特效主体(材质+规模四件套) → 极小人物位置 → 镜头运动反应。

用途：证规模。开场铺规模、大招成型全景、EWS 展示。

示例骨架："18mm 极端超广角高空远景，上层八成五被遮天剑群占据、下层一成五是地面战场，万柄冷银飞剑横跨数公里如银色星河，修士悬于剑群正下方仅占画面1%如蝼蚁，镜头缓慢后拉展全貌。"

## 2) 动作-特效释放句

**语序公式**：人物发力链动作 → 特效从肢体/武器长出(材质+形态) → 沿明确轴线飞行 → 命中目标 → 三层反馈 → 环境结果。

用途：证招式与轨迹。每镜核心句。

示例骨架："刀客沉腰蹬地拧腰挥臂，刀身拖出墨黑三层刀气（主体墨黑流体+边缘暗红血纹+表面紫色电弧噼啪缠绕）沿斜向轨迹劈落，命中剑修横架的刀面，三层爆开+地面犁出焦黑沟壑。"

## 3) 打击反馈句

**语序公式**：接触瞬间+顿帧冲击帧 → 受力体形变 → 位移 → 三层粒子 → 环境连锁 → 镜头受力。

用途：证力量。按需要选取可见反馈，不要求每次命中叠加顿帧和镜头受力，与铁律11物理反馈链同构。

示例骨架："剑锋劈中的同一瞬，护盾从接触点炸裂、一圈白色音爆环贴地推开，受击者身体弓成C型被轰飞数丈，炽白核心→青蓝雾化→黑灰碎片顺重力飞溅，地面蛛网状龟裂，镜头被撞得后挫。"

## 4) 蓄力压缩句

**语序公式**：手/眼/刃特写 → 粒子从八方螺旋汇聚 → 材质微观细节 → 临界万物悬停(升格/子弹时间) → 镜头微震蓄压。

用途：需要强调蓄力过程时可参考。时长和固定或运动的选择按铁律7、8，不为蓄力强加环绕、微震或环境动作。

示例骨架："50mm 钉在剑尖，千万道雷弧流光从剑柄根部向剑尖疯狂收束、空气高频扭曲鸣叫，临界一瞬碎片悬停、升格定格，镜头微震蓄压。"

## 5) 尺度证明句

**语序公式**：先给参照物/画框锁规模 → 让特效做一个能对比的动作(扫过云层/切开雪雾/吞没建筑/压过山岳巨物) → 再给极小人物位置二次确认。

用途：证规模。禁止只喊"巨大/终结级"；与铁律19尺度四件套配套，规模必须持续证明、不是一帧喊大。

示例骨架："剑气从远景深处直冲近景，径直将黄昏天际的金橙云层整齐一分为二，同时剑气扫过地面犁出一道数米宽、贯穿全画面的深邃沟壑，刀客在剑气根部仅剩一个黑点。"

## 6) 追尾位移句

**语序公式**：位移起法(蹬/踏/借力点+碎裂反馈) → 长距离方向跨度 → 拖尾残影 → 原位置被追来的攻击打爆 → 镜头滞后追赶/被甩出画框。

用途：证速度。瞬移/高速位移/突围段专用（与铁律28态四、铁律34瞬移甩镜配套）。

示例骨架："剑修脚尖点碎瓦砾蹬射而出，身形化作四五道水墨残影横贯半个战场，原位瞬间被追来的刀气打爆掀起尘浪，镜头滞后半拍急摇补抓，人物已冲出画框。"

## 7) 群体结构句

**语序公式**：先定义群体组织结构(几路/几层/前部中部尾部) → 整体运动方式(鱼群/潮水/星河同相位) → 个体在结构里分工 → 镜头停在群体外部看整体轮廓不追单个。

用途：需要展示群体结构时可用（与铁律27③配套）。禁止"密密麻麻糊一团"；个体近景按动作、反应或叙事重点选用。

示例骨架："万剑分五路立体群流，每路前部数百把剑组成前后错层的群体锋线、中部上下换层斜向补位、后部持续追入回填，整体如高速迁徙的巨型鱼群星河同步转向，镜头停在剑群外部拍宽度厚度纵深。"

## 8) 收势/延迟揭示句

**语序公式**：动作收束(入鞘/合扇/咔哒) → 极短时间冻结 → 裂纹/效果延迟蔓延 → 延迟爆发或粒子逆流回收 → 镜头匀速拉远留动态背影与被改变的世界。

用途：需要延迟揭示的结尾可选，不排除同框、静止或其他结束方式（与铁律10、7种标准收束模式衔接，收束模式表见 syntax-corpus.md）。

示例骨架："长剑缓缓入鞘，剑格闭合'咔哒'轻响的瞬间，背后的空间才反应过来——一道巨大剑芒瞬间爆开、从左下至右上将背景彻底撕裂；镜头匀速拉远，胜者背影立于崩塌的山门前。"

## 出稿前每镜自问清单（任一答不上这句就是空话、重写）

1. 这镜任务是什么？（证规模/证力量/证速度/证招式/证轨迹/证情绪，一镜一主任务）
2. 观众站哪？（机位此刻在哪个空间位置、对准什么、固定观察或运动到哪）
3. 特效什么材质、分几层、占画框多少、对照什么参照物、人物在画框哪个位置？（铁律19四件套）
4. 力从哪起、作用到哪里？（交代需要的身体与环境反馈，镜头可稳定或运动）
5. 固定或运动分别服务什么观看作用？（不要求运动方向等于事件方向）
6. 和上镜怎么接、给下镜留什么？（末帧接首帧；隐形剪辑点/钩子）

## 配套硬规矩

- **词汇回落句**：每个强词（炸裂/吞没/坍缩/翻涌/螺旋/音爆环/犁沟/虫视/暴拉/Whip Pan）必须带①搭配对象②句中位置③服务的画面，回落到完整句。词库只负责供词，不限制成句必须采用这八类。
- **句法养料**：写镜前按任务类型（题材/运镜/收束/节奏）查 `syntax-corpus.md` 提取骨架、替换参数、熔成自然句，参考不抄袭。
- **优先级**：字段式vs自然句——脑内可以按字段想，落字一律自然句（用户硬要求，无例外）。
