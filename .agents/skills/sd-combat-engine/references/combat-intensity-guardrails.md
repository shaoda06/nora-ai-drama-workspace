# 打戏力度与节奏参考

本库用于检查“设计的动作是否真正发生、必要受力是否可见”。不把某种拍法当作失败，不把单一样本经验当作所有模型的能力边界。镜头选择执行[场次分镜制作规范](../../short-drama-storyboard/references/场次分镜制作规范.md)；本文件维护交锋节奏的条件性默认建议，反馈分级见[铁律11](combat-iron-laws.md#铁律11物理反馈链方向性震屏)，动作负荷与已有反馈的验证边界见[节奏与动作负荷](combat-rhythm-and-load-guardrails.md)。

## 一、表达目标先于强度指标

根据剧本判断本段是交锋、试探、相持、潜伏、追逐、施法还是余波。先用符合本段目标的默认建议起稿，再根据人物能力、动作因果、项目风格和观看效果调整；采用其他拍法时，正文仍须完成同一表达任务。快慢、接触次数、人物位移和摄影机运动都服务这个目标；不设快打占比、首半秒接触、静止上限或相邻构图必须变化的指标。

## 二、对抗可读性

近身交锋核对谁攻击、谁防守、接触在哪里、受力和后续动作是否衔接。若本来要打却写成没有变化的摆姿势，指出缺失的动作。若剧情本来是相持、瞄准、观察或对峙，不为“激烈度”增加刺中、击飞或强迫双方移动。

**连续激烈交锋**：优先按正常速度连贯展开攻防，用格挡回弹、收手护身、撤步避让和趁隙追击连接下一招；避免每次接触后无缘由复位、等对方摆好姿势，或每击都减速而耗掉压迫感。这里的“正常速度”指动作按设计速度播放，不排斥招式本身快慢不同，也不要求双方轮流命中。试探、角力、受创恢复或情绪转折需要停顿时保留相应过程。

例如，甲横扫落空、兵器尚未回收，乙沿空当跨步逼近；甲撤步翻转柄尾架住来剑，受压后继续后移，乙顺势追进。后续动作由前一拍的位置、动量和兵器关系引出，不重新演一次起手。格挡偏转、落地滑移、失衡与恢复也可成为接续点；需要看清判断或蓄势时，保留相应反应。连贯招式与多项独立任务的负荷区别按[动作负荷](combat-rhythm-and-load-guardrails.md#一动作负荷)判断，不按动词或切镜数量决定快慢。此例是设计候选，具体模型执行未验证。

**近身动作的底稿**：先读不含装饰特效的动作句，仍应看得出进攻、防守、接触或有效避让以及局势变化；再用适用风格的声效、冲击帧、介质反应加强重点。已有出片反馈记录过“对峙、特效、对峙、特效”取代本应发生的近身交锋，因此不能以特效密度或运镜幅度代替打斗。该提醒不用于否定本来就依靠法术作用的斗法或静态相持。

**轻重有层次**：按[反馈分级](combat-iron-laws.md#反馈分级按能力防御材质与所选风格取用)选择实际承力对象和结果，把差异落实到动作与画面。对比试探、实打与决胜时，不只换“猛烈、剧烈”等形容词，也不让每一击都使用同样的最强强调。

远程法术、枪战和威慑不要求贴身接触。重复构图能呈现持续压力或力量对比时可保留；仅在遮蔽信息或损害节奏时修改。

## 三、慢放、定格与闪帧

以速度和压迫为主要体验的交锋，默认保留连续的常速动作，只在值得读清的细节、关键受力或感知转折处考虑慢放、顿帧或闪帧；用后检查进入和退出是否打断攻防。全段慢放适合突出细节、主观感受或仪式感等目标，不是激烈快打的默认解。按实际强调需要使用，不按片长分配次数。它们不是必需的“减速器”，也不是默认禁用项；固定机位、人物静止、画面定格和慢动作须分别描述。采用某种画风的闪帧时按该项目已选风格落实。

## 四、打戏节奏零件库

### 4.1 可选零件

蓄势、快打、转折、慢放、静默与爆发都是候选；无需每场齐全，也不固定哪项必选。静可以来自固定观察和人物停留，不必叠加黑白闪；收束可以克制或留白，不必用爆发。

### 4.2 首中尾的观看作用

开头按实际起点进入，可以先建立空间或直接进入动作。中段交代本段需要的攻防和局势；结尾承接结果、情绪或悬念。不能为了首中尾公式改写故事或强制换镜、加动作。

声音可在已允许的声源范围内配合交锋、蓄势与余波：以接触时点强调实打，按需要疏开连续冲击声，让呼吸或武器蓄能声成为注意中心，爆发后交代落地与残余声。具体安排沿[声景与配乐](../../short-drama-storyboard/references/场次分镜制作规范.md#声景与配乐)，不默认铺环境底声或配乐。降低某个声源、声音渐弱和全部静音分别表达，不固定要求抽空某个时长。

### 4.3 参考组合范式（★可拆可改 · 按戏份选用，禁止当模板照套）

**以下范式只是若干条合法组合，不是必答题**——出稿时可跨范式混拼，也可自创（保持 §4.2 的首中尾作用及本段实际因果）。

| 范式 | 零件序列 | 适合什么戏 | 备注 |
|---|---|---|---|
| **A. 经典反杀型** | 蓄 → 快 → 停 → 快 → 慢 → 静 → 爆 | 强者压境 → 主角受创 → 绝境觉醒 → 大招终结 | 六件齐全的重装组合，信息量最大，适合 15~30 秒；**不是唯一解** |
| **B. 快打碾压型** | 快 → 快 → 停 → 爆 | 实力碾压、秒杀、开场立威 | 几乎全程对攻，无情感段；"打来打去"感最强 |
| **C. 双强对攻型** | 快 → 停 → 快 → 停 → 爆 | 势均力敌的宿敌对决 | 多轮攻防互换，【停】可循环多次 |
| **D. 蓄势一击型** | 蓄 → 静 → 爆 | 极短杀手锏、一击必杀、狙击式偷袭 | 靠极静制造压强、靠爆释放；**适合 5~8 秒超短片** |
| **E. 群战乱斗型** | 快 → 快 → 快 → 停 → 爆 | 多人混战、围杀、突围 | 优先交代多向威胁与破围路径；可快切，也可连续调度 |
| **F. 高密度仙侠对决型** | 强碰 → 连续攻防与借势换位 → 判断／蓄势 → 终招对抗 → 结果 | 已确定双方终招的短片对决或高潮段 | 用交锋后果推动换位或换场，按必要信息安排短镜与反应停留；结果沿既定胜负或平局，不固定片长、镜数或每镜动作量。具体模型执行未验证 |

**组合的三个自由度**：
- **循环**：`快-停-快-停-…-爆`——可用于势均力敌的戏，不必凑齐慢/静；
- **合并**：`慢+静` 可合为一拍（短片常见）；`静+爆` 直连是最凶的排列（压强最大）；
- **省略**：没有情感诉求就砍【慢】；没有反转就砍【停】；追求极速就砍【蓄】——时长重新按剧情需要分配。

## 五、交付前自检

按本段目标连读动作、受力和空间：要求高速的段落有无无故复位或反复减速；要求分出轻重的段落是否只有形容词不同；多人是否只在人数说明里形成威胁。发现问题，订正对应动作、取景、时长或反馈；只写“未采用配额”不能代替这些检查。相邻机位相同、没有慢放、没有快切或结尾平静都不单独构成问题。修改意见须对应具体表达损失，并入现有自检。

## 六、参考检查的适用范围

旧 C21 的位移、接触比例、构图变化计数来自特定肉搏样本，不作为 Nora 的通用门槛。近景连招、多人、远程、大场面及静慢段均按实际需要选择，无需申请豁免；历史告警只能提示人工复核，不能迫使改变合理拍法。动作负荷和景别检查归并见 `combat-rhythm-and-load-guardrails.md`。
