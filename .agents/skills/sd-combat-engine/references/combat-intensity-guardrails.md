# 打戏力度与节奏参考

本库来自近身对拆的历史反馈，用于检查“设计的动作是否真正发生、必要受力是否可见”。不把某种拍法当作失败，不把单一样本经验当作所有模型的能力边界。镜头与节奏选择以[场次分镜制作规范](../../short-drama-storyboard/references/场次分镜制作规范.md)和 `combat-iron-laws.md` 铁律7、8、45为准。

## 一、表达目标先于强度指标

根据剧本判断本段是交锋、试探、相持、潜伏、追逐、施法还是余波。快慢、接触次数、人物位移和摄影机运动都服务这个目标；不设快打占比、首半秒接触、静止上限或相邻构图必须变化的指标。

## 二、对抗可读性

近身交锋核对谁攻击、谁防守、接触在哪里、受力和后续动作是否衔接。若本来要打却写成没有变化的摆姿势，指出缺失的动作。若剧情本来是相持、瞄准、观察或对峙，不为“激烈度”增加刺中、击飞或强迫双方移动。

远程法术、枪战和威慑不要求贴身接触。重复构图能呈现持续压力或力量对比时可保留；仅在遮蔽信息或损害节奏时修改。

## 三、慢放、定格与闪帧

按实际强调需要使用，不按片长分配次数。它们不是必需的“减速器”，也不是默认禁用项；固定机位、人物静止、画面定格和慢动作须分别描述。采用某种画风的闪帧时按该项目已选风格落实。

## 四、打戏节奏零件库

### 4.1 可选零件

蓄势、快打、转折、慢放、静默与爆发都是候选；无需每场齐全，也不固定哪项必选。静可以来自固定观察和人物停留，不必叠加黑白闪；收束可以克制或留白，不必用爆发。

### 4.2 首中尾的观看作用

开头按实际起点进入，可以先建立空间或直接进入动作。中段交代本段需要的攻防和局势；结尾承接结果、情绪或悬念。不能为了首中尾公式改写故事或强制换镜、加动作。

### 4.3 参考组合范式（★可拆可改 · 按戏份选用，禁止当模板照套）

**以下范式只是若干条合法组合，不是必答题**——出稿时可跨范式混拼，也可自创（满足 §4.2 三铁律即可）。

| 范式 | 零件序列 | 适合什么戏 | 备注 |
|---|---|---|---|
| **A. 经典反杀型** | 蓄 → 快 → 停 → 快 → 慢 → 静 → 爆 | 强者压境 → 主角受创 → 绝境觉醒 → 大招终结 | 六件齐全的重装组合，信息量最大，适合 15~30 秒；**不是唯一解** |
| **B. 快打碾压型** | 快 → 快 → 停 → 爆 | 实力碾压、秒杀、开场立威 | 几乎全程对攻，无情感段；"打来打去"感最强 |
| **C. 双强对攻型** | 快 → 停 → 快 → 停 → 爆 | 势均力敌的宿敌对决 | 多轮攻防互换，【停】可循环多次 |
| **D. 蓄势一击型** | 蓄 → 静 → 爆 | 极短杀手锏、一击必杀、狙击式偷袭 | 靠极静制造压强、靠爆释放；**适合 5~8 秒超短片** |
| **E. 群战乱斗型** | 快 → 快 → 快 → 停 → 爆 | 多人混战、围杀、突围 | 靠镜头快切与空间调度替代情感段 |

**组合的三个自由度**：
- **循环**：`快-停-快-停-…-爆`——可用于势均力敌的戏，不必凑齐慢/静；
- **合并**：`慢+静` 可合为一拍（短片常见）；`静+爆` 直连是最凶的排列（压强最大）；
- **省略**：没有情感诉求就砍【慢】；没有反转就砍【停】；追求极速就砍【蓄】——时长重新按剧情需要分配。

## 五、交付前自检

按本段目标核对动作、受力和空间是否可读，力度与节奏是否达到预期。相邻机位相同、没有慢放、没有快切或结尾平静都不单独构成问题。修改意见须对应具体表达损失，并入现有自检。

## 六、参考检查的适用范围

旧 C21 的位移、接触比例、构图变化计数来自特定肉搏样本，不作为 Nora 的通用门槛。近景连招、多人、远程、大场面及静慢段均按实际需要选择，无需申请豁免；历史告警只能提示人工复核，不能迫使改变合理拍法。动作负荷和景别检查归并见 `combat-rhythm-and-load-guardrails.md`。
