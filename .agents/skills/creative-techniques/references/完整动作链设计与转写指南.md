# 完整动作链设计与转写指南

版本：v1.0；更新日期：2026-10-28。

## 1. 用途与适用范围

本指南把一个事件从动作设计、镜头组织、参考分工到模型正文转写及连读检查放在同一条链中。适用于投掷、递接、拿放、开门、起坐等有明确状态变化的事件，尤其是同一次动作跨镜头、画外状态参与接续，或镜头切换容易造成重复、跳步、物件复原的段落。一个连续长镜头也可按同样方法组织起点、过程和结果，不必为了使用本指南拆镜。

**完整动作链**指观众理解事件所需的起始关系、动作因果、结果及必要反应连续成立。它可以包含多个小动作，也可以省略无关过程；镜头数量、身体动作数量和事件发生次数分别判断。两个角度展示同一次出手，不等于人物重新抱球再投一次。剧情有意重放、重复动作或制造错误示例时，保留该意图，明确重复发生在演示、剪辑还是现实事件中。

本指南提供完整组织方法，具体镜号、字段、P段、审批和模型格式沿既有业务规则。分镜落实到[场次分镜既有字段](../../short-drama-storyboard/references/场次分镜制作规范.md#景别选项与镜头字段分工)，模型正文按[视频提示词制作规范](../../nora-video-prompts/references/视频提示词制作规范.md#6-分段视频提示词文档)转写；打戏的攻防、受力与招式机制沿[专业方法归属](../SKILL.md#主题归属)。无需新建动作编号、状态台账、审批表或额外生成测试。

## 2. 从事件到镜头再到正文的完整方法

### 2.1 先确定观众要看懂的事件

用一句清楚的话确定目标：谁对什么做了什么，最后什么状态发生改变，观众必须在哪一刻理解这一变化。若有隐藏信息、故意误导、可视化或现实层切换，同时明确可见范围和揭示时点；不能为了交代完整而提前泄露剧情。

贯穿示例P011的目标是展示一次拍法正确的投篮：先看清人物与目标，女主瞄准并完成一次出手，同一颗球入筐，她确认进球并作出反应。五镜属于讨论分镜时的可视化，结束后下一段才回到长凳旁的现实状态。

### 2.2 把事件连成状态变化，再确定哪些过程需要展示

先在脑中或现有正文中顺着事件推演：人物在哪里、身体和视线朝哪里，关键物件由谁持有、位于哪里；什么动作使状态改变，改变后留下什么结果。只写影响理解或接续的内容，不逐镜抄全场设定。

P011的整条链为：

**罚球线站定、球从手边落下 → 球触地一次后被双手接稳在胸前 → 持球瞄准、尚未出手 → 屈膝举球并蹬地伸臂，拨腕离手 → 同一颗已经离手的球继续飞行并穿过篮圈、篮网 → 女主仍在投篮位置，先确认进球，再放下双臂、转头微笑。**

这条链中的拍球和出手各发生一次。特写期间球在画外仍由女主持在胸前；球一旦离手，后续入筐镜就从飞行阶段接入。事件不因切镜、裁切或暂时出画而复原。

允许有目的的省略：出手镜切到篮筐镜可以略去弧线中部的飞行时间，接点须保持同一颗已离手的球、来向及结果。无需把准备、发力、离手分别拆成三镜；根据观看任务和可见范围决定是否同镜完成。

### 2.3 用观看任务选择镜头、取景和运动

对每一镜先说明观众主要获得什么，再选择景别、机位、构图、运动及清晰区域。一镜可以有多个协同动作，重点是它们服务于当前观看任务。需要看完整发力时，让脚、膝、双臂、球和离手空间可见；需要读眼神时，明确面部裁切及注视目标；需要确认结果时，展示足以判定结果的过程。

P011全景建立人物与篮筐关系，眼神特写交代瞄准，侧面全身镜展示完整出手，篮筐特写确认球穿过网底，最后用人物反应结束。这套分工可按新剧情调整。固定、跟随、推拉、切镜都应服务观看目标；运镜时同样写清中间必须看见的过程及最终构图，不以固定机位作为统一默认拍法。

### 2.4 确定每个切点两侧的动作进度和方向

连读前镜结束画面、切换方式和后镜起始画面。明确前镜切走时已经发生什么，后镜从哪个阶段继续；涉及物件移动时说明持有、接触、分离、飞行或落定状态。可以动作匹配、改变观察角度或省略无关时间，必要因果和观众需要理解的接点仍须成立。

P011的关键接点是：接稳球后进入瞄准；瞄准结束时仍持球；出手镜完成离手；篮筐镜从同一颗已经在空中的球接入；球穿过网底后进入确认反应。把篮筐镜写成“她再次抱球投篮”会改变事件次数。故意重放的片段另按其已确认的表现目标设计。

方向按[当前镜头的画面坐标](镜头语言参考指南.md#13-统一方向参照)表达，结合真实场景和机位换算。P011投篮镜女主在画面左、篮筐方向在右，球向右上离手；篮筐镜从左上接来球，向右下落入篮圈；反应镜先看右上目标，再转向左侧长凳，身体仍在罚球线。换机位后重新核对这些关系，不把某一镜的左右固定成场景永久方位。

### 2.5 给过程、辨认和声音分配实际时间

镜长应容纳起始状态的辨认、必要动作和结果，不把每个动词机械分配同样时长。能够并行的对白与动作可同时展开；剧情要求先听后反应、先握稳后松手时保留先后。取舍沿[台词与动作同步](../../short-drama-storyboard/references/场次分镜制作规范.md#台词与动作的同步)执行，时长不够且需改变已确认分段或剧情时返回所属业务处理。

P011在15秒内分配3、2、3.5、3.5、3秒：建立关系、瞄准、完整出手、确认入筐、人物反应。出手和入筐各有完整展开空间。各时长为这个示例的安排，新事件按实际动作、对白和节奏重新分配。

声音同样沿链分配：谁在何时说哪一句、位于画内还是画外，动作音在什么可见事件发生时响起，是否跨切点延续。P011男主始终在场边画外讲解，女主进行无对白表演；穿网声在入筐时发生，尾声接到反应镜，不在球尚未落地时提前加入落地声。画外讲解只是一种已确认的声音组织方式，人物需要同步说话时仍应保留其表演任务。

### 2.6 把参考用途和动作链落实为同一份模型正文

参考图分别提供人物身份、衣装、环境或具体视点；正文说明当前镜头中这些主体怎样行动。参考中出现人物不等于该人物每镜都要入画，参考姿态也不自动成为所有镜头的固定起点。按[参考定义与保留说明](../../nora-video-prompts/references/视频提示词制作规范.md#ref2va参考定义与保留说明)区分稳定特征和需要变化的状态。

从分镜合并读取机位／构图、起始画面、动作、结束画面、转场及声音，按实际模型的既有格式写出完整正文。正文可按“谁与目标在哪里、当前什么状态 → 怎样变化 → 结束在哪里、下一镜从何阶段接入”的思路组织，顺序随句意调整；不新增同名模型字段，不把业务镜号、审核说明或未输入的项目历史作为模型已知条件。

P011的关键表达是：

- 眼神镜仍明确“Hands remain at chest height below frame with the ball, no release yet.”，把画外持球状态接住。
- 出手镜写“ONE complete throw”，同时给出起始持球、发力、离手及随挥的完整可见过程。
- 入筐镜写“The SAME already airborne ball”，明确对象和动作阶段，再描述穿圈、拉动篮网、落出网底。
- 反应镜写“at the SAME shooting position”，再写确认结果、放臂和转头，保持人物位置与反应对象。

这些句子连同上下文才构成动作链。单独重复“大写ONE”“同一颗球”或增加禁令，不能替代必要的起点、过程和接点。

### 3.2 连续五镜分镜

下面按段内时间整理示例分镜，保留动作、方向、持物和切镜关系。SH039–SH043只标识本例，完整设想、B／C为本例的可视化与机位称呼；新项目使用自身已确认的剧情及镜号。

#### 镜1（SH039）

**镜号**：SH039

**段内时间**：0–3秒

**时长**：3秒

**景别**：全景

**机位/构图**：设想B全场关系：从投篮轴线同一侧看，女主全身在画面左侧，篮筐在右侧较远处，中间飞行空间清楚。

**运镜**：固定镜头，先交代人、球、篮筐的位置关系。

**起始画面**：完整设想。女主站定面朝画面右侧篮筐，篮球从手边落下。

**情绪/动作**：球触地弹回，她双手接稳；鞋底在调整站姿时轻擦地面。

**结束画面**：女主双手持球在胸前、脚下站稳，篮筐仍在画面右侧。

**台词**：男主（VO，场边对女主讲解）：先用全景，看清人和篮筐。

**音效**：一次拍球声、一次鞋底轻擦地声；校园底声。

**转场方式**：直接切至SH040女主面部，承接接球站稳后看篮筐，不重复拍球。

#### 镜2（SH040）

**镜号**：SH040

**段内时间**：3–5秒

**时长**：2秒

**台词**：男主（VO，场边对女主讲解）：特写，看准目标。

**音效**：男主画外说明叠在轻校园底声上，无女主对白或配乐。

#### 镜3（SH041）

**镜号**：SH041

**段内时间**：5–8.5秒

**时长**：3.5秒

**景别**：全景

**机位/构图**：设想B侧前方稍低机位平拍，女主完整身体在画面左半，右上方留足球离手空间，篮筐朝向为画面右方。

**运镜**：固定镜头，脚、膝、双手与球的发力顺序完整可见。

**起始画面**：完整设想。女主双手在胸前托球，膝尚未下沉，嘴已闭合。

**情绪/动作**：屈膝举球，双腿伸直同时抬臂伸肘、拨球；手和球保持清楚，球最后离开指尖向画面右上方飞去。

**台词**：男主（VO，场边对女主讲解）：侧面固定，完整看到球出手。

**转场方式**：动作接续切至SH042：同一球已经离手，沿画面向右的方向继续飞行；不再举球。允许省略弧线中部少量飞行时间，禁止重放起手。

## 4. 从完整示例提取可复用的组织方法

对照上面同一条链，可把新事件依次写清：**观看目标 → 起始关系与持物 → 必要的动作因果 → 镜头及可见范围 → 每个切点两侧的状态 → 过程和声音的时长 → 结果及必要反应。** 这是一种组织思路，不是模板新增字段，也不要求每镜重复全套说明。

例如递物时，先确定人物与物件位置和持有关系，再写接收者接触并握稳、原持有者松手、物件最终由谁持有。近景要看清相应接触点；切镜后直接承接已握稳或已松手的实际阶段。是否需要交代目光、脚步、反应或完整交接路线，由故事和观看目标决定，不把投篮的五镜逐项换成递物五镜。

“动作过程完整”也不意味着增加过程负担。若剧情只需一个干净进球，中心穿网已经能表达结果；若剧情明确要求擦筐、反弹或失败，保留相应碰撞、轨迹和反应，并安排能看清过程的取景与时间。需要简化或改动已确认结果时回分镜或剧本处理，不在英文转写中擅自删改。

跨P执行时，每段的实际模型输入有自己的边界。本段起点须能由本段正文与真实输入成立；文本连贯不等于模型收到前段上下文。具体实现依据按[独立生成分段的状态表达](../../short-drama-storyboard/references/场次分镜制作规范.md#独立生成分段的状态表达)和实际执行规则落实，本指南不指定段间引导开关或要求新增首帧。

## 5. 顺着整条链连读检查

把同一事件的分镜和实际拼接后的模型正文按播放顺序各连读一遍。从文字反推可见、可听过程，再核对两者对应，而非只确认镜号齐全或标签存在：

1. 能否说明事件开始时谁在哪里、关键物件由谁持有，以及观众本段需要理解的目标？本例从罚球线与胸前持球推进到投篮结果。
2. 所有决定结果的动作能否顺着因果成立？存在接触、握稳、分离、飞行或落定时，是否漏掉了必要过程，或在不需要的地方额外演了一次？
3. 每镜的实际裁切、遮挡、焦点和运动能否让观众看清本镜任务？本例出手镜需看见脚膝、手球和离手空间，眼神镜允许球在画外。
4. 前镜结束、切点和后镜开始是否是同一事件的不同阶段？同一物件的持有人、数量、位置和运动有没有因切镜复原、复制或无原因改变？画外状态与显隐仍按[画外连续性](../../short-drama-storyboard/references/场次分镜制作规范.md#镜头可见内容与画外连续性)判断，不强行让所有物件入画。
5. 换机位后，人物朝向、视线目标、物件来去向与场景真实关系能否同时成立？本例右上出球、篮筐镜左上接球及左侧长凳反应有各自视点依据。
6. 时长是否足以辨认并完成关键动作与反应？对白、口型、画外声、动作音的归属及先后／并行是否与画面一致？本例球穿网时响擦网声，女主在画内无对白。
7. 参考输入与正文的分工是否一致，模型是否被要求依赖未输入的历史？中英文是否保留同一条链、同一动作次数和同一切入阶段？对照后的问题是否真正订正到对应正文？

将本次适用结果并入既有分镜自检；提示词核对沿[现有content_review](../../nora-video-prompts/references/视频提示词制作规范.md#内容核对的证据与结论)归入身份与声音对应、逐镜空间动作、接续与声音及翻译。无需复制本表另建检查文件，不要求每镜填满不适用项；修改只复核变化及其受影响接点，不重做已经有效且未变的全段。
