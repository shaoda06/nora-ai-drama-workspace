# 学习与反馈维护规范

供[创作技法学习与维护](../SKILL.md)及相关专业技能共用。学习材料提供候选方法，实际反馈提供限定结论；日常查用不要求全文读取，本次只进入学习、首次使用或反馈分支。

## 学习与收录

1. **读取本次材料。** 同时读取正文、每页配图及图中文字，混合帖子还要读取相关视频示范和讲解；必要作者补充或用户指定评论一并查看，不默认抓取全部评论。视频按[video-study](../../video-study/SKILL.md)先尝试获取并按需下载，优先复用字幕，缺少文字再转写，依赖画面的内容结合过程抽帧。不能用标题、封面或单帧代替动态观察，也不能把转写说成已看画面。读取不完整、模糊或获取失败时，明确缺失；依赖缺失部分的结论暂不收录，独立成立的内容可继续处理。
2. **提取可复用内容。** 分开讲解、画面观察与自己的归纳，按目的、可见状态／过程、适用条件及容易混淆的方法整理。表情按[拆解方法](表情拆解方法.md)提取意图、部位、幅度、顺序和结束状态；镜头按[指南](镜头语言参考指南.md#选择与转写)提取观看目的、空间与可见变化，区分摄影机运动、人物运动、剪辑、变焦与调焦；法术、动作沿所属专业方法。只有抽象赞美、营销保证或术语清单时，不为凑条目编造有效写法。他人样片和声称亲测不等于本流程已验证。
3. **先查重，再归位。** 按[主题归属](../SKILL.md#主题归属)对照名称、同义词、意图、可见变化及使用条件，并检查相关专业资料及流程是否已有同一要求。同义同法归并；强度、方向或情境变化补到原条目；只有独立用途及关键区别无法清楚容纳时才新增。组合优先放组合示例，不把组合重复计为基础技术；表情新增、拆分或合并时同步基础项总数及分类。跨主题内容按知识点归位，通用部分只维护一处，专项引用并补本领域条件，不复制全文。
4. **处理冲突。** 新内容与现有方法或候选（包括未验证项）不同时，先比较意图、题材、情境、强度、空间、媒介、模型及参考输入。可并存的注明条件和替代关系，不把同一时段的互斥要求堆在一起。同条件下仍无法解释的冲突，在本次交付中说明并暂不入正式参考；没有必要另建待验证库。不能仅凭帖子说法覆盖已验证写法或已确认流程。确有依据的纠正只改受影响部分，保留仍适用的结论。
5. **更新正确层级。** 具体写法、变体、适用条件与验证情况进对应参考；确有依据且可跨条目复用的方法修改专业方法文件；入口与读取时机由负责业务技能维护，不在参考内另定制作阶段。外部分享不自行升级为强制规则，模型能力声明需按实际能力依据核对；接口、配置、工具安装、项目批准与生成授权仍沿原规范。仅学习收录不追溯改写已确认项目，不自动启动修改后的测试。
6. **检查并交付。** 写入前核对目标文件最新内容，合并其他对话已经完成的更新；只修改本次知识点，不覆盖无关改动。核对重复、动作／光学／空间冲突、静帧与动态适用性、验证范围及相关调用入口。沿[Nora维护规范](../../nora-ai-short-drama/维护规范.md#维护任务读取路径)保存必要旧版、执行适用校验及本地提交。简述吸收、归并、未采纳和未读全部分及原因；没有新价值就说明无需修改，不制造学习记录或空文件。

共用参考不记录作者、帖子链接、图片页码、视频时间点或学习流水。读取所需的字幕、帧和来源信息仍按video-study留在临时资料中；实际项目请求、媒体和反馈原话留在原项目。既有许可证、必要署名、依赖来源及官方接口依据按原维护规则保留，不因不建来源台账而删除。

## 首次实际使用时的提示

首次实际采用未验证的具体候选写法或技巧组合时，在交付说明中简短说明采用项、可能偏差及结果观察重点。例如忍笑重点看双唇是否仍闭合、笑意是否收住；调焦重点看清晰中心是否移动，而非摄影机推近。按当前问题说明，不预言必然失败。常规摄影术语或概念解释不逐项提醒；纯浏览、讨论不触发提醒。

多项合并一次说明，复用会话或现有任务记录中的告知，不在写作、提交、取回时重复提醒，不建立首次使用台账。超出原验证模型或条件时说明该范围未验证；已知有问题的写法说明具体问题及本次调整，不笼统称为未验证。提示不写进模型正文，不新增确认或暂停，生成仍沿现有授权。

## 实际反馈复核

- 用户提供针对某项效果的真实反馈，或明确要求查看并复核指定结果时，结合实际发送的提示词、已知模型／模式、图片或视频用途、参考输入及影响条件判断。需要查看媒体时沿现有授权，未看就不声称看过；正常结果通知不触发自动查看。文字审查通过、生成／下载成功、整体采用或含义不明的“好”均不证明某项技法有效。
- 区分方法不适合当前目标、写法歧义、参考或其他要求冲突、模型执行偏差及用户改变目标。无法归因就保留不确定性；一次失败不自动否定方法，也不盲目改通用表达。可依据针对性反馈文字得出限定结论，不为更新强求再次查看或补测。
- 针对性真实反馈具备时，沿既有持续维护授权更新对应写法，无需再问是否允许更新。只更新反馈涉及的部分；项目具体修订及重生成仍按该任务授权，不扩大到其他项目。新组合有可复用结论且现有参考容纳不了时，可补候选及限定结论，不为每次临时用法扩库。
- **验证状态**：未验证＝没有对应针对性反馈（包括已经生成但无人评价该效果）；条件有效＝实际反馈支持该写法在注明条件下有效；需调整＝反馈指出相应写法或使用条件有问题；结论不足＝已有反馈仍不足以判断。概念与模型执行效果分开，不为每个术语建测试记录。
- 结论限定实际措辞、幅度、组合、已知模型／模式、用途和关键条件；未知条件明确未知，不继承其他模型、人物或同条目其他变体的效果。组合成功不等于所有组成条目及可选动作均有效；不同条件的相反反馈可并列保留。
- 修改后的新写法没有对应反馈时回到未验证，未改部分保留原有效范围。新候选与已有结论分别注明，不把整条重置或让新增内容继承旧结论。结论放在对应参考条目或示例旁，保留必要写法与条件，不建独立测试流水；既有证据仍按原位置保存。
- 写入后的检查和提交沿上方学习流程的维护收尾执行，不重复读取无关学习步骤。没有真实反馈不补结论，不组织集中补测。
