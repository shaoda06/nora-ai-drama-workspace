# 表情拆解方法

把人物的表演意图写成可见的面部变化，候选写法见[表情参考表](表情参考表.md)。

## 适用边界

- 分镜、剧本可以保留“委屈”“忍笑”等抽象词；转成图片或视频模型提示词时，已指定且需要呈现的表情必须细化，不能只写“眼神复杂”“十分难过”。人物头像、封面等非剧情用途同样适用。抽象词可以保留为概括，不能代替具体变化；未要求表演的中性参考图不另加情绪。
- 已有清楚且适合当前镜头的面部描述时直接沿用，不强制换词或加长。纯环境、背影及看不清脸的镜头不硬塞不可见的面部细节；必要表演无法被当前取景呈现时，交回分镜解决。
- 只处理表情表达，不改变已确认的情绪、剧情、人物关系和镜头设计。只写提示词不启动生成；收到结果也不自动查看或审片。

## 怎样拆解

1. **判断意图。** 从当前情境明确触发、面对谁、想显露还是掩饰、强弱及最终状态。“笑”先区分开心、应付、嘲讽或掩饰难过；缺失会改变剧情的意图时再询问，不替人物另编动机。
2. **选择可见动作。** 按问题读取参考表相应条目，通常挑两到四个有辨识度的变化，描述“部位＋方向／状态＋幅度”。例如眉头向内靠拢、上眼睑压低、双唇收紧、下颌绷住。不是每次写满眉眼鼻嘴，也不要求肌肉术语。参考表没有对应项时按同样方法组合，不强行套近义词；新组合未经反馈仍按未验证处理。
3. **适配媒介。** 图片选择一个明确瞬间，不把先后变化同时塞进静帧；视频写必要的起始、变化顺序和结束状态。忍笑要明确最后忍住还是笑出来，忍泪要明确泪水是否落下；时长沿分镜，不额外新增拍数。怒极反笑、口是心非、强颜欢笑等按[复合表情的组合方法](表情参考表.md#复合表情的组合方法)区分真实情绪、显露或掩饰意图及变化顺序，不直接叠加两条完整写法。
4. **适配人物与画面。** 幅度符合人物、画风和景别；保持既有脸型、年龄与面部特征，不自动增加酒窝、深皱纹、泛红或泪水。凝视写清对象，表中垂眼、移开视线或抬头等选项不能覆盖已确认的视线与头部朝向；多人镜头分别指明谁在什么时点变化。不把“深情”“冰冷”“灵动”换成另一个抽象词便算完成。瞳孔剧变、血丝、全脸变色等不作为通用情绪标记。
5. **分清组成。** 面部变化是核心，低头、转脸、捂嘴等辅助动作只在当前表演需要时加入；灯光、镜头、背景、音频和画风沿原任务规则，不随表情条目自动附送。说话时的口型服从台词，不能同时要求持续紧闭嘴唇。
6. **合并自检。** 连读实际完整提示词，核对同一时段的部位变化不冲突、程度不过量、动作可被取景看见，中外文含义一致。将结论并入调用方已有自检，不新增检查轮次。

例如，分镜“她委屈地笑了一下”可转成视频表演：“她眉头内侧微微抬起，双唇先抿紧，随后勉强牵起嘴角；笑容短暂停留便收住。”视线和头部朝向沿该镜头已确认的安排。这是选定情境下的一种演法，不是委屈的唯一面部模式。
