# 创作技法学习与维护

统一处理创作技巧的学习收录、创作查用及实际反馈。表情、镜头及完整动作链的组织与转写方法在本目录维护；打戏动作机制、法术和模型专用规则沿下方归属引用，不复制另一份资料。只读取当前入口和相关主题，不默认加载全部参考。

## 按任务进入

| 当前任务 | 读取与落实 |
| --- | --- |
| 学习小红书、抖音等指定图文／视频并吸收技法 | [学习与收录](references/学习与反馈维护规范.md#学习与收录)，读完后完成比较与必要更新；没有新价值就说明无需修改 |
| 查用表情或镜头方法、编写或修订当前产出 | 按下方[表情表达](#表情表达)或[镜头表达](#镜头表达)进入；其他专业按[主题归属](#主题归属)进入，不因此启动学习收录 |
| 同一事件的连续动作设计、跨镜头接续或模型正文转写 | [完整动作链设计与转写指南](references/完整动作链设计与转写指南.md)，整体查用方法、贯穿分镜与实际正文示例；落实到原业务产出，不拆成另一套状态台账 |
| 首次实际采用未验证的具体写法或组合 | [首次实际使用时的提示](references/学习与反馈维护规范.md#首次实际使用时的提示)，简短告知观察重点并继续原流程 |
| 收到针对性实际反馈，或用户要求查看并复核指定效果 | [实际反馈复核](references/学习与反馈维护规范.md#实际反馈复核)，更新对应写法的条件结论；不要求反馈发生在专门维护对话 |

用户明确要求学习吸收时执行维护；上下文已明确的后续材料沿用该目的，不重复确认。仅要求总结、讨论或作为某个项目参考时，按本次范围处理，不据此修改共用资料。单纯查用或临时写出一个描述不自动扩库。

## 表情表达

图片／视频提示词中已指定且需要呈现的抽象表情，按[表情拆解方法](references/表情拆解方法.md)和[表情参考表](references/表情参考表.md)落实具体面部变化；分镜、剧本可以保留表演意图。已有清楚且适用的描述直接复用，不为调用技能换词、加长或给中性图加情绪。首次采用候选及针对性反馈沿上表对应入口。

## 镜头表达

选择或细化景别、构图、角度、运镜、光影及焦点时，按[镜头选择与转写](references/镜头语言参考指南.md#选择与转写)落实。分镜阶段辅助选择拍法，图片／视频提示词转写已确认设计；已有适用表达直接复用。表情方法处理面部变化，镜头方法处理怎样拍清这些变化。首次采用具体候选或组合及实际反馈沿上表处理。

完整事件的连续动作与切镜组织，使用[完整动作链设计与转写指南](references/完整动作链设计与转写指南.md)中的整条方法和贯穿示例；正式分镜与模型正文的读取时机、输出和核对责任分别由对应业务技能维护。

## 主题归属

| 内容 | 唯一维护位置及取用方式 |
| --- | --- |
| 表情意图、面部变化、强度及组合 | 本技能的[拆解方法](references/表情拆解方法.md)和[参考表](references/表情参考表.md)；通用拆解方法与具体写法分开维护 |
| 景别、构图、机位、运镜、光影、焦点 | 本技能的[镜头指南](references/镜头语言参考指南.md) |
| 完整动作链的镜头组织、转写与连读检查 | 本技能的[完整动作链指南](references/完整动作链设计与转写指南.md)集中维护方法和完整示例；镜号、P段及已确认动作归分镜，模型结构与标签归视频提示词，打戏动作机制沿下方专业入口 |
| 转场与镜间衔接技巧 | 优先补入镜头指南相关章节；独立内容足够时再拆参考。区分镜内变化、切镜和后期转场，明确前镜结束、后镜开始及匹配条件；正式镜号、切点和分段仍归[分镜](../short-drama-storyboard/SKILL.md)，实现格式归[视频提示词](../nora-video-prompts/SKILL.md)或实际执行规范，不把术语当作模型已支持的功能 |
| 通用特效与材质 | 先检查[介质与分层](../sd-combat-engine/references/vfx-rendering-mandate.md)及相关题材资料的适用范围；已有归属原位更新，不把打戏专用要求扩大到全部视觉效果。确无合适归属且有实质内容时，才在本技能新增参考并同步入口 |
| 修仙法术、阵法、剑气与灵力 | [玄幻专项](../sd-xuanhuan-engine/SKILL.md)的[法术表现方法](../sd-xuanhuan-engine/references/xuanhuan-elements-vfx.md)及[造型参考库](../sd-xuanhuan-engine/references/仙侠法术与特效造型参考库.md)；保留专业设计与调用流程 |
| 武侠、通用动作与写实格斗 | [通用打戏](../sd-combat-engine/SKILL.md)或[写实专项](../sd-real-engine/SKILL.md)按问题选择方法；攻防因果、动力链和节奏不迁入本技能 |
| 国风、古风等题材／风格分享 | 按实际知识点分到[画风定位](../short-drama-develop/references/项目定位与画风规范.md)、[资产设计](../nora-drama-assets/SKILL.md)、镜头或动作资料；项目已采用风格留在项目，不仅按标签另建混合库 |
| 模型格式、输入标签、工作流及参数 | 沿[视频提示词](../nora-video-prompts/SKILL.md)、图片对应能力及[生成执行](../nora-generation/SKILL.md)的现行规范；外部技巧不能直接覆盖接口或执行规则 |

同一帖子可以涉及多个主题，读取结果复用，逐项归位。新增内容优先补现有条目或章节；已有完整专业流程的资料继续原位维护。只有职责和工作流程确实独立时才考虑另设技能，不按每个知识主题创建技能或空参考文件。

## 业务边界

正式剧情与表演意图、资产设计、镜号、P段、模板、空间接续及模型结构由原业务技能负责。本技能只提供方法，落实到当前获授权的产出和既有自检，不另造一份分镜或增加审核轮次。缺项会改变已确认剧情、人物关系、站位、视线、风格、能力或镜头时，回负责业务处理，不在转写中补编。

材料获取与视频分析调用[video-study](../video-study/SKILL.md)，纯图文使用当前可用的页面与图片能力；读完回到学习入口完成归并。本技能不生成媒体、不自动审片、不主动监控账号或批量扩抓、不为验证额外测试。上传、查询、下载、后处理和正常结果通知不触发创作重写或参考验证。维护修改沿[Nora维护规范](../nora-ai-short-drama/维护规范.md#维护任务读取路径)处理。
