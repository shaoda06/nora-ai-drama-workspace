# 镜头语言与表达

把观看意图落实为可见画面及其变化，并持续维护[镜头语言参考指南](references/镜头语言参考指南.md)。可独立学习和讨论，也供Nora分镜、资产、提示词及审查流程按需调用；方法在指南中维护，学习与反馈处理在本文件维护。

## 何时使用与职责

- 需要选择或细化取景、观察角度、构图、摄影机运动、光影、景深及焦点时使用。分镜阶段辅助选择拍法；图片／视频提示词阶段转写已确认设计。已有清楚且适用的表达直接复用，不为调用技能重写或堆叠术语。
- 用户指定小红书、抖音等图文或视频，要求学习镜头技巧、吸收写法或完善技能时，执行[持续学习与维护](#持续学习与维护)。学习目的已明确的后续材料沿用，不重复确认；仅要求总结或作为项目参考时，不据此更新技能。
- 只提供当前任务所需的方法。Nora的正式镜号、分段、模板、空间与状态接续由[分镜技能](../short-drama-storyboard/SKILL.md)维护；资产设计由[资产技能](../nora-drama-assets/SKILL.md)维护；模型格式、素材标签、台词和时码由[视频提示词技能](../nora-video-prompts/SKILL.md)适配。用户当前要求及已确认项目约定优先，不以新学技巧改变剧情、人物站位、风格或既定镜头。
- 表情本身的面部变化交[表情拆解](../facial-expression/SKILL.md)，本技能处理怎样拍清这些变化。学习视频的获取、字幕／转写和抽帧交[video-study](../video-study/SKILL.md)，读取后回到本技能比较与吸收。
- 不提交生成、不新增审批阶段、不自动审片；上传、查进度、下载、二采或后处理本身不触发本技能。实际生成与修订次数仍按当前任务授权。

## 选择与转写

当前任务是新写或修订正式场次分镜时，先沿[分镜选择流程](../short-drama-storyboard/references/场次分镜制作规范.md#运镜构图与切镜的选择)确定表达任务与取舍，再按下方方法落实；独立技巧讨论或材料学习不因此启动正式分镜。图片／视频提示词继续承接已确认设计。

1. **先确定观看目的。** 本镜需要看清谁、什么动作或信息，什么时候让观众知道，结束时留下什么。区分资产展示与叙事表达，按指南第1节处理；不把“孤独＝拉远”“强势＝仰拍”当成固定公式。缺项会改变剧情或已确认镜头时交回对应设计任务，不在提示词里补编。
2. **按问题取用方法。** 从指南第3至9节选择所需景别、构图、角度、运动、光影、焦点和色调；方法的条件、区别及方向参照只在指南维护。说明取景对象、关键可见范围和必要空间关系；摄影机移动、人物走位、变焦、调焦和切镜分别表达，不凭器材名或焦距数值承诺精确效果。
3. **适配媒介。** 图片只写一个选定时刻的构图与状态；视频按指南第5.1节和第10节写起始关系、变化触发、过程及结束落点，核对中间是否仍看得清关键动作。只描述有作用的变化，不要求每镜运动，也不以“固定更稳定”为由取消已确认运镜。
4. **落实到原有产出。** 分镜方法进入景别、机位／构图、运镜、起止画面等既有字段；图片进入画面正文；视频进入对应模型的正式结构及中文参考版。转写中发现现有设计不成立，回到负责技能修订，不另建一份分镜或擅自换生成模式。
5. **合并自检。** 使用指南的[简短自查](references/镜头语言参考指南.md#105-使用时的简短自查)，核对真实空间、裁切、运动、焦点、光线及前后镜接续，处理同时固定与移动、全景与细微表情必须同样清楚等矛盾。结果并入当前交付自检，不新增检查轮次。

## 持续学习与维护

完成用户指定材料的读取、比较、必要更新和说明；没有新价值时说明无需改动。不主动监控账号、批量扩抓其他帖子或为学习启动生成测试。

1. **读全相关材料。** 图文同时读正文、每页配图及图中文字；混合帖子读取其中相关视频示范与讲解，必要的作者补充一并查看，不默认抓全部评论。视频按video-study先尝试获取并按需下载，结合字幕／转写和关键过程抽帧。不能仅凭封面或一张关键帧判断运镜；区分实际可见的连续运动、剪辑、人物运动与自己的推断。读取不全或无法区分时明确范围，不用猜测补写。
2. **提取可复用内容。** 分开整理作者讲解、实际画面观察和归纳建议。保留观看目的、可见变化、适用情境、必要空间条件、容易混淆的拍法，以及静帧／视频的具体描述；材料没有证明的效果不写成事实。仅有“高级、震撼”等标签、营销保证或术语清单时，不为凑条目另编有效写法。
3. **先查重，再决定放哪里。** 对照指南中的同义名称、目的、画面变化及条件，并检查相关流程是否已有同一要求。同义同法归并，不重复建项；已有方法的强度、方向或情境变体补到原条目；有独立用途及可见区别且现有条目无法清楚容纳时才新增。组合技巧优先写入第10节，不把已有方法组合另算成一种基础技术。镜头方法归指南，学习与验证规则归本文件；正式分镜或模型执行规则仍归对应技能，跨职责调整须在本次授权范围内进行。
4. **处理冲突与已有结论。** 新材料与现有方法或候选写法（包括未验证项）不同，先比较目的、空间、幅度、媒介、模型及参考输入条件。可并存的写明适用条件及替代关系，不把互斥要求堆进同一时段。同一条件下仍无法解释的冲突，在交付中说明并暂不入指南；不能仅凭帖子说法覆盖已验证写法或改变已确认流程。确有依据的纠正只改受影响内容，保留仍适用的结论。
5. **按需更新指南。** 沿现有分类保存概念、适用条件及描述重点；具体候选写法或示例在对应位置标明模型执行的验证情况。只有出现实际反馈时才补相应条件结论，不为每个摄影术语建测试记录，也不把指南变成帖子摘抄集。技能中不记录作者、来源链接、图片页码、视频时间点或学习流水；必要读取证据沿video-study临时目录或项目原位置保存。
6. **检查并交付。** 核对受影响条目是否重复、动作或光学描述是否冲突、媒介是否合适、验证范围是否被扩大，检查旧引用及上下游入口。按[Nora维护规范](../nora-ai-short-drama/维护规范.md#维护任务读取路径)保存旧版、完成适用校验及本地提交；不另加审批。简述吸收、归并、未采纳及未读全的部分和原因，新候选未经对应实际反馈保持未验证。

## 实际使用与反馈复核

**分开判断方法与执行。** 摄影概念和拍法用途不等于模型能力承诺；他人样片、材料声称亲测、文字审查通过或本地生成成功，都不等于本流程已验证具体写法。一次模型执行失败也不自动否定拍法本身。

- 首次实际采用尚未验证的具体候选写法或技巧组合时，在交付说明中简短说明可能偏差及结果重点，例如“这次调焦写法尚未验证，重点看清晰中心是否从前景手中的信转到背景人物，而不是摄影机推近”。常规景别名称和概念解释不逐项提示。已有告知沿会话或原记录复用；不同模型或超出已有条件时，只说明该范围尚未验证，不新增确认或暂停。提示不进入模型正文。
- 收到用户对实际画面的针对性反馈，或用户明确要求查看并复核结果时，结合实际发送的提示词、模型／模式、图片或视频用途及参考输入，检查是观看目的不适合、描述歧义、输入冲突还是模型执行偏差。无法归因就保留不确定性，不把用户改变目标记成原写法失败。需查看媒体时按已有查看授权处理，不假称看过；正常结果通知不触发复核。
- 针对性真实反馈已具备时，更新指南相应写法的验证情况，不再单独询问是否允许维护；整体采用或一句含义不明的“好”不足以证明每项镜头技巧有效。只更新反馈涉及的部分，不自动重生成、扩大到其他项目或集中补测。
- 状态使用“未验证”“条件有效”“需调整”“结论不足”。有效或问题结论须限定实际措辞／组合、已知模型与模式、用途及影响结果的条件；条件未知明确未知。尚无针对性反馈的已生成写法仍属未验证；反馈不足以判断时记结论不足，不继承其他模型或同条目其他变体的效果。
- 记录放在指南对应条目旁的简短说明或示例后的验证说明，包含必要写法与条件，不设独立测试流水。新候选与已验证写法分开注明；改写后没有对应反馈的部分回到未验证，未改部分的有效条件保留。原项目请求、媒体与用户反馈原话仍留在原项目记录。
