# 镜头语言参考指南

版本：v1.10；更新日期：2026-10-26。

本指南由[镜头语言与表达](../SKILL.md)统一维护。选择与转写、学习材料吸收及实际反馈复核按该技能执行；本文件维护镜头方法与候选描述。

**验证范围**：摄影概念、用途说明与模型执行效果分别判断。未附对应实际反馈结论的具体写法和组合示例，其模型执行均为“未验证”；不因概念通行或文字检查通过而标为有效。后续候选及反馈在对应条目或示例旁注明适用写法、条件和状态，按[反馈复核](../SKILL.md#实际使用与反馈复核)维护，不集中补测。

## 1. 作用与使用边界

本指南为 AI 连续短剧／漫剧的参考图、镜头画面及生成提示词提供视觉表达参考，帮助将“电影感”“高级感”等笼统要求转化为可描述的景别、构图、观察角度、镜头运动、光影、焦段、景深和色调。

本指南不规定工作阶段、执行顺序、审批流程、文件命名、模型参数或提示词外层格式。何时读取、成果保存在哪里，由相应工作流程另行规定。

本指南是创作参考，不是摄影术语的穷尽清单，也不是任何生图／视频模型的能力承诺。

### 1.1 两种不同的画面目的

- **资产展示**：让人看清人物身份、身体比例、服装结构、道具形态或场景空间。优先清晰、可比较和可复用，不能为营造氛围遮住需要确认的内容。Nora参考图的展示范围与完整性按[参考图用途与取景](../../nora-drama-assets/references/核心参考图制作规范.md#参考图用途与取景)确定，固定结构图与镜头局部取景分别适用。
- **叙事表达**：引导观众注意人物、动作、关系或信息变化。可以按剧情使用遮挡、虚化、明暗和运动，但须保留理解剧情所需的信息。

同一项技术没有固定用途或固定情绪。例如，仰拍并不必然表示强大，暖色也不必然表示温馨；效果取决于人物行动、空间关系及前后镜头。机位通过改变观众看到的关系参与叙事：判断人物处境时，同时考虑人物在画面中的占比、周围环境、姿态和动作，不把情绪只归因于拍摄角度。

### 1.2 选择原则

1. 按画面目的选择，不要求每张图、每个镜头填满所有类别，也不要求使用特殊技巧。
2. 已批准的人物、服装、道具、空间、画幅和视觉风格保持有效。镜头语言不能自行改变资产设计或把动画改成真人。
3. 术语与可见结果一起表达。例如“浅景深”应说明谁清晰、什么虚化；“逆光”应说明光源位置和主体是否仍需看清。
4. 静态图片表达某一时刻的构图与状态；推拉、环绕、变焦和焦点转移属于时间过程，不能靠一张图证明执行效果。
5. 焦距和器材名称是视觉意图的描述，不表示生成模型会进行精确光学模拟；同时写清取景范围、空间关系和清晰区域。
6. 本指南不是模型专用语法。具体模型的章节结构、素材标签、声音与对白标注仍遵循对应指南。

### 1.3 统一方向参照

画面描述以当前镜头中观众看到的画面为方向参照；图片与视频提示词中的位置、朝向、光源和运动描述使用同一口径。

- 横向与纵向明确写“画面左侧／右侧／上方／下方”，不单写“左边／右边”。空间纵深使用“靠近镜头／远离镜头”或“前景／中景／背景”。分别说明身体朝向、头部朝向／视线和移动方向：面朝或背对镜头、面向画面哪侧；从哪里入画，朝镜头靠近或远离镜头，最后停在哪里。不能用“走向门口”代替朝向与路径，也不能默认看向哪里就向哪里行走。
- 模型正文的空间定位与运动描述不使用东南西北，也不交替使用身体左右与画面左右定位同一对象。先根据实际机位、已确认布局及适用参考图完成换算，再描述目标画面的可见关系；不能逐词把“东”替换成“右”。左手、右腕等身体部位仍按人物自身归属命名，另说明其画面位置，不能为统一方向而调换受伤侧或持物手。
- 多视图的“人物／道具自身右侧90°”保留为展示面的定义；先明确所在视格，再描述该视格内部的画面方向。例如“中列展示人物自身右侧90°纯侧面，鼻尖朝该视格画面右侧”。视格排列、展示面与格内画面位置各司其职，不能互相替代。固定的身体或物件不对称设计保持原归属，依视角换算可见位置，不为统一措辞镜像或改变设计。
- 场景资料保存稳定的物件关系和空间连接，例如门连接哪条通道、床靠哪面墙、矮几紧邻床头；必要时注明固定观察基准。不能把某一镜头的画面左右当作整个场景的永久方向。已有地理方位可作为布局换算依据，不直接搬入模型画面描述。
- 移动起点和落点同时关联明确的环境位置，如画面左侧菜畦边缘、背景院门门槛、右侧泥地通道；“入口”“房屋侧路线”“远侧”不能单独承担定位。人物朝向由头脸、肩背及其与环境的关系落实；背景选取须符合当前视点，不能为排除其他人物而随意换成空墙或把另一处门口放到身后。
- 转头、喊话或寻人写清起始朝向、变化时点／过程及结束方向，区分身体是否随头转动。向画外人物转头时写明转向画面哪侧，不只写对方姓名；朝门外喊话时明确门相对镜头的位置和声音投向。小幅左右寻找应有对象与结束点，不用笼统“晃头”制造无目的动作。背对镜头喊话可以成立，不同时要求正面嘴唇清晰可见。
- 切镜或改变机位后，按新视点重新描述画面位置；连续运动写清起始位置、相对镜头的运动过程和结束位置。人物、家具、门窗的真实关系保持不变，不机械沿用上一镜的左右，也不为匹配描述移动场景结构。

## 2. 阅读与选择方法

按构图与景别、观察角度、镜头运动、光影、焦段与景深、色调六类查找所需表达。这些类别用于检索，不是互斥的专业分类；同一画面可以组合使用多个类别。

先确定画面要展示的信息，再通过“含义与用途”选择方法，按照“描述重点”写清实际可见结果。名称含义不明确时，直接描述取景范围、主体位置、清晰区域或色彩效果，不用含糊术语代替画面要求。

## 3. 构图与景别

### 3.1 景别与取景范围

景别说明主体在画面中的取景尺度，不等同于观察角度、人物数量或构图方式。下表为常用范围；横竖画幅、姿态和多主体会影响实际裁切，关键部位是否可见须用具体画面描述确定，不把范围当成精确测量值。

| 条目 | 含义与用途 | 描述重点 |
| --- | --- | --- |
| 远景 | 环境占主导，人物较小，交代空间规模及行动位置 | 明确主体位置及环境关系，不要求同时辨清微小表情或手部细节 |
| 全景 | 展示人物完整身体及周围环境，交代位置和行动 | 明确人物在环境中的大小、脚下与周边可见范围 |
| 中全景 | 常从人物头部取至膝部附近，兼顾较完整姿态与交流 | 写明实际下缘，动作需要脚部或落点时检查是否容纳，不能默认全身入画 |
| 中景 | 常取人物腰部以上，表现手势、操作及交流 | 需要看见的手部、桌面或互动对象不能被裁掉 |
| 中近景 | 常取人物胸部以上，兼顾面部反应与上身动作 | 明确胸前、手部或对手是否入画，不默认所有手势均可见 |
| 近景 | 以人物头肩附近为主要取景范围，强调表情 | 写明肩部及面部裁切，需要手部动作时重新核对取景 |
| 特写 | 集中展示面部、手部或某个物件细节，突出反应或信息 | 指定特写对象和裁切范围；不是一律只拍眼睛 |
| 大特写 | 展示眼睛、嘴部等更小局部，突出细微变化或信息 | 指定局部边界，不同时要求全脸、全身及周边环境清楚入画 |

“面部特写”“手部局部特写”说明特写对象，“胸像”“半身”说明实际裁切，“超远景”强调远景中的环境规模；使用这些说法时仍写明取景范围，不把别名另立为固定景别选项。

### 3.2 构图方式与裁切说明

这些条目描述画面组织或具体裁切，可与景别组合，不是另一套景别分类。

| 条目 | 含义与用途 | 描述重点 |
| --- | --- | --- |
| 过肩镜头 | 以一人的肩部或头部局部作前景，拍摄另一人 | 写清从谁身后看谁、前景占比、谁清晰，并保持视线关系 |
| 双人镜头 | 两个人同时出现在画面中，表现关系及互动 | 指定画面左右、相对镜头的远近、人物间距和注意力中心；它本身不限定景别 |
| 牛仔景 | 常从头部取到大腿中部或膝部附近的裁切称呼，兼顾面部和腰侧动作 | 明确实际裁切点及手部是否完整，不能只凭名称决定构图 |
| 框中框构图 | 用门、窗、拱廊等形成画面内部边界，引导视线 | 指定形成边框的物体、主体所在区域以及是否存在遮挡 |
| 三分构图 | 借横向、纵向三等分附近的位置组织主体和环境，兼顾注意力与空间 | 指定主体靠画面哪侧、视线或行动朝向哪侧及留给什么；不要求生成网格线 |
| 黄金分割构图 | 借接近黄金比例的位置或曲线组织视觉重心 | 说明主体落点与视线引导关系；比例是安排参考，不要求模型精确计算或画出辅助线 |
| 中心构图 | 将主要人物或物件放在画面中央附近，集中注意力 | 指定中心对象与周围空间；不等于左右对称，也不固定代表人物强势 |
| 对称构图 | 利用左右或上下对应的结构组织画面，突出秩序、对照或偏离 | 写清对称轴及对应的环境结构；人物可以偏离对称，不为对称复制人物或改造场景 |
| 引导线构图 | 利用道路、墙沿、桌沿等已有线条，把视线引向人物、物件或空间落点 | 指定哪些线条通向哪里，避免线条把注意力带离本镜重点 |
| 留白／负空间构图 | 用低信息区域衬托主体，给视线、行动或人物处境留下空间 | 写清空处在画面哪侧及作用；不为留白随意缩小主体或清空已有场景 |
| 对角线构图 | 将人物、物件或空间走向沿画面对角方向组织，形成延伸与动势 | 指定对角线由什么形成及起止位置；不等于摄影机倾斜或场景地面倾斜 |
| 三角形构图 | 让人物或视觉重心在画面上形成可辨认的三点关系，组织多人关注与力量关系 | 从既有站位选择合适机位和取景，写清各点的主次与远近；不把人物强排成等边三角形 |
| 前景—中景—背景分层 | 用不同距离的主体与环境建立纵深，交代谁面对谁、谁在旁观或接近 | 指定各层内容、遮挡与清晰程度；脸、手及关键物不能因分层被挡住，也不要求三层同样清楚 |

构图方法可以组合，也可以随表演和摄影机运动改变。构图名称后写实际画面关系；需要变化时按[构图与运镜的配合](#51-构图与运镜的配合)说明过程，不要求一个镜头从头到尾维持同一几何形状。

## 4. 拍摄角度与观察方式

| 条目 | 含义与用途 | 描述重点 |
| --- | --- | --- |
| 平视角度 | 摄影机大致处于主体眼睛高度，形成接近平等观察的视角 | 主体坐下或站起时，说明机位是否随之改变 |
| 俯拍角度 | 从高于主体的位置向下观察，可展示桌面、布局或人物处境 | 指定俯拍对象、程度及需要保留的面部可见度；要让环境衬托人物处境时，写清人物占比、周围空处或包围他的物件，不能只靠抬高机位要求人物变小 |
| 仰拍角度 | 从低于主体的位置向上观察，改变人物与背景的空间关系 | 指定机位高度、仰角程度，不默认夸张透视 |
| 侧面视角 | 从主体侧方观察，强调轮廓、视线和行动方向 | 写明侧面或斜侧面及面朝的画面方向；固定多视图按第1.3节保留展示面定义 |
| 顶视角度 | 从上方接近垂直向下观察 | 用于空间、物件排列或动作轨迹；不能同时要求正面清楚呈现人物五官 |
| 虫视角 | 摄影机极低、接近地面向上观察 | 指定地面前景、主体距离和仰视程度，不等同于任何普通低机位；需要强调体量时，说明靠近镜头的靴子、箱体等与向上延伸的主体之间的大小关系，不能只靠贴地就承诺夸张透视 |
| 窥视视角 | 借门缝、窗缝等局部开口形成观察感 | 明确开口位置、遮挡边界和真正需要看见的内容 |
| 镜面反射视角 | 通过镜子、玻璃或水面反射组织画面 | 说明看的是实体、倒影还是两者，避免无意产生第二个人物 |
| 遮挡式视角 | 用前景物体遮住部分画面，形成层次或信息限制 | 指定遮挡物、占画面的大致范围，不挡住关键动作或资产细节 |
| 鸟瞰视角 | 从较高处观察较大范围，交代路线、群体分布或环境规模 | 指定高度感、朝向与需要辨认的范围；可以斜向俯视，不等同于垂直顶视。突出个体与群体的关系时，写清群体流向、个体的不同路径及可辨认的间距，不只写“渺小”或“孤独” |
| 倾斜视角（荷兰角） | 摄影机绕镜头轴倾斜，使画面中的水平与竖直线偏斜 | 写明倾斜程度及需要的视觉作用，可保留门框、墙沿等稳定线条作为倾斜参照；不把人物倾身、地面坡度或对角线构图当成摄影机倾斜 |

“窥视”“反射”“遮挡”还涉及构图和叙事视点，不只是摄影机高度。

低机位、高机位描述摄影机的位置，仰拍、俯拍描述观察方向，两者分别确定。例如接近地面的机位也可以平行地面拍摄脚步；不要只写“低角度”却同时要求相互矛盾的地面、正面脸部与背景范围。斜侧面视角写清相对主体的位置，不与画面倾斜混用。

### 4.1 正反打与视线连续性

正反打通过相互对应的机位表现人物交锋、听者反应及关系变化，可采用单人近景、特写或按叙事需要采用过肩取景。出镜人物的选择按[单人／多人取舍](../../short-drama-storyboard/references/场次分镜制作规范.md#对白反应与多人镜头的取舍)，局部入画的身份、裁切及画外状态边界按[可见内容与画外连续性](../../short-drama-storyboard/references/场次分镜制作规范.md#镜头可见内容与画外连续性)处理。设计重点是空间关系和信息衔接：

- 先明确人物相对站位、相互视线及连接两人的交互轴线。常规正反打保持机位在轴线同侧，依据各自机位说明人物在画面中的位置及视线方向，使双方看向彼此；高低位置不同的对话同时考虑视线高度。
- 切镜后按新视点换算画面方位，不把反打理解为水平翻转原画面。人物身份、伤痕所在身体位置、服装、持有物及动作进度保持连续；根据新的观察角度说明本镜实际可见的部分。
- 光源在场景中的位置保持稳定，入光的画面方向按新机位换算。反打可以改变取景和焦点，但不能无依据地移动光源、改变天气、环境状态或人物距离。
- 有意越轴或人物移动使轴线变化时，用能交代相对位置的镜头或连续摄影机运动建立新的空间关系，说明方向何时改变。
- 切镜围绕新信息、动作和反应安排，不机械地每句对白换一次镜头。听者反应镜头可以承接说话人的连续语流；切镜时的动作接续及声音连续性应明确表达。

- **摄影机高度与注视高度分别确定**：机位平视不自动代表人物视线平视。先依据对手的实际站姿、坐姿、蹲姿及相对眼高确定注视方向；身高接近且同样站立时，以接近水平的对视为常规，不用明显仰头／低头表现强弱。真实高度差、地形差或主动俯身等须有对应依据，并在反打中保持。
- **正面单人取景可采用近轴线视点**：摄影机靠近对手所在的观看位置，主体脸朝近镜头方向，眼睛看镜头旁的对手。需要让观众占据对手视点时，明确主观视点；看镜头旁、看镜头及直接对观众说话分别表达，不把所有正反打固定成侧脸，也不为单人取景改变双方的真实站位。

### 4.2 主观视点（POV）

摄影机占据某个角色的观看位置，让观众随该角色获得信息。先说明是谁在看、所处位置与姿态、起始视线和可见范围；眼睛高度随角色站立、坐下或俯身的实际状态确定。过肩取景从角色身后观察，主观视点从角色眼睛的位置观察，两者不混写。

- **身体局部按动作需要入画**：伸手、持物或低头看脚下时，可见的手臂、手套、鞋等保持该角色身份与状态；不强求每个主观镜头都露双手，也不把角色全身正面放在其自身视点前方。通过镜面看自己时明确反射关系。
- **视线变化有原因与落点**：写清先看到什么，什么声音、动作或发现引起转头／抬眼，变化中显露哪些信息，最后看向哪里。摄影机转向对应观察方向改变，向前移动对应角色实际靠近，不把抬头写成摄影机升高或无依据地飞离身体位置；晃动幅度按实际动作选择，不因POV默认剧烈摇晃。
- **控制信息出现的顺序**：门、前景遮挡与视线范围可以限制角色当下所见，随着角色动作再揭示空间或对象；关键物在角色尚未看见时，不同时要求在其主观画面中清楚出现。静帧只写选定时刻，连续揭示写入视频过程，参见[主观观察示例](#108-示例f主观视点中的动作与发现)。

## 5. 镜头运动

| 条目 | 含义与用途 | 描述重点 |
| --- | --- | --- |
| 推镜头 | 摄影机向主体靠近，逐渐集中注意力 | 写明从何种景别推到何种景别、速度和停止位置；区分机位前移与仅变焦 |
| 拉镜头 | 摄影机远离主体，让周围环境逐步进入画面 | 明确拉开后揭示什么，而不只是机械后退 |
| 横移镜头 | 摄影机向侧方平移，展示横向空间及前后景相对位移 | 写明画面方向、主体是否同步移动、相对距离是否保持 |
| 摇镜头 | 摄影机位置基本不变，转动观察方向以跟随或揭示 | 指定向哪侧或上下转动、跟随谁、何时落定；与摄影机横移、升降分别表达 |
| 升降镜头 | 摄影机整体升高或降低，改变观察高度和前后遮挡关系 | 指定起止高度感及新看见的内容；升降与俯仰转动可以配合，但不是同一动作 |
| 跟随镜头 | 摄影机随行动主体移动 | 指定跟随方位、距离、速度和主体在画面中的位置；不默认手持晃动 |
| 环绕镜头 | 摄影机围绕主体沿弧线移动 | 写明方向和大致弧度，不把“环绕”默认写成完整360° |
| 固定镜头 | 摄影机机位及取景保持稳定，由人物或环境产生变化 | 写清镜头内部的动作、停顿与注意力变化；固定不等于画面没有表演 |
| 希区柯克变焦（Dolly zoom） | 摄影机前后移动，同时反向变焦，使主体画面大小大致不变、背景空间感发生变化 | 描述主体尺寸与背景变化；用于需要该视觉效果的时刻，不与固定焦距要求冲突 |
| 甩镜 | 摄影机快速转动形成急剧视线转移，常伴随运动模糊 | 指定起点、方向、落点，以及落定后需要看清的内容 |
| 遮挡转场运镜 | 利用前景遮满画面的时刻连接另一镜头 | 写明遮挡物及进入、退出方向；区分连续移动与遮挡中隐藏的剪切，不把转场当成静态效果 |

### 5.1 构图与运镜的配合

先判断这一镜是保持观众注意、跟随动作，还是改变观众看见的信息、体验距离或压力感，再选择构图与运动。摄影机运动可以承担情绪和观看立场，即使没有揭示新物件也有作用；固定镜头也能通过人物走位、手势和视线形成变化。比较的是具体观看效果，不以“能拍清”就一律固定，也不把情绪变化直接等同于必须推近。

| 画面需要 | 可以怎样配合 | 过程与落点写什么 |
| --- | --- | --- |
| 突出一句话或一个反应 | 从关系清楚的双人或分层构图推向主要人物，按需要配合小幅摇镜重新取景；也可保持单人固定近景 | 从谁转向谁、何时靠近、最后的裁切与视线留白；人物真实位置不因居中而改变 |
| 让观众发现旁观者或证据 | 从单人或局部构图拉开，或借已有门框、前景遮挡作横移揭示 | 谁或什么原先不可见、何时显露、揭示后怎样组织主次；需要识别时再安排相应清晰区域 |
| 跟随人物接近或撤开 | 以三分或留白构图给行动方向留空间，按路径跟拍或摇镜 | 主体在画面中的位置怎样保持或改变、背景如何移动、最终停在哪里；不能为保留留白搬动门窗 |
| 看清放下、拾起或交接 | 选择容纳身体与接触点的景别，按动作需要俯仰摇镜、升降或跟随 | 手、物和落点在运动各阶段怎样保持可见；动作完成后是否回到面部，不能只描述漂亮的首尾 |
| 交代多人关系及其变化 | 依据有剧情动机的站位与行动，通过机位和取景形成三角重心或前中后景分层，按信息需要固定、横移或小幅绕行 | 主要说话者、回应者、旁观者的层次与遮挡怎样变化；检查运动路径中的轴线、视线及相互遮挡，不为几何形状重排已确认的站位 |
| 保持门窗框景或建筑对称 | 用固定镜头保留结构，或沿明确路径推拉，让内部主体的尺度变化 | 门框何时退出画面、对称轴是否保持；若随后改成单人取景，写明构图转变，不同时要求始终完整框景 |

描述动态构图时，将选择展开为“起始画面关系—表演或信息触发—摄影机／焦点变化—结束画面关系”。这是组织说明的方法，不是新增字段或固定运镜顺序。浅景深不自动产生焦点转移，横移也不自动保证三层主体始终清楚；分别说明需要保持清晰和此时才被揭示的对象。

同一任务有多种可行方法时，按观看效果和代价选择，不把下表当作优先级或固定配方：

| 当前条件 | 可选方法及取舍 |
| --- | --- |
| 人物原地对峙，双方反应都有作用 | 固定双人／分层构图便于同时读出关系；推近或切单人能强化一方的体验，但会减少另一方的可见反应。按此刻的表演重点决定保留谁。 |
| 前后主体都已入画，注意力从一处转到另一处 | 固定机位调焦可改变清晰中心而保留构图，写清起止清晰对象和触发；若双方必须同时辨认，保持所需景深并用表演引导。需要露出遮挡后的内容或改变观察位置时，再考虑横移、绕行或切镜。 |
| 人物沿明确路径移动 | 固定构图让观众观察人物与环境关系的变化；摇镜能跟随方向，但主体尺度可能变化；跟拍适合维持体验距离与人物尺度，须安排可成立的摄影机路径。 |
| 局部证物需要被发现和辨认 | 摇镜／横移可交代发现过程，拉开可交代其所在关系；原取景无法读清细节时，用收紧或细节镜头。露出物件与看懂证据分别安排，不让物件刚入画就切走。 |
| 要让观众感到压力增加或疏离 | 推近可缩短体验距离，拉开可加强隔离；固定构图也可通过逼近、沉默或环境尺度表现压力。以表演、节奏及前后镜的对照判断，不把推拉与某种情绪永久绑定。 |

信息揭示同时考虑可见时点、清晰范围、画面大小和辨认时间。运动中已经能够读清的内容不必额外停住；快速掠过、调焦尚未完成或细节过小时，应调整运动、取景或切点，让关键信息有可读阶段。时间按具体内容安排，不统一规定停留秒数。

检查运动中间是否裁掉关键脸部、手或接触点，遮挡是否提前泄露或推迟了信息，以及终点是否能接下一镜。不能同时要求机位和取景完全固定又推拉摇移，也不能要求对手逐渐出画却在结束时仍双人完整同框；必要时改写起止关系或选择有作用的切点，不为保住某个构图名称牺牲剧情。

## 6. 光影类型

| 条目 | 含义与用途 | 描述重点 |
| --- | --- | --- |
| 自然光 | 由太阳、天空等自然光源形成照明 | 写明时间、天气、入光方向；自然光不必然柔和 |
| 柔光 | 阴影边缘过渡柔和，表面明暗变化平缓 | 说明照明方向与需要保留的立体层次，不等同于没有阴影 |
| 硬光 | 阴影边缘较清晰，明暗形状明确 | 明确投影来源和位置；是否高对比还受补光等因素影响 |
| 逆光 | 主光位于主体后方，可能形成透光、边缘亮线或剪影 | 明确是否保留正面细节，不默认把主体压成黑影 |
| 轮廓光 | 主体边缘受光，与背景分离 | 指定受光边缘及强弱，不把真实边缘照明写成自发光描边 |
| 伦勃朗光 | 人像暗侧面颊保留小三角亮区的布光样式 | 说明主光方向和暗侧细节，不能只写“一半脸亮、一半脸暗” |
| 百叶窗切割光 | 光穿过条状遮挡形成明暗条纹 | 条纹需与光源、遮挡物和承接表面的方向一致 |
| 波纹光 | 水面等反射或折射形成的波动光纹 | 明确光纹来源及落在何处，不无依据地给任何室内加水波 |
| 雾化体积光 | 光穿过雾、尘等介质产生可见光束或光路 | 说明光源、方向及介质浓度，兼顾主体和空间的辨认 |
| 镜头炫光／光晕 | 强光入射产生可见光斑、条纹或柔化光晕 | 指定光源所在方向、影响范围和强弱；保留关键表情、口部及物件，不默认全画面蒙白 |

光源来源、光的软硬、方向和可见图案可以组合，例如“窗外阴天漫射光，从画面左侧进入”。不必在这些条目中只能选一项。

## 7. 焦段、景深与特殊光学表达

下列焦距数值按全画幅等效视角作交流约定，不规定真实设备或生成参数。焦距、拍摄距离、光圈及画幅共同影响画面观感；同一机位只换焦距，不等于改变透视关系。

| 条目 | 含义与用途 | 描述重点 |
| --- | --- | --- |
| 24mm广角 | 较宽视野，适合交代环境与前后景关系 | 写清主体距离与边缘位置；近距离人像可能产生夸张观感，不用于无意改变人物比例 |
| 35mm人文 | 常用于人物与环境共同入画的观察方式 | “人文”是用途俗称，不能代替主体大小、背景范围和机位说明 |
| 50mm标准 | 常作为全画幅标准焦段的表达 | 不能保证“完全等同人眼”；仍需指定距离和构图 |
| 85mm人像 | 常用于较窄视角的人物画面，在维持相近人物大小时通常需拉远机位 | 写清所需空间观感和背景范围，不默认必须浅景深 |
| 浅景深 | 清晰范围较窄，将注意力集中于某个距离上的主体 | 明确谁清晰、前景／背景如何虚化；需要识别的另一人或道具不能无意失焦 |
| 深景深 | 较大距离范围内的内容保持可辨认 | 指明哪些前、中、后景需要清晰，不把它写成所有距离绝对锐利 |
| 分裂焦点镜（Split-field diopter） | 让画面不同区域、不同距离的前后主体同时清晰 | 指定前后主体及位置；不是分屏、重影、复制人脸或焦点来回切换 |
| 移轴微缩 | 利用选择性清晰区域等视觉线索营造模型般的观感 | 明确清晰带与虚化区域；移轴镜头不只用于微缩，此处仅讨论微缩效果 |
| 探针镜头 | 细长镜身提供贴近微小物体、深入狭窄空间的拍摄可能；部分型号采用广角微距设计 | 写清低机位、近距离主体和背景关系；不等同于望远镜或必然极浅景深 |
| 超广角 | 比常规广角更宽的视野，突出环境包围与近大远小的空间关系 | 明确靠近镜头的物体、画面边缘及人物距离；不以夸张面部变形代替人物表演 |
| 鱼眼效果 | 用明显弯曲的线条和宽视野形成特殊观察感 | 写清畸变范围与主体位置，按明确的主观或风格需要使用；不等同于普通广角 |
| 长焦空间压缩感 | 在保持相近主体大小时，以较远机位和较窄视角呈现主体与背景较贴近的观感 | 同时交代拍摄距离、背景范围与人物关系；不是站在原地只变焦就改变透视 |
| 微距细节 | 放大呈现微小主体或表面结构，突出纹理、接触和细微变化 | 指定细节对象、实际取景尺度与清晰范围；局部面部特写不自动等于微距 |
| 运动模糊 | 主体或摄影机运动形成方向性模糊，帮助表现速度 | 写清谁清晰、谁模糊及运动方向；与整体失焦区分，不以模糊遮住必须看清的动作结果 |
| 双重曝光／叠影 | 将两组画面元素有意叠加，用于已明确的记忆、联想或风格表达 | 指定两层内容、主次、透明关系与出现范围；不把叠影误写成场景中多出一个实体人物 |

描述特殊镜头效果时，应写明观察位置、空间关系和清晰区域，不要求镜头设备本身出现在画面中。广角微距探针可保留较多背景细节，不能把所有探针镜头统一解释为“极浅景深”。

## 8. 色调与氛围

| 条目 | 含义与用途 | 描述重点 |
| --- | --- | --- |
| 冷色调 | 画面整体或指定区域偏蓝、青等色彩倾向 | 说明作用区域与程度，保留人物、服装和道具的必要辨识色 |
| 暖色调 | 画面整体或指定区域偏黄、橙等色彩倾向 | 区分光源本身偏暖与整体调色，不把暖色固定等同于温馨 |
| 低饱和 | 降低色彩鲜艳程度 | 保留剧情需要识别的颜色差异；低饱和不等同于低对比 |
| 高对比 | 增强明暗差异 | 指定哪些暗部／亮部仍需细节；不能为戏剧性丢失关键内容 |
| 黄金时刻 | 低角度日光形成的时间与照明条件，常见于日出后或日落前 | 与地点、时间、窗户朝向相容；它不是纯粹的调色名称 |
| 漂白旁路（Bleach bypass） | 源自胶片处理的观感，通常表现为低饱和、较强对比和较深暗部 | 描述目标视觉结果，不要求模型真的处理胶片；不等同于乳白低反差 |
| 钠灯琥珀色 | 借鉴钠灯照明的黄橙／琥珀色观感 | 指定灯光影响的范围，避免无依据改变所有物体固有色 |
| 乳白低反差 | 以较柔和的明暗关系、抬起的黑位等方式形成轻淡观感 | 保留主体与背景的分离和细节，不等同于必须过曝或覆盖浓雾 |

## 9. 辅助表达要素

- 留白与负空间的安排见[构图方式](#32-构图方式与裁切说明)。
- **眼神光**：眼中可见的小面积光源反射，有助于眼部可读性；不是让眼睛发光。
- **银灰色倾向**：以灰、冷灰及银色观感组织画面色彩，不等于留银胶片工艺。

## 10. 组合方法与描述示例

### 10.1 组合骨架

可按以下顺序组织视觉意图，但它不是必填字段表，也不是任何模型的最终提交格式：

**主体与行动 → 场景及空间关系 → 景别与构图 → 观察角度 → 必要的运动 → 光源与光质 → 焦点及景深 → 色调与整体风格。**

静态画面省略运动过程，直接描述该时刻。动态画面还需说明开始状态、变化过程和结束状态；对白、声音和切镜时间按实际内容及模型格式表达，不能被视觉术语清单取代。

有连续性要求时，分别说明哪些内容保持、哪些内容变化。例如换成近景可以减少背景入画，但不能因此改变房门位置、人物衣服或道具结构。

### 10.2 示例A：清晰展示一个道具

> 白色背景上，一把旧黄铜钥匙完整居中，钥匙齿形、圆环和表面磨损清楚可辨。镜头正对主要展示面，钥匙各部分处于可辨认的清晰范围内。柔和侧光表现厚度和金属质地，保留轻微接触阴影，不加入遮挡、戏剧性暗部或环境氛围。

重点：用构图、景深和光线服务结构辨认；本示例不规定资产应有几视图或采用何种尺寸。

### 10.3 示例B：叙事画面的静态开场

> 旧茶室内，一位成年女子坐在桌边，手指刚触到尚未拆开的信封。中近景，镜头位于桌边空位、略高于桌面，斜看女子，脸与信封同时入画。她位于画面右侧，画面左侧留出通往门口的空间。窗外柔光从画面左侧进入，脸部和信封可辨，远处茶柜略虚化。画面保持项目原有动画风格，木色温和，但不覆盖人物服装的固有色。

重点：写明这一刻的动作状态、注意力中心和空间，不在静态图里要求镜头完成推进或人物连续拆信。

### 10.4 示例C：将开场发展为动态镜头

> 开场保持女子手指触到信封的中近景。她听到画外脚步，手指停住，抬眼望向门口。摄影机只在她抬眼时缓慢靠近，最终停在能读清表情、仍保留信封边缘的近景。她问：“是你放在这里的？”说完继续看向门口。窗光方向与茶室布局保持不变，脚步声停止后保留室内环境声，不添加配乐。

重点：运镜有明确触发和落点，人物有动作、反应与交流。这是视觉／声音组织示例，不是H3等模型的完整提示词，不用于替换任何项目已批准的剧本。

### 10.5 使用时的简短自查

- 观众首先应看什么，描述是否支持这个重点？
- 关键脸部、动作、物件和空间是否看得清？
- 机位、运动、景深、光线之间是否相容？
- 按“最初看哪里—何事触发—中间必须看清什么—最终获得什么—怎样接下一镜”推演，遮挡、裁切、焦点和辨认时间是否支持这一过程？多项变化同时发生时，是否挤掉关键动作或反应？
- 连续画面的身份、造型、空间和状态是否保持？
- 术语是否落实为可见／可听的结果，而非堆叠形容词？

### 10.6 示例D：对白场景的光影、景深与遮挡

> 夜晚林间，一名女子位于画面偏左，望向画面右侧的画外对手。平视面部特写，双眼和嘴唇清晰，保留自然皮肤与衣料纹理。冷白柔光从画面右侧前方照亮面部，远处雾中逆光将人物轮廓与背景分开；前景较暗，面部仍可辨认。画面边缘的枝叶柔和虚化，避开眼睛、嘴和本镜关键动作；身后树干与焦外雪花形成柔和散景。她听完一句话后收紧目光，短暂停顿，再开口回应。

重点：同时明确表演、清晰主体、前景遮挡、背景分离和面部可读性。光色、天气及遮挡物按具体场景选择；需要辨认的第二人物或道具进入画面时，重新安排焦点与遮挡，不沿用使关键信息失焦的描述。此示例不规定所有对白都使用特写、浅景深或固定照明。

### 10.7 示例E：多人层次与动态重新构图

**交代关系**：院中女子位于画面右侧的中间层，面向画面左侧的男子；男子在前景左缘仅露肩颈，几位见证人位于背景院门内。女子的脸、必要手势与背景见证人互不遮挡。按已有站位选择机位，让三处视觉重心形成有主次的三角关系；院门为见证人形成框景。开场暂时固定取景，让说话和反应改变注意力。

**转向反应**：女子听到质疑后停住手，抬眼看向男子。摄影机此时缓慢向女子靠近，配合小幅摇镜让她接近画面中央，停在保留头顶、下巴及本镜必要手势的近景；男子的前景肩颈逐渐出画，院门框景随收紧退出取景。她回应时镜头已经停定，视线仍落在镜头旁的男子身上。人物与院门的位置、对视方向和场景光源不变。

重点：前中后景、三角关系和框景服务关系交代，推近与重新构图服务反应；不要求两种构图同时维持到结束。若这一镜的任务是让观众辨认见证人的反应，应保留相应取景或安排有依据的切镜，而不是照搬收紧到女子的方案。静态首帧只写所选开场瞬间，动态变化进入视频描述；示例不替代具体剧本，也不规定反击台词一律推近居中。

### 10.8 示例F：主观视点中的动作与发现

> 从一名站在殿门外的成年探索者双眼位置观察，起初略向下看半开的门缝，画面下缘可见他的袖口和双手。双手将两扇门向两侧推开，门后逐渐显露殿内地面与前方石像底座。门开到足以看清底座后，探索者留在门外抬眼，视点在原处缓慢向上转，沿底座看向石像面部，最后停住。双手随视线抬高退出画面，摄影机不升空、不切到角色外部视角。

重点：手部动作打开视野，随后转向揭示对象的高度；推门、向上观察与摄影机升高分别表达。此例只演示主观观察的组合方式，实际对象、衣着、姿态与动作沿项目设计确定；静态首帧只采用开场状态。

**模型执行验证**：未验证；本示例尚无对应模型、模式及参考输入条件下的实际反馈，不作为任何模型的能力保证。
