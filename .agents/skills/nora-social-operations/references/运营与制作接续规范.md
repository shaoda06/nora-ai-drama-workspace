# 运营与制作接续规范

## 接续入口

主技能的业务接续检查从这里进入，不在各制作技能重复维护运营规则。定位或首次提出运营需求时进入[模块01](../modules/01-运营启用与账号连接/README.md)。阶段明确时只处理当前动作；项目无运营需求时，不建立后台采集、发布包或报告任务，封面等展示需求仍可独立使用对应模块。

| 时点 | 读取与落实 |
| --- | --- |
| 开始或继续剧本、分镜、剪辑、封面等制作 | 读取[模块06](../modules/06-后续制作参考与指导/README.md)，筛选对当前对象有影响的报告结论，记入已有工作稿；相同报告与任务未变化时复用已有采用判断 |
| 分段后处理完成并采用 | 按[模块04](../modules/04-发布准备与记录/README.md)交付人工剪辑所需素材及最终导出目录，保持分段制作完成状态，不误记整集已导出 |
| 最终成片交接与准备发布 | 模块04核对最终文件、文案、封面、时间及模块06适用建议，整理发布包 |
| 作品发布后 | 模块05采集实际数据、结合成片和此前采用记录复盘；报告建议等待相应制作或发布阶段使用，不主动启动改图改片 |

## 项目目录与创建时机

项目配置与运营资料统一归项目内 `10-社交媒体资料/`，最终交付归 `98-成片交付/`；制作过程仍归 `09-剧集制作/`。所有项目最终成片采用相同目录，是否社交发布只影响运营材料。

| 创建时机 | 位置及内容 |
| --- | --- |
| 项目初始化 | 建立98号交付根目录；发布意向按模块01记录，未启用不预建空运营材料 |
| 首次启用运营 | `10-社交媒体资料/项目运营配置.md`；定位文档引用配置，具体字段只维护一份 |
| 首次落地个人页或封面 | `10-社交媒体资料/个人页资料/`或`封面资料/`，索引和工作稿按模块02、03创建；非社交用途也可按需启用封面资料 |
| 初始化单集制作 | 同时提前建立 `98-成片交付/EPxxx/成片/`，告知用户人工剪辑后的导出路径；不会因尚未准备发布包而缺目录 |
| 片头或片尾正式交付 | `98-成片交付/片头/`、`片尾/`，保存可供人工剪辑使用的交付文件，制作分段和源记录仍在09号目录 |
| 准备本集发布包 | 在对应EP目录补齐`发布说明.md`、`发布文案.md`和`封面/`，不建按平台或时间分层的目录 |
| 首次实际发布 | 项目运营目录的`发布记录.md`按平台与作品记录实际发布事实 |
| 采集与复盘 | `10-社交媒体资料/运营复盘/EPxxx/`保存报告及`采集资料/`；报告和快照使用实际日期时间区分 |

项目、单集目录按[初始化工具](../../nora-ai-short-drama/references/共用规则/项目初始化规范.md#2-创建项目目录)执行；其他资料首次有实际内容再建立。未发布项目只需要单集成片目录，无需空发布文案、封面或报告。

## 状态与归属

分段制作完成、待人工剪辑、最终成片已确认、发布包就绪、已发布分别记录于已有项目进度／发布说明和发布记录，不用一个“完成”代替全部状态。用户剪辑包括片头片尾拼接、音量调整和瑕疵修剪；Agent后处理不能推定这些工作已完成。

正式成片只保存在98号对应集目录，不复制到10号或另一套成片总目录。10号维护各用途当前正式封面，98号保存当集实际发布封面快照；新版通用封面不覆盖已发布快照。发布记录引用实际交付包和作品，复盘引用发布记录，后续采用写入当前工作稿，不新增重复制作台账。
