# 个人页视觉制作与管理规范

## 设计规范

本文件提供头像与主页背景图的通用设计方法。技术规格按[目标平台资料](平台个人页规格库.md)选择；人物形式、画风、配色、文字和具体构图依据本项目与本次选定方案，不预设统一视觉风格。

### 按用途讨论

先按任务读取项目定位、所需人物资料及已采用视觉的有效记录，提取当前设计依据，不默认重读全项目或查看全部图片。视频封面可以提供设计参考，头像和背景图仍按各自用途构图，不默认直接裁切封面。

头像方案按主体类型说明辨认特征、构图和背景，使方案之间可以比较；人物头像再说明取景、站位和表情，图形、标志或文字头像不套用人物字段。主体在小尺寸下应容易辨认；多人构图应保留各自辨认所需的面积。显示裁切形状和安全区域由目标平台决定；仅当该平台采用圆形裁切时，才按圆形范围安排核心内容。预留必要余量，避免重要信息被实际裁切或界面元素覆盖；平台裁切形状与画面是否设计边框分别确定。

主页背景图按目标平台实际可见区域、遮挡位置和当前账号资料布局安排主体、文字及装饰。与头像保持适当的画风、配色或图形联系，两图各有重点；不要求重复同一主体、文字或构图。平台截图用于确认当前显示关系，不把单一设备上的位置扩大为所有平台或客户端的固定布局。

### 背景图方案与显示适配

比较方案时，分别说清主视觉、文案、布局及与头像的搭配方式，让方案在画面重点上有所区别。头像可以只提供配色、画风或图形参考；提示词写明实际采用的参考用途，不因传入头像就默认复制其人物、方形构图或全部元素。是否重复人物、是否使用文字及候选数量，按本次方案和授权确定。

排版时区分完整画布、平台默认可见区域和界面／设备覆盖区域。主文案及核心图形放在实际可见且未被遮挡的位置，外围与可能被裁掉的部分承载次要装饰。安全区域依目标平台、客户端及设备显示确定，不设通用的固定坐标或留白比例；具体平台依据见[平台规格库](平台个人页规格库.md)。用户提供的实机截图或试用反馈用于修订位置，没有实际反馈时不宣称已通过实机验证。

用户要求“整体移动”时，明确一起移动的文字、主体和相关装饰，将它们作为一组描述，保留相对位置、大小、字形及换行；同时写明方向、建议幅度、露出背景的补齐方式和需要保全的内容，避免只移动标题或通过缩放、变形挤出空间。位移数值和最终采用位置记在项目工作稿，不固化为通用参数。只移动文字等局部要求则按其实际范围执行。

### 参考与提示词

有参考素材时，按本批授权确定其用途和保留范围：项目已有素材使用相应已批准版本，用户明确指定用于本任务的原始参考记录指定依据，不把输入资格当作输出已采用。选用与本次表现形式相符的素材；没有参考素材且任务允许从文字设计时，不强制补人物图或其他参考。逐项注明来源、版本与用途；多视图用于提取设计时，不复刻其网格、标注或主体副本，不叠加互相冲突的画风要求。只保留本次需要的依据，不将项目具体设计写入通用规则。

输入资格按[共用源图资格](../../../nora-drama-assets/references/图片提示词规范.md#源参考图与输入资格)，编辑源及换源按[共用修订规则](../../../nora-drama-assets/references/图片提示词规范.md#参考图统一修订规则)，图片查看按[主控看图边界](../../../nora-ai-short-drama/SKILL.md#看图能力调用边界)。自由组织本次完整提示词，写清主体、构图和背景；有表情、文字或参考素材时再说明相应要求，不设置固定生图提示词模板。准备好且已获授权后按[生成与记录](个人页视觉制作与管理规范.md#生成与记录)接续。

需要选择或细化取景、构图、光影及焦点时，调用[镜头语言与表达](../../../creative-techniques/SKILL.md#镜头表达)；按已选方案落实为静帧描述，平台可见区域及安全裁切仍按本专项执行。候选写法的首次使用提示和针对性实际反馈沿该技能处理，图形／文字排版不强套摄影术语。

人物头像或背景图有指定表情时，编写提示词调用[表情拆解](../../../creative-techniques/SKILL.md#表情表达)，把方案中的抽象表情落成静帧可见状态；首次使用说明与收到具体表情反馈后的验证更新沿该技能，不将单纯采用整图视为表情已验证。

### 规格依据

分别记录目标平台的官方要求、用户指定值和建议交付值，以及适用账号类型。涉及当前限制时核实最新官方依据；平台用户发布的教程不能当作官方规范。缺少依据时如实注明，用户提供的规格可作为当前制作输入，不据此声称已核实官方要求，也不套用其他平台的数据。

平台共有的读取字段、各平台具体数值及适用状态统一维护于[平台规格库](平台个人页规格库.md)。选定的项目画面方案及用户决定写入该账号工作稿，不回填本设计规范。

## 保存与采用

项目内的账号视觉使用 `10-社交媒体资料/个人页资料/`，与同级 `封面资料/` 分开；首次实际落地时按需建立，不预建空目录。平台与账号代号用于区分物料，不将账号真实联系方式写入通用技能。

| 内容 | 固定位置或命名 |
| --- | --- |
| 正式索引 | `10-社交媒体资料/个人页资料/账号视觉索引.md` |
| 正式头像 | `10-社交媒体资料/个人页资料/头像/{平台}-{账号代号}-头像.{扩展名}` |
| 正式背景图 | `10-社交媒体资料/个人页资料/背景图/{平台}-{账号代号}-背景图.{扩展名}` |
| 工作稿 | `10-社交媒体资料/个人页资料/其他资料/工作稿/{平台}-{账号代号}-主页视觉-工作稿.md`；使用[主页视觉工作稿模板](templates/个人页视觉制作工作稿模板.md) |
| 原生候选 | 工作稿同级 `素材/{平台}-{账号代号}-{头像或背景图}-候选-vNN-原生.{扩展名}` |
| 尺寸处理版 | 同一素材目录，使用 `{平台}-{账号代号}-{头像或背景图}-候选-vNN-{宽}x{高}.{扩展名}`；原图保持 |
| 请求与结果附件 | `10-社交媒体资料/个人页资料/其他资料/执行附件/{平台}-{账号代号}-{头像或背景图}-生成记录-NNN/` |
| 被替换正式图与记录旧版 | `10-社交媒体资料/个人页资料/其他资料/历史版本/`；按[共用历史归档命名](../../../nora-ai-short-drama/references/共用规则/文件版本与工作稿规范.md#归档与版本留存)保存 |

文件扩展名对应实际文件格式；原生图沿其实际格式保存，交付格式按目标平台和本批约定选择，不将某个平台可用的格式设为通用固定格式。

候选前缀由该用途的正式图片名去掉扩展名确定，沿[共用命名要求](../../../nora-ai-short-drama/references/共用规则/文件版本与工作稿规范.md#素材与执行附件)保持同一身份。`原生`与具体宽高是本专项规定的版本标识，不再追加工具、模型或任意说明后缀。

索引逐项记录平台／账号、图片用途、正式文件、采用候选版本、实际宽高与格式、采用依据及处理记录；尚未采用的对象不填正式文件。工作稿分别维护头像和背景图状态，不把一张图片的批准扩展到另一张。

生成、尺寸处理和用户采用分别留证；获采用且达到本批交付规格后，才保存正式图并更新索引。既有暂存候选及记录保留原处，沿已有入口接续；技能建立不自动授权迁移、改名或采用它们。首次归位需有对应整理授权，并保留来源及引用。

实机试用、位置修订和新版采用继续记录在同一账号工作稿；“先试一下”不等于正式采用。采用、替换及结束比较按[主控完成标准](../../../nora-ai-short-drama/references/共用规则/主控操作规范.md#完成标准)完成状态收尾，正式索引引用对应候选的同一审阅决定。正式路径被新版替换后，在旧版原采用记录补上归档入口，保留当时批准事实，避免该路径被误认为仍指向旧图。

浏览展示按[项目浏览规范](../../../nora-ai-short-drama/references/共用规则/项目浏览与同步规范.md)处理；当前解析器未支持的类型直接交付真实文件及记录链接，说明入口限制，不假称已接入，不修改共用网页来迁就单个项目。维护相关项目进度时仅更新本次对象，不改其他制作状态。

## 生成与记录

本文件只维护社交媒体头像、主页背景图的执行衔接和记录；设计、平台规格及保存位置从[技能入口](../../SKILL.md)按当前动作分流读取。实际执行进入[Nora生成技能](../../../nora-generation/SKILL.md)，不在本技能另建模型、工作流或后台监控。

### 能力与授权

沿[主控生成选型](../../../nora-drama-assets/references/图片提示词规范.md#当前参考图生成选型)确认本批能力、对象及数量。能力按当前任务、实际可用性及本批授权选择；某个项目曾使用的工具不成为本专项的固定默认，已明确选择则不重复询问。只写方案或提示词不调用生成。

内置Imagegen复用[任务与提示词](../../../nora-generation/references/Imagegen生成与尺寸处理规范.md#1-任务与提示词)、[子代理执行](../../../nora-generation/references/Imagegen生成与尺寸处理规范.md#子代理执行与父代理交付)的固定执行代理、真实工具调用、输入读取、结果转发和一次调用边界。头像和背景图不属于既有固定收尾脚本的五种登记类型，交接及记录使用下方专用衔接；不冒充人物基础图、剧集素材或封面，不向不支持的接口提交伪造类别。

### 社交图片交接与结果

1. 内容负责人按已确定的任务准备完整提示词、参考素材及其顺序与使用依据（若有）、请求比例、交付目标、授权数量，以及本次候选和原工作稿入口。请求JSON和实际提示词TXT保存在本次执行附件；请求以`kind:"社交媒体"`、`formal`、`draft`和`output`给出本图身份与路径，保存前执行[只读命名核对](../../../nora-ai-short-drama/references/comfyui-scripts/README.md#图片的只读命名核对)，按[专项命名](个人页视觉制作与管理规范.md#保存与采用)准备原生或尺寸处理版。核对通过不表示已生成或批准；这些是本批数据，不新增调用脚本或独立台账。
2. 按Imagegen规范的固定模型、等级及 `fork_turns` 派发执行子代理。子代理按当前工具说明调用内置Imagegen，原样提交本次正文和参考图，在同次调用中先保存完整返回值再转发图像。文生图不要求传入参考图；单项交接只执行一次；原生尺寸差异不自动重试，收尾失败只恢复保存与记录，不重生图。
3. 子代理使用工具真实输出路径，将原字节复制到本次原生候选位置，保留工具输出；核对可解码性、真实尺寸、格式及数量，保存实际调用结果凭据JSON。来源不明时按Imagegen规范回报缺项，不猜测其他任务的最新文件，不自动看新输出。
4. 子代理按[主页视觉工作稿模板](templates/个人页视觉制作工作稿模板.md)在原稿补齐生成和待审记录，并返回原生图路径、实际规格、记录入口和真实异常。这里按专用记录保存文件，不调用只支持旧类型的 `imagegen_results.py prepare/complete`，也不伪造其成功报告或网页核验。父代理复用已完成的技术核对，直接交付候选；按实际账号资料栏目核对正式采用记录，不将候选存在视为已采用。

此专用衔接仅用于头像与主页背景图；既有五类图片仍使用原固定脚本，不因这一分支改成手工登记。使用Qwen等备选能力时，先按其现行执行入口核实本用途能否如实提交与登记；不支持时说明具体限制，不借用别的图片类型绕过，不自动改工具或共用代码。

### 尺寸处理与交付

保留原生图与实际尺寸，按[目标平台规格](平台个人页规格库.md)和本批约定核对该图片用途的宽高、比例、格式及上传限制。原生图已达标时直接送审，并按用户决定采用，不额外缩小；推荐值或最小尺寸不等于精确输出尺寸。仅在用户明确要求精确尺寸或适用的上传限制确有需要时制作尺寸版本，并与原图关联，不把处理版标为原生图。原生图不满足本次要求时如实记录，按本批授权完成必要处理；明确要求严格比例时，不把近似比例写成达标。裁切、补边和扩图按其实际授权处理；不为凑尺寸拉伸人物或自动裁掉重要内容。只有确需提高分辨率时才考虑超分，并沿[图片后处理方式选择](../../../nora-generation/references/ComfyUI-图片超分执行规范.md#指定尺寸处理的方式选择)执行。

同一张画面的原生与尺寸处理版不计为两次生图。处理记录保存在该次执行附件，写明输入／输出、原尺寸／目标尺寸、实际方法、是否裁切及授权依据，并在工作稿关联。新图片的采用决定由用户作出，不以“开始下一件事”推定上一张已经采用。

交付展示本次候选，给出可用文件链接及真实规格，简述使用能力、必要处理和待审状态。按本批授权展示各项候选；同一张画面的原生图与处理版选一份主要预览，其余版本和提示词提供链接，避免同图重复展示。不为交付额外生成未获授权的裁切预览、拼图或新方案。用户明确要求预览或内容检查时再按该范围处理。
