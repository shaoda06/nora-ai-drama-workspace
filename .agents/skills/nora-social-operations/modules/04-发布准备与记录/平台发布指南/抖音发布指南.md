# 抖音发布指南

适用：Chrome中对应项目profile的电脑端后台，单条视频；不适用于手机App、图文或直播。先读[共用流程](../发布准备与记录规范.md#发布资料与选项执行)，只在已获本次代发及具体排期授权后提交。下文“项目配置”指项目`10-社交媒体资料/项目运营配置.md`；“本集说明／文案”指`98-成片交付/EPxxx/发布说明.md`与`发布文案.md`。

页面字段核实日期：2026-10-30。适用范围为电脑端视频发布／定时作品继续编辑页；已发布作品的“编辑作品”“设置权限”分开提供，不把编辑页可见字段当作新建页全部字段。

## 入口与资料

- 发布入口：[抖音创作者中心](https://creator.douyin.com/) → 发布作品 → 发布视频；从后台导航进入当前表单，避免误入图文或旧作品编辑页。
- 结果检查：[作品管理](https://creator.douyin.com/creator-micro/content/manage?enter_from=publish)。登录跳转后先核对项目配置中的账号身份。
- 上传本集说明指定的`成片/`文件；标题、正文、话题只取发布文案的“抖音”章节；封面取本集说明逐项指定的横版和竖版文件，不能从封面资料中自行挑最新图替换。

## 填写顺序与选项

| 顺序／表单项 | 固定处理方式 |
| --- | --- |
| 视频上传 | 上传入口显示1小时以内、16G以内；支持4K，建议视频画幅16:9、9:16、3:4、4:3或9:19.5。推荐与支持要求分别记录；选择已确认文件后等待处理完成，不改变已采用成片画幅来套用建议 |
| 标题与作品描述 | 作品描述区含独立标题框“填写作品标题，为作品获得更多流量”（上限30）及正文／话题编辑区（计数上限1000）；分别填对应内容。按页面实际计数检查，不以字符串长度替代平台计数；必要压缩同步文案，实质改写先确认 |
| 话题 | 按已确认清单添加并检查实际标签，避免仅输入文字未形成标签或重复添加 |
| 横版封面、竖版封面 | 分别上传本集指定图，检查裁切并保存；关闭编辑面板后回读发布表单两个封面预览。比例与数量沿[封面规格库](../../03-封面制作/平台封面规格库.md) |
| 自主声明／AI生成声明 | 点击基础信息区“自主声明”打开单选弹层；六项为“内容由AI生成／内容为个人观点或见解／内容为转载信息／内容含营销推广信息／虚构演绎，仅供娱乐／无需添加自主声明”。真实AI生成内容选第一项，按“确定”保存；不能同时选AI与演绎，也不将某项勾选理解为已完成其他声明。只读核查使用“取消”退出 |
| 保存权限／允许他人保存视频 | 发布设置中“保存权限”直接提供“允许／不允许”；按项目批准值选中，项目未定先确认。已发布作品从作品管理“设置权限”核对，不能因编辑作品页没有这一项就判为不提供 |
| 可见范围 | “谁可以看”有“公开／好友可见／仅自己可见”；按本次或项目选值回读选中状态，未确定先确认 |
| 独立原创声明 | 本次定时编辑表单未提供独立原创开关；“虚构演绎，仅供娱乐”属于上述自主声明的单选项，不能另行叠加或把标题中“原创”当作平台声明 |
| 合集、位置、关联、同步、推广等附加项 | 实际有“添加合集”“视频章节”“添加标签－位置”“关联热点”“添加音乐”；未安排不新增，位置推荐不自动选，自动推荐封面／章节不等于正式选用。既有作品原关联保留 |
| 发布时间 | “发布时间”提供“立即发布／定时发布”；选后者并填写用户批准排期。当前提示“支持2小时后及14天内的定时发布”，按页面校验和显示时区再确认有效性；超出范围重新申请排期，不自动改立即 |

## 提交与异常

发布前按[代为定时发布](../发布准备与记录规范.md#代为定时发布)完成预览核对，确认时间有效后提交。定时最短提前量不足时提出新时间并请求调整授权，不能切到立即发布。提交后作品管理中核对条目是否显示定时发布／审核状态及批准时间。

处理失败、审核异常、编号／资质要求时进入共用[审核处理](../发布准备与记录规范.md#审核状态与异常处理)。需更改时间、取消或提前发出时，只定位原条目并按用户授权执行，保存前后状态。出现登录、验证码或协议确认按工具权限处理，不重复上传绕过。

## 检查、记录与收尾

从作品管理核对原条目的定时时间、审核／公开状态，尤其复核横竖两张封面、自主声明和保存权限。修改时间或提前公开后，记录真实结果及与原排期的差异。

按[统一记录与检查收尾](../发布准备与记录规范.md#记录与检查收尾)逐项执行：定时回执与选项核对写本集发布说明，实际公开后补项目发布记录，同步项目进度和工作台；向用户汇报后完成浏览器及一次性跟进收尾。日后检查的安排读取[发布后检查与临时跟进](../发布准备与记录规范.md#发布后检查与临时跟进)。

## 页面变化与补充范围

按[共用选项规则](../发布准备与记录规范.md#发布资料与选项执行)处理新增、改名或强制字段。定时提前量、可选日期范围、字数及上传限制按当前账号表单核实；页面没有某项记“不提供”，不伪记“已关闭”。账号差异及本次核实结果留在项目，平台通用变化再更新本指南。

AI声明字段含义参考[抖音安全与信任中心公告](https://trust.douyin.com/article/15868)；页面具体层级仍以当前账号可见入口为准。
