# 快手发布指南

适用：Chrome中对应项目profile的电脑端后台，单条视频；不适用于手机App、图文或直播。先读[共用流程](../发布准备与记录规范.md#发布资料与选项执行)，只在已获本次代发及具体排期授权后提交。下文“项目配置”指项目`10-社交媒体资料/项目运营配置.md`；“本集说明／文案”指`98-成片交付/EPxxx/发布说明.md`与`发布文案.md`。

页面字段核实日期：2026-10-30。已核对上传前入口、上传后新建发布表单与电脑端已发布视频编辑页；已发布编辑页省略作者声明、定时及部分权限，不把该页缺项误判为新建页不提供。

## 入口与资料

- 发布入口：[快手视频发布](https://cp.kuaishou.com/article/publish/video)，或[创作者平台](https://cp.kuaishou.com/) → 发布作品 → 视频。
- 结果检查：[作品管理](https://cp.kuaishou.com/article/manage/video?status=2&from=publish)。查询时同时区分待发布、已发布或全部作品，待发布条目消失不能直接认定作品丢失。
- 视频取本集说明指定的最终文件；文案取“快手”章节；封面使用本集说明指定的一个常规主封面。没有确定用横版还是竖版时先确认选用，不任取其中一张。

## 填写顺序与选项

| 顺序／表单项 | 固定处理方式 |
| --- | --- |
| 视频上传 | 上传入口显示1小时以内、最大12GB；支持常见格式，推荐MP4；最高支持8K，推荐1080p（1920×1080）及以上。推荐横版像素不构成竖屏视频必须改横版的要求；上传后核对实际文件 |
| 描述／文案 | 新建页与已发布编辑页均只有“作品描述”，没有独立标题框；已发布编辑页显示计数上限500，标题、正文和话题合并后检查整体计数。标题放首行，空行后接正文，再接话题，排版同步本集文案 |
| 话题 | 作品描述下有“@用户”“#话题”；按快手章节指定清单添加，核对实际标签，不追加无关热门话题 |
| 常规主封面 | 上传本集指定的一张图，按指定版式裁切并保存；返回发布页检查实际采用图。PK或多封面实验未指定不启用。规格读[封面规格库](../../03-封面制作/平台封面规格库.md) |
| 允许下载此作品 | 按项目选定值明确勾选或取消，提交前及可用的编辑页回读；项目没有值时先确认，不默认保留勾选 |
| AI内容声明 | 新建表单“作者声明”的单选下拉有“内容为AI生成／演绎情节，仅供娱乐／个人观点，仅供参考／素材来源于网络”。AI内容选“内容为AI生成”，不能照抄抖音“内容由AI生成”的字段值或叠选。已发布编辑页没有该下拉，不能据此清除已有声明 |
| 可见范围 | “查看权限”提供“所有人可见／好友可见／仅自己可见”三个单选项；按项目／本次批准值设置，不能把页面预选“所有人可见”视为用户已确认 |
| 同框、下载与同城展示 | 新建表单“允许别人跟我拍同框／允许下载此作品／作品展示在同城页”均为独立复选框，本入口预选开启。下载、同框按项目批准值执行；同城展示未安排时按共用可选功能规则关闭。下载关闭不等于同框或同城关闭。独立转载许可或原创声明开关未提供，不臆造或声称已关闭 |
| 合集、分类、位置、推广及同步等（页面提供时） | 按共用规则，仅启用明确安排的可选项；已发布编辑页地点区为所在地区和视频详细地址，未指定不填写。强制分类未定先确认，不凭项目名猜选 |
| 定时发布 | “发布时间”单选“定时发布”，使用“选择日期时间”控件，选完点日期面板“确定”，它不是页面最终“发布”。回到表单逐字回读批准日期时间；无效输入可能被控件回退，不能以曾输入过为准。日期禁选边界决定当前可排范围，不能套用其他平台14天；页面没有给出固定最小提前量文字，不把初始约1小时后的候选值当作已证明的最短提前量。所选时间被回退或拒绝时按排期规则重新确认 |

定时控件下会显示当前账号粉丝活跃时段及“一键设置”；这是本项目排期建议的候选依据，记录在项目资料，不能固化为平台通用时段，也不能点击后绕过用户对具体时间的批准。时间面板提示上传高峰可能延迟1～2分钟，实际公开时间仍须发布后核实。

“作者服务”当前可选“关联小程序／招聘人才”，未安排不选择类型或关联对象；上传完成后还提供“添加章节”，未采用不新增。新建页未提供独立合集选择，不能把管理页的“合集管理”当作本次已关联合集。

## 提交与异常

核对封面已保存、文案和选项正确后提交，从作品管理确认原条目的定时及审核状态。页面仅显示“待发布”时仍需取得实际定时时间的回显，不据状态文字推定排期正确。

发布管理未显示编辑／取消入口时如实交付当前可用入口，不能承诺可修改。旧作品提示“非电脑端发布，部分功能暂不支持”时记录限制，不为检查而重复发布。报错、审核或权限问题按[异常处理](../发布准备与记录规范.md#审核状态与异常处理)保存原条目和证据，修改、取消、重发另按具体授权执行。

## 检查、记录与收尾

从待发布、已发布或全部作品定位原条目，核对定时时间和状态；重新进入可用编辑页复核主封面与允许下载值。待发布列表中消失不能替代已发布核验。

按[统一记录与检查收尾](../发布准备与记录规范.md#记录与检查收尾)逐项执行：定时回执与选项核对写本集发布说明，实际公开后补项目发布记录，同步项目进度和工作台；向用户汇报后完成浏览器及一次性跟进收尾。日后检查的安排读取[发布后检查与临时跟进](../发布准备与记录规范.md#发布后检查与临时跟进)。

取消临时上传后，上传入口可能仍提示“还有上次未发布的视频，是否继续编辑？”；确认是本次核查创建、且已授权清理的临时内容后，使用“放弃”并回读提示消失。不处理用户原有未发布内容。

## 页面变化与补充范围

按[共用选项规则](../发布准备与记录规范.md#发布资料与选项执行)处理新增、改名或强制字段。定时提前量、可选日期范围、字数及上传限制按当前账号表单核实；页面没有某项记“不提供”，不伪记“已关闭”。账号差异及本次核实结果留在项目，平台通用变化再更新本指南。

下载权限含义参考[快手帮助中心](https://www.kuaishou.com/help/feedback/2737)，它不代替本次表单的实际选择和保存结果。
