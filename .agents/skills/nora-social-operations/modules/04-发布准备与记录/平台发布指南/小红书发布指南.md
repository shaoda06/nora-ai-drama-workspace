# 小红书发布指南

适用：Chrome中对应项目profile的电脑端后台，单条视频；不适用于手机App、图文或直播。先读[共用流程](../发布准备与记录规范.md#发布资料与选项执行)，只在已获本次代发及具体排期授权后提交。下文“项目配置”指项目`10-社交媒体资料/项目运营配置.md`；“本集说明／文案”指`98-成片交付/EPxxx/发布说明.md`与`发布文案.md`。

## 入口与资料

- 发布入口：[小红书创作服务平台](https://creator.xiaohongshu.com/) → 发布笔记 → 上传视频。先核对视频标签和目标账号，不能在图文发布表单填写本指南的视频材料。
- 结果检查：[笔记管理](https://creator.xiaohongshu.com/new/note-manager?source=official)，从原视频笔记查看定时、审核与处置详情。
- 视频取本集说明指定的最终文件；标题、正文、话题取发布文案“小红书”章节；主封面使用本集说明指定的横版或竖版一张，没有选定版式先确认。

## 填写顺序与选项

| 顺序／表单项 | 固定处理方式 |
| --- | --- |
| 上传视频 | 等待上传、转码和封面加载完成，再检查标题对应的集号及视频信息 |
| 标题 | 填已确认的小红书标题，按当前计数和超限提示处理，不套用其他平台的标题长度 |
| 正文 | 填本平台正文；话题另按指定清单添加，不将话题串当完整正文 |
| 话题 | 选中对应实际话题并检查标签结果，不随意增加话题、@账号或商业关联 |
| 主封面 | 编辑并上传本集指定的一张图，按选定比例检查并保存，再回到表单复核。PK封面未明确安排不启用；规格读[封面规格库](../../03-封面制作/平台封面规格库.md) |
| 原创声明（页面提供时） | 先读取该字段当前说明，核对用户确认的权利事实及项目选定值。未确认不代勾；不能将AI制作或自产视频直接视为符合所有原创声明条件，也不能为处理审核异常随意切换此项 |
| AI生成／内容声明（页面提供时） | 按真实内容及当前表单规则选择；具体字段名称、入口和保存值需要核实并写入项目配置，不能把原创声明当作AI声明 |
| 可见范围、下载／保存权限（页面提供时） | 按项目确认的值逐项设置；页面未提供则记录“不提供”，不能宣称已关闭下载。缺少项目选择时集中确认 |
| 合集、位置、关联、推广及其他可选项 | 只使用项目／本次已明确配置；未指定不添加。若表单强制选择，确认含义和用户选值后继续 |
| 定时发布 | 选原生定时功能，填入用户批准的日期时间；核对页面限制及时区，不能因审核或时间限制自动改为立即公开 |

## 提交与异常

提交后到原笔记的管理条目核对时间、审核和定时状态。定时已设置、审核中、审核通过、公开和限制推荐／搜索分别记录，不能仅凭列表时间判断已正常公开。

出现节目编号、备案、资质或其他材料要求时，读取该笔记具体处置和平台说明，按[审核处理](../发布准备与记录规范.md#审核状态与异常处理)接续。普通集号、原创声明与节目编号不能互代；没有有效编号不编造，不自行切换声明、申诉或重发。其他作品过去通过，不代表当前条目已通过。需要办理或申诉的真实入口、材料和适用性尚未核实时明确报告缺项，由用户决定后续动作。

用户手动修改后重新进入审核，只登记该次实际修改与当前状态；字段原名、前后值或操作时间缺失就注明未核实，不推定修改有效。管理页没有可用修改／取消按钮时说明限制并交付原条目，不擅自另发一条。

## 检查、记录与收尾

从笔记管理打开原笔记审核详情，分别核对定时、审核、公开及推荐／搜索限制；列表显示某个时间不等于正常公开。原创声明、AI声明与编号要求分别核对，不能互代。

按[统一记录与检查收尾](../发布准备与记录规范.md#记录与检查收尾)逐项执行：定时回执与选项核对写本集发布说明，实际公开后补项目发布记录，同步项目进度和工作台；向用户汇报后完成浏览器及一次性跟进收尾。日后检查的安排读取[发布后检查与临时跟进](../发布准备与记录规范.md#发布后检查与临时跟进)。

## 页面变化与补充范围

按[共用选项规则](../发布准备与记录规范.md#发布资料与选项执行)处理新增、改名或强制字段。定时提前量、可选日期范围、字数及上传限制按当前账号表单核实；页面没有某项记“不提供”，不伪记“已关闭”。账号差异及本次核实结果留在项目，平台通用变化再更新本指南。
