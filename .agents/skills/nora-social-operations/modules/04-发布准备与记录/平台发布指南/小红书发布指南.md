# 小红书发布指南

适用：Chrome中对应项目profile的电脑端后台，单条视频；不适用于手机App、图文或直播。先读[共用流程](../发布准备与记录规范.md#发布资料与选项执行)，只在已获本次代发及具体排期授权后提交。下文“项目配置”指项目`10-社交媒体资料/项目运营配置.md`；“本集说明／文案”指`98-成片交付/EPxxx/发布说明.md`与`发布文案.md`。

页面字段核实日期：2026-10-30。已核对上传入口、上传后新建发布表单及已发布视频编辑页；已发布编辑页不提供新建定时开关，不能据此判断账号不支持定时。

## 入口与资料

- 发布入口：[小红书创作服务平台](https://creator.xiaohongshu.com/) → 发布笔记 → 上传视频。先核对视频标签和目标账号，不能在图文发布表单填写本指南的视频材料。
- 结果检查：[笔记管理](https://creator.xiaohongshu.com/new/note-manager?source=official)，从原视频笔记查看定时、审核与处置详情。
- 视频取本集说明指定的最终文件；标题、正文、话题取发布文案“小红书”章节；主封面使用本集说明指定的横版或竖版一张，没有选定版式先确认。

## 填写顺序与选项

| 顺序／表单项 | 固定处理方式 |
| --- | --- |
| 上传视频 | 上传入口显示4小时以内、最大20GB，推荐MP4、MOV；超过1080P视频可用网页端上传。等待上传和处理完成后核对文件、集号；“重新上传”会更换视频，核查时不使用 |
| 标题 | 独立标题框“填写标题会有更多赞哦”，聚焦后显示计数，上限20；按页面实际计数检查，不套用抖音30上限 |
| 正文 | 正文富文本框计数上限1000；填本平台正文和指定话题，不将话题串当完整正文；话题、用户和表情各有入口 |
| 话题 | 选中对应实际话题并检查标签结果，不随意增加话题、@账号或商业关联 |
| 主封面 | 编辑并上传本集指定的一张图，按选定比例检查并保存，再回到表单复核。PK封面未明确安排不启用；规格读[封面规格库](../../03-封面制作/平台封面规格库.md) |
| 原创声明 | 内容设置中的独立开关；说明为获得原创笔记标记及平台识别／打击搬运保护。按权利事实和项目选值开关；它与下方内容声明不同，不能用开启原创解决编号或AI标识问题，只读检查不切换 |
| 添加内容类型声明 | 新建表单入口名为“添加内容类型声明”，选中后显示声明值；它是内容设置中单独的下拉。有“虚构演绎，仅供娱乐”“笔记含AI合成内容”“内容包含营销广告”，以及“内容来源声明”子菜单的“自主拍摄／来源转载”。真实AI合成内容选择“笔记含AI合成内容”；原创开关不是此项，不将其他来源声明自动叠加为已确认 |
| 可见范围、下载／保存权限 | 更多设置中的可见范围有“公开可见／仅自己可见／仅互关好友可见／只给谁看／不给谁看”；后两项还需指定用户。按项目值核对，不把仅互关当作抖音好友可见。本次新建页及已发布编辑页均没有独立下载／保存开关，记录本入口不提供，不能宣称已关闭下载 |
| 合集、位置、关联、推广及其他可选项 | 实际内容设置有“添加章节／加入合集”；组件有地点、群聊、引用笔记、投票、直播预告、标记地点或朋友、路线、活动，另有店内商品。新建发布仅添加已明确安排项，已有作品的关联保留；自动生成章节不等于正式采用 |
| 定时发布 | “更多设置”中打开“定时发布”右侧开关，在出现的日期时间框填用户批准排期。点击文字可能只显示说明，必须核对开关和日期框实际出现。提示明确采用北京时间，支持未来1小时～14天；默认填入的时间不是用户批准时间，不直接使用。无效排期重新确认，不自动立即公开 |

新建页的原创开关和PK封面初始为关闭，内容类型声明初始为空；这是表单状态，不能代替项目选择。原作品编辑页的已保存状态与新建预选分开记录。

## 提交与异常

提交后到原笔记的管理条目核对时间、审核和定时状态。定时已设置、审核中、审核通过、公开和限制推荐／搜索分别记录，不能仅凭列表时间判断已正常公开。

出现节目编号、备案、资质或其他材料要求时，读取该笔记具体处置和平台说明，按[审核处理](../发布准备与记录规范.md#审核状态与异常处理)接续。普通集号、原创声明与节目编号不能互代；没有有效编号不编造，不自行切换声明、申诉或重发。其他作品过去通过，不代表当前条目已通过。需要办理或申诉的真实入口、材料和适用性尚未核实时明确报告缺项，由用户决定后续动作。

用户手动修改后重新进入审核，只登记该次实际修改与当前状态；字段原名、前后值或操作时间缺失就注明未核实，不推定修改有效。管理页没有可用修改／取消按钮时说明限制并交付原条目，不擅自另发一条。

## 检查、记录与收尾

从笔记管理打开原笔记审核详情，分别核对定时、审核、公开及推荐／搜索限制；列表显示某个时间不等于正常公开。原创声明、AI声明与编号要求分别核对，不能互代。

按[统一记录与检查收尾](../发布准备与记录规范.md#记录与检查收尾)逐项执行：定时回执与选项核对写本集发布说明，实际公开后补项目发布记录，同步项目进度和工作台；向用户汇报后完成浏览器及一次性跟进收尾。日后检查的安排读取[发布后检查与临时跟进](../发布准备与记录规范.md#发布后检查与临时跟进)。

仅核查的临时表单不提交。离开时若出现浏览器“Leave site? Changes you made may not be saved.”提示，在确认仅包含本次临时编辑且清理已授权后选择“Leave”，不点发布或保存草稿；返回上传入口核对草稿箱及作品列表。上传后即使没有手动点“保存”，离开也可能自动增加本地草稿；先比较核查前的草稿数，再按时长、标题及保存时间定位本次条目。草稿箱说明其存储在当前浏览器本地；只清理本次授权创建的条目，不能清空整个草稿箱。若删除弹窗提示“草稿删除后不可找回”，按浏览器工具规则在删除时取得确认，再删除并核对条目消失和数量回到基线。用户原有编辑按其决定保留。

## 页面变化与补充范围

按[共用选项规则](../发布准备与记录规范.md#发布资料与选项执行)处理新增、改名或强制字段。定时提前量、可选日期范围、字数及上传限制按当前账号表单核实；页面没有某项记“不提供”，不伪记“已关闭”。账号差异及本次核实结果留在项目，平台通用变化再更新本指南。
