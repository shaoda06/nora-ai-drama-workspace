# 发布准备与记录

读取[发布准备与记录规范](发布准备与记录规范.md)。输入为最终成片、账号配置、已采用封面及相关报告；输出为单集发布包和真实执行／发布状态。发布包准备后按[发布方式](发布准备与记录规范.md#发布方式)接续用户手动发布或获授权的代发；代发执行读取[代为定时发布](发布准备与记录规范.md#代为定时发布)。审核变化读取[审核状态与异常处理](发布准备与记录规范.md#审核状态与异常处理)；用户手动发布后按[实际发布与记录](发布准备与记录规范.md#实际发布与记录)补录，获授权的日后检查读取[发布后检查与临时跟进](发布准备与记录规范.md#发布后检查与临时跟进)。使用[发布说明](templates/发布说明模板.md)、[发布文案](templates/发布文案模板.md)、[发布记录](templates/发布记录模板.md)模板，按本次动作填写。
