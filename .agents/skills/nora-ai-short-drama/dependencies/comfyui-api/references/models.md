# 模型参考与核对方法

可移植适配日期：2026-09-26。原参考：[ComfyUI-Expert models.md](https://github.com/MCKRUZ/ComfyUI-Expert/blob/dee27dc3d69b609c0006a8a12e71aadfc475ae95/references/models.md)。本技能不指定默认模型组合，也不附带某个服务器的已安装清单。

模型需求来自当前任务实际工作流；可用文件依据实际安装的 `comfyui-inventory` 技能管理的库存及加载器定义。按名称发现该技能、读取其缓存位置和时效规则。模型类别可能配置外部目录，不能由类别名推断远端绝对存放路径；模型家族官方仓库不一定是第三方量化文件的发布来源。

## 遇到缺失模型

1. 从实际工作流读取class、字段、精确文件名、模型类型与配套编码器/VAE。
2. 刷新节点定义，核对该加载器的COMBO选项；再查服务器模型类别清单。注意路径分隔符、子目录与分类别名。
3. 如果确实缺失，查对应模型发布者或节点维护者的官方仓库，验证具体文件、量化格式、版本、许可及兼容性；提供可核实的来源，不用相似名称替换。
4. 只有需要下载时才核实远端实际目标目录。补齐本地文档不代表已获准下载大模型或更改服务器配置。
5. 文件列在清单中不代表其校验和、文件完整性或运行兼容性已经验证；遇到加载错误由 `comfyui-troubleshooter` 结合实际报错处理。
