# 生成任务读取规范

## 任务选择

只进入本次动作对应章节。链接按说明命中条件后再读，不沿链接递归加载整份文件；读取深度遵循[主入口](../../SKILL.md#读取范围)。图片选型和看图边界仍由主入口维护。

| 本次动作 | 模块入口及调用条件 |
| --- | --- |
| 写、校对或改图片提示词 | [图片提示词](#图片提示词)；不进入服务配置与生成执行 |
| 写、改分镜或视频提示词 | 分镜回创作模块；H3正文读[H3提示词](#h3提示词)，不因写提示词提交任务 |
| 准备或提交图片生成 | [图片生成执行](#图片生成执行)＋[ComfyUI服务与任务提交](#comfyui服务与任务提交)；正文有修改才进入提示词分支 |
| 准备或提交H3视频任务 | [H3视频执行](#h3视频执行)＋[ComfyUI服务与任务提交](#comfyui服务与任务提交)；按当前阶段及授权选择 |
| 查询已有任务、收到结果、恢复取回或排查异常 | [进度查询与结果处理](#进度查询与结果处理)；不重新读取创作模板或完整生成准备规范 |
| 已批准图片的后处理及正式保存 | [图片批准后处理](#图片批准后处理)；需要提交时再读服务与任务提交 |
| 导演包定稿留档或导入测试 | [导演包](#导演包)；按专项规定的时机及实际授权 |

## 视觉表达方法

视觉表达方法见[镜头语言参考指南](../生成规范/镜头语言参考指南.md)。项目定位中的视觉风格按需参考；参考图提示词、场次分镜、分段衔接及视频提示词按开发流程与专项规范中的调用要求读取相关章节。指南解释方法，流程规定何时参考及落实位置；不作为所有策划任务或上传、查询、下载、二采、后处理等纯执行操作的必读项，不改变模板、模型格式与审核职责。

编写或修订图片提示词、分镜及视频提示词时，执行[统一方向参照](../生成规范/镜头语言参考指南.md#13-统一方向参照)，将空间关系转换为当前镜头的画面坐标，保留固定多视图展示面定义。

安排静态画面时，按用途参考[构图方式](../生成规范/镜头语言参考指南.md#32-构图方式与裁切说明)，将主体落点、取景边界、必要层次与清晰区域写入实际画面正文；资产展示沿用专项布局，首帧只写开场状态。分镜及视频转写按[运镜、构图与切镜的选择](逐集内容制作规范.md#运镜构图与切镜的选择)落实指南中的动态配合方法，保留从起始构图到结束构图的可见过程，不只抄方法名称。

## 图片提示词

读取[视觉表达方法](#视觉表达方法)，再按下列提示词与类型要求处理；本节不触发提交。

- 编写、校对或修订图片提示词时，同时读取 `qwen-image-2-1-prompter` 和[Qwen提示词规范](../生成规范/Qwen-Image-2.1-提示词规范.md)。按[接入与适配](../生成规范/Qwen-Image-2.1-提示词规范.md#13-qwen-image-2-1-prompter接入与适配)选择T2I／Edit及API／Pipeline格式；按[中文规则](../生成规范/Qwen-Image-2.1-提示词规范.md#14-统一中文编写审阅与提交)编写、审阅和提交。仅换种子对照不改冻结正文。图片输入按[输入参考图检查与记录复用](../生成规范/Qwen-Image-2.1-提示词规范.md#24-输入参考图检查与记录复用)处理，默认不看图；缺少视觉信息先询问，新输出直接交用户审核。
- 场景图片先按[场景用途与状态归属](../素材规范/场景资料与参考图规范.md#40-图片用途与状态归属)明确用途，沿第4.2节核对机位需求与复用，再进入第4.1.1节选择生成分支。
- 按[专用模板索引](../生成规范/Qwen-Image-2.1-提示词规范.md#11-图片类型专用模板索引)选择七类图片或已列补充图片的生成方式和输入关系，不临时增类。服装、场景、道具状态图制作时读取[统一资产状态规则](../生成规范/Qwen-Image-2.1-提示词规范.md#27-资产状态参考图统一规则)，再进入其链接的对应资产规格；源图、修订、种子和记录通过统一入口读取。虚拟道具基础界面读取[道具专项规则](../素材规范/道具资料与参考图规范.md#虚拟道具基础界面)。每种一份填写模板；允许用户参考图的类型在对应模板内设大类，不另建用户参考图模板文件；生图模板不维护参考案例或待补位置，不把项目流水写入模板。

## 图片生成执行

制作与修订读取[Qwen参考图生成与修订的七项约定](../生成规范/Qwen-Image-2.1-提示词规范.md#22-qwen参考图生成与修订的七项约定)，输入来源、规格、审核及返修按各专项规范执行。

- 已备内容的纯提交直接使用[一次装配入口](../comfyui-scripts/README.md#一次装配与批量入队)，职责见[图片执行分工](ComfyUI-服务配置与任务提交规范.md#图片执行分工)。项目种子表、输入原始种子、规格与固定技术配置由脚本读取、核对和写入，Agent不重复人工检查；已有批准及历史事实保持。
- 首次创作并准备该生成分支的内容时完整读取[文生图执行规范](../生成规范/ComfyUI-文生图执行规范.md)或[图生图执行规范](../生成规范/ComfyUI-图生图执行规范.md)，按任务配置参考图、参数及画布。用户另有明确指定时按其选择处理，连续性及验收仍按开发流程第8节。

## 图片批准后处理

生产图片的批准后处理、正式保存及历史资产边界统一读取[图片超分执行规范](../生成规范/ComfyUI-图片超分执行规范.md)；按其中类型入口取得规格。画风样例按[定位画风验证流程](短剧开发流程规范.md#项目画风展开示例验证与复用)处理。

## H3提示词

读取[视觉表达方法](#视觉表达方法)，并从[分段视频提示词章节](逐集内容制作规范.md#6-分段视频提示词文档)定位P段、采用素材与对应模板；实际编写与检查按[执行顺序](逐集内容制作规范.md#提示词编写与检查顺序)完成，不以读取入口替代执行。

编写或修改H3提示词时，读取 `h3-prompt-writing` 对应实际输入模式的官方指南，按本流程[语言与命名适配](逐集内容制作规范.md#h3模型正文的语言与命名)及[切镜与接续表达](逐集内容制作规范.md#h3切镜与接续表达)落实到模板；当前多参考工作流优先使用Ref2VA。不另复制官方提示词规范，技能缺失时说明，不能声称已按官方规范完成。

## H3视频执行

已备内容的纯执行直达[一次装配入口](../comfyui-scripts/README.md#一次装配与批量入队)，按[视频执行分工](ComfyUI-服务配置与任务提交规范.md#视频执行分工)只提交、读取报告并汇报。技术配置、指纹、冻结关联、帧数和记录由脚本处理，不重新读节点全规范或手工整理执行附件。

首次创作、配置完整导演台任务或修改其内容时，才读取[节点规范的任务阅读路径](../生成规范/ComfyUI-MiniMaxH3导演台节点使用规范.md#任务阅读路径)及[H3执行规范](../生成规范/ComfyUI-H3视频执行规范.md)的当前阶段章节，确定真实正文、素材用途、时长、衔接及指定来源；后续只补读变化部分。阶段批准顺序仍按[开发流程第二部分第7节](短剧开发流程规范.md#7-生成视频验收与衔接修改)，不因技术准备或读取报告切换阶段。分段交付或本集完成时再读逐集目录规范第5节，不在准备一采时展开整集收尾。

## ComfyUI服务与任务提交

初始化项目服务、准备或提交生成任务时，按[服务配置与任务提交规范](ComfyUI-服务配置与任务提交规范.md)读取对应章节；已提交任务的查询、取回及恢复读取其中的[任务地址规则](ComfyUI-服务配置与任务提交规范.md#已提交任务的地址与恢复)，监控方式另按任务监控入口。纯创作、提示词讨论和普通文本修订不加载服务配置与提交细则。

准备或提交ComfyUI任务，以及获授权直接调用远端接口查询或取回时，读取依赖表指定的 `comfyui-api`、[固定工具说明](../comfyui-scripts/README.md)及[服务配置与任务提交规范](ComfyUI-服务配置与任务提交规范.md)的对应章节。仅操作后台已有任务时，直接进入[进度查询与结果处理](#进度查询与结果处理)。准备阶段的内容核对、工具本地技术检查、远端错误返回及提交时的报告复用由该规范维护；出现异常时使用 `comfyui-troubleshooter`，不以诊断代替修复授权。

图片及视频执行使用[服务配置与任务提交规范](ComfyUI-服务配置与任务提交规范.md)登记后台队列；上传、提交、监听、完成后取回及技术记录由后台执行。

依赖实际入口见[依赖表](技能依赖与协作规范.md#适用平台与技能依赖)。首次准备需要完整读取的执行规范按各分支要求执行；后续无变化内容复用；授权后只调用提交工具并读取结果，技术核验及报告由工具承担，不重新展开准备检查。

## 进度查询与结果处理

后台已有任务先读[后台工具的共用调用条件](../comfyui-scripts/README.md#后台任务查询与结果处理)，再按下列动作直达工具小节；不因此加载 `comfyui-api` 完整技能、上传提交说明或生成准备规范。获授权需要直接调用远端接口时才读取随包[comfyui-api](../../dependencies/comfyui-api/SKILL.md)及对应固定工具章节，不把该分支作为后台不可用时的自动回退。

- **主动查询进度**：调用[后台状态查询](../comfyui-scripts/README.md#后台状态查询)，读取[原任务地址规则](ComfyUI-服务配置与任务提交规范.md#已提交任务的地址与恢复)、[查询方式](ComfyUI-任务监控规范.md#11-待提交跟进方式与间隔)、本次后台状态及更新时间；不加载创作和提交准备分支。
- **收到结果通知**：调用[最终报告读取](../comfyui-scripts/README.md#后台最终报告读取)，读取通知前已完成收尾的报告并自动确认收到；正常视频使用`delivery.video_count`及各任务的`review_url`，直接按[精简收尾](ComfyUI-任务监控规范.md#视频完成通知后的精简收尾)汇报数量和审核入口，不另确认、不调用登记、不展开固定映射。异常按报告的失败阶段查对应证据，必要时用[状态查询](../comfyui-scripts/README.md#后台状态查询)或显式恢复入口；读取[结果处理模板](../模板/ComfyUI-任务监控提示词模板.md)和相应媒体交付要求。正常图片及超分只使用报告的`delivery`展示清单（含绝对路径、实测规格、数量及审核链接），按[图片精简收尾](ComfyUI-任务监控规范.md#4-图片处理)直接展示报告中的成果和审核入口，不再核对文件、补常规记录或刷新网页；异常再查。
- **异常或恢复取回**：先用[后台状态查询](../comfyui-scripts/README.md#后台状态查询)核对失败阶段；只有取回失败才进入[后台取回重试](../comfyui-scripts/README.md#后台取回重试)。另读[异常检查与连接恢复](ComfyUI-任务监控规范.md#31-异常检查与连接恢复)、[故障补做授权](ComfyUI-任务监控规范.md#33-故障补做授权与额度)；视频后端故障接续读第5.1节。使用随包[comfyui-troubleshooter](../../dependencies/comfyui-troubleshooter/SKILL.md)，不以诊断代替修复授权。

不创建同任务轮询或heartbeat，不自动重生成。已提交任务沿用原地址及任务ID；恢复不等于准备新的生成。

图片的取回、展示与记录读取[交付与用户审核规则](短剧开发流程规范.md#851-图片交付与用户审核)，内容分析读取[看图边界](../../SKILL.md#看图能力调用边界)。

视频结果交付、人工审核职责及客观异常处理统一读取[视频结果人工审核](逐集目录与资产管理规范.md#视频结果人工审核)。
