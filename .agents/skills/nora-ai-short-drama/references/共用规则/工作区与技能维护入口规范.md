# 工作区与技能维护入口规范

只在维护、寻找能力或具体辅助任务命中时读取对应行；不新增制作阶段。

| 当前任务 | 直接能力与规则 |
| --- | --- |
| 技能结构、规则、资源和分享 | 使用系统skill-creator；按[维护路径](../../维护规范.md#维护任务读取路径)处理受影响内容 |
| 明确寻找缺失能力 | [find-skills](../../../find-skills/SKILL.md)及[获取规则](../流程规范/技能依赖与协作规范.md#依赖发现与获取)；已有可用能力直接复用 |
| React／Next.js开发审阅 | 按实际环境发现vercel-react-best-practices或提供同一能力的react-best-practices入口，读相关规则；不因名称不同自动重装 |
| FastAPI开发审阅 | [fastapi](../../../fastapi/SKILL.md) |
| 维护范围扩大、额外机制与重复验证取舍 | 按名称发现stop-that-shit，只在实际问题命中时调用 |
| 方案与决策说明中的防御性赘述 | 按名称发现stss，不用于替代剧本或模型正文规则 |
| 风格库资源或服务维护 | [krea2-style-library](../../../krea2-style-library/SKILL.md)；浏览选风格由故事开发调用 |
| 共用网页代码维护 | [项目浏览规范](../流程规范/项目浏览入口规范.md)及适用工程技能，须具备共用代码修改授权 |

工程落实边界统一见[工程适配](../../维护规范.md#辅助技能的工程适配)。能力发现、获取、来源和版本使用[依赖规范](../流程规范/技能依赖与协作规范.md)及维护规范，不在每项创作任务加载。ComfyUI节点和模型部署须有相应授权，不由安装技能推定。
