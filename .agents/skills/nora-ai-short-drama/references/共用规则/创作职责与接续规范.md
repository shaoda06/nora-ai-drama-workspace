# 创作职责与接续规范

### 已选原图的接续

当前阶段接收到具体图片的选定决定时，按[外来原图的选定与入库](../流程规范/逐集目录与资产管理规范.md#外来原图的选定与入库)完成本阶段收尾；跨阶段接续同时核对实际文件、来源与确认范围、素材入口及未完成项，不把“已有参考选择记录”当作已完成入库。后续阶段复用该入口，不重新索要已明确的选择或下载授权。

### 剧本、分镜与提示词的职责分工

本节统一维护故事剧本、场次分镜与视频提示词的内容职责和接续边界。整集故事剧本正文是剧情、台词及必要表演的统一依据；分镜和提示词按实际采用的来源版本接续。

| 阶段 | 输入与应完成的内容 |
| --- | --- |
| 本集故事剧本 | 依据本集分集大纲、适用原稿、制作前检查及已确认设定，展开完整剧情与交流，写出对白／VO／OS原句、必要动作、情绪变化、听者反应、停顿、环境、场间衔接与结尾。交流和使剧情成立的必要表演在本阶段完成，不留给分镜或提示词临场补写；正文不加入镜号、景别、运镜、生成分段或模型提示词。 |
| 场次分镜 | 引用故事剧本的对应场次及版本，根据已有剧情、台词和必要表演安排景别、机位、构图、切镜、可见动作与反应的呈现方式、镜长和视频分段；将剧本中的动作、情绪和回应细化成可拍摄的表演及起止状态。 |
| 分段视频提示词 | 引用已确认场次分镜及其P段，将镜头、表演、台词、声音和实际参考输入转写为模型格式；不在格式转换中另编故事或对白。 |

分镜可以细化动作幅度、表情、站位、停顿及声音时点等呈现细节，剧本无需预先写完逐镜调度。细化须保留已有事件、人物意图、台词含义及因果；需要新增或实质修改台词、改变剧情事实、人物行为或决定因果的动作／反应时，先回写故事剧本，再同步分镜与提示词。单纯取景、切镜、运镜、镜长及分段安排在分镜维护，不逐镜抄回剧本；提示词阶段发现上游缺项，回到对应来源处理。

初稿、修订及送审时，由承担任务的agent在当前业务的合并自检中主动处理缺项及授权范围内的修正；本节用于确定内容归属，检查时机、范围与订正权限沿调用方已确定的要求，审批沿用既有流程。制作中发现问题时，同时按[制作返修的上游归属](制作返修与完整重做规范.md#制作返修的上游归属)核对实际请求、技术原因及同步范围。
