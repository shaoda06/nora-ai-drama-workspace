# 创作职责与接续规范

### 已选原图的接续

跨阶段先核对[项目资产与逐集引用](../流程规范/逐集目录与资产管理规范.md#项目资产与逐集引用)中的资产身份、保存位置和审批范围，再维护本集具体版本与镜号引用；不能将独立人物、道具、场景的当前资产本体或唯一审批记录留在逐集制作中。

当前阶段接收到具体图片的选定决定时，按[外来原图的选定与入库](../流程规范/逐集目录与资产管理规范.md#外来原图的选定与入库)完成本阶段收尾；跨阶段接续同时核对实际文件、来源与确认范围、素材入口及未完成项，不把“已有参考选择记录”当作已完成入库。后续阶段复用该入口，不重新索要已明确的选择或下载授权。

### 剧本、分镜与提示词的职责分工

本节统一维护故事剧本、场次分镜与视频提示词的内容职责和接续边界。整集故事剧本正文是剧情、台词及必要表演的统一依据；分镜和提示词按实际采用的来源版本接续。

| 阶段 | 输入与应完成的内容 |
| --- | --- |
| 本集故事剧本 | 依据本集分集大纲、适用原稿、制作前检查及已确认设定，展开完整剧情与交流，写出对白／VO／OS原句、必要动作、情绪变化、听者反应、停顿、环境、场间衔接与结尾。交流和使剧情成立的必要表演在本阶段完成，不留给分镜或提示词临场补写；正文不加入镜号、景别、运镜、生成分段或模型提示词。 |
| 场次分镜 | 引用故事剧本的对应场次及版本，根据已有剧情、台词和必要表演安排景别、机位、构图、切镜、可见动作与反应的呈现方式、镜长和视频分段；将剧本中的动作、情绪和回应细化成可拍摄的表演及起止状态。 |
| 分段视频提示词 | 引用已确认场次分镜及其P段，将镜头、表演、台词、声音和实际参考输入转写为模型格式；不在格式转换中另编故事或对白。 |

分镜可以细化动作幅度、表情、站位、停顿及声音时点等呈现细节，剧本无需预先写完逐镜调度。细化须保留已有事件、人物意图、台词含义及因果；需要新增或实质修改台词、改变剧情事实、人物行为或决定因果的动作／反应时，先回写故事剧本，再同步分镜与提示词。单纯取景、切镜、运镜、镜长及分段安排在分镜维护，不逐镜抄回剧本；提示词阶段发现上游缺项，回到对应来源处理。

初稿、修订及送审时，由承担任务的agent在当前业务的合并自检中主动处理缺项及授权范围内的修正；本节用于确定内容归属，检查时机、范围与订正权限沿调用方已确定的要求，审批沿用既有流程。制作中发现问题时，同时按[制作返修的上游归属](制作返修与完整重做规范.md#制作返修的上游归属)核对实际请求、技术原因及同步范围。

分镜可保留抽象表情意图；提示词按[表情拆解](../../../creative-techniques/SKILL.md#表情表达)细化眉眼、嘴部等可见变化，属于表达转写，不要求为这些措辞逐项回改分镜。情绪意图、视线目标、头部朝向、关键动作和起止结果沿已确认安排；需要改变这些事实时仍回对应上游处理。

### 打戏方法的适用范围与优先级

先按已确认的角色能力、当前动作和画风判断适用范围，再处理冲突；文件位于“通用库”不等于其中每条方法都适用于所有题材。按下表选读，未命中的另一题材无需加载。

| 范围 | 管什么 | 不扩大到什么 |
| --- | --- | --- |
| 通用打戏方法 | 人物目的、攻防因果、对手应对、动作与空间连续、关键接触及结果可读、镜头的观看任务 | 不统一规定是否发光、是否飞行、特效强弱或能量材质；库中的具体画风、档位和模型示例按条件使用 |
| 写实专项 | 现实能力下的步法、重心、人体发力、武器接触、伤损与环境反馈 | 写实场面的“不凭空增加法术”不限制已设定的玄幻能力；写实也不等于禁止正常照明、火花或摄影光效 |
| 玄幻专项 | 已设定能力下的法术、法阵、剑气流光、灵力抽丝、属性粒子、飞行、法相与尺度表现 | 不把所有玄幻场面都推到最大强度，不强制近身互殴、手绘化或某种能量材质；具体视觉过程按[法术表现路径](../../../sd-xuanhuan-engine/SKILL.md#法术表现的使用路径)落实 |
| 模型适配 | 实际所用模型的字段、引用方式、提示词结构、时长和素材容量等执行条件 | 不接管题材与美术选择，不将某模型案例中的禁光、克制或画风建议升为通用内容禁令 |

在[主控规则优先级](../../SKILL.md#外部技能协作与规则优先级)内，**同一个创作问题采用“适用的题材专项方法优先于通用默认”**，只覆盖发生冲突的部分，其余共同要求继续执行。另一题材的专属规则属于不适用，不参与压制当前题材；“铁律”“最高准则”“绝对禁止”等措辞不自行提升优先级。专项内部的档位、固定节拍和示例也须符合当前剧情与画风，不能用来改写已确认的胜负、能力或镜头。

例如，写实拳击按人体发力与接触反馈编排，不自行加剑气；仙侠御剑可以悬空、释放流光和粒子，但仍要交代施力来源、飞行路径、作用对象及反馈。“接触清楚”通过构图、层次和时间安排实现，不推导为“禁用光效”或普遍减弱法术。通用库中的落地发力链用于需要身体支撑的动作，不能要求悬空施法也必须蹬地。

混合场面按角色、能力或动作阶段应用对应方法：凡人躲避法术可用写实步法，法术本身按玄幻机制设计，两者共用空间与作用因果。武侠也按已定能力选择，不仅凭古装或题材名称套用写实／玄幻限制。真实模型限制依执行条件处理；若无法承载已确认表达，说明具体限制和影响，不静默改成另一种风格。
