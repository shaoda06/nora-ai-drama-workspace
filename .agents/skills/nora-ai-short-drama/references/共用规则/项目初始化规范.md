# 项目初始化规范

### 2. 创建项目目录

执行本节前先按[技术测试资料归属](文件版本与工作稿规范.md#技术测试资料归属)判断本次是否为真实短剧创作；工具或流程验收进入该规则的隔离验证分支，不直接套用下方正式项目创建步骤。

项目工作区的本地媒体依赖按[README的FFmpeg初始化与运行](../../../../../README.md#ffmpeg初始化与运行)落实。

项目初始化时按[工作区 ComfyUI 配置](../../../nora-generation/references/ComfyUI-服务配置与任务提交规范.md#工作区-comfyui-配置)复用共用服务设置；完整工作区已运行浏览服务时，可通过“任务进度→编辑”添加或修改节点，也可由Agent按用户确认内容维护同一份配置，不在项目根目录创建配置。

基本定位明确后，由agent调用[固定初始化脚本](#项目与单集目录初始化脚本)，在 `projects/` 下统一创建[项目基础结构](文件版本与工作稿规范.md#项目基础结构)及[综合资料的固定分类](文件版本与工作稿规范.md#综合资料存放规则)，同时按[项目总索引](#项目总索引)登记项目；不逐项手工创建或临时编写建目录代码。配套目录按下方选择建立，其余分类、资产和逐集子目录按对应规范的时机建立。用户简化创作流程时仍执行基础目录初始化，空目录不代表阶段已开始或需要补写内容；用户另有明确目录要求时按其范围处理。

立项时先按[可选配套安排](../../../short-drama-develop/references/项目定位与画风规范.md#封面与片头片尾的可选安排)明确封面、片头、片尾各自的选择，再把已确定“需要”的项传入同一次项目初始化：封面建立 `10-封面资料/`；片头、片尾分别建立 `09-剧集制作/片头/`、`09-剧集制作/片尾/` 及各自01至05准备目录。“不需要”或“待定”的项不传选择参数、不建对应目录。只建目录，不预填封面索引、内容稿、工作稿或其他空白文件，也不启动制作或生成；后续改为“需要”时按新选择补建，复用已有目录和内容，取消选择不自动删除已有资料。已有项目的纯接续仍沿用实际入口，不据此批量补建。

本步骤在项目基本定位阶段会话内完成。会话安排及已有入口的补登，执行[会话创建提醒](../流程规范/会话与进度管理规范.md#剧名或代号确定后的会话创建提醒)。创建项目根目录和顶级目录后，保存本阶段定位，按 [会话组织与项目进度](../流程规范/会话与进度管理规范.md) 在项目根目录建立 `项目进度.md`；项目名称或临时代号确定后，由主控按该规范完成自身会话改名及进度入口名称同步。不提前生成后续阶段尚未完成的创作资料。除综合资料的固定分类外，工作稿、历史版本和执行附件首次有对应内容需要保存时才创建，不随项目初始化预建空目录。

### 项目总索引

工作区统一使用 `projects/项目总索引.md` 控制首页项目卡片及顶部项目切换菜单的顺序。该文件是工作区级项目清单，人物、场景、分集等业务索引仍保存在各项目内部。

已有项目正式更名时，按[项目正式更名](项目初始化与接续规范.md#项目正式更名)同步本地目录、索引及关联入口，不仅修改本表中的名称。

**条目写法**：一级标题固定为“项目总索引”，下面使用Markdown表格，固定两列表头“编号、项目名称”。编号填写两位顺序号，项目名称只写 `projects/` 下实际项目文件夹的完整名称，不写简称、链接、状态、备注或显示别名；每个项目只登记一次。基本格式如下，将示例名称替换为实际文件夹名称：

```md
# 项目总索引

| 编号 | 项目名称 |
| --- | --- |
| 01 | 示例短剧甲 |
| 02 | 示例短剧乙 |
```

**编号与排序**：表格编号从01开始连续填写，不跳号、不重复；显示顺序以表格数据行在文件中的先后位置为准。调序时移动整行，再把编号重排为01、02、03……。网页在完整项目标题前自动显示两位显示序号及半角横杠，例如“01-示例短剧甲”“02-示例短剧乙”；首页和顶部菜单使用同一顺序和编号。显示序号随当前排列重新计算，不是固定项目ID；不要为了显示编号修改文件夹名称，或在条目名称中手写“01-”前缀。

**新增项目**：固定初始化脚本在目录创建成功后将项目追加到索引末尾；索引不存在时创建。重复初始化只补缺失条目，保留已有项目顺序；单集、片头及片尾初始化不修改总索引。用户指定新项目位置时，Agent在初始化后按指定位置调整表格行并连续编号。用户明确要求其他建目录方式时，仍须在创建项目的同一任务内登记总索引，不将补登记留到后续制作阶段。

**日常维护**：用户要求调序时只移动对应数据行并重排编号；经授权改名项目时，把条目改成实际新文件夹全名；经授权移除项目时，删除对应数据行并重排编号。维护时核对目录存在、名称一致、无遗漏及重复；补登记已有目录时按用户指定位置插入，未指定时追加末尾。修改索引本身不触发目录改名、删除或后续制作。

**网页读取与核验**：浏览服务先按总索引排列仍存在的项目，再将未登记的实际项目按文件夹名称字符顺序接在末尾；索引缺失时沿用名称排序。失效条目不显示，网页不回写索引。首页“项目总索引”入口的只读弹窗交互见[项目列表顺序](../../../../../工作区浏览服务/docs/组件与页面实现.md#项目列表顺序)。修改后核对弹窗内容、`/api/projects` 的项目顺序，以及首页和顶部菜单的“显示序号-标题”与跳转目标；仅索引资料变化无需重启服务。总索引随真实项目资料留在本机，沿用 `projects/` 的Git忽略规则，不强制纳入公共仓库。

旧有有序列表仍可读取；新建索引使用上述表格，向旧列表登记新项目时保留其原格式和顺序，格式迁移按用户授权单独处理，不因浏览或接续自动改写。

### 项目与单集目录初始化脚本

入口：[project_init.py](../../scripts/project_init.py)。Python 3.9+，仅标准库，由agent直接调用，不依赖或接入网页后台；共用[project_index.py](../../scripts/project_index.py)读取和追加总索引。项目创建时机由[第2节](#2-创建项目目录)维护，单集创建时机由[逐集目录规范第1节](../流程规范/逐集目录与资产管理规范.md#1-单集根目录与过程文件)维护。

在工作区根目录运行，将项目名和集号替换为本次实际值；独立安装时替换脚本路径：

```sh
# 项目初始化：12个固定顶级目录（含98-发布成片、99-综合资料）、综合资料分类及总索引。
python .agents/skills/nora-ai-short-drama/scripts/project_init.py --project 'projects/项目名称'

# 三项均已确定需要时；只需要部分配套时，仅保留对应参数。
python .agents/skills/nora-ai-short-drama/scripts/project_init.py --project 'projects/项目名称' --cover --intro --outro

# 开始本集：该集根及01至05准备目录，项目根必须已存在。
python .agents/skills/nora-ai-short-drama/scripts/project_init.py --project 'projects/项目名称' --episode EP001
```

| 参数 | 含义与路径基准 |
| --- | --- |
| `--project` | 必填，明确的项目根目录；相对路径从当前工作目录解析，也可传绝对路径，支持中文与空格。 |
| `--episode` | 可选，EP001至EP999，或固定名称“片头”“片尾”；省略时初始化项目骨架，指定时只初始化该制作对象准备目录，不预建其他集或共用对象。 |
| `--cover` | 项目模式可选开关，已确定需要封面时传入，创建封面根目录；默认不传、不创建。 |
| `--intro` | 项目模式可选开关，已确定需要片头时传入，创建片头根及01至05准备目录；默认不传、不创建。 |
| `--outro` | 项目模式可选开关，已确定需要片尾时传入，创建片尾根及01至05准备目录；默认不传、不创建。 |

三个配套开关可独立组合，只能用于项目模式，不能与 `--episode` 同时使用。脚本只依据传入参数建目录，不自行推断定位中的选择；agent负责按真实选择传参。`98-发布成片/` 始终随项目基础结构创建，用途见[发布成片目录](文件版本与工作稿规范.md#发布成片目录)。

脚本创建目录，并在项目模式维护上方[项目总索引](#项目总索引)；保留已有文件、目录和历史入口，重复运行只补缺失目录和项目索引条目。新项目初始化获授权后直接执行；已有项目仅在获授权补齐目录时执行，不借接续或只读查询自动整理。它不创建定位、项目进度、配置、人物／场景等业务索引或其他空白正文，也不移动资料或连接任何服务；这些内容仍由agent按当前任务和模板保存。目录路径被文件占用或链接越出项目时，报告具体冲突并停止，不覆盖冲突对象。

标准输出为JSON：`mode`为`project`或`episode`，`project`为实际绝对路径，单集模式含`episode`；`created`和`existing`分别列出本次创建和复用的相对目录，`.`表示项目根。项目模式另含 `project_index`（总索引绝对路径）和 `index_added`（本次是否新增条目）。退出0表示本次目录及总索引登记完成，1表示路径、制作对象或配套参数组合、I/O错误，2表示命令行解析错误；失败可能已创建部分目录，解决所报问题后可再次运行。成功只表示目录及项目登记就绪，不代表创作、配置或审批完成，不另建目录日志或状态文件。

维护此工具时在临时目录验证新建、配套的独立选择与组合、后续补建、重复调用及用户导出文件保留、总索引首次创建／末尾追加／重复不改写、单集不改索引、无占位文件、参数组合错误及冲突停止；测试不使用真实项目：

```sh
python -B -m unittest discover -s .agents/skills/nora-ai-short-drama/scripts -p 'test_project_init.py' -v
```
