# 项目初始化规范

### 2. 创建项目目录

执行本节前先按[技术测试资料归属](文件版本与工作稿规范.md#技术测试资料归属)判断本次是否为真实短剧创作；工具或流程验收进入该规则的隔离验证分支，不直接套用下方正式项目创建步骤。

项目工作区的本地媒体依赖按[README的FFmpeg初始化与运行](../../../../../README.md#ffmpeg初始化与运行)落实。

项目初始化时按[工作区 ComfyUI 配置](../../../nora-generation/references/ComfyUI-服务配置与任务提交规范.md#工作区-comfyui-配置)复用共用服务设置；完整工作区已运行浏览服务时，可通过“任务进度→编辑”添加或修改节点，也可由Agent按用户确认内容维护同一份配置，不在项目根目录创建配置。

基本定位明确后，由agent调用[固定初始化脚本](#项目与单集目录初始化脚本)，在 `projects/` 下统一创建[项目基础结构](文件版本与工作稿规范.md#项目基础结构)及[综合资料的固定分类](文件版本与工作稿规范.md#综合资料存放规则)，不逐项手工创建或临时编写建目录代码；其余分类、资产和逐集子目录按对应规范的时机建立。用户简化创作流程时仍执行基础目录初始化，空目录不代表阶段已开始或需要补写内容；用户另有明确目录要求时按其范围处理。

本步骤在项目基本定位阶段会话内完成。会话安排及已有入口的补登，执行[会话创建提醒](../流程规范/会话与进度管理规范.md#剧名或代号确定后的会话创建提醒)。创建项目根目录和顶级目录后，保存本阶段定位，按 [会话组织与项目进度](../流程规范/会话与进度管理规范.md) 在项目根目录建立 `项目进度.md`；项目名称或临时代号确定后，由主控按该规范完成自身会话改名及进度入口名称同步。不提前生成后续阶段尚未完成的创作资料。除综合资料的固定分类外，工作稿、历史版本和执行附件首次有对应内容需要保存时才创建，不随项目初始化预建空目录。


### 项目与单集目录初始化脚本

入口：[project_init.py](../../scripts/project_init.py)。Python 3.9+，仅标准库，由agent直接调用，不依赖或接入网页后台。项目创建时机由[第2节](#2-创建项目目录)维护，单集创建时机由[逐集目录规范第1节](../流程规范/逐集目录与资产管理规范.md#1-单集根目录与过程文件)维护。

在工作区根目录运行，将项目名和集号替换为本次实际值；独立安装时替换脚本路径：

```sh
# 项目初始化：项目根、11个顶级目录、综合资料固定分类。
python .agents/skills/nora-ai-short-drama/scripts/project_init.py --project 'projects/项目名称'

# 开始本集：该集根及01至05准备目录，项目根必须已存在。
python .agents/skills/nora-ai-short-drama/scripts/project_init.py --project 'projects/项目名称' --episode EP001
```

| 参数 | 含义与路径基准 |
| --- | --- |
| `--project` | 必填，明确的项目根目录；相对路径从当前工作目录解析，也可传绝对路径，支持中文与空格。 |
| `--episode` | 可选，EP001至EP999，或固定名称“片头”“片尾”；省略时初始化项目骨架，指定时只初始化该制作对象准备目录，不预建其他集或共用对象。 |

脚本只创建目录，保留已有文件、目录和历史入口；重复运行只补缺失目录。新项目初始化获授权后直接执行；已有项目仅在获授权补齐目录时执行，不借接续或只读查询自动整理。它不创建定位、项目进度、配置、索引或其他空白正文，也不移动资料或连接任何服务；这些内容仍由agent按当前任务和模板保存。目录路径被文件占用或链接越出项目时，报告具体冲突并停止，不覆盖冲突对象。

标准输出为JSON：`mode`为`project`或`episode`，`project`为实际绝对路径，单集模式含`episode`；`created`和`existing`分别列出本次创建和复用的相对目录，`.`表示项目根。退出0表示本次目录初始化完成，1表示路径或I/O错误，2表示命令行参数错误；失败可能已创建部分目录，解决所报问题后可再次运行。成功只表示目录就绪，不代表创作、配置或审批完成，不另建目录日志或状态文件。

维护此工具时在临时目录验证新建、重复调用、补缺且保留原文、单集范围、无占位文件及冲突停止；测试不使用真实项目：

```sh
python -B -m unittest discover -s .agents/skills/nora-ai-short-drama/scripts -p 'test_project_init.py' -v
```
