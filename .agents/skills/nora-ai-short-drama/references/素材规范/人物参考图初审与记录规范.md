# 人物参考图初审与记录规范

状态：已定稿。  
版本：v1.33。
生效日期：2026-10-06。

人物参考图生成、交付、用户审批与记录时必须读取本文，不在每次任务中重新制定清单或记录结构。制作顺序、规格及命名以 [开发流程第8.1节](../流程规范/短剧开发流程规范.md) 为准，实际执行参数读取对应的 [文生图说明](../生成规范/ComfyUI-文生图执行规范.md) 或 [图生图说明](../生成规范/ComfyUI-图生图执行规范.md)。本文专用于人物四类图；场景图必须使用 [场景专项规范](场景资料与参考图规范.md) 的固定目录、交付及记录模板，道具图使用 [道具专项规范](道具资料与参考图规范.md) 的固定三视图交付和记录，不套用本人物清单。

## 1. 固定交付顺序与边界

人物四类图的交付、文件与记录核对、复用及用户审批统一执行[图片交付与用户审核](../流程规范/短剧开发流程规范.md#851-图片交付与用户审核)；需要图片内容分析时读取[看图能力调用边界](../../SKILL.md#看图能力调用边界)。批准后的规格与处理读取[开发流程第8.1节](../流程规范/短剧开发流程规范.md#规格背景与布局)及[图片超分执行规范](../生成规范/ComfyUI-图片超分执行规范.md)。

## 2. 文件、依据与用户审核

### 2.1 通用核对

从文件和执行记录核对实际尺寸、PNG格式、数量、可解码性、完整性及任务来源；从资料及批准记录核对人物、年龄状态、服装状态与实际输入版本。不要将请求中的外貌、朝向或布局要求当成已验证的输出特征。画面是否符合要求由用户判断，记录真实反馈及决定。

### 2.2 人物上半身正面肖像图

制作目标按[肖像模板](../模板/Qwen-Image-2.1-人物上半身正面肖像提示词模板.md)及资料卡编写；送审尺寸读取[人物规格](../流程规范/短剧开发流程规范.md#规格背景与布局)。批准后按[超分规范的文件核对、保存与记录](../生成规范/ComfyUI-图片超分执行规范.md#4-文件核对保存与记录)处理，完成的正式肖像用于人物本体六视图的身份参考。

### 2.3 人物多视角参考图

制作目标按[人物六视图模板](../模板/Qwen-Image-2.1-人物六视图提示词模板.md)及已批准肖像、身体资料编写。朝向、分格及上下共同特征是生成要求，不是agent逐格看图的授权。

### 2.4 服装参考图

制作目标按[服装模板](../模板/Qwen-Image-2.1-服装正背面图提示词模板.md)及已确认服装设计编写；用途、衣装状态与批准版本从记录核对。

基础服装图按[Qwen类型索引](../生成规范/Qwen-Image-2.1-提示词规范.md#11-图片类型专用模板索引)选择文生图或用户参考图大类。已有衣装的破损、污渍、湿透、修补等延伸读取[统一资产状态规则](../生成规范/Qwen-Image-2.1-提示词规范.md#27-资产状态参考图统一规则)，填写[资产状态模板的服装大类](../模板/Qwen-Image-2.1-资产状态参考图提示词模板.md#1-服装状态参考图)；展示规格仍读取开发流程第8.1节，使用原CH生成／审阅记录及服装状态字段。

### 2.5 角色多视角参考图

制作目标按[角色六视图模板](../模板/Qwen-Image-2.1-角色六视图提示词模板.md)编写。核对已批准人物本体和衣装的输入版本及用途；是否满足穿戴、朝向及身份一致性由用户审核，默认不调用看图能力验证。

### 2.6 修改与复用

人物图片的修改、复用、批准范围及历史事实执行[图片交付与用户审核](../流程规范/短剧开发流程规范.md#851-图片交付与用户审核)，适用的人物与衣装状态按开发流程第8.1节核对。

用户采用人物图片后，按最终实际提示词和用户已确认的修改同步人物资料卡，执行[图片状态收尾第2项](../流程规范/短剧开发流程规范.md#852-图片采用替换与归档后的状态收尾)。同一人物不同阶段的基础造型按[人物造型规则](../流程规范/短剧开发流程规范.md#不可逆外形变化与基础造型)维护。

## 3. 工作稿生成区固定模板

位置：`03-人物资料/其他资料/工作稿/CH编号-参考图-工作稿.md`。每个人物一份，位置及维护按[工作稿管理规则](../流程规范/短剧开发流程规范.md#工作稿管理规则)，跨四类图片及人物／服装状态持续维护，不按图片类型新建同义台账。保留专项当前资产、生成与审阅章节，不删改字段；不适用填“不适用”，尚无结果填“待补充”，未知信息不编造。

使用[人物参考图工作稿模板](../模板/人物参考图工作稿模板.md)中的固定正文；本节保留适用范围与填写规则。

维护规则：

- 正式图存放层级按[开发流程8.1](../流程规范/短剧开发流程规范.md#固定目录正式命名与过程资产)执行；有阶段目录时，正式文件链接从工作稿所在目录指向原资产 `参考图/{人物阶段}/{正式文件名}`。目录调整只更新引用，不重置生成编号、候选版本或批准事实。
- 当前正式资产表只登记已批准且完成规定后处理的图片，超分未完成时不登记为新正式图；不同类型及状态分别登记，不列待审候选，不复制人物资料卡正文或项目制作进度。
- 生成序号以同一人物为计数范围，不按图片类型重启；实际提交、恢复及候选计数按[图片生成条目与候选计数](../流程规范/短剧开发流程规范.md#851-图片交付与用户审核)执行。
- 需超分类型的子记录及次数填写读取[图片超分执行规范](../生成规范/ComfyUI-图片超分执行规范.md#4-文件核对保存与记录)，关联原生成条目。
- 候选留存及版本计数读取上述共用规则；对应四类图及状态使用各自固定正式图片名。
- 实际输入除了正式路径，还关联当时采用的具体候选版本，避免正式文件替换后无法追溯。旧项目无候选版本时链接真实的留存副本或归档，并明确来源现状，不虚构历史版本。
- 替换正式图后更新正式资产表；旧生成条目保留原来源、结果与当时批准事实，可补充旧正式图的归档入口，不篡改旧任务事实。
- 技术测试使用明确指定的测试位置，不混入正式项目资产；本模板中的空JSON只是字段占位，不得作为实际提示词提交。
- 机器执行附件不复制大段进入审阅文档。人物任务目录为`03-人物资料/其他资料/执行附件/`，前缀为`{CH编号}-生成记录-{三位序号}`；后缀、留存条件及检查时间维护统一执行[精简留档规则](../流程规范/ComfyUI-任务监控规范.md#执行附件精简留档)。

## 4. 工作稿审阅区固定模板

位置：同一参考图工作稿的审阅区，每个生成编号及审阅轮次有独立章节；保存文件核对、展示、用户反馈、具体决定及采用范围。送审与状态读取[开发流程8.5.1](../流程规范/短剧开发流程规范.md#851-图片交付与用户审核)。

使用[人物参考图工作稿审阅区](../模板/人物参考图工作稿模板.md#审阅区)中的固定正文；本节保留适用范围与填写规则。

如“脸可以，衣服需要调整”，记录局部认可及待修改内容，不批准整图。上游资产替换后，依据生成记录列出受影响的下游角色图或已有制作引用，检查后再决定处理；不自动重生成、覆盖或抹去历史批准。阶段是否完成仍根据项目要求及实际资产覆盖判断，不以一张图或一批任务通过代替整个阶段完成。
