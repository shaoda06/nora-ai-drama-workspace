# 剧集素材工作稿模板

适用于首帧及剧集专用参考图，共用[集内素材规则](../流程规范/逐集目录与资产管理规范.md#21-剧集专用参考图)。首帧另读取[首帧参考图规范](../../../short-drama-storyboard/references/首帧参考图规范.md)的第4节及适用的共用规则；各类型命名、保存位置、填写要求与审批以对应规范为准。本文件只维护可填正文，不替代规范。

技术收尾与Agent交付按[图片交付与用户审核](../../../nora-drama-assets/references/核心参考图制作规范.md#851-图片交付与用户审核)接续；本模板仅定义本类型记录字段。

整集素材记录的计数范围读取[集内素材规则](../流程规范/逐集目录与资产管理规范.md#21-剧集专用参考图)，提交与候选计数读取[开发流程8.5.1](../../../nora-drama-assets/references/核心参考图制作规范.md#851-图片交付与用户审核)。导入条目标明实际来源及处理；参数不存在填“不适用”，未知填“待补充”；附件按规范真实保存，不含凭据。下方围栏内是产出正文，替换编号与占位内容，不将本模板文件名作为项目产出名。

新生成图批准后按[图片超分执行规范](../../../nora-generation/references/ComfyUI-图片超分执行规范.md)在原条目补齐超分子记录；完成后才登记正式资产。导入图片按实际采用与处理记录，未经生成或超分的相应字段填不适用。采用后的引用、候选及监控收尾执行[开发流程8.5.2](../../../nora-drama-assets/references/核心参考图制作规范.md#852-图片采用替换与归档后的状态收尾)；当前处置及依据填入既有“用户决定及具体候选、批准依据”，关联变化填入“下游影响及处理”。

批准后的规格处理状态按[超分规范第4节](../../../nora-generation/references/ComfyUI-图片超分执行规范.md#4-文件核对保存与记录)填写；审核与当前处置沿上方共用入口。

ComfyUI故障补做授权、额度及执行条件统一读取[任务监控规范第3.3节](../../../nora-generation/references/ComfyUI-任务监控规范.md#33-故障补做授权与额度)，模板本身不授予额度。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../共用规则/文件版本与工作稿规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 1. 当前正式资产 | 按表维护当前正式采用文件、版本、范围及决定入口；旧采用过程留在对应记录。 |
| 2. 逐次生成记录 | 每次实际生成建立一条记录，固定填写任务信息、输入参考、提示词与执行参数、执行结果、检查与采用五节。 |
| 3. 讨论与修改 | 逐项记录问题、备选、取舍和待定内容，写清日期与依据。 |
| 4. 审阅区 | 按生成记录及审阅轮次重复，固定填写审阅对象、文件与记录核对、展示与用户反馈、用户确认、采用与后续影响五节。 |
| 其他补充（按需启用） | 固定放在上述正文之后；只写已有章节无法容纳的事项，采用下方三项条目，不记录修改流水。 |

讨论按事项重复“讨论-001”等小节；编号接续已有记录，不因模板更新重排。生成及审阅仍使用各自已有编号和固定子节。

## 审阅区

上方正文的“4. 审阅区”是同一工作稿的一部分；按具体生成编号、候选及审阅轮次追加章节，生成条目与正式资产表引用该章节。批准决定、生成处置与正式资产的关联统一读取[开发流程8.5.1](../../../nora-drama-assets/references/核心参考图制作规范.md#851-图片交付与用户审核)；本模板不另维护审批规则。
