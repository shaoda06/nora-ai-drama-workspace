# 本集制作前检查模板

使用前读取[短剧开发流程规范](../流程规范/短剧开发流程规范.md)的第二部分第2节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

章节、表头和字段由下方围栏内正文维护；填写、当前状态更新、历史记录及审批要求统一读取[开发流程第二部分第2节](../流程规范/短剧开发流程规范.md#2-本集制作前检查)。填写时替换EP编号，不将本模板文件名作为项目产出名。

生成任务的技术检查引用工具执行检查报告，Agent只维护内容准备及业务决定；授权后不重复准备核对。共同任务不在各P复制整批摘要，见[执行前检查与复用](../流程规范/ComfyUI-服务配置与任务提交规范.md#执行前检查与复用)。

涉及首帧及环境素材时，先读取[首帧规范第1节](../素材规范/首帧参考图规范.md#1-制作复用与画面要求)确定实际需求，再填写准备情况。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../流程规范/短剧开发流程规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 1. 当前结论与待办 | 维护当前可推进范围、阻塞、用户待决及下一步；已解决的问题不继续列作待办。 |
| 2. 资料与素材准备情况 | 按资料表维护当前有效入口、缺项及对当前环节的影响。 |
| 3. 本集内容与连续性要求 | 写本集必须落实的事件、设定、伏笔、信息差与结束状态。 |
| 4. 前后剧情承接 | 核对前后集的时间、地点、人物、持有物及未完成行动，不把规划写成已发生事实。 |
| 5. 检查依据 | 列本次实际检查的来源、版本和范围。 |
| 6. 检查与变更记录 | 按时间保存检查问题、当时结论、处理决定和依据；过期结论标作历史，与第一章当前结论分开。 |
| 其他补充（按需启用） | 固定放在上述正文之后；只写已有章节无法容纳的事项，采用下方三项条目，不记录修改流水。 |
