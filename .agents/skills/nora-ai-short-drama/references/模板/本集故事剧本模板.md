# 本集故事剧本模板

使用前读取[逐集内容制作规范](../流程规范/逐集内容制作规范.md)的第2节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

保持三个章节。正文沿用该节的动作、对白及特殊标注，不为填模板强行加入OS／VO、闪回、字幕或空镜；不加入镜号、景别、运镜、生成分段或模型提示词。初写交代地点、时间及内外景；完成分场后同步确定的场次编号和场头，分场只做制作拆分。 下方围栏内是产出正文，替换编号与占位内容，不将本模板文件名作为项目产出名。

```markdown
# EP编号-故事剧本

- 文档版本：
- 更新日期：
- 确认状态：

## 1. 编写依据

- 本集分集大纲及版本：
- 制作前检查入口：
- 必要的已确认调整：

## 2. 故事剧本正文

<按照叙事顺序，完整写出本集剧情、环境、人物动作、表演提示、对白、场间衔接与结尾；不是再次扩写大纲。最终集以收束为主，不强制留下下一集钩子。>

## 3. 其他备注

<仅填写确有必要的补充说明。按逐集内容制作规范第2节，必要时以“供下集承接的结束状态”概括正文已经落实、下集必须承接而原计划未充分说明的事实；不另建状态表，无补充则写“不适用”。>
```
