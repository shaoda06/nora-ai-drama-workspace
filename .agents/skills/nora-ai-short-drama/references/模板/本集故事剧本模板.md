# 本集故事剧本模板

使用前读取[逐集内容制作规范](../流程规范/逐集内容制作规范.md)的第2节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

台词与声音设计、正文边界、场次编排及统计填写读取[逐集制作规范第2节](../流程规范/逐集内容制作规范.md#2-本集故事剧本)。下方围栏维护固定三个章节；填写时替换编号与占位内容，不将本模板文件名作为项目产出名。

填写与送审时落实[动作、情绪与标点的联动](../流程规范/逐集内容制作规范.md#动作情绪与标点的联动)，具体要求由制作规范统一维护。

```markdown
# EP编号-本集剧本

- 文档版本：

- 确认状态：

## 1. 故事剧本正文

### EP编号-C编号

**地点**：[<村镇／区域，具体地点>](<SC资料卡相对路径>)

**时间**：<日／夜／晨／傍晚等；必要天气> / <内／外>

**人物**：<本场角色全名及必要年龄或身份>

<按照叙事顺序，完整写出本集剧情、环境、人物动作、表演提示、对白／VO／OS、场间衔接与结尾；按制作规范第2节以有动机的口语交流讲清核心因果，写出随对话发生的情绪和反应变化，不仅靠屏幕细字交代原委。不是再次扩写大纲。最终集以收束为主，不强制留下下一集钩子。>

<按实际场次重复上述场次标题、场头及剧情正文，不加入镜号或视频分段。>
```
