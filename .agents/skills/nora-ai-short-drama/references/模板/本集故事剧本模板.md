# 本集故事剧本模板

使用前读取[逐集内容制作规范](../流程规范/逐集内容制作规范.md)的第2节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

开始填写时，按[剧本、分镜与提示词的职责分工](../流程规范/逐集内容制作规范.md#剧本分镜与提示词的职责分工)确定正文范围与下游接续。台词与声音设计、场次编排及统计填写读取[逐集制作规范第2节](../流程规范/逐集内容制作规范.md#2-本集故事剧本)。下方围栏维护固定三个章节；填写时替换编号与占位内容，不将本模板文件名作为项目产出名。

填写时落实[人物性格与当下处境的台词适配](../流程规范/逐集内容制作规范.md#人物性格与当下处境的台词适配)及[动作、情绪与标点的联动](../流程规范/逐集内容制作规范.md#动作情绪与标点的联动)；交付前按[文本自检与订正](../流程规范/短剧开发流程规范.md#文本交付前的自检与订正)处理问题，具体要求由对应规范统一维护。

头部执行[正式内容文档的共用头部](../流程规范/短剧开发流程规范.md#正式内容文档的共用头部)，文档状态按对应流程填写；正文的固定章节与业务编号保持。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../流程规范/短剧开发流程规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 1. 故事剧本正文 | 按C场次重复场头与正文，写完整剧情、台词、必要动作与表演反应，标明声源并保留场次连续性。 |
| 2. 其他备注 | 固定填写台词统计、节奏说明；必要的结束承接等其他补充写在现有字段，不能成为第二份剧情正文。 |
| 3. 编写依据 | 列实际采用的大纲、制作前检查及已确认调整的文件与版本；完整采用过程链接原记录。 |

```markdown
# EP编号-本集剧本

- 项目名称或代号：{{当前项目实际名称或代号}}
- 文档版本：{{当前文档版本号}}
- 更新日期：{{YYYY-MM-DD}}
- 确认状态：{{按对应流程填写当前文档的实际状态}}
- 确认范围：{{当前文档已确认内容及待决边界；尚未确认时如实填写}}
- 确认依据：{{实际审阅或决定记录的简短链接；未确认写“尚未确认”}}

## 1. 故事剧本正文

**时间**：<日／夜／晨／傍晚等；必要天气> / <内／外>

**人物**：<本场角色全名及必要年龄或身份>

<按照叙事顺序，完整写出本集剧情、环境、人物动作、表演提示、对白／VO／OS、场间衔接与结尾；按制作规范第2节以有动机的口语交流讲清核心因果，写出随对话发生的情绪和反应变化，不仅靠屏幕细字交代原委。不是再次扩写大纲。最终集以收束为主，不强制留下下一集钩子。>

<按实际场次重复上述场次标题、场头及剧情正文，不加入镜号或视频分段。>

## 2. 其他备注

**台词统计**：按制作规范第2节，仅计实际说出的正文字符，三类互斥；人物画外对白计VO，不重复计对白。可辨认的群众话语计台词；排除标点、空白、角色名、表演提示、信息字幕及非语言／模糊环境人声。

**节奏说明**：<语言与动作如何并行、重要留白及待验证的容量；字数不等于实测时长。修订稿补充前后统计对照或链接对应审阅记录。>
```
