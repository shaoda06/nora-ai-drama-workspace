# 本集生成说明模板

使用前读取[逐集目录与资产管理规范](../流程规范/逐集目录与资产管理规范.md)的第3节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

保持三个业务章节，只保存生成前准备。索引可导航至生成记录，但不在本文件维护实际上传响应、远端路径、任务ID或执行状态；工作流基准与制作顺序引用现行规范，不自行改写审批依赖。 下方围栏内是产出正文，替换编号与占位内容，不将本模板文件名作为项目产出名。

首帧及环境参考的输入条件统一读取[首帧规范第1节](../素材规范/首帧参考图规范.md#1-制作复用与画面要求)。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../流程规范/短剧开发流程规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 1. 制作依据 | 列实际采用的剧本、分镜及其他生成前依据的文件和版本。 |
| 2. 共用生成约定 | 写本集已确认的共用要求、工作流与顺序入口及参考素材约定。 |
| 3. 分段资料索引 | 按场次和P段维护提示词与已有生成记录入口；不存任务状态或远端响应。 |
| 其他补充（按需启用） | 固定放在上述正文之后；只写已有章节无法容纳的事项，采用下方三项条目，不记录修改流水。 |

```markdown
# EP编号-生成说明

- 文档版本：
- 更新日期：
- 确认状态：

## 1. 制作依据

| 依据资料 | 实际文件入口 | 采用版本 |
| --- | --- | --- |
| 整集故事剧本 | | |
| 本集分镜索引 | | |
| 其他相关依据（按实际需要） | | |

## 2. 共用生成约定

- 采用的工作流基准及规范入口：
- 本集制作顺序：
- 本集已确认的统一要求及确认依据：
- 场次首帧与逐段环境参考：<记录本集实际约定、用户选择依据及适用范围，具体素材映射见分段文档>

## 3. 分段资料索引

| 场次 | 分段 | 分段提示词入口 | 生成记录入口（已有时） |
| --- | --- | --- | --- |

## 其他补充

无。确有未被以上章节覆盖的事项时，按以下三项逐条填写；填写后删除本提示。

- 事项：<简短名称>
- 内容与适用范围：<当前需要补充的事实、说明及所指对象>
- 依据与当前状态：<实际来源入口；已确定／待确认／待落实，以及尚需处理的内容>

```
