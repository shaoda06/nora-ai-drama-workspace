# ComfyUI-任务监控提示词模板

版本：v1.6；更新日期：2026-10-16。

## 1. 使用方式

用于后台通知后的Agent结果处理，或用户主动要求复查既有任务；不创建生成监控heartbeat。技术策略的唯一真源为[任务监控规范](../流程规范/ComfyUI-任务监控规范.md)。按任务填写，不伪造远端ID或完成事实。

## 2. 任务填写区

```text
项目及阶段：{项目、任务类型、审批和当前授权}
本地任务ID：{后台UUID}
远端任务ID与地址：{已经取得的真实值，未提交填写未提交}
来源会话：{真实会话ID与名称}
记录入口：{后台任务状态.json、后台过程记录.json及原执行附件}
成果保存目标：{入队时明确的本机文件路径和输出对应关系}
通知ID：{本次批次UUID；主动查询无通知时填不适用}
当前问题：{最新结果、失败阶段或需要复查的具体事项}
```

## 3. 共用固定正文

工具调用先读[后台工具的共用条件](../comfyui-scripts/README.md#后台任务查询与结果处理)，再按动作选择[状态查询](../comfyui-scripts/README.md#后台状态查询)、[通知确认](../comfyui-scripts/README.md#后台通知确认)、[视频待审登记](../comfyui-scripts/README.md#后台视频待审登记)或[取回重试](../comfyui-scripts/README.md#后台取回重试)；具体业务处理按下方正文及媒体分支执行。

```text
有通知ID时先调用browser_tasks.py ack，一次确认并读取本批摘要。正常成功按摘要接续，不再次查询status或展开完整日志；异常按失败阶段读取对应证据。需要最新状态时用browser_tasks.py status；取回失败用原本地ID请求retry-collection，不重新生成。维护既有业务记录并按原授权交付；成果保存不等于人工批准，不擅自启动下一阶段。
```

## 4. 图片处理分支

```text
读取监控规范第4节及当前图片用途的专项规范，核对下载文件与执行记录后交用户审核，默认不调用看图能力。
```

## 5. 视频处理分支

```text
读取监控规范第5节及链接的目录与审核规则；正常completed结果直达“视频完成通知后的精简收尾”，异常只查对应失败阶段。后台按监控规范第2节“任务完成后取回全部成果”执行。正常成功调用browser_tasks.py register-results，复用本批成果条目完成待审登记和网页核验，不再展开固定映射；必要业务文字由Agent通过record-updates一次提供。读取报告，登记或同步失败仅接续未完成部分；保留用户决定，不自动批准。通过报告确认可审的网页入口交付；对话通知方式按该规则执行。缺项单列，不用部分文件证明全场完成。
```
