# ComfyUI-任务监控提示词模板

更新日期：2026-10-07。本文件提供任务填写区、共用固定正文和媒体分支；监控策略、取回条件、异常处理及附件留存统一读取[ComfyUI-任务监控规范](../流程规范/ComfyUI-任务监控规范.md)。

## 1. 使用方式

先读取监控规范，按实际任务填写第2节，组合“任务填写区＋第3节共用固定正文＋第4或第5节媒体分支”。规范路径使用实际安装位置的绝对路径；不得遗漏。监控方式与检查间隔从规范第1节读取，执行附件从第2节读取，任务身份与取回映射从第3节读取。

- 定时模式：将填写后的任务区、共用固定正文及对应媒体分支组合为同会话定时器提示词；创建、更新与恢复操作执行监控规范第1、2节。
- 图片会话内轮询模式：在当前会话使用同一填写区、共用正文及图片分支；定时器ID的填写与切换执行监控规范第1、2节。

替换全部花括号字段；不适用填“不适用”，状态不明如实保留未知，不把图片字段套用于视频。任务清单仅填写已确认提交的真实ID；待提交条目引用既有业务记录。具体填写边界读取监控规范第2、3节。

## 2. 任务填写区

```text
任务：{项目名称或代号}／{资产范围或EP/C编号}／{图片用途或视频阶段}
媒体类型：{图片／视频}
图片处理阶段：{原生候选生成／批准后2倍超分；超分注明审批原图、版本与批准记录；视频填不适用}
批次类型：{图片批次／单视频任务／视频队列}
本批计划输出图片总数：{初始计划，仅作范围记录，不固定监控方式；视频填不适用}
当前待生成图片数及核对时间：{本批排队中＋正在生成的输出张数；未知项单列及说明依据；视频填不适用}
监控方式：{当前会话内轮询／同会话heartbeat／仅待提交按监控规范第1.1节接续／无待生成及可继续提交任务，处理取回和审阅}
跟进范围：{仅查询取回／查询取回并推进已授权待提交范围；后者须注明现有任务清单或生成记录入口及实际授权依据，未填写按仅查询取回}
待提交范围入口：{现有任务清单或生成记录中的待提交条目，含准备资料、授权、任务类型、用户指定依据及最近分配检查时间；无则不适用，不填虚构prompt ID}
检查间隔：{已提交任务按监控规范第1节，待提交任务按监控规范第1.1节；明确例外记录依据}
服务地址（依据[任务地址绑定与恢复规则](../流程规范/ComfyUI-服务配置与任务提交规范.md#已提交任务的地址与恢复)读取实际提交证据）：{本任务实际ComfyUI URL；不同远端的任务逐项注明}
资料目录：{实际项目、资产或单集绝对路径}
技能入口：{nora-ai-short-drama SKILL.md绝对路径}
监控规范：{ComfyUI-任务监控规范.md绝对路径}
监控模板：{本文件绝对路径}
审核规范：{实际媒体／图片用途对应规范绝对路径}
定时器ID及状态：{真实ID及活动／因模式切换暂停／因无待生成图片暂停／用户停止；未创建填不适用}
最近切换依据：{核对时间、当前数量、原方式→新方式、定时器操作结果；未切换填不适用}
时间：使用者本机时间，时区{本机IANA时区或实际UTC偏移}；UTC事件转为该时区，记录实际偏移
报告模式：{每次定时检查报告／仅实质变化报告／用户明确指定方式}
展示方式：{视频默认方式读取开发流程第二部分第7节，填写该阶段的运行中展示与终态汇总安排；图片填逐项／统一展示；用户指定例外注明依据，客观异常单列}
图片修改／重试授权与次数：{用户明确授权的目标及次数；无则不追加生成；视频填不适用}
图片逐图累计次数与恢复入口：{已有生成记录及批次清单路径；填写每张已用次数、当前待确认提交和剩余额度，未知先核对不得猜测}
查询与取回入口：{comfyui_client.py绝对路径及status／download的实际参数}
任务清单（每项一行，允许多项，不纳入其他任务）：
{资产或分段编号} | {既有生成条目或R编号及阶段} | {prompt ID} | {执行记录入口} | {预期正式输出节点及文件类型／数量} | {候选文件路径或多输出映射入口}
```

## 3. 共用固定正文

```text
先读取填写区“监控规范”所指的ComfyUI-任务监控规范.md，以及本批既有执行／生成记录。
按该规范第1–3节执行本轮监控、查询、取回、异常处理、留档与收尾，并按第6节核对。
跟进范围、任务清单、用户授权及通知偏好使用填写区的实际内容；执行对应媒体分支。
```

## 4. 图片处理分支

读取监控规范第4节“图片处理”及其中按图片用途、阶段链接的专项规范，处理本批图片。
```

读取监控规范第5节“视频处理”及其中链接的导演台、目录与审核规范，处理本批视频。
```
