# ComfyUI-任务监控提示词模板

版本：v1.11；更新日期：2026-10-25。

## 1. 使用方式

用于编写后台通知后结果处理的交接提示词，或用户主动要求复查既有任务的处理提示词；日常查询与正常通知直接沿[对应处理分支](../../../nora-generation/references/进度查询与结果处理规范.md)执行，无需另填本模板。不创建生成监控heartbeat。技术策略的唯一真源为[任务监控规范](../../../nora-generation/references/ComfyUI-任务监控规范.md)。按任务填写，不伪造远端ID或完成事实。

## 2. 任务填写区

```text
项目及阶段：{项目、任务类型、审批和当前授权}
本地任务ID：{后台UUID}
远端任务ID与地址：{已经取得的真实值，未提交填写未提交}
来源会话：{真实会话ID与名称}
记录入口：{后台任务状态.json、后台过程记录.json及原执行附件}
成果保存目标：{入队时明确的本机文件路径和输出对应关系}
本批真实任务与预期范围：{既有执行清单入口；仅计算本次实际任务和成果}
对话通知要求：{按用户要求填写；整批统一通知时，部分完成只读报告确认，不逐段发消息}
通知ID：{本次批次UUID；主动查询无通知时填不适用}
当前问题：{最新结果、失败阶段或需要复查的具体事项}
```

## 3. 共用固定正文

工具调用先读[后台工具的共用条件](../comfyui-scripts/README.md#后台任务查询与结果处理)，再按动作选择[状态查询](../comfyui-scripts/README.md#后台状态查询)、[最终报告读取](../comfyui-scripts/README.md#后台最终报告读取)、异常时的[兼容待审登记](../comfyui-scripts/README.md#后台视频待审登记)或[取回重试](../comfyui-scripts/README.md#后台取回重试)；具体业务处理按下方正文及媒体分支执行。

```text
有通知ID时调用browser_tasks.py report，读取后台已保存的最终报告，工具在同次读取自动确认收到。正常成功按本次通知要求处理报告，不再次查询status或展开完整日志；视频整批统一通知时，部分完成只确认收到，待整批完成再汇报。异常按失败阶段读取对应证据。需要最新状态时用browser_tasks.py status；取回失败用原本地ID请求retry-collection，不重新生成。正常结果按下方媒体分支处理；用户新决定另按其实际范围处理，不擅自启动下一阶段。
```

## 4. 图片处理分支

```text
执行[监控规范第4节](../../../nora-generation/references/ComfyUI-任务监控规范.md#图片批次通知与超分静默)。普通图片整批就绪后只读report，按delivery集中展示成果及审核入口；正常超分静默，历史正常超分通知只读确认，不输出处理进度、完成回复或图片。技术核验、记录更新和网页同步由后台完成，不再读文件或补常规记录。异常才读取对应证据；默认不调用看图能力，技术成功不代表用户批准。
```

## 5. 视频处理分支

```text
视频结果按[视频完成通知后的精简收尾](../../../nora-generation/references/ComfyUI-任务监控规范.md#视频完成通知后的精简收尾)执行对应阶段分支；依据报告汇报，不重复技术收尾。异常按[结果恢复入口](../../../nora-generation/references/进度查询与结果处理规范.md#异常与恢复)处理，保留已有成果和用户决定。缺项单列，不用部分文件证明全场完成。
```
