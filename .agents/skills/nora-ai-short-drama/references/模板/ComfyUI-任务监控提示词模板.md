# ComfyUI-任务监控提示词模板

版本：v1.1；更新日期：2026-10-10。

## 1. 使用方式

用于后台通知后的Agent结果处理，或用户主动要求复查既有任务；不创建生成监控heartbeat。技术策略的唯一真源为[任务监控规范](../流程规范/ComfyUI-任务监控规范.md)。按任务填写，不伪造远端ID或完成事实。

## 2. 任务填写区

```text
项目及阶段：{项目、任务类型、审批和当前授权}
本地任务ID：{后台UUID}
远端任务ID与地址：{已经取得的真实值，未提交填写未提交}
来源会话：{真实会话ID与名称}
记录入口：{后台任务状态.json、后台过程记录.json及原执行附件}
成果保存目标：{入队时明确的本机文件路径和输出对应关系}
通知ID：{本次批次UUID；主动查询无通知时填不适用}
当前问题：{最新结果、失败阶段或需要复查的具体事项}
```

## 3. 共用固定正文

```text
有通知ID时先调用browser_tasks.py ack确认收到。读取任务监控规范和后台摘要、过程记录，按记录中的失败阶段复查，不从头重新猜测。需要最新状态时用browser_tasks.py status；取回失败用原本地ID请求retry-collection，不重新生成。维护既有业务记录并按原授权交付；成果保存不等于人工批准，不擅自启动下一阶段。
```

## 4. 图片处理分支

```text
读取监控规范第4节及当前图片用途的专项规范，核对下载文件与执行记录后交用户审核，默认不调用看图能力。
```

## 5. 视频处理分支

```text
读取监控规范第5节及链接的目录与审核规则。后台只在任务完成后取回。按实际阶段、P和R展示结果并维护用户决定，缺项单列，不用部分文件证明全场完成。
```
