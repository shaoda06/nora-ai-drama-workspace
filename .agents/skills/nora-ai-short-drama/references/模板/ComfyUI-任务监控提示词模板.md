# ComfyUI-任务监控提示词模板

版本：v1.15；更新日期：2026-10-28。

## 1. 使用方式

用于编写后台通知后结果处理的交接提示词，或用户主动要求复查既有任务的处理提示词；日常查询与正常通知直接沿[对应处理分支](../../../nora-generation/references/进度查询与结果处理规范.md)执行，无需另填本模板。不创建生成监控heartbeat。技术策略的唯一真源为[任务监控规范](../../../nora-generation/references/ComfyUI-任务监控规范.md)。按任务填写，不伪造远端ID或完成事实。复制提示词时将下方规则入口占位符替换为本机实际安装路径及章节；只复制本次适用的媒体分支，不把模板相对链接带入项目或新会话。

## 2. 任务填写区

```text
项目及阶段：{项目、任务类型、审批和当前授权}
本地任务ID：{后台UUID}
远端任务ID与地址：{已经取得的真实值，未提交填写未提交}
来源会话：{真实会话ID与名称}
记录入口：{后台任务状态.json、后台过程记录.json及原执行附件}
成果保存目标：{入队时明确的本机文件路径和输出对应关系}
本批真实任务与预期范围：{既有执行清单入口；仅计算本次实际任务和成果}
任务组ID及固定成员：{工具回执中的group_id和成员入口；历史无组任务明确注明}
对话通知要求：{默认按整轮业务范围汇总；填写已有的用户明确例外，无例外时沿默认规则}
通知ID：{本次批次UUID；主动查询无通知时填不适用}
当前问题：{最新结果、失败阶段或需要复查的具体事项}
工具入口：{实际绝对路径}/nora-ai-short-drama/references/comfyui-scripts/README.md 的“后台任务查询与结果处理”及本次动作小节
规则入口：{实际绝对路径}/nora-generation/references/ComfyUI-任务监控规范.md；异常入口：{实际绝对路径}/nora-generation/references/进度查询与结果处理规范.md
```

## 3. 共用固定正文

工具调用先读[后台工具的共用条件](../comfyui-scripts/README.md#后台任务查询与结果处理)，再按动作选择[状态查询](../comfyui-scripts/README.md#后台状态查询)、[最终报告读取](../comfyui-scripts/README.md#后台最终报告读取)、异常时的[兼容待审登记](../comfyui-scripts/README.md#后台视频待审登记)或[取回重试](../comfyui-scripts/README.md#后台取回重试)；具体业务处理按下方正文及媒体分支执行。

```text
先执行监控规范“跟进与通知”的默认整轮汇总规则，优先按groups核对本组固定成员、进度和缺项，历史任务再用rounds与原记录。有通知ID时调用browser_tasks.py report，读取后台已保存的最终报告，工具在同次读取自动确认收到；部分正常成功静默接收，在既有共同记录保留结果入口及尚未交付状态；达到整轮交付条件后连同此前已读结果一次汇报，并记录实际交付范围。report的读取回执及new_task_ids不代替整轮交付记录。报告指出业务同步未覆盖项时由Agent处理，不重做已完成的技术收尾。正常结果不再次查询status或展开完整日志。异常按groups[].issues合并，按失败阶段读取对应证据；沿原授权、原ID先静默修复，只有需用户决定、超出授权或确实无法继续时才合并汇报影响与待决项。处理后查一次最新组状态，接续同类后到成员；不另建轮询或heartbeat。需要最新状态时优先用browser_tasks.py status --group-id，排查单项用--task-id；取回失败用原本地ID请求retry-collection，不重新生成。正常结果按下方媒体分支处理；用户新决定另按其实际范围处理，不擅自启动下一阶段。
```

## 4. 图片处理分支

```text
先按填写区规则入口的“3. 跟进与通知”确定交付范围，再执行“图片批次通知与超分静默”。普通图片整批就绪后只读report，按delivery集中展示成果及审核入口；正常超分静默，历史正常超分通知只读确认，不输出处理进度、完成回复或图片。技术核验、记录更新和网页同步由后台完成，不再读文件或补常规记录。异常才读取对应证据；默认不调用看图能力，技术成功不代表用户批准。
```

## 5. 视频处理分支

```text
先按填写区规则入口的“3. 跟进与通知”确定交付时机；视频结果按其“视频完成通知后的精简收尾”执行对应阶段分支；依据报告汇报，不重复技术收尾。异常按填写区异常入口的“异常与恢复”处理，保留已有成果和用户决定。缺项单列，不用部分文件证明全场完成。
```
