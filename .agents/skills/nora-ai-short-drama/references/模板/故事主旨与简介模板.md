# 故事主旨与简介模板

使用前读取[短剧开发流程规范](../流程规范/短剧开发流程规范.md)的第一部分第3节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

保持七章名称与顺序；世界观子项按题材展开。 下方围栏内是产出正文，填写时使用产出标题，不将本模板文件名作为项目产出名。

```markdown
# 故事主旨与简介

## 1. 故事主旨
故事要表达的核心主题与情感指向。

## 2. 世界观与核心规则
时代与空间、相关社会环境，以及影响剧情的运行规则、代价和限制。
具体子项按题材需要展开，只写与故事有关的设定。

## 3. 核心故事设定
主角的特殊处境、故事起点及推动故事发生的核心前提。

## 4. 主要矛盾与主角目标
主要冲突、主角想要达成的目标、主要阻力及相关利害。

## 5. 一句话梗概
用一句话概括主角、处境、目标及核心冲突。

## 6. 故事简介
连贯介绍故事的起点、主要发展方向和核心吸引力，不展开为全局大纲。

## 7. 结局方向
主要矛盾、主角目标与主题表达预期如何收束。
```
