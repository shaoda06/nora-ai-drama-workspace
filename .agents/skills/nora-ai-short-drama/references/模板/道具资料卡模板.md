# 道具资料卡模板

使用前读取[短剧开发流程规范](../流程规范/短剧开发流程规范.md)的第一部分第6节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

先按[道具规范第1节](../素材规范/道具资料与参考图规范.md#1-制作时机与资产身份)确定本对象是否需要建卡，再填写下方正文。

虚拟界面按[固定元素与剧情内容规则](../素材规范/道具资料与参考图规范.md#虚拟界面固定元素与剧情内容)填写既有外观、状态及连续性字段。

保持七章及固定字段。 下方围栏内是产出正文，填写时使用产出标题，不将本模板文件名作为项目产出名。

头部执行[正式内容文档的共用头部](../流程规范/短剧开发流程规范.md#正式内容文档的共用头部)，文档状态按对应流程填写；正文的固定章节与业务编号保持。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../流程规范/短剧开发流程规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 1. 基本信息 | 登记道具编号、名称、类型和剧情用途。 |
| 2. 归属与使用 | 说明归属、使用人物、使用方式及流转关系。 |
| 3. 外观与结构 | 写可辨认的外观、结构、材质和尺度。 |
| 4. 道具状态 | 按状态表写实际状态、变化条件和剧情范围。 |
| 5. 连续性约束 | 说明必须保持的特征、允许变化与禁止混用。 |
| 6. 参考图生成要点 | 写参考图需要呈现的视图、结构、状态和输入要求。 |
| 7. 其他备注 | 只容纳前六章无法覆盖的项目特有补充，按其他补充条目填写。 |
