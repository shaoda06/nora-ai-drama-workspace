# Qwen-Image-2.1-资产状态参考图提示词模板

版本：v1.03；更新日期：2026-10-08。

用于已有服装、场景和道具的状态延伸，按下方对应大类填写；用途、源图和衍生记录读取[统一资产状态规则](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#27-资产状态参考图统一规则)。

使用前读取[Qwen提示词规范](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md)及[图像编辑共用填写与输出格式](Qwen-Image-2.1-图像编辑提示词模板.md)。占位符按[统一填写规则](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#15-模板占位符填写)处理；画风按[项目画风正文引用](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#16-项目画风正文引用)填写。只使用当前资产对应的一份正文，不把整个文件交给模型。

生成方式：图生图。输入资格与状态用途按统一资产状态规则，修订和种子分别读取[第2.5节](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#25-参考图统一修订规则)及[第2.6节](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#26-项目七类图片默认种子)。用户提供并指定的原图与项目已批准图都按其实际用途填写输入指代；单图用“图像”，多图按真实顺序逐张使用 `<image1>`、`<image2>` 等标签。输出使用编辑三字段JSON，`wh_ratio` 取对应规格，`ratio_follow` 为空；不在模型正文写像素和种子。

## 1. 服装状态参考图

规格与独立衣装展示读取[人物规格](../../../nora-drama-assets/references/人物参考图制作与记录规范.md#2-规格背景与布局)，状态身份与记录读取[人物规范](../../../nora-drama-assets/references/人物参考图制作与记录规范.md#44-服装参考图)。本大类只改变同套衣装的已确认状态，不承担人物身份、身体状态或新款式设计。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
依据{{实际输入图指代及逐张参考用途}}，生成同一套{{服装身份}}处于{{目标状态}}的独立服装正背面参考图。
纯白背景，一行两列，左列正面、右列背面，展示尺度一致。衣物空置独立陈列，没有真人身体及头部配饰，完整展示衣物、鞋履和必要的非头部附件，各格及格间合理留白。
柔和均匀的光照呈现衣料和目标状态细节。

服装描述：
将{{来源状态中需改变的部位}}呈现为{{目标破损、污渍、湿润或修补等完整状态描述，明确位置、范围、程度及连接关系}}。
{{需要承接的来源状态特征，以及本次新增、恢复或保留的范围}}。
正背面按{{已确认的对应变化位置}}表现同一状态，保持真实遮挡，不把只在正面可见的变化复制到背面。
保留输入图中{{未改变的款式、层次、材质、配色、纹样与识别特征范围}}；{{已确认的新暴露区域、修补材料或必要附件状态}}。
```

## 2. 场景状态参考图

规格、空间、机位与可见范围读取[场景规范第4节](../../../nora-drama-assets/references/场景资料与参考图规范.md#41-画面要求)。状态变化在已确认空间内呈现，不通过拆墙、去顶或移动固定陈设制造可见性。是否属于状态延伸、是否同时换机位，按[场景生成分支](../../../nora-drama-assets/references/场景资料与参考图规范.md#411-生成方式与参考输入)选择；下方填写本次目标机位与可见状态，不填写镜头内的动作过程。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
依据{{实际输入图指代及逐张参考用途}}，生成同一{{场景身份、室内／室外及目标区域}}处于{{目标时间、天气、季节或其他状态}}的一幅{{景别}}连续环境画面。
机位位于{{以固定物件定位的位置}}，从{{观察起点}}看向{{观察方向及目标}}，高度为{{已确认高度}}，采用{{俯仰关系及必要倾角}}。
取景覆盖{{必须包含的区域与边界}}；{{自然遮挡与画外区域}}。保持单张连续画面及合理环境余量。

场景描述：
保留输入图中{{未改变的布局、建筑连接、出入口、固定陈设与识别特征范围}}。
将{{来源状态中需变化的区域或物件}}呈现为{{本轮完整目标状态，包含数量、位置、范围、程度及与固定结构的关系}}；{{需要承接的来源状态特征}}。
前景：{{本机位关键近处结构与关系；无则写无}}。
中景：{{主要功能区域、可见陈设与关系}}。
背景：{{远处边界、结构与纵深关系}}。
{{本机位可见的配套用品、生活痕迹、材质与整洁或杂乱状态；未变化内容总括保留}}。
来自{{符合目标状态的实际光源及方向}}的光线形成{{明暗、阴影与必要清晰区域}}。
{{有确认依据的新可见结构及环境细节}}。透视与遮挡随本次机位变化，固定空间关系保持一致；{{仅在需求明确时加入的可见人物或道具}}。
```

## 3. 道具状态参考图

单视角、整体或局部取景、背景及送审规格读取[道具状态规则](../../../nora-drama-assets/references/道具资料与参考图规范.md#状态衍生与复用)。内部结构等新可见内容按已确认设计填写，输出只显示本次一个状态。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
依据{{实际输入图指代及各自用途}}，生成同一道具处于{{目标状态}}的一张单视角参考图。

采用{{最能说明状态的观察方向与俯仰角度}}，以{{整体或局部取景范围、主体位置及边缘留白}}清楚展示{{必须看清的状态特征}}。参考图提供道具设计与来源状态，输出采用这里指定的单一构图。

纯白背景，柔和光照呈现目标部位的结构、材质与连接关系。

道具描述：
将{{来源状态中需改变的部件}}呈现为{{目标形状、位置、数量及连接、分离或接触关系}}。

{{需要承接的前一状态特征及其在目标状态下的可见表现}}。

{{新暴露区域或关键内部细节的已确认设计}}。

保留输入图中{{未改变的设计与识别特征范围}}；随当前视角呈现相应透视与遮挡关系。
```
