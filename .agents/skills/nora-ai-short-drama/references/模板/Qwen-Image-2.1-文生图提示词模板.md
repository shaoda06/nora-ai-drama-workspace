# Qwen-Image-2.1-文生图提示词模板

本文件只维护文生图共用填写区、辅助骨架和两字段JSON格式；专用正文按[图片类型索引](../生成规范/Qwen-Image-2.1-提示词规范.md#11-图片类型专用模板索引)读取。先读规范第1—3节，再填对应类型文件；本文件不作为通用提示词直接提交；项目定位中的单张风格示例按开发流程验证分支使用此骨架，不套用正式资产构图。

语言遵循[统一中文规则](../生成规范/Qwen-Image-2.1-提示词规范.md#14-统一中文编写审阅与提交)，接口键名保持原样。


正文按语义分段，填写时保留清楚的换行与空行；输出JSON时在字符串内用`\n`表示换行、`\n\n`表示空行，JSON本身仍可为单行。字段数量及含义不变，已冻结请求原文不回写。

**占位符填写：** 所有 `{{…}}` 按[占位符填写规则](../生成规范/Qwen-Image-2.1-提示词规范.md#15-模板占位符填写)逐项处理，不能原样提交。本模板的填写依据为本次任务对应的已确认人物／场景／道具资料、目标状态与项目画风；有场次或镜头要求时同时核对，不适用内容及JSON空值按字段规则处理。

位置、朝向、光线与运动按[统一方向参照](../生成规范/镜头语言参考指南.md#13-统一方向参照)填写；多视图先明确视格，再描述该视格内的画面方向。

## 1. 中文需求填写区

```text
任务与用途：{{本次素材及使用目的}}
主体与数量：{{人物／场景／道具，以及明确数量}}
画风来源与版本：{{项目定位入口及已确认正文版本；风格测试注明候选版本}}
画风正文：{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}
已确认且不可改变：{{身份特征、颜色、结构、空间关系等}}

主体可见细节：{{本视图能看见的外貌或结构}}
姿态与视线：{{人物姿态、相对当前镜头的朝向、表情；不适用则省略}}
服装／材质：{{具体材料、表面状态、颜色}}

背景与边缘：{{背景、上缘、下缘及左右边缘实际可见内容}}
构图与取景：{{景别、主体位置和占比、完整展示要求、留白}}
光线：{{光源及其在当前画面中的方向、软硬、明暗及阴影}}

画面原文：{{需要出现在图中的原文、位置和样式；无文字则省略}}

允许补充：{{本次可以由编写者决定的细节范围}}
排除与约束：{{不应出现的内容及必须保留的边界}}

画面比例：{{采用开发流程或本次已确认比例}}
目标像素（仅需求记录）：{{已确认宽×高，不进入模型正文}}
```

## 2. 单主体正文骨架

```text
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

一幅{{横向／纵向／方形}}{{媒介与景别}}画面，在{{背景颜色与环境特征}}中呈现{{明确的单一主体}}。背景呈现{{可见表面、色彩变化与空间深度}}。

画面中央，{{主体位置、朝向与姿态}}。在{{主体最上方特征}}上方，{{留白范围与连续背景}}。画面左右边缘，{{周围空间的宽度与可见状态}}。

主体上部呈现{{可见形状、比例和识别细节}}。在{{明确位置}}，{{第二项重要识别特征及其颜色或结构}}。{{相关区域}}周围，{{材质边界、轮廓或过渡}}。

靠近中央，{{最重要的面部或结构特征}}。{{人物的视线与表情，或物体的功能部件与结构关系}}。

在{{已命名特征}}下方，{{依空间顺序出现的细节}}。{{指定可见表面}}呈现{{材质、纹理、磨损与适度色彩变化}}。在{{另一相关位置}}，{{其他已确认细节及其与周围形体的关系}}。

画面下缘呈现{{准确裁切位置、支撑面或衣物边界}}。{{如适用，说明局部遮挡及仍可见的部分}}。

光线来自{{光源与方向}}，形成{{软硬、亮度、阴影位置与高光特征}}，使{{重要材质与识别特征的可见效果}}。

整体构图呈现{{用一句话连接画面平衡、配色与情绪}}。
```

## 3. 多区域正文骨架

```text
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面内容：媒介、整体主体及横竖方向。
背景：整体空间、背景平面与主要色调。

画面上部：天空、天花板、顶部结构或已要求的标题。
画面左侧：可见元素、位置、材料，以及与中央区域的关系。
画面中央：主要对象及其空间关系。
画面右侧：可见元素与中央区域的衔接。
画面下部：前景、地面、底部结构或已要求的文字。

光线：方向、质量，以及作用于空间和材质的结果。
结尾：一句整体构图、色彩和氛围描述。
```

## 4. 可读文字插入格式

```text
在{{位置}}，以{{字体样式、颜色与相对大小}}显示文字“{{用户指定的准确原文}}”。
```

## 5. 文生图输出格式

```json
{"rewritten_prompt":"{{完整中文画面描述}}","wh_ratio":"{{用户已确定的比例}}"}
```
