# Qwen-Image-2.1-服装正背面图提示词模板

版本：v1.15；更新日期：2026-09-30。

主要确定独立衣装的款式、层次、材质、配色、纹样、正背结构、鞋履及必要的非头部配饰，适配资料卡人物状态和项目画风；不承担人物身份或身材定型。用于正背面设计与获授权修订；每次只展示同一套服装，先补齐背面和必要配饰设计。

使用前读取[Qwen提示词规范](../生成规范/Qwen-Image-2.1-提示词规范.md)，按本节固定生成方式读取[文生图共用填写与输出格式](Qwen-Image-2.1-文生图提示词模板.md)或[图像编辑共用填写与输出格式](Qwen-Image-2.1-图像编辑提示词模板.md)。尺寸、基础着装、制作依赖以[开发流程第8节](../流程规范/短剧开发流程规范.md#8-核心参考图)为准。只填写当前情况，不把整个文件交给模型。新正文按[统一中文规则](../生成规范/Qwen-Image-2.1-提示词规范.md#14-统一中文编写审阅与提交)填写。

画风占位符遵循[项目画风正文引用](../生成规范/Qwen-Image-2.1-提示词规范.md#16-项目画风正文引用)。

**占位符填写**：遵循[统一填写规则](../生成规范/Qwen-Image-2.1-提示词规范.md#15-模板占位符填写)。

**填写依据**：对应人物资料卡的目标人物状态与服装状态、已确认正背面设计、鞋履附件及项目画风；提取设定时排除头部配饰，不将发冠、发簪、发饰、耳饰等作为生成或保留对象；修订时同时核对实际输入服装图和授权修改范围。

- [1. 依据服装设定生成](#1-依据服装设定生成)
- [2. 已有服装修订](#2-已有服装修订)

左右与前后位置先按[方向表达规则](../生成规范/Qwen-Image-2.1-提示词规范.md#21-左右方向与可见位置)换算：先指明左列正面／右列背面，再说该视图内的具体位置，补足靠前或靠侧及邻近部件。背面只写可见结构；位置以该服装的已确认设计为准。


## 1. 依据服装设定生成

生成方式：文生图。不输入参考图片；修改文字后重新生成仍属于本子情况。

用途：从指定服装状态的资料卡生成独立服装展示；正背重要设计须已确认。先填写完整衣物层次、材质、颜色、鞋履和必要的非头部附件。正背图展示同一套服装，不添加人体。

**填写模板**

```text
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

一幅服装参考图，在纯白背景上以两个独立视图呈现一整套{{服装身份与状态}}。左列为正面，右列为同套服装的背面，展示尺度一致。

衣物独立陈列，没有真人穿着，空置开口与层次结构清晰可辨。画面不包含发冠、发簪、发饰、耳饰等头部配饰。

{{正面领口、系合方式、袖形、内外层、腰部与下摆；用正面视格内部的画面方位及邻近衣物部件定位不对称细节}}。

{{已确认的对应背片、接缝、背面扣合、开衩与下摆结构；只描述背面可见内容，保留对正面专属部件的遮挡}}。

两个视图保持{{准确配色、材质、厚度、纹样与磨损状态}}。

{{鞋履与必要的非头部配饰、对应正背朝向，以及在服装旁边或下方的独立摆放位置}}。

每件衣物与配饰完整可见，整体轮廓周围及视格之间留出白色余量。

柔和均匀的照明呈现{{对应材质的表面与褶皱}}，使浅色衣料与白色背景保持区分。整体为一致、清楚的服装正背面设计。
```

## 2. 已有服装修订

生成方式：图生图。必须实际输入所依据的已有图片，不能只改文字后无图生成。

**填写模板**

```text
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

将图像中同一套服装的{{指定部位或状态}}改为{{已确认修改}}，同时在正面和背面落实对应结构。

保持左列正面、右列背面的一行两列布局，以及{{未改动的款式、层次、颜色、材质、鞋履与必要的非头部配饰}}。

{{分别限定正面或背面视格，再用该视格内的画面方位及邻近部件明确修改位置、接缝与遮挡；依据资料中的固定设计换算可见位置，保持部件归属及前后层次}}。

画面不包含发冠、发簪、发饰、耳饰等头部配饰；输入图中如有此类配饰，将其移除。服装以无人穿着的独立形式完整展示，正背展示尺度一致，附件与完整轮廓留有白色余量，纯白背景及均匀柔光保持。
```
