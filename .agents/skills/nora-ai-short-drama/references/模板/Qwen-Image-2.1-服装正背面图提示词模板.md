# Qwen-Image-2.1-服装正背面图提示词模板

版本：v1.19；更新日期：2026-10-04。

主要确定独立衣装的款式、层次、材质、配色、纹样、正背结构、鞋履及必要的非头部配饰，适配资料卡人物状态和项目画风；不承担人物身份或身材定型。用于独立正背面设计；每次只展示同一套服装，先补齐背面和必要配饰设计。

使用前读取[Qwen提示词规范](../生成规范/Qwen-Image-2.1-提示词规范.md)，按所选大类读取[文生图共用填写与输出格式](Qwen-Image-2.1-文生图提示词模板.md)或[图像编辑共用填写与输出格式](Qwen-Image-2.1-图像编辑提示词模板.md)。尺寸、基础着装、制作依赖以[开发流程第8节](../流程规范/短剧开发流程规范.md#8-核心参考图)为准。只填写当前情况，不把整个文件交给模型。新正文按[统一中文规则](../生成规范/Qwen-Image-2.1-提示词规范.md#14-统一中文编写审阅与提交)填写。

画风占位符遵循[项目画风正文引用](../生成规范/Qwen-Image-2.1-提示词规范.md#16-项目画风正文引用)。

**占位符填写**：遵循[统一填写规则](../生成规范/Qwen-Image-2.1-提示词规范.md#15-模板占位符填写)。

**填写依据**：对应人物资料卡的目标人物状态与服装状态、已确认正背面设计、鞋履附件及项目画风；提取设定时排除头部配饰，不将发冠、发簪、发饰、耳饰等作为生成或保留对象。

- [1. 依据服装设定生成](#1-依据服装设定生成)
- [2. 依据用户提供或指定的服装参考图生成](#2-依据用户提供或指定的服装参考图生成)

同套衣装的状态延伸读取[统一状态规则](../生成规范/Qwen-Image-2.1-提示词规范.md#27-资产状态参考图统一规则)，填写[资产状态模板的服装大类](Qwen-Image-2.1-资产状态参考图提示词模板.md#1-服装状态参考图)。

左右与前后位置先按[方向表达规则](../生成规范/Qwen-Image-2.1-提示词规范.md#21-左右方向与可见位置)换算：先指明左列正面／右列背面，再说该视图内的具体位置，补足靠前或靠侧及邻近部件。背面只写可见结构；位置以该服装的已确认设计为准。


## 1. 依据服装设定生成

生成方式：仅文生图，不输入参考图片。

用途：从指定服装状态的资料卡生成独立服装展示；正背重要设计须已确认。先填写完整衣物层次、材质、颜色、鞋履和必要的非头部附件。正背图展示同一套服装，不添加人体。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
一幅服装参考图，在纯白背景上以两个独立视图呈现一整套{{服装身份与状态}}。左列为正面，右列为同套服装的背面，展示尺度一致。

衣物独立陈列，没有真人穿着，空置开口与层次结构清晰可辨。画面不包含发冠、发簪、发饰、耳饰等头部配饰。

每件衣物与配饰完整可见，整体轮廓周围及视格之间留出白色余量。

柔和均匀的照明呈现{{对应材质的表面与褶皱}}，使浅色衣料与白色背景保持区分。整体为一致、清楚的服装正背面设计。

服装描述：
{{正面领口、系合方式、袖形、内外层、腰部与下摆；用正面视格内部的画面方位及邻近衣物部件定位不对称细节}}。

{{已确认的对应背片、接缝、背面扣合、开衩与下摆结构；只描述背面可见内容，保留对正面专属部件的遮挡}}。

两个视图保持{{准确配色、材质、厚度、纹样与磨损状态}}。

{{鞋履与必要的非头部配饰、对应正背朝向，以及在服装旁边或下方的独立摆放位置}}。
```

## 2. 依据用户提供或指定的服装参考图生成

生成方式：图生图。输入资格读取[图片类型索引](../生成规范/Qwen-Image-2.1-提示词规范.md#11-图片类型专用模板索引)及[输入记录规则](../生成规范/Qwen-Image-2.1-提示词规范.md#24-输入参考图检查与记录复用)。

用途：从用户提供的原参考图或指定的已批准服装图提取本次采用的衣装设计，结合已确认正背结构生成独立正背面展示；参考图中的人体不承担人物定型用途。

填写说明：单图用“图像”，多图逐张使用真实顺序的 `<image1>`、`<image2>` 等标签。填写各图的参考范围及本次变化，未改变部分总括保留；不把头部配饰写入采用范围。输出使用编辑三字段JSON，`wh_ratio` 取服装规格，`ratio_follow` 为空。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
依据{{实际输入图指代及逐张参考用途}}，生成同一套{{服装身份与目标状态}}的独立正背面参考图。
在纯白背景上，一行两列，左列正面、右列背面，两侧展示尺度一致。衣物空置独立陈列，没有真人身体，不展示头部配饰。
完整容纳衣装、鞋履及必要的非头部配饰，各视格四周与视格之间保留白色余量。照明柔和均匀，衣物轮廓和层次清楚。

服装描述：
从{{输入图指代}}采用{{本次指定的款式、层次、材质、配色或纹样范围}}；保留{{不在变化范围内的衣装设计与识别特征}}。
将{{需要改变的部位}}呈现为{{本轮完整目标设计，包含位置、数量、形状及与邻近部件的关系}}。
左列正面显示{{本次需明确的正面可见结构与细节}}；右列背面显示{{有确认依据的背片、接缝、扣合及下摆结构}}，按各自朝向保持真实遮挡。
{{需要补足的已确认鞋履与非头部配饰，以及独立摆放位置}}。
两个视图保持同套衣装的材质、配色和目标状态一致；参考图中的人体、原背景及额外标签不进入展示。
```
