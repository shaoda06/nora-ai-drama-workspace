# 人物参考图审阅记录模板

使用前读取[人物参考图初审与记录规范](../素材规范/人物参考图初审与记录规范.md)的第2、4节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

按两阶段分工填写通用及对应类型检查；技术审查通过及内容审查完成均不等于用户批准。 技术不通过时所有内容字段填“未进行（技术审查未通过）”；技术通过后完整填写内容发现。页面依次显示技术审查、内容审查、用户审核三个标签；已完成内容检查显示“有内容问题／无内容问题”，未进行或待审查不得显示无问题。展示按[开发流程8.5.1](../流程规范/短剧开发流程规范.md#851-图片有限返修与集中送审)。下方围栏内是产出正文，填写时使用产出标题，不将本模板文件名作为项目产出名。

文件入口遵循[浏览入口通用文本与链接规则](../流程规范/项目浏览入口规范.md#通用文本与链接)。本记录位于 `03-人物资料/其他资料/审阅记录/`，候选示例为 `[候选v01](../过程稿/CH001-状态-人物多视角参考图-草稿-v01.png)`，对应生成记录示例为 `[生成记录001](../../CH001-人物名/参考图/生成记录.md#生成记录-001)`。填写时替换为真实文件与章节；不要照搬生成记录中的相对路径，因为两份文档所在目录不同。

输入参考按[输入参考图检查与记录复用](../生成规范/Qwen-Image-2.1-提示词规范.md#24-输入参考图检查与记录复用)处理。“已实际查看”项如实列出本次查看的输出及必要局部；输入未重新查看时，在该项注明“输入参考复用已有记录”及版本、记录入口，不写为已查看。

```markdown
# {正式图片名去扩展名}-审阅记录-001

## 1. 审阅对象
- 图片类型：
- 人物状态、服装状态：
- 本轮候选文件及版本：
- 对应生成记录：
- 审阅依据：

## 2. 检查结果

### 2.1 技术审查（阻塞）
- 已实际查看的整图、输入参考及必要局部：
- 技术规格：
- 文件完整性、数量及来源／请求核对证据：
- 画面异常（纹理、损坏、异常重叠、严重变形、重复头部／多余肢体、融合或断裂）：
- 六视图逐格朝向及同列上下共同可见内容一致性（人物／角色六视图适用，逐列记录；只查内部一致，不在此核对设计符合度）：
- agent 技术审查结论：通过／不通过／待确认
- 技术问题位置与依据：
- 本轮已用次数及剩余技术重试额度：

### 2.2 内容审查（非阻塞）
- agent 内容审查状态：已完成；有内容问题／已完成；无内容问题／未进行／待审查
- 未进行原因：技术审查未通过，未进行内容审查（技术通过时填不适用）
- 资料依据：
- 人物身份与身体比例：
- 视图与排布（六视图朝向问题已归技术项）：
- 服装、鞋履及配饰：
- 白色背景、光照与取景完整性：
- 与输入参考及其他视图的一致性（六视图同列上下内部一致性已归技术项）：
- 可见缺陷、清晰度与未经允许的附加内容：
- 对应类型专项检查（逐项记录第2节适用项目）：
- 不适用项目及说明：
- agent 内容审查发现：逐项列明符合／有偏差／待确认／不适用及依据；偏差不阻塞送审、不自动返修

## 3. 问题与修改要求
- 问题分类：技术阻塞／内容发现（仅辅助用户决定）
- 自动重试依据及处理：仅技术不通过且剩余额度内；其他情况不适用
- 本次展示结果：技术通过附1张当前图；3次技术失败附全部3张及逐张原因
- 图片及原图入口：使用真实候选；对话媒体使用绝对路径，记录内使用可解析的相对链接
- 各次生成、技术结果及原因：失败3次时逐张填写；不足3张说明实际阻碍
- 历史失败版本及记录入口：
- 问题所在位置：
- 具体偏差与依据：
- 需要修改的内容：
- 必须保留的内容：

## 4. 用户确认
- 结论：待确认／批准采用／修改后再审／不采用
- 批准的具体候选：
- 确认范围：
- 确认时间与依据：

## 5. 采用与后续影响
- 正式保存位置：
- 被替换版本及归档入口：
- 需要检查的下游资产：
- 后续处理：
```
