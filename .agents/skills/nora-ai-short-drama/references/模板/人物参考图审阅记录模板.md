# 人物参考图审阅记录模板

使用前读取[人物参考图初审与记录规范](../素材规范/人物参考图初审与记录规范.md)的第2、4节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

按[图片交付与用户审核](../流程规范/短剧开发流程规范.md#851-图片交付与用户审核)记录文件核对、实际展示及用户决定。默认禁止调用看图能力；仅按[看图能力调用边界](../../SKILL.md#看图能力调用边界)明确获准时分析指定问题。未查看不写通过或无问题，用户未反馈的细节不补填。

文件入口遵循[浏览入口通用文本与链接规则](../流程规范/项目浏览入口规范.md#通用文本与链接)。本记录位于 `03-人物资料/其他资料/审阅记录/`，候选示例为 `[候选v01](../过程稿/CH001-状态-人物多视角参考图-草稿-v01.png)`，对应生成记录示例为 `[生成记录001](../../CH001-人物名/参考图/生成记录.md#生成记录-001)`。填写时替换为真实文件与章节；不要照搬生成记录中的相对路径，因为两份文档所在目录不同。

```markdown
# {正式图片名去扩展名}-审阅记录-001

## 1. 审阅对象
- 图片类型：
- 人物状态、服装状态：
- 本轮候选文件及版本：
- 对应生成记录：
- 审阅依据：

## 2. 文件与记录核对

- 文件核对结论：通过／异常／待核对
- 实际尺寸、格式、数量及可解码性：
- 文件完整性、来源版本与请求核对证据：
- 图片身份、用途及适用状态的记录依据：
- 看图调用状态：未调用（默认）／已按授权查看
- 看图授权及限定范围：未调用时填不适用；调用时注明用户要求或明确规范条款及具体图片、问题
- 授权查看的发现：未调用时填不适用；不扩展为固定视觉审查

## 3. 展示与用户反馈

- 本次展示候选及原图入口：实际文件与具体版本
- 文件或记录异常及处理：
- 用户反馈的问题、位置与依据：尚无反馈则如实填写
- 用户要求的修改及保留范围：
- 修改／重试授权与次数：无则不追加生成
- 关联的上一轮候选及记录入口：

## 4. 用户确认
- 结论：待确认／批准采用／修改后再审／不采用
- 批准的具体候选：
- 确认范围：
- 确认时间与依据：

## 5. 采用与后续影响
- 批准后超分状态与关联：肖像记录原1024批准版本、超分编号、输入／输出及执行记录入口；其他类型不适用
- 超分文件核对与交付：2048×2048 PNG，数量、解码及来源结果；未完成不填已保存
- 正式保存位置：
- 被替换版本及归档入口：
- 需要检查的下游资产：
- 后续处理：
```
