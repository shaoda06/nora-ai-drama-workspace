# 工作稿模板

用于各阶段的文档、方案及跨对象集中讨论。保存、命名、版本及素材规则只在[工作稿管理规则](../共用规则/文件版本与工作稿规范.md#工作稿管理规则)维护。图片和分段视频使用对应工作稿模板的专项字段；场次及整集制作在本模板的制作区补充实际执行事实，审阅区填写[视频人工审阅区模板](视频人工审阅区模板.md)。

下方是工作稿正文；当前稿版本先按[文档版本编号](../共用规则/文件版本与工作稿规范.md#文档版本编号)核对项目约定，v01不覆盖用户指定的版本体系。草稿内容按对应正式文档模板编写，嵌入当前内容区，不另生成逐版本草稿文件。

本集剧本、场次分镜草稿嵌入“## 1. 当前内容”时，正式正文各级标题统一加两个`#`，不能把父章和子章写成同一级。例如正式剧本的`# EP003-本集剧本`、`## 1. 故事剧本正文`、`### EP003-C001`，在工作稿中分别写为`### EP003-本集剧本`、`#### 1. 故事剧本正文`、`##### EP003-C001`；同步正式文件时恢复模板层级。分镜索引的表头及完整行按[场次内视频分段与本集索引](../../../short-drama-storyboard/references/视频分段规划规范.md#4-场次内视频分段与本集索引)填写；网页读取格式与同步检查见[项目浏览入口规范](../流程规范/项目浏览入口规范.md)。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../共用规则/文件版本与工作稿规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 1. 当前内容 | 编写或修订时放当前草稿；按对象适用的批准或自检条件同步后，只留正式文件与具体版本入口。 |
| 2. 讨论与修改 | 按表记录提出问题的时间或依据、备选方案、取舍和待定事项。 |
| 3. 审阅区 | 按审阅编号重复记录具体对象、展示版本、反馈、用户决定及后续影响。 |
| 4. 制作与变更记录 | 按表保存实际制作、执行附件、输出、位置变化及影响；不覆盖旧任务事实。 |
| 其他补充（按需启用） | 固定放在上述正文之后；只写已有章节无法容纳的事项，采用下方三项条目，不记录修改流水。 |

```markdown
# {对象名}-工作稿

- 当前稿版本：v01
- 最近更新：
- 当前状态及待办：
- 正式文件入口：尚未形成时如实填写

## 1. 当前内容

待审时填写当前草稿或方案，按正式模板调整标题层级并保留业务字段。需要用户批准的文档在批准并同步后，此处只保留正式文件及具体版本入口；再次修订注明所基于的正式版本、新草稿版本与待审范围，批准前不覆盖原正式正文。提示词与生成说明按其自检及执行授权要求同步当前准备正文，用户明确要求先审时才等待，不伪造批准或覆盖已冻结执行输入。完整接替规则读取模板上方的工作稿管理入口。制作结果仍按适用专项模板维护。
```
