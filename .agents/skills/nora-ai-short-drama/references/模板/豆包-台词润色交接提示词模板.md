# 豆包-台词润色交接提示词模板

由Codex填写真实的本机绝对路径，替换全部占位内容；人物卡按相关人物逐行列出，剧情资料列出本集分集大纲及必要的前集剧本、后续大纲，不适用的条目删去。输出位置按上述规范填写，给用户完整可复制正文。

```text
三、保存结果

```
