# Qwen-Image-2.1-首帧参考图提示词模板

版本：v1.7；更新日期：2026-09-29。

按[首帧规范](../素材规范/首帧参考图规范.md)选择已批准素材；每场必备一张首帧图，只生成场次首个分段首镜开始时刻的单张画面；后续分段默认不制作首帧，用户明确要求时再讨论例外。参考图的六视图布局或白底不进入剧情画面；同一人物多视角不能变成多个角色。首帧不是必须全身入镜，取景服从首镜。输入槽位和人数按实际需要，不机械凑足角色、场景与道具。

使用前读取[Qwen提示词规范](../生成规范/Qwen-Image-2.1-提示词规范.md)，按本节固定生成方式读取[文生图共用填写与输出格式](Qwen-Image-2.1-文生图提示词模板.md)或[图像编辑共用填写与输出格式](Qwen-Image-2.1-图像编辑提示词模板.md)。尺寸、基础着装、制作依赖以[开发流程第8节](../流程规范/短剧开发流程规范.md#8-核心参考图)为准。只填写当前情况，不把整个文件交给模型。

**占位符填写：** 所有 `{{…}}` 按[占位符填写规则](../生成规范/Qwen-Image-2.1-提示词规范.md#15-模板占位符填写)逐项处理，不能原样提交。本模板的填写依据为本段首镜开始时刻的分镜、对应人物／场景／道具资料和实际输入素材；图像标签按真实输入顺序填写，不把后续动作写成首帧状态。

- [1. 单参考生成或修订](#1-单参考生成或修订)
- [2. 多参考合成](#2-多参考合成)


## 1. 单参考生成或修订

生成方式：图生图。实际输入1张参考图。

**填写模板**

```text
以图像为{{明确的身份、环境或既有首帧构图依据}}，生成{{已确认画风}}的单张{{景别}}镜头画面。{{说明该参考是保留构图的底图，还是仅提供身份或空间依据}}。

机位在{{位置、高度、朝向}}，画面中{{真实人数及各人物身份、服装、站位、朝向和视线}}。

环境保持{{已确认布局、时间、天气和光照}}，{{关键道具的结构、状态与持有关系}}。

此刻{{动作刚开始时的静态姿态}}，{{前后景、遮挡和取景边缘}}。

完整表达这个开始时刻，保留参考承担的识别信息，并呈现单一连续剧情画面。
```

## 2. 多参考合成

生成方式：图生图。实际输入2张或以上参考图，并逐图明确用途。

**填写模板**

```text
将这些参考合成为{{已确认画风}}的一张{{景别}}镜头画面。

<image1>提供{{该图的明确主体、身份或空间用途及保留内容}}，<image2>提供{{该图的明确用途及保留内容}}。{{按实际顺序逐张追加其余输入标签和用途；只有两张时删除本句}}。

{{明确有无构图底图，以及哪个输入控制构图；没有底图时按下述新镜头组织}}。

机位在{{位置、高度及朝向}}，{{实际人物数量、逐人对应的身份来源、服装状态、站位、朝向和视线}}。

{{场景布局、时间天气和光照}}。

{{道具来源、摆放或持有关系及当前状态}}。

画面停留在{{首镜动作开始状态}}，{{景深、前后景遮挡及取景边缘}}。

各参考中的同一主体只在剧情要求的位置出现，以一致的比例、透视和光照融入单张连续环境画面。
```
