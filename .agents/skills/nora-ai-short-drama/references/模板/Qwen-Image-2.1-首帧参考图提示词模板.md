# Qwen-Image-2.1-首帧参考图提示词模板

版本：v1.16；更新日期：2026-10-02。

按[首帧规范](../素材规范/首帧参考图规范.md)选择已批准素材；制作时机、复用及分段用途执行该规范第1节。参考图的六视图布局或白底不进入剧情画面；同一人物多视角不能变成多个角色。首帧不是必须全身入镜，取景服从首镜。输入槽位和人数按实际需要，不机械凑足角色、场景与道具。

使用前读取[Qwen提示词规范](../生成规范/Qwen-Image-2.1-提示词规范.md)，按本节固定图生图方式读取[图像编辑共用填写与输出格式](Qwen-Image-2.1-图像编辑提示词模板.md)。首帧尺寸按首帧规范第1节；输入资产的基础着装与制作依赖按[开发流程第8节](../流程规范/短剧开发流程规范.md#8-核心参考图)。只填写当前情况，不把整个文件交给模型。

画风占位符遵循[项目画风正文引用](../生成规范/Qwen-Image-2.1-提示词规范.md#16-项目画风正文引用)。

**占位符填写**：遵循[统一填写规则](../生成规范/Qwen-Image-2.1-提示词规范.md#15-模板占位符填写)。

**填写依据**：本段首镜开始时刻的分镜、对应人物／场景／道具资料和实际输入素材；图像标签按真实输入顺序填写，不把后续动作写成首帧状态。机位、站位、朝向与光源按[统一方向参照](../生成规范/镜头语言参考指南.md#13-统一方向参照)换算为本镜头的画面关系，不直接搬入资料中的东南西北。

无人物镜头的“人物描述”填写无人及实际需要的主体状态、道具关系，不为填写板块添加人物。

- [1. 单参考生成](#1-单参考生成)
- [2. 多参考合成](#2-多参考合成)


## 1. 单参考生成

生成方式：图生图。实际输入1张符合首帧专项要求的环境源素材。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
以图像为{{明确的环境及空间依据}}，生成单张{{景别}}镜头画面。

机位在{{位置、高度、朝向}}。

环境保持{{已确认布局、时间、天气和光照}}。

{{前后景、遮挡和取景边缘}}。

完整表达这个开始时刻，保留参考承担的识别信息，并呈现单一连续剧情画面。

人物描述：
画面中{{真实人数及各人物身份、服装、站位、朝向和视线}}。

{{关键道具的结构、状态与持有关系}}。

此刻{{动作刚开始时的静态姿态}}。
```

## 2. 多参考合成

生成方式：图生图。实际输入2张或以上环境、人物或道具源素材，并逐图明确用途。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
将这些参考合成为一张{{景别}}镜头画面。

<image1>提供{{该图的明确主体、身份或空间用途及保留内容}}，<image2>提供{{该图的明确用途及保留内容}}。{{按实际顺序逐张追加其余输入标签和用途；只有两张时删除本句}}。

{{明确源素材中的空间布局如何用于本镜头构图}}。

机位在{{位置、高度及朝向}}。

{{场景布局、时间天气和光照}}。

{{景深、前后景遮挡及取景边缘}}。

各参考中的同一主体只在剧情要求的位置出现，以一致的比例、透视和光照融入单张连续环境画面。

人物描述：
{{实际人物数量、逐人对应的身份来源、服装状态、站位、朝向和视线}}。

{{道具来源、摆放或持有关系及当前状态}}。

画面停留在{{首镜动作开始状态}}。
```
