# 项目进度模板

使用前读取[会话与进度管理规范](../流程规范/会话与进度管理规范.md)的第4节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

建立或维护项目根目录的项目进度；当前行更新及历史说明读取[会话规范第4节](../流程规范/会话与进度管理规范.md#4-项目进度文件)，不把初始化示例当作已有项目事实。 下方围栏内是产出正文，填写时使用产出标题，不将本模板文件名作为项目产出名。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../流程规范/短剧开发流程规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 项目与主控入口 | 填写项目实际名称及唯一主控会话入口。 |
| 阶段进度表 | 按既定六列表维护阶段当前状态、成果、待决与下一步；新增已安排阶段用表内行，不往表后追加完成流水。 |
| 其他补充（按需启用） | 固定放在上述正文之后；只写已有章节无法容纳的事项，采用下方三项条目，不记录修改流水。 |

```markdown
# 项目进度

- 项目名称或代号：待确认
- 主控会话入口：待补充

| 阶段名称 | 对应会话入口 | 当前状态 | 成果入口 | 待决事项 | 下一步 |
| --- | --- | --- | --- | --- | --- |
| 项目基本定位 | 待补充 | 进行中 | 尚未生成 | 无 | 完成项目基本定位 |
| 主旨与简介 | 尚未创建 | 未开始 | 尚未生成 | 无 | 定位阶段完成后开始 |
| 故事大纲 | 尚未创建 | 未开始 | 尚未生成 | 无 | 简介阶段完成后开始 |
| 人物资料卡 | 尚未创建 | 未开始 | 尚未生成 | 无 | 全局大纲阶段完成后开始 |
| 道具资料卡 | 尚未创建 | 未开始 | 尚未生成 | 无 | 依据大纲和相关人物设计建卡 |
| 场景资料卡 | 尚未创建 | 未开始 | 尚未生成 | 无 | 已明确地点先建基础设计，场次明确后补充 |
| 分集大纲 | 尚未创建 | 未开始 | 尚未生成 | 无 | 依据大纲及已确认设定完成全剧分集 |
| 人物参考图 | 尚未创建 | 未开始 | 尚未生成 | 无 | 对应人物卡和画风确认且获授权后制作 |
| 道具参考图 | 尚未创建 | 未开始 | 尚未生成 | 无 | 对应道具卡和画风确认且获授权后制作 |
| 场景参考图 | 尚未创建 | 未开始 | 尚未生成 | 无 | 对应场景设计及场次取景需求确认且获授权后制作 |

## 其他补充

无。确有未被以上章节覆盖的事项时，按以下三项逐条填写；填写后删除本提示。

- 事项：<简短名称>
- 内容与适用范围：<当前需要补充的事实、说明及所指对象>
- 依据与当前状态：<实际来源入口；已确定／待确认／待落实，以及尚需处理的内容>

```
