# 项目进度模板

使用前读取[会话与进度管理规范](../流程规范/会话与进度管理规范.md)的第4节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

建立或维护项目根目录的项目进度；填写真实状态，不把初始化示例当作已有项目事实。 下方围栏内是产出正文，填写时使用产出标题，不将本模板文件名作为项目产出名。

```markdown
# 项目进度

- 项目名称或代号：待确认
- 主控会话入口：待补充

| 阶段名称 | 对应会话入口 | 当前状态 | 成果入口 | 待决事项 | 下一步 |
| --- | --- | --- | --- | --- | --- |
| 项目基本定位 | 待补充 | 进行中 | 尚未生成 | 无 | 完成项目基本定位 |
| 主旨与简介 | 尚未创建 | 未开始 | 尚未生成 | 无 | 定位阶段完成后开始 |
| 故事大纲 | 尚未创建 | 未开始 | 尚未生成 | 无 | 简介阶段完成后开始 |
| 人物资料卡 | 尚未创建 | 未开始 | 尚未生成 | 无 | 全局大纲阶段完成后开始 |
| 关键道具资料卡 | 尚未创建 | 未开始 | 尚未生成 | 无 | 人物资料卡阶段完成后开始 |
| 分集大纲 | 尚未创建 | 未开始 | 尚未生成 | 无 | 关键道具资料卡阶段完成后开始 |
| 核心参考图 | 尚未创建 | 未开始 | 尚未生成 | 无 | 分集大纲阶段完成后开始 |
```
