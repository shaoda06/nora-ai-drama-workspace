# 项目进度模板

使用前读取[会话与进度管理规范](../流程规范/会话与进度管理规范.md)的第4节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

建立或维护项目根目录的项目进度；当前行更新及历史说明读取[会话规范第4节](../流程规范/会话与进度管理规范.md#4-项目进度文件)，不把初始化示例当作已有项目事实。 下方围栏内是产出正文，填写时使用产出标题，不将本模板文件名作为项目产出名。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../共用规则/文件版本与工作稿规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 项目与主控入口 | 填写项目实际名称及唯一主控会话入口。 |
| 阶段进度表 | 按既定六列表维护阶段当前状态、成果、待决与下一步；待决与下一步的单元格按事项分条；新增已安排阶段用表内行，不往表后追加完成流水。 |
| 其他补充（按需启用） | 固定放在上述正文之后；只写已有章节无法容纳的事项，采用下方三项条目，不记录修改流水。 |

当前事项及完成边界统一按[会话规范第4节](../流程规范/会话与进度管理规范.md#4-项目进度文件)填写；未开始行不预填未来步骤。两栏的可填格式：`- 第一项<br>- 第二项`；无事项填 `- 无`。具体引用写在条目内，例如 `- 核对[画风正文v11](实际相对路径#章节锚点)`，填写时替换为项目实际入口。

封面、片头、片尾的选择和实际制作行执行[可选配套的会话与进度接续](../流程规范/会话与进度管理规范.md#可选配套的会话与进度接续)。有实际安排时在下方既有六列表内增加对应行，未选用或尚未安排时不预建；不得因这些可选行缺失判定正片制作未完成。

## 其他补充

无。确有未被以上章节覆盖的事项时，按以下三项逐条填写；填写后删除本提示。

- 事项：<简短名称>
- 内容与适用范围：<当前需要补充的事实、说明及所指对象>
