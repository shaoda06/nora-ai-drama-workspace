# 场次修改轮次模板

填写、时机与历史接入执行[场次修改轮次](../共用规则/场次版本组合规范.md#场次修改轮次)，工具调用见[登记工具](../comfyui-scripts/README.md#场次修改轮次登记)。本模板是交给工具的完整组合计划，不是单次任务的选中范围；沿用分段也须列出，数组顺序就是本轮播放顺序。替换示例为实际项目内相对路径、版本及身份。

```json
{
  "note": "本轮修改范围或首次接入依据",
  "script": {"file": "09-剧集制作/EP003/02-剧集剧本/EP003-本集剧本.md", "version": "v21"},
  "storyboard": {"file": "09-剧集制作/EP003/03-分镜脚本/EP003-C001-场次分镜.md", "version": "v26"},
  "segments": [
    {"id": "P001", "duration": 7.2, "stage": "一采", "run": "R012"},
    {"id": "P002", "duration": 8.2, "stage": "一采", "run": "R011"}
  ]
}
```

工具生成的组合文件头为`episode`、`scene`和`rounds`数组；各轮保存上述内容及自动递增的`number`和带时区`created_at`，文档路径指向保留副本。时长单位为秒，阶段为一采／二采／后处理，R从R001开始。复用旧R只在本轮列表中引用，不修改旧R审阅记录；轮次不另设确认状态或采用决定。

局部修改改用下列计划；`base_round`为明确选定的原组合编号，`segment_changes`中的每项填写完整P／时长／阶段／R。未改项和未提供的文档引用沿用基轮。不要同时填写`segments`，不从执行映射或候选排序补齐。新布局仍使用上方完整计划。

```json
{
  "note": "仅P007返修，其余明确沿用第10轮",
  "base_round": 10,
  "script": {"file": "09-剧集制作/EP003/02-剧集剧本/EP003-本集剧本.md", "version": "v18"},
  "storyboard": {"file": "09-剧集制作/EP003/03-分镜脚本/EP003-C001-场次分镜.md", "version": "v22"},
  "segment_changes": [
    {"id": "P007", "duration": 6.5, "stage": "一采", "run": "R010"}
  ]
}
```

工具保存展开后的完整组合、`base_round`及`changed_segments`，不复制或改写原分段资料。新任务输入映射填写本工具返回的轮次整数；其中`selected_indices`及`segments`描述实际执行范围与时间线，填写边界见[场次修改轮次](../共用规则/场次版本组合规范.md#场次修改轮次)。

获授权补记历史组合时，另存`historical_at`为证据所载的带时区方案时间，`created_at`仍为实际补记时间，`basis`指向原始依据文件；有多份依据时用`evidence`数组列出路径。不把补记时间伪装成当年的登记时间。跨阶段编号和接入占位轮次的整理执行[场次修改轮次](../共用规则/场次版本组合规范.md#场次修改轮次)，不由本模板推算或自动迁移。
