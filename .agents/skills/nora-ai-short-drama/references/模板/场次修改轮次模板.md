# 修改轮次模板

业务规则见[修改轮次](../共用规则/场次版本组合规范.md#场次修改轮次)，调用方法见[登记工具](../comfyui-scripts/README.md#场次修改轮次登记)。一份计划对应一次批次，`scenes`只列改动场次，由工具展开其余沿用场次；没有既有组合的场次须给完整方案。路径相对项目根，时长为秒，阶段为一采／二采／后处理，R按原身份独立计数。

## 完整场次方案

```json
{
  "note": "本批修改C001和C002",
  "script": {"file": "09-剧集制作/EP003/02-剧集剧本/EP003-本集剧本.md", "version": "v05"},
  "scenes": {
    "C001": {
      "storyboard": {"file": "09-剧集制作/EP003/03-分镜脚本/EP003-C001-场次分镜.md", "version": "v04"},
      "segments": [
        {"id": "P001", "duration": 14, "stage": "一采", "run": "R004"},
        {"id": "P002", "duration": 11, "stage": "一采", "run": "R003"}
      ]
    },
    "C002": {
      "storyboard": {"file": "09-剧集制作/EP003/03-分镜脚本/EP003-C002-场次分镜.md", "version": "v06"},
      "segments": [
        {"id": "P001", "duration": 9, "stage": "一采", "run": "R004"}
      ]
    }
  }
}
```

示例只演示结构，实际`segments`须覆盖该场本轮全部P，数组顺序即播放顺序。同轮只有一个共同`script`。未改场次沿用上一已登记轮，首次接旧记录时取该场最新完整记录，不从候选排序补齐。

## 局部替换方案

```json
{
  "note": "只改C002的P003，其余沿用第8轮",
  "base_round": 8,
  "scenes": {
    "C002": {
      "storyboard": {"file": "09-剧集制作/EP003/03-分镜脚本/EP003-C002-场次分镜.md", "version": "v07"},
      "segment_changes": [
        {"id": "P003", "duration": 10, "stage": "一采", "run": "R004"}
      ]
    }
  }
}
```

顶层`base_round`是单集基轮。场次内`segments`与`segment_changes`互斥；未提供的剧本、未改场次及P沿用基轮。首次从旧场次记录局部接入，在该场条目填原`base_round`，不在顶层冒充旧记录已是单集轮次。

保存文件为`EP编号-修改轮次.json`，头部为`episode`、`rounds`。每轮含`number`、带时区`created_at`、`note`、共同`script`、完整有序`scenes`及`changed_scenes`；各场保存分镜、完整分段和适用的`changed_segments`，文档引用指向留存副本。旧场次文件、原R审阅与任务记录不改。

本批任务均填写工具返回的同一`scene_modification_round`整数，任务各自的`scene`、实际选中范围和请求时长保持原含义；任务映射不是播放组合。
