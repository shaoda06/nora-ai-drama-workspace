# Qwen-Image-2.1-场景参考图提示词模板

版本：v1.25；更新日期：2026-10-19。

每次输出单张连续场景画面。先按[场景图用途原则](../../../nora-drama-assets/references/场景资料与参考图规范.md#40-图片用途与状态归属)确定总览／基础图或机位图用途及可见范围；以下空间短语按真实画面选择，不机械填满每个方位或将整套结构塞入同框。总览按基础设计填写；机位图按分镜归纳出的目标视角及适用条件填写时间、天气、照明与取景，不写人物表演或后续动作结果。

使用前读取[Qwen提示词规范](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md)，按所选分支读取[文生图共用填写与输出格式](Qwen-Image-2.1-文生图提示词模板.md)或[图像编辑共用填写与输出格式](Qwen-Image-2.1-图像编辑提示词模板.md)。尺寸、制作依赖读取[场景规格](../../../nora-drama-assets/references/场景资料与参考图规范.md#41-画面要求)及其生成分支。只填写当前情况，不把整个文件交给模型。新正文按[统一中文规则](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#14-统一中文编写审阅与提交)填写。

画风占位符遵循[项目画风正文引用](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#16-项目画风正文引用)。

**占位符填写**：遵循[统一填写规则](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#15-模板占位符填写)。

**固定填写结构**：各大类均保留三个板块；逐项填写机位位置、观察方向与目标、高度、俯仰角度、景别、取景边界、自然遮挡，以及关键前中后景、结构关系、材质、环境状态和光源。图生图另逐张填写参考用途与保留／变化范围；文生图无图片输入。填写结构固定，具体取值依据视图方案，不统一所有视图的机位和构图；没有的空间层次或遮挡如实写无，不为填满字段添加物体。

**填写依据**：对应场景资料卡、本图用途与适用环境状态、机位与可见范围，以及项目画风；不为填满方位编造空间。机位、布局及光源按[统一方向参照](../../../camera-language/references/镜头语言参考指南.md#13-统一方向参照)转换为本图的画面位置与纵深关系。

环境、配套用品与生活痕迹先按[场景规范第3.1节](../../../nora-drama-assets/references/场景资料与参考图规范.md#31-环境与配套细节设计)落实到场景资料卡，再将本机位可见的细节写入下方“场景描述”；不只列主体名称让模型自行补全。

- [1. 依据场景资料卡及场次需求生成](#1-依据场景资料卡及场次需求生成)
- [2. 依据输入参考图及场次需求生成](#2-依据输入参考图及场次需求生成)
- [3. 依据用户提供的场景参考图生成](#3-依据用户提供的场景参考图生成)

已有环境的昼夜、天气等状态延伸读取[统一状态规则](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#27-资产状态参考图统一规则)，填写[资产状态模板的场景大类](Qwen-Image-2.1-资产状态参考图提示词模板.md#2-场景状态参考图)。


## 1. 依据场景资料卡及场次需求生成

生成方式：仅文生图，不输入参考图片。

用途：按资料卡中已确认的总览或机位方案生成环境图；视图规划、复用与补图执行[场景规范第4.2节](../../../nora-drama-assets/references/场景资料与参考图规范.md#42-视图规划与复用)。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
生成{{场景身份、室内／室外及目标区域}}在{{时间、天气与活动状态}}下的一幅{{景别}}环境画面。

观察机位位于{{以固定物件定位的已确认位置}}，从{{观察起点}}看向{{观察方向与目标}}。机位高度为{{高度或明确的视线高度}}，采用{{平视／俯拍／仰拍及必要倾角}}。

取景范围为{{画面边界及必须包含的区域}}。{{本视图真实的建筑围合、自然遮挡与画外区域；无重要遮挡时如实描述}}。整体为单张连续环境画面。

场景描述：
前景：{{关键近处结构与关系；无则写无}}。
中景：{{主要功能区域、固定陈设及相互位置}}。
背景：{{远处结构、空间边界及纵深关系}}。
{{本视图必须保持的结构、数量、尺度及通道连接，换算为画面方位；不将全部建筑塞入同框}}。

{{本机位可见的环境背景、配套用品与生活细节，写明位置、数量尺度及摆放关系；不适用时省略}}。
{{已确认的材质、颜色、磨损、使用痕迹及整洁或杂乱状态}}。
来自{{实际光源及其在本机位下的方向}}的光线形成{{符合时间天气的照明与阴影}}。
{{本次允许的环境变化；无变化时明确保持所述状态}}。
{{仅当本场状态需要时，加入已确认的可见人物或道具}}。
```

## 2. 依据输入参考图及场次需求生成

生成方式：图生图。输入资格及分支选择读取[场景生成规则](../../../nora-drama-assets/references/场景资料与参考图规范.md#411-生成方式与参考输入)。

用途：以已批准总览、结构图或其他机位环境图为实际输入，生成所需总览或目标机位环境图；保留固定设计，按目标方向重新呈现透视与遮挡，不照搬源图构图。用户自备图任务读取[场景规范第4.1.2节](../../../nora-drama-assets/references/场景资料与参考图规范.md#412-用户自备图的图生图制作与采用)，填写本文件第3大类；状态延伸填写资产状态模板。目标为单张连续场景环境画面。

填写说明：逐张填写输入的采用范围，以及目标机位、关键关系和本场变化；不重复抄写整张图的细节。单图用“图像”，多图按实际顺序使用 `<image1>`、`<image2>` 等标签。仅填写实际提供的输入；填写后的正文保留以下三个板块。

输出格式：采用图像编辑三字段JSON，`wh_ratio` 为目标宽高的最简比例，`ratio_follow` 为空字符串；送审画布按[场景规格](../../../nora-drama-assets/references/场景资料与参考图规范.md#41-画面要求)设置，不跟随输入参考图的比例。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

{{逐张说明从输入图采用的布局、陈设、材质或外观范围，以及为符合项目美术实现、目标布局与取景允许调整的内容}}。
{{输入包含结构图时：将其空间关系呈现为实际环境，成图不保留线稿、标注、图例、示意视角或剖顶低墙}}。

观察机位位于{{以固定物件定位的已确认位置}}，从{{观察起点}}看向{{观察方向与目标}}。机位高度为{{高度或明确的视线高度}}，采用{{平视／俯拍／仰拍及必要倾角}}。

取景范围为{{画面边界及必须包含的区域}}。{{本视图真实的建筑围合、自然遮挡与画外区域；无重要遮挡时如实描述}}。整体为单张连续环境画面。

场景描述：
前景：{{关键近处结构与关系；无则写无}}。
中景：{{主要功能区域、固定陈设及相互位置}}。
背景：{{远处结构、空间边界及纵深关系}}。
{{本视图必须保持的结构、数量、尺度及通道连接，换算为画面方位；不将全部建筑塞入同框}}。

{{本机位可见的环境背景、配套用品与生活细节，写明位置、数量尺度及摆放关系；不适用时省略}}。
{{已确认的材质、颜色、磨损、使用痕迹及整洁或杂乱状态}}。
来自{{实际光源及其在本机位下的方向}}的光线形成{{符合时间天气的照明与阴影}}。
{{本次允许的环境变化；无变化时明确保持所述状态}}。
{{仅当本场状态需要时，加入已确认的可见人物或道具}}。
```


## 3. 依据用户提供的场景参考图生成

生成方式：图生图。输入用途、制作与采用读取[场景规范第4.1.2节](../../../nora-drama-assets/references/场景资料与参考图规范.md#412-用户自备图的图生图制作与采用)。

用途：从用户提供并指定的原图采用本次场景设计范围，结合已确认场景卡和视图方案生成连续环境画面。各输入的布局、陈设、材质或外观用途分别填写。

填写说明：单图用“图像”，多图按真实顺序逐张使用标签；明确哪些内容保留、哪些按本项目调整。未改变区域总括保留，变化区域写足目标关系。输出使用编辑三字段JSON，`wh_ratio` 取场景规格，`ratio_follow` 为空。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
依据{{实际输入图指代及逐张参考用途}}，生成{{场景身份、室内／室外及目标区域}}在{{本次时间、天气与活动状态}}下的一幅{{景别}}连续环境画面。
从{{输入图指代}}采用{{已明确的空间、陈设、材质或外观范围}}，保留{{不在变化范围内的结构与识别特征}}。
机位位于{{以固定物件定位的位置}}，从{{观察起点}}看向{{观察方向与目标}}，高度为{{已确认高度}}，采用{{平视／俯拍／仰拍及必要倾角}}。
取景覆盖{{必须包含的区域及画面边界}}，{{自然遮挡、建筑围合和允许画外的区域}}；保持单张连续画面及合理环境余量。

场景描述：
将{{需要调整的区域或物件}}呈现为{{本轮完整目标关系，包含位置、数量、连接、间隔及接触状态}}。
前景：{{本机位关键近处结构与关系；无则写无}}。
中景：{{主要功能区域、固定陈设及位置关系}}。
背景：{{远处结构、边界与纵深关系}}。
{{已确认且本机位可见的环境、配套用品与生活细节，写明位置、数量尺度及摆放关系}}。
{{本次需改变的材质、颜色、磨损或整洁杂乱程度；未改变部分总括保留}}。
来自{{实际光源及方向}}的光线形成{{符合本次时间天气的照明与阴影}}。
{{输入为结构图时，转换为实际环境且不保留标注、图例或剖顶低墙；不适用时省略}}。
{{仅在本次需求明确时加入的可见人物或道具}}。透视和遮挡按本次机位呈现，固定空间关系保持一致。
```
