# Qwen-Image-2.1-场景参考图提示词模板

版本：v1.18；更新日期：2026-10-02。

每次输出单张连续场景画面。先按[场景图用途原则](../素材规范/场景资料与参考图规范.md#40-先明确剧情画面中的场景状态)确定剧情中的实际环境状态与可见范围；以下空间短语按真实画面选择，不机械填满每个方位或将整套结构塞入同框。依据场景资料卡及本场需求描述时间、天气、照明、机位与取景。

使用前读取[Qwen提示词规范](../生成规范/Qwen-Image-2.1-提示词规范.md)，按所选分支读取[文生图共用填写与输出格式](Qwen-Image-2.1-文生图提示词模板.md)或[图像编辑共用填写与输出格式](Qwen-Image-2.1-图像编辑提示词模板.md)。尺寸、制作依赖以[开发流程第8节](../流程规范/短剧开发流程规范.md#8-核心参考图)为准。只填写当前情况，不把整个文件交给模型。新正文按[统一中文规则](../生成规范/Qwen-Image-2.1-提示词规范.md#14-统一中文编写审阅与提交)填写。

画风占位符遵循[项目画风正文引用](../生成规范/Qwen-Image-2.1-提示词规范.md#16-项目画风正文引用)。

**占位符填写**：遵循[统一填写规则](../生成规范/Qwen-Image-2.1-提示词规范.md#15-模板占位符填写)。

**填写依据**：对应场景资料卡、本场剧情中的环境状态、机位与可见范围，以及项目画风；不为填满方位编造空间。机位、布局及光源按[统一方向参照](../生成规范/镜头语言参考指南.md#13-统一方向参照)转换为本图的画面位置与纵深关系。

## 1. 依据场景资料卡及场次需求生成

生成方式：仅文生图，不输入参考图片。

用途：逐集划分场次后，按场景卡及本场需求创建单张场景图；不预制多视角套装。空间未知部分先补设计。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
一幅{{景别}}画面，呈现{{场景身份及室内／室外环境}}在{{时间、天气与活动状态}}下的景象。

观察机位位于{{适合本场的已确认位置、高度与朝向}}，面向{{本场需要的视觉锚点}}。{{本视图实际存在的建筑围合、可见边界与自然遮挡}}。

来自{{实际光源与方向}}的光线形成{{符合时段的照明与阴影}}。

画面包含{{仅本视图需要的结构与关系}}，边缘保留自然环境空间；{{如适用，说明自然遮挡或位于画外的区域}}。整体为单张连续场景，布局清楚且一致。

场景描述：
前景为{{已确认近处结构及空间关系}}。
画面左侧为{{该画面左侧的结构、入口或固定陈设}}。
中央为{{中央布局与主要功能区域}}。
画面右侧为{{该画面右侧的结构与连接关系}}。
背景为{{场景卡支持的纵深、边界与远处结构}}。{{连接这些区域的通道、门与动线}}。

{{材质、颜色、尺度及适度磨损}}。

{{仅当本场状态需要时，加入已确认的可见人物或道具}}。
```

## 2. 依据已批准参考图及场次需求生成

生成方式：图生图。输入资格及分支选择读取[场景生成规则](../素材规范/场景资料与参考图规范.md#411-生成方式与参考输入)。

用途：利用结构图约束实际空间布局，或依据已批准环境图生成本场需要的状态与视角。目标为单张连续场景环境画面。

填写说明：逐张填写输入的采用范围，以及目标机位、关键关系和本场变化；不重复抄写整张图的细节。单图用“图像”，多图按实际顺序使用 `<image1>`、`<image2>` 等标签。仅填写实际提供的输入；填写后的正文保留以下三个板块。

输出格式：采用图像编辑三字段JSON，`wh_ratio` 为 `16:9`，`ratio_follow` 为空字符串；送审画布按[场景规格](../素材规范/场景资料与参考图规范.md#41-画面要求)设置，不跟随结构图的比例。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
依据{{单图自然指代或多图标签及各自用途}}，生成{{场景身份及室内／室外环境}}在{{时间、天气与活动状态}}下的一幅{{景别}}环境画面。

{{逐张说明从参考图采用的结构布局、固定陈设、材质或外观范围，以及本次允许变化的内容}}。

观察机位位于{{已确认的位置、高度与朝向}}，面向{{本场视觉锚点}}，按这一机位形成正常的空间透视与自然遮挡。{{当前可见的建筑围合、边界及画外区域}}。

{{输入包含结构图时：将其表达的空间关系呈现为场景中的实际环境，不在成图中保留平面线稿、尺寸标注、图例、示意视角或剖顶低墙}}。整体为单张连续场景画面，边缘保留自然环境空间。

场景描述：
{{本机位必须保留的关键结构、数量与连接关系，按场景实际方位换算为画面位置和纵深；其余布局由参考图约束，不逐项转写整张结构图}}。

{{本场需要的材质、颜色、尺度及环境状态；与参考图不同的已确认变化逐项写清}}。

来自{{实际光源与方向}}的光线形成{{符合时段的照明与阴影}}。

{{仅当本场状态需要时，加入已确认的可见人物或道具}}。
```
