# Qwen-Image-2.1-场景参考图提示词模板

版本：v1.10；更新日期：2026-09-30。

每次输出单张连续场景画面。先按[场景图用途原则](../素材规范/场景资料与参考图规范.md#40-先明确剧情画面中的场景状态)确定剧情中的实际环境状态与可见范围；以下空间短语按真实画面选择，不机械填满每个方位或将整套结构塞入同框。优先复用适用的已批准场景图，确需生成时选择依据场景资料卡及场次需求生成、时间天气或照明变化、机位或取景变化；三种情况分别提供填写模板。

使用前读取[Qwen提示词规范](../生成规范/Qwen-Image-2.1-提示词规范.md)，按本节固定生成方式读取[文生图共用填写与输出格式](Qwen-Image-2.1-文生图提示词模板.md)或[图像编辑共用填写与输出格式](Qwen-Image-2.1-图像编辑提示词模板.md)。尺寸、基础着装、制作依赖以[开发流程第8节](../流程规范/短剧开发流程规范.md#8-核心参考图)为准。只填写当前情况，不把整个文件交给模型。新正文按[统一中文规则](../生成规范/Qwen-Image-2.1-提示词规范.md#14-统一中文编写审阅与提交)填写。

画风占位符按[项目画风正文引用](../生成规范/Qwen-Image-2.1-提示词规范.md#16-项目画风正文引用)填写，统一引用已确认正文；输入图风格冲突先明确处理范围。

**占位符填写：** 所有 `{{…}}` 按[占位符填写规则](../生成规范/Qwen-Image-2.1-提示词规范.md#15-模板占位符填写)逐项处理，不能原样提交。本模板的填写依据为对应场景资料卡、本场剧情中的环境状态、机位与可见范围，以及项目画风；编辑分支同时核对实际输入图及授权变化，不为填满方位编造空间。机位、布局及光源按[统一方向参照](../生成规范/镜头语言参考指南.md#13-统一方向参照)转换为本图的画面位置与纵深关系。

## 1. 依据场景资料卡及场次需求生成

生成方式：文生图。不输入参考图片；修改文字后重新生成仍属于本子情况。

用途：逐集划分场次后，按场景卡及本场需求创建单张场景图；不预制多视角套装。空间未知部分先补设计。

**填写模板**

```text
一幅{{景别}}画面，呈现{{场景身份及室内／室外环境}}在{{时间、天气与活动状态}}下的景象。

观察机位位于{{适合本场的已确认位置、高度与朝向}}，面向{{本场需要的视觉锚点}}。{{本视图实际存在的建筑围合、可见边界与自然遮挡}}。

前景为{{已确认近处结构及空间关系}}。
画面左侧为{{该画面左侧的结构、入口或固定陈设}}。
中央为{{中央布局与主要功能区域}}。
画面右侧为{{该画面右侧的结构与连接关系}}。
背景为{{场景卡支持的纵深、边界与远处结构}}。{{连接这些区域的通道、门与动线}}。

{{材质、颜色、尺度及适度磨损}}。

{{仅当本场状态需要时，加入已确认的可见人物或道具}}。

来自{{实际光源与方向}}的光线形成{{符合时段的照明与阴影}}。

画面包含{{仅本视图需要的结构与关系}}，边缘保留自然环境空间；{{如适用，说明自然遮挡或位于画外的区域}}。整体为单张连续场景，布局清楚且一致。

{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}
```

## 2. 时间天气或照明变化

生成方式：图生图。必须实际输入所依据的已有图片，不能只改文字后无图生成。

**填写模板**

```text
将图像中的场景改为{{已确认时间、天气或照明状态}}。

保持原机位、取景、建筑、出入口、道路与固定陈设的位置和结构，以及{{必须保持的材质和场景识别特征}}。

{{光源方向、色温、明暗、阴影及天气造成的可见变化}}。{{与新时间状态对应、且已确认的灯具或门窗状态}}。

整体为单张连续场景画面，保留原有空间尺度及自然环境边缘。

{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}
```

## 3. 机位或取景变化

生成方式：图生图。必须实际输入所依据的已有图片，不能只改文字后无图生成。

**填写模板**

```text
以图像为{{实际采纳的布局、家具或材质}}参考，生成{{本场剧情中实际存在的环境状态}}的单张连续场景画面。

观察机位位于{{已确认位置、高度及朝向}}，以{{适合本场活动的景别和范围}}呈现{{主要画面与必要空间关系}}。

保持{{建筑、门窗和固定陈设的真实关系}}，{{完整墙顶、真实开敞或已确认损毁等本场建筑状态}}。

{{依据资料卡可见的新区域与自然遮挡；无需入镜部分可留在画外}}。

{{结构辅助图输入时，只取其布局／材质，不继承其示意视角与展示方式的具体说明；普通环境图输入时省略}}。

保持{{时间、天气、光照及生活状态}}，让{{本图需要的活动区域与动线}}清楚可辨，并保留自然环境边缘。

{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}
```
