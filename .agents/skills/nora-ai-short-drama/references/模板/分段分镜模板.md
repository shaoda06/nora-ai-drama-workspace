# 分段分镜模板

使用前读取[逐集内容制作规范](../流程规范/逐集内容制作规范.md)的第4节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

保留来源镜号与镜头内容，不在分段时另写剧情。 下方围栏内是产出正文，填写时使用产出标题，不将本模板文件名作为项目产出名。

```text
场次：<集号-场次号；EP00N-C001>
分段：<EP00N-C001-P001>
地点：<具体地点>
时间：<日/夜等> / <内/外>
人物：<本段实际人物>
来源场次分镜：<路径、版本>
包含镜号：<按原顺序列项目镜号>
分段计划时长：<4–15 秒，各镜之和>
开始状态：<人物站位、姿态、服装、持有物、环境和声音状态>
结束状态：<结束时可见／可听状态及下一段衔接要点>

<依次写入时间、原镜号、景别、运镜、情绪/动作、台词、音效、时长>
```

镜头正文逐镜使用[场次分镜模板](场次分镜模板.md)中的八字段。时间格式为 `00:00-00:03秒`，第一镜从本段0秒开始，后续连续顺延，小数秒保留实际精度；除时间按本段重算外，保留原镜号、台词及其他原始内容。
