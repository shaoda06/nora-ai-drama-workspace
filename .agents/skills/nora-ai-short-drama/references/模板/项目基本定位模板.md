# 项目基本定位模板

使用前读取[短剧开发流程规范的定位填写要求](../../../short-drama-develop/references/项目定位与画风规范.md#定位文件填写要求)。本文件维护固定章节、字段和可填正文；审批、保存及填写方法由该入口维护。

正文排版执行[固定结构与补充写法中的段落与换行要求](../共用规则/文件版本与工作稿规范.md#固定结构与补充写法)，包括画风正文的代码块。

完整画风正文及视频执行短版执行[画风内容边界、同阶段准备与确认](../../../short-drama-develop/references/项目定位与画风规范.md#项目画风展开示例验证与复用)，种子表执行[项目七类图片默认种子](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#26-项目七类图片默认种子)。分集编排入口无正式索引时删除该行；完整正文的英文小节仅在需要且已有语言适配时保留；视频执行短版沿用定位文档头部，不单设元数据；在画风整理阶段同步填写中文及当前目标模型所需适配，不省略整个小节或把未确认写成已确认；样例无已认可图片时删除图片行；补充依据无额外资料时删除；风格库资料仅在实际选用库内资源时保留。

下方围栏内是产出正文，按实际内容替换占位符，不将填写提示或未选定枚举保存为项目事实。

头部执行[正式内容文档的共用头部](../共用规则/文件版本与工作稿规范.md#正式内容文档的共用头部)，文档状态按对应流程填写；正文的固定章节与业务编号保持。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../共用规则/文件版本与工作稿规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 1. 受众定位 | 写清主要受众、观看场景与内容需求，作为后续取舍依据。 |
| 2. 题材与叙事标签 | 区分主类型、辅助类型与叙事标签，写实际采用的题材范围。 |
| 3. 时空背景 | 确定时代、地域及现实或架空边界，不在此展开全剧情节。 |
| 4. 情绪与叙事基调 | 说明整体情绪、节奏及表达尺度，供简介、剧本统一使用。 |
| 5. 视觉表现形式 | 按既有小节填写制作规格、视觉规格、完整画风、视频执行短版及语言适配、样例和种子；补充依据只写当前视觉选择的依据与限制。 |
| 其他补充（按需启用） | 固定放在上述正文之后；只写已有章节无法容纳的事项，采用下方三项条目，不记录修改流水。 |
