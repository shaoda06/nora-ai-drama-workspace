# 项目基本定位模板

使用前读取[短剧开发流程规范](../流程规范/短剧开发流程规范.md)的第一部分第1节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

保持五章名称与顺序，章内按项目需要展开；第五章的风格库记录仅在用户选择库内风格时填写，否则删除该小节及填写提示，不保留空字段。不记录用户粘贴的快捷选择说明；原文、中文译文与项目适配结论分开，具体执行[视觉风格选择与记录](../流程规范/短剧开发流程规范.md#视觉风格选择与记录)。未明确的内容填写“待确认”，不将推荐方向写成已确认决定。下方围栏内是产出正文，填写时使用产出标题，不将本模板文件名作为项目产出名。

```markdown
# 项目基本定位

- 项目名称或代号：
- 文档版本：
- 更新日期：
- 确认状态：

## 1. 受众定位

说明主要面向的受众，以及相应的观看兴趣和内容侧重。

## 2. 题材与叙事标签

说明主要题材及必要的辅助标签，明确主次。
标签应能指导后续创作，不堆叠互不相关的类型。

## 3. 时空背景

说明故事所处的时代、地域或空间类型。
这里只确定背景方向，详细世界观在《主旨与简介》中展开。

## 4. 情绪与叙事基调

说明作品的主要情绪体验和叙事基调。
存在多种基调时，明确主基调及辅助基调。

## 5. 视觉表现形式

说明采用的视觉形式及已确认的总体风格方向。
不在此填写具体模型、工作流节点或生成参数。

### 所选风格库资料

仅在用户选择库内风格时保留，按所选风格分别填写；以下原文是参考资料，不是直接提交模型的项目提示词。

- 风格名称：
- 资源位置：以工作区根目录为基准，用代码文本记录资源目录及实际读取的提示词文件位置。

**正面提示词原文**：

~~~text
完整保留从文件读取的原文。
~~~

**正面提示词中文译文**：

填写忠实译文；原文已是中文时注明“同原文”。

**负面提示词原文**：

~~~text
完整保留从文件读取的原文；确无负面提示词时写“未提供”。
~~~

**负面提示词中文译文**：

填写忠实译文；原文已是中文时注明“同原文”，确无负面提示词时写“未提供”。
```
