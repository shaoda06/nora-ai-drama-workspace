# 人物参考图工作稿模板

使用前读取[人物参考图制作与记录规范](../../../nora-drama-assets/references/人物参考图制作与记录规范.md)的第5节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

技术字段、实际上传／执行来源、生成／审阅记录及通知前网页核验由脚本维护，具体职责见[图片执行分工](../../../nora-generation/references/ComfyUI-服务配置与任务提交规范.md#图片执行分工)。Agent在生成执行环节只提交、读报告并展示，不手工补填或复查这些技术条目；用户新决定仍按实际内容输入保存，不由技术成功推定。

图片类型名称及用途说明的填写位置读取[图片类型填写](../../../nora-drama-assets/references/人物参考图制作与记录规范.md#图片类型填写)；生成记录、审阅记录和当前正式资产表使用同一名称。

每个人物一份，跨图片类型与状态持续维护；提交、候选计数与修改授权读取[开发流程8.5.1](../../../nora-drama-assets/references/核心参考图制作规范.md#851-图片交付与用户审核)。 下方围栏内是产出正文，填写时使用产出标题，不将本模板文件名作为项目产出名。

采用后的引用、候选及监控收尾执行[开发流程8.5.2](../../../nora-drama-assets/references/核心参考图制作规范.md#852-图片采用替换与归档后的状态收尾)；当前处置填入“用户采用状态”，原因、具体候选及依据填入“用户决定原因与依据”。

人物四类图按[人物专项规则](../../../nora-drama-assets/references/人物参考图制作与记录规范.md#2-规格背景与布局)填写真实处理；需超分类型批准后按[图片超分执行规范](../../../nora-generation/references/ComfyUI-图片超分执行规范.md)在原生成条目补齐下方超分字段，不需超分类型及历史无此处理填不适用。原生图输出、参数、批准保留；正式文件指向对应类型核对通过的正式尺寸结果。

服装状态延伸读取[统一资产状态规则](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#27-资产状态参考图统一规则)；当前正式资产与候选的图片类型仍填“服装参考图”，在任务用途注明状态图，沿用人物状态和服装状态字段。

文件入口遵循[浏览入口通用文本与链接规则](../流程规范/项目浏览入口规范.md#通用文本与链接)。工作稿位置、素材与输入附件读取[工作稿管理规则](../共用规则/文件版本与工作稿规范.md#工作稿管理规则)。输出候选链接使用 `素材/{实际候选文件名}`；正式图链接指向原资产目录；审阅入口使用本文件具体章节，例如 `[审阅001](#审阅-生成记录-001-001)`。生成结果的浏览同步及本批候选／待审核验按[图片执行分工](../../../nora-generation/references/ComfyUI-服务配置与任务提交规范.md#图片执行分工)由后台完成；Agent不在通知后再核验。

当前采用字段及文件核对结论读取[开发流程8.5.1](../../../nora-drama-assets/references/核心参考图制作规范.md#851-图片交付与用户审核)；批准后处理状态读取[超分规范第4节](../../../nora-generation/references/ComfyUI-图片超分执行规范.md#4-文件核对保存与记录)，当前处置与历史收尾读取[开发流程8.5.2](../../../nora-drama-assets/references/核心参考图制作规范.md#852-图片采用替换与归档后的状态收尾)。下方状态字段选择当次实际值，不将未选定枚举或填写说明保留为当前结论。

故障补做授权、额度及执行条件统一读取[任务监控规范第3.3节](../../../nora-generation/references/ComfyUI-任务监控规范.md#33-故障补做授权与额度)，模板本身不授予额度。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../共用规则/文件版本与工作稿规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 1. 当前正式资产 | 按表维护当前正式采用文件、版本、范围及决定入口；旧采用过程留在对应记录。 |
| 2. 逐次生成记录 | 每次实际生成建立一条记录，固定填写任务信息、输入参考、提示词与执行参数、执行结果、检查与采用五节。 |
| 3. 讨论与修改 | 逐项记录问题、备选、取舍和待定内容，写清日期与依据。 |
| 4. 审阅区 | 按生成记录及审阅轮次重复，固定填写审阅对象、文件与记录核对、展示与用户反馈、用户确认、采用与后续影响五节。 |
| 其他补充（按需启用） | 固定放在上述正文之后；只写已有章节无法容纳的事项，采用下方三项条目，不记录修改流水。 |

讨论按事项重复“讨论-001”等小节；编号接续已有记录，不因模板更新重排。生成及审阅仍使用各自已有编号和固定子节。

## 审阅区

上方正文的“4. 审阅区”是同一工作稿的一部分；按具体生成编号、候选及审阅轮次追加章节，生成条目与正式资产表引用该章节。批准决定、生成处置与正式资产的关联统一读取[开发流程8.5.1](../../../nora-drama-assets/references/核心参考图制作规范.md#851-图片交付与用户审核)；本模板不另维护审批规则。
