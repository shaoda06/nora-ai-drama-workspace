# 场次分镜模板

使用前读取[逐集内容制作规范](../流程规范/逐集内容制作规范.md)的第3、4节及适用的共用规则；填写要求与审批以该规范为准，命名和保存位置读取[逐集目录规范第2节](../流程规范/逐集目录与资产管理规范.md#2-正式文件与目录)。本文件维护场头、逐镜正文及场次内视频分段的可填内容，不替代规范。

开始填写时，先按[剧本、分镜与提示词的职责分工](../流程规范/逐集内容制作规范.md#剧本分镜与提示词的职责分工)核对来源剧本与内容边界。先填场头，再按[景别选项与镜头字段分工](../流程规范/逐集内容制作规范.md#景别选项与镜头字段分工)填写下方逐镜字段；时间坐标与分段填写规则读取制作规范第3、4节。位置、朝向与运动按[统一方向参照](../生成规范/镜头语言参考指南.md#13-统一方向参照)填写。下方围栏内是产出正文，填写时使用产出标题，不将本模板文件名作为项目产出名。

“来源剧本”的版本选择与台词接续按[台词润色后的批准与分镜接续](../流程规范/逐集内容制作规范.md#回稿检查批准与分镜接续)执行，填写下方既有字段，不另抄一份台词稿。

填写与送审时落实[动作、情绪与标点的联动及表演指代、时点检查](../流程规范/逐集内容制作规范.md#动作情绪与标点的联动)，具体要求由制作规范统一维护。

选择出镜人物及裁切时，按[对白、反应与多人镜头的取舍](../流程规范/逐集内容制作规范.md#对白反应与多人镜头的取舍)和[镜头可见内容与画外连续性](../流程规范/逐集内容制作规范.md#镜头可见内容与画外连续性)填写机位、起止画面及动作；必要的画外接续事实填写既有场头或分段状态，声音填写台词／音效，转写边界由所链接规范维护。

取景与运动先按[运镜、构图与切镜的选择](../流程规范/逐集内容制作规范.md#运镜构图与切镜的选择)判断，视线高度与近轴线正面取景按[正反打](../生成规范/镜头语言参考指南.md#41-正反打与视线连续性)落实；各P的开场、段内变化及段间接续按[H3切镜与接续表达](../流程规范/逐集内容制作规范.md#h3切镜与接续表达)核对，结果填写既有字段及P段状态。

返修前按[完整重做的范围与完成要求](../流程规范/逐集内容制作规范.md#完整重做的范围与完成要求)确定本轮范围；大幅结构变化按该节重建正文及P段，小修改才局部修订；本模板不要求沿用旧稿安排。

镜号、修订后的顺序及历史版本关联按[场次编号规则](../流程规范/逐集内容制作规范.md#1-层级编号与时长)填写。资产及视图的名称、编号、链接与镜头空间描述按[场次分镜引用要求](../流程规范/逐集内容制作规范.md#3-场次分镜脚本)填写；下游模型标签的转换读取该节所链规则，不在镜头正文用裸编号代替方向说明。

编写场头与开场镜头时，按[场次与跨集转场接续](../流程规范/逐集内容制作规范.md#场次与剧集之间的转场和接续)核对前场／上集结尾和本场开头，必要的过渡落实到现有镜头字段及分段时间表。

每场镜头正文及分段规划写完后，按[文本自检与订正](../流程规范/短剧开发流程规范.md#文本交付前的自检与订正)处理问题；先按[剧本到分镜的覆盖核对](../流程规范/逐集内容制作规范.md#剧本到分镜的覆盖核对)检查转写，再按[镜头状态的变化、延续与参考差异](../流程规范/逐集内容制作规范.md#镜头状态的变化延续与参考差异)完整复查；实际采用素材就绪后再对照参考核对，状态描述落实到下方现有字段。

含心理声音与开口对白切换时，按[口型切换规则](../流程规范/逐集内容制作规范.md#心理独白与开口对白的切换)填写动作及台词；含显隐变化时，按[显隐过程规则](../流程规范/逐集内容制作规范.md#显现与消失的过程)填写可见过程与衔接。按[逐段音色输入规则](../素材规范/参考音视频管理规范.md#3-人物声音的可选关联)对照本段发声安排，将音色纳入／排除、公共／本组归属及未就绪需求落实到既有参考输入规划。

涉及画面文字时先执行[视频生成全程无字幕](../流程规范/逐集内容制作规范.md#视频生成全程无字幕)；确需可读的场景内文字，再按[文字布局与可读性](../流程规范/逐集内容制作规范.md#画面文字的布局与可读性)填写既有镜头字段。含体感或抽象画面描述时，按[可观察画面转写](../流程规范/逐集内容制作规范.md#不可见感受与抽象画面描述的转写)及上述镜头字段分工落实到机位/构图、起止画面及情绪/动作等对应字段。

划分视频段时填写各P的参考输入规划，按[参考输入规划与分段可执行性](../流程规范/逐集内容制作规范.md#参考输入规划与分段可执行性)检查容量和超限方案；具体文件、版本和模型标签在后续素材映射中落实，不在本模板复制执行记录。

头部执行[正式内容文档的共用头部](../流程规范/短剧开发流程规范.md#正式内容文档的共用头部)，文档状态按对应流程填写；正文的固定章节与业务编号保持。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../流程规范/短剧开发流程规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 1. 镜头正文 | 按P分段和SH镜头展开，逐镜填写既定十二项，时间、动作、对白、起止画面和转场相互对应。 |
| 2. 视频分段 | 固定维护分段总表、各P素材规划及H3时间对应表；与镜头正文同步，不追加素材生成流水。 |
| 其他补充（按需启用） | 固定放在上述正文之后；只写已有章节无法容纳的事项，采用下方三项条目，不记录修改流水。 |
