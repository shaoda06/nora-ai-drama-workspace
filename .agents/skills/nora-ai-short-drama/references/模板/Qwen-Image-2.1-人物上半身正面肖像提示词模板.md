# Qwen-Image-2.1-人物上半身正面肖像提示词模板

版本：v1.31；更新日期：2026-10-01。

用于确定人物身份、头面与上半身可见细节，以及项目画风；完整身材与孕态由人物六视图承接。

使用前读取[Qwen提示词规范](../生成规范/Qwen-Image-2.1-提示词规范.md)，按本节固定生成方式读取[文生图共用填写与输出格式](Qwen-Image-2.1-文生图提示词模板.md)。尺寸、基础着装、制作依赖以[开发流程第8节](../流程规范/短剧开发流程规范.md#8-核心参考图)为准。只填写当前情况，不把整个文件交给模型。新正文按[统一中文规则](../生成规范/Qwen-Image-2.1-提示词规范.md#14-统一中文编写审阅与提交)填写。

画风占位符遵循[项目画风正文引用](../生成规范/Qwen-Image-2.1-提示词规范.md#16-项目画风正文引用)。

**占位符填写**：遵循[统一填写规则](../生成规范/Qwen-Image-2.1-提示词规范.md#15-模板占位符填写)。

**填写依据**：制作项目人物时使用对应人物资料卡的目标年龄／人物状态、项目画风；定位画风验证使用下方固定模特人物描述与本次美术实现正文。基础着装与年龄适配遵循[提示词规范第2.3节](../生成规范/Qwen-Image-2.1-提示词规范.md#23-基础着装与年龄适配)。

## 1. 依据人物资料卡生成

生成方式：仅文生图，不输入参考图片。

用途：无参考图、仅依据已确认文字资料建立身份。用户已排除的旧图不得用于五官／发型提取或作为当前身份验收基准；仅指向旧图的细节不能当作独立文字依据。正文依次组织为风格要求、画面要求、人物描述；画面要求填写半身构图、下边缘及适用基础着装，人物描述填写已确认面部特征、皮肤发型及颈肩胸可见特征。人物特征须按目标资料卡填写；不将“减少幼态”套用于所有人。年龄表达按规范，用户明确要求保留数字时注明依据。

年龄与性别按模板固定公式填写，使用资料卡中目标阶段的已确认年龄，不为填写公式猜测年龄。婴儿选择襁褓分支，并将“手臂自然垂落于身体两侧”改为“双臂自然包裹于襁褓内”；其他人物使用对应性别的上衣分支。

肖像采用[开发流程第8.1节](../流程规范/短剧开发流程规范.md#81-人物参考图)的取景要求，具体位置与截断方式填写在所用分支的构图段，不在其他段落重复。肖像用于确定身份、可见上半身细节与画风；不要加入腹部、腰髋、腿部或全身比例呈现的正文。人物状态仍记于生成资料，不把画外状态写成已取消；资料卡中影响颈肩胸的可见特征应保留。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
一幅人物正面半身近景，纯白背景，{{男性使用：人物身着白色贴身背心，女性角色使用：人物身着白色贴身无肩带内衣，婴儿使用：人物身着白色贴身襁褓}}，正对镜头，头部端正，手臂自然垂落于身体两侧。轮廓清晰实在，头顶上方保留适量白色背景余量。画面以头面及肩胸为主体，画面底边在胸部下缘与肚脐之间将躯干及入镜手臂清晰硬截断，肚脐与双手位于画外。

人物描述：
{{固定公式，人物年龄+性别}}
{{完整归纳资料卡中人物的面部五官、发型、已确认发饰、颈肩和胸部可见的体型特征，不加入画外完整身材或要求}}
```

## 画风验证固定模特描述

用于[项目画风展开、示例验证与复用](../流程规范/短剧开发流程规范.md#项目画风展开示例验证与复用)。男女各一张，复用上方半身肖像正文、生成环节及审批原图规格；认可后按定位画风验证流程保留原图，不超分。只将“人物描述”板块的两个占位符整体替换为对应性别的下列原文，不读取项目人物资料卡、不猜测具体年龄。风格要求填入同一版美术实现正文；待确认的风格候选可用于验证，记录其真实状态。画面要求及基础着装按半身模板对应性别填写，不另维护样例专用构图或参数。以下是固定填充值，不是独立提示词模板，不单独提交。

**女性模特人物描述**：

```text
年轻成年中国女性。
柔和的鹅蛋脸，舒展的眉形，深棕色眼睛，自然的浅玫瑰色嘴唇，神态平静自然。黑发在头顶束成简洁的发髻，额前少量发束沿脸侧落下。
```

**男性模特人物描述**：

```text
年轻成年中国男性。
脸型硬朗，五官立体，体型自然，薄肌身材，舒展的眉形，深棕色眼睛，神态平静自然。黑色短发。
```
