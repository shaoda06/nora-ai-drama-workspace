# 主旨与简介模板

使用前读取[简介文件填写要求](../流程规范/短剧开发流程规范.md#简介文件填写要求)及第3节的故事核心、世界观和共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件维护固定字段与可填正文，不替代规范。

保持七章名称与顺序；世界观子项按题材展开。下方围栏内是产出正文，按实际内容替换占位符，不将填写提示或未选定枚举保存为项目事实。已有确认日期、制作规格、关联资料等必要信息可在头部固定字段之后保留。

```markdown
# 主旨与简介

- 项目名称或代号：{{当前名称或临时代号}}
- 文档版本：{{版本号}}
- 更新日期：{{YYYY-MM-DD}}
- 确认状态：{{待确认／部分确认／已确认，选择一项}}
- 确认说明：{{实际确认范围、仍未确认的内容或必要修订说明}}
- 确认依据：{{实际审阅或决定记录链接；未确认写“尚未确认”}}

## 1. 故事主旨
故事要表达的核心主题与情感指向。

## 2. 世界观与核心规则
时代与空间、相关社会环境，以及影响剧情的运行规则、代价和限制。
具体子项按题材需要展开，只写与故事有关的设定。

## 3. 核心故事设定
主角的特殊处境、故事起点及推动故事发生的核心前提。

## 4. 主要矛盾与主角目标
主要冲突、主角想要达成的目标、主要阻力及相关利害。

## 5. 一句话梗概
用一句话概括主角、处境、目标及核心冲突。

## 6. 故事简介
连贯介绍故事的起点、主要发展方向和核心吸引力，不展开为全局大纲。

## 7. 结局方向
主要矛盾、主角目标与主题表达预期如何收束。
```
