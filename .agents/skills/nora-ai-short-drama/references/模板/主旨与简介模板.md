# 主旨与简介模板

使用前读取[简介文件填写要求](../流程规范/短剧开发流程规范.md#简介文件填写要求)及第3节的故事核心、世界观和共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件维护固定字段与可填正文，不替代规范。

保持七个业务章节名称与顺序；世界观子项按题材展开。下方围栏内是产出正文，按实际内容替换占位符，不将填写提示或未选定枚举保存为项目事实。必要的规格与关联内容放入对应正文，确认日期及修改经过保存在实际记录。

头部执行[正式内容文档的共用头部](../流程规范/短剧开发流程规范.md#正式内容文档的共用头部)，文档状态按对应流程填写；正文的固定章节与业务编号保持。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../流程规范/短剧开发流程规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 1. 故事主旨 | 说明故事想表达的核心问题和态度，不写宣传口号。 |
| 2. 世界观与核心规则 | 按题材写世界如何运作、能力限制和行为后果，保持可供后续引用。 |
| 3. 核心故事设定 | 交代主角处境及故事成立的关键设定，不重复完整人物卡。 |
| 4. 主要矛盾与主角目标 | 写清主角要什么、阻力来自哪里，以及失败的代价。 |
| 5. 一句话梗概 | 用一句话串起主角、目标、阻力和故事特点。 |
| 6. 故事简介 | 连贯介绍核心故事及主要发展，不逐集展开。 |
| 7. 结局方向 | 交代最终冲突如何收束及主要人物的结果，不附编制或修改记录。 |
| 其他补充（按需启用） | 固定放在上述正文之后；只写已有章节无法容纳的事项，采用下方三项条目，不记录修改流水。 |

```markdown
# 主旨与简介

- 项目名称或代号：{{当前项目实际名称或代号}}
- 文档版本：{{当前文档版本号}}
- 更新日期：{{YYYY-MM-DD}}
- 确认状态：{{待确认／部分确认／已确认，选择一项}}
- 确认范围：{{当前文档已确认内容及待决边界；尚未确认时如实填写}}
- 确认依据：{{实际审阅或决定记录的简短链接；未确认写“尚未确认”}}

## 1. 故事主旨
故事要表达的核心主题与情感指向。

## 2. 世界观与核心规则
时代与空间、相关社会环境，以及影响剧情的运行规则、代价和限制。
具体子项按题材需要展开，只写与故事有关的设定。

## 3. 核心故事设定
主角的特殊处境、故事起点及推动故事发生的核心前提。

## 4. 主要矛盾与主角目标
主要冲突、主角想要达成的目标、主要阻力及相关利害。

## 5. 一句话梗概
用一句话概括主角、处境、目标及核心冲突。

## 6. 故事简介
连贯介绍故事的起点、主要发展方向和核心吸引力，不展开为全局大纲。

## 7. 结局方向
主要矛盾、主角目标与主题表达预期如何收束。

## 其他补充

无。确有未被以上章节覆盖的事项时，按以下三项逐条填写；填写后删除本提示。

- 事项：<简短名称>
- 内容与适用范围：<当前需要补充的事实、说明及所指对象>
- 依据与当前状态：<实际来源入口；已确定／待确认／待落实，以及尚需处理的内容>

```
