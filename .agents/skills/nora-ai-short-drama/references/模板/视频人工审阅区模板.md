# 视频人工审阅区模板

使用前读取[逐集目录与资产管理规范](../流程规范/逐集目录与资产管理规范.md)的第4、5节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

适用于一采、二采、后处理；下方正文填写在所属对象工作稿的审阅区，不另生成审阅文件。每轮明确具体输出、R编号及版本，用户决定按[视频结果人工审核](../流程规范/逐集目录与资产管理规范.md#视频结果人工审核)记录。

采用后的关联与核对读取[视频采用记录与批准依据](../流程规范/逐集目录与资产管理规范.md#视频采用记录与批准依据)；本审阅区提供决定、具体输出及依据字段。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../流程规范/短剧开发流程规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 1. 审阅对象 | 明确本轮被审分段、阶段、输出文件、R编号及展示入口。 |
| 2. 用户反馈 | 按反馈表记录用户原意、时间依据及其提供的画面范围。 |
| 3. 人工审核决定 | 写真实决定、所指具体输出、适用范围与决定依据。 |
| 4. 采用与后续处理 | 记录候选或选定入口、后续授权、替代关系和受影响版本；额外审阅说明归本节其他补充字段。 |

```markdown
### 审阅-R001-一采-001

#### 1. 审阅对象

- 所属分段／场次／整集：
- 处理阶段或成片类型：
- 被审具体输出文件及R编号／版本：
- 来源任务或执行记录入口：
- agent取回及展示入口：<实际取回记录与网页审核入口，明确本段P／R／阶段>

#### 2. 用户反馈

| 反馈时间／依据 | 画面时间点或范围（用户提供时） | 用户反馈的问题或意见 |
| --- | --- | --- |

#### 3. 人工审核决定

- 决定：待审核／批准采用／修改后再审／不采用
- 对应具体输出：
- 批准或要求修改的范围：
- 决定时间与依据：

#### 4. 采用与后续处理

- 当前候选／选定入口：
- 用户要求的后续处理及授权范围：
- 移动或替代关系及对应记录入口：
- 受影响的分段、场次或整集版本及处理决定：
- 其他补充：<本轮审阅其余字段无法覆盖的事项、内容与适用范围、依据与当前状态；没有则写“无”>

```
