# 分段视频工作稿模板

整场送审或准备完成时，按[场次修改轮次](../流程规范/逐集目录与资产管理规范.md#场次修改轮次)登记完整版本组合；本文件沿用自身版本与各段R，轮次关联不进入模型正文。执行条目关联该轮及实际选中范围，原组位置与缓存接续来源留在执行映射，不据未选中组填写本轮其他分段的播放版本。

使用前读取[逐集目录与资产管理规范](../流程规范/逐集目录与资产管理规范.md)的第4节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

审阅区填写[视频人工审阅区模板](视频人工审阅区模板.md)的正文，不另建文件。固定字段填写实际执行与采用依据；计数、查询补记、留档及客观规格规则读取[逐集目录规范第4节](../流程规范/逐集目录与资产管理规范.md#分段生成记录)。每个实际制作阶段使用一个 `R编号-阶段` 条目，标题与“处理阶段”一致；同R重试追加在其执行过程字段下，不复制当前状态条目。阶段归属按[阶段与当前版本修改](../流程规范/短剧开发流程规范.md#视频阶段与当前版本修改)填写，各阶段独立修订号与上游来源按[修订编号规则](../流程规范/逐集目录与资产管理规范.md#视频修订编号与执行过程)填写。直接修改已有视频时，用现有来源、参数和输出字段记录实际操作；未调用模型或ComfyUI的字段填不适用，不造提示词文件或任务ID。下方围栏内是产出正文，替换编号与占位内容，不将本模板文件名作为项目产出名。

采用后的填写与核对读取[视频采用记录与批准依据](../流程规范/逐集目录与资产管理规范.md#视频采用记录与批准依据)，本模板只提供对应引用字段。

后处理目标与填写口径读取[后处理交付规格](../生成规范/ComfyUI-H3视频执行规范.md#后处理交付规格)，推荐值不作为平台硬性要求或成品实测值。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../流程规范/短剧开发流程规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 1. 当前选定结果 | 按一采、二采、后处理表维护当前选定文件、修订号、来源和用户依据。 |
| 2. 修订版各阶段与采用记录 | 按实际R编号及阶段登记任务、输入、参数、取回、检查与采用；同R重试留在原记录，位置变化写在对应表。 |
| 3. 讨论与修改 | 逐项记录待定问题、备选方案和修改依据，不能把执行状态混入讨论。 |
| 4. 审阅区 | 每轮使用视频人工审阅区模板，明确被审输出与用户决定。 |
| 其他补充（按需启用） | 固定放在上述正文之后；只写已有章节无法容纳的事项，采用下方三项条目，不记录修改流水。 |

讨论按事项重复“讨论-001”等小节；编号接续已有记录，不因模板更新重排。生成及审阅仍使用各自已有编号和固定子节。
