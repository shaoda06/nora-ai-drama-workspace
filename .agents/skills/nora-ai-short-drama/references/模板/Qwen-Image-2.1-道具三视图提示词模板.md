# Qwen-Image-2.1-道具三视图提示词模板

版本：v1.6；更新日期：2026-09-27。

用于同一道具同一状态的正面、自身右侧90度和背面三视图；分别提供依据资料生成与状态变化模板。

使用前读取[Qwen提示词规范](../生成规范/Qwen-Image-2.1-提示词规范.md)，按本节固定生成方式读取[文生图共用填写与输出格式](Qwen-Image-2.1-文生图提示词模板.md)或[图像编辑共用填写与输出格式](Qwen-Image-2.1-图像编辑提示词模板.md)。尺寸、基础着装、制作依赖以[开发流程第8节](../流程规范/短剧开发流程规范.md#8-核心参考图)为准。只填写当前情况，不把整个文件交给模型。新正文按[统一中文规则](../生成规范/Qwen-Image-2.1-提示词规范.md#14-统一中文编写审阅与提交)填写。

**占位符填写：** 所有 `{{…}}` 按[占位符填写规则](../生成规范/Qwen-Image-2.1-提示词规范.md#15-模板占位符填写)逐项处理，不能原样提交。本模板的填写依据为对应道具资料卡的目标状态、正面定义、摆放基准、各面结构及项目画风；状态修订同时核对实际输入图和已确认变化。

- [1. 依据道具资料卡生成](#1-依据道具资料卡生成)
- [2. 状态变化](#2-状态变化)


## 1. 依据道具资料卡生成

生成方式：文生图。不输入参考图片；修改文字后重新生成仍属于本子情况。

用途：依据已确认道具卡的正面定义、摆放基准、左右背面结构及同一状态生成三视图。保留需要的真实标记；不添加视图标签。

**填写模板**

```text
一幅{{已确认视觉风格}}道具参考图，在纯白背景上呈现处于{{固定状态描述}}的同一{{道具身份}}。

一行均匀排列三个视图：左侧正面，中间为道具自身右侧的精确九十度侧面，右侧背面。正面以{{已确认正面标志}}定义，各视图遵循{{摆放与朝向基准}}。

{{正面轮廓、可见部件与表面标记}}。

{{右侧厚度、侧面形状与连接关系}}。

{{已确认背面结构与表面细节}}。

三个视图保持一致的{{材质、颜色、尺寸比例、磨损及运行状态}}。{{如适用，已确认的开口位置或活动部件状态}}。

完整轮廓及所有外伸部件均位于各自视格内，四周保留白色余量，展示尺度可比较。

柔和均匀的光线呈现结构与表面，标记清楚可辨。整体为同一物件同一状态的一致三视图。
```

## 2. 状态变化

生成方式：图生图。必须实际输入所依据的已有图片，不能只改文字后无图生成。

```text
将图像所示同一道具呈现为{{已确认目标状态及变化}}，保持{{不变的造型身份、尺寸比例、材质、配色及标记}}。

保留一行三列排布，从左到右为正面、道具自身右侧90度侧视、背面，三个视角均展示该目标状态，结构和变化位置相互对应。

{{本次改变的部件、开合关系或损伤位置，以及新可见内部结构的已确认设计}}。

三个视角展示尺度可比较，主体及外伸部件完整入画，纯白背景，四周及各视格之间留出合理余量，关键轮廓清楚。
```
