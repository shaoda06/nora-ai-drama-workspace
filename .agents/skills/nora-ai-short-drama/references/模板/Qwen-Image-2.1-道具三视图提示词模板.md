# Qwen-Image-2.1-道具三视图提示词模板

版本：v1.15；更新日期：2026-10-04。

用于同一道具同一状态的正面、自身右侧90度和背面三视图。剧情需要的状态延伸另用[资产状态参考图模板的道具大类](Qwen-Image-2.1-资产状态参考图提示词模板.md#3-道具状态参考图)，不将该补图套入本模板的三视图布局。

使用前读取[Qwen提示词规范](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md)，按所选大类读取[文生图共用填写与输出格式](Qwen-Image-2.1-文生图提示词模板.md)或[图像编辑共用填写与输出格式](Qwen-Image-2.1-图像编辑提示词模板.md)。尺寸与制作依赖以[道具规范第3节](../../../nora-drama-assets/references/道具资料与参考图规范.md#3-三视图与状态规则)为准。只填写当前情况，不把整个文件交给模型。新正文按[统一中文规则](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#14-统一中文编写审阅与提交)填写。

画风占位符遵循[项目画风正文引用](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#16-项目画风正文引用)。

**占位符填写**：遵循[统一填写规则](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#15-模板占位符填写)。

**填写依据**：对应道具资料卡的目标状态、正面定义、摆放基准、各面结构及项目画风。

- [1. 依据道具资料卡生成](#1-依据道具资料卡生成)
- [2. 依据用户提供或指定的道具参考图生成](#2-依据用户提供或指定的道具参考图生成)


## 1. 依据道具资料卡生成

生成方式：仅文生图，不输入参考图片。

用途：依据已确认道具卡的正面定义、摆放基准、左右背面结构及同一状态生成三视图。保留需要的真实标记；不添加视图标签。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
一幅道具参考图，在纯白背景上呈现处于{{固定状态描述}}的同一{{道具身份}}。

一行均匀排列三个视图：左列正面，中列为道具自身右侧的精确九十度侧面，右列背面。正面以{{已确认正面标志}}定义，各视图遵循{{摆放与朝向基准}}。

完整轮廓及所有外伸部件均位于各自视格内，四周保留白色余量，展示尺度可比较。

柔和均匀的光线呈现结构与表面，标记清楚可辨。整体为同一物件同一状态的一致三视图。

道具描述：
{{左列正面轮廓、可见部件与表面标记；位置使用该视格内的画面方位及邻近部件}}。

{{中列侧视图可见的厚度、侧面形状与连接关系}}。

{{右列背面可见的已确认结构与表面细节；位置按该视格视角换算}}。

三个视图保持一致的{{材质、颜色、尺寸比例、磨损及运行状态}}。{{如适用，已确认的开口位置或活动部件状态}}。
```

## 2. 依据用户提供或指定的道具参考图生成

生成方式：图生图。输入资格读取[图片类型索引](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#11-图片类型专用模板索引)及[输入记录规则](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#24-输入参考图检查与记录复用)。

用途：依据用户提供的原参考图或指定的已批准道具图，采用已明确的设计范围，生成本次基础三视图；缺少的关键侧面或背面设计按资料卡确认。

填写说明：单图用“图像”，多图按实际输入顺序逐张使用标签，说明每张的采用范围与目标变化。输出使用编辑三字段JSON，`wh_ratio` 取基础三视图规格，`ratio_follow` 为空。

**填写模板**

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
依据{{实际输入图指代及逐张参考用途}}，生成同一{{道具身份}}处于{{目标基础状态}}的三视图参考图。
纯白背景，一行三列：左列正面，中列为道具自身右侧精确九十度侧面，右列背面。以{{正面定义}}及{{摆放基准}}确定朝向。
三个视图展示尺度可比较，完整容纳主体与外伸部件，格内和格间合理留白，柔和均匀的光照使轮廓与材质可辨。

道具描述：
从{{输入图指代}}采用{{结构、材质、配色或标记的指定范围}}，保留{{不在变化范围内的设计与识别特征}}。
将{{需调整的部件}}呈现为{{本轮完整目标形状、数量、位置与连接关系}}。
左列正面显示{{需明确的可见结构与准确标记}}；中列侧面显示{{已确认厚度、侧部及连接关系}}；右列背面显示{{有确认依据的背部结构与细节}}。
三个视图保持同一物件、同一状态，按各自朝向呈现透视及遮挡。参考图中的持有人、场景背景、支架及额外标签不进入独立展示；{{必要既有附件及已确认标记的保留要求}}。
```
