# 分段视频提示词文档模板

整场送审或准备完成时，按[场次修改轮次](../共用规则/场次版本组合规范.md#场次修改轮次)登记完整版本组合；本文件沿用自身版本与各段R，轮次关联不进入模型正文。

使用前读取[视频提示词制作规范](../../../nora-video-prompts/references/视频提示词制作规范.md#6-分段视频提示词文档)及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

开始转写时，先按[完整重做与局部修订](../共用规则/制作返修与完整重做规范.md#完整重做的范围与完成要求)确定范围，再按[剧本、分镜与提示词的职责分工](../共用规则/创作职责与接续规范.md#剧本分镜与提示词的职责分工)核对来源及上游缺项的处理入口。

英文模型正文与中文参考版的排版执行[固定结构与补充写法中的段落与换行要求](../共用规则/文件版本与工作稿规范.md#固定结构与补充写法)。

模型正文执行[语言与命名适配](../../../nora-video-prompts/references/视频提示词制作规范.md#h3模型正文的语言与命名)及[切镜与接续表达](../../../nora-video-prompts/references/视频提示词制作规范.md#h3切镜与接续表达)。转写分镜中的资产／视图引用时，执行[项目引用与模型标签](../../../nora-video-prompts/references/视频提示词制作规范.md#项目引用与模型标签)，将结果落实到本段实际素材映射、中英文正文及既有提交前检查。

镜头内的位置、朝向、光源与运动按[统一方向参照](../../../camera-language/references/镜头语言参考指南.md#13-统一方向参照)写入英文正文及中文参考版；切镜后按新机位换算，保持主体与环境的实际关系。

按[单人／多人取舍](../../../short-drama-storyboard/references/场次分镜制作规范.md#对白反应与多人镜头的取舍)忠实转写已确认的出镜安排，按[可见内容与画外连续性](../../../short-drama-storyboard/references/场次分镜制作规范.md#镜头可见内容与画外连续性)筛选每镜画面与必要声音；制作依据中的画外接续记录不自动成为模型的出镜／动作要求，局部身体入画须有明确身份与裁切。具体检查由下方所链内容核对维护。

编写前确认场次分镜已按[镜头状态的变化、延续与参考差异](../../../short-drama-storyboard/references/场次分镜制作规范.md#镜头状态的变化延续与参考差异)完成整场复查及实际参考核对，按该规则转写状态与差异；准备阶段核对公共＋本组最终正文与实际输入的一致性，提交由工具复用未变化的依据。

按[导演台公共／本组拆分规则](../../../nora-generation/references/ComfyUI-MiniMaxH3导演台节点使用规范.md#4-公共提示词与本组提示词)规划素材及定义的归属，完成各段完整六节正文后，再拆到对应输入区并逐段核对最终拼接内容。Ref2VA参考定义及保留说明按[参考定义与保留说明](../../../nora-video-prompts/references/视频提示词制作规范.md#ref2va参考定义与保留说明)填写并核对来源与章节归属；导演台分配按[参考定义与状态描述](../../../nora-generation/references/ComfyUI-MiniMaxH3导演台节点使用规范.md#41-参考定义与状态描述)处理，模型格式继续读取对应H3指南。

转写时承接分镜中的[动作与情绪联动](../../../short-drama-write/references/对白与表演修订规范.md#动作情绪与标点的联动)、[画面文字布局](../共用规则/画面文字与字幕规范.md#画面文字的布局与可读性)、[心理独白与口型切换](../../../short-drama-storyboard/references/场次分镜制作规范.md#心理独白与开口对白的切换)、[显隐过程](../../../short-drama-storyboard/references/场次分镜制作规范.md#显现与消失的过程)及所用[界面固定元素](../../../nora-drama-assets/references/道具资料与参考图规范.md#虚拟界面固定元素与剧情内容)；人物发声安排与音色纳入／排除按[逐段音色输入规则](../../../nora-drama-assets/references/参考音视频管理规范.md#3-人物声音的可选关联)填写。

正文编写、中文转译、内容核对及准备按[提示词编写与检查顺序](../../../nora-video-prompts/references/视频提示词制作规范.md#提示词编写与检查顺序)执行。转写说话、倾听及停顿期间的姿态与手部状态时，按[身体表演](../../../short-drama-write/references/对白与表演修订规范.md#说话与倾听时的身体表演)对照完整分镜字段，落实到实际模型正文及同版中文参考。检查分类与证据要求由[内容核对](../../../nora-video-prompts/references/视频提示词制作规范.md#内容核对的证据与结论)维护，下方只填写本次结果引用。

转写机位和动作时，合并读取[镜头字段分工](../../../short-drama-storyboard/references/场次分镜制作规范.md#景别选项与镜头字段分工)及[运镜、构图与切镜的选择](../../../short-drama-storyboard/references/场次分镜制作规范.md#运镜构图与切镜的选择)，保持同镜运动、必要可见信息和动作全过程；段内状态与实际段间设置按上方切镜与接续入口处理，不在提示词阶段另排切点或逐镜复制全套状态。

素材输入条件按[首帧规范第1节](../../../short-drama-storyboard/references/首帧参考图规范.md#1-制作复用与画面要求)核对；环境选图与生成组对应按[场景规范第4.3节](../../../nora-drama-assets/references/场景资料与参考图规范.md#43-场次采用记录与提示词边界)填写本段映射。

这是项目准备文档外壳，不是H3模型正文规范；只将“提交给模型的完整提示词”区按语言适配编写的模型正文提交模型；紧随其后的中文参考版用于审阅与复盘，不提交模型。 下方围栏内是产出正文，填写时使用产出标题，不将本模板文件名作为项目产出名。

头部执行[正式内容文档的共用头部](../共用规则/文件版本与工作稿规范.md#正式内容文档的共用头部)，文档状态按对应流程填写；正文的固定章节与业务编号保持。

实际模型正文及中文参考版按[视频生成全程无字幕](../共用规则/画面文字与字幕规范.md#视频生成全程无字幕)的默认写法与[获授权对照](../共用规则/画面文字与字幕规范.md#生成字幕问题的提示词对照)填写，并核对各镜描述、声音与参考用途没有反向要求。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../共用规则/文件版本与工作稿规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 镜头对应 | 用对应表关联项目镜号、H3 Shot及时间范围。 |
| 参考素材映射 | 列本段实际输入文件、版本、批准依据和Picture／Audio输入位置。 |
| 主体与声音对应 | 对应准确中文名称、Subject、角色声音、音色与口型，区分实际输入和未就绪需求。 |
| 提交给模型的完整提示词 | 只放实际提交模型的完整正文，执行语言适配并保持模型结构与原文台词。 |
| 中文提示词参考版 | 逐项对应英文正文，供中文核对，不作为额外模型输入。 |
| 制作依据与目标 | 记录当前采用的分镜、风格、任务模式、时长和状态依据。 |
| 提交前检查 | 准备阶段分别填写工具格式检查报告入口与Agent内容核对结论；实际执行引用共同工具报告。 |
| 其他补充（按需启用） | 固定放在上述正文之后；只写已有章节无法容纳的事项，采用下方三项条目，不记录修改流水。 |
