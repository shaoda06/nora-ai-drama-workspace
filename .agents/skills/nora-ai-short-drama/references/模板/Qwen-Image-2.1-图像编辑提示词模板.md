# Qwen-Image-2.1-图像编辑提示词模板

本文件只维护图像编辑共用输入清单与三字段JSON格式；专用正文按[图片类型索引](../生成规范/Qwen-Image-2.1-提示词规范.md#11-图片类型专用模板索引)读取。使用前读取规范第1、2、4节，包含[七项约定](../生成规范/Qwen-Image-2.1-提示词规范.md#22-qwen参考图生成与修订的七项约定)。按实际输入核对图号，单图自然称“图像”，多图逐张说明用途。输入图按[输入参考图检查与记录复用](../生成规范/Qwen-Image-2.1-提示词规范.md#24-输入参考图检查与记录复用)按记录核对；需看图时先满足明确授权条件。


正文分段与JSON换行转义遵循[统一中文编写、审阅与提交](../生成规范/Qwen-Image-2.1-提示词规范.md#14-统一中文编写审阅与提交)。

**占位符填写**：遵循[统一填写规则](../生成规范/Qwen-Image-2.1-提示词规范.md#15-模板占位符填写)。

**填写依据**：本次任务对应的已确认资料、实际输入图版本和顺序、用户授权的修改／保留范围及目标状态。

修改位置与目标朝向按[统一方向参照](../生成规范/镜头语言参考指南.md#13-统一方向参照)填写；先指明输入图及适用视格，再描述格内画面位置。新视角按目标机位重新换算，保留主体真实结构关系。

## 1. 需求与输入图清单

```text
任务类型：{{人物六视图衍生／角色六视图合成／首帧生成／场景参考图／道具状态参考图}}
画风来源与版本：{{项目定位入口及已确认正文版本}}
画风正文：{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}
编辑目标：{{这次需要发生的明确变化；涉及结构时说明数量、位置、连接或接触关系}}

输入图清单（逐张列出）：
  图片编号：{{1、2等，与实际输入顺序一致}}
  文件或素材版本：{{实际源素材文件、版本及批准依据，核对该类型固定输入关系}}
  输入检查依据：{{默认引用生成／操作／批准记录及图片版本；如按明确授权查看，另注明依据及范围，不把生成目标当成已验证画面}}
  用途：{{身份／服装体型／场景布局／道具结构／材质}}
  采用范围：{{具体从这张图保留或借用什么}}

保留画布：{{需要沿用哪张图的构图；重新构图时写“无固定画布”}}
不可改变：{{身份、年龄感、结构、色彩、材质、画风等}}
允许改变：{{本次视角、姿态、取景、服装、光线或指定部件}}

对照条件（做对照时）：{{本次改变项与固定项；仅换种子时复用原提示词，不再优化}}
新增可见区域依据：{{来自哪份已确认资料；缺失的关键设计先明确}}

取景与边缘：{{完整展示的部位，以及画面上、下、左、右边缘余量}}
画面文字：{{保留／替换的准确原文；无需求则省略}}

目标比例与像素：{{开发流程或用户已确认值；像素仅保留在需求记录}}
```

画风正文的填写位置与引用方式见[项目画风正文引用](../生成规范/Qwen-Image-2.1-提示词规范.md#16-项目画风正文引用)。

## 2. 衍生与合成正文

按[固定生成方式与输入关系](../生成规范/Qwen-Image-2.1-提示词规范.md#11-图片类型专用模板索引)选择人物六视图、角色六视图、首帧、场景参考图或道具状态参考图专用正文。本共用格式不改变图片类型的生成方式。
