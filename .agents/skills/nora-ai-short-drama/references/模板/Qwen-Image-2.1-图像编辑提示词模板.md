# Qwen-Image-2.1-图像编辑提示词模板

本文件只维护图像编辑共用输入清单与三字段JSON格式；专用正文按[图片类型索引](../生成规范/Qwen-Image-2.1-提示词规范.md#11-图片类型专用模板索引)读取。使用前读取规范第1、2、4节，包含[七项约定](../生成规范/Qwen-Image-2.1-提示词规范.md#22-qwen参考图生成与修订的七项约定)。按实际输入核对图号，单图自然称“图像”，多图逐张说明用途。输入图按[输入参考图检查与记录复用](../生成规范/Qwen-Image-2.1-提示词规范.md#24-输入参考图检查与记录复用)决定实际查看或复用记录。


正文按语义分段，填写时保留清楚的换行与空行；输出JSON时在字符串内用`\n`表示换行、`\n\n`表示空行，JSON本身仍可为单行。字段数量及含义不变，已冻结请求原文不回写。

**占位符填写：** 所有 `{{…}}` 按[占位符填写规则](../生成规范/Qwen-Image-2.1-提示词规范.md#15-模板占位符填写)逐项处理，不能原样提交。本模板的填写依据为本次任务对应的已确认资料、实际输入图版本和顺序、用户授权的修改／保留范围及目标状态；JSON比例字段按规范填写，允许的空字符串不填成说明文字。

## 1. 需求与输入图清单

```text
任务类型：{{局部修改／换装／新视角／扩图／场景状态变化／道具变化}}
编辑目标：{{这次需要发生的明确变化；涉及结构时说明数量、位置、连接或接触关系}}

输入图清单（逐张列出）：
  图片编号：{{1、2等，与实际输入顺序一致}}
  文件或素材版本：{{实际文件及批准／候选状态；候选用作底图时注明本目标修订用途，核对专项来源限制}}
  输入检查依据：{{本次实际查看／复用已有记录；注明图片版本及记录入口，只填写有依据的可见特征}}
  用途：{{编辑主体／身份／服装体型／场景布局／道具结构／材质}}
  采用范围：{{具体从这张图保留或借用什么}}

保留画布：{{需要沿用哪张图的构图；重新构图时写“无固定画布”}}
不可改变：{{身份、年龄感、结构、色彩、材质、画风等}}
允许改变：{{本次视角、姿态、取景、服装、光线或指定部件}}

修订依据（有前轮时）：{{上一候选和审阅入口、具体缺陷；供agent核对，不要求模型记住前轮}}
对照条件（做对照时）：{{本次改变项与固定项；仅换种子时复用原提示词，不再优化}}
新增可见区域依据：{{来自哪份已确认资料；缺失的关键设计先明确}}

取景与边缘：{{完整展示的部位，以及上、下、左、右余量}}
画面文字：{{保留／替换的准确原文；无需求则省略}}

目标比例与像素：{{开发流程或用户已确认值；像素仅保留在需求记录}}
```

## 2. 单图局部修改或状态修改

只用于已授权的已有图修改。明确修改目标、保留内容与衔接方式，再从[肖像修订](Qwen-Image-2.1-人物上半身正面肖像提示词模板.md#2-已有肖像局部或状态修订)、[服装修订](Qwen-Image-2.1-服装正背面图提示词模板.md#2-已有服装修订)、[场景变化](Qwen-Image-2.1-场景参考图提示词模板.md)或[道具变化](Qwen-Image-2.1-道具三视图提示词模板.md#2-状态变化)选择专用正文。人物六视图的建立及重试仍从[已批准肖像生成](Qwen-Image-2.1-人物六视图提示词模板.md)。

## 7. 图像编辑输出格式

```json
{"rewritten_prompt":"{{按语义分段的完整编辑指令}}","wh_ratio":"{{明确比例或空字符串}}","ratio_follow":"{{输入图标签或空字符串}}"}
```
