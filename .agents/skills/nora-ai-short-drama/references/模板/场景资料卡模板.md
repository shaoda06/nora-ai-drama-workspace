# 场景资料卡模板

使用前读取[场景资料与参考图规范](../../../nora-drama-assets/references/场景资料与参考图规范.md)的第3节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

保持七章及固定字段；第六章6.1按视图维护方案，6.2按实际场次追加需求与引用。建卡时机、布局表达、状态与场次填写执行[场景规范第1、3节](../../../nora-drama-assets/references/场景资料与参考图规范.md#3-场景资料卡固定模板)，环境与配套细节设计执行[第3.1节](../../../nora-drama-assets/references/场景资料与参考图规范.md#31-环境与配套细节设计)，图片用途与状态职责执行[第4.0节](../../../nora-drama-assets/references/场景资料与参考图规范.md#40-图片用途与状态归属)。下方围栏内使用产出标题，不将本模板文件名作为项目产出名。

头部执行[正式内容文档的共用头部](../共用规则/文件版本与工作稿规范.md#正式内容文档的共用头部)，文档状态按对应流程填写；正文的固定章节与业务编号保持。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../共用规则/文件版本与工作稿规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 1. 基本信息 | 登记场景编号、边界、关联场景、剧情用途和使用人物。 |
| 2. 空间结构 | 写方位、布局、出入口及固定用品的数量、位置与尺度。 |
| 3. 视觉设定 | 写基准状态的风格、材质、色彩、光线和标志元素。 |
| 4. 时间与剧情状态 | 按状态表写相对基准的变化、触发条件及恢复或衔接方式。 |
| 5. 连续性约束 | 区分必须固定、允许变化和禁止出现的内容。 |
| 6. 参考图生成要点 | 固定使用视图方案、场次需求与引用两个小节；逐项写实际机位、可见范围、采用素材及缺项。 |
| 7. 其他备注 | 只容纳前六章无法覆盖的项目特有补充，按其他补充条目填写。 |

## 6. 参考图生成要点

### 6.1 视图方案

每个实际需要的视图重复以下字段；同一方案不按场次重复抄写。

- 视图编号与名称：
- 用途及覆盖区域：总览／基础图、机位场景参考图或兼任；再说明区域关系、重点区域或补充方向
- 需求来源与适用机位：本次设计用途或实际分镜入口及镜号范围；机位标识不替代下方具体观察关系
- 适用环境状态：引用基准或本场状态依据；逐镜变化在分镜维护，不在此重复动作过程
- 布局依据及版本：已批准平面图或已确认空间描述
- 机位位置：用布局依据中的固定物件定位；有机位标注图时附入口
- 观察方向与目标：从何处看向何处；工位图区分看向工位与从工位向外看
- 机位高度：
- 俯仰角度：
- 景别与取景边界：
- 关键前景、中景与背景：从场景设计中选取本机位可见的环境与配套细节；不存在的层次明确写无，不为填满字段虚增陈设
- 自然遮挡与画外区域：
- 必须保持的结构及陈设关系：
- 采用的参考图及各自用途：总览／其他视图的具体版本、结构或外观采用范围；无图如实注明
- 正式视图入口与批准版本：未就绪时如实填写

### 6.2 场次需求与引用

- 场次与状态适用关系：按已进入制作的场次记录，不预填全剧未来场次
- 本场次需要呈现的空间与关键区域：从剧情活动与分镜需要选取，说明当场实际环境状态；不罗列全建筑作为同框要求
- 场景图取景及必须可见的空间关系：引用所需机位方案及分镜需求，说明需要的可见区域、自然遮挡和运动覆盖；不要求总览包含所有镜头背景
- 可复用的已批准场景图及适用条件：直接复用／总览兼任／需调整／缺图；指向场次分镜实际选图范围，不在此复制生成组输入表
