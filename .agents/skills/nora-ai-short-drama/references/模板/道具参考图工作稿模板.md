# 道具参考图工作稿模板

使用前读取[道具资料与参考图规范](../../../nora-drama-assets/references/道具资料与参考图规范.md)的第5.1节及适用的共用规则；命名、保存位置、填写要求与审批以该规范为准。本文件只维护可填正文，不替代规范。

技术字段、实际上传／执行来源、生成／审阅记录及交付前条目核验由对应脚本维护，按[图片交付与用户审核](../../../nora-drama-assets/references/核心参考图制作规范.md#851-图片交付与用户审核)区分Imagegen与ComfyUI分支。Agent按已选分支派发或提交、接收报告并展示，不手工补填或重复核验脚本已完成的技术条目；用户新决定仍按实际内容输入保存，不由技术成功推定。

每个PR一份，跨状态与剧集持续维护。 下方围栏内是产出正文，填写时使用产出标题，不将本模板文件名作为项目产出名。

道具状态延伸读取[统一资产状态规则](../../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#27-资产状态参考图统一规则)，仍使用本PR记录和状态字段。

采用后的引用、候选及监控收尾执行[开发流程8.5.2](../../../nora-drama-assets/references/核心参考图制作规范.md#852-图片采用替换与归档后的状态收尾)；当前处置填入“用户采用状态”，原因、具体候选及依据填入“用户决定原因与依据”。

规格与批准后处理读取[道具规范第3节](../../../nora-drama-assets/references/道具资料与参考图规范.md#3-三视图与状态规则)；超分执行及记录状态读取[图片超分执行规范](../../../nora-generation/references/ComfyUI-图片超分执行规范.md)。下方填写真实执行值，不在模板中另设默认尺寸。

当前采用字段及文件核对结论读取[开发流程8.5.1](../../../nora-drama-assets/references/核心参考图制作规范.md#851-图片交付与用户审核)；批准后处理状态读取[超分规范第4节](../../../nora-generation/references/ComfyUI-图片超分执行规范.md#4-文件核对保存与记录)，当前处置与历史收尾读取[开发流程8.5.2](../../../nora-drama-assets/references/核心参考图制作规范.md#852-图片采用替换与归档后的状态收尾)。下方状态字段选择当次实际值，不将未选定枚举或填写说明保留为当前结论。

ComfyUI故障补做授权、额度及执行条件统一读取[任务监控规范第3.3节](../../../nora-generation/references/ComfyUI-任务监控规范.md#33-故障补做授权与额度)，模板本身不授予额度。

## 章节职责

填写与补充统一执行[固定结构与补充写法](../共用规则/文件版本与工作稿规范.md#固定结构与补充写法)。下表说明固定正文各部分的分工，填写时不复制本表。

| 章节或区域 | 内容与写法 |
| --- | --- |
| 1. 当前正式资产 | 按表维护当前正式采用文件、版本、范围及决定入口；旧采用过程留在对应记录。 |
| 2. 逐次生成记录 | 每次实际生成建立一条记录，固定填写任务信息、输入参考、提示词与执行参数、执行结果、检查与采用五节。 |
| 3. 讨论与修改 | 逐项记录问题、备选、取舍和待定内容，写清日期与依据。 |
| 4. 审阅区 | 按生成记录及审阅轮次重复，固定填写审阅对象、文件与记录核对、展示与用户反馈、用户确认、采用与后续影响五节。 |
| 其他补充（按需启用） | 固定放在上述正文之后；只写已有章节无法容纳的事项，采用下方三项条目，不记录修改流水。 |

讨论按事项重复“讨论-001”等小节；编号接续已有记录，不因模板更新重排。生成及审阅仍使用各自已有编号和固定子节。

## 审阅区

上方正文的“4. 审阅区”是同一工作稿的一部分；按具体生成编号、候选及审阅轮次追加章节，生成条目与正式资产表引用该章节。批准决定、生成处置与正式资产的关联统一读取[开发流程8.5.1](../../../nora-drama-assets/references/核心参考图制作规范.md#851-图片交付与用户审核)；本模板不另维护审批规则。
