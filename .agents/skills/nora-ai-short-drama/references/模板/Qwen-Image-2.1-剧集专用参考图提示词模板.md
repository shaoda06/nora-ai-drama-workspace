# Qwen-Image-2.1-剧集专用参考图提示词模板

版本：v1.0；更新日期：2026-10-02。

用途、输入选择、规格、存放与采用按[剧集专用参考图规则](../流程规范/逐集目录与资产管理规范.md#21-剧集专用参考图)。使用前读取[Qwen提示词规范](../生成规范/Qwen-Image-2.1-提示词规范.md)及对应文生图／图像编辑共用格式；占位符执行其第1.5节，画风执行第1.6节。用途名不改变生成分支，不为每种姿态、互动或构图另建模板。

## 1. 依据已批准图片生成

生成方式：图生图，实际输入按上述规则选择。单图自然指代“图像”，多图使用与输入槽位一一对应的 `<image1>`、`<image2>` 等；JSON采用图像编辑三字段格式，画幅按本次方案填写，不自动继承白底或多视图排布。

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
依据{{实际参考图片指代及逐张用途}}，生成{{目标画面及需要明确的参考关系}}。
{{逐张说明继承的身份、服装、环境、物件或姿态，以及本次允许改变的内容}}。
采用{{景别与构图}}，观察位置为{{机位位置、高度、朝向及必要俯仰}}，取景包含{{所需范围、清晰区域及自然遮挡}}。画面为{{本次已确认的呈现形式}}。

内容描述：
{{实际出现的主体及其位置、姿态、朝向、视线或接触关系；无人物时只描述实际对象}}。
{{人物、物件和环境之间必须保持的比例、前后关系与支撑关系}}。
{{本次参考需要明确的静态状态、背景、材质及光线}}。
{{实际需要继承和允许变化的视觉细节，不重定义上游已确认设计}}。
```

## 2. 依据已确认需求生成

生成方式：文生图，无参考图片。JSON采用文生图两字段格式。采用条件按上述规则，不以省略已有参考图片重新设计角色或场景。

```text
风格要求：
{{项目已确认的画风与美术实现正文，原样引用，不缩写为风格名称，不自行改写}}

画面要求：
生成{{目标画面及需要明确的参考关系}}，采用{{景别与构图}}。
观察位置为{{机位位置、高度、朝向及必要俯仰}}，取景包含{{所需范围、清晰区域及自然遮挡}}。画面为{{本次已确认的呈现形式}}。

内容描述：
{{已确认的主体外观、服装或物件设计；只写实际出现的内容}}。
{{位置、姿态、朝向、视线或接触关系，以及主体与环境的比例、前后和支撑关系}}。
{{当前静态状态、背景、材质及光线}}。
```

本图的管理编号、适用镜头范围和批准状态记录在素材文档中，不进入模型正文；具体参考作用须转写为上述可见画面关系。
