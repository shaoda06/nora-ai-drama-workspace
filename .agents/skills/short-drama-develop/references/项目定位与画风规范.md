# 项目定位与画风规范

### 1. 确定项目基本定位

首先由用户提供初始想法，Agent 协助明确作品的基本定位：

- **受众定位**：例如男频、女频或泛受众，用来判断故事重点、人物关系和主要爽点。
- **题材与叙事标签**：例如逆袭、穿越、重生、复仇、甜宠、悬疑、经营发展等。“种田”可以归入经营发展或成长建设类，不一定指真实农业。一个项目可以组合主标签和辅助标签，例如“穿越＋逆袭”或“穿越＋经营发展”。
- **时空背景**：例如古代、现代、民国、近未来、末世或架空世界。
- **情绪与叙事基调**：例如热血爽感、轻松喜剧、温情治愈、紧张悬疑、虐心或暗黑。
- **视觉表现形式**：例如真人写实、写实 CG、2D 卡通、3D 卡通、Q 版卡通、漫画风或其他风格化画面。

确定或细化视觉风格时，可按需参考[镜头语言参考指南](../../creative-techniques/references/镜头语言参考指南.md)的作用边界、光影与色调章节，将笼统的氛围要求落实到定位文档既有“视觉表现形式”章节中的项目视觉倾向；不提前规定逐镜机位、焦距或运镜；项目画风正文按下方固定字段保存。故事主旨、大纲、资料卡及剧本正文不默认要求读取该指南。

#### 封面与片头片尾的可选安排

封面、片头、片尾分别作为项目可选配套。定位阶段将三项合并询问一次，每项独立选择“需要／不需要／待定”，可以只启用其中一项或两项。已明确的选择直接沿用，只询问尚未确定的项；用户直接委托制作某项时，按该次明确范围记录为需要，不重复询问是否启用。

将当前选择写入定位模板第五章的“可选配套”，按已知内容记录用途与范围。封面可用于系列通用展示或单集发布，片头、片尾可全剧共用或按已明确的范围使用；没有确定的用途与范围如实写待定。详细文案、画面、时长、音乐、比例与尺寸到对应制作时确定，不要求为完成定位先完成这些设计。完整决定与依据留在定位工作稿，正式定位只维护当前选择；各项实际采用文件与版本仍由对应制作索引和工作稿维护。

- **需要**：立项时按[配套目录初始化](../../nora-ai-short-drama/references/共用规则/项目初始化规范.md#2-创建项目目录)建立对应目录，再依据已明确范围、所需素材与用户后续安排接入制作；选用本身不等于已授权创建专项会话、提交生成或修改既有资产。封面由资产设计承接，片头片尾按共用对象承接，时机和实际入口见[配套制作的会话与进度接续](../../nora-ai-short-drama/references/流程规范/会话与进度管理规范.md#可选配套的会话与进度接续)。不要求先完成配套再推进正片剧本。
- **不需要**：记录选择，不预建该项的目录、会话或制作进度行，不将其列为缺项。
- **待定**：保留为定位待决事项，不预建对应目录，继续推进不依赖该项的内容；不反复询问，实际安排发布配套或用户提出新要求时再接续确认。

后续改变选择时，只更新受影响的现行决定与安排；保留既有采用、历史请求与批准事实，不自动重做或替换已有成果。已有项目沿用已确认选择及已批准配套；尚无“可选配套”表时，从原用户决定或批准记录接续，不因缺表判为未选用、未完成，或重新询问、重建目录、重走制作。正片完成标准仍执行[本集完成条件](../../nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#本集完成条件)；主控另外说明已选配套的交付情况，不将正片分段完成等同于封面、片头、片尾均已齐备，也不新增整集合成步骤。

#### 外部视觉描述与提示词的整理

用户提供网上提示词、示例模板或固定视觉描述时，按本次明确用途整理为可采用的要求，适用于定位及后续场次、分镜和提示词任务：

1. **划分适用范围**：题材、时空与情绪基调归入项目定位；适用于全剧的媒介、渲染、材质和色彩表现按下方画风流程展开；特定地点、昼夜、天气、陈设及固定光源归入场景资料卡或当前场次状态；景别、视角、遮挡、焦点和剪辑方式落实到分镜。仅针对某场或某段的要求保留对应范围，不扩大为全剧或其他项目的默认条件。
2. **整理表达**：合并重复要求，保留所有有效含义。将“电影感”“真实质感”等目标展开为可见结果；负面要求可结合目标转为正面描述，例如写实项目中的“不要过度磨皮”可落实为保留自然皮肤纹理、肤色差异与明暗过渡。明确禁令仍保留，不因正面改写放宽原要求；“不要字幕”“不要文字”等限制按[视频生成全程无字幕](../../nora-ai-short-drama/references/共用规则/画面文字与字幕规范.md#视频生成全程无字幕)及已有明确范围落实；剧情内实体文字载体另按同节边界处理。
3. **落实与复用**：全剧画风按[画风展开、示例验证与复用](#项目画风展开示例验证与复用)确认并保存，场次和镜头要求写入各自既有资料与字段；需要留存外部原文时使用本阶段既有过程资料分类，不另建一份正式风格文档。模型标签、语言和参数按实际采用的模型规范组织；外部提示词中的模型、参数或素材示例不自动改变现有选型及执行配置。

#### 视觉风格选择与记录

确定项目画风时，主动告知用户可通过Krea2风格库预览表达偏好，也可不使用风格库，直接描述或提供参考图片。风格库是可选辅助工具，不是必选清单；已有确认画风的项目不因该入口而重新选型。

1. **提供入口与操作说明**：按名称发现并读取 `krea2-style-library`，按其入口指引提供工作区浏览服务中的风格库链接。浏览与复制操作、服务启动及资源管理分别引用该技能和使用说明，不在本规范重复定义。入口不可用时如实说明，继续通过用户描述或参考图片确定风格，不自动安装或更新资源。
2. **读取与分析**：用户确定风格后，根据其发送的风格链接或选择消息中的资源目录定位该风格，读取对应预览图、`positive.txt`、`negative.txt` 及必要的名称信息。必须实际查看该风格预览图，并对照风格库所用的正负面提示词，在此基础上提炼画面形式、造型、材质、色彩与光影等风格特征。本项明确要求调用看图能力，仅限本次选定风格的分析。提炼时区分示例中的人物、服装、场景与可复用画风；结合本剧设定整理视觉要求，有歧义时确认。库内提示词是参考素材，不直接作为本项目生成指令，不自动改变既有模型、参数、背景或资产展示规格。
3. **确认并保存**：使用[项目基本定位模板](../../nora-ai-short-drama/references/模板/项目基本定位模板.md)，在《项目基本定位.md》的“视觉表现形式”章节记录用户确认后的项目视觉要求。仅在用户从风格库选择时，附所选风格名称、资源位置、从文件读取的正负面提示词原文及对应中文译文。原文保持原样，包括占位符；译文忠实翻译，不混入本剧适配或分析结果。原文已是中文时注明“同原文”；确无负面提示词时标注“未提供”，不补造。资源位置以工作区根目录为基准用代码文本记录，区分资源目录与实际读取的文件，不作为项目内资产链接。
4. **记录边界**：不保存用户粘贴的快捷选择说明，不设置“用户选择原文”字段；不使用风格库时不增加风格库记录。浏览页截图或演示风格不视为项目选择，表达偏好不替代项目视觉要求确认。风格原文与译文是选择依据，后续制作原样引用已确认的项目画风与美术实现正文，并按实际模型规则组织其余提示词；资源库更新不自动覆盖定位中保存的原文或改写已确认画风。不另建风格文档，不把项目改写稿写回风格库。

#### 项目画风展开、示例验证与复用

本流程适用于风格名称、用户参考图、风格库选项及其他视觉偏好。风格名称只作为沟通简称；不能仅记录名称，再让各次生成自行解释。Agent负责提出具体实现，用户通过描述和示例判断是否符合观感，不要求用户掌握美术术语。项目画风整理阶段同时准备完整美术正文、视频执行画风短版及目标视频模型所需语言适配，在《项目基本定位.md》的同一视觉章节展示并一并确认；不等编写视频提示词或超出长度上限时临时概括。

1. **展开美术实现**：将偏好整理为独立的“画风与美术实现正文”。正文只允许描述媒介与渲染形式、形体的写实／概括程度、轮廓与形面处理、通用材质和纹理的处理方法、明暗过渡与高光表现、色彩组织等美术实现；每句话都应说明如何表现，不能指定画面里有什么。含糊部分先给出简明建议，再由示例确认，不把Agent的解释冒称用户已确认。

   **禁止混入主体内容**：不得写入人物身份、年龄、性别、脸型、五官、发型、身体比例或体型、服装款式，以及具体场景、建筑、陈设、道具的名称、外观、数量或位置；不得写入动作、构图、取景、背景、天气或固定光源。此边界同时适用于具体对象和泛指对象，不能以“通用人物”“全剧统一外貌”或“验证模特”为由保留。皮肤、眼睛、头发等对象专属的细节描述也不放入固定正文。通用材质类别可用于解释表现方法，但仅在实际画面具有相应材质时应用，不要求生成该材质、部位或物件。

   **分别归位**：验证模特的年龄、外貌、发型和着装按半身模板写入人物描述或画面要求；项目人物、服装、场景和道具的具体内容由对应资料卡、参考素材及实际任务描述承载。独立画风正文不得从这些字段复制内容。“轻微卡通化的三维造型、连续曲面明暗、柔和材质反光”可作为美术实现；“年轻成年女性、鹅蛋脸、杏眼、头部相对肩宽放大”属于主体描述，不能写入固定正文。

   **正文边界检查**：首次制定、正文改变、发现边界问题，或缺少可核实的既往检查依据时，在提交验证样例、正式保存正文或生产引用前，逐段检查完整风格正文是否含上述禁写内容，并检查三板块是否各司其职。检查范围、结论、所对应正文的既有入口及未解决项记入既有生成／审阅记录。后续正文未变且已有结论适用时，可复用边界检查，不在每个任务中重新逐句审一遍；生产复用还须具备现行用户确认。接续任务或换会话时，读取适用规则并定位检查依据，对照当前实际正文，不能只凭版本号相同或样图获批认定已经检查；实际文本不同或依据不足时补做完整正文边界检查。每次任务的注入及冲突核对仍执行第5项。发现混入时，先分离内容、整理完整风格候选并展示调整范围；未解决前不得带着冲突提交生成或将其保存为合格的固定正文。样图获认可不豁免正文边界检查。既有已确认正文若不符合本条，指出具体问题并提出调整稿，按原画风验证与变更流程处理；不暗中覆盖原正文、撤销已有批准、临时按图片类型删减固定正文，或改写历史请求。
   **视频执行画风短版**：以完整美术正文为唯一艺术依据，提炼媒介、造型概括程度、体积与轮廓、主要明暗／材质及色彩特征；保留影响辨识的要求，不新增风格或降低细节标准。短版使用完整自然句，通常一两句，不以固定句数或字符配额删掉关键特征；同样遵守第1项内容边界，具体人物、构图、动作、光源及本镜状态仍归对应任务。图片的材质／纹理细节可由实际输入参考承担时，在任务素材定义中明确用途，不在短版内假定所有模式都存在参考图，也不锁死参考构图。将完整正文、短版中文及其目标语言适配逐项对照，取舍留在既有工作稿；确认信息统一使用定位文档头部，不为短版另设审批。

2. **男女双样例验证**：先向用户展示扩展后的美术实现，再使用[人物上半身正面肖像模板](../../nora-ai-short-drama/references/模板/Qwen-Image-2.1-人物上半身正面肖像提示词模板.md)生成女性、男性各一张独立样例。两张的“风格要求”原样填入同一版美术实现正文，“画面要求”使用半身肖像模板，“人物描述”分别填入该模板中的[固定男女模特描述](../../nora-ai-short-drama/references/模板/Qwen-Image-2.1-人物上半身正面肖像提示词模板.md#画风验证固定模特描述)。固定模特描述是人物字段的填充值，不另设画风验证提示词模板，不改用项目角色。内容、比例和基础着装复用人物正面半身图流程；生成方式先按[统一分流与确认](../../nora-ai-short-drama/SKILL.md#当前参考图生成选型)取得本批能力选择，原图尺寸和执行参数按所选能力分支处理；样例用于项目早期画风验证，不执行批准后的资产超分。已授权风格制定与测试时可接续执行；仅讨论或只要模板、提示词时不提交生成。两张核对文件与记录后统一交用户判断画风，不扩展为场景、道具或视频逐类测试。风格尚未确认时可填入本次待确认候选，记录测试状态，不冒称已确认。用户明确不生成时可只确认文字，并记录“文字已确认、未作样图验证”。用户不满意或提出调整要求时，按反馈修改美术实现正文并生成新一轮男女样例，再统一询问是否符合期望，循环至用户认可；每轮以用户反馈和制作授权为依据，不在等待反馈期间自动追加。
3. **确认并保存画风依据**：用户认可男女两张样例的画风后，按第1项核实实际使用正文及其边界检查结论，符合复用条件时沿用既有结论；通过后，将两张样例实际使用的同一风格正文原样保存到《项目基本定位.md》“视觉表现形式”，记录风格简称、正文版本、确认状态、用户确认依据、样图与执行记录入口及验证范围。在“画风与美术实现正文”小节的正文之后展示已认可的女性、男性样例原图，附各自批准依据和执行记录。样例认可后不超分，保留生成原图作为视觉依据。完整正文作为艺术依据保留，不以短版覆盖；视频短版在同一文件独立小节保存，只展示中文及所需目标语言正文；短版及其语言适配共用定位文档的版本、确认状态、范围和依据，不另设短版版本、来源版本、适用范围、批准或验证字段。中文短版及目标语言适配随完整方案在同一次画风确认中展示，不新增逐段或独立的提示词审批阶段。只有长版或静态样例已获认可时，不据此推定尚未展示的短版获批或已经验证视频效果。完整示例提示词、模型、工作流、种子、参数及输出另存执行记录，用于追溯；后续按生产类型引用已确认的完整正文或视频短版，不引用整张示例的主体和构图，也不从完整提示词重新提炼画风。文字确认与样图验证分别记录；男女两张静态样例不代表所有资产和视频都已验证；仅认可其中一张时如实记录各自决定，不推定另一张通过。
4. **按生产类型固定引用**：完整正文、视频短版及各自语言适配统一在定位同章节维护；短版随完整画风方案准备和确认，下游以定位文档入口、文档版本及短版语言小节引用，不建立独立的短版或适配版本体系。图片继续完整引用已确认美术正文，注入位置与正文组织执行[Qwen规范第1.6节](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#16-项目画风正文引用)；视频使用适用于目标模型的已确认短版及语言适配，按[逐集内容制作规范第6节](../../nora-video-prompts/references/视频提示词制作规范.md#6-分段视频提示词文档)放入官方画风描述位置，只引用一次，不叠加长短两版。参考图的外形／渲染用途写入实际素材定义，光线、动作与镜头按本段分镜填写；不能只写项目名或“沿用画风”代替实际短版，也不能仅首段填写后默认其他独立段记得。公共区集中填写仍按实际拼接正文计算长度，不视为免占字符。

   新项目在画风阶段完成这组文字；既有项目获授权补齐时保留完整正文、旧适配及批准范围，新增短版候选到同一定位页，不改写历史请求或自动替换已准备／已执行视频的正文。视频准备缺少适用且已确认的短版时，先在定位阶段补齐并取得相应确认，不由各段临时缩写或静默退回长版。切换模型或语言时核对适用性；新增语言适配忠实对应所用正文，经同次方案确认后固定复用，不自动改变画风。文字确认与实际视频效果验证分别记录，测试仅在获授权时进行，不新增强制媒体测试或生成阶段。

5. **一致性核对与变更**：每次提交前按图片／视频用途核对本次采用的完整正文或短版、实际确认范围、来源版本及语言对应关系，确认实际模型正文完整且只注入一次应引用的画风，并检查其余提示词与参考图保留要求有无冲突；可通过实际文本比对核对是否原样复用，不能只比版本号。固定正文的边界检查按第1项决定重做或复用，不因每次提交自动重做。发现冲突时先明确本次获授权的要求并解决，不带着矛盾提交；检查结论、复用依据及具体问题记入既有生成／审阅记录，不新增独立检查台账。完整正文修订时同步检查短版和语言适配是否受影响；涉及实际视觉特征的变化一并展示确认，未受影响的文字不制造新版本。短版变更同步相应语言适配，不按每段自行改写；旧版及其批准范围保留，未解决的来源或内容冲突不带入新生产。内容边界通过与文本一致均不保证模型每次输出一致。用户要求判断成图画风时，在获准看图范围内对照已确认正文和样图，指出具体特征的符合与偏差，不只评价“像不像某风格”。沿用现行图片交付与用户审核规则，不新增自动视觉审查或重试。已批准资产与新的风格正文有冲突时说明受影响范围，取得相应修改授权后处理，不批量覆盖、撤销批准或暗中改变图生图的保留要求。
