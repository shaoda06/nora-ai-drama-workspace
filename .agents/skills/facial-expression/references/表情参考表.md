# 表情参考表

下列写法是结合情境选用的候选，不是情绪与面部动作的一一对应公式。按[拆解方法](../SKILL.md#怎样拆解)选择幅度、可见部位和变化过程；图片只取一个瞬间。初始条目均未实测；“未验证”也包括已生成但尚无针对性反馈的写法。首次实际使用的告知与生成后反馈更新按[主文件](../SKILL.md#首次实际使用时的提示)处理。

## 笑意与亲近

| 表情／意图 | 可选的具体面部变化 | 使用条件与区别 | 验证情况 |
| --- | --- | --- | --- |
| 温和微笑 | 唇角小幅抬起，脸颊略提，眉间放松 | 不默认露齿；按互动对象确定视线 | 未验证 |
| 开心大笑 | 嘴逐渐张开，脸颊抬高，眼睛随笑意眯起 | 与浅笑区分幅度；是否出声沿原音频设计 | 未验证 |
| 忍笑 | 抿住嘴唇，唇角刚抬起又被压回，脸颊仍略鼓起 | 视频明确最后忍住还是笑出来；闭口不能覆盖说台词时段 | 未验证 |
| 礼貌微笑 | 短暂抬起唇角，眼周变化较小，随后收回笑容 | 不自动等同虚伪；静帧只写笑容保持时的状态 | 未验证 |
| 苦笑 | 嘴角勉强抬起，眉间仍收紧，笑容很快落下 | 同时保留难过与笑的冲突，避免夸张扭曲 | 未验证 |
| 得意 | 唇角抬起并短暂停留，下巴略抬 | 不必都写成单侧歪嘴；下巴属于可选辅助姿态 | 未验证 |
| 温柔／关切 | 眉间松开，视线停留在对方脸上，唇角保持很浅的弧度 | 情意由情境和回应共同成立，微笑不单独证明人物关系 | 未验证 |

## 冲突与压抑

| 表情／意图 | 可选的具体面部变化 | 使用条件与区别 | 验证情况 |
| --- | --- | --- | --- |
| 轻蔑／藐视 | 一侧唇角略提，上眼睑压低，视线扫过对方后移开 | 与愉快的笑区分；不要同时要求另一侧出现强烈笑意 | 未验证 |
| 克制的愤怒 | 眉头靠拢并压低，双唇收紧，下颌绷住 | 不自动加入吼叫；说话时解除持续闭口要求 | 未验证 |
| 爆发的愤怒 | 眉间紧皱，眼睑紧张，嘴随斥责张开，下颌保持紧绷 | 斥责必须已有剧情和台词依据；不自动增加血丝、青筋 | 未验证 |
| 委屈 | 眉头内侧略抬，唇角下沉，下唇轻轻前送 | 成熟人物或克制表演可减弱前送，避免一律嘟嘴 | 未验证 |
| 强忍眼泪 | 眼中积起泪光，抿紧嘴唇，下唇轻颤后收住 | 写清泪水是否落下，不同时要求全程无泪与泪流满面 | 未验证 |
| 失落 | 视线下移，唇角放下，面部逐渐松弛 | 不默认哭泣；视频可表现从努力维持到松开的过程 | 未验证 |
| 内疚 | 短暂看向对方后垂眼，嘴唇收拢，下巴慢慢降低 | 需要情境支持；低头本身也可能是害羞或思考 | 未验证 |

## 反应与犹疑

| 表情／意图 | 可选的具体面部变化 | 使用条件与区别 | 验证情况 |
| --- | --- | --- | --- |
| 惊讶 | 眉毛抬起，上眼睑打开，嘴唇短暂分开 | 按轻微吃惊或震惊控制幅度，不固定瞪到最大 | 未验证 |
| 怀疑／半信半疑 | 一侧眉毛略抬，眼睑稍收紧，嘴唇抿住 | 明确视线对象；不与同一时刻大幅睁眼叠用 | 未验证 |
| 害怕 | 眼睛张大，眉间收紧，嘴唇分开后又紧抿 | 视频描述顺序；不固定要求瞳孔剧变或脸色惨白 | 未验证 |
| 害羞 | 对视后垂眼，唇角轻轻抬起，嘴唇保持轻合 | 脸红只是可选细节，不绑定性别、年龄或固定人设 | 未验证 |
| 欲言又止 | 看向对方，嘴唇刚分开便重新合上，停顿后移开视线 | 视频保留开口到收住的顺序；静帧无法单独交代整个过程 | 未验证 |
| 困倦／疲惫 | 上眼睑逐渐下垂，闭眼停留变长，嘴唇和下颌放松 | 困倦与悲伤不能只靠垂眼区分；不自动增加黑眼圈 | 未验证 |
