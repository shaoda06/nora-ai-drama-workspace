# 表情参考表

第一版包含38项基础条目，按情境选择候选写法，不把情绪与面部动作当作一一对应公式。按[拆解方法](../SKILL.md#怎样拆解)选择幅度、可见部位和变化过程；图片只取一个瞬间。初始条目均未实测；“未验证”也包括已生成但尚无针对性反馈的写法。首次实际使用的告知与生成后反馈更新按[主文件](../SKILL.md#首次实际使用时的提示)处理。

动作变体附在相应条目的使用说明中，不另算基础条目；复合表情按文末[组合方法](#复合表情的组合方法)处理。表中低头、转脸、移开视线等辅助动作均须符合已确认分镜；变体和组合写法也均未验证，不继承基础条目的验证结论。

## 笑意与亲近

| 表情／意图 | 可选的具体面部变化 | 使用条件与区别 | 验证情况 |
| --- | --- | --- | --- |
| 温和微笑 | 唇角小幅抬起，脸颊略提，眉间放松 | 不默认露齿；按互动对象确定视线。“开心歪头”可用此表情配合已确认的歪头动作，不另列一种表情 | 未验证 |
| 开心大笑 | 嘴逐渐张开，脸颊抬高，眼睛随笑意眯起 | 与浅笑区分幅度；是否出声沿原音频设计 | 未验证 |
| 忍笑 | 唇角先抬起，脸颊略提，眼睛稍眯；随后将上唇和下唇明显压紧，两侧上扬的嘴角逐渐回落，直到嘴线接近平直；最后保持双唇压紧、嘴角接近水平，脸颊和眼睛仍留着笑意 | 视频明确最后忍住还是笑出来；闭口不能覆盖说台词时段。“捂嘴偷笑”仅在已有动作依据时加捂嘴，并按遮挡后的可见部位描述 | 条件有效：H3文生视频、文戏＋去油一采、8秒写实正面近景，同参数同种子对比后，用户确认本写法更像忍笑；抿唇、嘴角收回及眼颊留笑更明显。收嘴动作偏晚，精确时点尚不稳定；其他模型、静帧和捂嘴变体未验证。 |
| 礼貌微笑 | 短暂抬起唇角，眼周变化较小，随后收回笑容 | 不自动等同虚伪；静帧只写笑容保持时的状态 | 未验证 |
| 假笑／皮笑肉不笑 | 唇角抬起，眼周变化很小，笑容保持得略僵，随后收起 | 与礼貌微笑的可见动作可能重叠；虚假意图须由情境支持，不只凭眼周不动判断 | 未验证 |
| 坏笑／戏谑 | 一侧唇角缓慢抬起，眉毛略挑，笑容短暂停留 | 可以是逗弄或玩笑，不自动等于恶意或轻蔑；依既有互动意图选择幅度 | 未验证 |
| 尴尬微笑 | 嘴角短暂牵起，嘴唇随后抿住，笑容很快收回 | 与主动礼貌回应区分；不自动加出汗、脸红或左右乱看 | 未验证 |
| 苦笑 | 嘴角勉强抬起，眉间仍收紧，笑容很快落下 | 同时保留难过与笑的冲突，避免夸张扭曲；需要掩饰难过时另按强颜欢笑的组合方法 | 未验证 |
| 得意 | 唇角抬起并短暂停留，下巴略抬 | 不必都写成单侧歪嘴；下巴属于可选辅助姿态 | 未验证 |
| 温柔 | 眉间松开，眼睑与嘴部放松，唇角保持很浅的弧度 | 按既定对象安排注视，不由微笑推定人物关系。“摸头杀式微笑”“宠溺刮鼻”“拥抱式微笑”可配合本条或温和微笑，接触动作须有原表演依据 | 未验证 |
| 关切 | 眉头轻轻靠拢，眉头内侧略抬，双唇轻合，目光停留在需要观察的对象上 | 不默认微笑；区别于温柔的放松，也不直接演成愤怒的压眉瞪视。关注对象沿剧情与分镜 | 未验证 |

## 冲突与距离

| 表情／意图 | 可选的具体面部变化 | 使用条件与区别 | 验证情况 |
| --- | --- | --- | --- |
| 轻蔑／藐视 | 一侧唇角略提，上眼睑压低，视线扫过对方后移开 | 与愉快的笑区分；不要同时要求另一侧出现强烈笑意 | 未验证 |
| 克制的愤怒 | 眉头靠拢并压低，双唇收紧，下颌绷住 | 不自动加入吼叫；说话时解除持续闭口要求 | 未验证 |
| 爆发的愤怒 | 眉间紧皱，眼睑紧张，嘴随斥责张开，下颌保持紧绷 | 斥责必须已有剧情和台词依据；不自动增加血丝、青筋 | 未验证 |
| 赌气／闹别扭 | 双唇抿住，唇角略向下压，下唇可轻微前送 | 不等同于暴怒或哭泣；“气鼓侧脸”等变体的转脸动作由分镜决定，不默认鼓腮或嘟嘴 | 未验证 |
| 倔强／不服输 | 双唇压紧，下颌收住，眉间略紧，保持既定注视方向和面部张力 | 不服输的意图须有情境依据；不自动加抬下巴、怒瞪或挑衅动作 | 未验证 |
| 冷淡／疏离 | 唇线平直，眉眼变化很小，对对方的话仅作短暂、轻微的面部回应 | 可保持距离而没有贬低意味，与轻蔑区分；不因一时冷淡推定人物长期性格 | 未验证 |
| 漫不经心 | 眼睑略放松，嘴部自然松弛，对交流的面部回应较轻、较慢 | 不等于困倦或疲惫；是否移开视线依分镜，不自动增加哈欠或闭眼 | 未验证 |

## 悲伤与压抑

| 表情／意图 | 可选的具体面部变化 | 使用条件与区别 | 验证情况 |
| --- | --- | --- | --- |
| 委屈 | 眉头内侧略抬，唇角下沉，下唇轻轻前送 | 成熟人物或克制表演可减弱前送，避免一律嘟嘴 | 未验证 |
| 强忍眼泪 | 眼中积起泪光，抿紧嘴唇，下唇轻颤后收住 | 写清泪水是否落下，不同时要求全程无泪与泪流满面 | 未验证 |
| 默默流泪 | 眉头内侧略抬，嘴唇轻合，泪水沿脸颊滑下，嘴部没有明显哭喊动作 | 泪水已经落下，与忍泪区分；“低头垂泪”在已有低头安排时采用，核对取景是否仍看得见泪水 | 未验证 |
| 抽泣 | 下唇间歇颤动，嘴唇短暂分开又合拢，眉间持续收紧 | 视频写必要的间歇变化；呼吸与抽泣声沿原声音及表演安排，不自动新增音效或台词 | 未验证 |
| 放声大哭 | 眉头内侧抬起并靠拢，眼睑挤紧，嘴张开，唇角向下牵拉 | 哭声与泪水按已确认表演分别落实；静帧只表现哭泣状态，不能靠一张图证明“放声” | 未验证 |
| 失落 | 视线下移，唇角放下，面部逐渐松弛 | 不默认哭泣；视频可表现从努力维持到松开的过程 | 未验证 |
| 麻木／心如死灰 | 原先绷紧的面部逐渐松开，嘴唇微分，目光停在一处，对外界刺激的面部反应减少 | 变化前的紧绷须有原表演依据，已处于麻木状态时只写当前状态；与普通平静、冷淡靠情境和反应过程区分 | 未验证 |
| 内疚 | 短暂看向对方后垂眼，嘴唇收拢，下巴慢慢降低 | 需要情境支持；低头本身也可能是害羞或思考 | 未验证 |

## 反应与犹疑

| 表情／意图 | 可选的具体面部变化 | 使用条件与区别 | 验证情况 |
| --- | --- | --- | --- |
| 惊讶 | 眉毛抬起，上眼睑打开，嘴唇短暂分开 | 按轻微吃惊或震惊控制幅度，不固定瞪到最大 | 未验证 |
| 惊喜 | 眉毛和上眼睑先抬起，嘴唇分开，随后唇角上扬、脸颊抬起 | 重点是从意外转向开心；静帧选择其中一个时点，不同时要求嘴角下沉和上扬 | 未验证 |
| 震惊／愣住 | 眼睛突然睁大，嘴唇半张，刚进行的面部动作停住，短暂停留后才出现下一步反应 | 除幅度外还有反应停顿；停顿及后续反应沿分镜，不新增全身冻结或瞳孔剧变 | 未验证 |
| 怀疑／半信半疑 | 一侧眉毛略抬，眼睑稍收紧，嘴唇抿住 | 明确视线对象；不与同一时刻大幅睁眼叠用 | 未验证 |
| 困惑／不解 | 眉头轻轻靠拢，嘴唇微分后收拢，眉间的收紧短暂停留 | 重点是尚未理解，不默认认为对方说谎；需要等待解释的含义由上下文支持 | 未验证 |
| 试探／小心求证 | 眉头略收，双唇轻合，注视已指定的对象；对方回应后，眉间再按确认或仍疑惑的结果放松或保持收紧 | “试探”是交流意图，结合对方回应和既定结果选择变化，不能仅靠一副固定脸证明；不另编回答或结论 | 未验证 |
| 紧张／不安 | 嘴唇短暂抿紧又放松，眉间轻收，可出现短促眨眼 | 等待、心虚或社交紧张等意图沿剧情；不自动增加躲闪视线、出汗或发抖，也不等同害怕 | 未验证 |
| 害怕 | 眼睛张大，眉间收紧，嘴唇分开后又紧抿 | 视频描述顺序；不固定要求瞳孔剧变或脸色惨白 | 未验证 |
| 害羞 | 对视后垂眼，唇角轻轻抬起，嘴唇保持轻合 | 脸红只是可选细节，不绑定性别、年龄或固定人设 | 未验证 |
| 欲言又止 | 看向对方，嘴唇刚分开便重新合上，停顿后移开视线 | 视频保留开口到收住的顺序；静帧无法单独交代整个过程 | 未验证 |

## 复合表情的组合方法

以下是组合示例，不另计入38项基础条目，验证情况均为**未验证**。先确定真实情绪、准备显露或掩饰的意图、触发和结束状态，再从基础条目中选必要动作。分别描述同一时刻不同部位的状态，或按先后写变化；不能把两条完整写法直接叠加。图片只取一个有辨识度的瞬间，无法单独证明掩饰意图或整个转折。

- **怒极反笑**：在愤怒已经成立的情境下，可写“眉头压低，下颌绷紧；双唇松开，一侧唇角慢慢抬起，眉间仍未松开”。保留眉间与下颌的紧张，避免同时叠加开心大笑的眼颊变化；最后保持笑容还是收回，沿分镜决定，不自动新增笑声。
- **口是心非**：先明确“嘴上否认什么、实际掩饰什么”，不能一律按害羞处理。例如已确认“嘴上否认喜欢，却压不住开心”时，可写“说完否认的话后，唇角刚抬起便被压回，脸颊仍略提”。否认台词必须已有依据，抿嘴安排在话后，不覆盖说话口型；其他意图重新选择对应组合。
- **强颜欢笑**：在难过但想让对方放心等已确认情境下，可写“眉头内侧略抬，下唇轻颤后收住；随后牵起嘴角，维持片刻浅笑，眉间仍收紧”。与短暂苦笑的区别在于有意维持笑容掩饰难过；泪水和笑容是否最终失守按分镜，不自动添加。

动作变体与复合表情的反馈仍更新到对应基础条目的“验证情况”，简记实际变体或组合及其适用条件；只更新反馈确实涉及的部分，不把组合成功视为所有组成条目均已验证。
