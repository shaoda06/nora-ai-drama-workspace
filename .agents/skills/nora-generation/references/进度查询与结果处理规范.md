# 进度查询与结果处理规范

## 进度查询与结果处理

后台已有任务先读[后台工具的共用调用条件](../../nora-ai-short-drama/references/comfyui-scripts/README.md#后台任务查询与结果处理)，再按下列动作直达工具小节；不因此加载 `comfyui-api` 完整技能、上传提交说明或生成准备规范。获授权需要直接调用远端接口时才读取随包[comfyui-api](../../nora-ai-short-drama/dependencies/comfyui-api/SKILL.md)及对应固定工具章节，不把该分支作为后台不可用时的自动回退。

- **主动查询进度**：调用[后台状态查询](../../nora-ai-short-drama/references/comfyui-scripts/README.md#后台状态查询)，读取[原任务地址规则](ComfyUI-服务配置与任务提交规范.md#已提交任务的地址与恢复)、[查询方式](ComfyUI-任务监控规范.md#11-待提交跟进方式与间隔)、本次后台状态及更新时间；不加载创作和提交准备分支。
- **收到结果通知**：调用[最终报告读取](../../nora-ai-short-drama/references/comfyui-scripts/README.md#后台最终报告读取)，读取通知前已完成收尾的报告并自动确认收到；正常视频使用`delivery.video_count`及各任务的`review_url`，直接按[精简收尾](ComfyUI-任务监控规范.md#视频完成通知后的精简收尾)汇报数量和审核入口，不另确认、不调用登记、不展开固定映射。异常按报告的失败阶段查对应证据，必要时用[状态查询](../../nora-ai-short-drama/references/comfyui-scripts/README.md#后台状态查询)或显式恢复入口；读取[结果处理模板](../../nora-ai-short-drama/references/模板/ComfyUI-任务监控提示词模板.md)和相应媒体交付要求。正常图片及超分只使用报告的`delivery`展示清单（含绝对路径、实测规格、数量及审核链接），按[图片精简收尾](ComfyUI-任务监控规范.md#4-图片处理)直接展示报告中的成果和审核入口，不再核对文件、补常规记录或刷新网页；异常再查。
- **异常或恢复取回**：先用[后台状态查询](../../nora-ai-short-drama/references/comfyui-scripts/README.md#后台状态查询)核对失败阶段；只有取回失败才进入[后台取回重试](../../nora-ai-short-drama/references/comfyui-scripts/README.md#后台取回重试)。另读[异常检查与连接恢复](ComfyUI-任务监控规范.md#31-异常检查与连接恢复)、[故障补做授权](ComfyUI-任务监控规范.md#33-故障补做授权与额度)；视频后端故障接续读第5.1节。使用随包[comfyui-troubleshooter](../../nora-ai-short-drama/dependencies/comfyui-troubleshooter/SKILL.md)，不以诊断代替修复授权。

不创建同任务轮询或heartbeat，不自动重生成。已提交任务沿用原地址及任务ID；恢复不等于准备新的生成。

图片的取回、展示与记录读取[交付与用户审核规则](../../nora-drama-assets/references/核心参考图制作规范.md#851-图片交付与用户审核)，内容分析读取[看图边界](../../nora-ai-short-drama/SKILL.md#看图能力调用边界)。

视频结果交付、人工审核职责及客观异常处理统一读取[视频结果人工审核](../../nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#视频结果人工审核)。
