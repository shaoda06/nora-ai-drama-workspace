# 进度查询与结果处理规范

## 进度查询与结果处理

本规范适用于ComfyUI后台任务；Imagegen原生任务的完成消息与收尾恢复使用[Imagegen分支](Imagegen生成与尺寸处理规范.md#子代理执行与父代理交付)。按本次动作直接进入下方一个分支。工具的共同调用条件见[后台任务查询与结果处理](../../nora-ai-short-drama/references/comfyui-scripts/README.md#后台任务查询与结果处理)，已读时复用；普通后台任务不加载 `comfyui-api`、上传提交说明或生成准备规范。获授权直接调用远端接口时，才读取随包[comfyui-api](../../nora-ai-short-drama/dependencies/comfyui-api/SKILL.md)及对应固定工具章节，不把该分支作为后台不可用时的自动回退。

不创建同任务轮询或heartbeat，不自动重生成。已提交任务沿用原地址及任务ID；恢复不等于准备新的生成。

### 主动查询进度

已有组ID时优先使用`browser_tasks.py status --group-id`读取全组计数、状态和问题成员；需排查具体问题再按子任务ID查询。按[后台状态查询](../../nora-ai-short-drama/references/comfyui-scripts/README.md#后台状态查询)调用工具，读取实际状态和更新时间，沿[原任务地址规则](ComfyUI-服务配置与任务提交规范.md#已提交任务的地址与恢复)及[查询方式](ComfyUI-任务监控规范.md#11-待提交跟进方式与间隔)汇报。仅查进度不进入结果交付、创作或提交准备分支。

### 正常图片结果

普通图片按[批次通知规则](ComfyUI-任务监控规范.md#图片批次通知与超分静默)等整批就绪后通知；正常超分静默，历史已发出的正常超分通知只读report确认，不发送对话进度、完成回复或图片。

调用[最终报告读取](../../nora-ai-short-drama/references/comfyui-scripts/README.md#后台最终报告读取)，同次读取自动确认收到。直接按[图片完成通知后的精简收尾](ComfyUI-任务监控规范.md#图片完成通知后的精简收尾)使用报告的delivery展示清单中的绝对路径、实测规格、数量和审核链接；展示去重及用户审核沿其链接的图片交付规则，内容分析沿[看图边界](../../nora-ai-short-drama/SKILL.md#看图能力调用边界)。不进入视频分支，不再核对文件、补常规记录或刷新网页。

### 正常视频结果

收到后台通知时先静默读取report，不先发开场提示。按[整轮汇总规则](ComfyUI-任务监控规范.md#3-跟进与通知)核对本轮范围、共同记录中的已接收报告和交付情况；结果读取回执只表示本次接收，不能代替整轮交付记录。新任务组不会逐项发送正常成功通知，优先使用`groups`核对完整成员；历史逐任务通知的部分成功仍静默接收。整轮齐备时包含此前已读结果一起交付，不把should_notify_user=false当作跳过未完成交付的依据，也不只汇总new_task_ids。reused只表示通知ID曾被确认，不能代替实际结果去重。

按[视频完成通知后的精简收尾](ComfyUI-任务监控规范.md#视频完成通知后的精简收尾)读取报告并进入对应阶段的处理入口；报告提示业务记录尚需接续时，按[技术记录与业务记录的分工](../../nora-ai-short-drama/references/流程规范/会话与进度管理规范.md#技术记录与业务记录的分工)完成具体未覆盖项。完成通知按上述整轮范围汇总；异常进入下节。报告及采用收尾确认本集制作完成时，接续[完集复盘](../../nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#完集复盘与经验维护)；复盘复用后台已有核验，不重复结果登记，部分正常完成不触发整集复盘。

### 异常与恢复

定位失败阶段后，按[问题参考](../../nora-ai-short-drama/references/共用规则/制作问题与解决方案参考.md)检索对应现象、适用条件和已知无效尝试，用于选择排查方向；实际恢复仍按本节固定入口和原授权执行，解决后按[经验维护](../../nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#完集复盘与经验维护)留存结论。

有通知时先读最终报告，按其中失败阶段查对应证据；状态不足以判断时再用[后台状态查询](../../nora-ai-short-drama/references/comfyui-scripts/README.md#后台状态查询)，无通知的恢复任务先查状态。只有取回失败才使用[后台取回重试](../../nora-ai-short-drama/references/comfyui-scripts/README.md#后台取回重试)。直接定位[异常检查与连接恢复](ComfyUI-任务监控规范.md#31-异常检查与连接恢复)、[故障补做授权](ComfyUI-任务监控规范.md#33-故障补做授权与额度)的对应情况；视频后端故障读[第5.1节](ComfyUI-任务监控规范.md#51-后端故障后的视频接续)，登记或网页失败读[后台视频收尾与通知](ComfyUI-任务监控规范.md#后台视频收尾与通知)或图片处理中的对应后端收尾要求，复用后台已完成部分和既有重试额度。诊断需要时使用随包[comfyui-troubleshooter](../../nora-ai-short-drama/dependencies/comfyui-troubleshooter/SKILL.md)，修复沿下方[已有授权的登记修复](#已有授权的登记修复)判断，不把已有授权重新交给用户确认。

取回错误若已确认是登记的output根目录与原终态导出路径不符，按[取回配置修复](../../nora-ai-short-drama/references/comfyui-scripts/README.md#后台取回配置修复)仅修复原任务取回元数据，再接续原取回；不改原生成输入或重新生成。

#### 已有授权的登记修复

本节适用于已有成果的登记、关联记录和网页核验失败，ComfyUI、Imagegen及本地规格处理均按此判断。准备阶段预检全部关联更新的字段、原文唯一性、支持的填充标记及项目进度范围；实际登记保留并发变化检查。正常成功时“不重复登记”的要求不限制异常恢复。

用户已授权保存、采用或同步本批成果时，完成这些动作所需的本地登记修复属于原授权，由Agent自行处理，不让用户选择内部命令或再次确认已经批准的图片。先定位报告中的失败阶段，保留失败报告及经过，复用原任务、原成果、实际批准依据和已完成项，仅恢复未完成的登记或核验；按失败对象选择已有入口：图片、Imagegen及本地图片规格处理进入[图片成果登记修复](../../nora-ai-short-drama/references/comfyui-scripts/README.md#已有图片成果的登记修复)；视频取回后的待审登记进入[后台视频待审登记](../../nora-ai-short-drama/references/comfyui-scripts/README.md#后台视频待审登记)；已经批准的视频采用、定稿或网页收尾进入[视频批准一次收尾](../../nora-ai-short-drama/references/comfyui-scripts/README.md#视频批准的一次收尾)，沿原请求和结果接续。各入口只接续原授权范围内尚未完成的登记、采用、留档或网页核验，保留原生成关联、请求和批准；不手写替代登记，不重新生成或超分。

图片登记文字修复时，范围冲突先修正关联更新计划，不放宽阶段保护。例如项目道具的正式入库只更新道具阶段；已获授权同步的剧集进度单独维护，不能夹在道具收尾计划中。原提交、取回和审批证据保持原样；修复请求须与当前登记更新相符，填写实际原因和基于当前原文的完整替换文字，保留用户修改。工具保留修复前报告、原更新及修复请求；新增写入文件、改动用户确认或批准依据、源文字再次变化时停止，不自动覆盖。登记与网页核验实际完成后再报告修复完成。

修复不得更换已选成果、改变批准状态或扩大项目、对象与阶段的写入范围。需要新增生成或费用、缺少真实批准依据、涉及新的创作选择，或确实无法保留用户修改时，才向用户说明具体影响并请求相应决定；可在原授权内解决的命令和记录问题由Agent继续处理。

### 结果处理交接正文

需要编写结果处理的交接提示词或接续既有监控提示词时，使用[结果处理模板](../../nora-ai-short-drama/references/模板/ComfyUI-任务监控提示词模板.md)。日常查询和正常结果直接执行上方对应分支，不另加载模板。
