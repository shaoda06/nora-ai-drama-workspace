# ComfyUI-图生图执行规范

状态：现行图生图执行规范。\
版本：v1.56。
更新日期：2026-10-20。
用途：执行 Qwen Image 2.1 普通版带参考图编辑，涵盖单图与多图输入、画布设置、任务执行和验收。

提示词按 [Qwen Image 2.1 提示词规范](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md) 第 4 节整理，并依其[接入与适配](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#13-qwen-image-2-1-prompter接入与适配)使用qwen-image-2-1-prompter的Edit分支；素材规格、连续性和正式命名按 [开发流程第 8 节](../../nora-ai-short-drama/references/流程规范/短剧开发流程规范.md)。本文不重复规定提示词写法。

本执行规范的适用类型和源素材由[固定生成方式索引](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#11-图片类型专用模板索引)确定；修订任务执行[参考图统一修订规则](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#25-参考图统一修订规则)。下文节点能力和参数说明不扩大业务适用范围。

基础服装、场景和道具任务先按类型索引及专项生成规则确定分支与输入，再填写对应现有模板内的图生图大类；场景任务读取[场景生成规则](../../nora-drama-assets/references/场景资料与参考图规范.md#411-生成方式与参考输入)及[场景模板](../../nora-ai-short-drama/references/模板/Qwen-Image-2.1-场景参考图提示词模板.md)。资产状态任务读取[统一状态规则](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#27-资产状态参考图统一规则)及[资产状态模板](../../nora-ai-short-drama/references/模板/Qwen-Image-2.1-资产状态参考图提示词模板.md)。所选图生图任务按本文完成上传、连接及画布设置。

首帧任务先读取[首帧参考图规范](../../short-drama-storyboard/references/首帧参考图规范.md)，将其中的开始状态与画面要求落实到提示词；目录、命名和共用集内记录读取该规范第2、4、5节及其链接的集内素材规则。实际选择图生图时，本文只维护上传、连接、画布与执行映射。

制作、修订和结果核对按[Qwen参考图生成与修订的七项约定](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#22-qwen参考图生成与修订的七项约定)执行；工具选型见[技能入口](../../nora-ai-short-drama/SKILL.md#当前参考图生成选型)。候选先交用户审核；修订按[参考图统一修订规则](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#25-参考图统一修订规则)执行。

技术映射、规格核对及记录由脚本执行，职责以[图片执行分工](ComfyUI-服务配置与任务提交规范.md#图片执行分工)为准；Agent不因下列技术说明重新测文件、核对节点或抄写参数。

## 1. 输入与基准文件

- 提示词结果：`rewritten_prompt`、`wh_ratio`、`ratio_follow`，后两者恰有一个非空。用户明确指定直接使用原文时记录该选择，画幅仍单独确定。
- 输入图：按实际顺序列出本地文件、用途、版本与确认状态、真实宽高；资格与已有记录核对读取[输入参考图规则](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#24-输入参考图检查与记录复用)，各类型所需上游图、身体资料及技术测试边界读取[类型索引](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#11-图片类型专用模板索引)及其专项规则。本文件不另放宽输入条件。
- 输出要求：明确像素宽高、数量、PNG格式、保存位置和本次参数。

**基准不可原样提交。** 当前保留换装示例提示词和两个示例文件名，均为须替换的占位内容。每次复制为任务副本，替换实际图片、提示词、画幅、输出前缀与本次参数。执行副本不回写本地基准，也不保存或覆盖远端工作流。

## 2. 参考图上传与输入顺序

地址配置、选端及已提交任务恢复读取[工作区ComfyUI配置](ComfyUI-服务配置与任务提交规范.md#工作区-comfyui-配置)；素材上传到最终选中远端，执行接口由固定工具承担。

1. 为本次任务建立图片编号清单。`image_1`、`image_2` 对应实际输入顺序，必须与多图提示词标签一致；逐张记录身份、服装、场景或道具参考用途。
2. Agent登记本机素材和加载器绑定，后台轮到任务时上传至主节点；type=input、overwrite=false，使用响应中的真实name、subfolder、type。
3. 后台将实际返回的input相对路径填写到声明的LoadImage.inputs.image，使用正斜杠；Agent不把本机绝对路径或HTTP地址作为远端输入。
4. `LoadImage` 的第0个输出是图片，第1个是遮罩；参考图连接第0个输出。

当前两图连接：

| 提示词对应图号 | 图片路径位置 | 编码器连接 |
| --- | --- | --- |
| image_1 | `470.inputs.image` | `459:474.inputs.images.image_1 = ["470", 0]` |
| image_2 | `475.inputs.image` | `459:474.inputs.images.image_2 = ["475", 0]` |

**单图任务：** 在副本中删除 `459:474.inputs.images.image_2`，并移除未使用的节点 `475`；保留第一张图及其连接。不得把同一张图重复填入第二槽冒充双参考，也不得遗留示例服装图。

**增加参考图：** 每张图使用唯一的 `LoadImage` 节点ID，依次连接 `images.image_3` 等连续槽位。API中使用点号键，例如 `images.image_3`，不替换为嵌套对象或未经验证的图片批次。未使用槽位直接省略，不写空字符串或空路径。

导出画布对外提供10个图片入口，API基准只连接2张。当前服务端编码器定义列出最多16个槽位；扩展时按[执行前检查与复用](ComfyUI-服务配置与任务提交规范.md#执行前检查与复用)核对新增槽位定义与资源开销，不据此宣称多图效果已经验证。画布第五入口内部存在 `images.image_5_1` 的外层别名；API展开后应按编码器真实输入写 `images.image_5`，不能直接照抄外层名称。

单图正文可不带标签，执行端仍使用 `images.image_1`；这是提示词写法与输入字段的区别。已确定顺序后不为方便处理尺寸而偷偷调换图片。

## 3. 参数映射

以下编号只适用于当前API模板，重新导出后应重新核对。

| 信息 | API位置 | 当前基准与处理 |
| --- | --- | --- |
| 编辑正文 | `459:474.inputs.prompt` | 只填 `rewritten_prompt` 的值 |
| 反向提示词 | `459:474.inputs.negative_prompt` | 空字符串；CFG=1时不发挥常规负向引导作用 |
| 参考图预处理 | `459:474.inputs.resolution` | `0`，详见第4节 |
| 参考图VAE | `459:474.inputs.vae` | `["459:454", 0]`，保留实际图像编码链路 |
| 自定义画布开关 | `459:468.inputs.switch` | `false`；需要指定尺寸时改为 `true` |
| 画布比例 | `13.inputs.aspect_ratio` | 基准 `1:1 (Square)`；开关开启时生效 |
| 画布像素规模 | `13.inputs.megapixels` | 基准 `1`；按目标像素计算 |
| 画布对齐倍数 | `13.inputs.multiple` | 图生图基准为 `32` |
| 自定义画布宽高 | `459:456.inputs.width`、`height` | 默认连接节点13第0、1输出 |
| 自定义分支数量 | `459:456.inputs.batch_size` | `1`；开关关闭时这个节点的数量不决定输出批次 |
| 种子 | `459:458.inputs.seed` | 按[项目七类图片默认种子](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#26-项目七类图片默认种子)选择本次分支并完成输入种子核对，记录实际整数值 |
| 步数、CFG | `459:458.inputs.steps`、`cfg` | `25`、`1` |
| 采样器、调度器 | `459:458.inputs.sampler_name`、`scheduler` | `euler`、`simple` |
| 降噪参数 | `459:458.inputs.denoise` | `1`，不是未经验证的“身份保持强度”旋钮 |
| 参考条件缓存 | `459:469.inputs.device`、`dtype` | `auto`、`default`，首次测试沿用 |
| 输出文件前缀 | `461.inputs.filename_prefix` | 使用本次任务唯一前缀 |
| 保存格式 | `461.inputs.format`、`format.bit_depth`、`format.input_color_space` | `png`、`8-bit`、`sRGB`，点号键保持原结构 |

`wh_ratio`、`ratio_follow` 是任务元数据，不是此API图已有的节点输入，不能直接作为未知字段塞入编码器。它们必须转成第4节所述的实际画布设置。

该图通过编码器把参考图送入条件；编码器第2输出是按首张参考图尺寸建立的空latent。它不是传统“输入照片直接加噪后重建”的latent，因此不能照搬传统图生图经验，随意降低 `denoise` 来保证身份。

输出数量须按实际任务及所选画布分支确认。请求多张候选时优先建立独立任务，各任务的种子选择按[Qwen种子规则](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#26-项目七类图片默认种子)执行；更改批次须验证所选分支的实际数量，不能把参考图数量当作输出数量。

## 4. 参考图预处理与输出画布

### 4.1 两套尺寸机制

- `resolution=0`：各参考图保留自身尺寸并按节点逻辑对齐到32的倍数；不意味着一定逐像素不变。
- `resolution>0`：各参考图按约 `resolution²` 的总像素规模、保留比例并对齐到32的倍数处理。它不是指定输出宽度或高度，也不是强制把每张图变成正方形。
- `switch=false`：采样使用 `459:474` 第2输出的latent，画布来自第一张参考图预处理后的尺寸；节点13此时不控制输出。
- `switch=true`：采样使用 `459:456` 的空latent，画布来自节点13或明确填写的宽高。参考图仍由编码器参与条件，不因切换而省略。

自定义画布与第一张参考图差异较大时，构图和编辑定位可能改变。头部图生成全身属于有意重新构图，但身份、造型和留白效果仍须实测；不得为了凑尺寸偷偷拉伸、裁切参考图或最终结果。

### 4.2 已确定尺寸：设置自定义画布

`wh_ratio`非空时开启 `459:468.inputs.switch=true`。先按下表取得本次原生送审宽高及最简比例，再用这些整数替换 `459:456.inputs.width`、`height` 的节点13连接；节点13此时不控制画布，参考条件连接保持有效。执行端核对宽高均满足32倍数约束，不在本文件另定业务尺寸。

| 用途 | 送审尺寸与比例的规则入口 |
| --- | --- |
| 人物多视角图、角色多视角图、服装正背面图 | [人物专项规则](../../nora-drama-assets/references/人物参考图制作与记录规范.md#2-规格背景与布局) |
| 场景图 | [场景规范第4.1节](../../nora-drama-assets/references/场景资料与参考图规范.md#41-画面要求) |
| 首帧图 | [首帧规范第1节](../../short-drama-storyboard/references/首帧参考图规范.md#1-制作复用与画面要求) |
| 道具三视图、虚拟道具基础界面 | [道具规格](../../nora-drama-assets/references/道具资料与参考图规范.md#3-三视图与状态规则) |
| 资产状态参考图 | [统一状态规则的对应规格入口](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#27-资产状态参考图统一规则) |
| 剧集专用参考图 | [集内素材规则](../../nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#21-剧集专用参考图) |

场景和首帧图显式使用上述自定义画布，`ratio_follow`为空；参考输入不承担输出画布尺寸的决定作用。输入素材的版本与批准后处理依对应专项规范核对；参考图预处理仍按第4.1节单独设置，不因输入和输出同尺寸而自动更改resolution或切换画布分支。

`wh_ratio`填写目标宽高的最简整数比；近似推荐标签不替代精确宽高。原生送审与正式保存要求按对应规格执行，后处理读取[图片超分规范](ComfyUI-图片超分执行规范.md)。

`megapixels = 宽 × 高 ÷ (1024 × 1024)`。输入组合、画布分支及尺寸是否已验证，以对应实际执行记录为准。执行前核对节点限制，输出后读取实际尺寸；只改节点13却遗漏自定义开关不会正确切换画布。

### 4.3 跟随输入图画幅

- `ratio_follow="<image1>"`：若任务允许沿用第一张图预处理后的尺寸，可用 `switch=false`，记录原图尺寸与 `resolution`。若任务要求保持精确原尺寸，先检查预处理及32对齐是否改变它；冲突时先确定尺寸方案，不能默默取整后宣称一致。
- `ratio_follow="<imageN>"` 且N不是1：当前模板不会自动切到第N张图。保持图号顺序，读取该图真实宽高，明确目标尺寸后开启自定义分支。若只要求跟随比例、未指定像素，可沿用该图宽高，前提是满足已确认交付要求和节点对齐条件。
- 对比例选择器不支持的比例，可在任务副本中将 `459:456.inputs.width`、`height` 的连接替换为明确整数，并保持 `switch=true`；先检查节点限制与32对齐，再用真实输出验收。此时记录节点13已不控制该分支。
- `wh_ratio`与`ratio_follow`同时非空或同时为空、图号越界、目标宽高与比例冲突时，先修正任务配置，不提交。

图生图输入图和输出图可以拥有不同尺寸，但必须明确哪张是身份参考、哪张承担画布作用。提示词字段不会自动切换工作流分支。

## 5. 执行与恢复

入队准备、审批依赖及Agent／后台分工读取[提交规则](ComfyUI-服务配置与任务提交规范.md#新任务的选端与提交)；监控、成果取回、技术留档、通知及失败处理读取[监控规范](ComfyUI-任务监控规范.md)第1–3节。下列步骤补充本工作流的配置、输出映射与业务交付。

接口调用细节沿用 `comfyui-api`；正常提交不作远端能力预检；明确要求能力盘点时才使用 `comfyui-inventory`，获授权错误定位使用 `comfyui-troubleshooter`。

1. **内容准备。** 按专用提示词模板完成本次正文，明确类型／状态、素材顺序与用途、来源批准、执行授权及既定规格；记录实际内容依据，不手填技术副本和重复台账。
2. **一次装配并入队。** 使用[任务清单入口](../../nora-ai-short-drama/references/comfyui-scripts/README.md#一次装配与批量入队)，由工具从本节既有基准生成API／画布、上传与成果映射、种子及模板技术记录，统一准备检查后入队。只做准备加`--prepare-only`；已有完整资料可用旧式入口。入队成功只汇报数量并结束本轮，不继续补ID、进度或查网页。
3. **后台结果。** 后台完成上传、提交、取回、技术核验和生成／审阅记录，核验审核入口后再通知。Agent读取一次report并直接展示图片供用户审核；异常才查原附件，不因质量判断自动再生成。

任务中断时读取[已提交任务的地址与恢复](ComfyUI-服务配置与任务提交规范.md#已提交任务的地址与恢复)及[异常检查与连接恢复](ComfyUI-任务监控规范.md#31-异常检查与连接恢复)。仅导出、整理说明或检查配置不触发生成。

## 6. 验收与记录

### 提交前

Agent确认要表达的内容及本次授权，填写任务清单。脚本按[图片执行分工](ComfyUI-服务配置与任务提交规范.md#图片执行分工)完成字段格式、尺寸／比例、种子、输入关联、配对及固定配置检查，自动写技术记录。Agent只读取提交报告，失败时处理报告指出的具体缺项；不再按本节人工核对一遍。

### 生成后

后台完成技术核验、实际来源／上传绑定记录、候选审阅登记及网页核验后再通知。Agent只读取report并直接展示其中的`delivery`清单，不量尺寸、不读请求／响应、不补技术字段或检查网页。画面质量与设计符合度由用户审核，视觉分析仍按主技能边界执行。用户要求修改时再形成新的内容输入和授权，不因正常收尾自动改稿或再生成。

完成标准：请求和输出可追溯，真实规格已检查，文件与记录核对及用户审核状态已说明。技术测试结论与项目审批状态分别记录。


## 7. 异常纹理的单变量排查经验

用户明确反馈皮肤斑驳、过锐发丝、衣料失真或背景颗粒等异常，并授权种子对照时，核对已有输入和请求记录，按指定次数固定输入、提示词及其他参数，仅换有记录的新种子。结果直接展示给用户判断；如需agent视觉分析，先满足[看图能力调用边界](../../nora-ai-short-drama/SKILL.md#看图能力调用边界)，信息不足先询问。无效则保留结果，不自动追加对照或改动环境。

单变量对照是排查手段，不证明根因或效果保证。候选须由用户审核；本节不授权额外看图、生成或远端配置修改。

正常制作按[项目七类图片默认种子](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#26-项目七类图片默认种子)执行，内容调整按默认方式重新生成。异常时更换该类默认种子及单变量测试的记录边界由该规则统一规定；不把某项目的数值写成跨项目通用默认。
