# ComfyUI服务与任务提交规范

## ComfyUI服务与任务提交

初始化项目服务、准备或提交生成任务时，按[服务配置与任务提交规范](ComfyUI-服务配置与任务提交规范.md)读取对应章节；已提交任务的查询、取回及恢复读取其中的[任务地址规则](ComfyUI-服务配置与任务提交规范.md#已提交任务的地址与恢复)，监控方式另按任务监控入口。纯创作、提示词讨论和普通文本修订不加载服务配置与提交细则。

准备或提交ComfyUI任务，以及获授权直接调用远端接口查询或取回时，读取依赖表指定的 `comfyui-api`、[固定工具说明](../../nora-ai-short-drama/references/comfyui-scripts/README.md)及[服务配置与任务提交规范](ComfyUI-服务配置与任务提交规范.md)的对应章节。仅操作后台已有任务时，直接进入[进度查询与结果处理](进度查询与结果处理规范.md#进度查询与结果处理)。准备阶段的内容核对、工具本地技术检查、远端错误返回及提交时的报告复用由该规范维护；出现异常时使用 `comfyui-troubleshooter`，不以诊断代替修复授权。

图片及视频执行使用[服务配置与任务提交规范](ComfyUI-服务配置与任务提交规范.md)登记后台队列；上传、提交、监听、完成后取回及技术记录由后台执行。

依赖实际入口见[依赖表](../../nora-ai-short-drama/references/流程规范/技能依赖与协作规范.md#适用平台与技能依赖)。首次准备需要完整读取的执行规范按各分支要求执行；后续无变化内容复用；授权后只调用提交工具并读取结果，技术核验及报告由工具承担，不重新展开准备检查。
