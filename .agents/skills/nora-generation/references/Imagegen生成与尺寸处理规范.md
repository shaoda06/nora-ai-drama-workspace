# Imagegen生成与尺寸处理规范

版本：v1.1；更新日期：2026-10-21。

适用于已明确选用 Codex 内置 `imagegen` 的图片生成和编辑。这里的“本地生图”指当前会话可调用的内置工具，不表示模型运行在本机GPU。各类型的默认能力、备用能力及切换条件由[主入口选型](../../nora-ai-short-drama/SKILL.md#当前参考图生成选型)决定，本规范不自动改变选型。

## 1. 任务与提示词

- 按名称发现并读取当前可用的 `imagegen` 技能与实际工具说明，直接使用内置生成／编辑工具；不因需要指定尺寸改用API或CLI，不为此索要密钥。能力不可用时如实说明，不自行切换另一种生成能力。
- 人物、服装、角色、场景、道具及首帧仍使用原资产编号、资料卡、图片类型、视图布局、来源与审批依赖。内容依据沿[核心参考图](../../nora-drama-assets/references/核心参考图制作规范.md#8-核心参考图)及其专项；不增加一套Imagegen资产分类或目录。
- 复用相应图片模板中的画风、构图、主体及保留／变化要求，完整引用项目已确认的画风正文；把实际编辑目标与输入图用途写清楚。Qwen专有JSON、图像标签、种子及采样参数不强加给Imagegen，也不为Imagegen任务强制调用Qwen提示词优化技能。规格请求按第2节写入实际工具支持的参数或提示词。
- 编辑已有图片时实际传入指定源文件，不把文字复述当作传图。工具明确要求读取尚未看过的编辑输入时，只读取本次输入以完成编辑；不扩展为新输出的常规视觉审查。输出仍按[看图边界](../../nora-ai-short-drama/SKILL.md#看图能力调用边界)直接交用户审核。

## 2. 生成规格与原图送审

1. **先确定比例与正式尺寸。** 正式宽高沿人物、道具、场景或首帧专项，不因改用Imagegen另定像素标准。生成时明确目标比例和后处理后的正式分辨率，但不把请求值当作工具保证值。方图可请求1:1，服装正背面请求4:3；专项使用“16:9推荐尺寸”时，Imagegen可请求16:9，正式像素仍沿专项的既定宽高；项目另有画幅按已确认要求处理。
2. **接受预期的原生尺寸差异。** Imagegen返回的原生像素可能不同于请求值，通常低于正式目标；比例相近而非数学上完全相等也可作为候选送审。记录真实宽高、请求比例及正式目标，不因这类预期差异认定生成失败、自动重试或改换能力。不承诺某个固定原生尺寸、严格比例或“输入尺寸就是输出上限”。
3. **源图直接送审。** 保留完整原图，不为了凑严格比例或Qwen送审像素而先裁边、拉伸、缩放、补边或再次生成。仅展示、复制保存、读取尺寸和解码不改变画面。用户明确要求裁切、扩图等另按该授权制作，分别保留原始与处理后文件，不能混称原生输出。
4. **区分轻微误差与更换画幅。** 原图与目标近似比例的轻微差异允许随获批后的指定尺寸处理适配；这不授权把横图强行变成竖图、改变重要构图或接受明显变形。比例明显不符或用户指出构图问题时说明实际情况，按本轮授权处理；不自定通用误差百分比、补做次数或新的审批门槛。

文件与记录核对、用户采用状态、展示去重及计数沿[图片交付与用户审核](../../nora-drama-assets/references/核心参考图制作规范.md#851-图片交付与用户审核)。文件核对通过只指可解码、来源及实际规格已如实记录，不代表画面已通过用户审核。尚未获批时不处理成正式资产。

## 3. 来源与记录

- 将实际原生输出复制到该类型既有工作稿素材目录，以候选版本保存；原工具输出保留。一次实际生成继续累计原对象的生成编号，采用、失败、修订和超分仍回原记录维护，不另建Imagegen台账或重复项目副本。
- 使用原类型的生成／审阅模板，在现有字段填写实际工具名称、完整实际提示词、编辑输入及具体版本、生成用途、原生文件、真实宽高与格式、正式目标及当前用户决定。提示词与实际调用参数可保存到同前缀执行附件；未暴露的模型版本、种子、采样、client_id及prompt_id如实填未提供或不适用，不借用ComfyUI的值，不伪造后台任务ID。
- Imagegen生成阶段没有ComfyUI后台取回通知；当前执行者负责保存候选、上述文件核对和记录，按[交付前同步检查](../../nora-ai-short-drama/references/流程规范/项目浏览入口规范.md#交付前同步检查)同步已有网页，随后直接送审。不调用ComfyUI的report伪装原生生成收尾。超分阶段才沿实际远端任务、后台记录及静默通知处理。
- 原生尺寸不同于Qwen送审尺寸是本分支正常事实；不得把缩放后的图登记成原生送审图。下游引用正式图时，同时保留Imagegen原图、原批准章节与实际尺寸处理的来源链；非公开种子不编造为Qwen种子。

## 4. 获批后到正式尺寸

用户批准具体原图后，按[图片超分规范的Imagegen分支](ComfyUI-图片超分执行规范.md#imagegen原图的指定尺寸处理)接续：以该原图为输入，使用现有RTX图片处理工作流的指定分辨率方式到达专项正式尺寸；不按原图机械乘2，不重新调用Imagegen或Qwen生成内容。接受近似比例到正式尺寸的轻微适配，保留完整画面，不先裁边。

画风验证样例等原本无需资产超分的用途仍按相应专项保留原生图，不因本规范新增一次放大。

人物本体六视图与穿衣角色六视图的正式目标仍是人物专项规定的尺寸；Qwen分支的“原生即正式、不超分”不代表较低分辨率的Imagegen原图可以直接冒充正式图。原图已经达到正式尺寸且不需处理时，用户批准后直接保存；其他情况按实际需要的指定尺寸处理记录，不缩小再放大以凑一次超分。

指定尺寸提交使用超分规范中的统一任务清单`size`参数，不得省略目标而落入默认2倍模式，不改正式目标或绕过原图批准关联。仅在真实处理结果达到规定宽高、来源及正式保存核对通过后登记已采用；用户批准、实际处理与正式保存分别留证，不新增默认二次画面审批。
