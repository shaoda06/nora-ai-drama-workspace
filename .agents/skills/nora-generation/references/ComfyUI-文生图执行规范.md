# ComfyUI-文生图执行规范

状态：现行执行规范。\
版本：v1.47。
更新日期：2026-10-20。
用途：使用本地工作流副本配置参数、提交远端 ComfyUI、取回图片并完成验收记录。当前参数映射适用于 Qwen Image 2.1 普通版工作流。

提示词编写另见 [Qwen Image 2.1 提示词规范与模板](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md)，并依其[接入与适配](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#13-qwen-image-2-1-prompter接入与适配)使用qwen-image-2-1-prompter的T2I分支。本文件只接收该规范第 3 节的文生图两字段结果，不处理图像编辑的 `ratio_follow`，不重复规定提示词写法。

场景任务先按[场景生成规则](../../nora-drama-assets/references/场景资料与参考图规范.md#411-生成方式与参考输入)确定分支；仅所选文生图任务执行本文。

场景任务执行[场景专项规范](../../nora-drama-assets/references/场景资料与参考图规范.md)规定的场次需求、资料、画面规格与记录路径；本文只维护文生图技术映射，不另定义场景布局、审批或目录。

道具任务执行[道具专项规范](../../nora-drama-assets/references/道具资料与参考图规范.md)规定的展示方式、规格与生成／审阅记录；实际选择文生图时按本文设置节点并核验真实输出。

制作、修订和结果核对按[Qwen参考图生成与修订的七项约定](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#22-qwen参考图生成与修订的七项约定)执行；工具选型见[技能入口](../../nora-ai-short-drama/SKILL.md#当前参考图生成选型)。候选先交用户审核；修订按[参考图统一修订规则](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#25-参考图统一修订规则)执行。

虚拟道具基础界面任务执行[道具专项规则](../../nora-drama-assets/references/道具资料与参考图规范.md#虚拟道具基础界面)，沿用本文文生图节点映射与PR记录，不套用三视图布局。

资产状态参考图按[统一状态规则](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#27-资产状态参考图统一规则)及[图生图执行规范](ComfyUI-图生图执行规范.md)执行；基础服装、场景和道具任务先按类型索引选择分支，仅所选文生图任务执行本文。

## 1. 输入与工作流文件

本文件的节点映射、规格核对及技术记录由脚本执行，职责以[图片执行分工](ComfyUI-服务配置与任务提交规范.md#图片执行分工)为准；已备内容的纯提交不由Agent手工落实下列技术步骤。

执行前取得两类信息：

- 提示词结果：`rewritten_prompt` 与 `wh_ratio`。用户明确要求直接使用原文时，按用户要求处理并记录。
- 运行要求：目标像素宽高、图片数量、输出格式、保存位置，以及项目类别默认种子、已确定的CFG或采样步数等；种子取值统一按提示词规范第2.6节执行。

本地基准文件：

| 文件 | 用途 |
| --- | --- |
| [普通画布版](../../nora-ai-short-drama/references/comfyui-workflow/Qwen2.1-文生图-普通版.workflow.json) | 保留节点布局与子工作流，供可视化检查和后续修改 |
| [API 执行版](../../nora-ai-short-drama/references/comfyui-workflow/Qwen2.1-文生图-普通版.api.json) | 已展开子工作流，供程序配置参数并提交执行 |

**基准文件不可直接提交。** 两个导出版本保留1024×1024方图配置和占位提示词，不是当前参考图任务的成品配置。每次必须在任务副本中替换为本次实际提示词、比例、像素规模和输出前缀，并核对数量及采样参数；不得沿用示例内容直接生成。

由装配工具从配套画布基准配置并导出API任务副本，保存本次实际参数。基准维护边界读取[维护规范](../../nora-ai-short-drama/维护规范.md#工作流基准与任务副本)。

### 共用模型组合

本文与[图生图执行规范](ComfyUI-图生图执行规范.md)共用以下模型组合，由本节统一维护。

当前模型组合为主模型 `qwen_image_2.1_int8_convrot.safetensors`、编码器 `qwen3vl_8b_bf16.safetensors`、VAE `qwen_image_2.1_vae_bf16.safetensors`。除非用户明确要求，不更换该组合。执行前按[执行前检查与复用](ComfyUI-服务配置与任务提交规范.md#执行前检查与复用)由工具完成本地资料检查，正常提交不查询远端节点／模型能力；不支持的节点或模型由远端返回真实错误。

## 2. 提示词与参数映射

| 信息 | 当前工作流中的位置 | 处理方式 |
| --- | --- | --- |
| 正向提示词 | `459:452.inputs.prompt` | 提取 `rewritten_prompt` 的值，不把整个 JSON 当作提示词 |
| 反向提示词 | `459:452.inputs.negative_prompt` | 默认沿用本次已确定设置；需要单独编写时明确记录 |
| 宽高比 | `13.inputs.aspect_ratio` | 基准比例选项；明确宽高任务按第3节绕过该选择器 |
| 像素规模 | `13.inputs.megapixels` | 根据目标宽高计算，并核对对齐后的结果 |
| 对齐倍数 | `13.inputs.multiple` | 当前基准为 `32`；明确宽高的任务按第3节核对节点约束 |
| 图片数量 | `459:456.inputs.batch_size` | 按本次请求设置，当前基准为 `1` |
| 种子 | `459:458.inputs.seed` | 按[项目七类图片默认种子](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#26-项目七类图片默认种子)按核心类别或补充图片分支选值，作为运行参数记录 |
| CFG、步数 | `459:458.inputs.cfg`、`459:458.inputs.steps` | 当前基准为 `1` 和 `25`，按本次要求沿用或调整 |
| 文件名前缀 | `461.inputs.filename_prefix` | 为本次任务使用可辨认的前缀 |
| 输出格式 | `461.inputs.format` 及其关联字段 | 当前基准为 PNG；格式变更时同步检查关联字段 |

节点编号属于当前模板。工作流重新导出或调整结构后，应重新核对映射，不能假定编号永久不变。

官方增强器工具的输出记录中，`negative_prompt` 固定为空；这不代表 ComfyUI 没有反向提示词输入。当前工作流使用标准 KSampler，CFG 为 `1` 时，反向条件不发挥常规引导作用。修改 CFG 属于采样参数调整，应与提示词改写分开记录。

## 3. 分辨率设置

先读取下表对应规格，取得本次原生送审宽高及最简比例。首次生成与修订均在任务副本中将 `459:456.inputs.width`、`height` 的节点13连接替换为这些整数，保留batch_size及其他采样设置，记录节点13不决定本次画布。执行端核对宽高满足节点的32倍数约束；批准后处理读取[图片超分执行规范](ComfyUI-图片超分执行规范.md)。生成方式按[图片类型索引](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#11-图片类型专用模板索引)及其链接的专项规则选择。

| 用途 | 送审尺寸与比例的规则入口 |
| --- | --- |
| 人物上半身正面肖像、服装正背面图 | [人物专项规则](../../nora-drama-assets/references/人物参考图制作与记录规范.md#2-规格背景与布局) |
| 定位画风样例 | [定位画风验证流程](../../short-drama-develop/references/项目定位与画风规范.md#项目画风展开示例验证与复用) |
| 道具三视图 | [道具规范第3节](../../nora-drama-assets/references/道具资料与参考图规范.md#3-三视图与状态规则) |
| 虚拟道具基础界面 | [道具专项规则](../../nora-drama-assets/references/道具资料与参考图规范.md#虚拟道具基础界面) |
| 场景图 | [场景规范第4.1节](../../nora-drama-assets/references/场景资料与参考图规范.md#41-画面要求) |
| 剧集专用参考图 | [集内素材规则](../../nora-ai-short-drama/references/流程规范/逐集目录与资产管理规范.md#21-剧集专用参考图) |

`wh_ratio`填写目标宽高的最简整数比；近似推荐标签不替代精确宽高。生成后核对实际输出尺寸。

节点13使用 `megapixels × 1024 × 1024` 计算目标像素量再对齐宽高，公式为 `宽 × 高 ÷ (1024 × 1024)`。历史单次测试不保证其他任务的原生输出规格。所有新任务按[执行前检查与复用](ComfyUI-服务配置与任务提交规范.md#执行前检查与复用)核对目标值符合节点限制；不查询远端能力清单，生成后读取真实宽高；规格失败时记录偏差并讨论修正，不私自放大或裁切冒充达标。其他比例不直接假定为选择器选项。

只修改目标尺寸时，不需要同时修改 CFG。比较提示词时沿用该图片类型的项目默认种子，优先固定尺寸和其他采样参数；修改 CFG、尺寸或模型时，在记录中单独说明。

## 4. 执行流程

入队准备、审批依赖及Agent／后台分工读取[提交规则](ComfyUI-服务配置与任务提交规范.md#新任务的选端与提交)；监控、成果取回、技术留档、通知及失败处理读取[监控规范](ComfyUI-任务监控规范.md)第1–3节。下列步骤补充本工作流的配置、输出映射与业务交付。

1. **内容准备。** 按专用提示词模板完成本次正文，明确类型／状态、素材顺序与用途、来源批准、执行授权及既定规格；记录实际内容依据，不手填技术副本和重复台账。
2. **一次装配并入队。** 使用[任务清单入口](../../nora-ai-short-drama/references/comfyui-scripts/README.md#一次装配与批量入队)，由工具从本节既有基准生成API／画布、上传与成果映射、种子及模板技术记录，统一准备检查后入队。只做准备加`--prepare-only`；已有完整资料可用旧式入口。入队成功只汇报数量并结束本轮，不继续补ID、进度或查网页。
3. **后台结果。** 后台完成上传、提交、取回、技术核验和生成／审阅记录，核验审核入口后再通知。Agent读取一次report并直接展示图片供用户审核；异常才查原附件，不因质量判断自动再生成。

远端服务接口的详细调用方法由 `comfyui-api` 技能负责。本文件保留当前工作流的使用方式与验收要求。

## 5. 检查与验收

### 提交前

Agent确认要表达的内容及本次授权，填写任务清单。脚本按[图片执行分工](ComfyUI-服务配置与任务提交规范.md#图片执行分工)完成字段格式、尺寸／比例、种子、输入关联、配对及固定配置检查，自动写技术记录。Agent只读取提交报告，失败时处理报告指出的具体缺项；不再按本节人工核对一遍。

### 生成后

后台完成技术核验、实际来源／上传绑定记录、候选审阅登记及网页核验后再通知。Agent只读取report并直接展示其中的`delivery`清单，不量尺寸、不读请求／响应、不补技术字段或检查网页。画面质量与设计符合度由用户审核，视觉分析仍按主技能边界执行。用户要求修改时再形成新的内容输入和授权，不因正常收尾自动改稿或再生成。

完成标准：本次任务状态清楚，图片及记录已保存，真实规格及用户审核状态已向用户说明。

## 本地配套基准

服务地址读取[工作区配置规则](ComfyUI-服务配置与任务提交规范.md#工作区-comfyui-配置)。工作流基准与任务副本维护统一读取[维护规范](../../nora-ai-short-drama/维护规范.md#工作流基准与任务副本)。文生图使用普通版配套基准。由工具从配套画布配置并导出API任务副本，只注入已授权的提示词、素材和参数；所有占位提示词与素材必须替换。真实请求、参数、任务ID及响应仍保留在项目。
