# 图片生成执行规范

## 图片生成执行

先按[统一分流与生成前确认](../../nora-ai-short-drama/SKILL.md#当前参考图生成选型)取得本批能力选择，不把默认建议当作执行授权；已明确选择时沿用。Imagegen生成／编辑直达[Imagegen生成与尺寸处理规范](Imagegen生成与尺寸处理规范.md)，不加载Qwen采样与API映射；下列要求适用于Qwen／ComfyUI分支。

制作与修订读取[Qwen参考图生成与修订的七项约定](../../nora-drama-assets/references/Qwen-Image-2.1-提示词规范.md#22-qwen参考图生成与修订的七项约定)，输入来源、规格、审核及返修按各专项规范执行。

新任务先按[素材命名与保存](../../nora-ai-short-drama/references/共用规则/文件版本与工作稿规范.md#素材与执行附件)填写该类型适用的`formal`或专项对象身份，工具据该身份分配候选及版本；显式`output`也核对同一身份。图片类型用于选择模板、布局与种子，不能代替正式文件名。

- 已备内容的纯提交直接使用[一次装配入口](../../nora-ai-short-drama/references/comfyui-scripts/README.md#一次装配与批量入队)，职责见[图片执行分工](ComfyUI-服务配置与任务提交规范.md#图片执行分工)。项目种子表、输入原始种子、规格与固定技术配置由脚本读取、核对和写入，Agent不重复人工检查；已有批准及历史事实保持。
- 首次创作并准备该生成分支的内容时完整读取[文生图执行规范](ComfyUI-文生图执行规范.md)或[图生图执行规范](ComfyUI-图生图执行规范.md)，按任务配置参考图、执行API参数及输出尺寸；原画布保持不变，不生成任务画布。用户另有明确指定时按其选择处理，连续性按[核心参考图入口](../../nora-drama-assets/references/核心参考图制作规范.md#8-核心参考图)选择当前类型的专项要求，验收按[验收、记录与保存](../../nora-drama-assets/references/核心参考图制作规范.md#85-验收记录与保存)执行。
