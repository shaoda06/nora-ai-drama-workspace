# Nora 提示词管理

作为 Nora 主控按任务调用的工具子技能，也可直接使用；管理跨项目复用的提示词，不启动短剧制作阶段。浏览后台负责展示与读写，本技能负责内容收录、分类及操作选择。

## 定位与内容

- 在当前工作区根目录定位 `共享提示词/`、`提示词管理/` 和 `工作区浏览服务/`，不把某台电脑的绝对路径写入提示词。操作远端工作区时使用其实际目录或已授权服务，不将本机路径当成远端库。
- 先查已有分类和相关标题，再按需读正文；匹配用户指定的对象及公开／隐私归属，不默认加载整库。新内容优先复用合适分类，需要拆分时按可独立使用的用途分条。
- 分类已表达的含义不重复放进标题，例如“图片反推”下使用“通用”“摄影”。保留有区分作用的模型、用途等名称；重名时比较目标内容，不覆盖无关条目。
- 区分原文收录与优化改写。要求保留原文时只做获准的排版整理，不增删指令；来源信息按本次要求处理，不把某次省略来源的选择固化为全库规则。需要补充来源且未指定格式时，将说明与可复制正文分开。
- 已有条目默认保持其公开／隐私归属；新建沿用用户对本批的明确选择，归属未明确时先询问，不从来源公开或网页默认开关推断授权。
- 项目专用提示词仍按所属项目规范保存；收进共用库不代表项目已采用，也不授权提交生成。

## 保存与操作

文件格式、页面字段、刷新与回收规则的真源是[浏览服务的提示词管理说明](../../../工作区浏览服务/README.md#提示词管理)。普通录入按以下映射操作，无需逐次查后端源码；行为与说明不符时再定位相关实现。

| 页面含义 | 保存方式 |
| --- | --- |
| 公开；隐私开关关闭 | `共享提示词/{分类}/{标题}.md` |
| 隐私；隐私开关打开 | `提示词管理/{分类}/{标题}.md` |
| 分类 | 库内文件夹，可多层；主目录不带分类层 |
| 标题 | 文件名去掉 `.md`；不使用跨平台禁用字符 `<>:"/\|?*` |
| 正文 | UTF-8 Markdown，只保存提示词正文，不加 YAML 元信息或重复的管理字段 |

- **新增、修改、条目改名和移动**：本机批量操作优先直接处理上述文件；写入前核对目标及最新内容，不覆盖并发编辑。公开与隐私之间移动须有相应授权，完成后只保留目标库的一份有效条目。
- **分类整体改名／移动、删除、恢复或清空回收站**：优先使用现有网页操作，保留两库联动、冲突检查和回收记录。不要用直接删文件替代移入回收站，也不自行拼造回收站记录。需要批量接口时才读取[现有路由](../../../工作区浏览服务/backend/routes/prompts.py)及其实际请求要求，沿用服务的写入鉴权与版本冲突检查。
- 页面入口为浏览服务的 `/#/prompts`；使用该工作区实际服务地址。本机默认地址为 `http://127.0.0.1:8782/#/prompts`，不能将其用于推定另一台电脑的服务。
- 普通资料操作依赖现有格式和自动刷新，不修改共用前后端、不构建或重启服务。

## 核对与交付

- 写入后回读本次条目，核对数量、分类、标题、正文及公开／隐私归属。仅改名或移动时确认正文未变。
- 运行中的服务可通过 `GET /api/prompts` 核对列表，按返回的 `path` 请求 `GET /api/prompts/document?path=...` 回读正文；查询参数用 URL 编码。界面显示有疑问或用户要求查看时再到页面核对，不对同一结果反复检查。服务不可用时说明文件已保存、网页尚未核验。
- 按[工作区 Git 提交规则](../../../AGENTS.md#git-提交与推送)处理公开正文和本次改动；隐私库、回收站及临时文件保持忽略，不把本地提交称为已推送或发布。
- 简述实际完成的条目、分类、归属及核对结果；纯检索和讨论不写库、不提交。
