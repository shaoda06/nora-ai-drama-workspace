# 视频读取操作参考

只读当前分支。以下为Bash／zsh示例，路径和流编号必须替换为本次实际值；Windows使用已确认的可执行文件路径及相应Shell语法。每步检查退出状态和实际输出，失败时先说明原因，不把空文件或部分结果当作完成。

## 链接获取与下载

从分享文字中取出完整URL，保留必要查询参数，不把整段分享文案当作Shell命令。优先使用当前可用的下载工具；下面使用[yt-dlp](https://github.com/yt-dlp/yt-dlp#usage-and-options)，已有安装直接复用。提取器列表包含某个平台不等于当前链接一定可下载，结果以实际执行为准。

```bash
command -v yt-dlp
taskUrl='https://实际分享链接'
taskWork=$(mktemp -d "${TMPDIR:-/tmp}/video-study.XXXXXX")
yt-dlp --ignore-config --no-playlist --no-overwrites --no-simulate \
  --socket-timeout 20 --retries 2 --fragment-retries 2 \
  -P "$taskWork" -o '%(extractor_key)s-%(id)s.%(ext)s' \
  --print after_move:filepath -- "$taskUrl"
```

工具可自行处理支持的短链；若短链无法解析，先通过可访问页面取得真实落地URL再尝试。`--ignore-config`避免用户全局配置触发额外批量下载或后处理；`--no-playlist`限定本条视频，输出路径从实际完成结果读取，不根据标题猜文件名。需要现成字幕时可按素材语言添加`--write-subs --write-auto-subs --sub-langs 'zh.*,en.*'`；无字幕不等于无语音。

下载工具不支持、缺失或解析失败时，利用当前可用且已授权的页面／浏览器能力查看该视频播放页，尝试页面实际提供的下载入口或媒体地址。已取得可访问的直接媒体URL时可用`curl --fail --location`保存到本任务目录；需要的Referer等请求条件以实际页面为准，不猜地址或伪造请求签名。登录、验证码等访问障碍无法通过现有正常访问方式解决时，报告实际障碍；不擅自导出浏览器Cookie或读取账号凭据。

下载完成后进入下节读取媒体信息，确认不是HTML登录页、封面图片或未完成的`.part`文件，并核对目标作品与所需内容。复用本次`taskWork`，将`taskVideo`设为实际下载文件。失败报告写明卡在短链解析、页面访问、提取器解析还是媒体下载，保留必要错误摘要，避免输出Cookie或带凭据的地址。只有当前获取路径失败或缺少必要访问条件时，才请求用户提供本地文件。

## 检查输入与工具

```bash
command -v ffmpeg
command -v ffprobe
taskVideo='/absolute/path/video.mp4'
# 本地文件首次分析时创建；链接下载分支已创建则复用，不重复执行此行。
taskWork=$(mktemp -d "${TMPDIR:-/tmp}/video-study.XXXXXX")
ffprobe -v error -show_entries format=duration,start_time:stream=index,codec_type,codec_name,width,height,avg_frame_rate,start_time:stream_tags=language,title:stream_disposition=attached_pic -of json "$taskVideo"
```

从输出选择真实视频流、目标语言音轨和字幕流；排除`attached_pic=1`的封面流。没有音轨时继续可用的字幕或画面分析，不启动语音识别。多个语言音轨按任务选择，无法确定且影响结论时再询问。无需为纯字幕阅读安装FFmpeg。

## 字幕音轨与转写

### 已有字幕

独立SRT／VTT直接读取。内嵌文字字幕用实际流编号导出，例如字幕是全文件的第2号流：

```bash
ffmpeg -hide_banner -nostdin -n -i "$taskVideo" -map 0:2 -c:s srt "$taskWork/subtitles.srt"
```

这里的`2`是`ffprobe`返回的流index，不是“第几条字幕”。ASS转SRT仅保留阅读所需文字与时间，样式不作为画面证据；图片字幕不能用此命令变成文字，需要实际图片识别。网页字幕使用当前可用的合法访问方式取得，登录或访问失败时不猜内容。

### 提取音轨

下例仅处理原视频起点12秒、长度8秒的音轨，假设目标音频流index为1；整段转写时去掉`-ss`和`-t`。

```bash
ffmpeg -hide_banner -nostdin -n -ss 12 -i "$taskVideo" -t 8 -map 0:1 -vn -ac 1 -ar 16000 -c:a pcm_s16le "$taskWork/speech.wav"
```

输出为便于语音识别的单声道16kHz PCM WAV，只作分析副本；不以它替换音色参考或原素材。`-t`是长度，不是终点；记录本次原视频起点及选用音轨。立体声两侧有不同说话内容时，先按实际声道选择，不盲目混成单声道。

### 本地语音识别

先查现有命令和模型路径，再选择一种实现。命令存在不等于模型权重可用，测试用占位模型不能当作语音识别模型。沿任务授权补齐缺项，不默认下载安装、升级或切换到云端。

**OpenAI Whisper CLI**：检查`whisper --help`。下面的模型参数使用已存在的完整权重文件路径，避免仅填模型名而触发隐式下载；语言按素材确定，未知时省略语言参数。

```bash
taskWhisperModel='/absolute/path/existing-multilingual-model.pt'
whisper "$taskWork/speech.wav" --model "$taskWhisperModel" --language zh --task transcribe --output_format srt --output_dir "$taskWork" --device cpu --fp16 False
```

CPU为通用示例，已有验证的加速配置可复用；不固定要求某个模型大小。中文素材使用支持中文的模型，不选择仅英语的`.en`模型。

**whisper.cpp CLI**：已有该实现时先查`whisper-cli --help`，沿当前版本确认参数。

```bash
taskWhisperCppModel='/absolute/path/existing-ggml-model.bin'
whisper-cli -m "$taskWhisperCppModel" -f "$taskWork/speech.wav" -l zh -osrt -of "$taskWork/transcript"
```

读取实际生成的SRT，保留机器转写原文；必要纠错写成对照或另存整理稿。上述片段的字幕时间加回12秒才能用于原视频定位。字幕、音轨或视频流有不同起始时间时，依据`ffprobe`的`start_time`核对偏移，不能仅凭文件名或字幕第一句默认对齐。

## 按时间点抽帧

先确定需要查看的区间和精度，已提取的相同内容直接复用。补看其他区间或分辨率时，在本任务临时目录内新建抽帧子目录，避免图片与日志重名。下面假设真实视频流index为0、片段为12至14秒，选择该范围内原始帧序号为3的倍数的帧，形成约每3个源帧取1帧的观察序列：

```bash
taskFrames=$(mktemp -d "$taskWork/frames.XXXXXX")
ffmpeg -hide_banner -nostdin -n -i "$taskVideo" -map 0:0 -vf "setpts=PTS-STARTPTS,select='between(t,12,14)*not(mod(n,3))',scale='min(1280,iw)':-2,showinfo=checksum=0" -fps_mode vfr "$taskFrames/frame_%05d.png" 2> "$taskFrames/frames.log"
```

`setpts`以首个解码视频帧为零点，`select`保留所选源帧，`showinfo`在日志中记录每张输出帧的`n`和`pts_time`；第一个日志`n=0`对应`frame_00001.png`。读取这些真实时间并保留对应关系，不把“每3帧取1帧”换算成固定秒数。原视频存在起始偏移时，将该零点与字幕／音轨时间对齐；不要在选择后再重置时间戳。

需要该区间全部源帧时，将选择式改为`between(t,12,14)`；扩大取样间隔只用于概览，不能据此判定短暂动作不存在。细节不清时保留原始分辨率或按实际脸部位置取局部，不把低分辨率拼图放大当作增加细节。此示例为保留时间关系从原文件解码，长视频采用快速定位或预剪片段时须记录并加回真实偏移。

提取完先核对图片数量、日志时间与目标区间，再调用当前可用的图片查看工具逐批阅读；文件生成成功不等于已看过。保留本轮必要证据，后续问题复用相同区间与分辨率的已有图片，不重复提取全片。
