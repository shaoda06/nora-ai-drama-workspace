# 交付核对规范

### 交付核对

承接当前任务已确定的对象、范围及订正权限，按下表进入对应分支；一项任务涉及多类对象时合并所需检查，同轮已完成且依据未变的检查直接复用。只受托审查时交付问题，不写回来源；实际获授权修订时再执行文末同步要求。

| 当前交付对象 | 读取分支 |
| --- | --- |
| 原稿分析、定位、故事大纲、分集大纲或剧本 | [文字与计划](#文字与计划)，结合所属业务规则及当前采用依据 |
| 人物、场景、道具资料或图片提示词 | [资产与参考输入](#资产与参考输入)的对应类型；有叙事文字时合并文字与计划的适用项 |
| 场次／整集分镜、首帧设计与P段规划 | [分镜与分段](#分镜与分段)；只核对本阶段已有文本、资产依据及参考规划 |
| 视频提示词、素材就绪后的资料包或提交准备 | [视频提示词与实际输入](#视频提示词与实际输入)；使用最终正文、中文参考版及实际素材映射 |

### 文字与计划

按当前对象涉及的文字与计划检查：因果是否成立，人物动机与变化是否有行动依据，场景是否有作用，三类台词是否符合身份、知情范围和叙事用途，统计是否与正文一致，语言密度及留白是否适合项目节奏，情绪与时长是否相容，伏笔／信息／物品／伤势是否连续，动作与镜头是否可明确表达。问题说明、订正与交付边界按[文本审查问题与交付](文本审查与返修规范.md#文本审查问题与交付)执行。

### 资产与参考输入

按当前资产类型读取[资产设计入口](../../nora-drama-assets/SKILL.md#按资产与动作读取)指定的业务规则与模板，核对资料、图片用途、状态及来源。纯资料卡审查按卡片要求完成；图片提示词审查按对应图片类型与Qwen适配检查，不进入视频模型正文核对。

**场景及环境输入**：本集整体交付时核对全部实际场次；局部任务核对当前场次及受影响接续。相关场次均关联真实 SC 资料卡，必要空间设计已确认；按[首帧规范第1节](../../short-drama-storyboard/references/首帧参考图规范.md#1-制作复用与画面要求)检查实际环境表达及输入方案，对实际采用图片核对批准依据和可追溯版本，不把无需环境图记为素材缺项，不重复保存正式资产。未来剧集尚未建场景卡不影响本集完成；涉及图片或视频模型正文时，核对场景管理字段未泄漏到正文。

**道具及其图片**：按[道具规范第1节](../../nora-drama-assets/references/道具资料与参考图规范.md#1-制作时机与资产身份)核对本次范围内实际需要的道具资料及表达方式；只对实际采用的道具图片检查批准状态与引用版本，涉及模型正文时，核对道具管理信息未进入正文。

### 分镜与分段

场次与整集分镜送审前，先按[完整重做的范围与完成要求](../../nora-ai-short-drama/references/共用规则/制作返修与完整重做规范.md#完整重做的范围与完成要求)核对本轮实际覆盖范围及完成条件，再执行[场次与跨集接续检查](../../short-drama-storyboard/references/场次分镜制作规范.md#场次与剧集之间的转场和接续)，核对时间、空间、行动起点及前场结果；需要的过渡已经落实到正文与分段，调整后的时长及下游引用保持一致。

按[剧本覆盖核对](../../short-drama-storyboard/references/场次分镜制作规范.md#剧本到分镜的覆盖核对)检查本次分镜对来源剧本的转写，结合[文字与计划](#文字与计划)及下方[视听表达](#视听表达)核对因果、对白与连续性；涉及资产和首帧方案时选读[资产与参考输入](#资产与参考输入)的对应项。此阶段检查拟用素材及容量规划，不要求尚未编写的视频模型正文或尚未制作的实际素材就绪。

分镜送审时核对[参考输入规划与分段可执行性](../../short-drama-storyboard/references/视频分段规划规范.md#参考输入规划与分段可执行性)：各P均有容量结论或明确待决项，超限段已有处理方案。

因调整素材或细分产生的编号、时码、镜号对应与衔接变化须同步到已形成的索引、提示词及计划素材映射。

### 视频提示词与实际输入

按[模型正文内容核对](../../nora-video-prompts/references/视频提示词制作规范.md#模型正文的内容核对)检查本次最终正文、中文对应及实际拼接输入，结合[视听表达](#视听表达)及[资产与参考输入](#资产与参考输入)的适用项核对转写；上游覆盖结论已成立且未变时直接复用，缺项或变化部分才补核对对应剧本与分镜。

确认本集故事剧本、场次分镜及其视频分段、视频提示词之间剧情和对白一致；文档来源版本可追溯。参考图的复用用途明确、段间状态可衔接、没有模型上限内“秒数够但对白说不完”的片段。交付资料包不等于执行完成；实际生成记录、验收及恢复规则遵循 H3 执行说明。

视频资料包进入提交准备前，按[参考输入规划与分段可执行性](../../short-drama-storyboard/references/视频分段规划规范.md#参考输入规划与分段可执行性)用具体素材完成核对，不能携带未解决的容量超限。因调整素材或细分产生的编号、时码、镜号对应与衔接变化，沿已确定的修订范围同步到索引、提示词及计划素材映射。

### 视听表达

分镜及视频提示词分支按当前文本涉及的内容选读以下检查，落实到当前正文、上游及本阶段的规划或实际输入。图片提示词按对应图片规则处理；不因同属视听表达加载无关的声音与视频要求。

| 当前内容 | 直接核对项 |
| --- | --- |
| 动作、状态及可见过程 | [可观察画面转写](../../short-drama-storyboard/references/场次分镜制作规范.md#不可见感受与抽象画面描述的转写)、[镜头状态](../../short-drama-storyboard/references/场次分镜制作规范.md#镜头状态的变化延续与参考差异)；涉及显隐时加[显隐过程](../../short-drama-storyboard/references/场次分镜制作规范.md#显现与消失的过程) |
| 心理声音与现场开口切换 | [心理声／开口切换](../../short-drama-storyboard/references/场次分镜制作规范.md#心理独白与开口对白的切换) |
| 人物声音参考的规划或实际输入 | [人物声音关联](../../nora-drama-assets/references/参考音视频管理规范.md#3-人物声音的可选关联) |
| 虚拟界面 | [界面元素](../../nora-drama-assets/references/道具资料与参考图规范.md#虚拟界面固定元素与剧情内容) |
| 对白与动作容量 | [对白与动作时长核对](../../nora-ai-short-drama/references/共用规则/层级编号与时长规范.md#对白与动作时长核对) |

### 修订与交付同步

获授权根据用户反馈返修构图、机位、运镜、光影或焦点描述时，按问题参考[镜头语言参考指南](../../short-drama-storyboard/references/镜头语言参考指南.md)相关章节，落实到对应分镜、图片提示词或视频提示词；上游变化同步受影响的首帧与下游文档，图片修订仍遵循既有审批和生成授权。指南不增设验收项目或审批阶段，不授权agent审核视频质量、自动返修或重生成。

检查结论和未解决项使用既有记录保存，不增加检查表或审批阶段。

本轮形成或修订可交付资料后，先维护源文件、索引与必要进度，再按[交付前同步检查](../../nora-ai-short-drama/references/流程规范/项目浏览入口规范.md#交付前同步检查)核验浏览服务的同步状态和实际条目，不在本节另定重建条件或同步方式。
