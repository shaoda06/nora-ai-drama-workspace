# 交付核对规范

### 交付核对

场次与整集分镜送审前，先按[完整重做的范围与完成要求](../../nora-ai-short-drama/references/共用规则/制作返修与完整重做规范.md#完整重做的范围与完成要求)核对本轮实际覆盖范围及完成条件，再执行[场次与跨集接续检查](../../short-drama-storyboard/references/场次分镜制作规范.md#场次与剧集之间的转场和接续)，核对时间、空间、行动起点及前场结果；需要的过渡已经落实到正文与分段，调整后的时长及下游引用保持一致。

场次分镜完成、素材就绪及视频提交准备时，先按[剧本覆盖核对](../../short-drama-storyboard/references/场次分镜制作规范.md#剧本到分镜的覆盖核对)和[模型正文内容核对](../../nora-video-prompts/references/视频提示词制作规范.md#模型正文的内容核对)检查转写，再按[可观察画面转写](../../short-drama-storyboard/references/场次分镜制作规范.md#不可见感受与抽象画面描述的转写)、[镜头状态规则](../../short-drama-storyboard/references/场次分镜制作规范.md#镜头状态的变化延续与参考差异)、[心理声／开口切换](../../short-drama-storyboard/references/场次分镜制作规范.md#心理独白与开口对白的切换)、[显隐过程](../../short-drama-storyboard/references/场次分镜制作规范.md#显现与消失的过程)、[界面元素](../../nora-drama-assets/references/道具资料与参考图规范.md#虚拟界面固定元素与剧情内容)及[人物声音关联](../../nora-drama-assets/references/参考音视频管理规范.md#3-人物声音的可选关联)核对正文、上游与实际输入的一致性；时长和输入容量分别按[对白与动作时长核对](../../nora-ai-short-drama/references/共用规则/层级编号与时长规范.md#对白与动作时长核对)及[参考输入规划](../../short-drama-storyboard/references/视频分段规划规范.md#参考输入规划与分段可执行性)处理。检查结论和未解决项使用既有记录保存，不增加检查表或审批阶段。

获授权根据用户反馈返修构图、机位、运镜、光影或焦点描述时，按问题参考[镜头语言参考指南](../../short-drama-storyboard/references/镜头语言参考指南.md)相关章节，落实到对应分镜、图片提示词或视频提示词；上游变化同步受影响的首帧与下游文档，图片修订仍遵循既有审批和生成授权。指南不增设验收项目或审批阶段，不授权agent审核视频质量、自动返修或重生成。

在现有交付环节检查文字与计划：因果是否成立，人物动机与变化是否有行动依据，场景是否有作用，三类台词是否符合身份、知情范围和叙事用途，统计是否与正文一致，语言密度及留白是否适合项目节奏，情绪与时长是否相容，伏笔／信息／物品／伤势是否连续，动作与镜头是否可明确表达。问题说明、订正与交付边界按[文本审查问题与交付](文本审查与返修规范.md#文本审查问题与交付)执行。

本轮形成或修订可交付资料后，先维护源文件、索引与必要进度，再按[交付前同步检查](../../nora-ai-short-drama/references/流程规范/项目浏览入口规范.md#交付前同步检查)核验浏览服务的同步状态和实际条目，不在本节另定重建条件或同步方式。

核对本集全部实际场次均关联真实 SC 资料卡，必要空间设计已确认；按[首帧规范第1节](../../short-drama-storyboard/references/首帧参考图规范.md#1-制作复用与画面要求)检查实际环境表达及输入方案，对实际采用图片核对批准依据和可追溯版本，不把无需环境图记为素材缺项，不重复保存正式资产。未来剧集尚未建场景卡不影响本集完成；场景管理字段未泄漏到提交模型的提示词。

按[道具规范第1节](../../nora-drama-assets/references/道具资料与参考图规范.md#1-制作时机与资产身份)核对本集实际需要的道具资料及表达方式；只对实际采用的道具图片检查批准状态与引用版本，道具管理信息不进入模型正文。

确认本集故事剧本、场次分镜及其视频分段、视频提示词之间剧情和对白一致；文档来源版本可追溯。参考图的复用用途明确、段间状态可衔接、没有模型上限内“秒数够但对白说不完”的片段。交付资料包不等于执行完成；实际生成记录、验收及恢复规则遵循 H3 执行说明。

分镜送审时核对[参考输入规划与分段可执行性](../../short-drama-storyboard/references/视频分段规划规范.md#参考输入规划与分段可执行性)：各P均有容量结论或明确待决项，超限段已有处理方案；视频资料包进入提交准备前，需用具体素材完成核对，不能携带未解决的容量超限。因调整素材或细分产生的编号、时码、镜号对应与衔接变化须同步到索引、提示词及计划素材映射。
