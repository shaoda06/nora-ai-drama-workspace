# 文本自检与订正规范

### 文本交付前的自检与订正

本轮承担创作或修订的agent，将本地检查与本次适用的第三方方法合并为一次交付前检查，订正后交付；不按技能名称重复审同一稿或各写报告。同会话已读取且版本未变的方法直接复用；首次形成完整稿仍检查整稿，后续局部修订复查受影响内容及必要接续。分镜完整重做按[完整重做的范围与完成要求](../../nora-ai-short-drama/references/共用规则/制作返修与完整重做规范.md#完整重做的范围与完成要求)覆盖本轮全部范围，不沿用局部修订的检查范围。检查结论、订正和未解决项并入既有工作稿或编写依据，不增加独立阶段、评分表或审批。执行时机及产出如下：

大纲与剧本交付前，同时按[创作定位与爽感原则](../../nora-ai-short-drama/references/共用规则/创作定位与原稿规范.md#创作定位与爽感原则)核对观众的期待是否具体、较量是否推进、回报是否接得住铺垫；延迟兑现时是否仍有进展，反转是否有依据。只写“节奏紧凑”“爽点密集”等评价不能代替正文中的实际事件；问题并入本轮既有自检与订正，不以反转数量评稿。

第3步剧本及第4步场次分镜的合并自检同时按[山音方法的范围与适配](../../nora-ai-short-drama/references/共用规则/山音方法适配规范.md#山音方法的范围与适配)自动复用本轮山音方法，未读时补读相关章节；第6步提示词不另用山音改写剧情。第3步剧本、第4步场次分镜及第6步视频提示词形成初稿或实质性修订后、文本交付前，默认读取 `short-drama-review` 的实际安装入口，按[文本审查的方法补充](文本审查与返修规范.md#文本审查的方法补充)选用当前阶段的参考方法，与下列既有检查一并执行。仅改错字、格式或记录时不重做全文审查；无关阶段与媒体结果不纳入。检查后按本节既有授权边界订正，再交付，不另设审查会话或批准轮次。

- **第3步，整集剧本初稿或修订稿送审前**：先按[对白诊断范围与接续](../../short-drama-write/references/对白与表演修订规范.md#对白诊断范围与接续)确定检查范围，在该范围内按[台词设计、节奏与统计](../../short-drama-write/references/对白与表演修订规范.md#台词设计节奏与统计)核对交流是否充分展开及连续无对白段的用途，再按[人物性格与当下处境的台词适配](../../short-drama-write/references/对白与表演修订规范.md#人物性格与当下处境的台词适配)及[动作、情绪与标点的联动](../../short-drama-write/references/对白与表演修订规范.md#动作情绪与标点的联动)连读完整交流，处理人物口吻、接话、因果与情绪变化，核对场次及上下集承接；初稿交接、回稿检查及批准后的接续按[豆包台词润色交接](../../short-drama-write/references/台词润色交接与回稿规范.md#豆包台词润色交接与回稿检查)执行。
- **第4步，每场镜头正文及P段规划写完、分镜送审前**：按[覆盖核对](../../short-drama-storyboard/references/场次分镜制作规范.md#剧本到分镜的覆盖核对)、[镜头状态](../../short-drama-storyboard/references/场次分镜制作规范.md#镜头状态的变化延续与参考差异)、[时长核对](../../nora-ai-short-drama/references/共用规则/层级编号与时长规范.md#对白与动作时长核对)及[转场接续](../../short-drama-storyboard/references/场次分镜制作规范.md#场次与剧集之间的转场和接续)，把整场按播放顺序连起来检查，并按[分镜正文的清楚表达](../../short-drama-storyboard/references/场次分镜制作规范.md#分镜正文的清楚表达)逐句检查镜头说明和分段摘要，再按[表演指代与时点要求](../../short-drama-write/references/对白与表演修订规范.md#动作情绪与标点的联动)核对具体所指；问题落实到镜头正文、声音时点及分段时间表，不能只逐镜检查字段是否填满。
- **第6步，实际采用素材就绪、编写提示词前**：用实际文件及版本复查分镜与参考的差异，按第6步既有要求处理状态和素材映射，不直接沿用此前假定的输入。
- **第6步，提示词完成或修订后、交付或提交生成前**：按[模型正文的内容核对](../../nora-video-prompts/references/视频提示词制作规范.md#模型正文的内容核对)，分别完成格式与内容核对；按[语言与命名](../../nora-video-prompts/references/视频提示词制作规范.md#h3模型正文的语言与命名)及[切镜表达](../../nora-video-prompts/references/视频提示词制作规范.md#h3切镜与接续表达)核对实际拼接后送给模型的完整内容，保留上游已经成立的动作顺序、人物表演、台词与声音限制；提交参数和连接仍按第7步执行规范核对。

检查中发现的漏写、前后矛盾、重复动作、错误顺序或转写丢失，已有确定依据且属于本轮授权创作／修订范围的，先订正正文并同步受影响的相邻镜头、分段和下游引用，再交付。需要改变已确认的核心剧情、人物、关系或视觉方向，或存在无法从已有资料确定的创作分歧时，说明具体位置、影响及待决定内容，不自行补造。已经获得对应修改授权的直接落实，不重复请求确认。

返修后重查修改处及受其影响的前后衔接、时长和下游文本；未受影响且依据未变的内容复用既有检查。交付简述已检查和订正的重点，只列真实未解决项，不逐句展示内部推演。视频生成后的问题按[制作返修的上游归属](../../nora-ai-short-drama/references/共用规则/制作返修与完整重做规范.md#制作返修的上游归属)判断，不把模型没有执行正确文本一律归咎于分镜并反复改稿。
