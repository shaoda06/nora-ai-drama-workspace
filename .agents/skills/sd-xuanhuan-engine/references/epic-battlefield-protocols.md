# 史诗战场协议（R3 玄幻 · 一镜到底群战专章）

> **来源**：吸收自用户提供的玄幻一镜到底参考稿（30s 单人 vs 满屏兽潮）。
> **定位**：本协议是 **R3 玄幻档「一镜到底 + 群战 + 武器形态变化」**的补充规则层，与 `core-combat-laws.md`（黄金颗粒度/双向力量互换）、`grand-scale-domains.md`（尺度四件套）并列使用。**冲突时**：镜头颗粒度以 `core-combat-laws.md` 为准，大场面尺度以 `grand-scale-domains.md` 为准，本协议只管"阵营色彩 / 位移 / 群战数量 / 武器形态 / 蓄力收束"五件事。

---

## 〇、适用场景

- 单人（或少数人）对**满屏敌军/兽潮/军阵**的清场式战斗；
- **一镜到底**（无切镜、无空镜转场）的高动态战斗总纲；
- 战斗中存在**武器形态变化**（如一剑化双刀）、**超高速位移**、**阵营色彩对立**的场面。

不适用：双人对招、室内近身搏击（走 `close-quarters-engine.md`）、文戏。

---

## 一、阵营色彩锁（Faction Color Lock）

已采用阵营配色时，在既有场景设定和逐镜正文中维护其对应关系；主角、敌人或不同阵营不预设固定冷暖。辨识方法及受光、接触混色与固有色的区别统一按[对抗辨识与色彩](xuanhuan-elements-vfx.md#2-对抗辨识与色彩)，不另设一套颜色禁令。

一镜到底或群战中，在交叉、遮挡与重新显露后，仍需能追踪谁发出的攻击、正作用于谁。结合已定角色轮廓、武器、法术形态和运动路径维持归属；同色群体可用站位与队形变化交代，不把颜色视为唯一线索，也不因局部反光改变角色身份。

---

## 二、超音速位移 · Z 型折线三件套（Supersonic Z-Line）

> **一句话：高速位移按"斜前→锐角折返→斜前"的 Z 字折线突进；每个折点必须留三件套。**

**三件套（每个折点必现）**：

| 件 | 内容 | 写法 |
|---|---|---|
| **① 起点残影** | 折点处原位置留下未散的主角残影 | "起点处一道赤金残影未散" |
| **② 轨迹连线** | 从上一折点连向本折点的熔金轨迹 | "一道熔金轨迹自残影连向落点" |
| **③ 终点凝实** | 落点处光聚凝实、主角显形 | "落点处赤金光聚、主角身形骤然凝实" |

**附带**：每个折点炸开**锥形音爆云 + 环形气浪**；残影保留 **0.1~0.2 秒**后凝实再溶解；三段轨迹在空中**连成可见的 Z 字形光轨**。

**机位候选**：需要跟随时可贴追折点；需要看清完整轨迹时可固定俯拍。甩镜、过冲和模糊按可读性选择，不要求每个折点都换运镜。

**与总控条款的关系**：本协议是 `grand-scale-domains.md` 尺度四件套在"高速位移"上的具体化；**Z 型折线 = 3 次锐角变向**，段内不切镜（一镜到底）。

## 三、群战递增铁律（Monotonic Escalation）

> **一句话：敌人的数量随时间单调递增、绝不回落——直到清场那一下。**

| 阶段 | 密度 |
|---|---|
| 开场 | 数百只铺开（若选择直接进入满屏兽潮的开场） |
| 中段 | 上千只；精英单位（持械兽将/精锐兵）开始成排踏出 |
| 终局前 | 密密麻麻挤满画面每一处缝隙，连天光都被遮去大半 |
| 清场 | 大招一扫而空 → 清净 → 尾帧定格（数量骤降只允许发生在**最后一次清场**） |

**四条铁律**：

1. **单调递增**：任何一帧的任何方向都必须看到成百上千的敌人，**绝不回落**（"打着打着敌人变少了"= 违规）；
2. **规模成片**：每一招的杀伤规模必须"成片/成排/上百只"，**禁单个点杀**；
3. **优先"补员"**：清掉一部分后，**从更远处涌来更多**（数量继续递增），不许清空一片就留白；
4. **精英分层**：精英单位（持械兽将）数量**逐幕递增**（零星 → 成排 → 整队压上 → 四面围杀）。

**为什么**：单人 VS 群战的爽感来自"**永远打不完的压迫感**"；数量回落会让观众觉得"快赢了"，张力立刻泄掉。

## 四、武器形态单次变形（One-Time Weapon Morph）

> **一句话：全片只允许武器变一次形；这次变形必须完整演出，绝不凭空换模。**

**三铁律**：

1. **唯一性**：全片武器形态变化**只发生一次**——严禁中途再变形态、严禁凭空多出一把武器、严禁变形后合并回原形态；
2. **过程可读**：交代当前剧情需要的变形步骤；本方案选一镜到底时保持连续，多镜方案也可用切镜呈现，不把切镜本身当作过程缺失；
3. **连续可信**：变形**不是"换模型"**——是从"实体 A"通过可见的物理/能量过程"长出"实体 B（有前摇、有过程、有结果）。

**五步变形模板**（参考稿「一剑化双刀」结构，可迁移）：

```
① 核心反应：剑脊脉线亮至极限、剑体剧烈震颤（能量在上限积压）
② 一分为二：从中脊一裂为二，吞口/护手左右各分一头，器灵/龙影脱出盘旋一周
③ 各向延展：两段各向两端延展成刃，一刃暖色熔岩、一刃暗色沉敛（一明一暗）
④ 配件展开：柄尾流苏/链坠甩出并燃亮
⑤ 成式定姿：双手各接一器、交叉成起手式，一声金属咬合脆响荡开（涟漪/气浪）
```

- **全程约 0.4s**（快但不"瞬移换模"）；
- **分化前**持原武器要有明确起势（举过顶收束能量）；**分化后**直接接第一招；
- **机检点**：核对变形关键步骤是否可见；特写与冲击帧按需要选择，不强制绑定（见 `sd-combat-engine/references/impact-frame-and-banlist.md`）。

**写作禁区**：❌"剑突然变成两把刀" ❌"不知何时手上多了一把刀" ❌"双刀又合成一把剑" ❌用剪辑/切镜掩盖变形过程。

## 五、蓄力涡旋与尾帧定格（Charge Vortex & Freeze Frame）

### 5.1 蓄力涡旋写法（大招前）

终极技前的最强蓄力，用**"天地能量向武器汇聚"的可见涡旋**表现：

```
双器交叉高举向天 → 周身所有光效/火焰疯狂向器身汇聚 → 天光被吸引形成巨大涡旋
→ 涡旋中心盘踞器灵/龙影 → 身体压低、前足虚点、后足蹬满（蓄势待发的起手）
```

- 蓄力期间**四周敌人仍在成阵列压来**（数量已满屏）——蓄力不能把背景抽空；
- 机位**极速仰拍**，满屏能量涡旋 + 四周压来的敌潮剪影；
- **蓄力中绝不停顿**（"零顿帧"）。

### 5.2 尾帧定格（收束）

- **源稿采用末帧接续时，末镜 13.5s 起**：镜头运动收束、人物停止大幅动作（**收束窗**）；**末镜末 1s 整秒**：全体人物（或主角）保持姿态与站位、动作完全静止、**画面定格**（**2026-10-12 用户裁定 · 整秒硬定格，剪辑时整秒剪除**）；
- 定格帧要**干净利落**：主角姿态完美、碎光飘落、战场空无活物（或只剩残局）；
- **定格帧的双重作用**：① 艺术收束（逼格拉满）；② **作段缝依据**——可直接截取该末帧作下一段的画面依据（承接总控 `short-drama-director/references/segment-splicing.md` 尾帧锚定法，一致性 100%、成本 0）；
- 定格**必须发生在终结动作完成之后**（未杀完的定格、收势未完成的定格 = 违规）。
