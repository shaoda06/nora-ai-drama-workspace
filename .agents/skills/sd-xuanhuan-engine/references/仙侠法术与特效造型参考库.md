# 仙侠法术与特效造型参考库

用于选择法术形态、材质、规模和环境作用。按当前元素与用途检索，不默认将所有候选加入同一场。具体成分参考[元素材质库](xuanhuan-elements-vfx.md)，剑阵与法相的空间表达参考[大场面规则](grand-scale-domains.md)，招式过程参考[法武招式库](arsenal-moves-library.md)。

| 类别 | 外观设计可选维度 | 转成动态场面时需要补足 |
| --- | --- | --- |
| 火系 | 火环、旋流、焰刃、飞散火雨及凝聚的实体轮廓 | 点燃与聚集位置、移动路径、热与光对环境的作用、熄灭或残留 |
| 冰水系 | 冰晶棱面、水幕、冰刃、冻结边界和流动层次 | 冻结或汇流先后、破裂与飞散方向、接触物状态变化 |
| 雷风系 | 分叉电弧、具有厚度的雷刃、涡旋与风压轨迹 | 能量起点、传播和释放、衣料碎屑反馈，保持攻击方向可读 |
| 剑阵 | 阵环、剑群的近中远层次、硬质剑身与刃光 | 展开、离阵、分路、命中及回收；阵环不能代替飞剑运动 |
| 结界与幻术 | 边界、透明度、折射、空间变形或虚实层次 | 建立条件、被触碰时的反应、解除后的真实状态 |
| 召唤与法相 | 轮廓、材质、人物与环境的尺度关系 | 从出现到形成的过程、与施法者的关系、动作影响及消散 |
| 治愈与飞升 | 光点流向、局部恢复、上升与环境变化 | 谁受到何种变化、持续时间与结束状态；不借特效新增世界规则 |

每个采用方案明确施法媒介、形成—释放—作用—结束过程、对手应对及环境反馈。静态造型可供资产设计，动作与空间过程在剧本／分镜确定；不要将一张漂亮示例直接当成完整视频动作。配色、风格、角色和结局以项目依据为准。
