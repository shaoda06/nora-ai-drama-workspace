# 04 · 十三类三层复合元素与玄幻特效体系 (Xuanhuan Elements & VFX Arsenal)

---

## 法术表现设计与落地

本节用于选择和展开玄幻法术的可见表现。法术形态、材质与运动在此统一维护；造型候选见[仙侠法术与特效造型参考库](仙侠法术与特效造型参考库.md)，大型阵法、剑群与法相的空间方法见[尺度方法](grand-scale-domains.md)。下方元素配比与造型是可调整的设计参考，不是要求每种法术同时具有水墨、硬质核心和流体，也不规定所有项目使用同一规模、颜色或笔法。

### 表现力度与画风

修仙、仙侠、国风玄幻项目中的已成立法术，应主动设计足以体现其性质和力度的视觉表现。粒子、剑气流光、灵力抽丝、阵纹流转、能量拖尾及空间波动均可按招式需要使用，不要求用户逐项点名才启用；不因担心画面复杂或模型难理解，自动缩成细光线、微弱闪光和零散亮点。选择与当前攻防相称的强度，蓄势、侵入、相持可以细密而有压迫，重击、爆发应有明显的密度、速度和形态变化，不把每次试探都改成毁天灭地。

表现力通过清晰的形态、动量、层次和环境响应建立。先按项目画风选择表现方法：三维国漫可用通透阵面、体积流动、晶体折射、丝束和有厚度的流光；水墨或手绘项目再采用[介质与笔法](../../sd-combat-engine/references/vfx-rendering-mandate.md)中的适用方法。不能把“发光”一概视为廉价，也不能把“国风”一律转成水墨。

### 从法术名称写成画面过程

每个承担叙事作用的法术，明确来源与归属、形态与材质、运动路径、作用目标、接触变化及结束状态。把这些写进自然句，不另交参数表，也不只给“强大剑气”“高级粒子”“炫酷法阵”等名称。具体选择如下，按本镜需要取用，不把全表叠在每一招上：

| 表现类型 | 应明确的可见过程 |
| --- | --- |
| 粒子、星尘、瓣屑 | 从阵轨、瓣根、兵刃或实际碰撞点产生；沿轨道汇流、螺旋卷入或定向喷散；有加速、拖尾、减速与消散。近处颗粒较大且有视差，中层形成主体流向，远处更细更暗；亮核、雾层、碎屑按材质选用，不将所有颗粒画成同样的静态光点。 |
| 剑气、流光与能量拖尾 | 区分兵刃附着、离刃飞行和运动残留；写出刃锋或流光前端、主体厚薄、边缘丝缕或碎光、沿挥击弧线或攻击轴线的速度变化，以及接触后的剥裂、折向或散开。细锐剑芒、翻卷光带、成束流光各有用途，不强制全部变成厚重绸缎。 |
| 灵力抽丝、牵引与侵入 | 写清从何种载体抽出，细流怎样分岔成丝、并束、盘绕、拉长或收紧，游丝与主束的关系；受力后有弧度变化、波动与回弹。侵入效果明确从谁的接触点沿何路径向谁推进；能量丝可通透、流动、带辉光与剥落微粒，不能无依据长成实体钢丝，也不能靠加粗一条直线表现全部变化。 |
| 法阵、阵纹与阵眼 | 阵眼供力、阵脉传导、符纹逐段点亮、阵层翻转或交错，形成可辨的控制关系；接触后局部弯压、偏斜、断流或重组，再交代能量去向。星宿连线、古篆几何纹、莲瓣、阴阳结构等按已定设计选择，不混贴全部符号，也不自动采用科技界面外观。 |
| 对撞、压制与破阵 | 能量确实接触承力面，接点压缩、扭曲或剥落，随后沿阻力方向反弹、分流或突破；用分层飞散、阵面形变、角色受力、衣发与薄水反应等呈现冲击，不能只有两团光接近后闪一下。 |

例如：剑锋向前挑出，一束银青剑气从刃口拉长，前端收成细锐弧刃，后方流光分出数缕游丝；撞上结界时弧刃弯压，冰青晶屑沿接面两侧迸散，剩余流光绕过裂口后逐渐断成细粒。牵引法术则可从阵纹交点抽出通透丝束，主束随指势收紧，外围游丝螺旋并入；外来花脉从附着花瓣沿丝束向手端攀行，红金粒流跟随其前端，手端保持接收而非发射。例子只说明过程，不设定项目必须采用的能力、配色或动作。

### 强效果与画面可读性

“不遮住关键内容”应通过构图、前后层、局部密度、明暗、透明度和爆发时点解决，不自动降低整招强度。接点可以强烈爆发，但保留辨认来源、接触和受力的清晰区域；爆发后及时疏开，让变化结果显露。近处游离碎光可越出画框，主体法术也可部分在画外，不为完整展示而塞入全部人物、阵层、道具或地标。

### 表现核对

检查实际画面描述是否交代：法术从哪里来、怎样形成和运动、碰到什么、改变了什么、怎样结束；角色颜色与传播方向是否一致；已选粒子、流光、抽丝等是否具有具体材质和动态，而非在转写时被删成“亮起”“闪过”。核对选定强度是否有足够的速度、密度、形变或环境反馈，是否把“清晰”误写成“微弱”；保留辨认人物、主阵纹和关键接触的区域。检查适用的效果，不强制每镜出现全部类型，也不要求每次命中都有爆白、烟雾或震屏。

## 一、 能量四态系统（先定形再有光）

严禁使用“一团光芒”、“强烈能量束”等无轮廓描述，能量必须归属于以下四态之一：

1. **态一 · 附着态（贴刃缠身）**：能量死死咬在兵器或肢体表面。剑脊走主流能量，刃口烧至白炽最锐，金色/紫色电弧顺金属纹理螺旋攀附。挥斩时爆亮延展，收势瞬间回缩贴刃。
2. **态二 · 脱体态（斩击光刃）**：离开载体独立飞行的实体。具备明确的几何截面（半月形、月牙薄刃、破空光锥），厚度扁平，边缘带水墨飞白或锯齿，飞行时切割空气留痕。
3. **态三 · 聚集体（万剑/法阵群流）**：先钉单体、再写集合。单体为标准尺寸冷银飞剑（剑尖向前、剑柄在后），整体按三维鱼群组织（前部错层锋线、中部穿插补位、后部追入回填），外部机位展现宏观流动，禁止平面剑板。
4. **态四 · 移动气场态（流向尾流）**：静止蓄力时能量向心汇聚翻涌；极速位移时衣摆与属性真气被风压倒拽，拉出锥形流光长拖尾，身体前端形成透明空气音爆锥。

## 二、 三混合配比法则 (The Tri-Blend VFX Ratio)

每种特效在三层结构基础上，按元素属性分配三种视觉成分比例：
$$\text{特效} = \text{硬质能量体 (\%)} + \text{水墨飞白 (\%)} + \text{流体沙尘/浪涌 (\%)}$$

| 元素属性 | 能量体% (硬核光刃) | 水墨% (飞白写意) | 流体% (雾/烟/沙/水) | 视觉特征与质感 |
|---|---|---|---|---|
| **水墨剑气** | 30% | 50% | 20% | 泼墨写意、枯笔飞白、墨滴飞溅 |
| **墨黑紫电 (刀)** | 45% | 25% | 30% | 浓稠墨流 + 边缘暗红血纹 + 表面跳跃紫电 |
| **赤红火枪** | 55% | 10% | 35% | 熔岩翻涌 + 金色螺旋符文 + 前端白色激波 |
| **暗金拳气 (体修)** | 55% | 15% | 30% | 液态暗金金属光泽 + 纯白激波 + 土黄石屑 |
| **紫蓝神雷** | 60% | 20% | 20% | 刺目紫蓝电柱 + 纯白分叉电弧 + 空间黑色裂隙 |
| **金橙烈焰** | 50% | 10% | 40% | 金色火核 + 橙红翻涌火浪 + 螺旋升腾黑烟 |
| **幽蓝寒冰** | 40% | 10% | 50% | 锐利幽蓝冰晶 + 纯白浓厚霜雾 + 冰水飞溅 |
| **透翠风刃** | 45% | 15% | 40% | 透明压缩气刃 + 翠绿流动风纹 + 金色光边 |
| **黑紫虚空** | 50% | 30% | 20% | 绝对纯黑虚空裂隙 + 边缘紫色余烬 + 金色扭曲纹 |
| **土褐金岩** | 30% | 10% | 60% | 悬浮碎石 + 地脉龟裂 + 纯金符文 |
| **金紫黑神识** | 40% | 35% | 25% | 精神涟漪 + 视界畸变 + 墨色阴影扩散 |
| **纯金圣光** | 60% | 10% | 30% | 纯净炽烈圣芒 + 金羽飘散 + 净化光晕 |
| **暗黑死气** | 35% | 35% | 30% | 浓黑腐蚀雾流 + 灰烬颗粒 + 阴寒死寂 |

## 三、 十三类三层复合元素标准库全解

1. **水墨黑白三层（剑仙/居合专属）**：外层水墨晕染飞白 + 中层青蓝水浪翻涌 + 内层白炽冰晶核心，边缘附着金色细碎流光符文。
2. **墨黑紫电三层（魔宗狂刀专属）**：主体浓稠墨黑吸光液态流体 + 边缘暗红搏动血纹 + 表面狂暴跳跃纯紫锯齿电弧，末端爆裂细碎火星。
3. **赤红三层（长枪/霸王枪专属）**：主体半透明赤红熔岩能量 + 表面金色螺旋转动符文 + 前端纯白高压激波锥。
4. **暗金白三层（体修/金刚拳宗专属）**：主体暗金液态真气（厚重金属质感）+ 前端纯白压缩激波 + 周围环绕土黄石屑与金色古道纹。
5. **紫蓝白三层（九霄神雷专属）**：主体紫蓝粗壮雷柱（内部电浆翻腾）+ 纯白树枝状分叉跳跃电弧 + 外围金色雷印，伴随黑色细微空间裂隙。
6. **金橙黑三层（焚天火刃专属）**：主体纯金火核 + 边缘橙红翻涌火浪 + 外层黑色螺旋升腾烟尘，高温使空气剧烈热浪扭曲。
7. **幽蓝白三层（玄冰剑修专属）**：主体幽蓝半透明冰晶 + 中层纯白浓厚霜雾 + 外层蓝色水浪流动，表面浮现六边形冰裂符文。
8. **透翠绿三层（风系神速专属）**：主体完全透明高压风刃 + 中层翠绿流动风纹 + 边缘金色极细光芒。
9. **土褐金三层（地脉厚土专属）**：主体粗糙土黄岩石尖刺 + 中层深褐地脉裂隙 + 外层金色厚土符文。
10. **黑紫金三层（虚空裂隙专属）**：主体纯黑虚空裂缝（吞噬一切光线）+ 边缘紫色飘散余烬 + 周围金色空间扭曲碎纹。
11. **金紫黑三层（神识摄魂专属）**：主体金色精神水波纹 + 中层深紫神念流体 + 外层墨色阴影扩散。
12. **金白羽三层（圣道金身专属）**：主体纯金神圣光柱 + 中层白炽净化光芒 + 外层飘落的金色羽刃与神圣光轮。
13. **暗绿毒瘴三层（万毒魔煞专属）**：主体墨绿腐蚀性流体 + 中层惨绿翻腾毒雾 + 表面暗紫气泡爆裂。

## 四、 角色劲气性格库与冷暖色彩对冲

### 1. 经典角色签名劲气速查
* **太极**：黑白阴阳双色，螺旋凝聚尖锥与重甲，刚柔并济；
* **白鸽**：紫黑色气焰，新月弧刃与飞旋刀轮，踢技轨迹强可视化；
* **红茶**：橙红色爆裂火焰，一击一炸，蛮力与热浪翻涌；
* **凛羽**：冰蓝银白霜雾，寒气渗透如纱如雾，唯有终结技化作冰暴；
* **雷电**：纯紫与银白电弧，零前摇瞬闪残影，雷光撕裂虚空；
* **芭乐**：浅粉渐变至深粉，花瓣飘散到花蕾暴风，越打越浓烈；
* **冰女**：蓝白渐变硬冰，结晶蔓延与冰刺封杀，触碰即冻结；
* **剑神**：红紫色瞬闪光轨，剑尖细锐白光、剑脊紫铜火星，出剑即收；
* **绯雪**：火红刀焰，沿刀锋前扑吞咬，贴脸连斩，火潮断空。

### 2. 冷暖色彩对抗铁律
* **同色相撞大忌**：严禁“蓝剑打蓝雾”、“黑焰打黑夜”，视觉缺乏辨识度。
* **高反差对冲**：暖色能量（赤红/金橙）必须砸在冷色环境或冷色防御（青黑/深蓝）上；冷色能量（冰白/紫电）必须撕裂暖调光尘。
* **三方强分离**：`主冲击色 vs 敌人主体色 vs 场景基底色` 必须两两可辨。
