# Nora 社交媒体主页视觉

负责 Nora 项目的社交媒体账号头像与主页背景图，作为主控下的可选专项；账号名称、简介、注册、发布和运营不在本技能范围。沿用[主控读取范围](../nora-ai-short-drama/SKILL.md#读取范围)与[规则优先级](../nora-ai-short-drama/SKILL.md#外部技能协作与规则优先级)。

## 按任务读取

先确定项目、目标平台、账号、图片用途及当前动作，再进入对应资料。已有信息直接复用，不要求每次读取全部参考文件。

| 当前任务 | 读取入口与本次交付 |
| --- | --- |
| 确定头像或背景图技术规格 | 按[平台规格库](references/平台规格库.md)读取目标平台章节，确认本次图片用途的规格；其他平台重新选择，不沿用上一平台的数值 |
| 讨论画面、构图、表情、配色及搭配 | [设计规范](references/设计规范.md)及本项目已确认资料；给出具体可比较方案，只讨论时不生成或写项目文件 |
| 准备提示词或根据反馈修订 | [参考与提示词](references/设计规范.md#参考与提示词)；背景图布局或遮挡反馈另读[背景图方案与显示适配](references/设计规范.md#背景图方案与显示适配)，结合本批选定方案及目标平台规格 |
| 已授权生成、取回、尺寸处理与交付 | [生成与记录规范](references/生成与记录规范.md)，衔接[Nora生成执行](../nora-generation/SKILL.md) |
| 正式保存、采用或替换 | 按下方[保存与采用](#保存与采用)维护文件、索引及决定；首次建工作稿再读取模板 |

头像和背景图独立确定、授权及采用；只执行本批已明确的对象与动作。平台参数由平台资料维护，人物形式、配色、文案和构图由本项目方案确定，不在本入口预设。

## 保存与采用

读取[保存与采用规范](references/保存与采用规范.md)处理目录、命名、候选、正式图和历史来源；新建账号工作稿使用[主页视觉工作稿模板](references/主页视觉工作稿模板.md)。
