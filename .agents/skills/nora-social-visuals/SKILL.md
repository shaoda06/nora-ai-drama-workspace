# Nora 社交媒体主页视觉

本技能是 Nora 主控下的可选制作专项，负责社交媒体头像与主页背景图，不增加短剧必经阶段。直接调用时沿用[主控读取范围与授权边界](../nora-ai-short-drama/SKILL.md#读取范围)及[规则优先级](../nora-ai-short-drama/SKILL.md#外部技能协作与规则优先级)。账号名称、简介、注册、发布和运营不纳入本技能。

## 按当前动作进入

| 动作 | 本次完成内容 |
| --- | --- |
| 讨论方案 | 按下方设计规则给可比较的构图、表情及搭配；只讨论时不生图、不写项目文件 |
| 准备或修订图片 | 明确本批对象、平台与账号、选定设计、参考图、目标规格和实际授权；按[生成与记录](references/生成与记录规范.md)衔接执行 |
| 取回或交付 | 复用原执行记录，只处理实际结果及必要尺寸处理，不重新创作或生成 |
| 用户采用或替换 | 在原工作稿登记具体文件、版本与采用范围，按下方保存规则维护索引和正式图 |

头像和背景图分别确定、分别授权、分别采用。头像已确定或已生成，不表示允许制作背景图；同批已明确两项时合并处理，不重复询问。

## 平台规格库

本技能面向多个社交媒体平台，不绑定抖音。先确定目标平台，再按[平台规格库](references/平台规格库.md)读取该平台章节；不同平台的头像、背景图规格及显示区域分别维护，不相互套用。新增平台按同一字段追加实际已知数据，不预填未核实的平台规范。

## 设计与规格

先按任务读取项目定位、所需人物资料、已采用视觉及其记录，提取本次设计依据；不默认重读全项目或查看全部图片。视频封面可以提供配色与图形参考，头像和背景图按各自用途重新构图，不默认裁切封面。

**头像**：先确定人物、符号或文字等表现方向，再讨论具体站位、前后关系、取景和表情。头像交付必须严格为1:1，宽高相等，边长至少500像素；可以大于500，不设必须缩到500的步骤。这是本技能的交付下限，不冒充任何平台的官方最低要求；平台有已核实的更高下限时按较高值执行。原生图已满足比例与像素下限时直接送审，获采用后直接使用原生图。用于圆形展示时，脸、主要发型或核心图形集中在内接圆范围，四角不放重要内容，保留头顶及左右余量。小尺寸以清楚辨认主体和表情为先，避免堆入小字、装饰和复杂背景；不把圆形展示理解为需要交付圆框或透明圆形图片。

选用双人Q版时，两人应各有足够的面部面积，前后错开但不遮挡五官。用已确认人物的表情差异表现互动；不因可爱化擅自改变身份、基础发型、衣装或已确定关系。双人Q版、暖米白底、红蓝配色和某一种探头姿势均是可选设计，不是所有项目的固定画法。

**主页背景图**：按实际平台、客户端显示与本批设计讨论比例、主体、文字、留白及头像／昵称遮挡。与头像保持必要的配色、画法或图形联系，两图各有重点，不要求重复同一对大头像或同一段文字。背景图的固定布局、文案和像素标准随实际任务确定，不预填统一方案。

**规格依据**：分别记录平台官方要求、用户指定值和建议交付值。涉及当前平台限制时核实最新官方依据及适用账号类型；平台用户发布的教程不能当作官方规范。没有查到依据时如实记录，不把常见尺寸、最低像素、默认显示区域或遮挡位置写成平台硬性要求。用户给定的规格可以用于当前制作，但不据此声称已核实官方要求。

500×500表示头像的最小交付尺寸；例如1254×1254已达标，直接保留该尺寸，不为了对齐推荐值再缩小。只有用户明确要求精确输出尺寸，或已核实的平台上传限制确实要求处理时，才制作必要尺寸版本。背景图的尺寸与比例按目标平台及本批方案确定，不套用头像标准。

## 参考与生成边界

人物身份、造型和画法以本批指定的已批准参考图及记录为准；已有正式Q版图时实际传入Q版参考，不只靠真人图或文字重建。逐图注明版本、用途及保留项，多视图只提取人物设计，不复刻网格、标注与多个人物副本。Q版与真人等不同已确认形态按本次选择使用，不机械叠加互相冲突的画风正文。

源图资格与返修使用[图片提示词共用规则](../nora-drama-assets/references/图片提示词规范.md#源参考图与输入资格)，查看图片沿[主控看图边界](../nora-ai-short-drama/SKILL.md#看图能力调用边界)。本技能自由编写本次完整图片提示词，不设固定生图提示词模板；把头像构图、表情、背景、参考用途及保留范围写清楚即可。

能力选择、授权、实际生成和尺寸处理按[生成与记录](references/生成与记录规范.md)。既定设计与授权已完整时直接执行，不为重新列方案而重复确认；文件可解码或生成成功不代表用户已经采用。

## 保存与采用

项目内的账号视觉使用 `11-社交媒体资料/`，与 `10-封面资料/` 分开；首次实际落地时按需建立，不预建空目录。平台与账号代号用于区分物料，不将账号真实联系方式写入通用技能。

| 内容 | 固定位置或命名 |
| --- | --- |
| 正式索引 | `11-社交媒体资料/账号视觉索引.md` |
| 正式头像 | `11-社交媒体资料/头像/{平台}-{账号代号}-头像.png`；格式按本批约定变更扩展名 |
| 正式背景图 | `11-社交媒体资料/背景图/{平台}-{账号代号}-背景图.png` |
| 工作稿 | `11-社交媒体资料/其他资料/工作稿/{平台}-{账号代号}-主页视觉-工作稿.md`；使用[主页视觉工作稿模板](references/主页视觉工作稿模板.md) |
| 原生候选 | 工作稿同级 `素材/{平台}-{账号代号}-{头像或背景图}-候选-vNN-原生.png` |
| 尺寸处理版 | 同一素材目录，使用同一候选前缀加 `-{宽}x{高}`；原图保持 |
| 请求与结果附件 | `11-社交媒体资料/其他资料/执行附件/{平台}-{账号代号}-{头像或背景图}-生成记录-NNN/` |
| 被替换正式图与记录旧版 | `11-社交媒体资料/其他资料/历史版本/`；按[共用历史归档命名](../nora-ai-short-drama/references/共用规则/文件版本与工作稿规范.md#归档与版本留存)保存 |

索引逐项记录平台／账号、图片用途、正式文件、采用候选版本、实际宽高与格式、采用依据及处理记录；尚未采用的对象不填正式文件。工作稿分别维护头像和背景图状态，不把一张图片的批准扩展到另一张。

生成、尺寸处理和用户采用分别留证；获采用且达到本批交付规格后，才保存正式图并更新索引。既有暂存候选及记录保留原处，沿已有入口接续；技能建立不自动授权迁移、改名或采用它们。首次归位需有对应整理授权，并保留来源及引用。

浏览展示按[项目浏览规范](../nora-ai-short-drama/references/共用规则/项目浏览与同步规范.md)处理；当前解析器未支持的类型直接交付真实文件及记录链接，说明入口限制，不假称已接入，不修改共用网页来迁就单个项目。维护相关项目进度时仅更新本次对象，不改其他制作状态。
