# 平台规格库

按目标平台读取对应章节，平台之间分别维护数据。每个平台分别记录官方要求、用户提供参考和该平台当前采用的制作规格；使用官方要求时记录官方链接、适用账号／客户端及核实日期。用户提供参考可以作为设计输入，未经核实不标为官方要求。

新增平台时按本表字段追加独立章节：头像比例及平台像素限制、背景图尺寸／比例、默认显示区域与遮挡、支持格式／文件大小、资料依据及适用状态。只填实际掌握的项目，缺项明确待核实；不复制其他平台数值。平台数据更新不自动改变既有项目的图片或采用记录。

## 抖音

资料依据：用户提供的抖音头像及主页背景图技术规格。下表为用户参考资料，尚未完成最新官方依据核实；使用时结合目标账号客户端的实际显示，不能据此声称平台统一强制要求。

| 项目 | 已有参考与适用边界 |
| --- | --- |
| 头像制作规格 | 用户确认的抖音制作规格：必须严格1:1，宽高相等，边长至少500像素，可以更大；这是本平台的制作约定，不是技能通用标准，也不声称已核实为官方最低要求 |
| 头像展示 | 用户参考为圆形裁切展示；核心人脸／图形放中间圆形安全区，四角不放重要内容。原生图满足本平台制作规格时直接使用，不要求压到500×500 |
| 主页背景图尺寸 | 1125×633为用户提供的建议尺寸，用于该平台设计讨论，不作为所有平台或所有背景图的固定尺寸 |
| 背景默认显示区域 | 用户参考为中间1125×400；下方区域下拉可见。属于显示参考，未核实为所有客户端的一致行为 |
| 背景遮挡与排版 | 头像、昵称及顶部界面元素会覆盖部分背景；已有用户客户端截图中，头像位于左下、昵称覆盖中下区域，不能概括为固定左上遮挡。其他客户端或布局变化仍结合当前截图确认，文字和主体按实际可见区域布局 |
| iPhone显示适配参考 | 用户实机反馈为：靠上的背景文字可能被灵动岛遮挡。顶部留白需结合当前设备与抖音实际显示确定，不仅依据完整图片的预览排版；不预设统一下移距离或百分比。此项是设备适配参考，不作为所有iPhone、抖音客户端或其他平台的一致规格 |
| 格式与文件大小 | 用户参考为JPG／PNG，避免文件过大及大量小字；具体格式限制、文件大小上限和压缩行为待官方核实，不自行填数值 |

其他平台按需增加章节；未登记平台不沿用抖音数据。背景图的画面方案、文字及具体制作细则随实际任务补充。
