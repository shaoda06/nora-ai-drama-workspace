# 保存与采用规范

项目内的账号视觉使用 `11-社交媒体资料/`，与 `10-封面资料/` 分开；首次实际落地时按需建立，不预建空目录。平台与账号代号用于区分物料，不将账号真实联系方式写入通用技能。

| 内容 | 固定位置或命名 |
| --- | --- |
| 正式索引 | `11-社交媒体资料/账号视觉索引.md` |
| 正式头像 | `11-社交媒体资料/头像/{平台}-{账号代号}-头像.{扩展名}` |
| 正式背景图 | `11-社交媒体资料/背景图/{平台}-{账号代号}-背景图.{扩展名}` |
| 工作稿 | `11-社交媒体资料/其他资料/工作稿/{平台}-{账号代号}-主页视觉-工作稿.md`；使用[主页视觉工作稿模板](主页视觉工作稿模板.md) |
| 原生候选 | 工作稿同级 `素材/{平台}-{账号代号}-{头像或背景图}-候选-vNN-原生.{扩展名}` |
| 尺寸处理版 | 同一素材目录，使用 `{平台}-{账号代号}-{头像或背景图}-候选-vNN-{宽}x{高}.{扩展名}`；原图保持 |
| 请求与结果附件 | `11-社交媒体资料/其他资料/执行附件/{平台}-{账号代号}-{头像或背景图}-生成记录-NNN/` |
| 被替换正式图与记录旧版 | `11-社交媒体资料/其他资料/历史版本/`；按[共用历史归档命名](../../nora-ai-short-drama/references/共用规则/文件版本与工作稿规范.md#归档与版本留存)保存 |

文件扩展名对应实际文件格式；原生图沿其实际格式保存，交付格式按目标平台和本批约定选择，不将某个平台可用的格式设为通用固定格式。

候选前缀由该用途的正式图片名去掉扩展名确定，沿[共用命名要求](../../nora-ai-short-drama/references/共用规则/文件版本与工作稿规范.md#素材与执行附件)保持同一身份。`原生`与具体宽高是本专项规定的版本标识，不再追加工具、模型或任意说明后缀。

索引逐项记录平台／账号、图片用途、正式文件、采用候选版本、实际宽高与格式、采用依据及处理记录；尚未采用的对象不填正式文件。工作稿分别维护头像和背景图状态，不把一张图片的批准扩展到另一张。

生成、尺寸处理和用户采用分别留证；获采用且达到本批交付规格后，才保存正式图并更新索引。既有暂存候选及记录保留原处，沿已有入口接续；技能建立不自动授权迁移、改名或采用它们。首次归位需有对应整理授权，并保留来源及引用。

实机试用、位置修订和新版采用继续记录在同一账号工作稿；“先试一下”不等于正式采用。采用、替换及结束比较按[主控完成标准](../../nora-ai-short-drama/SKILL.md#完成标准)完成状态收尾，正式索引引用对应候选的同一审阅决定。正式路径被新版替换后，在旧版原采用记录补上归档入口，保留当时批准事实，避免该路径被误认为仍指向旧图。

浏览展示按[项目浏览规范](../../nora-ai-short-drama/references/共用规则/项目浏览与同步规范.md)处理；当前解析器未支持的类型直接交付真实文件及记录链接，说明入口限制，不假称已接入，不修改共用网页来迁就单个项目。维护相关项目进度时仅更新本次对象，不改其他制作状态。
