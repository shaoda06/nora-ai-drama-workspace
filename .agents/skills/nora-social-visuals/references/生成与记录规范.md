# 生成与记录规范

本文件只维护社交媒体头像、主页背景图的执行衔接和记录；设计、规格及目录由[技能入口](../SKILL.md)维护。实际执行进入[Nora生成技能](../../nora-generation/SKILL.md)，不在本技能另建模型、工作流或后台监控。

## 能力与授权

沿[主控生成选型](../../nora-ai-short-drama/SKILL.md#当前参考图生成选型)确认本批能力、对象及数量。默认建议内置Imagegen，其他能力为按实际可用性选择的备选；默认偏好不代替本批授权，已明确选择则不重复询问。只写方案或提示词不调用生成。

内置Imagegen复用[任务与提示词](../../nora-generation/references/Imagegen生成与尺寸处理规范.md#1-任务与提示词)、[子代理执行](../../nora-generation/references/Imagegen生成与尺寸处理规范.md#子代理执行与父代理交付)的固定执行代理、真实工具调用、输入读取、结果转发和一次调用边界。社交图片不属于既有固定收尾脚本的五种登记类型，交接及记录使用下方专用衔接；不冒充人物基础图、剧集素材或封面，不向不支持的接口提交伪造类别。

## 社交图片交接与结果

1. 内容负责人按已确定的任务准备完整提示词、顺序明确的参考图与用途／批准依据、请求比例、交付目标、授权数量，以及本次候选和原工作稿入口。请求JSON和实际提示词TXT保存在本次执行附件；这些是本批数据，不新增调用脚本或独立台账。
2. 按Imagegen规范的固定模型、等级及 `fork_turns` 派发执行子代理。子代理按当前工具说明调用内置Imagegen，原样提交本次正文和参考图，在同次调用中先保存完整返回值再转发图像。单项交接只执行一次；原生尺寸差异不自动重试，收尾失败只恢复保存与记录，不重生图。
3. 子代理使用工具真实输出路径，将原字节复制到本次原生候选位置，保留工具输出；核对可解码性、真实尺寸、格式及数量，保存实际调用结果凭据JSON。来源不明时按Imagegen规范回报缺项，不猜测其他任务的最新文件，不自动看新输出。
4. 子代理按[主页视觉工作稿模板](主页视觉工作稿模板.md)在原稿补齐生成和待审记录，并返回原生图路径、实际规格、记录入口和真实异常。这里按专用记录保存文件，不调用只支持旧类型的 `imagegen_results.py prepare/complete`，也不伪造其成功报告或网页核验。父代理复用已完成的技术核对，直接交付候选；未支持的网页栏目不作为已同步结果。

此专用衔接仅用于头像与主页背景图；既有五类图片仍使用原固定脚本，不因这一分支改成手工登记。使用Qwen等备选能力时，先按其现行执行入口核实本用途能否如实提交与登记；不支持时说明具体限制，不借用别的图片类型绕过，不自动改工具或共用代码。

## 尺寸处理与交付

保留原生图与实际尺寸。头像按[头像交付标准](../SKILL.md#设计与规格)核对严格1:1及最小边长；背景图核对目标平台和本批选定规格。头像原生图已达标时，直接送审及按用户决定采用，不额外缩小；提到推荐值或最小尺寸不等于要求精确输出该像素。仅在用户明确要求精确尺寸或已核实的平台上传限制确有需要时，制作相应尺寸版本并与原图关联，不把处理版标为原生图。原生图不满足比例或像素下限时如实记录，按本批授权完成必要处理，不把接近1:1写成已严格达标。裁切、补边和扩图按其实际授权处理；不为凑尺寸拉伸人物或自动裁掉重要内容。只有确需提高分辨率时才考虑超分，并沿[图片后处理方式选择](../../nora-generation/references/ComfyUI-图片超分执行规范.md#指定尺寸处理的方式选择)执行。

同一张画面的原生与尺寸处理版不计为两次生图。处理记录保存在该次执行附件，写明输入／输出、原尺寸／目标尺寸、实际方法、是否裁切及授权依据，并在工作稿关联。新图片的采用决定由用户作出，不以“开始下一件事”推定上一张已经采用。

交付展示本次候选，给出可用文件链接及真实规格，简述使用能力、必要处理和待审状态。只展示一份主要预览，原生图、处理版和提示词按需提供链接；不为交付额外生成圆形裁切图、拼图或第二张方案。用户明确要求预览或内容检查时再按该范围处理。
